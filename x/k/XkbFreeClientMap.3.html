XkbFreeClientMap(3)

الحزمة: libx11

التراخيص: MIT AND X11

XkbFreeClientMap(3) وظائف XKB XkbFreeClientMap(3)

الاسم

XkbFreeClientMap - تحرير الذاكرة المستخدمة بواسطة عضو خريطة العميل في بنية XkbDescRec

الملخص

void XkbFreeClientMap (XkbDescPtr xkb, unsigned int which, Bool free_all);

المعاملات

xkb
وصف لوحة المفاتيح الذي يحتوي على خريطة العميل لتحريرها
which
قناع يحدد مكونات الخريطة للتحرير
free_all
صحيح => تحرير جميع مكونات العميل والخريطة نفسها

الوصف

تقوم XkbFreeClientMap بتحرير مكونات خريطة العميل المحددة بواسطة which في بنية XkbDescRec المحددة بواسطة المعامل xkb وتعيين قيم مكونات البنية المقابلة إلى NULL. يحدد المعامل which مجموعة من أقنعة خريطة العميل المعروضة في الجدول 1.

إذا كان free_all صحيحًا، يتم تجاهل which؛ تقوم XkbFreeClientMap بتحرير كل مكون بنية غير فارغ في خريطة العميل، وتحرر بنية XkbClientMapRec المشار إليها بواسطة العضو map للمعامل xkb، وتعيين العضو map إلى NULL.

الجدول 1 أقنعة XkbAllocClientMap
القناع التأثير
XkbKeyTypesMask يحدد حقل type_count عدد الإدخالات المطلوب تخصيصها مسبقًا للحقل types لخريطة العميل. إذا كان حقل type_count أقل من XkbNumRequiredTypes، فإنه يُرجع BadValue.
XkbKeySymsMask تُستخدم حقلا min_key_code و max_key_code للمعامل xkb لتخصيص حقلي syms و key_sym_map لخريطة العميل. يتم تخصيص الحقول لاحتواء الحد الأقصى لعدد الإدخالات اللازمة لـ max_key_code - min_key_code + 1 مفاتيح.
XkbModifierMapMask تُستخدم حقلا min_key_code و max_key_code للمعامل xkb لتخصيص الحقل modmap لخريطة العميل. يتم تخصيص الحقل لاحتواء الحد الأقصى لعدد الإدخالات اللازمة لـ max_key_code - min_key_code + 1 مفاتيح.

ملاحظة: يجب أن تكون حقلا min_key_code و max_key_code للمعامل xkb قيمًا صالحة إذا تم تعيين أقنعة XkbKeySymsMask أو XkbModifierMapMask في المعامل which. إذا لم تكن صالحة، تُرجع XkbAllocClientMap BadValue.

البنى

الوصف الكامل للوحة مفاتيح Xkb مُعطى بواسطة XkbDescRec. تمثل مكونات البنية في XkbDescRec المكونات الرئيسية لـ Xkb.

typedef struct {
   struct _XDisplay * display;      /* connection to X server */
   unsigned short     flags;        /* private to Xkb, do not modify */
   unsigned short     device_spec;  /* device of interest */
   KeyCode            min_key_code; /* minimum keycode for device */
   KeyCode            max_key_code; /* maximum keycode for device */
   XkbControlsPtr     ctrls;        /* controls */
   XkbServerMapPtr    server;       /* server keymap */
   XkbClientMapPtr    map;          /* client keymap */
   XkbIndicatorPtr    indicators;   /* indicator map */
   XkbNamesPtr        names;        /* names for all components */
   XkbCompatMapPtr    compat;       /* compatibility map */
   XkbGeometryPtr     geom;         /* physical geometry of keyboard */
} XkbDescRec, *XkbDescPtr;
يشير الحقل display إلى بنية عرض X. الحقل flags خاص بالمكتبة: تعديل flags قد يؤدي إلى نتائج غير متوقعة. يحدد الحقل device_spec معرف الجهاز لجهاز إدخال لوحة المفاتيح، أو XkbUseCoreKeyboard، الذي يحدد جهاز لوحة المفاتيح الأساسي. يحدد حقلا min_key_code و max_key_code أقل وأكبر رمز مفتاح يمكن إرجاعه بواسطة لوحة المفاتيح.

كل مكون بنية لديه بت قناع مطابق يُستخدم في استدعاءات الوظائف للإشارة إلى أنه يجب معالجة البنية بطريقة ما، مثل تخصيصها أو تحريرها. تُظهر هذه الأقنعة وعلاقاتها بالحقول في XkbDescRec في الجدول 2.

الجدول 2 بتات الأقنعة لـ XkbDescRec
بت القناع حقل XkbDescRec القيمة
XkbControlsMask ctrls (1L<<0)
XkbServerMapMask server (1L<<1)
XkbIClientMapMask map (1L<<2)
XkbIndicatorMapMask indicators (1L<<3)
XkbNamesMask names (1L<<4)
XkbCompatMapMask compat (1L<<5)
XkbGeometryMask geom (1L<<6)
XkbAllComponentsMask جميع الحقول (0x7f)

الحقل map لوصف لوحة مفاتيح Xkb الكامل هو مؤشر إلى خريطة عميل Xkb، وهي من نوع XkbClientMapRec:

   typedef struct {                   /* Client Map */
      unsigned char     size_types;   /* # occupied entries in types */
      unsigned char     num_types;    /* # entries in types */
      XkbKeyTypePtr     types;        /* vector of key types used by this keymap */
      unsigned short    size_syms;    /* length of the syms array */
      unsigned short    num_syms;     /* # entries in syms */
      KeySym *          syms;         /* linear 2d tables of keysyms, 1 per key */
      XkbSymMapPtr      key_sym_map;  /* 1 per keycode, maps keycode to syms */
      unsigned char *   modmap;       /* 1 per keycode, real mods bound to key */
} XkbClientMapRec, *XkbClientMapPtr;
