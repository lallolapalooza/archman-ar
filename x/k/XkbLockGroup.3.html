XkbLockGroup(3)

الحزمة: libx11

التراخيص: MIT AND X11

XkbLockGroup(3) XKB FUNCTIONS XkbLockGroup(3)

الاسم

XkbLockGroup - قفل مجموعة المفاتيح

الخلاصة

Bool XkbLockGroup (Display *display, unsigned int device_spec, unsigned int group);

الوسائط

display
الاتصال بخادم X
device_spec
معرف الجهاز، أو XkbUseCoreKbd
group
فهرس مجموعة المفاتيح المراد قفلها

الوصف

XkbLockGroup يرسل طلباً إلى الخادم لقفل group المحدد ولا ينتظر رداً. يعيد القيمة True إذا تم إرسال الطلب و False بخلاف ذلك.

استخدم الثوابت الرمزية التالية للإشارة إلى فهارس مجموعات المفاتيح:

الجدول 1 أسماء المجموعات الرمزية
الاسم الرمزي القيمة
XkbGroup1Index 0
XkbGroup2Index 1
XkbGroup3Index 2
XkbGroup4Index 3

قيم الإرجاع

True
تعيد الدالة XkbLockGroup القيمة True عندما يتم إرسال طلب إلى الخادم لقفل group المحدد ولا تنتظر رداً.
False
تعيد الدالة XkbLockGroup القيمة False إذا لم يتم إرسال الطلب.
