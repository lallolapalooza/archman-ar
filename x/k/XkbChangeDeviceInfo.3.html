XkbChangeDeviceInfo(3)

الحزمة: libx11

التراخيص: MIT AND X11

XkbChangeDeviceInfo(3) وظائف XKB XkbChangeDeviceInfo(3)

الاسم

XkbChangeDeviceInfo - تحديث وصف الخادم لجهاز بالتغييرات الملحوظة في XkbDeviceChangesRec

المُلَخَّص

Bool XkbChangeDeviceInfo (Display *dpy, XkbDeviceInfoPtr device_info, XkbDeviceChangesPtr changes);

المُعاملات

dpy
الاتصال بخادم X
device_info
نسخة محلية من حالة الجهاز وتكوينه
changes
ملاحظة تحدد التغييرات في device_info

الوصف

تُحدِّث XkbChangeDeviceInfo وصف الخادم للجهاز المحدد في device_info->device_spec بالتغييرات المحددة في changes والموجودة في device_info. يتم إجراء التحديث بواسطة طلب XkbSetDeviceInfo.

الهياكل

يمكن تتبع التغييرات على جهاز امتداد Xkb عن طريق الاستماع إلى أحداث XkbDeviceExtensionNotify وتجميع التغييرات في بنية XkbDeviceChangesRec. يمكن بعد ذلك استخدام التغييرات الملحوظة في البنية في العمليات اللاحقة لتحديث تكوين الخادم أو نسخة محلية من تكوين جهاز امتداد Xkb. تم تعريف بنية التغييرات على النحو التالي:

typedef struct _XkbDeviceChanges {
    unsigned int         changed;        /* bits indicating what has changed */
    unsigned short       first_btn;      /* number of first button which changed, if any */
    unsigned short       num_btns;       /* number of buttons that have changed */
    XkbDeviceLedChangesRec leds;
} XkbDeviceChangesRec,*XkbDeviceChangesPtr;
