XkbGetMap(3)

الحزمة: libx11

التراخيص: MIT AND X11

XkbGetMap(3) وظائف XKB XkbGetMap(3)

الاسم

XkbGetMap - تخصيص هيكل XkbDescRec وتعبئته بخريطة العميل وخريطة الخادم للوحة المفاتيح الخاصة بالخادم

الملخص

XkbDescPtr XkbGetMap (Display *display, unsigned int which, unsigned int device_spec);

المعاملات

display
الاتصال بخادم X
which
قناع يحدد المكونات الفرعية التي سيتم تعبئتها
device_spec
معرف الجهاز، أو XkbUseCoreKbd

الوصف

توفر Xkb وظيفتين للحصول على مكونات خريطة لوحة المفاتيح من الخادم. الوظيفة الأولى، XkbGetMap، تقوم بتخصيص هيكل XkbDescRec، واسترداد مكونات الخريطة من الخادم، وتخزينها في هيكل XkbDescRec الذي قامت بتخصيصه للتو. الوظيفة الثانية، XkbGetUpdatedMap، تسترد مكونات الخريطة من الخادم وتخزنها في هيكل XkbDescRec تم تخصيصه مسبقًا.

لتخصيص هيكل XkbDescRec وتعبئته بخريطة العميل وخريطة الخادم للوحة المفاتيح الخاصة بالخادم، استخدم XkbGetMap. XkbGetMap مشابهة لـ XkbGetKeyboard، ولكنها تستخدم فقط للحصول على عنوان هيكل XkbDescRec الذي تم تعبئته بمكونات خريطة لوحة المفاتيح. تسمح بتحكم أدق في أي الهياكل الفرعية لمكونات خريطة لوحة المفاتيح سيتم تعبئتها. XkbGetKeyboard ترجع دائمًا مكونات مملوءة بالكامل، بينما يمكن تعليم XkbGetMap لإرجاع مكون مملوء جزئيًا.

which mask هو OR شامل للبتات من الأقنعة المعرفة في الجدول 14.1. فقط تلك الأجزاء من خريطة خادم لوحة المفاتيح وخرائط عملاء لوحة المفاتيح المحددة في which يتم تخصيصها وتعبئتها.

بالإضافة إلى تخصيص واسترداد خريطة الخادم وخريطة العميل، تقوم XkbGetMap أيضًا بتعيين الحقول device_spec و min_key_code و max_key_code لوصف لوحة المفاتيح.

XkbGetMap متزامنة؛ فهي تستعلم الخادم عن المعلومات المطلوبة، وتنتظر الرد، ثم تعود. إذا نجحت، تعود XkbGetMap بمؤشر إلى هيكل XkbDescRec الذي قامت بتخصيصه. إذا فشلت، تعود XkbGetMap بالقيمة NULL. عند الفشل، يتم أيضًا إنشاء أحد أخطاء البروتوكول التالية: BadAlloc (تعذر تخصيص هيكل XkbDescRec)، BadValue (بعض بتات القناع في which غير معرفة)، أو BadImplementation (إصدار متوافق من امتداد Xkb غير متاح في الخادم). لتحرير البيانات المرجعة، استخدم XkbFreeKeyboard.

توفر Xkb أيضًا وظائف مساعدة للحصول على تعريفات مكونات جزئية من الخادم. تم تحديد هذه الوظائف في عمود "الوظائف المساعدة" في الجدول 1. راجع الأقسام المدرجة في الجدول لمزيد من المعلومات حول هذه الوظائف.

الهياكل

الوصف الكامل للوحة مفاتيح Xkb يعطى بواسطة XkbDescRec. تمثل هياكل المكونات في XkbDescRec المكونات الرئيسية لـ Xkb.

typedef struct {
   struct _XDisplay * display;      /* connection to X server */
   unsigned short     flags;        /* private to Xkb, do not modify */
   unsigned short     device_spec;  /* device of interest */
   KeyCode            min_key_code; /* minimum keycode for device */
   KeyCode            max_key_code; /* maximum keycode for device */
   XkbControlsPtr     ctrls;        /* controls */
   XkbServerMapPtr    server;       /* server keymap */
   XkbClientMapPtr    map;          /* client keymap */
   XkbIndicatorPtr    indicators;   /* indicator map */
   XkbNamesPtr        names;        /* names for all components */
   XkbCompatMapPtr    compat;       /* compatibility map */
   XkbGeometryPtr     geom;         /* physical geometry of keyboard */
} XkbDescRec, *XkbDescPtr;
يشير الحقل display إلى هيكل عرض X. الحقل flags خاص بالمكتبة: قد يؤدي تعديل flags إلى نتائج غير متوقعة. يحدد الحقل device_spec معرف الجهاز لجهاز إدخال لوحة المفاتيح، أو XkbUseCoreKeyboard، الذي يحدد جهاز لوحة المفاتيح الأساسي. يحدد الحقلين min_key_code و max_key_code أقل وأكبر مفتاح يمكن إرجاعه بواسطة لوحة المفاتيح.

لكل مكون من المكونات الهيكلية بت قناع مقابل يتم استخدامه في استدعاءات الوظائف للإشارة إلى أنه يجب معالجة الهيكل بطريقة ما، مثل تخصيصه أو تحريره. يتم عرض هذه الأقنعة وعلاقتها بالحقول في XkbDescRec في الجدول 2.
