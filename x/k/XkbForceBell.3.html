XkbForceBell(3)

الحزمة: libx11

التراخيص: MIT AND X11

NAME

XkbForceBell, XkbForceDeviceBell - force a bell

SYNOPSIS

  #include <X11/Xlib.h>
  #include <X11/Xutil.h>
  #include <X11/extensions/XKBbells.h>

  void XkbForceBell(
      Display *display,
      int     device_spec,
      int     percent,
      int     pitch,
      int     duration
  );

  void XkbForceDeviceBell(
      Display *display,
      int     device_spec,
      int     percent,
      int     pitch,
      int     duration
  );

ARGUMENTS

o display
Specifies the connection to the X server.
o device_spec
Specifies the Xkb device whose bell is to be rung. This can be XkbUseCoreKbd, XkbUseCorePtr, or a specific device ID. It may also be XkbAllDevices to ring the bells on all devices. (This argument is only used by XkbForceDeviceBell).
o percent
Specifies the requested volume as a percentage of the maximum volume. A value of 0 means minimum volume, 100 means maximum volume.
o pitch
Specifies the desired pitch in Hertz (Hz).
o duration
Specifies the desired duration in microseconds.

DESCRIPTION

The XkbForceBell function is used to force a bell sound, either from the core keyboard device or from a device specified by device_spec.

XkbForceDeviceBell is identical to XkbForceBell.

If device_spec is XkbUseCoreKbd, the bell is forced on the core keyboard device. If device_spec is a specific device ID, the bell is forced on that device. If device_spec is XkbAllDevices, bells are forced on all bell-capable devices.

The parameters percent, pitch, and duration specify the desired characteristics of the bell. These values are only requests; the actual bell generated may differ depending on the capabilities of the bell device and the X server configuration.

Note that XkbForceBell and XkbForceDeviceBell generate bell events that are not reported to clients. To receive bell notifications, use XkbSelectEvents.

RETURNS VALUES

None.

STRUCTURES

Xkb generates XkbBellNotify events for all bells except for those resulting from calls to XkbForceDeviceBell and XkbForceBell. To receive XkbBellNotify events under all possible conditions, pass XkbBellNotifyMask in both the bits_to_change and values_for_bits parameters to XkbSelectEvents.

The XkbBellNotify event has no event details. It is either selected or it is not. However, you can call XkbSelectEventDetails using XkbBellNotify as the event_type and specifying XkbAllBellEventsMask in bits_to_change and values_for_bits. This has the same effect as a call to XkbSelectEvents.

The structure for the XkbBellNotify event type contains:

   typedef struct _XkbBellNotify {
       int            type;        /* Xkb extension base event code */
       unsigned long  serial;      /* X server serial number for event */
       Bool           send_event;  /* True => synthetically generated */
       Display *      display;     /* server connection where event generated */
       Time           time;        /* server time when event generated */
       int            xkb_type;    /* XkbBellNotify */
       unsigned int   device;      /* Xkb device ID, will not be XkbUseCoreKbd */
       int            percent;     /* requested volume as % of max */
       int            pitch;       /* requested pitch in Hz */
       int            duration;    /* requested duration in microseconds */
       unsigned int   bell_class;  /* X input extension feedback class */
       unsigned int   bell_id;     /* X input extension feedback ID */
       Atom           name;        /* "name" of requested bell */
       Window         window;      /* window associated with event */
       Bool           event_only;  /* False -> the server did not produce a beep */
   } XkbBellNotifyEvent;
If your application needs to generate visual bell feedback on the screen when it receives a bell event, use the window ID in the XkbBellNotifyEvent, if present.
