XkbFreeGeomKeys(3)

الحزمة: libx11

التراخيص: MIT AND X11

XkbFreeGeomKeys(3) XKB FUNCTIONS XkbFreeGeomKeys(3)

الاسم

XkbFreeGeomKeys - تحرير مفاتيح الهندسة

الملخص

void XkbFreeGeomKeys (XkbRowPtr row, int first, int count, Bool free_all);

المعاملات

row
الصف الذي سيتم فيه تحرير المفاتيح
first
أول مفتاح سيتم تحريره
count
عدد المفاتيح التي سيتم تحريرها
free_all
True => يتم تحرير جميع المفاتيح

الوصف

إذا كانت free_all صحيحة، فسيتم تحرير جميع المفاتيح بغض النظر عن قيمة first أو count. بخلاف ذلك، سيتم تحرير count مفتاحًا بدءًا من المفتاح المحدد بواسطة first.
