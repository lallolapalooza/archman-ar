XkbLockModifiers(3)

الحزمة: libx11

التراخيص: MIT AND X11

XkbLockModifiers(3) وظائف XKB XkbLockModifiers(3)

الاسم

XkbLockModifiers - يغلق ويفتح أي من المعدلات الثمانية الحقيقية للوحة المفاتيح

الملخص

Bool XkbLockModifiers (Display *display, unsigned int device_spec, unsigned int affect, unsigned int values);

المعاملات

display
الاتصال بخادم X
device_spec
معرف الجهاز، أو XkbUseCoreKbd
affect
قناع المعدلات الحقيقية التي سيتم تغيير حالة قفلها
values
1 => قفل، 0 => فتح؛ فقط للمعدلات المحددة بواسطة affect

الوصف

ترسل XkbLockModifiers طلبًا إلى الخادم لقفل المعدلات الحقيقية المحددة بواسطة كل من affect و values وفتح المعدلات الحقيقية المحددة بواسطة affect، ولكن ليس المحددة بواسطة values. لا تنتظر XkbLockModifiers ردًا من الخادم. تُرجع القيمة True إذا تم إرسال الطلب، و False بخلاف ذلك.

تستخدم الوظائف في هذا القسم التي تغير استخدام المعدلات قناعًا في المعامل affect. وهو OR شامل للبتات للأقنعة القانونية للمعدلات:

جدول 1 أقنعة المعدلات الحقيقية
القناع
ShiftMask
LockMask
ControlMask
Mod1Mask
Mod2Mask
Mod3Mask
Mod4Mask
Mod5Mask

قيم الإرجاع

True
تُرجع الدالة XkbLockModifiers القيمة True إذا تم إرسال طلب إلى الخادم لقفل المعدلات الحقيقية المحددة بواسطة كل من affect و values وفتح المعدلات الحقيقية المحددة بواسطة affect، ولكن ليس المحددة بواسطة values.
False
تُرجع الدالة XkbLockModifiers القيمة False إذا لم يتم إرسال الطلب.
