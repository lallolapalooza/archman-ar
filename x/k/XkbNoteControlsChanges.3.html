XkbNoteControlsChanges(3)

الحزمة: libx11

التراخيص: MIT AND X11

XkbNoteControlsChanges(3) XKB FUNCTIONS XkbNoteControlsChanges(3)

الاسم

XkbNoteControlsChanges - يسجل التغييرات في هيكل التغييرات عند استلام العميل لحدث XkbControlsNotify

الملخص

void XkbNoteControlsChanges (XkbControlsChangesPtr changes, XkbControlsNotifyEvent *new, unsigned int wanted);

المعاملات

changes
يسجل التغييرات التي يشير إليها new
new
يخبر ما هي الأشياء التي تغيرت
wanted
يخبر ما هي أجزاء new التي يجب تسجيلها في changes

الوصف

كلما تغير حقل في هيكل عناصر التحكم في وصف لوحة المفاتيح الخاص بالخادم، يرسل الخادم حدث XkbControlsNotify إلى جميع العملاء المهتمين. لاستقبال أحداث XkbControlsNotify تحت جميع الشروط الممكنة، استخدم XkbSelectEvents ومرر XkbControlsNotifyMask في كل من bits_to_change و values_for_bits.

لاستقبال أحداث XkbControlsNotify فقط تحت شروط معينة، استخدم XkbSelectEventDetails باستخدام XkbControlsNotify كـ event_type وتحديد تغييرات الحالة المطلوبة في bits_to_change و values_for_bits باستخدام أقنعة بت من الجدول 1.

يوضح الجدول 1 القيم الفعلية لأقنعة البت الفردية المستخدمة لتحديد عناصر التحكم للتعديل وتمكين وتعطيل عنصر التحكم. لاحظ أن نفس قناع البت يستخدم لتحديد التعديلات العامة على المعلمات المستخدمة لتكوين عنصر التحكم (which)، وتمكين وتعطيل عنصر التحكم (enabled_ctrls). الشذوذات في الجدول (لا يوجد "ok" في العمود) هي لعناصر التحكم التي لا تحتوي على سمات قابلة للتكوين؛ ولعناصر التحكم التي ليست عناصر تحكم منطقية وبالتالي لا يمكن تمكينها أو تعطيلها.

يشير حقل changed_ctrls إلى مكونات عناصر التحكم التي تغيرت ويتكون من بتات مأخوذة من الأقنعة المعرفة في الجدول 1 مع "ok" في عمود changed_ctrls.

يتم الإبلاغ عن عناصر التحكم الممكّنة حاليًا في الخادم في حقل enabled_ctrls. إذا تم تمكين أو تعطيل أي عناصر تحكم (أي، تغير محتوى حقل enabled_ctrls)، فسيتم تمييزها في enabled_ctrl_changes. البتات الصالحة لهذه الحقول هي الأقنعة المدرجة في الجدول 1 مع "ok" في عمود enabled_ctrls. يبلغ حقل num_groups عن عدد المجموعات المرتبطة بالمفتاح الذي ينتمي إلى أكبر عدد من المجموعات ويتم تحديثه تلقائيًا عند تغيير تخطيط لوحة المفاتيح.

إذا كان التغيير ناتجًا عن طلب من عميل، يتم تعيين حقلي keycode و event_type إلى الصفر، ويحدد حقلا req_major و req_minor الطلب. القيمة req_major هي نفس رمز تشغيل امتداد التوزيع الرئيسي. بخلاف ذلك، يتم تعيين event_type إلى نوع الحدث الذي تسبب في التغيير (واحد من KeyPress، KeyRelease، DeviceKeyPress، DeviceKeyRelease، ButtonPress أو ButtonRelease)، و req_major و req_minor غير محددين. إذا كان event_type هو KeyPress، KeyRelease، DeviceKeyPress، أو DeviceKeyRelease، يتم تعيين حقل keycode إلى المفتاح الذي تسبب في التغيير. إذا كان event_type هو ButtonPress أو ButtonRelease، فإن keycode يحتوي على رقم الزر.

عندما يتلقى العميل حدث XkbControlsNotify، يمكنه تسجيل التغييرات في هيكل التغييرات باستخدام XkbNoteControlsChanges.

المعلمة wanted هي OR الشامل للبتات المأخوذة من مجموعة الأقنعة المحددة في الجدول 1 مع "ok" في عمود changed_ctrls. يقوم XkbNoteControlsChanges بنسخ أي تغييرات مبلغ عنها في new ومحددة في wanted إلى سجل التغييرات المحدد بواسطة old.

هياكل

يتم تعريف هيكل حدث XkbControlsNotify على النحو التالي:
typedef struct {
    int           type;          /* Xkb extension base event code */
    unsigned long serial;        /* X server serial number for event */
    Bool          send_event;    /* True => synthetically generated */
    Display *     display;       /* server connection where event generated */
    Time          time;          /* server time when event generated */
    int           xkb_type;      /* XkbCompatMapNotify */
    int           device;        /* Xkb device ID, will not be XkbUseCoreKbd */
    unsigned int  changed_ctrls; /* bits indicating which controls data have changed*/
    unsigned int  enabled_ctrls; /* controls currently enabled in server */
    unsigned int  enabled_ctrl_changes; /* bits indicating enabled/disabled controls */
    int           num_groups;    /* current number of keyboard groups */
    KeyCode       keycode;       /* != 0 => keycode of key causing change */
    char          event_type;    /* Type of event causing change */
    char          req_major;     /* major event code of event causing change */
    char          req_minor;     /* minor event code of event causing change */
} XkbControlsNotifyEvent;
