XkbGetUpdatedMap(3)

الحزمة: libx11

التراخيص: MIT AND X11

XkbGetUpdatedMap(3) وظائف XKB XkbGetUpdatedMap(3)

الاسم

XkbGetUpdatedMap - تحديث معلومات الخريطة للعميل أو الخادم في وصف لوحة مفاتيح موجود

الملخص

Status XkbGetUpdatedMap (Display *display, unsigned int which, XkbDescPtr xkb);

الوسائط

display
الاتصال بخادم X
which
قناع يحدد المكونات الفرعية المراد تعبئتها
xkb
وصف لوحة المفاتيح المراد تحديثه

الوصف

المعلمة which هي عملية OR شاملة بت (bitwise inclusive OR) للأقنعة في الجدول 1. إذا لم تكن المكونات المطلوبة لهيكل xkb مخصصة بالفعل، فإن XkbGetUpdatedMap تقوم بتخصيصها. XkbGetUpdatedMap تجلب المعلومات المطلوبة للجهاز المحدد في XkbDescRec المقدمة في المعلمة xkb.

الجدول 1 أقنعة مكونات الخرائط Xkb
ووظائف الملاءمة
القناع القيمة الخريطة الحقول الملاءمة
الوظائف
XkbKeyTypesMask (1<<0) عميل types size_types num_types XkbGetKeyTypes XkbResizeKeyType XkbCopyKeyType XkbCopyKeyTypes
XkbKeySymsMask (1<<1) عميل syms size_syms num_syms key_sym_map XkbGetKeySyms XkbResizeKeySyms XkbChangeTypesOfKey
XkbModifierMapMask (1<<2) عميل modmap XkbGetKeyModifierMap
XkbExplicitComponentsMask (1<<3) خادم explicit XkbGetKeyExplicitComponents
XkbKeyActionsMask (1<<4) خادم key_acts acts num_acts size_acts XkbGetKeyActions XkbResizeKeyActions
XkbKeyBehaviorsMask (1<<5) خادم behaviors XkbGetKeyBehaviors
XkbVirtualModsMask (1<<6) خادم vmods XkbGetVirtualMods
XkbVirtualModMapMask (1<<7) خادم vmodmap XkbGetVirtualModMap

XkbGetUpdatedMap متزامنة؛ فهي تستعلم من الخادم عن المعلومات المطلوبة، وتنتظر رداً، ثم تعود. إذا نجحت، تعيد XkbGetUpdatedMap النجاح (Success). إذا فشلت، تعيد XkbGetUpdatedMap أحد القيم التالية: BadAlloc (عدم القدرة على تخصيص مكون في هيكل XkbDescRec)، BadValue (بعض بتات القناع في which غير معرفة)، BadImplementation (إصدار متوافق من امتداد Xkb غير متوفر في الخادم أو الرد من الخادم غير صالح).

قيم الإرجاع

النجاح (Success)
تعيد الوظيفة XkbGetUpdatedMap النجاح (Success) إذا تم استلام رد للاستعلام من الخادم للمعلومات المطلوبة.

الهياكل

الوصف الكامل للوحة مفاتيح Xkb يعطى بواسطة XkbDescRec. تمثل مكونات الهيكل في XkbDescRec المكونات الرئيسية لـ Xkb.

typedef struct {
   struct _XDisplay * display;      /* اتصال بخادم X */
   unsigned short     flags;        /* خاص بـ Xkb، لا تقم بالتعديل */
   unsigned short     device_spec;  /* جهاز الاهتمام */
   KeyCode            min_key_code; /* أقل رمز مفتاح للجهاز */
   KeyCode            max_key_code; /* أكبر رمز مفتاح للجهاز */
   XkbControlsPtr     ctrls;        /* عناصر التحكم */
   XkbServerMapPtr    server;       /* خريطة مفاتيح الخادم */
   XkbClientMapPtr    map;          /* خريطة مفاتيح العميل */
   XkbIndicatorPtr    indicators;   /* خريطة المؤشرات */
   XkbNamesPtr        names;        /* أسماء جميع المكونات */
   XkbCompatMapPtr    compat;       /* خريطة التوافق */
   XkbGeometryPtr     geom;         /* الهندسة الفيزيائية للوحة المفاتيح */
} XkbDescRec, *XkbDescPtr;
يشير الحقل display إلى هيكل عرض X. الحقل flags خاص بالمكتبة: قد يؤدي تعديل flags إلى نتائج غير متوقعة. يحدد الحقل device_spec معرف الجهاز لجهاز إدخال لوحة المفاتيح، أو XkbUseCoreKeyboard، الذي يحدد جهاز لوحة المفاتيح الأساسي. تحدد الحقول min_key_code و max_key_code أقل وأكبر رمز مفتاح يمكن أن يعيده لوحة المفاتيح.

لكل مكون هيكلي قناع بت مطابق يستخدم في استدعاءات الوظائف للإشارة إلى أنه يجب معالجة الهيكل بطريقة ما، مثل تخصيصه أو تحريره. تظهر هذه الأقنعة وعلاقاتها بالحقول في XkbDescRec في الجدول 2.

الجدول 2 بتات الأقنعة لـ XkbDescRec
بت القناع حقل XkbDescRec القيمة
XkbControlsMask ctrls (1L<<0)
XkbServerMapMask server (1L<<1)
XkbIClientMapMask map (1L<<2)
XkbIndicatorMapMask indicators (1L<<3)
XkbNamesMask names (1L<<4)
XkbCompatMapMask compat (1L<<5)
XkbGeometryMask geom (1L<<6)
XkbAllComponentsMask جميع الحقول (0x7f)
