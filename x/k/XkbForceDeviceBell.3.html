XkbForceDeviceBell(3)

الحزمة: libx11

التراخيص: MIT AND X11

i> parameter لأنه XkbForceDeviceBell لا يسبب حدث XkbBellNotify.

يمكنك استدعاء XkbBell دون تهيئة امتداد لوحة المفاتيح أولاً.

الهياكل

ينشئ Xkb أحداث XkbBellNotify لجميع الأجراس باستثناء تلك الناتجة عن استدعاءات XkbForceDeviceBell و XkbForceBell. لاستقبال أحداث XkbBellNotify في جميع الظروف الممكنة، مرر XkbBellNotifyMask في كل من المعاملين bits_to_change و values_for_bits إلى XkbSelectEvents.

لا يحتوي حدث XkbBellNotify على تفاصيل حدث. يتم تحديده أو لا يتم تحديده. ومع ذلك، يمكنك استدعاء XkbSelectEventDetails باستخدام XkbBellNotify كـ event_type وتحديد XkbAllBellEventsMask في bits_to_change و values_for_bits. هذا له نفس تأثير استدعاء XkbSelectEvents.

يحتوي الهيكل لنوع حدث XkbBellNotify على:

   typedef struct _XkbBellNotify {
       int            type;        /* رمز حدث امتداد Xkb الأساسي */
       unsigned long  serial;      /* رقم تسلسلي لخادم X للحدث */
       Bool           send_event;  /* True => تم إنشاؤه اصطناعيًا */
       Display *      display;     /* اتصال الخادم حيث تم إنشاء الحدث */
       Time           time;        /* وقت الخادم عند إنشاء الحدث */
       int            xkb_type;    /* XkbBellNotify */
       unsigned int   device;      /* معرف جهاز Xkb، لن يكون XkbUseCoreKbd */
       int            percent;     /* مستوى الصوت المطلوب كنسبة مئوية من الحد الأقصى */
       int            pitch;       /* درجة الصوت المطلوبة بالهرتز */
       int            duration;    /* المدة المطلوبة بالميكروثانية */
       unsigned int   bell_class;  /* فئة ملاحظات امتداد إدخال X */
       unsigned int   bell_id;     /* معرف ملاحظات امتداد إدخال X */
       Atom           name;        /* "اسم" الجرس المطلوب */
       Window         window;      /* النافذة المرتبطة بالحدث */
       Bool           event_only;  /* False -> لم ينتج الخادم صوت طنين */
   } XkbBellNotifyEvent;
إذا احتاج تطبيقك إلى إنشاء ردود فعل مرئية للجرس على الشاشة عند استقبال حدث جرس، استخدم معرف النافذة في XkbBellNotifyEvent، إذا كان موجودًا.
