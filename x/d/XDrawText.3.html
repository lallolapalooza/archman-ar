XDrawText(3)

الحزمة: libx11

التراخيص: MIT AND X11

XDrawText(3) وظائف XLIB XDrawText(3)

اسم

XDrawText, XDrawText16, XTextItem, XTextItem16 - رسم نص متعدد النص وهياكل رسم النص

الصيغة

int XDrawText(Display *display, Drawable d, GC gc, int x, int y, XTextItem *items, int nitems);

int XDrawText16(Display *display, Drawable d, GC gc, int x, int y, XTextItem16 *items, int nitems);

المعاملات

d
يحدد الرسم.
display
يحدد الاتصال بخادم X.
gc
يحدد GC.
items
يحدد مصفوفة عناصر نصية.
nitems
يحدد عدد عناصر النص في المصفوفة.
x

y
حدد إحداثيات x و y، وهي نسبية إلى أصل الرسم المحدد وتحدد أصل الحرف الأول.

الوصف

الدالة XDrawText16 تشبه XDrawText باستثناء أنها تستخدم أحرفًا ثنائية البايت أو 16 بت. تسمح كلتا الدالتين بمسافات معقدة وتحويلات خطوط بين السلاسل المحسوبة.

يتم معالجة كل عنصر نصي بدوره. يؤدي عضو الخط (font) الذي يختلف عن None في عنصر إلى تخزين الخط في GC واستخدامه للنص اللاحق. تحدد دلتا عنصر النص تغييرًا إضافيًا في الموضع على طول محور x قبل رسم السلسلة. تتم إضافة الدلتا دائمًا إلى أصل الحرف ولا تعتمد على أي خصائص للخط. يتم التعامل مع كل صورة حرف، كما هو محدد بواسطة الخط في GC، كقناع إضافي لعملية تعبئة على الرسم. يتم تعديل الرسم فقط حيث يكون للحرف الخاص بالخط بت معين يساوي 1. إذا أنتج عنصر النص خطأ BadFont، فقد يكون قد تم رسم عناصر النص السابقة.

بالنسبة للخطوط المعرفة بفهرسة خطية بدلاً من فهرسة مصفوفة ثنائية البايت، يتم تفسير كل هيكل XChar2b كرقم 16 بت حيث يكون byte1 هو البايت الأكثر أهمية.

تستخدم كلتا الدالتين مكونات GC هذه: function، plane-mask، fill-style، font، subwindow-mode، clip-x-origin، clip-y-origin، و clip-mask. كما أنهما تستخدمان مكونات GC هذه المعتمدة على الوضع: foreground، background، tile، stipple، tile-stipple-x-origin، و tile-stipple-y-origin.

يمكن لـ XDrawText و XDrawText16 إنشاء أخطاء BadDrawable و BadFont و BadGC و BadMatch.

الهياكل

تحتوي هياكل XTextItem و XTextItem16 على:

typedef struct {
        char *chars;    /* مؤشر إلى السلسلة */
        int nchars;     /* عدد الأحرف */
        int delta;      /* دلتا بين السلاسل */
        Font font;      /* الخط الذي سيتم طباعته فيه، None لا يتغير */
} XTextItem;
typedef struct {
        XChar2b *chars; /* مؤشر إلى أحرف ثنائية البايت */
        int nchars;     /* عدد الأحرف */
        int delta;      /* دلتا بين السلاسل */
        Font font;      /* الخط الذي سيتم طباعته فيه، None لا يتغير */
} XTextItem16;

إذا كان عضو الخط (font) ليس None، فسيتم تغيير الخط قبل الطباعة وسيتم تخزينه أيضًا في GC. إذا تم إنشاء خطأ أثناء رسم النص، فقد تم رسم العناصر السابقة. يتم رسم خط الأساس للأحرف بدءًا من إحداثيات x و y التي تمررها في وظائف رسم النص.

على سبيل المثال، ضع في اعتبارك المستطيل الخلفي الذي ترسمه XDrawImageString. إذا كنت تريد أن تكون الزاوية العلوية اليسرى للمستطيل الخلفي عند إحداثيات البكسل (x,y)، فمرر (x,y + ascent) كإحداثيات أصل خط الأساس لوظائف النص. الصعود (ascent) هو صعود الخط، كما هو معطى في هيكل XFontStruct. إذا كنت تريد أن تكون الزاوية السفلية اليسرى للمستطيل الخلفي عند إحداثيات البكسل (x,y)، فمرر (x,y - descent + 1) كإحداثيات أصل خط الأساس لوظائف النص. النزول (descent) هو نزول الخط، كما هو معطى في هيكل XFontStruct.

التشخيص

BadDrawable
قيمة لمعامل الرسم (Drawable) لا تسمي نافذة أو صورة نقطية (Pixmap) محددة.
BadFont
قيمة لمعامل الخط (Font) أو GContext لا تسمي خطًا أو GContext محددًا.
BadGC
قيمة لمعامل GContext لا تسمي GContext محددًا.
BadMatch
يتم استخدام نافذة InputOnly كرسم (Drawable).
