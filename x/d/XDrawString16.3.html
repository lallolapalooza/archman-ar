XDrawString16(3)

الحزمة: libx11

التراخيص: MIT AND X11

XDrawString(3) وظائف XLIB XDrawString(3)

الاسم

XDrawString, XDrawString16 - رسم أحرف النص

الصيغة

int XDrawString(Display *display, Drawable d, GC gc, int x, int y, _Xconst char *string, int length);

int XDrawString16(Display *display, Drawable d, GC gc, int x, int y, _Xconst XChar2b *string, int length);

المعاملات

d
يحدد العنصر القابل للرسم.
display
يحدد الاتصال بخادم X.
gc
يحدد GC.
length
يحدد عدد الأحرف في معامل السلسلة النصية.
string
يحدد السلسلة النصية.
x

y
حدد إحداثيات x و y، والتي تكون نسبة إلى أصل العنصر القابل للرسم المحدد وتحدد أصل الحرف الأول.

الوصف

يتم التعامل مع كل صورة حرف، كما تم تعريفها بواسطة الخط في GC، كقناع إضافي لعملية تعبئة على العنصر القابل للرسم. يتم تعديل العنصر القابل للرسم فقط حيث يكون للحرف المكتوب بالخط بت معين يساوي 1. بالنسبة للخطوط المعرفة بفهرسة مصفوفة من بايتين والمستخدمة مع XDrawString16، يتم استخدام كل بايت كـ byte2 مع byte1 يساوي صفرًا.

تستخدم كلتا الدالتين مكونات GC هذه: الوظيفة، قناع المستوى، نمط التعبئة، الخط، وضع النافذة الفرعية، أصل قص x، أصل قص y، وقناع القص. كما تستخدمان هذه المكونات المعتمدة على وضع GC: الأمامية، الخلفية، البلاط، التظليل، أصل x للبلاط والتظليل، وأصل y للبلاط والتظليل.

XDrawString و XDrawString16 يمكن أن تولدا أخطاء BadDrawable و BadGC و BadMatch.

التشخيص

BadDrawable
قيمة لمعامل Drawable لا تسمي نافذة أو رسمة نقطية معرفة.
BadGC
قيمة لمعامل GContext لا تسمي سياق رسومات معرف.
BadMatch
تستخدم نافذة InputOnly كعنصر قابل للرسم.
BadMatch
بعض المعاملات أو أزواج المعاملات لها النوع الصحيح والنطاق الصحيح ولكنها تفشل في المطابقة بطريقة أخرى مطلوبة للطلب.
