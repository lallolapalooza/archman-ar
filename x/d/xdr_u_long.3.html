الاسم

xdr — روتينات مكتبية لتمثيل البيانات الخارجي

المكتبة

مكتبة C القياسية (libc، -lc)

ملخص ووصف

تسمح هذه الروتينات لبرامج C بوصف هياكل بيانات عشوائية بطريقة مستقلة عن الآلة. يتم إرسال البيانات لاستدعاءات الإجراءات البعيدة باستخدام هذه الروتينات.

النماذج الأولية أدناه معرّفة في <rpc/xdr.h> وتستخدم الأنواع التالية:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

لتعريف نوع XDR، انظر <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
مرشح بدائي يقوم بالترجمة بين المصفوفات متغيرة الطول وتمثيلاتها الخارجية المقابلة. الوسيط arrp هو عنوان المؤشر إلى المصفوفة، بينما sizep هو عنوان عداد عناصر المصفوفة؛ لا يمكن أن يتجاوز هذا العداد maxsize. الوسيط elsize هو sizeof كل عنصر من عناصر المصفوفة، و elproc هو مرشح XDR يترجم بين شكل C لعناصر المصفوفة وتمثيلها الخارجي. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
مرشح بدائي يقوم بالترجمة بين القيم المنطقية (أعداد صحيحة C) وتمثيلاتها الخارجية. عند ترميز البيانات، ينتج هذا المرشح قيمًا إما واحد أو صفر. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
مرشح بدائي يقوم بالترجمة بين سلاسل البايتات المعدودة وتمثيلاتها الخارجية. الوسيط sp هو عنوان مؤشر السلسلة. يقع طول السلسلة في العنوان sizep؛ لا يمكن أن تكون السلاسل أطول من maxsize. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_char(XDR *xdrs, char *cp);
مرشح بدائي يقوم بالترجمة بين أحرف C وتمثيلاتها الخارجية. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك. ملاحظة: الأحرف المرمزة ليست مجمعة، وتشغل 4 بايتات لكل منها. بالنسبة لمصفوفات الأحرف، يجدر النظر في xdr_bytes() أو xdr_opaque() أو xdr_string().
void xdr_destroy(XDR *xdrs);
وحدة ماكرو تستدعي الروتينة المسؤولة عن تدمير تدفق XDR المرتبط بـ xdrs. يشمل التدمير عادةً تحرير هياكل البيانات الخاصة المرتبطة بالتدفق. استخدام xdrs بعد استدعاء xdr_destroy() غير محدد.
bool_t xdr_double(XDR *xdrs, double *dp);
مرشح بدائي يقوم بالترجمة بين أرقام double C ذات الدقة المزدوجة وتمثيلاتها الخارجية. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
مرشح بدائي يقوم بالترجمة بين enums C (أعداد صحيحة في الواقع) وتمثيلاتها الخارجية. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_float(XDR *xdrs, float *fp);
مرشح بدائي يقوم بالترجمة بين floats C وتمثيلاتها الخارجية. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
void xdr_free(xdrproc_t proc, char *objp);
روتينة تحرير عامة. الوسيط الأول هو روتينة XDR للكائن الذي يتم تحريره. الوسيط الثاني هو مؤشر إلى الكائن نفسه. ملاحظة: المؤشر المُمرر إلى هذه الروتينة *لا* يتم تحريره، ولكن ما يشير إليه يتم تحريره (بشكل متكرر).
unsigned int xdr_getpos(XDR *xdrs);
وحدة ماكرو تستدعي الروتينة المسؤولة عن الحصول على الموضع لتدفق XDR، xdrs. تعيد الروتينة عددًا صحيحًا غير مُوقَّع، يشير إلى موضع تدفق بايتات XDR. من السمات المرغوبة لتدفقات XDR أن العمليات الحسابية البسيطة تعمل مع هذا الرقم، على الرغم من أن مثيلات تدفق XDR ليست ملزمة بضمان ذلك.
long *xdr_inline(XDR *xdrs, int len);
وحدة ماكرو تستدعي الروتينة المسؤولة عن الحصول على المخزن المؤقت المضمن لتدفق XDR، xdrs. تعيد الروتينة مؤشرًا إلى جزء متجاور من المخزن المؤقت للتدفق؛ len هو طول البايت للمخزن المؤقت المطلوب. ملاحظة: يتم تحويل المؤشر إلى long *.
تحذير: قد تعيد xdr_inline() قيمة NULL (0) إذا لم تتمكن من تخصيص جزء متجاور من مخزن مؤقت. لذلك، قد يختلف السلوك بين مثيلات التدفق؛ وهي موجودة من أجل الكفاءة.
bool_t xdr_int(XDR *xdrs, int *ip);
مرشح بدائي يقوم بالترجمة بين أعداد C الصحيحة وتمثيلاتها الخارجية. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_long(XDR *xdrs, long *lp);
مرشح بدائي يقوم بالترجمة بين أعداد long C الصحيحة وتمثيلاتها الخارجية. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
تقوم هذه الروتينة بتهيئة كائن تدفق XDR الذي يشير إليه xdrs. تتم كتابة بيانات التدفق إلى، أو قراءتها من، جزء من الذاكرة في الموقع addr بطول لا يزيد عن size بايت. تحدد op اتجاه تدفق XDR (إما XDR_ENCODE أو XDR_DECODE أو XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
مرشح بدائي يقوم بالترجمة بين البيانات المعتمة ذات الحجم الثابت وتمثيلها الخارجي. الوسيط cp هو عنوان الكائن المعتم، و cnt هو حجمه بالبايت. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
مثل xdr_reference() باستثناء أنها تسلسل مؤشرات فارغة، بينما xdr_reference() لا تفعل ذلك. وبالتالي، يمكن لـ xdr_pointer() تمثيل هياكل البيانات المتكررة، مثل الأشجار الثنائية أو القوائم المرتبطة.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
تقوم هذه الروتينة بتهيئة كائن تدفق XDR الذي يشير إليه xdrs. تتم كتابة بيانات التدفق إلى مخزن مؤقت بحجم sendsize؛ تشير القيمة صفر إلى أن النظام يجب أن يستخدم قيمة افتراضية مناسبة. تتم قراءة بيانات التدفق من مخزن مؤقت بحجم recvsize؛ يمكن أيضًا تعيينه لقيمة افتراضية مناسبة عن طريق تمرير قيمة صفر. عندما يكون المخزن المؤقت للإخراج للتدفق ممتلئًا، يتم استدعاء writeit. وبالمثل، عندما يكون المخزن المؤقت للإدخال للتدفق فارغًا، يتم استدعاء readit. سلوك هاتين الروتينيين مشابه لاستدعاءات النظام read(2) و write(2)، باستثناء أن handle يتم تمريره إلى الروتينيين السابقين كوسيط أول. ملاحظة: يجب على المتصل تعيين حقل op لتدفق XDR.
تحذير: لقراءة تدفق XDR تم إنشاؤه بواسطة واجهة برمجة التطبيقات هذه، ستحتاج إلى استدعاء xdrrec_skiprecord() أولاً قبل استدعاء أي واجهات برمجة تطبيقات XDR أخرى. هذا يدرج بايتات إضافية في التدفق لتوفير حدود السجل.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
مرشح بدائي يتجاوز المؤشر pp، والذي يشير إلى هيكل البيانات الذي تتم معالجته بواسطة الروتينة proc، ويجب أن يكون حجم الهيكل بالبايتات size. هذه الروتينة مفيدة لإعادة استخدام الروتينات XDR الموجودة لتضمين هياكل بيانات معقدة. هذه الروتينة مفيدة فقط عندما لا تكون هناك حاجة لتمثيل مؤشر فارغ، أو للتعامل مع أنواع مثل المصفوفات. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
وحدة ماكرو تستدعي الروتينة المسؤولة عن تعيين الموضع لتدفق XDR، xdrs. يتم تعيين الموضع إلى pos. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك. ملاحظة: لا تضمن جميع مثيلات التدفق أن هذه الروتينة تعمل بشكل صحيح.
bool_t xdr_short(XDR *xdrs, short *sp);
مرشح بدائي يقوم بالترجمة بين أعداد short C القصيرة وتمثيلاتها الخارجية. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_skiprecord(XDR *xdrs);
يقوم هذا المرشح بقراءة البايتات من تدفق XDR حتى يصل إلى نهاية السجل. إذا كان التدفق في حالة "سجل"، فإنه يقرأ حتى نهاية السجل. إذا كان التدفق في وضع "تدفق"، فإنه لا يفعل شيئًا. يستخدم هذا المرشح عادةً لقراءة نهاية سجل XDR أو لتخطي بقية السجل الحالي.
char *xdr_sizeof(xdrproc_t proc, char *objp);
تقوم هذه الروتينة بحساب حجم الكائن الذي يشير إليه objp، والذي تتم معالجته بواسطة الروتينة proc، وتعيد حجمه بالبايتات. إذا فشلت الروتينة proc في إرجاع حجم ثابت، فإن سلوك هذه الروتينة غير محدد.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
مرشح بدائي يقوم بالترجمة بين سلاسل C المنتهية بصفر وتمثيلاتها الخارجية. الوسيط sp هو عنوان مؤشر السلسلة. لا يمكن أن تتجاوز السلاسل maxsize بايت في الطول. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
مرشح بدائي يقوم بالترجمة بين أحرف C غير الموقعة وتمثيلاتها الخارجية. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك. ملاحظة: الأحرف المرمزة ليست مجمعة، وتشغل 4 بايتات لكل منها.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
مرشح بدائي يقوم بالترجمة بين أعداد unsigned long C الصحيحة وتمثيلاتها الخارجية. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
مرشح بدائي يقوم بالترجمة بين أعداد unsigned short C القصيرة وتمثيلاتها الخارجية. تعيد هذه الروتينة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_union(XDR *xdrs, enum_t *enumval, char *defaultval,
                 const struct xdr_discريم *choices,
                 xdrproc_t defaultproc);
مرشح بدائي يقوم بالترجمة بين هياكل C الفرعية والتمثيل الخارجي. الوسيط enumval هو مؤشر إلى قيمة التمييز للاتحاد. الوسيط defaultval هو مؤشر إلى قيمة الاتحاد الافتراضية. الوسيط choices هو مؤشر إلى مصفوفة من الهياكل xdr_discrim. الوسيط defaultproc هو مؤشر إلى الروتينة XDR المستخدمة لمعالجة الاتحاد.
bool_t xdr_vector(XDR *xdrs, char *arr, unsigned int len,
                  unsigned int maxsize, xdrproc_t elementproc);
مثل xdr_array()، ولكن الوسيط الأول هو مؤشر إلى مصفوفة البايتات، وليس مؤشر إلى مؤشر.
bool_t xdr_void(void);
لا يفعل شيئًا. يستخدم كمرشح XDR افتراضي عند عدم وجود حاجة لترجمة بيانات.

فيما يلي بعض روتينات XDR الإضافية المتوفرة:

bool_t xdr_longlong_nofilter(XDR *xdrs, long long *ll);
bool_t xdr_u_longlong_nofilter(XDR *xdrs, unsigned long long *ull);
bool_t xdr_hyper_nofilter(XDR *xdrs, quad_t *q);
bool_t xdr_u_hyper_nofilter(XDR *xdrs, u_quad_t *uq);

SYNOPSIS AND DESCRIPTION

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *lenp,
                   unsigned int maxsize, xdrproc_t clntproc,
                   xdrproc_t xdrproc);
A filter primitive that translates between C arrays and their external representations. The argument arrp is the address of the pointer to the array, while lenp is the address of the array's length. The argument maxsize is the maximum size of the array, and clntproc is the XDR routine used to translate the array's elements. This routine returns one if it succeeds, zero otherwise.
Note: This routine is used internally by the XDR package and is not intended for direct use by applications.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
A filter primitive that translates between C bool_t values and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *lenp,
                 unsigned int maxsize);
A filter primitive that translates between arbitrary sequences of non-null bytes and their external representations. The argument sp is the address of the pointer to the byte sequence, while lenp is the address of the byte sequence's length. The argument maxsize is the maximum size of the byte sequence. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_char(XDR *xdrs, char *cp);
A filter primitive that translates between C characters and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdr_destroy(XDR *xdrs);
This routine destroys the XDR stream created by xdr_create(), xdrmem_create(), xdrrec_create(), or xdrstdio_create().
bool_t xdr_double(XDR *xdrs, double *dp);
A filter primitive that translates between C double precision floating-point numbers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
A filter primitive that translates between C enumeration types and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_float(XDR *xdrs, float *fp);
A filter primitive that translates between C float precision floating-point numbers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdr_free(xdrproc_t proc, char *objp);
This routine frees the memory associated with the XDR structure pointed to by objp, using the specified XDR proc routine to perform the freeing operation.
unsigned int xdr_getpos(XDR *xdrs);
A macro that invokes the get position routine associated with the XDR stream xdrs. It returns the current position of the XDR stream. The value returned can be used later with xdr_setpos().
Warning: it is difficult to reposition some types of XDR streams, so this routine may return meaningless values for some types of XDR streams.
void *xdr_inline(XDR *xdrs, unsigned int len);
A routine that returns a pointer to a buffer of size len bytes from the XDR stream xdrs. This buffer may be used to copy data directly into or out of the stream. This routine returns NULL if no buffer of the requested size is available.
Warning: this routine should be used with caution, as it relies on the internal implementation of the XDR stream.
bool_t xdr_int(XDR *xdrs, int *ip);
A filter primitive that translates between C integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_long(XDR *xdrs, long *lp);
A filter primitive that translates between C long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                    enum xdr_op op);
This routine initializes the XDR stream object pointed to by xdrs. The XDR stream data is read from or written to the memory buffer starting at addr with size size. The argument op determines the direction of the XDR stream (either XDR_ENCODE, XDR_DECODE, or XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int size);
A filter primitive that translates between arbitrary sequences of bytes and their external representations. The argument cp is the starting address of the byte sequence, and size is the number of bytes to translate. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_pointer(XDR *xdrs, char **pp, unsigned int size,
                   xdrproc_t proc);
A filter primitive that provides pointer chasing within structures. The argument pp is the address of the pointer; size is the sizeof the structure that *pp points to; and proc is an XDR procedure that filters the structure between its C form and its external representation. This routine handles NULL pointers correctly. This routine returns one if it succeeds, zero otherwise.
XDR *xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, FILE *infile,
                   FILE *outfile);
This routine initializes the XDR stream object pointed to by xdrs for record-oriented I/O. The arguments sendsize and recvsize specify the buffer sizes for sending and receiving records, respectively. The arguments infile and outfile are standard I/O streams used for input and output. This routine returns a pointer to the initialized XDR stream structure, or NULL on failure.
Warning: XDR streams created by xdrrec_create() are not compatible with XDR streams created by other XDR creation routines. Also, XDR streams created with different xdr*_create APIs are not compatible for the same reason.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
This routine can be invoked only on streams created by xdrrec_create(). The data in the output buffer is marked as a completed record, and the output buffer is optionally written out if sendnow is nonzero. This routine returns one if it succeeds, zero otherwise.
bool_t xdrrec_eof(XDR *xdrs);
This routine can be invoked only on streams created by xdrrec_create(). After consuming the rest of the current record in the stream, this routine returns one if the stream has no more input, zero otherwise.
bool_t xdrrec_skiprecord(XDR *xdrs);
This routine can be invoked only on streams created by xdrrec_create(). It tells the XDR implementation that the rest of the current record in the stream's input buffer should be discarded. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
A primitive that provides pointer chasing within structures. The argument pp is the address of the pointer; size is the sizeof the structure that *pp points to; and proc is an XDR procedure that filters the structure between its C form and its external representation. This routine returns one if it succeeds, zero otherwise.
Warning: this routine does not understand null pointers. Use xdr_pointer() instead.
xdr_setpos(XDR *xdrs, unsigned int pos);
A macro that invokes the set position routine associated with the XDR stream xdrs. The argument pos is a position value obtained from xdr_getpos(). This routine returns one if the XDR stream could be repositioned, and zero otherwise.
Warning: it is difficult to reposition some types of XDR streams, so this routine may fail with one type of stream and succeed with another.
bool_t xdr_short(XDR *xdrs, short *sp);
A filter primitive that translates between C short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
This routine initializes the XDR stream object pointed to by xdrs. The XDR stream data is written to, or read from, the stdio stream file. The argument op determines the direction of the XDR stream (either XDR_ENCODE, XDR_DECODE, or XDR_FREE).
Warning: the destroy routine associated with such XDR streams calls fflush(3) on the file stream, but never fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
A filter primitive that translates between C strings and their corresponding external representations. Strings cannot be longer than maxsize. Note: sp is the address of the string's pointer. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
A filter primitive that translates between unsigned C characters and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
A filter primitive that translates between C unsigned integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
A filter primitive that translates between C unsigned long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
A filter primitive that translates between C unsigned short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* may equal NULL */
A filter primitive that translates between a discriminated C union and its corresponding external representation. It first translates the discriminant of the union located at dscmp. This discriminant is always an enum_t. Next the union located at unp is translated. The argument choices is a pointer to an array of xdr_discrim() structures. Each structure contains an ordered pair of [value,proc]. If the union's discriminant is equal to the associated value, then the proc is called to translate the union. The end of the xdr_discrim() structure array is denoted by a routine of value NULL. If the discriminant is not found in the choices array, then the defaultarm procedure is called (if it is not NULL). Returns one if it succeeds, zero otherwise.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
A filter primitive that translates between fixed-length arrays and their corresponding external representations. The argument arrp is the address of the pointer to the array, while size is the element count of the array. The argument elsize is the sizeof each of the array's elements, and elproc is an XDR filter that translates between the array elements' C form, and their external representation. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_void(void);
This routine always returns one. It may be passed to RPC routines that require a function argument, where nothing is to be done.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
A primitive that calls xdr_string(xdrs, sp,MAXUN.UNSIGNED ); where MAXUN.UNSIGNED is the maximum value of an unsigned integer. xdr_wrapstring() is handy because the RPC package passes a maximum of two XDR routines as arguments, and xdr_string(), one of the most frequently used primitives, requires three. Returns one if it succeeds, zero otherwise.

حول Arch Linux

Arch Linux هو توزيعة لينكس مستقلة، خفيفة وسهلة، مصممة للمساهمين ذوي الخبرة. تتبع Arch Linux مبادئ التطوير البسيط، مما يعني أنها تركز على أن تكون بسيطة ومناسبة للمطور. يتم تحقيق ذلك من خلال:

  • البساطة: Arch Linux مصمم ليكون بسيطًا، دون أي تعديلات غير ضرورية على البرامج.
  • الحداثة: يتم توفير أحدث إصدارات البرامج المستقرة.
  • النهج العملي: لا تفرض Arch Linux بيئة سطح مكتب أو مجموعة من البرامج الأساسية، مما يمنح المستخدم الحرية الكاملة في تخصيص نظامه.
  • المركزية على المستخدم: الهدف هو تلبية احتياجات المستخدم المتقدم، مما يمنح المستخدم تحكمًا كاملاً في نظامه.
  • التنوع: يتم دعم هندسات معالجات متعددة.

تثبيت Arch Linux

يتم توفير Arch Linux كـ "قرص تثبيت حي" (live install image) يسهل تشغيله وتشغيل مثبت Arch Linux. يتم التثبيت يدويًا عن طريق سطر الأوامر، مما يسمح للمستخدم ببناء نظام مطابق لاحتياجاته. يمكن العثور على تعليمات مفصلة في دليل التثبيت.

الحصول على المساعدة

هناك العديد من المصادر المتاحة للحصول على المساعدة، بما في ذلك Arch Wiki، وقوائم البريد، و IRC. منتديات Arch Linux هي أيضًا مكان جيد لطرح الأسئلة.

المساهمة

Arch Linux هو مشروع مجتمعي، ويتم تشجيع المساهمات. يمكن العثور على معلومات حول كيفية المساهمة في صفحة المساهمة.

حزمة البرامج

تستخدم Arch Linux نظام إدارة الحزم pacman. يمكنك الحصول على معلومات إضافية حول حزم البرامج من خلال أرشيف حزم Arch Linux.
