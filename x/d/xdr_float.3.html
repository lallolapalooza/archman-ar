الاسم

xdr - روتينات مكتبية لتمثيل البيانات الخارجي

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص والوصف

تسمح هذه الروتينات لمبرمجي C بوصف هياكل بيانات عشوائية بطريقة مستقلة عن الآلة. تُنقل بيانات استدعاءات الإجراءات البعيدة باستخدام هذه الروتينات.

النماذج الأولية أدناه مُعلنة في <rpc/xdr.h> وتستخدم الأنواع التالية:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

للاطلاع على إعلان النوع XDR، انظر <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
عنصر تصفية أولي يترجم بين المصفوفات متغيرة الطول وتمثيلاتها الخارجية المقابلة. الوسيط arrp هو عنوان المؤشر إلى المصفوفة، بينما sizep هو عنوان عدد عناصر المصفوفة؛ لا يمكن أن يتجاوز عدد العناصر هذا maxsize. الوسيط elsize هو sizeof لكل عنصر من عناصر المصفوفة، وelproc هو مرشح XDR يترجم بين الشكل C لعناصر المصفوفة وتمثيلها الخارجي. تُرجع هذه الروتين واحدًا إذا نجحت، وصفرًا خلاف ذلك.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
عنصر تصفية أولي يترجم بين القيم المنطقية (أعداد C الصحيحة) وتمثيلاتها الخارجية. عند ترميز البيانات، ينتج هذا المرشح قيمًا إما واحد أو صفر. تُرجع هذه الروتين واحدًا إذا نجحت، وصفرًا خلاف ذلك.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
عنصر تصفية أولي يترجم بين سلاسل البايتات المعدودة وتمثيلاتها الخارجية. الوسيط sp هو عنوان مؤشر السلسلة. يقع طول السلسلة في العنوان sizep؛ لا يمكن أن تكون السلاسل أطول من maxsize. تُرجع هذه الروتين واحدًا إذا نجحت، وصفرًا خلاف ذلك.
bool_t xdr_char(XDR *xdrs, char *cp);
عنصر تصفية أولي يترجم بين محارف C وتمثيلاتها الخارجية. تُرجع هذه الروتين واحدًا إذا نجحت، وصفرًا خلاف ذلك. ملاحظة: المحارف المرمزة لا تُحزم، وتشغل 4 بايتات لكل منها. بالنسبة لمصفوفات المحارف، يجدر التفكير في xdr_bytes() أو xdr_opaque() أو xdr_string().
void xdr_destroy(XDR *xdrs);
ماكرو يستدعي روتين التدمير المرتبط بتدفق XDR، xdrs. يتضمن التدمير عادةً تحرير هياكل البيانات الخاصة المرتبطة بالتدفق. استخدام xdrs بعد استدعاء xdr_destroy() غير مُعرّف.
bool_t xdr_double(XDR *xdrs, double *dp);
عنصر تصفية أولي يترجم بين أعداد C ذات الدقة المزدوجة double وتمثيلاتها الخارجية. تُرجع هذه الروتين واحدًا إذا نجحت، وصفرًا خلاف ذلك.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
عنصر تصفية أولي يترجم بين تعدادات C enum (أعداد صحيحة في الواقع) وتمثيلاتها الخارجية. تُرجع هذه الروتين واحدًا إذا نجحت، وصفرًا خلاف ذلك.
bool_t xdr_float(XDR *xdrs, float *fp);
عنصر تصفية أولي يترجم بين أعداد C العائمة float وتمثيلاتها الخارجية. تُرجع هذه الروتين واحدًا إذا نجحت، وصفرًا خلاف ذلك.
void xdr_free(xdrproc_t proc, char *objp);
روتين تحرير عام. الوسيط الأول هو روتين XDR للكائن الذي يتم تحريره. الوسيط الثاني هو مؤشر إلى الكائن نفسه. ملاحظة: المؤشر المُمرر إلى هذه الروتين لا يتم تحريره، لكن ما يشير إليه يتم تحريره (بشكل تكراري).
unsigned int xdr_getpos(XDR *xdrs);
ماكرو يستدعي روتين الحصول على الموضع المرتبط بتدفق XDR، xdrs. تُرجع الروتين عددًا صحيحًا غير مُوقّع، يشير إلى موضع تدفق بايتات XDR. من الخصائص المرغوبة في تدفقات XDR أن الحساب البسيط يعمل مع هذا الرقم، رغم أن نسخ تدفقات XDR ليست مضطرة لضمان ذلك.
long *xdr_inline(XDR *xdrs, int len);
ماكرو يستدعي الروتين المضمّن المرتبط بتدفق XDR، xdrs. تُرجع الروتين مؤشرًا إلى قطعة متجاورة من مخزن التدفق المؤقت؛ len هو طول البايتات للمخزن المطلوب. ملاحظة: يتم تحويل المؤشر إلى long *.
تحذير: قد تُرجع xdr_inline() القيمة NULL (0) إذا لم تتمكن من تخصيص قطعة متجاورة من المخزن المؤقت. لذلك قد يختلف السلوك بين نسخ التدفقات؛ وهي موجودة من أجل الكفاءة.
bool_t xdr_int(XDR *xdrs, int *ip);
عنصر تصفية أولي يترجم بين أعداد C الصحيحة وتمثيلاتها الخارجية. تُرجع هذه الروتين واحدًا إذا نجحت، وصفرًا خلاف ذلك.
bool_t xdr_long(XDR *xdrs, long *lp);
عنصر تصفية أولي يترجم بين أعداد C الصحيحة الطويلة long وتمثيلاتها الخارجية. تُرجع هذه الروتين واحدًا إذا نجحت، وصفرًا خلاف ذلك.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
تُهيّئ هذه الروتين كائن تدفق XDR المشار إليه بواسطة xdrs. تُكتب بيانات التدفق إلى قطعة من الذاكرة في الموقع addr التي لا يتجاوز طولها size بايت، أو تُقرأ منها. يحدد op اتجاه تدفق XDR (إما XDR_ENCODE أو XDR_DECODE أو XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
عنصر تصفية أولي يترجم بين البيانات المعتمة ثابتة الحجم وتمثيلها الخارجي. الوسيط cp هو عنوان الكائن المعتم، وcnt هو حجمه بالبايتات. تُرجع هذه الروتين واحدًا إذا نجحت، وصفرًا خلاف ذلك.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
مثل xdr_reference() باستثناء أنه يُسلسل المؤشرات الفارغة، بينما xdr_reference() لا يفعل ذلك. وبالتالي، يمكن لـ xdr_pointer() تمثيل هياكل بيانات تكرارية، مثل الأشجار الثنائية أو القوائم المترابطة.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
تُهيّئ هذه الروتين كائن تدفق XDR المشار إليه بواسطة xdrs. تُكتب بيانات التدفق إلى مخزن مؤقت بحجم sendsize؛ تشير القيمة صفر إلى أن النظام يجب أن يستخدم قيمة افتراضية مناسبة. تُقرأ بيانات التدفق من مخزن مؤقت بحجم recvsize؛ يمكن أيضًا تعيينه إلى قيمة افتراضية مناسبة بتمرير القيمة صفر. عندما يمتلئ مخزن الإخراج للتدفق، يتم استدعاء writeit. وبالمثل، عندما يفرغ مخزن الإدخال للتدفق، يتم استدعاء readit. سلوك هاتين الروتينتين مشابه لاستدعاءات النظام read(2) وwrite(2)، باستثناء أن handle يُمرر إلى الروتينتين السابقتين كوسيط أول. ملاحظة: يجب أن يضبط المستدعي حقل op لتدفق XDR.

NAME

xdr_float, xdr_double, xdr_int, xdr_long, xdr_short, xdr_u_int, xdr_u_long, xdr_u_short, xdr_char, xdr_u_char, xdr_bool, xdr_enum, xdr_opaque, xdr_bytes, xdr_string, xdr_pointer, xdr_reference, xdr_wrapstring, xdr_union, xdr_vector, xdr_getpos, xdr_setpos, xdr_inline, xdrrec_create, xdrrec_endofrecord, xdrrec_eof, xdrrec_skiprecord, xdrstdio_create, xdralloc_create, xdr_free - External Data Representation filter primitives

LIBRARY

XDR library (libtirpc), -ltirpc

SYNOPSIS AND DESCRIPTION

#include <rpc/xdr.h>

The following routines provide filtering primitives for External Data Representation (XDR) streams. XDR is a standard for describing data structures and operations between different computer systems.

bool_t xdr_array(XDR *xdrs, char **cpp, unsigned int *nip, unsigned int maxsize,
                 unsigned int elsize, xdrproc_t elproc);
A filter primitive that translates between C arrays and their corresponding external representations. The argument cpp is the address of the pointer to the array, while nip is the address of the count of elements in the array. The argument maxsize is the maximum number of elements the array can contain. The argument elsize is the sizeof each element in the array, and elproc is an XDR filter that translates between the array elements' C form, and their external representation. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
A filter primitive that translates between C bool_t values and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_bytes(XDR *xdrs, char **cpp, unsigned int *lip, unsigned int maxsize);
A filter primitive that translates between sequences of arbitrary bytes and their external representations. The argument cpp is the address of the pointer to the byte sequence. The argument lip is the address of the count of bytes in the sequence. The argument maxsize is the maximum number of bytes the sequence may contain. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_char(XDR *xdrs, char *cp);
A filter primitive that translates between C characters and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdr_destroy(XDR *xdrs);
Frees the XDR stream structure and any associated resources. This should be called on all XDR streams when they are no longer needed.
bool_t xdr_double(XDR *xdrs, double *dp);
A filter primitive that translates between C double precision real numbers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
A filter primitive that translates between C enum types and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_float(XDR *xdrs, float *fp);
A filter primitive that translates between C float precision real numbers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdr_free(xdrproc_t proc, char *ptr);
Frees memory previously allocated by an XDR filter. The argument proc is the XDR filter used to encode or decode the data structure pointed to by ptr.
unsigned int xdr_getpos(XDR *xdrs);
A macro that invokes the get position routine associated with the XDR stream xdrs. This routine returns a position value. The value is used by xdr_setpos(). Note that not all XDR streams support this operation.
void *xdr_inline(XDR *xdrs, unsigned int len);
Returns a pointer to a buffer of at least len bytes in size, suitable for use with XDR routines. This buffer may be temporary, so the data should be processed immediately. Returns NULL if the XDR stream does not support in-line XDR, or if the requested length is not available.
bool_t xdr_int(XDR *xdrs, int *ip);
A filter primitive that translates between C integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_long(XDR *xdrs, long *lp);
A filter primitive that translates between C long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int len, enum xdr_op op);
Initializes the XDR stream object pointed to by xdrs. The XDR stream data is read from or written to the memory buffer starting at address addr, for len bytes. The argument op specifies the direction of the XDR stream (either XDR_ENCODE, XDR_DECODE, or XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int len);
A filter primitive that translates between arbitrary data and its external representation. The argument cp is the pointer to the data, and len is the number of bytes of data. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_pointer(XDR *xdrs, char **pp, unsigned int size,
                   xdrproc_t proc);
A primitive that handles XDR filtering for pointers. The argument pp is the address of the pointer to be filtered. The argument size is the size of the object pointed to by pp. The argument proc is the XDR filter procedure to be used for filtering the object. This routine handles NULL pointers correctly. Returns one if it succeeds, zero otherwise.
void xdrrec_create(XDR *xdrs, unsigned int hiresize, unsigned int losize,
                   char *morecols, int (*readit)(char *, char *, unsigned int),
                   int (*writeit)(char *, char *, unsigned int));
Initializes the XDR stream object pointed to by xdrs for record oriented I/O. The arguments hiresize and losize specify the sizes of the buffers used for reading and writing records, respectively. The argument morecols is a pointer to a buffer used when records span buffer boundaries. The arguments readit and writeit are pointers to functions that read from and write to the underlying transport, respectively.
Note: The readit and writeit functions should return the number of bytes read or written, respectively, or -1 on error.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
This routine can be invoked only on streams created by xdrrec_create(). The data in the output buffer is marked as a completed record, and the output buffer is optionally written out if sendnow is nonzero. This routine returns one if it succeeds, zero otherwise.
bool_t xdrrec_eof(XDR *xdrs);
This routine can be invoked only on streams created by xdrrec_create(). After consuming the rest of the current record in the stream, this routine returns one if the stream has no more input, zero otherwise.
bool_t xdrrec_skiprecord(XDR *xdrs);
This routine can be invoked only on streams created by xdrrec_create(). It tells the XDR implementation that the rest of the current record in the stream's input buffer should be discarded. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
A primitive that provides pointer chasing within structures. The argument pp is the address of the pointer; size is the sizeof the structure that *pp points to; and proc is an XDR procedure that filters the structure between its C form and its external representation. This routine returns one if it succeeds, zero otherwise.
Warning: this routine does not understand null pointers. Use xdr_pointer() instead.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
A macro that invokes the set position routine associated with the XDR stream xdrs. The argument pos is a position value obtained from xdr_getpos(). This routine returns one if the XDR stream could be repositioned, and zero otherwise.
Warning: it is difficult to reposition some types of XDR streams, so this routine may fail with one type of stream and succeed with another.
bool_t xdr_short(XDR *xdrs, short *sp);
A filter primitive that translates between C short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
This routine initializes the XDR stream object pointed to by xdrs. The XDR stream data is written to, or read from, the stdio stream file. The argument op determines the direction of the XDR stream (either XDR_ENCODE, XDR_DECODE, or XDR_FREE).
Warning: the destroy routine associated with such XDR streams calls fflush(3) on the file stream, but never fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
A filter primitive that translates between C strings and their corresponding external representations. Strings cannot be longer than maxsize. Note: sp is the address of the string's pointer. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
A filter primitive that translates between unsigned C characters and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
A filter primitive that translates between C unsigned integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
A filter primitive that translates between C unsigned long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
A filter primitive that translates between C unsigned short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* may equal NULL */
A filter primitive that translates between a discriminated C union and its corresponding external representation. It first translates the discriminant of the union located at dscmp. This discriminant is always an enum_t. Next the union located at unp is translated. The argument choices is a pointer to an array of xdr_discrim() structures. Each structure contains an ordered pair of [value,proc]. If the union's discriminant is equal to the associated value, then the proc is called to translate the union. The end of the xdr_discrim() structure array is denoted by a routine of value NULL. If the discriminant is not found in the choices array, then the defaultarm procedure is called (if it is not NULL). Returns one if it succeeds, zero otherwise.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
A filter primitive that translates between fixed-length arrays and their corresponding external representations. The argument arrp is the address of the pointer to the array, while size is the element count of the array. The argument elsize is the sizeof each of the array's elements, and elproc is an XDR filter that translates between the array elements' C form, and their external representation. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_void(void);
This routine always returns one. It may be passed to RPC routines that require a function argument, where nothing is to be done.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
A primitive that calls xdr_string(xdrs, sp,MAXUN.UNSIGNED ); where MAXUN.UNSIGNED is the maximum value of an unsigned integer. xdr_wrapstring() is handy because the RPC package passes a maximum of two XDR routines as arguments, and xdr_string(), one of the most frequently used primitives, requires three. Returns one if it succeeds, zero otherwise.
