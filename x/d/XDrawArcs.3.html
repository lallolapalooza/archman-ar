XDrawArcs(3)

الحزمة: libx11

التراخيص: MIT AND X11

NAME

XDrawArcs — draw arcs

SYNTAX

XDrawArcs(Display *display, Drawable d, GC gc, XArc *arcs, int n_arcs);

ARGUMENTS

• display
Specifies the connection to the X server.
• d
Specifies the drawable (a window or a pixmap).
• gc
Specifies the graphics context.
• arcs
Specifies an array of arc structures.
• n_arcs
Specifies the number of arcs in the array.

DESCRIPTION

The XDrawArcs function draws one or more arcs. The arcs are defined by the XArc structures in the arcs argument. Each XArc structure contains a bounding box, a starting angle, and an ending angle.

The angles are measured in degrees clockwise from the positive x-axis. A starting angle of 0 corresponds to the position at 3 o'clock. An arc that starts at angle A and ends at angle B is drawn counterclockwise if B > A, and clockwise if A > B.

If the start and end angles are the same, a full ellipse or circle is drawn. If the start and end angles differ by 360 degrees, a full ellipse or circle is also drawn.

The arcs are drawn using the specified graphics context. Clipping is done by the graphics context, and the drawable's clip mask.

STRUCTURES

The XArc structure is defined as:

typedef struct {
    XPoint x, y;
    unsigned int width, height;
    int start_angle;
    int end_angle;
} XArc;

Where:

• x, y
Specify the x and y coordinates of the upper-left corner of the arc's bounding box.
• width, height
Specify the width and height of the arc's bounding box.
• start_angle
Specifies the starting angle of the arc in degrees (1/64th of a full circle).
• end_angle
Specifies the ending angle of the arc in degrees (1/64th of a full circle).

DIAGNOSTICS

If the specified number of arcs is not valid, or if the graphics context is invalid, an error will be generated.

If the specified drawable is not valid, an error will be generated.

If any argument or pair of arguments has the correct type and range but fails to match in some other way required by the request, an error will be generated.
