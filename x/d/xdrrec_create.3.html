الاسم

xdr — روتينيات مكتبة لتمثيل البيانات الخارجي

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص والوصف

تسمح هذه الروتينيات لمبرمجي C بوصف هياكل بيانات اعتباطية بطريقة مستقلة عن الجهاز. يتم إرسال البيانات لاستدعاءات الإجراءات عن بعد باستخدام هذه الروتينيات.

النماذج الأولية أدناه معلنة في <rpc/xdr.h> وتستخدم الأنواع التالية:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

لإعلان النوع XDR، راجع <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
مرشح بدائي يقوم بالترجمة بين المصفوفات ذات الطول المتغير وتمثيلاتهم الخارجية المقابلة. الوسيط arrp هو عنوان المؤشر إلى المصفوفة، بينما sizep هو عنوان عدد العناصر في المصفوفة؛ لا يمكن أن يتجاوز عدد العناصر هذا maxsize. الوسيط elsize هو sizeof كل عنصر من عناصر المصفوفة، و elproc هو مرشح XDR يقوم بالترجمة بين شكل C لعناصر المصفوفة وتمثيلهم الخارجي. تعيد هذه الروتينية واحدًا إذا نجحت، وصفرًا بخلاف ذلك.

تحذير: قد تعيد xdr_inline() القيمة NULL (0) إذا لم تتمكن من تخصيص جزء متجاور من مخزن. لذلك قد يختلف السلوك بين مثيلات التيار؛ وهي موجودة من أجل الكفاءة.

مثل xdr_reference() باستثناء أنها تقوم بتسلسل المؤشرات الفارغة، بينما xdr_reference() لا تفعل ذلك. وبالتالي، يمكن لـ xdr_pointer() تمثيل هياكل بيانات متكررة، مثل الأشجار الثنائية أو القوائم المترابطة.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
تقوم هذه الروتينية بتهيئة كائن تيار XDR المشار إليه بواسطة xdrs. يتم كتابة بيانات التيار إلى مخزن بحجم sendsize؛ قيمة الصفر تشير إلى أن النظام يجب أن يستخدم قيمة افتراضية مناسبة. يتم قراءة بيانات التيار من مخزن بحجم recvsize؛ يمكن أيضًا تعيينه إلى قيمة افتراضية مناسبة عن طريق تمرير قيمة صفر. عندما يمتلئ مخزن الإخراج للتيار، يتم استدعاء writeit. وبالمثل، عندما يكون مخزن الإدخال للتيار فارغًا، يتم استدعاء readit. سلوك هاتين الروتينيتين مشابه لاستدعاءات النظام read(2) و write(2)، باستثناء أنه يتم تمرير handle إلى الروتينيات السابقة كوسيط أول. ملاحظة: يجب على المتصل تعيين حقل op لتيار XDR.
تحذير: لقراءة تيار XDR تم إنشاؤه بواسطة واجهة برمجة التطبيقات هذه، ستحتاج إلى استدعاء xdrrec_skiprecord() أولاً قبل استدعاء أي واجهات برمجة تطبيقات XDR أخرى. هذا يدرج بايت إضافية في التيار لتوفير حدود السجل
