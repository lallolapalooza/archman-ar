الملخص والوصف

تسمح هذه الروتينات لبرامج C بوصف هياكل بيانات عشوائية بطريقة مستقلة عن الآلة. يتم إرسال البيانات لنداءات الإجراءات البعيدة (remote procedure calls) باستخدام هذه الروتينات.

النماذج الأولية أدناه معرّفة في <rpc/xdr.h> وتستخدم الأنواع التالية:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

لإعلان النوع XDR، راجع <rpc/xdr.h>.

void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
تهيئة كائن تيار XDR المشار إليه بواسطة xdrs. يتم قراءة البيانات من أو كتابتها إلى ملف C المرتبط بالكائن file. يحدد op اتجاه تيار XDR (إما XDR_ENCODE، XDR_DECODE، أو XDR_FREE).
bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
فلتر أولي يترجم بين المصفوفات ذات الطول المتغير وتمثيلاتها الخارجية المقابلة. الوسيط arrp هو عنوان المؤشر إلى المصفوفة، بينما sizep هو عنوان عدد العناصر في المصفوفة؛ لا يمكن أن يتجاوز عدد العناصر هذا maxsize. الوسيط elsize هو sizeof لكل عنصر من عناصر المصفوفة، و elproc هو فلتر XDR يترجم بين شكل C لعناصر المصفوفة وتمثيلها الخارجي. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
فلتر أولي يترجم بين القيم المنطقية (أعداد صحيحة C) وتمثيلاتها الخارجية. عند ترميز البيانات، تنتج هذه المرشحة قيمًا إما واحد أو صفر. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
فلتر أولي يترجم بين سلاسل البايتات المرقمة وتمثيلاتها الخارجية. الوسيط sp هو عنوان مؤشر السلسلة. يقع طول السلسلة في العنوان sizep؛ لا يمكن أن تكون السلاسل أطول من maxsize. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_char(XDR *xdrs, char *cp);
فلتر أولي يترجم بين أحرف C وتمثيلاتها الخارجية. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك. ملاحظة: الأحرف المشفرة ليست مجمعة، وتشغل 4 بايتات لكل منها. بالنسبة لمصفوفات الأحرف، يجدر النظر في xdr_bytes()، xdr_opaque()، أو xdr_string().
void xdr_destroy(XDR *xdrs);
ماكرو يستدعي روتين التدمير المرتبط بتيار XDR، xdrs. يتضمن التدمير عادةً تحرير هياكل البيانات الخاصة المرتبطة بالتيار. استخدام xdrs بعد استدعاء xdr_destroy() غير محدد.
bool_t xdr_double(XDR *xdrs, double *dp);
فلتر أولي يترجم بين أرقام C ذات الدقة المزدوجة double وتمثيلاتها الخارجية. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
فلتر أولي يترجم بين تعدادات C enum (أعداد صحيحة في الواقع) وتمثيلاتها الخارجية. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_float(XDR *xdrs, float *fp);
فلتر أولي يترجم بين أرقام C العائمة float وتمثيلاتها الخارجية. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
void xdr_free(xdrproc_t proc, char *objp);
روتين تحرير عام. الوسيط الأول هو روتين XDR للكائن الذي يتم تحريره. الوسيط الثاني هو مؤشر إلى الكائن نفسه. ملاحظة: المؤشر الذي تم تمريره إلى هذا الروتين لا يتم تحريره، ولكن ما يشير إليه يتم تحريره (بشكل متكرر).
unsigned int xdr_getpos(XDR *xdrs);
ماكرو يستدعي روتين الحصول على الموضع المرتبط بتيار XDR، xdrs. يعيد الروتين عددًا صحيحًا غير موقّع، والذي يشير إلى موضع تيار البايتات XDR. ميزة مرغوبة في تيارات XDR هي أن العمليات الحسابية البسيطة تعمل مع هذا الرقم، على الرغم من أن مثيلات تيار XDR قد لا تضمن ذلك.
long *xdr_inline(XDR *xdrs, int len);
ماكرو يستدعي روتين الخط المباشر المرتبط بتيار XDR، xdrs. يعيد الروتين مؤشرًا إلى قطعة متجاورة من مخزن التيار المؤقت؛ len هو طول البايت للمخزن المطلوب. ملاحظة: يتم تحويل المؤشر إلى long *.
تحذير: قد تعيد xdr_inline() القيمة NULL (0) إذا لم تتمكن من تخصيص قطعة متجاورة من المخزن المؤقت. لذلك قد يختلف السلوك بين مثيلات التيار؛ إنه موجود من أجل الكفاءة.
bool_t xdr_int(XDR *xdrs, int *ip);
فلتر أولي يترجم بين أعداد C الصحيحة وتمثيلاتها الخارجية. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_long(XDR *xdrs, long *lp);
فلتر أولي يترجم بين أعداد C الصحيحة الطويلة long وتمثيلاتها الخارجية. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
تهيئة كائن تيار XDR المشار إليه بواسطة xdrs. يتم كتابة البيانات أو قراءتها من، جزء من الذاكرة في الموقع addr بطول لا يتجاوز size بايت. يحدد op اتجاه تيار XDR (إما XDR_ENCODE، XDR_DECODE، أو XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
فلتر أولي يترجم بين البيانات المعتمة ذات الحجم الثابت وتمثيلها الخارجي. الوسيط cp هو عنوان الكائن المعتم، و cnt هو حجمه بالبايت. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
مثل xdr_reference() باستثناء أنها تسلسل مؤشرات فارغة، بينما xdr_reference() لا تفعل ذلك. وبالتالي، يمكن لـ xdr_pointer() تمثيل هياكل البيانات المتكررة، مثل الأشجار الثنائية أو القوائم المتصلة.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
تهيئة كائن تيار XDR المشار إليه بواسطة xdrs. يتم كتابة بيانات التيار إلى مخزن مؤقت بحجم sendsize؛ قيمة صفر تشير إلى أن النظام يجب أن يستخدم قيمة افتراضية مناسبة. يتم قراءة بيانات التيار من مخزن مؤقت بحجم recvsize؛ يمكن أيضًا تعيين هذا إلى قيمة افتراضية مناسبة عن طريق تمرير قيمة صفر. عندما يمتلئ المخزن المؤقت الناتج للتيار، يتم استدعاء writeit. وبالمثل، عندما يكون المخزن المؤقت للإدخال للتيار فارغًا، يتم استدعاء readit. سلوك هذين الروتينين مشابه لاستدعاءات النظام read(2) و write(2)، باستثناء أن handle يتم تمريره إلى الروتينات السابقة كوسيط أول. ملاحظة: يجب على المتصل تعيين حقل op لتيار XDR.
تحذير: لقراءة تيار XDR تم إنشاؤه بواسطة واجهة برمجة التطبيقات هذه، ستحتاج إلى استدعاء xdrrec_skiprecord() أولاً قبل استدعاء أي واجهات برمجة تطبيقات XDR أخرى. هذا يدرج بايتات إضافية في التيار لتوفير حدود السجل.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
يسمح هذا بتمثيل هياكل بيانات معقدة. على سبيل المثال، يمثل xdr_reference() مصفوفة من أنواع معينة. الوسيط pp هو عنوان المؤشر إلى الكائن المراد تسلسله. يجب أن يكون size هو حجم الكائن بالبايت، ويجب أن يكون proc هو روتين XDR الذي يقوم بتسلسل الكائن.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
ماكرو يستدعي روتين تعيين الموضع المرتبط بتيار XDR، xdrs. تقوم الدالة بتعيين الموضع الحالي لتيار XDR إلى pos. تعيد الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_short(XDR *xdrs, short *sp);
فلتر أولي يترجم بين أعداد C الصحيحة القصيرة short وتمثيلاتها الخارجية. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
فلتر أولي يترجم بين سلاسل C المنتهية بمحرف فارغ (null-terminated) وتمثيلاتها الخارجية. الوسيط sp هو عنوان مؤشر السلسلة. لا يمكن أن تكون السلاسل أطول من maxsize. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_u_int32_t(XDR *xdrs, u_int32_t *uip);
فلتر أولي يترجم بين أعداد C الصحيحة غير الموقعة ذات 32 بت وتمثيلاتها الخارجية. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_u_int64_t(XDR *xdrs, u_int64_t *ullp);
فلتر أولي يترجم بين أعداد C الصحيحة غير الموقعة ذات 64 بت وتمثيلاتها الخارجية. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
فلتر أولي يترجم بين أعداد C الصحيحة الطويلة غير الموقعة unsigned long وتمثيلاتها الخارجية. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_u_longlong_t(XDR *xdrs, unsigned long long *ullp);
فلتر أولي يترجم بين أعداد C الصحيحة الطويلة جدًا غير الموقعة unsigned long long وتمثيلاتها الخارجية. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_uint(XDR *xdrs, unsigned int *up);
فلتر أولي يترجم بين أعداد C الصحيحة غير الموقعة unsigned int وتمثيلاتها الخارجية. تعيد هذه الدالة واحدًا إذا نجحت، وصفرًا بخلاف ذلك.
bool_t xdr_union(XDR *xdrs, enum_t *discr, char *fmt,
                 xdr_discriminator_union fmt, xdrproc_t dfltproc);
يتعامل مع التعدادات غير المستوية (discriminator unions) في XDR. الوسيط discr هو المؤشر إلى المشخص. يجب أن يكون fmt مصفوفة من هياكل xdr_union التي تصف الحقول المختلفة للمنظمة. يجب أن يكون dfltproc هو روتين XDR الافتراضي الذي يجب استدعاؤه إذا لم يكن المشخص في fmt.

bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
This routine can be invoked only on streams created by xdrrec_create(). The data in the output buffer is marked as a completed record, and the output buffer is optionally written out if sendnow is nonzero. This routine returns one if it succeeds, zero otherwise.
bool_t xdrrec_eof(XDR *xdrs);
This routine can be invoked only on streams created by xdrrec_create(). After consuming the rest of the current record in the stream, this routine returns one if the stream has no more input, zero otherwise.
bool_t xdrrec_skiprecord(XDR *xdrs);
This routine can be invoked only on streams created by xdrrec_create(). It tells the XDR implementation that the rest of the current record in the stream's input buffer should be discarded. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
A primitive that provides pointer chasing within structures. The argument pp is the address of the pointer; size is the sizeof the structure that *pp points to; and proc is an XDR procedure that filters the structure between its C form and its external representation. This routine returns one if it succeeds, zero otherwise.
Warning: this routine does not understand null pointers. Use xdr_pointer() instead.
xdr_setpos(XDR *xdrs, unsigned int pos);
A macro that invokes the set position routine associated with the XDR stream xdrs. The argument pos is a position value obtained from xdr_getpos(). This routine returns one if the XDR stream could be repositioned, and zero otherwise.
Warning: it is difficult to reposition some types of XDR streams, so this routine may fail with one type of stream and succeed with another.
bool_t xdr_short(XDR *xdrs, short *sp);
A filter primitive that translates between C short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
This routine initializes the XDR stream object pointed to by xdrs. The XDR stream data is written to, or read from, the stdio stream file. The argument op determines the direction of the XDR stream (either XDR_ENCODE, XDR_DECODE, or XDR_FREE).
Warning: the destroy routine associated with such XDR streams calls fflush(3) on the file stream, but never fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
A filter primitive that translates between C strings and their corresponding external representations. Strings cannot be longer than maxsize. Note: sp is the address of the string's pointer. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
A filter primitive that translates between unsigned C characters and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
A filter primitive that translates between C unsigned integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
A filter primitive that translates between C unsigned long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
A filter primitive that translates between C unsigned short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* may equal NULL */
A filter primitive that translates between a discriminated C union and its corresponding external representation. It first translates the discriminant of the union located at dscmp. This discriminant is always an enum_t. Next the union located at unp is translated. The argument choices is a pointer to an array of xdr_discrim() structures. Each structure contains an ordered pair of [value,proc]. If the union's discriminant is equal to the associated value, then the proc is called to translate the union. The end of the xdr_discrim() structure array is denoted by a routine of value NULL. If the discriminant is not found in the choices array, then the defaultarm procedure is called (if it is not NULL). Returns one if it succeeds, zero otherwise.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
A filter primitive that translates between fixed-length arrays and their corresponding external representations. The argument arrp is the address of the pointer to the array, while size is the element count of the array. The argument elsize is the sizeof each of the array's elements, and elproc is an XDR filter that translates between the array elements' C form, and their external representation. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_void(void);
This routine always returns one. It may be passed to RPC routines that require a function argument, where nothing is to be done.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
A primitive that calls xdr_string(xdrs, sp,MAXUN.UNSIGNED ); where MAXUN.UNSIGNED is the maximum value of an unsigned integer. xdr_wrapstring() is handy because the RPC package passes a maximum of two XDR routines as arguments, and xdr_string(), one of the most frequently used primitives, requires three. Returns one if it succeeds, zero otherwise.
