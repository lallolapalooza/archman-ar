XdbeGetBackBufferAttributes(3)

الحزمة: libxext

التراخيص: LicenseRef-libxext

XdbeGetBackBufferAttributes(3) X FUNCTIONS XdbeGetBackBufferAttributes(3)

الاسم

XdbeGetBackBufferAttributes - يعيد سمات المخزن المؤقت لـ DBE.

الملخص

#include <X11/extensions/Xdbe.h>

XdbeBackBufferAttributes *XdbeGetBackBufferAttributes(
Display *dpy,
XdbeBackBuffer buffer)

الوصف

تعيد هذه الدالة السمات المرتبطة بالمخزن المؤقت المحدد.

يحتوي هيكل XdbeBackBufferAttributes على الحقول التالية:

Window window النافذة التي ينتمي إليها المخزن المؤقت

إذا كان المخزن المؤقت ليس XdbeBackBuffer صالحًا، فإن النافذة تعيد None.

يمكن تحرير هيكل XdbeBackBufferAttributes المعاد باستخدام دالة Xlib Xfree().

انظر أيضا

DBE، XdbeAllocateBackBufferName()، XdbeBeginIdiom()، XdbeDeallocateBackBufferName()، XdbeEndIdiom()، XdbeFreeVisualInfo()، XdbeGetVisualInfo()، XdbeQueryExtension()، XdbeSwapBuffers().

libXext 1.3.6 X Version 11
