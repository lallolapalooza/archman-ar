xdr_short(3) Library Functions Manual xdr_short(3)

NAME

xdr_short, xdr_u_short, xdr_long, xdr_u_long, xdr_hyper, xdr_u_hyper, xdr_longlong_array, xdr_vector - library routines for external data representation

LIBRARY

Standard C library (libc, -lc)

SYNOPSIS AND DESCRIPTION

These routines allow C programmers to describe arbitrary data structures in a machine-independent fashion. Data for remote procedure calls are transmitted using these routines.

The prototypes below are declared in <rpc/xdr.h> and make use of the following types:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

For the declaration of the XDR type, see <rpc/xdr.h>.

bool_t xdr_short(XDR *xdrs, short *sp);
A filter primitive that translates between C short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
A filter primitive that translates between C unsigned short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_long(XDR *xdrs, long *lp);
A filter primitive that translates between C long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
A filter primitive that translates between C unsigned long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_hyper(XDR *xdrs, long long *llp);
A filter primitive that translates between C long long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_hyper(XDR *xdrs, unsigned long long *ullp);
A filter primitive that translates between C unsigned long long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_longlong_array(XDR *xdrs, long long *arr, unsigned int num);
Translates a C array of long long integers to or from its XDR representation. The argument num specifies the number of elements in the array. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_vector(XDR *xdrs, char *arr, unsigned int len,
                 unsigned int maxsize, xdrproc_t element_xdr);
Translates a C array of elements of fixed size to or from its XDR representation. The argument arr points to the array, len is the number of elements in the array, maxsize is the maximum number of elements allowed, and element_xdr is the XDR routine for individual elements. This routine returns one if it succeeds, zero otherwise.

The functions xdr_array(), xdr_bool(), xdr_bytes(), xdr_char(), xdr_destroy(), xdr_double(), xdr_enum(), xdr_float(), xdr_free(), xdr_getpos(), xdr_inline(), xdr_int(), xdr_long(), xdrmem_create(), xdr_opaque(), xdr_pointer(), xdrrec_create(), xdr_reference(), xdr_setpos(), xdr_string(), xdr_u_long(), xdr_uint(), xdr_u_hyper(), xdr_ulonglong_array(), xdr_union(), xdr_void(), and xdrrec_skiprecord() are described in xdr(3).
