XvShmPutImage(3)

الحزمة: libxv

التراخيص: SMLNJ, HPND-sell-variant

XvPutImage(3) وظائف libXv XvPutImage(3)

الاسم

XvPutImage, XvShmPutImage - عرض صورة Xv

الملخص

#include <X11/extensions/Xvlib.h>

int XvPutImage (Display *dpy, XvPortID port,
                Drawable d, GC gc, XvImage *image,
                int src_x, int src_y,
                unsigned int src_w, unsigned int src_h,
                int dest_x, int dest_y,
                unsigned int dest_w, unsigned int dest_h);

int XvShmPutImage (Display *dpy, XvPortID port,
                   Drawable d, GC gc, XvImage *image,
                   int src_x, int src_y,
                   unsigned int src_w, unsigned int src_h,
                   int dest_x, int dest_y,
                   unsigned int dest_w, unsigned int dest_h,
                   Bool send_event);

المعاملات

dpy
يحدد الاتصال بخادم X.
port
معرف المنفذ لمنفذ على محول قادر على صور Xv.
d
gc
سياق الرسومات الذي يحدد قناع القطع لاستخدامه، إن وجد.
image
مؤشر إلى صورة Xv المطلوب عرضها.
src_?
جزء صورة Xv المطلوب عرضه.
dest_?
جزء الرسم الوجهة الذي سيتم ملؤه بالصورة.
send_event
يشير إلى ما إذا كان يجب إرسال حدث XShmCompletion أم لا. إذا تم إرساله، فسيحدد حقلا major_code و minor_code للحدث الرمز الرئيسي لملحق Xv والرمز الثانوي لـ XvShmPutImage.

الوصف

XvPutImage(3) تشبه XPutImage(3). XvShmPutImage(3) تشبه XShmPutImage(3). ستقوم المكتبة بتخصيص بنية XvImage وملء جميع الحقول باستثناء data. قد يتم تكبير Width و height في بعض تنسيقات YUV. سيتم إعطاء حجم مخزن البيانات الذي يحتاج إلى تخصيصه في حقل data_size في XvImage. لا يتم تخصيص بيانات الصورة بواسطة هذه الوظيفة. قد يمرر العميل مؤشرًا إلى الذاكرة المخصصة مسبقًا باسم data أو قد يخصص الذاكرة ويملأ حقل بيانات بنية XvImage بعد ملء حقل data_size بواسطة الخادم. يمكن تحرير بنية XvImage بواسطة XFree(3).

التشخيصات

[XvBadPort]
يتم إنشاؤه إذا كان المنفذ المطلوب غير موجود.
[XvBadAlloc]
يتم إنشاؤه إذا فشل خادم X في تخصيص الموارد المطلوبة لإكمال العملية.
[BadMatch]
يتم إنشاؤه إذا تم تقديم معاملات غير متوافقة، مثل منفذ غير قادر على عرض صور Xv.
[BadShmSegCode]
يتم إنشاؤه إذا تم تحديد قطعة ذاكرة مشتركة غير صالحة.
