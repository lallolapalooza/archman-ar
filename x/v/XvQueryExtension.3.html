XvQueryExtension(3)

الحزمة: libxv

التراخيص: SMLNJ, HPND-sell-variant

XvQueryExtension(3) وظائف libXv XvQueryExtension(3)

الاسم

XvQueryExtension - إرجاع الإصدار والإصدار الخاص بالامتداد

الملخص

#include <X11/extensions/Xvlib.h>

int XvQueryExtension(Display *dpy, unsigned int *p_version,
                    unsigned int *p_revision,
                    unsigned int *p_request_base,
                    unsigned int *p_event_base,
                    unsigned int *p_error_base);

المعاملات

dpy
يحدد الاتصال بخادم X.
p_version
مؤشر إلى مكان كتابة رقم الإصدار الحالي لامتداد الفيديو Xv.
p_revision
مؤشر إلى مكان كتابة رقم الإصدار الخاص بامتداد الفيديو Xv.
p_request_base
مؤشر إلى حيث يتم إرجاع رقم الطلب الرئيسي للامتداد
p_event_base
مؤشر إلى حيث يتم إرجاع قاعدة أحداث الامتداد
p_error_base
مؤشر إلى حيث يتم إرجاع قاعدة أخطاء الامتداد

الوصف

XvQueryExtension(3) يرجع أرقام الإصدار والإصدار لامتداد الفيديو Xv المحمل حاليًا على النظام. يتم أيضًا إرجاع رقم الطلب الرئيسي للامتداد، وقاعدة الأحداث، وقاعدة الأخطاء.

قيم الإرجاع

[نجاح]
تم الإرجاع إذا اكتمل XvQueryExtension(3) بنجاح.
[XvBadExtension]
تم الإرجاع إذا لم يكن امتداد الفيديو Xv متاحًا للعرض المحدد.
