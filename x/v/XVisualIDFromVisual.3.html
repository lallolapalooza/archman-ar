XVisualIDFromVisual(3)

الحزمة: libx11

التراخيص: MIT AND X11

XGetVisualInfo(3) وظائف XLIB XGetVisualInfo(3)

الاسم

XGetVisualInfo, XMatchVisualInfo, XVisualIDFromVisual, XVisualInfo - الحصول على معلومات مرئية وبنية مرئية

الصيغة

XVisualInfo *XGetVisualInfo(Display *display, long vinfo_mask, XVisualInfo *vinfo_template, int *nitems_return);

Status XMatchVisualInfo(Display *display, int screen, int depth, int class, XVisualInfo *vinfo_return);

VisualID XVisualIDFromVisual(Visual *visual);

المعاملات

class
يحدد فئة الشاشة.
depth
يحدد عمق الشاشة.
display
يحدد الاتصال بخادم X.
nitems_return
يعيد عدد الهياكل المرئية المطابقة.
screen
يحدد الشاشة.
visual
يحدد النوع المرئي.
vinfo_mask
يحدد قيمة قناع المعلومات المرئية.
vinfo_return
يعيد معلومات المرئيات المطابقة.
vinfo_template
يحدد السمات المرئية التي سيتم استخدامها في مطابقة الهياكل المرئية.

الوصف

تقوم الدالة XGetVisualInfo بإرجاع قائمة بالهياكل المرئية التي لها سمات تساوي السمات المحددة بواسطة vinfo_template. إذا لم تتطابق أي هياكل مرئية مع القالب باستخدام vinfo_mask المحدد، ترجع XGetVisualInfo قيمة NULL. لتحرير البيانات التي تم إرجاعها بواسطة هذه الدالة، استخدم XFree.

تقوم الدالة XMatchVisualInfo بإرجاع معلومات المرئيات للمرئيات التي تتطابق مع العمق والفئة المحددة للشاشة. نظرًا لأنه يمكن أن توجد مرئيات متعددة تتطابق مع العمق والفئة المحددين، فإن المرئيات الدقيقة المختارة غير محددة. إذا تم العثور على مرئيات، ترجع XMatchVisualInfo قيمة غير صفرية والمعلومات عن المرئيات إلى vinfo_return. وإلا، عند عدم العثور على مرئيات، ترجع XMatchVisualInfo قيمة صفر.

تقوم الدالة XVisualIDFromVisual بإرجاع معرف المرئيات للنوع المرئي المحدد.

الهياكل

الهيكل XVisualInfo يحتوي على:

/* بتات قناع معلومات المرئيات */

#define VisualNoMask 0x0
#define VisualIDMask 0x1
#define VisualScreenMask 0x2
#define VisualDepthMask 0x4
#define VisualClassMask 0x8
#define VisualRedMaskMask 0x10
#define VisualGreenMaskMask 0x20
#define VisualBlueMaskMask 0x40
#define VisualColormapSizeMask 0x80
#define VisualBitsPerRGBMask 0x100
#define VisualAllMask 0x1FF 
/* القيم */
typedef struct {
        Visual *visual;
        VisualID visualid;
        int screen;
        int depth;
        int class;
        unsigned long red_mask;
        unsigned long green_mask;
        unsigned long blue_mask;
        int colormap_size;
        int bits_per_rgb;
} XVisualInfo;
