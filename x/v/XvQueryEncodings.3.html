XvQueryEncodings(3)

الحزمة: libxv

التراخيص: SMLNJ, HPND-sell-variant

XvQueryEncodings(3) وظائف libXv XvQueryEncodings(3)

الاسم

XvQueryEncodings - إرجاع قائمة الترميزات لمحول

الملخص

#include <X11/extensions/Xvlib.h>

int XvQueryEncodings(Display *dpy, XvPortID port,
                     unsigned int *p_num_encodings,
                     XvEncodingInfo **pp_encoding_info);

المعاملات

dpy
يحدد الاتصال بخادم X.
port
يحدد المنفذ الذي سيتم الاستعلام عن محوله لقائمة الترميزات الخاصة به.
p_num_encodings
مؤشر إلى المكان الذي سيتم فيه كتابة عدد الترميزات التي يدعمها المحول.
pp_encoding_info
مؤشر إلى المكان الذي سيتم فيه إرجاع قائمة معلومات الترميز العائدة. XvEncodingInfo له البنية التالية: 
    typedef struct {
      XvEncodingID encoding_id;
      char *name;
      unsigned long width;
      unsigned long height;
      XvRational rate;
      unsigned long num_encodings;
    } XvEncodingInfo;
encoding_id
يحدد معرف الترميز الخاص بالترميز. يتم استخدام معرف الترميز لتحديد ترميز عند تغيير سمة الترميز لمنفذ.
name
مؤشر إلى سلسلة نصية مهيأة تحدد الترميز. السلسلة لها التنسيق "timing-signaltype". على سبيل المثال "ntsc-composite".
width,height
العرض والارتفاع، بالبكسل، لصورة الفيديو المفككة.
rate
معدل إطارات الفيديو المفكك.

يستخدم الهيكل XvRational لتحديد رقم كسري. له البنية التالية:

    typedef struct {
      int numerator;
      int denominator;
    } XvRational;

تحدد الحقول numerator و denominator الأجزاء المناسبة لرقم كسري.

الوصف

XvQueryEncodings(3) ترجع معلومات الترميز عن محول. يتم وصف كل ترميز بواسطة هيكل XvEncodingInfo الموصوف أعلاه. يتم تحديد الترميزات بواسطة معرف ترميز، والذي يمكن استخدامه لتعيين أو الحصول على سمة الترميز لمنفذ.

قيم الإرجاع

[نجاح]
تم الإرجاع إذا اكتمل XvQueryEncodings(3) بنجاح.
[XvBadExtension]
تم الإرجاع إذا كان امتداد Xv غير متاح.
[XvBadAlloc]
تم الإرجاع إذا فشل XvQueryEncodings(3) في تخصيص ذاكرة لـ معالجة الطلب.

التشخيصات

[XvBadPort]
تم الإنشاء إذا كان المنفذ المطلوب غير موجود.
