XvGetStill(3)

الحزمة: libxv

التراخيص: SMLNJ, HPND-sell-variant

XvGetStill(3) وظائف libXv XvGetStill(3)

الاسم

XvGetStill - التقاط إطار فيديو واحد من رسم

التركيب

#include <X11/extensions/Xvlib.h>

int XvGetStill(Display *dpy, XvPortID port, Drawable d, GC gc,
               int vx, int vy, unsigned int vw, unsigned int vh,
               int dx, int dy, unsigned int dw, unsigned int dh);

المعاملات

dpy
يحدد الاتصال بخادم X.
port
يحدد المنفذ الذي سيتم إخراج اللقطة إليه.
d
يحدد الرسم الذي سيتم التقاط اللقطة منه. البكسماپ غير مدعومة حاليًا.
gc
يحدد السياق الرسومي. مكونات GC هي: subwindow-mode، clip-x-origin، clip-y-origin، و clip-mask.
vx,vy,vw,vh
تحدد موقع وحجم منطقة الفيديو الوجهة التي ستتم كتابة اللقطة إليها. vx و vy يحددان إحداثيات x و y للزاوية العلوية اليسرى لمنطقة الفيديو؛ vw و vh يحددان العرض والارتفاع، بالبكسل، لمنطقة الفيديو.
dx,dy,dw,dh
تحدد موقع وحجم الرسم المصدر الذي سيتم التقاط الصورة الثابتة منه. dx و dy يحددان إحداثيات x و y للزاوية العلوية اليسرى لمنطقة الرسم؛ dw و dh يحددان العرض والارتفاع، بالبكسل، لمنطقة الرسم.

الوصف

يلتقط إطار فيديو واحد من رسم. يتم تحديد موضع وحجم المستطيل الوجهة (الفيديو) بواسطة vx، vy، vw، و vh. يتم تحديد موضع وحجم المستطيل المصدر (الرسم) بواسطة dx، dy، dw، و dh.

يتم قص بيانات الرسم إلى حدود الرسم، ويتم تغيير حجمها إلى حجم منطقة الفيديو المطلوب (أو أقرب حجم مدعوم) ويتم قصها إلى حدود ترميز الفيديو. محتويات أي منطقة لم يتم تحديثها ببيانات الرسم غير معرفة.

إذا كان المنفذ محجوزًا بواسطة عميل آخر، يتم تجاهل هذا الطلب، ويتم إنشاء حدث XvVideoNotify بتفصيل XvBusy للرسم.

قيم الإرجاع

[نجاح]
تم الإرجاع إذا اكتمل XvGetStill(3) بنجاح.
[XvBadExtension]
تم الإرجاع إذا لم يكن امتداد Xv متاحًا.
[XvBadAlloc]
تم الإرجاع إذا فشل XvGetStill(3) في تخصيص الذاكرة لمعالجة الطلب.

التشخيصات

[XvBadPort]
يتم إنشاؤه إذا كان المنفذ المطلوب غير موجود.
[BadDrawable]
يتم إنشاؤه إذا كان الرسم المطلوب غير موجود.
[BadGC]
يتم إنشاؤه إذا كان السياق الرسومي المطلوب غير موجود.
[BadAlloc]
يتم إنشاؤه إذا كانت الموارد غير كافية لمعالجة الطلب.
