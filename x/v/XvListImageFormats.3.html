XvListImageFormats(3)

الحزمة: libxv

التراخيص: SMLNJ, HPND-sell-variant

XvListImageFormats(3) وظائف libXv XvListImageFormats(3)

الاسم

XvListImageFormats - إرجاع قائمة بتنسيقات الصور التي يدعمها منفذ فيديو

الصيغة

#include <X11/extensions/Xvlib.h>

XvImageFormatValues * XvListImageFormats (Display *dpy,
                 XvPortID port,  int *p_num_formats);

الوسائط

dpy
يحدد الاتصال بخادم X.
port
يحدد المنفذ الذي سيتم الاستعلام عن محوله لقائمة سماته.
p_num_formats
مؤشر إلى المكان الذي تتم فيه كتابة عدد التنسيقات التي تم إرجاعها في المصفوفة.

الوصف

XvListImageFormats(3) يُرجع قيم XvImageFormatValues التي يدعمها المنفذ المحدد. يجب تحرير هذه القائمة باستخدام XFree(3).

قيم الإرجاع

يحتوي XvImageFormatValues على الهيكل التالي:

    typedef struct {
      int id;                      /* معرف فريد للتنسيق */
      int type;                    /* XvRGB, XvYUV */
      int byte_order;              /* LSBFirst, MSBFirst */
      char guid[16];               /* معرف فريد عالميًا */
      int bits_per_pixel;
      int format;                  /* XvPacked, XvPlanar */
      int num_planes;
      /* للتنسيقات RGB */
      int depth;
      unsigned int red_mask;
      unsigned int green_mask;
      unsigned int blue_mask;
      /* لتنسيقات YUV */
      unsigned int y_sample_bits;
      unsigned int u_sample_bits;
      unsigned int v_sample_bits;
      unsigned int horz_y_period;
      unsigned int horz_u_period;
      unsigned int horz_v_period;
      unsigned int vert_y_period;
      unsigned int vert_u_period;
      unsigned int vert_v_period;
      char component_order[32];    /* مثال: UYVY */
      int scanline_order;          /* XvTopToBottom, XvBottomToTop */
    } XvImageFormatValues;
id
معرف فريد للتنسيق. غالبًا ما يكون FOURCC للتنسيق، عند الاقتضاء. يُستخدم هذا المعرف لوصف التنسيق أثناء إنشاء XvImage.
type
XvRGB أو XvYUV.
byte_order
ترتيب البايتات للصورة. إما LSBFirst أو MSBFirst.
guid
المعرف الفريد عالميًا (المعروف أيضًا باسم المعرف الفريد عالميًا). عندما لا يكون مناسبًا، تكون جميع الأحرف NULL.
bits_per_pixel
البايتات التي تشغلها (ولكن ليست بالضرورة مستخدمة) لكل بكسل. لاحظ أنه بالنسبة لبعض التنسيقات المستوية التي تحتوي على كسور بايتات لكل بكسل (مثل IF09) قد يتم تقريب هذا الرقم _للأسفل_.
format
XvPacked أو XvPlanar.
num_planes
عدد المستويات في التنسيقات المستوية.
depth
البايتات الهامة لكل بكسل.
red_mask, green_mask, blue_mask
أقنعة البتات الحمراء والخضراء والزرقاء (تنسيقات RGB فقط).
?_sample_bits
حجم كل عينة بالبت (تنسيقات YUV فقط).
horz_?_period, vert_?_period
الدورة (بالبكسل) التي تحدث فيها العينات في الاتجاهين الأفقي والرأسي (تنسيقات YUV فقط).
component_order
أحرف ASCII كبيرة تمثل ترتيب تخزين العينات داخل التنسيقات المعبأة. بالنسبة للتنسيقات المستوية، يمثل هذا ترتيب المستويات.
scanline_order
XvTopToBottom أو XvBottomToTop.

ملاحظات

نظرًا لأن بعض التنسيقات (خاصة بعض تنسيقات YUV المستوية) قد لا يتم تعريفها بالكامل بواسطة المعلمات المذكورة أعلاه، يجب أن يوفر guid، عند توفره، الوصف الأكثر دقة للتنسيق.

التشخيصات

[XvBadPort]
يتم إنشاؤه إذا كان المنفذ المطلوب غير موجود.
