XvPutVideo(3)

الحزمة: libxv

التراخيص: SMLNJ, HPND-sell-variant

XvPutVideo(3) وظائف libXv XvPutVideo(3)

الاسم

XvPutVideo - كتابة الفيديو إلى عنصر قابل للرسم

الملخص

#include <X11/extensions/Xvlib.h>

int XvPutVideo(Display *dpy, XvPortID port, Drawable d, GC gc,
               int vx, int vy, unsigned int vw, unsigned int vh,
               int dx, int dy, unsigned int dw, unsigned int dh);

الوسائط

dpy
يحدد الاتصال بخادم X.
port
يحدد المنفذ الذي سيتم الحصول على الفيديو منه.
d
يحدد العنصر القابل للرسم (النافذة) الذي سيتم كتابة الفيديو إليه.
gc
يحدد سياق الرسومات. مكونات GC هي: subwindow-mode، clip-x-origin، clip-y-origin، و clip-mask.
vx,vy,vw,vh
يحدد حجم وموقع مصدر (الفيديو) المنطقة التي سيتم كتابتها. vx و vy يحددان البكسل العلوي الأيسر للمنطقة. vw و vh يحددان العرض والارتفاع، بالبكسل، للمنطقة.
dx,dy,dw,dh
يحدد الموقع والحجم لمنطقة الوجهة (القابلة للرسم) التي سيتم كتابة صورة الفيديو إليها. dx و dy يحددان البكسل العلوي الأيسر للمنطقة. dw و dh يحددان العرض والارتفاع، بالبكسل، للمنطقة.

الوصف

XvPutVideo تكتب الفيديو إلى عنصر قابل للرسم. يتم تحديد موقع وحجم المستطيل المصدر (الفيديو) بواسطة vx، vy، vw، و vh. يتم تحديد موقع وحجم المستطيل الوجهة (القابل للرسم) بواسطة dx، dy، dw، و dh.

يتم اقتصاص بيانات الفيديو إلى حدود ترميز الفيديو، ويتم تحجيمها إلى حجم منطقة العنصر القابل للرسم المطلوب (أو أقرب حجم مدعوم) ويتم اقتصاصها إلى حدود العنصر القابل للرسم.

إذا بدأ الفيديو بنجاح، يتم إنشاء حدث XvVideoNotify مع تفصيل XvStarted للعنصر القابل للرسم. إذا كان المنفذ قيد الاستخدام بالفعل، فسيتم استباق الفيديو الخاص به، وإذا كان العنصر القابل للرسم الجديد مختلفًا عن القديم، فسيتم إنشاء حدث XvVideoNotify مع تفصيل XvPreempted للعنصر القابل للرسم القديم. إذا كان المنفذ محجوزًا بواسطة عميل آخر، فسيتم تجاهل هذا الطلب، وسيتم إنشاء حدث XvVideoNotify مع تفصيل XvBusy للعنصر القابل للرسم. إذا لم يكن المنفذ يتلقى إشارة فيديو صالحة أو إذا انقطعت إشارة الفيديو أثناء نشاط الفيديو، فسيتم إنشاء حدث VideoNotify مع تفصيل XvHardError للعنصر القابل للرسم.

[نجاح]
تم الإرجاع إذا اكتمل XvPutVideo(3) بنجاح.
[XvBadExtension]
تم الإرجاع إذا كان امتداد Xv غير متاح.
[XvBadAlloc]
تم الإرجاع إذا كانت الموارد غير كافية لمعالجة الطلب.

التشخيصات

[XvBadPort]
يتم إنشاؤه إذا كان المنفذ المطلوب غير موجود.
[BadDrawable]
يتم إنشاؤه إذا كان العنصر القابل للرسم المطلوب غير موجود.
[BadGC]
يتم إنشاؤه إذا كان سياق الرسومات المطلوب غير موجود.
[BadAlloc]
يتم إنشاؤه إذا كانت الموارد غير كافية لمعالجة الطلب.
