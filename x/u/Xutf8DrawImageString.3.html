Xutf8DrawImageString(3)

الحزمة: libx11

التراخيص: MIT AND X11

XmbDrawImageString(3) دوال XLIB XmbDrawImageString(3)

الاسم

XmbDrawImageString, XwcDrawImageString, Xutf8DrawImageString - رسم نص صورة باستخدام مجموعة خطوط واحدة

الصيغة

void XmbDrawImageString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, const char *string, int num_bytes);

void XwcDrawImageString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, const wchar_t *string, int num_wchars);

void Xutf8DrawImageString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, const char *string, int num_bytes);

المعاملات

d
يحدد العنصر القابل للرسم.

يحدد الاتصال بخادم X.
font_set
يحدد مجموعة الخطوط.

يحدد GC.

يحدد عدد البايتات في معامل السلسلة.

يحدد عدد الأحرف في معامل السلسلة.

يحدد سلسلة الأحرف.
x

يحدد إحداثيات x و y.

الوصف

تقوم الدوال XmbDrawImageString و XwcDrawImageString و Xutf8DrawImageString بملء مستطيل وجهة بالبكسل الخلفي المحدد في GC ثم رسم النص ببكسل المقدمة. المستطيل المملوء هو المستطيل الذي تم إرجاعه بواسطة XmbTextExtents أو XwcTextExtents أو Xutf8TextExtents للنص نفسه و XFontSet.

عندما تحتوي XFontSet على مجموعات أحرف مفقودة، يتم رسم كل حرف غير متاح باستخدام السلسلة الافتراضية التي تم إرجاعها بواسطة XCreateFontSet. السلوك الخاص بنقطة رمز غير صالحة غير محدد.

الدالة Xutf8TextExtents هي امتداد تم تقديمه بواسطة The XFree86 Project, Inc.، في الإصدار 4.0.2 الخاص بهم. يشير وجودها بواسطة الماكرو X_HAVE_UTF8_STRING.
