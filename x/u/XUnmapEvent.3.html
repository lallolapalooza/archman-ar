XUnmapEvent(3)

الحزمة: libx11

التراخيص: MIT AND X11

XUnmapEvent(3) XLIB FUNCTIONS XUnmapEvent(3)

الاسم

XUnmapEvent - بنية حدث UnmapNotify

البنى

بنية أحداث UnmapNotify تحتوي على:

typedef struct {
        int type;       /* UnmapNotify */
        unsigned long serial;   /* # of last request processed by server */
        Bool send_event;        /* true if this came from a SendEvent request */
        Display *display;       /* Display the event was read from */
        Window event;
        Window window;
        Bool from_configure;
} XUnmapEvent;

عندما تستقبل هذا الحدث، يتم تعيين أعضاء البنية كالتالي.

يتم تعيين العضو type إلى اسم ثابت لنوع الحدث الذي يعرفه بشكل فريد. على سبيل المثال، عندما يبلغ خادم X عن حدث GraphicsExpose إلى تطبيق عميل، فإنه يرسل بنية XGraphicsExposeEvent مع تعيين العضو type إلى GraphicsExpose. يتم تعيين العضو display إلى مؤشر إلى الشاشة التي تمت قراءة الحدث عليها. يتم تعيين العضو send_event إلى True إذا جاء الحدث من طلب بروتوكول SendEvent. يتم تعيين العضو serial من الرقم التسلسلي المبلغ عنه في البروتوكول ولكنه توسيع من 16 بت أقل بتات أهمية إلى قيمة كاملة 32 بت. يتم تعيين العضو window إلى النافذة الأكثر فائدة لموزعي الأدوات.

يتم تعيين العضو event إما إلى النافذة غير المعينة أو إلى والدها، اعتمادًا على ما إذا كان StructureNotify أو SubstructureNotify قد تم تحديده. هذه هي النافذة التي يستخدمها خادم X للإبلاغ عن الحدث. يتم تعيين العضو window إلى النافذة التي تم إلغاء تعيينها. يتم تعيين العضو from_configure إلى True إذا تم إنشاء الحدث نتيجة لتغيير حجم والد النافذة عندما كانت النافذة نفسها لديها win_gravity بقيمة UnmapGravity.
