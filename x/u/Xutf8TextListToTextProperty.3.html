الوصف

تقوم الوظائف XmbTextListToTextProperty و XwcTextListToTextProperty و Xutf8TextListToTextProperty بتعيين قيمة XTextProperty المحددة إلى مجموعة من العناصر المفصولة بـ null تمثل تسلسل العناصر المحددة لقوائم السلاسل النصية المنتهية بـ null. يجب أن تكون السلاسل النصية المدخلة بالترميز المحلي الحالي (لـ XmbTextListToTextProperty و XwcTextListToTextProperty)، أو بترميز UTF-8 (لـ Xutf8TextListToTextProperty).

تقوم الوظائف بتعيين حقل الترميز الخاص بـ text_prop_return إلى Atom للعرض المحدد، مع تسمية الترميز المحدد بواسطة النمط المحدد، وتحويل قائمة النص المحددة إلى هذا الترميز للتخزين في حقل قيمة text_prop_return. إذا تم تحديد النمط XStringStyle أو XCompoundTextStyle، فإن هذا الترميز هو “STRING” أو “COMPOUND_TEXT”، على التوالي. إذا تم تحديد النمط XUTF8StringStyle، فإن هذا الترميز هو “UTF8_STRING”. (هذا امتداد تم تقديمه بواسطة The XFree86 Project, Inc.، في إصدارهم 4.0.2. وجوده يشار إليه بالماكرو X_HAVE_UTF8_STRING.) إذا تم تحديد النمط XTextStyle، فإن هذا الترميز هو ترميز اللغة المحلية الحالية. إذا تم تحديد النمط XStdICCTextStyle، فإن هذا الترميز هو “STRING” إذا كان النص قابلاً للتحويل بالكامل إلى STRING، وإلا فإنه “COMPOUND_TEXT”. يتم تخزين بايت null نهائي في نهاية حقل القيمة الخاص بـ text_prop_return ولكن لا يتم تضمينه في عضو nitems.

إذا كانت الذاكرة غير كافية لسلسلة القيمة الجديدة، فإن الوظائف تعيد XNoMemory. إذا كانت اللغة المحلية الحالية غير مدعومة، فإن الوظائف تعيد XLocaleNotSupported. في كلتا هاتين الحالتين الخطأ، لا تقوم الوظائف بتعيين text_prop_return.

لتحديد ما إذا كانت الوظائف مضمونة لعدم إرجاع XLocaleNotSupported، استخدم XSupportsLocale.

إذا لم يكن النص المقدم قابلاً للتحويل بالكامل إلى الترميز المحدد، فإن الوظائف تعيد عدد الأحرف غير القابلة للتحويل. يتم تحويل كل حرف غير قابل للتحويل إلى سلسلة افتراضية محددة من قبل التنفيذ ومحددة للترميز. بخلاف ذلك، تعيد الوظائف Success. لاحظ أن القابلية الكاملة للتحويل لجميع الأنماط باستثناء XStringStyle مضمونة.

لتحرير التخزين لحقل القيمة، استخدم XFree.

تقوم الوظائف XmbTextPropertyToTextList و XwcTextPropertyToTextList و Xutf8TextPropertyToTextList بإعادة قائمة من السلاسل النصية التي تمثل العناصر المفصولة بـ null لهيكل XTextProperty المحدد. يتم ترميز السلاسل المعاد إرجاعها باستخدام ترميز اللغة المحلية الحالية (لـ XmbTextPropertyToTextList و XwcTextPropertyToTextList) أو UTF-8 (لـ Xutf8TextPropertyToTextList). يجب أن تكون البيانات في text_prop من التنسيق 8.

يتم فصل عناصر متعددة من الخاصية (على سبيل المثال، السلاسل في تحديد نص منفصل) بواسطة بايت null. لا يلزم أن تكون محتويات الخاصية منتهية بـ null؛ لا ينبغي تضمين أي null نهائي في text_prop.nitems.

إذا كانت الذاكرة غير كافية للقائمة وعناصرها، فإن XmbTextPropertyToTextList و XwcTextPropertyToTextList و Xutf8TextPropertyToTextList تعيد XNoMemory. إذا كانت اللغة المحلية الحالية غير مدعومة، فإن الوظائف تعيد XLocaleNotSupported. بخلاف ذلك، إذا كان حقل الترميز الخاص بـ text_prop غير قابل للتحويل إلى ترميز اللغة المحلية الحالية، فإن الوظائف تعيد XConverterNotFound. بالنسبة للغات المدعومة، وجود محول من COMPOUND_TEXT أو STRING أو UTF8_STRING أو ترميز اللغة المحلية الحالية مضمون إذا أعاد XSupportsLocale القيمة True للغة المحلية الحالية (ولكن النص الفعلي قد يحتوي على أحرف غير قابلة للتحويل). تحويل الترميزات الأخرى يعتمد على التنفيذ. في كل هذه الحالات الخطأ، لا تقوم الوظائف بتعيين أي قيم إرجاع.

بخلاف ذلك، تعيد XmbTextPropertyToTextList و XwcTextPropertyToTextList و Xutf8TextPropertyToTextList قائمة السلاسل النصية المنتهية بـ null إلى list_return وعدد السلاسل النصية إلى count_return.

إذا لم يكن حقل القيمة الخاص بـ text_prop قابلاً للتحويل بالكامل إلى ترميز اللغة المحلية الحالية، فإن الوظائف تعيد عدد الأحرف غير القابلة للتحويل. يتم تحويل كل حرف غير قابل للتحويل إلى سلسلة باللغة المحلية الحالية تكون خاصة باللغة المحلية الحالية. للحصول على قيمة هذه السلسلة، استخدم XDefaultString. بخلاف ذلك، تعيد XmbTextPropertyToTextList و XwcTextPropertyToTextList و Xutf8TextPropertyToTextList القيمة Success.

لتحرير التخزين للقائمة ومحتوياتها التي أعادتها XmbTextPropertyToTextList أو Xutf8TextPropertyToTextList، استخدم XFreeStringList. لتحرير التخزين للقائمة ومحتوياتها التي أعادتها XwcTextPropertyToTextList، استخدم XwcFreeStringList.

تقوم الوظيفة XwcFreeStringList بتحرير الذاكرة المخصصة بواسطة XwcTextPropertyToTextList.

تقوم الوظيفة XDefaultString بإعادة السلسلة الافتراضية التي تستخدمها Xlib لتحويل النص (على سبيل المثال، في XmbTextPropertyToTextList). السلسلة الافتراضية هي السلسلة باللغة المحلية الحالية التي يتم إخراجها عند العثور على حرف غير قابل للتحويل أثناء تحويل النص. إذا كانت السلسلة المعاد إرجاعها بواسطة XDefaultString هي سلسلة فارغة ("")، فلا يتم إخراج أي حرف في النص المحول. لا تعيد XDefaultString القيمة NULL.

السلسلة المعاد إرجاعها بواسطة XDefaultString مستقلة عن السلسلة الافتراضية لرسم النص؛ انظر XCreateFontSet للحصول على السلسلة الافتراضية لـ XFontSet.

السلوك عند توفير نقطة رمز غير صالحة لأي وظيفة Xlib غير معرف.

السلسلة المعاد إرجاعها منتهية بـ null. مملوكة لـ Xlib ولا ينبغي تعديلها أو تحريرها بواسطة العميل. قد يتم تحريرها بعد تغيير اللغة المحلية الحالية. حتى يتم تحريرها، لن يتم تعديلها بواسطة Xlib.

الدالتان Xutf8TextListToTextProperty و Xutf8TextPropertyToTextList هما امتدادات قدمتها The XFree86 Project, Inc.، في الإصدار 4.0.2 الخاص بهم. يتم الإشارة إلى وجودهما بواسطة الماكرو X_HAVE_UTF8_STRING.

البُنى

يحتوي الهيكل XTextProperty على:

typedef struct {
        unsigned char *value;   /* بيانات الخاصية */
        Atom encoding;  /* نوع الخاصية */
        int format;     /* 8، 16، أو 32 */
        unsigned long nitems;   /* عدد العناصر في value */
} XTextProperty;

يحتوي الهيكل XICCEncodingStyle على:

#define XNoMemory -1
#define XLocaleNotSupported -2
#define XConverterNotFound -3 
typedef enum {
        XStringStyle,           /* STRING */
        XCompoundTextStyle,     /* COMPOUND_TEXT */
        XTextStyle,             /* نص بتشفير المالك (الموقع المحلي الحالي) */
        XStdICCTextStyle,       /* STRING، وإلا COMPOUND_TEXT */
        XUTF8StringStyle        /* UTF8_STRING */
} XICCEncodingStyle;
