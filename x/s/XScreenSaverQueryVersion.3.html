XScreenSaverQueryVersion(3)

الحزمة: libxss

التراخيص: X11

XScreenSaver(3) X الإصدار 11 XScreenSaver(3)

الاسم

XScreenSaver - مكتبة عميل امتداد حافظ الشاشة لـ X11

الملخص

#include <X11/extensions/scrnsaver.h>

typedef struct {
    Window window;                /* نافذة حافظ الشاشة */
    int state;                    /* ScreenSaver{Off,On,Disabled} */
    int kind;                     /* ScreenSaver{Blanked,Internal,External} */
    unsigned long til_or_since;   /* بالمللي ثانية */
    unsigned long idle;           /* بالمللي ثانية */
    unsigned long eventMask;      /* الأحداث */
} XScreenSaverInfo;

typedef struct {
    int type;               /* من نوع الحدث */
    unsigned long serial;   /* # آخر طلب تمت معالجته بواسطة الخادم */
    Bool send_event;        /* صحيح إذا جاء هذا من طلب SendEvent */
    Display *display;       /* العرض الذي تم قراءة الحدث منه */
    Window window;          /* نافذة حافظ الشاشة */
    Window root;            /* النافذة الجذرية لشاشة الحدث */
    int state;              /* ScreenSaver{Off,On,Cycle} */
    int kind;               /* ScreenSaver{Blanked,Internal,External} */
    Bool forced;            /* امتدادات المنطقة الجديدة */
    Time time;              /* ختم وقت الحدث */
} XScreenSaverNotifyEvent;

الوصف

يوفر نظام النوافذ X دعمًا لتغيير الصورة على شاشة العرض بعد فترة غير نشاط قابلة للضبط من قبل المستخدم لتجنب حرق طبقة الفوسفور في أنبوب أشعة الكاثود. ومع ذلك، لا يتم توفير واجهات للمستخدم للتحكم في الصورة التي يتم رسمها. يسمح هذا الامتداد لعميل "حافظ الشاشة" خارجي باكتشاف متى سيتم عرض الصورة البديلة وتوفير الرسومات.

تتضمن تطبيقات خادم X الحالية عادةً شكلًا واحدًا على الأقل من صور "حافظ الشاشة". تاريخيًا، كان هذا نسخة من شعار X مرسومة على نمط الخلفية الجذرية. ومع ذلك، طلب العديد من المستخدمين آلية تسمح لهم بكتابة برامج حافظ الشاشة التي توفر إمكانيات مشابهة لتلك التي توفرها أنظمة النوافذ الأخرى. على وجه الخصوص، غالبًا ما يرغب هؤلاء المستخدمون في أن يكونوا قادرين على عرض شعارات الشركة، وتعليمات حول كيفية إعادة تنشيط الشاشة، وأدوات قفل الشاشة التلقائي. يوفر هذا الامتداد وسيلة لكتابة هذه العملاء.

افتراضات

يقوم هذا الامتداد بتصدير مفهوم نافذة حافظ شاشة خاصة يتم تعيينها فوق جميع النوافذ الأخرى على الشاشة. هذه النافذة لها سمة override-redirect مضبوطة بحيث لا تخضع لمعالجة من قبل مدير النوافذ. علاوة على ذلك، لا يتم إرجاع معرف X للنافذة أبدًا بواسطة طلبات QueryTree على النافذة الجذرية، لذا فهي غير مرئية عادةً للعملاء الآخرين.

XScreenSaverQueryExtension ترجع True إذا كان امتداد XScreenSaver متاحًا على الشاشة المعطاة. يجب على العميل استدعاء XScreenSaverQueryExtension قبل استدعاء أي وظيفة أخرى من XScreenSaver للتفاوض على إصدار بروتوكول متوافق؛ وإلا سيحصل العميل على سلوك غير محدد (قد يعمل XScreenSaver أو لا يعمل).

إذا كان الامتداد مدعومًا، يتم إرجاع رقم الحدث لأحداث ScreenSaverNotify في القيمة المشار إليها بواسطة event_base. نظرًا لعدم تعريف أي أخطاء إضافية بواسطة هذا الامتداد، فإن نتائج error_base غير محددة.

XScreenSaverQueryVersion ترجع True إذا نجح الطلب؛ يتم إرجاع قيم الإصدارات الرئيسية والثانوية للبروتوكول المدعومة بواسطة الخادم في major_version_return و minor_version_return.

XScreenSaverAllocInfo تخصص وتعيد هيكل XScreenSaverInfo لاستخدامه في استدعاءات XScreenSaverQueryInfo. يتم تهيئة جميع الحقول في الهيكل إلى الصفر. إذا لم تكن هناك ذاكرة كافية متاحة، يتم إرجاع NULL. يمكن تحرير نتائج هذا الروتين باستخدام XFree.

XScreenSaverQueryInfo ترجع معلومات حول الحالة الحالية لخادم الشاشة في saver_info ويتم إرجاع قيمة غير صفرية. إذا لم يكن الامتداد مدعومًا، فلن يتغير saver_info ويتم إرجاع 0.

يحدد الحقل state ما إذا كان حافظ الشاشة نشطًا حاليًا أم لا وكيف يجب تفسير قيمة til-or-since:

Off
الشاشة ليست قيد الحفظ حاليًا؛ يحدد til-or-since عدد المللي ثوانٍ حتى يتوقع تفعيل حافظ الشاشة.
On
الشاشة قيد الحفظ حاليًا؛ يحدد til-or-since عدد المللي ثوانٍ منذ تفعيل حافظ الشاشة.
Disabled
حافظ الشاشة معطل حاليًا؛ til-or-since هو صفر.

يحدد الحقل kind الآلية التي يتم استخدامها حاليًا أو التي كانت ستُستخدم لولا ذلك لو تم حفظ الشاشة:

Blanked
تم تعطيل إشارة الفيديو لشاشة العرض.
Internal
تم عرض صورة حافظ شاشة مدمجة خاصة بالخادم؛ لم يقم أي عميل بضبط سمات نافذة حافظ الشاشة أو كان لدى عميل آخر قبضة على الخادم عند تنشيط حافظ الشاشة.
External
تم تعيين نافذة حافظ الشاشة مع سمات تم ضبطها بواسطة عميل يستخدم طلب ScreenSaverSetAttributes.

يحدد الحقل idle عدد المللي ثوانٍ منذ آخر مدخل تم استلامه من المستخدم على أي من أجهزة الإدخال.
يحدد الحقل event-mask أي أحداث حافظ شاشة، إن وجدت، طلبها هذا العميل باستخدام ScreenSaverSelectInput.

XScreenSaverSelectInput يطلب إنشاء أحداث متعلقة بحافظ الشاشة لهذا العميل. إذا لم يتم تعيين أي بتات في event-mask، فلن يتم إنشاء أي أحداث. بخلاف ذلك، يمكن تعيين أي مجموعة من البتات التالية:

ScreenSaverNotify
إذا تم تعيين هذا البت، يتم إنشاء أحداث ScreenSaverNotify كلما تم تنشيط حافظ الشاشة أو إلغاء تنشيطه.
ScreenSaverCycle
إذا تم تعيين هذا البت، يتم إنشاء أحداث ScreenSaverNotify كلما مرت فترة دورة حافظ الشاشة.

XScreenSaverSetAttributes يضبط السمات التي سيتم استخدامها في المرة التالية التي يتم فيها تنشيط حافظ الشاشة الخارجي. إذا كان لدى عميل آخر السمات مضبوطة حاليًا، يتم إنشاء خطأ BadAccess ويتم تجاهل الطلب.
بخلاف ذلك، يتم فحص سمات النافذة المحددة كما لو تم استخدامها في طلب CreateWindow أساسي يكون والده هو الجذر. يتم تجاهل حقل override-redirect حيث يتم تعيينه ضمنيًا على True. إذا أدت سمات النافذة إلى خطأ وفقًا لقواعد CreateWindow، يتم تجاهل الطلب.
بخلاف ذلك، يتم تخزين السمات وستدخل حيز التنفيذ عند التنشيط التالي الذي يحدث عندما لا يكون الخادم محتكرًا بواسطة عميل آخر. قد يتم تحرير أي موارد محددة لسمتي background-pixmap أو cursor على الفور.
