xset(1)

الحزمة: xorg-xset

التراخيص: custom

XSET(1) دليل الأوامر العام XSET(1)

الاسم

xset - أداة تفضيلات المستخدم لـ X

الملخص

xset [-display display]
[-b] [b {on|off}] [b [volume [pitch [duration]]]]
[-bc] [bc]
[-c] [c {on|off}] [c [volume]]
[+dpms] [-dpms]
[dpms standby [ suspend [ off]]]
[dpms force {standby|suspend|off|on}]
[fp=pathlist] [-fp=pathlist] [+fp=pathlist] [fp-pathlist] [fp+pathlist]
[fp default] [fp rehash]
[-led [integer|named indicator]] [led [integer|named indicator]]
[led {on|off}]
[mouse [accel_mult[/accel_div] [threshold]]] [mouse default]
[p pixel color]
[-r [keycode]] [r [keycode]] [r {on|off}] [r rate delay [rate]]
[s [length [period]]] [s {blank|noblank}]
[s {expose|noexpose}] [s {on|off}] [s default] [s activate] [s reset]
[q]
[-version]

الوصف

يستخدم هذا البرنامج لضبط خيارات التفضيل المختلفة للمستخدم للعرض.

الخيارات

-display display
يحدد هذا الخيار الخادم المراد استخدامه؛ انظر X(7).
b
يتحكم الخيار b في مستوى الصوت، تردد النغمة، ومدة صوت الجرس. يقبل هذا الخيار ما يصل إلى ثلاثة معاملات رقمية، أو شرطة سابقة (-)، أو علامة 'on/off'. إذا لم يتم تقديم أي معاملات، أو تم استخدام علامة 'on'، فسيتم استخدام الإعدادات الافتراضية للنظام. إذا تم تقديم الشرطة أو علامة 'off'، فسيتم إيقاف تشغيل الجرس. إذا تم تقديم معامل رقمي واحد فقط، فسيتم ضبط مستوى صوت الجرس إلى تلك القيمة، كنسبة مئوية من الحد الأقصى. وبالمثل، يحدد المعامل الرقمي الثاني تردد الجرس، بالهرتز، ويحدد المعامل الرقمي الثالث المدة بالمللي ثانية. لاحظ أن ليس كل الأجهزة يمكنها تغيير خصائص الجرس. سيقوم خادم X بتعيين خصائص الجرس بأقرب ما يمكن لمواصفات المستخدم.
bc
يتحكم الخيار bc في وضع توافق الأخطاء (bug compatibility) في الخادم، إذا كان ذلك ممكناً؛ الشرطة السابقة (-) تعطّل الوضع، وإلا يتم تمكين الوضع. تمر العديد من العملاء قبل الإصدار R4 بقيم غير صالحة في بعض طلبات البروتوكول، ولم تقم الخوادم قبل الإصدار R4 بإنشاء أخطاء بشكل صحيح في هذه الحالات. مثل هؤلاء العملاء، عند تشغيلهم على خادم R4، سينتهون بشكل غير طبيعي أو يفشلون بطريقة أخرى في العمل بشكل صحيح. يقوم وضع توافق الأخطاء بإعادة تقديم أخطاء معينة بشكل صريح في خادم X، بحيث لا يزال بإمكان تشغيل العديد من هؤلاء العملاء. يجب استخدام هذا الوضع بحذر؛ يجب إجراء تطوير التطبيقات الجديدة مع تعطيل هذا الوضع. يجب أن يدعم الخادم امتداد بروتوكول MIT-SUNDRY-NONSTANDARD لكي يعمل هذا الخيار.
c
يتحكم الخيار c في نقر المفتاح (key click). يمكن لهذا الخيار أن يأخذ قيمة اختيارية، أو شرطة سابقة (-)، أو علامة 'on/off'. إذا لم يتم تقديم أي معامل أو تم استخدام علامة 'on'، فسيتم استخدام الإعدادات الافتراضية للنظام. إذا تم استخدام علامة الشرطة أو 'off'، فسيتم تعطيل نقر المفتاح. إذا تم تقديم قيمة من 0 إلى 100، فسيتم استخدامها للإشارة إلى مستوى الصوت، كنسبة مئوية من الحد الأقصى. سيقوم خادم X بضبط مستوى الصوت إلى أقرب قيمة يمكن للأجهزة دعمها.
-dpms
يعطل الخيار -dpms ميزات إشارات إدارة طاقة العرض (DPMS).
+dpms
يمكّن الخيار +dpms ميزات إشارات إدارة طاقة العرض (DPMS).
dpms flags...
يسمح الخيار dpms بضبط معلمات إشارات إدارة طاقة العرض (DPMS). يمكن للخيار أن يأخذ ما يصل إلى ثلاث قيم رقمية، أو علامة `force` متبوعة بحالة DPMS. تقوم علامات `force` بإجبار الخادم على التبديل فوراً إلى حالة DPMS المحددة. يمكن أن تكون حالة DPMS إحدى القيم `standby` أو `suspend` أو `off` أو `on`. عندما يتم تقديم قيم رقمية، فإنها تضبط فترة عدم النشاط (بالثواني) قبل تنشيط الأوضاع الثلاثة. القيمة الأولى المقدمة هي لوضع `standby`، والثانية لوضع `suspend`، والثالثة لوضع `off`. ضبط هذه القيم يمكّن ميزات DPMS ضمنياً. القيمة صفر تعطل وضعًا معينًا.
fp= path,...
يضبط fp= مسار الخطوط إلى الإدخالات المقدمة في المعامل path. يتم تفسير الإدخالات بواسطة الخادم، وليس بواسطة العميل. عادة ما تكون أسماء أدلة أو أسماء خوادم خطوط، ولكن التفسير يعتمد على الخادم.
fp default
يؤدي المعامل default إلى إعادة تعيين مسار الخطوط إلى الإعداد الافتراضي للخادم.
fp rehash
يعيد المعامل rehash تعيين مسار الخطوط إلى قيمته الحالية، مما يؤدي إلى إعادة قراءة الخادم لقواعد بيانات الخطوط في مسار الخطوط الحالي. يستخدم هذا بشكل عام فقط عند إضافة خطوط جديدة إلى دليل خطوط (بعد تشغيل mkfontdir لإعادة إنشاء قاعدة بيانات الخطوط).
-fp or fp-
تزيل الخيارات -fp و fp- عناصر من مسار الخطوط الحالي. يجب أن تتبعها قائمة مفصولة بفواصل من الإدخالات.
+fp or fp+
تضيف هذه الخيارات +fp و fp+ عناصر إلى بداية مسار الخطوط الحالي وإلى نهايته، على التوالي. يجب أن تتبعها قائمة مفصولة بفواصل من الإدخالات.
led
يتحكم الخيار led في مصابيح LED الخاصة بلوحة المفاتيح. يتحكم هذا في تشغيل أو إيقاف تشغيل مصباح LED واحد أو كل المصابيح. يقبل عددًا صحيحًا اختياريًا، أو شرطة سابقة (-)، أو علامة 'on/off'. إذا لم يتم تقديم أي معامل أو تم استخدام علامة 'on'، فسيتم تشغيل جميع مصابيح LED. إذا تم استخدام شرطة سابقة أو علامة 'off'، فسيتم إيقاف تشغيل جميع مصابيح LED. إذا تم تقديم قيمة بين 1 و 32، فسيتم تشغيل أو إيقاف تشغيل مصباح LED هذا اعتمادًا على وجود شرطة سابقة. ``xset led 3'' سيشغل مصباح LED رقم 3. ``xset -led 3'' سيقوم بإيقاف تشغيله. قد تشير قيم مصابيح LED المحددة إلى مصابيح LED مختلفة على أجهزة مختلفة. إذا كان خادم X يدعم امتداد XKEYBOARD (XKB)، يمكن الإشارة إلى مصابيح LED باسم مؤشر XKB عن طريق تحديد الكلمة المفتاحية `named` واسم المؤشر. على سبيل المثال، لتشغيل مصباح LED Scroll Lock:
xset led named "Scroll Lock"
mouse
يتحكم الخيار m في معلمات الماوس؛ يمكن اختصاره إلى 'm'. بالطبع، ينطبق هذا على معظم أجهزة التأشير، وليس فقط الفئران. المعلمات الخاصة بجهاز التأشير هي `acceleration` (التسارع) و `threshold` (العتبة). يمكن تحديد التسارع كعدد صحيح، أو ككسر بسيط. العتبة هي مجرد عدد صحيح. يتم تطبيق الإعداد على جميع أجهزة التأشير المتصلة. يجب استخدام xinput(1) إذا كنت بحاجة إلى إعدادات خاصة بالجهاز.

بشكل افتراضي، سيتحرك المؤشر (التمثيل على الشاشة لجهاز التأشير) أسرع بـ `acceleration` مرات عندما يسافر الجهاز أكثر من `threshold` ميكي (أي بكسلات افتراضية) في 10 مللي ثانية، بما في ذلك نطاق انتقالي صغير. بهذه الطريقة، يمكن استخدام جهاز التأشير للمحاذاة الدقيقة عند تحريكه ببطء، ومع ذلك يمكن ضبطه للسفر عبر الشاشة بحركة سريعة للمعصم عند الرغبة. يمكن حذف واحد أو كلا المعلمتين للخيار m، ولكن إذا تم تقديم واحدة فقط، فسيتم تفسيرها على أنها التسارع. إذا لم يتم تقديم أي معاملات أو تم استخدام العلامة 'default'، فسيتم تعيين الإعدادات الافتراضية للنظام.

إذا تم تقديم المعامل `threshold` وكان 0، فسيتم استخدام المعامل `acceleration` في الأس لصيغة طبيعية ومستمرة أكثر، مما يوفر تحكمًا دقيقًا للحركة البطيئة ولكن نطاقًا واسعًا للحركة السريعة، وانتقالًا تدريجيًا للحركات بينهما. القيمة الموصى بها لـ `acceleration` في هذه الحالة هي 3/2 إلى 3، ولكنها ليست محصورة في هذا النطاق.

في خادم X.org X 1.6 وما فوق، يرتبط السلوك الموضح حتى الآن بالملف الشخصي الافتراضي. توجد ملفات شخصية أخرى (أي وظائف تحدد تسارع المؤشر من سرعة الجهاز) وإعدادات إضافية، لذا قد لا ينطبق الوصف أعلاه على الحالات غير الافتراضية. في خادم X.org 1.7، هذه متاحة كخصائص لجهاز الإدخال (انظر xinput).

p
يتحكم الخيار p في قيم ألوان البكسل.

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

xset(1) manual page

NAME

xset — user preference utility for X server

SYNOPSIS

xset [ options ]

DESCRIPTION

The xset utility is used to interact with the X server to set user preferences such as the screen saver control, font path (though this is deprecated), and other miscellaneous inputs and outputs. Settings made with xset are typically reset to their default values when you log out.

The utility is run with the desired option from the command line.

OPTIONS

c
The c option controls the bell characteristics. Invoking with "-c", or "c off", will disable the bell, whereas "c", or "c on" will enable the bell. Following the "-c" or "c" option with an integer keycode between 0 and 255 will disable or enable the bell on that key respectively, but only if it makes sense for the particular keycode. Keycodes below 8 are not typically valid for this command.
dp
The dp option is used to control the font path. The following sub-options are available:
-L
Reset the font path to the default value.
-f
Set the font path to the user specified path. The path is a comma-separated list of directories. Deprecated.
-fp
Set the font path to the user specified path. The path is a comma-separated list of directories.
-p
Print the current font path.

Because of the deprecation of font path manipulation, use of xset dp is not recommended.

fp
The fp option controls the font path. This option is deprecated and should not be used. See dp for more information.
b
The b option controls the keyboard bell volume and pitch.
-s
Set the bell volume. The volume is a value between 0 and 100. Example: "xset b 75".
-p
Set the bell pitch. The pitch is a value between 0 and 100. Example: "xset b 100 0".
-d
Set the bell duration. The duration is a value between 0 and 100. Example: "xset b 100 0 50".
-n
Disable the keyboard bell.

If no arguments are given, the current settings are printed.

led
The led option controls the keyboard LEDs.
-n
Disable the keyboard LEDs. The LEDs will be turned off.
-i
Enable the keyboard LEDs. The LEDs will be turned on.

Following the "led" or "-led" option with an integer keycode between 0 and 255 will disable or enable the LED on that key respectively, but only if it makes sense for the particular keycode. Keycodes below 8 are not typically valid for this command.

m
The m option controls the mouse parameters.
-r
Set the mouse acceleration. The acceleration is a value between -1 and 1. A value of 0 means no acceleration. Positive values increase acceleration, negative values decrease it.
-s
Set the mouse sensitivity. The sensitivity is a value between 1 and 10. Higher values mean higher sensitivity.

If no arguments are given, the current settings are printed.

r
The r option controls the autorepeat. Invoking with "-r", or "r off", will disable autorepeat, whereas "r", or "r on" will enable autorepeat. Following the "-r" or "r" option with an integer keycode between 0 and 255 will disable or enable autorepeat on that key respectively, but only if it makes sense for the particular keycode. Keycodes below 8 are not typically valid for this command. Example: "xset -r 10" will disable autorepeat for the "1" key on the top row of an IBM PC keyboard.

If the server supports the XFree86-Misc extension, or the XKB extension, then a parameter of 'rate' is accepted and should be followed by zero, one or two numeric values. The first specifies the delay before autorepeat starts and the second specifies the repeat rate. In the case that the server supports the XKB extension, the delay is the number of milliseconds before autorepeat starts, and the rate is the number of repeats per second. If the rate or delay is not given, it will be set to the default value.

s
The s option lets you set the screen saver parameters. This option accepts up to two numerical parameters, a 'blank/noblank' flag, an 'expose/noexpose' flag, an 'on/off' flag, an 'activate/reset' flag, or the 'default' flag. If no parameters or the 'default' flag is used, the system will be set to its default screen saver characteristics. The 'on/off' flags simply turn the screen saver functions on or off. The 'activate' flag forces activation of screen saver even if the screen saver had been turned off. The 'reset' flag forces deactivation of screen saver if it is active. The 'blank' flag sets the preference to blank the video (if the hardware can do so) rather than display a background pattern, while 'noblank' sets the preference to display a pattern rather than blank the video. The 'expose' flag sets the preference to allow window exposures (the server can freely discard window contents), while 'noexpose' sets the preference to disable screen saver unless the server can regenerate the screens without causing exposure events. The length and period parameters for the screen saver function determines how long the server must be inactive for screen saving to activate, and the period to change the background pattern to avoid burn in. The arguments are specified in seconds. If only one numerical parameter is given, it will be used for the length.
q
The q option gives you information on the current settings.
-version
The -version option prints the program version and exits without doing anything else.

These settings will be reset to default values when you log out.

Note that not all X implementations are guaranteed to honor all of these options.
