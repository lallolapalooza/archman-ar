NAME

XSetWMHints - set window manager hints

SYNTAX

    Bool XSetWMHints(
        Display *display,
        Window w,
        XWMHints *hints
    );

ARGUMENTS

  • display

    Specifies the connection to the X server.

  • w

    Specifies the window for which to set hints.

  • hints

    Specifies the hints to be set.

DESCRIPTION

The XSetWMHints function sets the window manager hints for the specified window. Hints are a way for applications to communicate information to the window manager about how they should be handled.

The hints are provided in the hints argument, which is a pointer to an XWMHints structure. This structure contains various fields that can be set to provide information to the window manager. The specific fields that are relevant depend on the particular hint being set.

PROPERTIES

The XSetWMHints function sets the _MOTIF_WM_HINTS property on the specified window. This property is used by Motif-compliant window managers to retrieve window manager hints.

STRUCTURES

The XWMHints structure is defined as follows:

    typedef struct {
        long flags;
        int  initial_state;
        Pixmap icon;
        int  icon_x, icon_y;
        int  icon_width, icon_height;
        Pixmap icon_mask;
        XID  input_hint;
        /* ... other fields ... */
    } XWMHints;

The flags field is a bitmask that indicates which of the other fields in the structure are valid. The following flags are defined:

  • StateHint: Indicates that the initial_state field is valid.
  • IconPixmapHint: Indicates that the icon field is valid.
  • IconPositionHint: Indicates that the icon_x and icon_y fields are valid.
  • IconSizeHint: Indicates that the icon_width and icon_height fields are valid.
  • InputHint: Indicates that the input_hint field is valid.

The initial_state field specifies the initial state of the window. The following values are defined:

  • NormalState: The window should be displayed in its normal state.
  • IconicState: The window should be displayed as an icon.
  • ZoomState: The window should be zoomed.

DIAGNOSTICS

If the XSetWMHints function fails, it returns False. Otherwise, it returns True.
