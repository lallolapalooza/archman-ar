XSelectionClearEvent(3)

الحزمة: libx11

التراخيص: MIT AND X11

XSelectionClearEvent(3) وظائف XLIB XSelectionClearEvent(3)

الاسم

XSelectionClearEvent - هيكل حدث SelectionClear

الهياكل

الهيكل الخاص بأحداث SelectionClear يحتوي على:

typedef struct {
        int type;       /* SelectionClear */
        unsigned long serial;   /* # of last request processed by server */
        Bool send_event;        /* true if this came from a SendEvent request */
        Display *display;       /* Display the event was read from */
        Window window;
        Atom selection;
        Time time;
} XSelectionClearEvent;

عندما تستقبل هذا الحدث، يتم تعيين أعضاء الهيكل على النحو التالي.

يتم تعيين عضو النوع (type) إلى ثابت اسم الحدث الذي يحدده بشكل فريد. على سبيل المثال، عندما يبلغ خادم X عن حدث GraphicsExpose لتطبيق عميل، فإنه يرسل هيكل XGraphicsExposeEvent مع تعيين عضو النوع إلى GraphicsExpose. يتم تعيين عضو العرض (display) إلى مؤشر إلى العرض الذي تمت قراءة الحدث عليه. يتم تعيين عضو إرسال_الحدث (send_event) إلى True إذا جاء الحدث من طلب بروتوكول SendEvent. يتم تعيين عضو المسلسل (serial) من الرقم التسلسلي المبلغ عنه في البروتوكول ولكن تم توسيعه من أقل 16 بت إلى قيمة كاملة 32 بت. يتم تعيين عضو النافذة (window) إلى النافذة الأكثر فائدة لموزعي الأدوات.

يتم تعيين عضو التحديد (selection) إلى ذرة التحديد. يتم تعيين عضو الوقت (time) إلى آخر وقت تغيير تم تسجيله للتحديد. عضو النافذة (window) هو النافذة التي حددها المالك الحالي (المالك الذي يفقد التحديد) في استدعاء XSetSelectionOwner الخاص به.
