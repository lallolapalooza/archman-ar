XSetScreenSaver(3)

الحزمة: libx11

التراخيص: MIT AND X11

XSetScreenSaver(3) وظائف XLIB XSetScreenSaver(3)

الاسم

XSetScreenSaver، XForceScreenSaver، XActivateScreenSaver، XResetScreenSaver، XGetScreenSaver - معالجة واقي الشاشة

الصيغة

int XSetScreenSaver(Display *display, int timeout, int interval, int prefer_blanking, int allow_exposures);

int XForceScreenSaver(Display *display, int mode);

int XActivateScreenSaver(Display *display);

int XResetScreenSaver(Display *display);

int XGetScreenSaver(Display *display, int *timeout_return, int *interval_return, int *prefer_blanking_return, int *allow_exposures_return);

المعاملات

allow_exposures
يحدد قيم التحكم في توفير الشاشة. يمكنك تمرير DontAllowExposures، AllowExposures، أو DefaultExposures.
allow_exposures_return
يعيد قيمة التحكم الحالية في توفير الشاشة (DontAllowExposures، AllowExposures، أو DefaultExposures).
display
يحدد الاتصال بخادم X.
interval
يحدد الفاصل الزمني، بالثواني، بين تغييرات واقي الشاشة.
interval_return
يعيد الفاصل الزمني بين استدعاءات واقي الشاشة.
mode
يحدد الوضع الذي سيتم تطبيقه. يمكنك تمرير ScreenSaverActive أو ScreenSaverReset.
prefer_blanking
يحدد كيفية تمكين تعتيم الشاشة. يمكنك تمرير DontPreferBlanking، PreferBlanking، أو DefaultBlanking.
prefer_blanking_return
يعيد الأفضلية الحالية لتعتيم الشاشة (DontPreferBlanking، PreferBlanking، أو DefaultBlanking).
timeout
يحدد المهلة، بالثواني، حتى يتم تشغيل واقي الشاشة.
timeout_return
يعيد المهلة، بالثواني، حتى يتم تشغيل واقي الشاشة.

الوصف

يتم تحديد المهلة والفاصل الزمني بالثواني. القيمة صفر للمهلة تعطل واقي الشاشة (لكن واقي الشاشة النشط لا يتم تعطيله)، والقيمة -1 تستعيد الوضع الافتراضي. القيم السالبة الأخرى تولد خطأ BadValue. إذا كانت قيمة المهلة غير صفرية، فإن XSetScreenSaver تقوم بتمكين واقي الشاشة. يتم تحديد كلتا القيمتين في نطاق عدد صحيح موقع 16 بت بواسطة بروتوكول السلك، على الرغم من النموذج الأولي C. إذا لم يتم إنشاء أي إدخال من الأجهزة (لوحة المفاتيح، الفأرة، وما إلى ذلك) لعدد ثواني المهلة المحدد بمجرد تمكين واقي الشاشة، يتم تفعيل واقي الشاشة.

لكل شاشة، إذا كان التعتيم مفضلاً وكانت الأجهزة تدعم تعتيم الفيديو، تصبح الشاشة فارغة ببساطة. بخلاف ذلك، إذا تم السماح بالتعريضات أو يمكن إعادة إنشاء الشاشة دون إرسال أحداث Expose إلى العملاء، يتم تعبئة الشاشة بنمط خلفية النافذة الجذر مع إعادة تعيين المصدر بشكل عشوائي كل ثانية فاصل زمني. بخلاف ذلك، لا تتغير حالات الشاشات، ولا يتم تفعيل واقي الشاشة. يتم تعطيل واقي الشاشة، ويتم استعادة جميع حالات الشاشة عند الإدخال التالي من لوحة المفاتيح أو المؤشر أو عند استدعاء XForceScreenSaver التالي مع الوضع ScreenSaverReset.

إذا كانت طريقة واقي الشاشة الخاصة بالخادم تدعم التغيير الدوري، فإن معامل الفاصل الزمني يعمل كتلميح حول مدة فترة التغيير، والقيمة صفر تلمح إلى عدم إجراء أي تغيير دوري. تشمل أمثلة طرق تغيير الشاشة خلط خريطة الألوان بشكل دوري، أو تحريك صورة رمزية حول الشاشة بشكل دوري، أو تعبئة الشاشة بنمط خلفية النافذة الجذر، مع إعادة تعيين المصدر بشكل عشوائي دوريًا.

يمكن لـ XSetScreenSaver توليد خطأ BadValue.

إذا كان الوضع المحدد هو ScreenSaverActive وكان واقي الشاشة معطلاً حاليًا، فإن XForceScreenSaver يقوم بتفعيل واقي الشاشة حتى لو تم تعطيل واقي الشاشة بمهلة صفر. إذا كان الوضع المحدد هو ScreenSaverReset وكان واقي الشاشة ممكّنًا حاليًا، فإن XForceScreenSaver يقوم بتعطيل واقي الشاشة إذا تم تفعيله، ويتم إعادة تعيين مؤقت التفعيل إلى حالته الأولية (كما لو تم استلام إدخال الجهاز).

يمكن لـ XForceScreenSaver توليد خطأ BadValue.

تقوم الدالة XActivateScreenSaver بتفعيل واقي الشاشة.

تقوم الدالة XResetScreenSaver بإعادة تعيين واقي الشاشة.

تقوم الدالة XGetScreenSaver بالحصول على قيم واقي الشاشة الحالية.

التشخيصات

BadValue
تكون قيمة رقمية ما خارج نطاق القيم التي يقبلها الطلب. ما لم يتم تحديد نطاق محدد لمعامل، يتم قبول النطاق الكامل الذي تحدده نوع المعامل. يمكن لأي معامل محدد كمجموعة من البدائل توليد هذا الخطأ.
