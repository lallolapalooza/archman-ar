XAllocSizeHints(3) وظائف XLIB XAllocSizeHints(3)

الاسم

XAllocSizeHints, XSetWMNormalHints, XGetWMNormalHints, XSetWMSizeHints, XGetWMSizeHints, XSizeHints - تخصيص بنية تلميحات الحجم وتعيين أو قراءة خاصية WM_NORMAL_HINTS لنافذة

الصيغة

XSizeHints *XAllocSizeHints(void);

void XSetWMNormalHints(Display *display, Window w, XSizeHints *hints);

Status XGetWMNormalHints(Display *display, Window w, XSizeHints *hints_return, long *supplied_return);

void XSetWMSizeHints(Display *display, Window w, XSizeHints *hints, Atom property);

Status XGetWMSizeHints(Display *display, Window w, XSizeHints *hints_return, long *supplied_return, Atom property);

الوصف

تقوم الدالة XAllocSizeHints بتخصيص وإعادة مؤشر إلى بنية XSizeHints. لاحظ أن جميع الحقول في بنية XSizeHints يتم تعيينها مبدئيًا إلى صفر. إذا لم تكن هناك ذاكرة كافية متاحة، فإن XAllocSizeHints تعيد NULL. لتحرير الذاكرة المخصصة لهذه البنية، استخدم XFree.

تقوم الدالة XSetWMNormalHints باستبدال تلميحات الحجم للخاصية WM_NORMAL_HINTS على النافذة المحددة. إذا كانت الخاصية غير موجودة بالفعل، فإن XSetWMNormalHints تقوم بتعيين تلميحات الحجم للخاصية WM_NORMAL_HINTS على النافذة المحددة. يتم تخزين الخاصية بنوع WM_SIZE_HINTS وبتنسيق 32.

يمكن لـ XSetWMNormalHints إنشاء أخطاء BadAlloc و BadWindow.

تقوم الدالة XGetWMNormalHints بإعادة تلميحات الحجم المخزنة في الخاصية WM_NORMAL_HINTS على النافذة المحددة. إذا كانت الخاصية من نوع WM_SIZE_HINTS، بتنسيق 32، وطويلة بما يكفي لاحتواء بنية تلميحات حجم قديمة (قبل ICCCM) أو جديدة، فإن XGetWMNormalHints تقوم بتعيين الحقول المختلفة لبنية XSizeHints، وتعين الوسيط supplied_return إلى قائمة الحقول التي قدمها المستخدم (سواء احتوت على قيم محددة أم لا)، وتعيد حالة غير صفرية. بخلاف ذلك، تعيد حالة صفرية.

إذا أعادت XGetWMNormalHints بنجاح وتم قراءة خاصية تلميحات حجم قبل ICCCM، فإن الوسيط supplied_return سيحتوي على البتات التالية:

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

إذا كانت الخاصية طويلة بما يكفي لاحتواء حجم الأساس وحقول ثقل النافذة أيضًا، فإن الوسيط supplied_return سيحتوي أيضًا على البتات التالية:

PBaseSize|PWinGravity

يمكن لـ XGetWMNormalHints إنشاء خطأ PN BadWindow.

تقوم الدالة XSetWMSizeHints باستبدال تلميحات الحجم للخاصية المحددة على النافذة المسماة. إذا كانت الخاصية المحددة غير موجودة بالفعل، فإن XSetWMSizeHints تقوم بتعيين تلميحات الحجم للخاصية المحددة على النافذة المسماة. يتم تخزين الخاصية بنوع WM_SIZE_HINTS وبتنسيق 32. لتعيين تلميحات الحجم العادية لنافذة، يمكنك استخدام الدالة XSetWMNormalHints.

يمكن لـ XSetWMSizeHints إنشاء أخطاء BadAlloc و BadAtom و BadWindow.

تقوم الدالة XGetWMSizeHints بإعادة تلميحات الحجم المخزنة في الخاصية المحددة على النافذة المسماة. إذا كانت الخاصية من نوع WM_SIZE_HINTS، بتنسيق 32، وطويلة بما يكفي لاحتواء بنية تلميحات حجم قديمة (قبل ICCCM) أو جديدة، فإن XGetWMSizeHints تقوم بتعيين الحقول المختلفة لبنية XSizeHints، وتعين الوسيط supplied_return إلى قائمة الحقول التي قدمها المستخدم (سواء احتوت على قيم محددة أم لا)، وتعيد حالة غير صفرية. بخلاف ذلك، تعيد حالة صفرية. للحصول على تلميحات الحجم العادية لنافذة، يمكنك استخدام الدالة XGetWMNormalHints.

إذا أعادت XGetWMSizeHints بنجاح وتم قراءة خاصية تلميحات حجم قبل ICCCM، فإن الوسيط supplied_return سيحتوي على البتات التالية:

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

إذا كانت الخاصية طويلة بما يكفي لاحتواء حجم الأساس وحقول ثقل النافذة أيضًا، فإن الوسيط supplied_return سيحتوي أيضًا على البتات التالية:

PBaseSize|PWinGravity

يمكن لـ XGetWMSizeHints إنشاء أخطاء BadAtom و BadWindow.

الخصائص

WM_NORMAL_HINTS
تلميحات الحجم لنافذة في حالتها العادية. النوع C لهذه الخاصية هو XSizeHints.

البنى

تحتوي بنية XSizeHints على:

/* بتات قناع تلميحات الحجم */

#define USPosition (1L << 0) /* موقع x، y محدد من قبل المستخدم */
#define USSize (1L << 1) /* عرض height محدد من قبل المستخدم */
#define PPosition (1L << 2) /* موقع محدد من قبل البرنامج */
#define PSize (1L << 3) /* حجم محدد من قبل البرنامج */
#define PMinSize (1L << 4) /* الحد الأدنى للحجم محدد من قبل البرنامج */
#define PMaxSize (1L << 5) /* الحد الأقصى للحجم محدد من قبل البرنامج */
#define PResizeInc (1L << 6) /* زيادات تغيير الحجم محددة من قبل البرنامج */
#define PAspect (1L << 7) /* نسب العرض إلى الارتفاع الدنيا والقصوى المحددة من قبل البرنامج */
#define PBaseSize (1L << 8)
#define PWinGravity (1L << 9)
#define PAllHints (PPosition| PSize| PMinSize| PMaxSize| PResizeInc| PAspect) 
/* القيم */
typedef struct {
        long flags;     /* علامات تحدد الحقول المحددة في هذه البنية */
        int x, y;       /* مهمل */
        int width, height;      /* مهمل */
        int min_width, min_height;
        int max_width, max_height;
        int width_inc, height_inc;
        struct {
               int x;   /* البسط */
               int y;   /* المقام */
        } min_aspect, max_aspect;
        int base_width, base_height;
        int win_gravity;
        /* قد يتم توسيع هذه البنية في المستقبل */
} XSizeHints;

تم إهمال الأعضاء x و y و width و height وهي موجودة فقط لأسباب التوافق. تحدد الأعضاء min_width و min_height الحد الأدنى لحجم النافذة الذي لا يزال يسمح للتطبيق بأن يكون مفيدًا. تحدد الأعضاء max_width و max_height الحد الأقصى لحجم النافذة. تحدد الأعضاء width_inc و height_inc متتالية حسابية للأحجام (من الحد الأدنى إلى الحد الأقصى) التي تفضل النافذة تغيير حجمها إليها. يتم التعبير عن min_aspect و max_aspect كنسب x و y، وتسمح للتطبيق بتحديد نطاق نسب العرض إلى الارتفاع التي يفضلها. تحدد الأعضاء base_width و base_height الحجم المطلوب للنافذة. سيقوم مدير النوافذ بتفسير موضع النافذة وعرض حدودها لتحديد موضع نقطة المستطيل الخارجي للنافذة الإجمالية المحددة بواسطة عضو win_gravity. يشمل المستطيل الخارجي للنافذة أي حدود أو زخارف يوفرها مدير النوافذ. بمعنى آخر، إذا قرر مدير النوافذ وضع النافذة حيث يتم وضع الوا

XSetWMNormalHints(3) — libX11 — Arch Linux

NAME

XSetWMNormalHints — set window manager normal hints

SYNTAX

void XSetWMNormalHints(Display *display, Window w,
        XWMHints *hints);

ARGUMENTS

display
Specifies the connection to the X server.
w
Specifies the window.
hints
Specifies the hints.

DESCRIPTION

The function XSetWMNormalHints sets the MWM hints for the specified window w.

The hints argument is a pointer to an XWMHints structure, which contains information about the window's size, position, and other attributes.

The XWMHints structure is defined as follows:

PROPERTIES

This function sets the WM_NORMAL_HINTS property on the window.

STRUCTURES

The XWMHints structure contains the following fields:

flags
Indicates which fields in the structure are set. The following bits are defined:
InputHint
Set if input is valid.
StateHint
Set if initial_state is valid.
IconPixmapHint
Set if icon_pixmap is valid.
IconWindowHint
Set if icon_window is valid.
IconPositionHint
Set if icon_x and icon_y are valid.
GeometryHint
Set if x, y, width, height, min_width, min_height, max_width, max_height, and width_inc, height_inc are valid.
TransientHint
Set if transient_for is valid.
WindowGroupHint
Set if window_group is valid.
input
Boolean indicating whether the window should receive keyboard input.
initial_state
The initial state of the window. Can be NormalState, IconicState, or ZoomState.
icon_pixmap
A pixmap to be used for the window's icon.
icon_window
A window to be used for the window's icon.
icon_x
icon_y
The x and y coordinates for the icon's position.
x
y
The x and y coordinates for the window's position.
width
height
The width and height of the window.
min_width
min_height
The minimum width and height of the window.
max_width
max_height
The maximum width and height of the window.
width_inc
height_inc
The increment for width and height. This can be used for implementing resizable windows with grid-based geometry.
min_aspect
max_aspect
Minimum and maximum aspect ratios. The aspect ratio is defined as height/width.
transient_for
A window that this window is transient for. This is typically used for dialog boxes and other temporary windows.
window_group
A window that this window belongs to. This is used to group related windows together, such as all the windows associated with a single application.

Note that use of the PAllHints macro is highly discouraged.

DIAGNOSTICS

BadAlloc
The server failed to allocate the requested resource or server memory.
BadAtom
A value for an Atom argument does not name a defined Atom.
BadWindow
A value for a Window argument does not name a defined Window.
