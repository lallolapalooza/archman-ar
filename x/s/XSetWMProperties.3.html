XSetWMProperties(3)

الحزمة: libx11

التراخيص: MIT AND X11

NAME

XSetWMProperties - set window manager properties

SYNTAX 

/* In Xutil/icccm.h, or often included via Xlib.h */
#include <X11/Xutil.h>

Bool
XSetWMProperties(Display *display,
                    Window w,
                    XTextProperty *name,
                    XTextProperty *icon_name,
                    char **argv,
                    int argc,
                    XWMHints *wmHints,
                    XClassHint *classHints,
                    XSizeHints *sizeHints);

ARGUMENTS

display
Specifies the connection to the X server.
w
Specifies the window.
name
Specifies the window's name property.
icon_name
Specifies the window's icon name property.
argv
Specifies the command line arguments that started the application.
argc
Specifies the number of command line arguments.
wmHints
Specifies the window manager hints.
classHints
Specifies the window's class hints.
sizeHints
Specifies the window's size hints.

DESCRIPTION

The function XSetWMProperties sets several properties on the specified window w that are used by the window manager to manage the window. These properties include:

  • WM_NAME
  • WM_ICON_NAME
  • WM_COMMAND
  • WM_HINTS
  • WM_CLASS
  • WM_NORMAL_HINTS

The arguments name, icon_name, wmHints, classHints, and sizeHints can be NULL if the corresponding properties are not to be set.

The argv and argc arguments specify the command line arguments that were used to start the application. This information is used by the window manager to restart the application.

The XSetWMProperties function returns True if the properties were successfully set, and False otherwise.

PROPERTIES

The following properties are set by this function:

WM_NAME
The window's name. This is set from the name argument, which should be an XTextProperty structure. Typically, this is created using XStringListToTextProperty or XTextListToTextProperty.
WM_ICON_NAME
The window's icon name. This is set from the icon_name argument, which should be an XTextProperty structure. Typically, this is created using XStringListToTextProperty or XTextListToTextProperty.
WM_COMMAND
The command line arguments used to start the application. This is set from the argv and argc arguments.
WM_HINTS
Window manager hints. This is set from the wmHints argument, which should be an XWMHints structure. This structure provides information to the window manager about how the window should be managed, such as whether it is a normal window, a dialog, or an input-only window, and whether it can be iconified.
WM_CLASS
The window's class. This is set from the classHints argument, which should be an XClassHint structure. This structure provides the instance name and the class name of the window, which can be used by the window manager to group windows or to apply specific decorations.
WM_NORMAL_HINTS
Normal window hints. This is set from the sizeHints argument, which should be an XSizeHints structure. This structure provides information about the window's preferred size, minimum and maximum size, and aspect ratio.

DIAGNOSTICS

On success, XSetWMProperties returns True. On failure, it returns False.

الاسم

XSetWMProperties - تعيين خصائص مدير النوافذ

الصياغة 

/* في Xutil/icccm.h، أو غالبًا ما يتم تضمينها عبر Xlib.h */
#include <X11/Xutil.h>

Bool
XSetWMProperties(Display *display,
                    Window w,
                    XTextProperty *name,
                    XTextProperty *icon_name,
                    char **argv,
                    int argc,
                    XWMHints *wmHints,
                    XClassHint *classHints,
                    XSizeHints *sizeHints);

الوسائط

display
يحدد الاتصال بخادم X.
w
يحدد النافذة.
name
يحدد خاصية اسم النافذة.
icon_name
يحدد خاصية اسم أيقونة النافذة.
argv
يحدد وسائط سطر الأوامر التي بدأت التطبيق.
argc
يحدد عدد وسائط سطر الأوامر.
wmHints
يحدد تلميحات مدير النوافذ.
classHints
يحدد تلميحات فئة النافذة.
sizeHints
يحدد تلميحات حجم النافذة.

الوصف

تحدد الدالة XSetWMProperties عدة خصائص على النافذة المحددة w والتي يستخدمها مدير النوافذ لإدارة النافذة. تشمل هذه الخصائص:

  • WM_NAME
  • WM_ICON_NAME
  • WM_COMMAND
  • WM_HINTS
  • WM_CLASS
  • WM_NORMAL_HINTS

يمكن أن تكون الوسائط name و icon_name و wmHints و classHints و sizeHints NULL إذا لم يكن من المفترض تعيين الخصائص المقابلة.

تحدد الوسائط argv و argc وسائط سطر الأوامر التي تم استخدامها لبدء التطبيق. تُستخدم هذه المعلومات بواسطة مدير النوافذ لإعادة تشغيل التطبيق.

تُرجع الدالة XSetWMProperties القيمة True إذا تم تعيين الخصائص بنجاح، و False بخلاف ذلك.

الخصائص

يتم تعيين الخصائص التالية بواسطة هذه الدالة:

WM_NAME
اسم النافذة. يتم تعيين هذا من الوسيط name، والذي يجب أن يكون بنية XTextProperty. عادةً، يتم إنشاء هذا باستخدام XStringListToTextProperty أو XTextListToTextProperty.
WM_ICON_NAME
اسم أيقونة النافذة. يتم تعيين هذا من الوسيط icon_name، والذي يجب أن يكون بنية XTextProperty. عادةً، يتم إنشاء هذا باستخدام XStringListToTextProperty أو XTextListToTextProperty.
WM_COMMAND
وسائط سطر الأوامر المستخدمة لبدء التطبيق. يتم تعيين هذا من الوسائط argv و argc.
WM_HINTS
تلميحات مدير النوافذ. يتم تعيين هذا من الوسيط wmHints، والذي يجب أن يكون بنية XWMHints. توفر هذه البنية معلومات لمدير النوافذ حول كيفية إدارة النافذة، مثل ما إذا كانت نافذة عادية، أو مربع حوار، أو نافذة للإدخال فقط، وما إذا كان يمكن تصغيرها.
WM_CLASS
فئة النافذة. يتم تعيين هذا من الوسيط classHints، والذي يجب أن يكون بنية XClassHint. توفر هذه البنية اسم المثيل واسم الفئة للنافذة، والتي يمكن استخدامها بواسطة مدير النوافذ لتجميع النوافذ أو لتطبيق زخارف محددة.
WM_NORMAL_HINTS
تلميحات النافذة العادية. يتم تعيين هذا من الوسيط sizeHints، والذي يجب أن يكون بنية XSizeHints. توفر هذه البنية معلومات حول الحجم المفضل للنافذة، والحجم الأدنى والأقصى، ونسبة العرض إلى الارتفاع.

التشخيصات

عند النجاح، تُرجع XSetWMProperties القيمة True. عند الفشل، تُرجع القيمة False.
