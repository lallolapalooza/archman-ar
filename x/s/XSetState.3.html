XSetState(3)

الحزمة: libx11

التراخيص: MIT AND X11

XSetState(3) وظائف XLIB XSetState(3)

الاسم

XSetState, XSetFunction, XSetPlaneMask, XSetForeground, XSetBackground - روتينات مساعدة للـ GC

الصيغة

int XSetState(Display *display, GC gc, unsigned long foreground, unsigned long background, int function, unsigned long plane_mask);

int XSetFunction(Display *display, GC gc, int function);

int XSetPlaneMask(Display *display, GC gc, unsigned long plane_mask);

int XSetForeground(Display *display, GC gc, unsigned long foreground);

int XSetBackground(Display *display, GC gc, unsigned long background);

الوسائط

background
يحدد الخلفية التي تريد تعيينها للـ GC المحدد.
display
يحدد الاتصال بخادم X.
foreground
يحدد المقدمة التي تريد تعيينها للـ GC المحدد.
function
يحدد الدالة التي تريد تعيينها للـ GC المحدد.
gc
يحدد الـ GC.
plane_mask
يحدد قناع المستوى.

الوصف

تقوم الدالة XSetState بتعيين مكونات المقدمة والخلفية وقناع المستوى والدالة للـ GC المحدد.

يمكن لـ XSetState إنشاء أخطاء BadAlloc و BadGC و BadValue.

تقوم XSetFunction بتعيين قيمة محددة في الـ GC المحدد.

يمكن لـ XSetFunction إنشاء أخطاء BadAlloc و BadGC و BadValue.

تقوم الدالة XSetPlaneMask بتعيين قناع المستوى في الـ GC المحدد.

يمكن لـ XSetPlaneMask إنشاء أخطاء BadAlloc و BadGC.

تقوم الدالة XSetForeground بتعيين المقدمة في الـ GC المحدد.

يمكن لـ XSetForeground إنشاء أخطاء BadAlloc و BadGC.

تقوم الدالة XSetBackground بتعيين الخلفية في الـ GC المحدد.

يمكن لـ XSetBackground إنشاء أخطاء BadAlloc و BadGC.

التشخيصات

BadAlloc
فشل الخادم في تخصيص المورد المطلوب أو ذاكرة الخادم.
BadGC
قيمة وسيطة GContext لا تشير إلى GContext محدد.
BadValue
بعض القيم الرقمية تقع خارج نطاق القيم التي يقبلها الطلب. ما لم يتم تحديد نطاق معين لوسيطة، يتم قبول النطاق الكامل الذي تحدده نوع الوسيطة. يمكن لأي وسيطة محددة كمجموعة من البدائل إنشاء هذا الخطأ.
