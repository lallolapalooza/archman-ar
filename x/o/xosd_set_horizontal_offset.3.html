xosd_set_horizontal_offset(3)

الحزمة: xosd

التراخيص: GPL2

xosd_set_horizontal_offset(3) دليل وظائف المكتبة xosd_set_horizontal_offset(3)

الاسم

xosd_set_horizontal_offset - تغيير مسافة بادئة لنافذة XOSD

الملخص

#include <xosd.h>

int xosd_set_horizontal_offset (xosd* osd, int offset);

الوصف

تغير xosd_set_horizontal_offset عدد وحدات البكسل التي تكون نافذة XOSD مزاحة بها من يسار الشاشة.

المعاملات

osd
كائن العرض على الشاشة الذي سيتم العمل عليه.
offset
المسافة البادئة من يسار الشاشة، بوحدات البكسل.

قيمة الإرجاع

عند النجاح، يتم إرجاع الصفر. عند حدوث خطأ، يتم إرجاع -1.

انظر أيضًا

xosd_create(3)، xosd_set_align(3).
