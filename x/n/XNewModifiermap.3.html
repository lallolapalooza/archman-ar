XNewModifiermap(3)

الحزمة: libx11

التراخيص: MIT AND X11

NAME

XNewModifierKeymap, XFreeModifierKeymap - create and free modifier keymaps

SYNOPSIS

    #include <X11/Xutil.h>

    XModifierKeymap *XNewModifierKeymap(int max_keys_per_mod);

    void XFreeModifierKeymap(XModifierKeymap *modifier_keymap);

ARGUMENTS

‐ max_keys_per_mod
Specifies the maximum number of keycodes that can be associated with each modifier.
‐ modifier_keymap
Specifies the XModifierKeymap structure to be freed.

DESCRIPTION

The XNewModifierKeymap function allocates and returns a pointer to a new XModifierKeymap structure. The structure is initialized to contain an 8 by max_keys_per_mod array. All elements of the array are initialized to zero.

The XFreeModifierKeymap function frees the specified XModifierKeymap structure.

STRUCTURES

The XModifierKeymap structure contains:

typedef struct {
        int max_keypermod;      /* This server's max number of keys per modifier */
        KeyCode *modifiermap;   /* An 8 by max_keypermod array of the modifiers */
} XModifierKeymap;

DIAGNOSTICS

BadAlloc
The server failed to allocate the requested resource or server memory.
BadValue
Some numeric value falls outside the range of values accepted by the request. Unless a specific range is specified for an argument, the full range defined by the argument's type is accepted. Any argument defined as a set of alternatives can generate this error.

الاسم

XNewModifierKeymap, XFreeModifierKeymap - إنشاء وتحرير خرائط مفاتيح المعدِّل

الملخص

    #include <X11/Xutil.h>

    XModifierKeymap *XNewModifierKeymap(int max_keys_per_mod);

    void XFreeModifierKeymap(XModifierKeymap *modifier_keymap);

المعاملات

‐ max_keys_per_mod
يحدد الحد الأقصى لعدد رموز المفاتيح التي يمكن ربطها بكل معدِّل.
‐ modifier_keymap
يحدد بنية XModifierKeymap التي سيتم تحريرها.

الوصف

تقوم الدالة XNewModifierKeymap بتخصيص وإرجاع مؤشر إلى بنية XModifierKeymap جديدة. يتم تهيئة البنية لتضمين مصفوفة بحجم 8 × max_keys_per_mod. تتم تهيئة جميع عناصر المصفوفة إلى الصفر.

تقوم الدالة XFreeModifierKeymap بتحرير بنية XModifierKeymap المحددة.

الهياكل

تحتوي بنية XModifierKeymap على:

typedef struct {
        int max_keypermod;      /* This server's max number of keys per modifier */
        KeyCode *modifiermap;   /* An 8 by max_keypermod array of the modifiers */
} XModifierKeymap;

التشخيصات

BadAlloc
فشل الخادم في تخصيص المورد المطلوب أو ذاكرة الخادم.
BadValue
تتجاوز بعض القيم الرقمية النطاق المقبول للطلب. ما لم يتم تحديد نطاق معين لمعامل، يتم قبول النطاق الكامل الذي تحدده نوع المعامل. يمكن لأي معامل معرّف كمجموعة من البدائل أن يولد هذا الخطأ.
