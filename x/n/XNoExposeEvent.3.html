XNoExposeEvent(3)

الحزمة: libx11

التراخيص: MIT AND X11

XGraphicsExposeEvent(3) وظائف XLIB XGraphicsExposeEvent(3)

الاسم

XGraphicsExposeEvent, XNoExposeEvent - هياكل أحداث GraphicsExpose و NoExpose

الهياكل

تحتوي هياكل أحداث GraphicsExpose و NoExpose على:

typedef struct {
        int type;       /* GraphicsExpose */
        unsigned long serial;   /* # of last request processed by server */
        Bool send_event;        /* true if this came from a SendEvent request */
        Display *display;       /* Display the event was read from */
        Drawable drawable;
        int x, y;
        int width, height;
        int count;      /* if nonzero, at least this many more */
        int major_code; /* core is CopyArea or CopyPlane */
        int minor_code; /* not defined in the core */
} XGraphicsExposeEvent;
typedef struct {
        int type;       /* NoExpose */
        unsigned long serial;   /* # of last request processed by server */
        Bool send_event;        /* true if this came from a SendEvent request */
        Display *display;       /* Display the event was read from */
        Drawable drawable;
        int major_code; /* core is CopyArea or CopyPlane */
        int minor_code; /* not defined in the core */
} XNoExposeEvent;

عندما تتلقى هذه الأحداث، يتم تعيين أعضاء الهيكل الخاص بها على النحو التالي.

يتم تعيين العضو type إلى الاسم الثابت لنوع الحدث الذي يعرفه بشكل فريد. على سبيل المثال، عندما يبلغ خادم X عن حدث GraphicsExpose لتطبيق عميل، فإنه يرسل هيكل XGraphicsExposeEvent مع تعيين العضو type إلى GraphicsExpose. يتم تعيين العضو display إلى مؤشر إلى العرض الذي تمت قراءة الحدث منه. يتم تعيين العضو send_event إلى True إذا جاء الحدث من طلب بروتوكول SendEvent. يتم تعيين العضو serial من الرقم التسلسلي المبلغ عنه في البروتوكول ولكن تم توسيعه من 16 بت للأقل أهمية إلى 32 بت كاملة. يتم تعيين العضو window إلى النافذة الأكثر فائدة لموزعي الأدوات.

تحتوي كلا الهيكلين على هذه الأعضاء المشتركة: drawable، major_code، و minor_code. يتم تعيين العضو drawable إلى الرسم القابل للرسم للمنطقة الوجهة التي كان من المقرر تنفيذ طلب الرسومات عليها. يتم تعيين العضو major_code إلى طلب الرسومات الذي بدأه العميل ويمكن أن يكون إما X_CopyArea أو X_CopyPlane. إذا كان X_CopyArea، فقد بدأ الاستدعاء إلى XCopyArea الطلب. إذا كان X_CopyPlane، فقد بدأ الاستدعاء إلى XCopyPlane الطلب. هذه الثوابت محددة في X11/Xproto.h. العضو minor_code، مثل العضو major_code، يشير إلى طلب الرسومات الذي بدأه العميل. ومع ذلك، فإن العضو minor_code غير محدد بواسطة بروتوكول X الأساسي وسيكون صفرًا في هذه الحالات، على الرغم من أنه قد يتم استخدامه بواسطة امتداد.

يحتوي هيكل XGraphicsExposeEvent على هذه الأعضاء الإضافية: x، y، width، height، و count. يتم تعيين الأعضاء x و y إلى الإحداثيات بالنسبة إلى أصل الرسم وتشير إلى الزاوية العلوية اليسرى للمستطيل. يتم تعيين الأعضاء width و height إلى حجم (امتداد) المستطيل. يتم تعيين العضو count إلى عدد أحداث GraphicsExpose التي ستتبع. إذا كان count صفرًا، فلا توجد أحداث GraphicsExpose أخرى لهذه النافذة. ومع ذلك، إذا كان count غير صفري، فمن المتوقع أن تتبع على الأقل هذا العدد من أحداث GraphicsExpose (وربما أكثر) لهذه النافذة.
