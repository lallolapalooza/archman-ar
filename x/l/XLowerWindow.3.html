XLowerWindow(3)

الحزمة: libx11

التراخيص: MIT AND X11

XRaiseWindow(3) وظائف XLIB XRaiseWindow(3)

الاسم

XRaiseWindow، XLowerWindow، XCirculateSubwindows، XCirculateSubwindowsUp، XCirculateSubwindowsDown، XRestackWindows - تغيير ترتيب تكديس النوافذ

الصيغة

int XRaiseWindow(Display *display, Window w);

int XLowerWindow(Display *display, Window w);

int XCirculateSubwindows(Display *display, Window w, int direction);

int XCirculateSubwindowsUp(Display *display, Window w);

int XCirculateSubwindowsDown(Display *display, Window w);

int XRestackWindows(Display *display, Window windows[], int nwindows);

الوسائط

direction
يحدد الاتجاه (للأعلى أو للأسفل) الذي تريد تدوير النافذة به. يمكنك تمرير RaiseLowest أو LowerHighest.
display
يحدد الاتصال بخادم X.
nwindows
يحدد عدد النوافذ التي سيتم إعادة تكديسها.
w
يحدد النافذة.
windows
يحدد مصفوفة تحتوي على النوافذ التي سيتم إعادة تكديسها.

الوصف

تقوم الدالة XRaiseWindow برفع النافذة المحددة إلى أعلى المكدس بحيث لا تحجبها أي نافذة شقيقة. إذا تم اعتبار النوافذ كأوراق متداخلة مكدسة على مكتب، فإن رفع النافذة يشبه نقل الورقة إلى أعلى المكدس مع ترك موقعها x و y على المكتب ثابتًا. قد يؤدي رفع نافذة مرئية إلى إنشاء أحداث Expose للنافذة وأي نوافذ فرعية مرئية كانت محجوبة سابقًا.

إذا كانت سمة تجاوز إعادة التوجيه (override-redirect) للنافذة False وقام عميل آخر بتحديد SubstructureRedirectMask على النافذة الأم، فإن خادم X ينشئ حدث ConfigureRequest، ولا يتم إجراء أي معالجة إضافية. وإلا، يتم رفع النافذة.

XRaiseWindow يمكن أن تولد خطأ BadWindow.

تقوم الدالة XLowerWindow بخفض النافذة المحددة إلى أسفل المكدس بحيث لا تحجب أي نوافذ شقيقة. إذا تم اعتبار النوافذ كأوراق متداخلة مكدسة على مكتب، فإن خفض النافذة يشبه نقل الورقة إلى أسفل المكدس مع ترك موقعها x و y على المكتب ثابتًا. سيؤدي خفض نافذة مرئية إلى إنشاء أحداث Expose على أي نوافذ تم حجبها سابقًا.

إذا كانت سمة تجاوز إعادة التوجيه (override-redirect) للنافذة False وقام عميل آخر بتحديد SubstructureRedirectMask على النافذة الأم، فإن خادم X ينشئ حدث ConfigureRequest، ولا يتم إجراء أي معالجة إضافية. وإلا، يتم خفض النافذة إلى أسفل المكدس.

XLowerWindow يمكن أن تولد خطأ BadWindow.

تقوم الدالة XCirculateSubwindows بتدوير النوافذ الفرعية للنافذة المحددة في الاتجاه المحدد. إذا حددت RaiseLowest، فإن XCirculateSubwindows ترفع النافذة الفرعية المرئية الأدنى (إن وجدت) التي تحجبها نافذة فرعية أخرى إلى أعلى المكدس. إذا حددت LowerHighest، فإن XCirculateSubwindows تخفض النافذة الفرعية المرئية الأعلى (إن وجدت) التي تحجب نافذة فرعية أخرى إلى أسفل المكدس. تتم بعد ذلك معالجة العرض على النوافذ التي تم حجبها سابقًا. إذا قام عميل آخر بتحديد SubstructureRedirectMask على النافذة، فإن خادم X ينشئ حدث CirculateRequest، ولا يتم إجراء أي معالجة إضافية. إذا تم إعادة تكديس نافذة فرعية فعليًا، فإن خادم X ينشئ حدث CirculateNotify.

XCirculateSubwindows يمكن أن تولد أخطاء BadValue و BadWindow.

تقوم الدالة XCirculateSubwindowsUp برفع النافذة الفرعية المرئية الأدنى للنافذة المحددة التي يتم حجبها جزئيًا أو كليًا بواسطة نافذة فرعية أخرى. لا تتأثر النوافذ الفرعية غير المحجوبة تمامًا. هذه دالة مساعدة تساوي XCirculateSubwindows مع تحديد RaiseLowest.

XCirculateSubwindowsUp يمكن أن تولد خطأ BadWindow.

تقوم الدالة XCirculateSubwindowsDown بخفض النافذة الفرعية المرئية الأعلى للنافذة المحددة التي تحجب جزئيًا أو كليًا نافذة فرعية أخرى. لا تتأثر النوافذ الفرعية غير المحجوبة تمامًا. هذه دالة مساعدة تساوي XCirculateSubwindows مع تحديد LowerHighest.

XCirculateSubwindowsDown يمكن أن تولد خطأ BadWindow.

تقوم الدالة XRestackWindows بإعادة تكديس النوافذ بالترتيب المحدد، من الأعلى إلى الأسفل. لا يتأثر ترتيب تكديس النافذة الأولى في مصفوفة النوافذ، ولكن يتم تكديس النوافذ الأخرى في المصفوفة أسفل النافذة الأولى، بترتيب المصفوفة. لا يتأثر ترتيب تكديس النوافذ الأخرى. لكل نافذة في مصفوفة النوافذ التي ليست شقيقة للنافذة الأولى، ينتج خطأ BadMatch.

إذا كانت سمة تجاوز إعادة التوجيه (override-redirect) لنافذة False وقام عميل آخر بتحديد SubstructureRedirectMask على النافذة الأم، فإن خادم X ينشئ أحداث ConfigureRequest لكل نافذة لا تحمل سمة تجاوز إعادة التوجيه، ولا يتم إجراء أي معالجة إضافية. وإلا، سيتم إعادة تكديس النوافذ بترتيب من الأعلى إلى الأسفل.

XRestackWindows يمكن أن تولد خطأ BadWindow.

التشخيص

BadValue
تكون قيمة رقمية معينة خارج نطاق القيم التي تقبلها الطلب. ما لم يتم تحديد نطاق معين للوسيط، يتم قبول النطاق الكامل الذي تحدده نوع الوسيط. يمكن لأي وسيط محدد كمجموعة من البدائل توليد هذا الخطأ.
BadWindow
لا تحدد قيمة وسيط نافذة (Window) نافذة معرفة.

Introduction

Arch Linux is a versatile, self-directed GNU/Linux distribution targeted at knowledgeable Linux users. It follows a rolling-release model, which allows users to stay up-to-date with the latest software versions. Arch Linux is known for its simplicity, modernity, stability, and user-centricity.

News

Stay updated with the latest Arch Linux news on the official Arch Linux website.

Getting Arch

Arch Linux can be obtained through various means, primarily by downloading the official installation ISO image.

Installation

The installation process is guided by the Arch Linux Installation Guide. This guide provides step-by-step instructions to set up a functional Arch Linux system.

Live environment

The Arch Linux installation ISO provides a live environment, allowing you to try out Arch Linux before installing it or to perform system recovery tasks.

Documentation

Comprehensive documentation is available on the Arch Linux Wiki, which is the primary resource for users seeking information about installation, configuration, troubleshooting, and more.

Community

Arch Linux has a vibrant community. You can engage with other users and developers through the Arch Linux Forums, mailing lists, and other communication channels.

Development

Arch Linux development is an ongoing process. Information about the development roadmap and current efforts can be found on the official website and associated development resources.

Contributing

Contributions to Arch Linux are welcomed. This can include bug reporting, documentation improvements, package maintenance, or development. More information on how to contribute can be found on the Contributing page on the Arch Wiki.

Related projects

Arch Linux has inspired or is related to several other projects, including:

  • Manjaro Linux
  • EndeavourOS
  • Garuda Linux

Credits

Arch Linux is the work of many individuals. Special thanks are due to the core development team, the packagers, the documentation writers, and the entire community for their contributions. For a full list of credits, please refer to the documentation included with the distribution or on the Arch Linux website.
