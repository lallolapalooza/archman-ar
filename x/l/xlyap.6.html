XScreenSaver Manual

NAME

xscreensaver-demo - demo modes for the XScreenSaver.

SYNOPSIS

xscreensaver-demo [ options ] [ program ]

DESCRIPTION

xscreensaver-demo is a program that runs various xscreensaver hacks, and allows you to choose which ones to run. It is useful for testing screensavers. It can also be used to launch the xscreensaver daemon.

OPTIONS

The following options are supported:

-display display
Use display to connect to the X server.
-root
Run in the root window.
-window window
Run in the specified window.
-left x
Place the window at x coordinates.
-top y
Place the window at y coordinates.
-width width
Set the window width.
-height height
Set the window height.
-defer
Defer the execution of the saver.
-debug
Enable debugging output.
-verbose
Enable verbose output.
-log file
Log output to file.
-delay seconds
Set the delay between screen redraws.
-fps
Show the frames per second.
-text string
Display the given string.
-textdelay seconds
Set the delay between text updates.
-n name
Use the specified name for the window title.
-p program
Run the specified program.
-r rate
Set the animation rate.
-f file
Load configuration from file.
-h, --help
Show help message and exit.
-v, --version
Show version information and exit.

NOTES

This program is intended for use with the XScreenSaver daemon. It can be used to test individual screensaver modules or to launch the daemon itself.

The xscreensaver-demo program allows you to preview and configure various screensaver modules. You can select a module from the list, adjust its settings, and see a preview of how it will look. You can also set the delay before the screensaver starts and the delay between screen updates.

ENVIRONMENT

The following environment variables are used by xscreensaver-demo:

DISPLAY
The default display name.
XSCREENSAVER_HOME
The directory containing the screensaver configuration files.
