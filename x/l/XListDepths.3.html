XListDepths(3) - X Window System

الاسم

XListDepths - سرد عمق الألوان المتاح لشاشة.

الصياغة

int XListDepths(Display *display, int screen_number, int **buffer_return, int *count_return);

المعاملات

display

يحدد اتصال الخادم.

screen_number

يحدد رقم الشاشة.

buffer_return

تحدد مؤشرًا إلى مخزن مؤقت لـ ints. سيحتوي هذا المخزن المؤقت على قائمة العمق.

count_return

تحدد مؤشرًا إلى int. سيحتوي على عدد العمق في المخزن المؤقت.

الوصف

تقوم الدالة XListDepths بإرجاع قائمة بعمق البتات المدعومة لكل شاشة.

تقوم الدالة XListDepths بتخصيص ذاكرة للمخزن المؤقت الذي يتم إرجاعه. يجب على المتصل تحرير هذه الذاكرة باستخدام XFree().

إذا تمكنت الدالة من سرد العمق بنجاح، فإنها ترجع Success. وإلا، فإنها ترجع BadValue أو BadDrawable.
