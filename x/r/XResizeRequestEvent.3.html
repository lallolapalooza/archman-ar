XResizeRequestEvent(3)

الحزمة: libx11

التراخيص: MIT AND X11

XResizeRequestEvent(3) وظائف XLIB XResizeRequestEvent(3)

الاسم

XResizeRequestEvent - هيكل حدث طلب إعادة التحجيم

الهياكل

يحتوي هيكل أحداث ResizeRequest على:

typedef struct {
        int type;       /* ResizeRequest */
        unsigned long serial;   /* # of last request processed by server */
        Bool send_event;        /* true if this came from a SendEvent request */
        Display *display;       /* Display the event was read from */
        Window window;
        int width, height;
} XResizeRequestEvent;

عند استلام هذا الحدث، يتم تعيين أعضاء الهيكل كالتالي.

يتم تعيين العضو type إلى اسم ثابت نوع الحدث الذي يحدده بشكل فريد. على سبيل المثال، عندما يقوم خادم X بالإبلاغ عن حدث GraphicsExpose لتطبيق عميل، فإنه يرسل هيكل XGraphicsExposeEvent مع تعيين العضو type إلى GraphicsExpose. يتم تعيين العضو display إلى مؤشر للشاشة التي تمت قراءة الحدث عليها. يتم تعيين العضو send_event إلى True إذا جاء الحدث من طلب بروتوكول SendEvent. يتم تعيين العضو serial من رقم التسلسل المبلغ عنه في البروتوكول ولكنه موسع من أقل 16 بت أهمية إلى قيمة كاملة 32 بت. يتم تعيين العضو window إلى النافذة الأكثر فائدة لموزعي الأدوات.

يتم تعيين العضو window إلى النافذة التي حاول عميل آخر تغيير حجمها. يتم تعيين الأعضاء width و height إلى الحجم الداخلي للنافذة، باستثناء الحدود.
