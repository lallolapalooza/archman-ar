XReadBitmapFile(3)

الحزمة: libx11

التراخيص: MIT AND X11

XReadBitmapFile(3) وظائف XLIB XReadBitmapFile(3)

الاسم

XReadBitmapFile, XReadBitmapFileData, XWriteBitmapFile, XCreatePixmapFromBitmapData, XCreateBitmapFromData - معالجة صور نقطية

الصيغة

int XReadBitmapFile(Display *display, Drawable d, _Xconst char *filename, unsigned int *width_return, unsigned int *height_return, Pixmap *bitmap_return, int *x_hot_return, int *y_hot_return);

int XReadBitmapFileData(_Xconst char *filename, unsigned int *width_return, unsigned int *height_return, unsigned char **data_return, int *x_hot_return, int *y_hot_return);

int XWriteBitmapFile(Display *display, _Xconst char *filename, Pixmap bitmap, unsigned int width, unsigned int height, int x_hot, int y_hot);

Pixmap XCreatePixmapFromBitmapData(Display *display, Drawable d, char *data, unsigned int width, unsigned int height, unsigned long fg, unsigned long bg, unsigned int depth);

Pixmap XCreateBitmapFromData(Display *display, Drawable d, _Xconst char *data, unsigned int width, unsigned int height);

الوصف

تقوم الدالة XReadBitmapFile بقراءة ملف يحتوي على صورة نقطية. يتم تحليل الملف بتشفير المنطقة المحلية الحالية. القدرة على قراءة تنسيقات غير قياسية تعتمد على التنفيذ. إذا لم يكن بالإمكان فتح الملف، فإن XReadBitmapFile تعيد BitmapOpenFailed. إذا كان يمكن فتح الملف ولكنه لا يحتوي على بيانات صورة نقطية صالحة، فإنها تعيد BitmapFileInvalid. إذا تم تخصيص مساحة عمل غير كافية، فإنها تعيد BitmapNoMemory. إذا كان الملف قابلاً للقراءة وصالحاً، فإنه يعيد BitmapSuccess.

تعيد XReadBitmapFile ارتفاع وعرض الصورة النقطية، كما قرأتها من الملف، إلى width_return و height_return. ثم تقوم بإنشاء بكسماپ بالحجم المناسب، وتقرأ بيانات الصورة النقطية من الملف إلى البكسماپ، وتعين البكسماپ لمتغير bitmap الخاص بالمتصل. يجب على المتصل تحرير البكسماپ باستخدام XFreePixmap عند الانتهاء. إذا كانت name_x_hot و name_y_hot موجودة، فإن XReadBitmapFile تعيدها إلى x_hot_return و y_hot_return؛ وإلا، فإنها تعيد -1، -1.

يمكن لـ XReadBitmapFile أن تولد أخطاء BadAlloc و BadDrawable.

تقوم الدالة XReadBitmapFileData بقراءة ملف يحتوي على صورة نقطية، بنفس الطريقة التي تعمل بها XReadBitmapFile، ولكنها تعيد البيانات مباشرة بدلاً من إنشاء بكسماپ في الخادم. يتم إرجاع بيانات الصورة النقطية في data_return؛ يجب على العميل تحرير هذه المساحة عند الانتهاء منها عن طريق استدعاء XFree. الحالة والقيم المرجعة الأخرى هي نفسها كما في XReadBitmapFile.

تقوم الدالة XWriteBitmapFile بكتابة صورة نقطية إلى ملف بتنسيق X الإصدار 11. يتم اشتقاق الاسم المستخدم في ملف الإخراج من اسم الملف عن طريق حذف بادئة الدليل. يتم كتابة الملف بتشفير المنطقة المحلية الحالية. إذا لم يكن بالإمكان فتح الملف للكتابة، فإنه يعيد BitmapOpenFailed. إذا تم تخصيص ذاكرة غير كافية، فإن XWriteBitmapFile تعيد BitmapNoMemory؛ وإلا، عند عدم وجود خطأ، فإنها تعيد BitmapSuccess. إذا لم تكن x_hot و y_hot تساوي -1، -1، فإن XWriteBitmapFile تكتبهما كإحداثيات نقطة اتصال للصورة النقطية.

يمكن لـ XWriteBitmapFile أن تولد أخطاء BadDrawable و BadMatch.

تقوم الدالة XCreatePixmapFromBitmapData بإنشاء بكسماپ بالعمق المحدد ثم تقوم بعمل XPutImage بتنسيق الصورة النقطية للبيانات فيها. يجب أن يكون العمق مدعومًا بواسطة شاشة الكائن القابل للرسم المحدد، وإلا سينتج خطأ BadMatch.

يمكن لـ XCreatePixmapFromBitmapData أن تولد أخطاء BadAlloc و BadMatch.

تسمح لك الدالة XCreateBitmapFromData بتضمين ملف صورة نقطية مكتوب بواسطة XWriteBitmapFile (تنسيق X الإصدار 11 فقط) في برنامج C الخاص بك (باستخدام #include) دون قراءة ملف الصورة النقطية. المثال التالي ينشئ صورة نقطية رمادية:

#include "gray.bitmap"

Pixmap bitmap;
bitmap = XCreateBitmapFromData(display, window, gray_bits, gray_width, gray_height);

إذا تم تخصيص مساحة عمل غير كافية، فإن XCreateBitmapFromData تعيد None. تقع على عاتقك مسؤولية تحرير الصورة النقطية باستخدام XFreePixmap عند الانتهاء.

يمكن لـ XCreateBitmapFromData أن تولد خطأ BadAlloc.

التشخيصات

BadAlloc
فشل الخادم في تخصيص المورد المطلوب أو ذاكرة الخادم.
BadDrawable
قيمة وسيطة Drawable لا تشير إلى نافذة أو بكسماپ معرفة.
BadMatch
يتم استخدام نافذة InputOnly ككائن قابل للرسم.
