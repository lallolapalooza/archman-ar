XReadBitmapFileData(3)

الحزمة: libx11

التراخيص: MIT AND X11

XReadBitmapFile(3) وظائف XLIB XReadBitmapFile(3)

الاسم

XReadBitmapFile, XReadBitmapFileData, XWriteBitmapFile, XCreatePixmapFromBitmapData, XCreateBitmapFromData - معالجة الصور النقطية

الصيغة

int XReadBitmapFile(Display *display, Drawable d, _Xconst char *filename, unsigned int *width_return, unsigned int *height_return, Pixmap *bitmap_return, int *x_hot_return, int *y_hot_return);

int XReadBitmapFileData(_Xconst char *filename, unsigned int *width_return, unsigned int *height_return, unsigned char **data_return, int *x_hot_return, int *y_hot_return);

int XWriteBitmapFile(Display *display, _Xconst char *filename, Pixmap bitmap, unsigned int width, unsigned int height, int x_hot, int y_hot);

Pixmap XCreatePixmapFromBitmapData(Display *display, Drawable d, char *data, unsigned int width, unsigned int height, unsigned long fg, unsigned long bg, unsigned int depth);

Pixmap XCreateBitmapFromData(Display *display, Drawable d, _Xconst char *data, unsigned int width, unsigned int height);

الوصف

تقوم الوظيفة XReadBitmapFile بقراءة ملف يحتوي على صورة نقطية. يتم تحليل الملف بتشفير اللغة المحلية الحالية. تعتمد القدرة على قراءة تنسيقات أخرى غير القياسية على التنفيذ. إذا لم يمكن فتح الملف، فإن XReadBitmapFile تعيد BitmapOpenFailed. إذا أمكن فتح الملف ولكنه لا يحتوي على بيانات صورة نقطية صالحة، فإنه يعيد BitmapFileInvalid. إذا تم تخصيص مساحة تخزين كافية، فإنه يعيد BitmapNoMemory. إذا كان الملف قابلاً للقراءة وصالحًا، فإنه يعيد BitmapSuccess.

تعيد XReadBitmapFile ارتفاع وعرض الصورة النقطية، كما تم قراءتها من الملف، إلى width_return و height_return. ثم تقوم بإنشاء صورة نقطية بالحجم المناسب، وتقرأ بيانات الصورة النقطية من الملف إلى الصورة النقطية، وتعين الصورة النقطية إلى متغير bitmap الخاص بالمتصل. يجب على المتصل تحرير الصورة النقطية باستخدام XFreePixmap عند الانتهاء. إذا كانت name_x_hot و name_y_hot موجودة، فإن XReadBitmapFile تعيدها إلى x_hot_return و y_hot_return؛ بخلاف ذلك، فإنها تعيد -1,-1.

يمكن لـ XReadBitmapFile إنشاء أخطاء BadAlloc و BadDrawable.

تقوم الوظيفة XReadBitmapFileData بقراءة ملف يحتوي على صورة نقطية، بنفس طريقة XReadBitmapFile، ولكنها تعيد البيانات مباشرة بدلاً من إنشاء صورة نقطية في الخادم. يتم إعادة بيانات الصورة النقطية في data_return؛ يجب على العميل تحرير هذه المساحة عند الانتهاء منها عن طريق استدعاء XFree. الحالة والقيم المرتجعة الأخرى هي نفس XReadBitmapFile.

تقوم الوظيفة XWriteBitmapFile بكتابة صورة نقطية إلى ملف بتنسيق X الإصدار 11. يتم اشتقاق الاسم المستخدم في ملف الإخراج من اسم الملف عن طريق حذف بادئة الدليل. يتم كتابة الملف بتشفير اللغة المحلية الحالية. إذا لم يمكن فتح الملف للكتابة، فإنه يعيد BitmapOpenFailed. إذا تم تخصيص ذاكرة غير كافية، فإن XWriteBitmapFile تعيد BitmapNoMemory؛ بخلاف ذلك، في حالة عدم وجود خطأ، فإنها تعيد BitmapSuccess. إذا لم تكن x_hot و y_hot -1, -1، فإن XWriteBitmapFile تكتبها كإحداثيات نقطة الاتصال للصورة النقطية.

يمكن لـ XWriteBitmapFile إنشاء أخطاء BadDrawable و BadMatch.

تقوم الوظيفة XCreatePixmapFromBitmapData بإنشاء صورة نقطية بالعمق المحدد ثم تقوم بعمل XPutImage بتنسيق الصورة النقطية للبيانات. يجب أن يكون العمق مدعومًا بواسطة شاشة الرسم المحددة، وإلا فسيحدث خطأ BadMatch.

يمكن لـ XCreatePixmapFromBitmapData إنشاء أخطاء BadAlloc و BadMatch.

تسمح لك الوظيفة XCreateBitmapFromData بتضمين ملف صورة نقطية مكتوب بواسطة XWriteBitmapFile (تنسيق X الإصدار 11 فقط) في برنامج C الخاص بك (باستخدام #include) دون قراءة ملف الصورة النقطية. يقوم المثال التالي بإنشاء صورة نقطية رمادية:

#include "gray.bitmap"

Pixmap bitmap;
bitmap = XCreateBitmapFromData(display, window, gray_bits, gray_width, gray_height);

إذا تم تخصيص مساحة تخزين غير كافية، فإن XCreateBitmapFromData تعيد None. تقع على عاتقك مسؤولية تحرير الصورة النقطية باستخدام XFreePixmap عند الانتهاء.

يمكن لـ XCreateBitmapFromData إنشاء خطأ BadAlloc.

التشخيص

BadAlloc
فشل الخادم في تخصيص المورد المطلوب أو ذاكرة الخادم.
BadDrawable
قيمة وسيطة Drawable لا تسمي نافذة أو صورة نقطية محددة.
BadMatch
يتم استخدام نافذة InputOnly كرسم.
