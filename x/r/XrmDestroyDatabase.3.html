NAME

XrmDestroyDatabase - destroy a representation database

SYNTAX

C Language

#include <X11/Xlib.h>

void XrmDestroyDatabase(
    XrmDatabase    database
);

ARGUMENTS

database Specifies the database to be destroyed.

DESCRIPTION

The XrmDestroyDatabase function destroys the specified representation database and frees all associated memory.

FILE SYNTAX

The representation database is a hierarchical database that stores information about resources. The syntax for the representation database is as follows:

    resource_name(';' resource_name)* : value

Where:

  • resource_name is an identifier that represents a resource.
  • ; is used to separate resource names in a hierarchy.
  • : separates the resource name from its value.
  • value is the value of the resource.

For example:

    XTerm*background: red
    XTerm*font:     *-*-fixed-medium-r-*-*-13-*-*-*-*-*-iso8859-1

الاسم

XrmDestroyDatabase - تدمير قاعدة بيانات تمثيل

الصيغة

لغة C

#include <X11/Xlib.h>

void XrmDestroyDatabase(
    XrmDatabase    database
);

الوسائط

database تحدد قاعدة البيانات المراد تدميرها.

الوصف

تقوم الدالة XrmDestroyDatabase بتدمير قاعدة بيانات التمثيل المحددة وتحرير جميع الذاكرة المرتبطة بها.

صيغة الملف

قاعدة بيانات التمثيل هي قاعدة بيانات هرمية تخزن معلومات حول الموارد. صيغة قاعدة بيانات التمثيل هي كما يلي:

    resource_name(';' resource_name)* : value

حيث:

  • resource_name هو معرف يمثل موردًا.
  • ; يستخدم للفصل بين أسماء الموارد في الهيكل الهرمي.
  • : يفصل اسم المورد عن قيمته.
  • value هي قيمة المورد.

على سبيل المثال:

    XTerm*background: red
    XTerm*font:     *-*-fixed-medium-r-*-*-13-*-*-*-*-*-iso8859-1
