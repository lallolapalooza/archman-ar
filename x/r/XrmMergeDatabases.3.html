XrmMergeDatabases(3)

الحزمة: libx11

التراخيص: MIT AND X11

XrmMergeDatabases(3) وظائف XLIB XrmMergeDatabases(3)

الاسم

XrmMergeDatabases, XrmCombineDatabase, XrmCombineFileDatabase - دمج قواعد بيانات الموارد

الصيغة

#include <X11/Xresource.h>

void XrmMergeDatabases(XrmDatabase source_db, XrmDatabase *target_db);

void XrmCombineDatabase(XrmDatabase source_db, XrmDatabase *target_db, Bool override);

Status XrmCombineFileDatabase(_Xconst char *filename, XrmDatabase *target_db, Bool override);

المعاملات

source_db
يحدد قاعدة بيانات الموارد التي سيتم دمجها في قاعدة البيانات المستهدفة.
target_db
يحدد قاعدة البيانات المستهدفة التي سيتم دمج قاعدة البيانات المصدر فيها.
filename
يحدد اسم ملف قاعدة بيانات الموارد.
override
يحدد ما إذا كانت إدخالات المصدر تتجاوز إدخالات الهدف.

الوصف

الاستدعاء للوظيفة XrmMergeDatabases يعادل استدعاء الوظيفة XrmCombineDatabase مع معامل تجاوز (override) قيمته True.

تقوم الوظيفة XrmCombineDatabase بدمج محتويات قاعدة بيانات واحدة في أخرى. إذا تم استخدام نفس المحدد لإدخال في كلا القاعدتين، فإن الإدخال في source_db سيحل محل الإدخال في target_db إذا كان override هو True؛ وإلا، يتم تجاهل الإدخال في source_db. إذا كانت target_db تحتوي على NULL، تقوم XrmCombineDatabase ببساطة بتخزين source_db فيها. بخلاف ذلك، يتم تدمير source_db بالدمج، ولكن قاعدة البيانات التي يشير إليها target_db لا يتم تدميرها. يتم دمج إدخالات قاعدة البيانات دون تغيير القيم أو الأنواع، بغض النظر عن لغات قواعد البيانات. لا يتم تعديل لغة قاعدة البيانات المستهدفة.

تقوم الوظيفة XrmCombineFileDatabase بدمج محتويات ملف موارد في قاعدة بيانات. إذا تم استخدام نفس المحدد لإدخال في كل من الملف وقاعدة البيانات، فإن الإدخال في الملف سيحل محل الإدخال في قاعدة البيانات إذا كان override هو True؛ وإلا، يتم تجاهل الإدخال في الملف. يتم تحليل الملف في اللغة الحالية. إذا لم يكن بالإمكان قراءة الملف، يتم إرجاع حالة صفرية؛ وإلا، يتم إرجاع حالة غير صفرية. إذا كانت target_db تحتوي على NULL، تقوم XrmCombineFileDatabase بإنشاء وإرجاع قاعدة بيانات جديدة لها. بخلاف ذلك، فإن قاعدة البيانات التي يشير إليها target_db لا يتم تدميرها بالدمج. يتم دمج إدخالات قاعدة البيانات دون تغيير القيم أو الأنواع، بغض النظر عن لغة قاعدة البيانات. لا يتم تعديل لغة قاعدة البيانات المستهدفة.
