XRecolorCursor(3)

الحزمة: libx11

التراخيص: MIT AND X11

XRecolorCursor(3) وظائف XLIB XRecolorCursor(3)

الاسم

XRecolorCursor, XFreeCursor, XQueryBestCursor - معالجة المؤشرات

الصيغة

int XRecolorCursor(Display *display, Cursor cursor, XColor *foreground_color, XColor *background_color);

int XFreeCursor(Display *display, Cursor cursor);

Status XQueryBestCursor(Display *display, Drawable d, unsigned int width, unsigned int height, unsigned int *width_return, unsigned int *height_return);

المعاملات

background_color
يحدد قيم RGB للخلفية المصدر.
cursor
يحدد المؤشر.
d
يحدد الكائن القابل للرسم، والذي يشير إلى الشاشة.
display
يحدد الاتصال بخادم X.
foreground_color
يحدد قيم RGB للمقدمة المصدر.
width

height
حدد العرض والارتفاع للمؤشر الذي تريد معلومات الحجم له.
width_return

height_return
إرجاع أفضل عرض وارتفاع أقرب إلى العرض والارتفاع المحددين.

الوصف

تقوم الدالة XRecolorCursor بتغيير لون المؤشر المحدد، وإذا كان المؤشر معروضًا على شاشة، يصبح التغيير مرئيًا على الفور. يتم تجاهل أعضاء البكسل في هياكل XColor؛ يتم استخدام قيم RGB فقط.

يمكن لـ XRecolorCursor إنشاء خطأ BadCursor.

تقوم الدالة XFreeCursor بحذف الارتباط بين معرف مورد المؤشر والمؤشر المحدد. يتم تحرير مساحة تخزين المؤشر عندما لا تشير إليها أي موارد أخرى. لا ينبغي الإشارة إلى معرف المؤشر المحدد مرة أخرى.

يمكن لـ XFreeCursor إنشاء خطأ BadCursor.

تسمح بعض الشاشات بمؤشرات أكبر من غيرها. توفر الدالة XQueryBestCursor طريقة لمعرفة أحجام المؤشرات الممكنة فعليًا على الشاشة. تقوم بإرجاع أكبر حجم يمكن عرضه. يجب أن تكون التطبيقات مستعدة لاستخدام مؤشرات أصغر على الشاشات التي لا يمكنها دعم الكبيرة.

يمكن لـ XQueryBestCursor إنشاء خطأ BadDrawable.

التشخيصات

BadCursor
قيمة لمعامل Cursor لا تسمي مؤشرًا محددًا.
BadDrawable
قيمة لمعامل Drawable لا تسمي نافذة أو Pixmap محددة.
