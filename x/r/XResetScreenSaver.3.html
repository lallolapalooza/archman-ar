XResetScreenSaver(3)

الحزمة: libx11

التراخيص: MIT AND X11

XSetScreenSaver(3) وظائف XLIB XSetScreenSaver(3)

الاسم

XSetScreenSaver, XForceScreenSaver, XActivateScreenSaver, XResetScreenSaver, XGetScreenSaver - معالجة موفر الشاشة

الصيغة

int XSetScreenSaver(Display *display, int timeout, int interval, int prefer_blanking, int allow_exposures);

int XForceScreenSaver(Display *display, int mode);

int XActivateScreenSaver(Display *display);

int XResetScreenSaver(Display *display);

int XGetScreenSaver(Display *display, int *timeout_return, int *interval_return, int *prefer_blanking_return, int *allow_exposures_return);

الوسائط

allow_exposures
يحدد قيم التحكم في توفير الشاشة. يمكنك تمرير DontAllowExposures، AllowExposures، أو DefaultExposures.
allow_exposures_return
يعيد قيمة التحكم الحالية في توفير الشاشة (DontAllowExposures، AllowExposures، أو DefaultExposures).
display
يحدد الاتصال بخادم X.
interval
يحدد الفترة الزمنية، بالثواني، بين تغييرات موفر الشاشة.
interval_return
يعيد الفترة الزمنية بين استدعاءات موفر الشاشة.
mode
يحدد الوضع المطلوب تطبيقه. يمكنك تمرير ScreenSaverActive أو ScreenSaverReset.
prefer_blanking
يحدد كيفية تمكين تعتيم الشاشة. يمكنك تمرير DontPreferBlanking، PreferBlanking، أو DefaultBlanking.
prefer_blanking_return
يعيد تفضيل تعتيم الشاشة الحالي (DontPreferBlanking، PreferBlanking، أو DefaultBlanking).
timeout
يحدد مهلة الانتظار، بالثواني، حتى يتم تشغيل موفر الشاشة.
timeout_return
يعيد مهلة الانتظار، بالثواني، حتى يتم تشغيل موفر الشاشة.

الوصف

يتم تحديد مهلة الانتظار والفترة الزمنية بالثواني. يؤدي تعيين مهلة الانتظار إلى 0 إلى تعطيل موفر الشاشة (ولكن لا يتم إلغاء تنشيط موفر شاشة نشط)، ويعيد تعيين مهلة الانتظار إلى -1 الوضع الافتراضي. القيم السالبة الأخرى تولد خطأ BadValue. إذا كانت قيمة مهلة الانتظار غير صفرية، فإن XSetScreenSaver يمكّن موفر الشاشة. يتم تحديد كلتا القيمتين بحد أقصى 16 بت من أعداد صحيحة موقعة بواسطة بروتوكول الاتصال، على الرغم من نموذج C. إذا لم يتم إنشاء أي إدخال من الأجهزة (لوحة المفاتيح، الماوس، وما إلى ذلك) خلال عدد الثواني المحدد لمهلة الانتظار بمجرد تمكين موفر الشاشة، فإن موفر الشاشة يتم تنشيطه.

لكل شاشة، إذا كان التعتيم مفضلاً وكانت الأجهزة تدعم تعتيم الفيديو، تصبح الشاشة فارغة ببساطة. بخلاف ذلك، إذا تم السماح بالتعرضات أو كان يمكن إعادة إنشاء الشاشة دون إرسال أحداث Expose إلى العملاء، يتم تبليط الشاشة مع الخلفية الأصلية لنافذة الجذر مع إعادة تنظيمها بشكل عشوائي كل فترة زمنية محددة. بخلاف ذلك، لا تتغير حالات الشاشة، ولا يتم تنشيط موفر الشاشة. يتم إلغاء تنشيط موفر الشاشة، ويتم استعادة جميع حالات الشاشة عند الإدخال التالي للوحة المفاتيح أو المؤشر أو عند الاستدعاء التالي لـ XForceScreenSaver بالوضع ScreenSaverReset.

إذا كانت طريقة موفر الشاشة الخاصة بالخادم تدعم التغيير الدوري، فإن وسيط الفترة الزمنية يعمل كمؤشر حول المدة التي يجب أن تكون عليها فترة التغيير، وصفر يشير إلى عدم إجراء تغيير دوري. تشمل أمثلة طرق تغيير الشاشة تشويش لوحة الألوان بشكل دوري، أو تحريك صورة أيقونة حول الشاشة بشكل دوري، أو تبليط الشاشة بنمط خلفية النافذة الأصلية، مع إعادة تنظيمها بشكل عشوائي بشكل دوري.

يمكن لـ XSetScreenSaver إنشاء خطأ BadValue.

إذا كان الوضع المحدد هو ScreenSaverActive وكان موفر الشاشة غير نشط حاليًا، فإن XForceScreenSaver ينشط موفر الشاشة حتى لو تم تعطيل موفر الشاشة بمهلة انتظار صفرية. إذا كان الوضع المحدد هو ScreenSaverReset وكان موفر الشاشة ممكّنًا حاليًا، فإن XForceScreenSaver يعطل موفر الشاشة إذا تم تنشيطه، ويتم إعادة تعيين مؤقت التنشيط إلى حالته الأولية (كما لو تم تلقي إدخال الجهاز).

يمكن لـ XForceScreenSaver إنشاء خطأ BadValue.

تقوم وظيفة XActivateScreenSaver بتنشيط موفر الشاشة.

تقوم وظيفة XResetScreenSaver بإعادة تعيين موفر الشاشة.

تقوم وظيفة XGetScreenSaver بجلب قيم موفر الشاشة الحالية.

التشخيصات

BadValue
قيمة رقمية ما تقع خارج نطاق القيم التي يقبلها الطلب. ما لم يتم تحديد نطاق معين لوسيط، يتم قبول النطاق الكامل الذي تحدده فئة الوسيط. يمكن لأي وسيط محدد كمجموعة من البدائل إنشاء هذا الخطأ.
