XRemoveHost(3)

الحزمة: libx11

التراخيص: MIT AND X11

XAddHost(3) وظائف XLIB XAddHost(3)

الاسم

XAddHost, XAddHosts, XListHosts, XRemoveHost, XRemoveHosts, XSetAccessControl, XEnableAccessControl, XDisableAccessControl, XHostAddress, XServerInterpretedAddress - التحكم في الوصول إلى المضيف وهيكل التحكم بالمضيف

الصيغة

int XAddHost(Display *display, XHostAddress *host);

int XAddHosts(Display *display, XHostAddress *hosts, int num_hosts);

XHostAddress *XListHosts(Display *display, int *nhosts_return, Bool *state_return);

int XRemoveHost(Display *display, XHostAddress *host);

int XRemoveHosts(Display *display, XHostAddress *hosts, int num_hosts);

int XSetAccessControl(Display *display, int mode);

int XEnableAccessControl(Display *display);

int XDisableAccessControl(Display *display);

الوسائط

display
يحدد الاتصال بخادم X.
host
يحدد المضيف الذي سيتم إضافته أو إزالته.
hosts
يحدد كل مضيف سيتم إضافته أو إزالته.
mode
يحدد الوضع. يمكنك تمرير EnableAccess أو DisableAccess.
nhosts_return
يعيد عدد المضيفين الموجودين حاليًا في قائمة التحكم بالوصول.
num_hosts
يحدد عدد المضيفين.
state_return
يعيد حالة التحكم بالوصول.

الوصف

تقوم الدالة XAddHost بإضافة المضيف المحدد إلى قائمة التحكم بالوصول لهذا العرض. يجب أن يكون الخادم على نفس المضيف الذي يقوم العميل بإصدار الأمر منه، وإلا فستكون النتيجة خطأ BadAccess.

يمكن لـ XAddHost إنشاء أخطاء BadAccess و BadValue.

تقوم الدالة XAddHosts بإضافة كل مضيف محدد إلى قائمة التحكم بالوصول لهذا العرض. يجب أن يكون الخادم على نفس المضيف الذي يقوم العميل بإصدار الأمر منه، وإلا فستكون النتيجة خطأ BadAccess.

يمكن لـ XAddHosts إنشاء أخطاء BadAccess و BadValue.

تقوم الدالة XListHosts بإعادة قائمة التحكم بالوصول الحالية بالإضافة إلى ما إذا كان استخدام القائمة عند إعداد الاتصال قد تم تمكينه أو تعطيله. تسمح XListHosts للبرنامج بمعرفة الآلات التي يمكنها إجراء اتصالات. كما أنها تعيد مؤشرًا إلى قائمة هياكل المضيف التي تم تخصيصها بواسطة الدالة. عند عدم الحاجة إليها، يجب تحرير هذه الذاكرة عن طريق استدعاء XFree.

تقوم الدالة XRemoveHost بإزالة المضيف المحدد من قائمة التحكم بالوصول لهذا العرض. يجب أن يكون الخادم على نفس المضيف الذي تقوم به العملية العميلة، وإلا فستكون النتيجة خطأ BadAccess. إذا قمت بإزالة جهازك من قائمة الوصول، فلن تتمكن من الاتصال بهذا الخادم بعد ذلك، ولا يمكن عكس هذه العملية ما لم تقم بإعادة تعيين الخادم.

يمكن لـ XRemoveHost إنشاء أخطاء BadAccess و BadValue.

تقوم الدالة XRemoveHosts بإزالة كل مضيف محدد من قائمة التحكم بالوصول لهذا العرض. يجب أن يكون خادم X على نفس المضيف الذي تقوم به العملية العميلة، وإلا فستكون النتيجة خطأ BadAccess. إذا قمت بإزالة جهازك من قائمة الوصول، فلن تتمكن من الاتصال بهذا الخادم بعد ذلك، ولا يمكن عكس هذه العملية ما لم تقم بإعادة تعيين الخادم.

يمكن لـ XRemoveHosts إنشاء أخطاء BadAccess و BadValue.

تقوم الدالة XSetAccessControl إما بتمكين أو تعطيل استخدام قائمة التحكم بالوصول عند كل إعداد اتصال.

يمكن لـ XSetAccessControl إنشاء أخطاء BadAccess و BadValue.

تقوم الدالة XEnableAccessControl بتمكين استخدام قائمة التحكم بالوصول عند كل إعداد اتصال.

يمكن لـ XEnableAccessControl إنشاء خطأ BadAccess.

تقوم الدالة XDisableAccessControl بتعطيل استخدام قائمة التحكم بالوصول عند كل إعداد اتصال.

يمكن لـ XDisableAccessControl إنشاء خطأ BadAccess.

الهياكل

هيكل XHostAddress يحتوي على:

typedef struct {
        int family;     /* مثال: FamilyInternet */
        int length;     /* طول العنوان بالبايت */
        char *address;  /* مؤشر إلى مكان العثور على العنوان */
} XHostAddress;

يحدد عضو العائلة أي عائلة عنوان بروتوكول سيتم استخدامها (على سبيل المثال، TCP/IP أو DECnet) ويمكن أن تكون FamilyInternet، FamilyInternet6، FamilyServerInterpreted، FamilyDECnet، أو FamilyChaos. يحدد عضو الطول طول العنوان بالبايت. يحدد عضو العنوان مؤشرًا إلى العنوان.

بالنسبة لعائلة ServerInterpreted، يتم تجاهل الطول ويشير عضو العنوان إلى هيكل XServerInterpretedAddress الذي يحتوي على:

typedef struct {
        int typelength;         /* طول سلسلة النوع، بالبايت */
        int valuelength;        /* طول سلسلة القيمة، بالبايت */
        char *type;             /* مؤشر إلى مكان العثور على سلسلة النوع */
        char *value;            /* مؤشر إلى مكان العثور على العنوان */
} XServerInterpretedAddress;

تشير أعضاء النوع والقيمة إلى سلاسل تمثل نوع وقيمة إدخال الخادم المفسر. قد لا تكون هذه السلاسل منتهية بصفر، لذا يجب توخي الحذر عند الوصول إليها. تحدد أعضاء typelength و valuelength الطول بالبايت لسلاسل النوع والقيمة.

التشخيصات

BadAccess
حاول عميل تعديل قائمة التحكم بالوصول من مضيف غير محلي (أو مرخص بطريقة أخرى).
BadValue
قيمة رقمية ما تقع خارج نطاق القيم التي يقبلها الطلب. ما لم يتم تحديد نطاق محدد لحجة، يتم قبول النطاق الكامل الذي تحدده نوع الحجة. أي حجة معرفة كمجموعة من البدائل يمكن أن تولد هذا الخطأ.
