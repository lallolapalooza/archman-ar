XtSessionReturnToken(3)

الحزمة: libxt

التراخيص: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtSessionGetToken(3) XT FUNCTIONS XtSessionGetToken(3)

اسم

XtSessionGetToken, XtSessionReturnToken - إدارة الرموز المميزة للفحص

الصيغة

#include <X11/Intrinsic.h>

XtCheckpointToken XtSessionGetToken(Widget w);

void XtSessionReturnToken(XtCheckpointToken token);

الوسائط

w
يحدد أداة الجلسة.
token
يحدد الرمز المميز المراد إرجاعه.

الوصف

ستعيد الدالة XtSessionGetToken القيمة NULL إذا لم تكن عملية الفحص التي بدأها مدير الجلسة قيد التنفيذ حاليًا.

للإشارة إلى اكتمال عملية حفظ مؤجلة وإرجاع رمز الفحص، استخدم XtSessionReturnToken.
