xtables-translate(8)

الحزمة: iptables-nft

التراخيص: GPL-2.0-only

IPTABLES-TRANSLATE(8) دليل مدير النظام IPTABLES-TRANSLATE(8)

الاسم

iptables-translate — أداة ترجمة للانتقال من iptables إلى nftables

ip6tables-translate — أداة ترجمة للانتقال من ip6tables إلى nftables

ebtables-translate — أداة ترجمة للانتقال من ebtables إلى nftables

arptables-translate — أداة ترجمة للانتقال من arptables إلى nftables

الوصف

هناك مجموعة من الأدوات لمساعدة مسؤول النظام على ترجمة مجموعة قواعد معينة من iptables(8)، ip6tables(8)، ebtables(8) و arptables(8) إلى nftables(8).

الأوامر المتاحة هي:

•
iptables-translate
•
iptables-restore-translate
•
ip6tables-translate
•
ip6tables-restore-translate
•
ebtables-translate
•
arptables-translate

الاستخدام

تأخذ كمدخلات بناء جملة iptables(8)/ip6tables(8)/ebtables(8)/arptables(8) الأصلية وتخرج بناء جملة nftables(8) الأصلي.

تقوم أداة iptables-restore-translate بقراءة مجموعة قواعد بالصيغة التي تنتجها iptables-save(8). وبالمثل، تقوم أداة ip6tables-restore-translate بقراءة مجموعة قواعد تنتجها ip6tables-save(8). لا تحدث أي تعديلات على مجموعة القواعد، هذه الأدوات هي محولات نصية فقط.

تقرأ أداة iptables-translate سطر أوامر كما لو تم إدخاله إلى iptables(8)، وتقرأ أداة ip6tables-translate أمراً كما لو تم إدخاله إلى ip6tables(8).

أمثلة

أمثلة على التشغيل الأساسي.

ترجمة أمر واحد:

root@machine:~# iptables-translate -A INPUT -p tcp --dport 22 -m conntrack --ctstate NEW -j ACCEPT
nft add rule ip filter INPUT tcp dport 22 ct state new counter accept
root@machine:~# ip6tables-translate -A FORWARD -i eth0 -o eth3 -p udp -m multiport --dports 111,222 -j ACCEPT
nft add rule ip6 filter FORWARD iifname eth0 oifname eth3 meta l4proto udp udp dport { 111,222} counter accept

ترجمة مجموعة قواعد كاملة:

root@machine:~# iptables-save > save.txt
root@machine:~# cat save.txt
# Generated by iptables-save v1.6.0 on Sat Dec 24 14:26:40 2016
*filter
:INPUT ACCEPT [5166:1752111]
:FORWARD ACCEPT [0:0]
:OUTPUT ACCEPT [5058:628693]
-A FORWARD -p tcp -m tcp --dport 22 -m conntrack --ctstate NEW -j ACCEPT
COMMIT
# Completed on Sat Dec 24 14:26:40 2016
root@machine:~# iptables-restore-translate -f save.txt
# Translated by iptables-restore-translate v1.6.0 on Sat Dec 24 14:26:59 2016
add table ip filter
add chain ip filter INPUT { type filter hook input priority 0; }
add chain ip filter FORWARD { type filter hook forward priority 0; }
add chain ip filter OUTPUT { type filter hook output priority 0; }
add rule ip filter FORWARD tcp dport 22 ct state new counter accept
root@machine:~# iptables-restore-translate -f save.txt > ruleset.nft
root@machine:~# nft -f ruleset.nft
root@machine:~# nft list ruleset
table ip filter {
	chain INPUT {
		type filter hook input priority 0; policy accept;
	}
	chain FORWARD {
		type filter hook forward priority 0; policy accept;
		tcp dport ssh ct state new counter packets 0 bytes 0 accept
	}
	chain OUTPUT {
		type filter hook output priority 0; policy accept;
	}
}

قيود

بعض (القليل من) الإضافات قد لا تكون مدعومة (أو مدعومة بالكامل) لأي سبب كان (على سبيل المثال، تم اعتبارها قديمة، أو لم يكن لدينا الوقت للعمل عليها).

لا يوجد ترجمة متاحة لـ arptables(8).

للحصول على معلومات محدثة حول هذا، يرجى التوجه إلى https://wiki.nftables.org/.
