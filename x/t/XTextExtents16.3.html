XTextExtents16(3)

الحزمة: libx11

التراخيص: MIT AND X11

XTextExtents(3) وظائف XLIB XTextExtents(3)

الاسم

XTextExtents, XTextExtents16, XQueryTextExtents, XQueryTextExtents16 - حساب أو الاستعلام عن امتدادات النص

الصيغة

int XTextExtents(XFontStruct *font_struct, _Xconst char *string, int nchars, int *direction_return, int *font_ascent_return, int *font_descent_return, XCharStruct *overall_return);

int XTextExtents16(XFontStruct *font_struct, _Xconst XChar2b *string, int nchars, int *direction_return, int *font_ascent_return, int *font_descent_return, XCharStruct *overall_return);

int XQueryTextExtents(Display *display, XID font_ID, _Xconst char *string, int nchars, int *direction_return, int *font_ascent_return, int *font_descent_return, XCharStruct *overall_return);

int XQueryTextExtents16(Display *display, XID font_ID, _Xconst XChar2b *string, int nchars, int *direction_return, int *font_ascent_return, int *font_descent_return, XCharStruct *overall_return);

الوسائط

direction_return
يُرجع قيمة تلميح الاتجاه (FontLeftToRight أو FontRightToLeft).
display
يحدد الاتصال بخادم X.
font_ID
يحدد إما معرف الخط أو معرف GContext الذي يحتوي على الخط.
font_ascent_return
يُرجع صعود الخط.
font_descent_return
يُرجع نزول الخط.
font_struct
يحدد بنية XFontStruct.
nchars
يحدد عدد الأحرف في سلسلة الأحرف.
string
يحدد سلسلة الأحرف.
overall_return
يُرجع الحجم الكلي في بنية XCharStruct المحددة.

الوصف

تقوم الدالتان XTextExtents و XTextExtents16 بإجراء حساب الحجم محليًا، وبالتالي تتجنبان التكلفة المزدوجة لـ XQueryTextExtents و XQueryTextExtents16. تُرجع كلتا الدالتين بنية XCharStruct، والتي يتم تعيين أعضائها إلى القيم التالية.

يتم تعيين عضو الصعود (ascent) إلى الحد الأقصى لمقاييس صعود جميع الأحرف في السلسلة. يتم تعيين عضو النزول (descent) إلى الحد الأقصى لمقاييس النزول. يتم تعيين عضو العرض (width) إلى مجموع مقاييس عرض الأحرف لجميع الأحرف في السلسلة. لكل حرف في السلسلة، ليكن W هو مجموع مقاييس عرض الأحرف لجميع الأحرف التي تسبقه في السلسلة. ليكن L هو مقياس الهامش الأيسر للحرف مضافًا إليه W. ليكن R هو مقياس الهامش الأيمن للحرف مضافًا إليه W. يتم تعيين lbearing إلى الحد الأدنى L لجميع الأحرف في السلسلة. يتم تعيين rbearing إلى الحد الأقصى R.

بالنسبة للخطوط المعرفة بفهرسة خطية بدلاً من الفهرسة المصفوفة ثنائية البايت، يتم تفسير كل بنية XChar2b كرقم 16 بت حيث يكون byte1 هو البايت الأكثر أهمية. إذا لم يكن للخط حرف افتراضي محدد، يتم اعتبار الأحرف غير المعرفة في السلسلة لها مقاييس صفرية بالكامل.

تقوم الدالتان XQueryTextExtents و XQueryTextExtents16 بإرجاع مربع الإحاطة لسلسلة الأحرف المحددة المكونة من 8 بت و 16 بت في الخط المحدد أو الخط الموجود في GC المحدد. تستعلم هاتان الدالتان خادم X، وبالتالي تعانيان من تكلفة الجولة المزدوجة التي تتجنبها XTextExtents و XTextExtents16. تُرجع كلتا الدالتين بنية XCharStruct، والتي يتم تعيين أعضائها إلى القيم التالية.

يتم تعيين عضو الصعود (ascent) إلى الحد الأقصى لمقاييس صعود جميع الأحرف في السلسلة. يتم تعيين عضو النزول (descent) إلى الحد الأقصى لمقاييس النزول. يتم تعيين عضو العرض (width) إلى مجموع مقاييس عرض الأحرف لجميع الأحرف في السلسلة. لكل حرف في السلسلة، ليكن W هو مجموع مقاييس عرض الأحرف لجميع الأحرف التي تسبقه في السلسلة. ليكن L هو مقياس الهامش الأيسر للحرف مضافًا إليه W. ليكن R هو مقياس الهامش الأيمن للحرف مضافًا إليه W. يتم تعيين lbearing إلى الحد الأدنى L لجميع الأحرف في السلسلة. يتم تعيين rbearing إلى الحد الأقصى R.

بالنسبة للخطوط المعرفة بفهرسة خطية بدلاً من الفهرسة المصفوفة ثنائية البايت، يتم تفسير كل بنية XChar2b كرقم 16 بت حيث يكون byte1 هو البايت الأكثر أهمية. إذا لم يكن للخط حرف افتراضي محدد، يتم اعتبار الأحرف غير المعرفة في السلسلة لها مقاييس صفرية بالكامل.

يتم تجاهل الأحرف ذات المقاييس الصفرية بالكامل. إذا لم يكن للخط حرف افتراضي محدد، يتم أيضًا تجاهل الأحرف غير المعرفة في السلسلة.

يمكن أن تولد XQueryTextExtents و XQueryTextExtents16 أخطاء BadFont و BadGC.

التشخيصات

قيمة وسيطة خط أو GContext لا تشير إلى خط معرف.
BadGC
قيمة وسيطة GContext لا تشير إلى GContext معرف.
