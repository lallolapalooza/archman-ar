XtAppInitialize(3)

الحزمة: libxt

التراخيص: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtAppInitialize(3) XT FUNCTIONS XtAppInitialize(3)

اسم

XtAppInitialize, XtVaAppInitialize - تهيئة، فتح، أو إغلاق عرض

الصيغة

#include <X11/Intrinsic.h>

Widget XtAppInitialize(XtAppContext* app_context_return, const char *application_class, XrmOptionDescRec* options, Cardinal num_options, int *argc_in_out, char **argv_in_out, String *fallback_resources, ArgList args, Cardinal num_args);

Widget XtVaAppInitialize(XtAppContext* app_context_return, const char *application_class, XrmOptionDescRec* options, Cardinal num_options, int *argc_in_out, char **argv_in_out, String *fallback_resources, ...);

المعاملات

app_context_return
يحدد سياق التطبيق.
application_class
يحدد اسم الفئة لهذا التطبيق، والذي عادة ما يكون الاسم العام لجميع نسخ هذا التطبيق.
options
يحدد كيفية تحليل سطر الأوامر لأي موارد خاصة بالتطبيق. يتم تمرير المعامل options كمعلمة لـ XrmParseCommand. لمزيد من المعلومات، راجع *Xlib - C Language X Interface*.
num_options
يحدد عدد الإدخالات في قائمة الخيارات.
argc_in_out
يحدد مؤشرًا لعدد معاملات سطر الأوامر.
argv_in_out
يحدد معاملات سطر الأوامر.
fallback_resources
يحدد قيم الموارد التي سيتم استخدامها إذا تعذر فتح ملف موارد فئة التطبيق أو قراءته، أو NULL.
args
يحدد قائمة المعاملات لتجاوز أي مواصفات مورد أخرى لعنصر واجهة المستخدم الرئيسي الذي تم إنشاؤه.
num_args
يحدد عدد الإدخالات في قائمة المعاملات.
...
يحدد قائمة المعاملات المتغيرة لتجاوز أي مواصفات مورد أخرى لعنصر واجهة المستخدم الرئيسي الذي تم إنشاؤه.

الوصف

تقوم الدالة XtAppInitialize باستدعاء XtToolkitInitialize متبوعة بـ XtCreateApplicationContext، ثم تستدعي XtOpenDisplay مع display_string NULL و application_name NULL، وأخيراً تستدعي XtAppCreateShell مع application_name NULL، و widget_class applicationShellWidgetClass، والمعاملات args و num_args المحددة وتعيد عنصر واجهة المستخدم الرئيسي الذي تم إنشاؤه. يتم إرجاع argc و argv المعدلين بواسطة XtDisplayInitialize في argc_in_out و argv_in_out. إذا لم يكن app_context_return NULL، يتم أيضًا إرجاع سياق التطبيق الذي تم إنشاؤه. إذا تعذر فتح العرض المحدد بواسطة سطر الأوامر، يتم إصدار رسالة خطأ وتقوم XtAppInitialize بإنهاء التطبيق. إذا كان fallback_resources غير NULL، يتم استدعاء XtAppSetFallbackResources بالقيمة قبل استدعاء XtOpenDisplay.

تم استبدال XtAppInitialize و XtVaAppInitialize بـ XtOpenApplication و XtVaOpenApplication على التوالي.
