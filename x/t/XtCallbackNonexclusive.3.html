XtCallbackNonexclusive(3)

الحزمة: libxt

التراخيص: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtPopup(3) XT FUNCTIONS XtPopup(3)

الاسم

XtPopup, XtPopupSpringLoaded, XtCallbackNone, XtCallbackNonexclusive, XtCallbackExclusive - عرض نافذة منبثقة

الصيغة

#include <X11/Intrinsic.h>

void XtPopup(Widget popup_shell, XtGrabKind grab_kind);

void XtPopupSpringLoaded(Widget popup_shell);

void XtCallbackNone(Widget w, XtPointer client_data, XtPointer call_data);

void XtCallbackNonexclusive(Widget w, XtPointer client_data, XtPointer call_data);

void XtCallbackExclusive(Widget w, XtPointer client_data, XtPointer call_data);

الإجراءات

void XtMenuPopup(String shell_name);

الوسائط

call_data
يحدد بيانات الاستدعاء، والتي لا تستخدمها هذه الإجراءات.
client_data
يحدد الـ shell المنبثق.
grab_kind
يحدد الطريقة التي يجب بها تقييد أحداث المستخدم.
popup_shell
يحدد الـ shell المطلوب عرضه.
w
يحدد الـ widget.

الوصف

تقوم الدالة XtPopup بما يلي:

  • تستدعي XtCheckSubclass للتأكد من أن popup_shell هو فئة فرعية من Shell.
  • تولد خطأ إذا كان حقل popped_up الخاص بالـ shell هو True بالفعل.
  • تستدعي إجراءات الاستدعاء في قائمة popup_callback الخاصة بالـ shell.
  • تضبط حقل popped_up الخاص بالـ shell إلى True، وحقل spring_loaded إلى False، وحقل grab_kind الخاص بالـ shell من grab_kind.
  • إذا كان حقل create_popup_child الخاص بالـ shell غير NULL، فإن XtPopup تقوم باستدعائه مع popup_shell كمعامل.
  • إذا كان grab_kind هو XtGrabNonexclusive أو XtGrabExclusive، فإنها تستدعي:
XtAddGrab(popup_shell, (grab_kind == XtGrabExclusive), False)
  • تستدعي XtRealizeWidget مع تحديد popup_shell.
  • تستدعي XMapWindow مع تحديد popup_shell.

تقوم الدالة XtPopupSpringLoaded بنفس وظيفة XtPopup تمامًا باستثناء أنها تضبط حقل spring_loaded الخاص بالـ shell إلى True وتستدعي دائمًا XtAddGrab مع exclusive True و spring_loaded True.

تقوم الدوال XtCallbackNone، XtCallbackNonexclusive، و XtCallbackExclusive باستدعاء XtPopup مع تحديد الـ shell بواسطة معامل بيانات العميل وتعيين grab_kind كما يحدد الاسم. تحدد XtCallbackNone، XtCallbackNonexclusive، و XtCallbackExclusive XtGrabNone، XtGrabNonexclusive، و XtGrabExclusive على التوالي. ثم تقوم كل دالة بجعل الـ widget الذي نفذ قائمة الاستدعاء غير حساس باستخدام XtSetSensitive. استخدام هذه الدوال في الاستدعاءات ليس إلزاميًا. على وجه الخصوص، يجب على التطبيق توفير رمز مخصص للاستدعاءات التي تنشئ نوافذ منبثقة ديناميكيًا أو التي تحتاج إلى القيام بأكثر من إلغاء تنشيط الزر.

XtMenuPopup معروفة لمدير الترجمة، والذي يجب عليه تنفيذ إجراءات خاصة للنوافذ المنبثقة ذات التحميل الزنبركي. تتم ترجمة استدعاءات XtMenuPopup في مواصفات الترجمة إلى استدعاءات لإجراء غير مُصدَّر، ويقوم مدير الترجمة بملء المعاملات بناءً على الحدث المحدد على الجانب الأيسر من الترجمة.

إذا تم استدعاء XtMenuPopup عند ButtonPress (ربما مع معدلات)، فإن مدير الترجمة يعرض الـ shell مع تعيين grab_kind إلى XtGrabExclusive و spring_loaded إلى True. إذا تم استدعاء XtMenuPopup عند EnterWindow (ربما مع معدلات)، فإن مدير الترجمة يعرض الـ shell مع تعيين grab_kind إلى XtGrabNonexclusive و spring_loaded إلى False. خلاف ذلك، يقوم مدير الترجمة بتوليد خطأ. عند عرض الـ widget، تحدث الإجراءات التالية:

  • تستدعي XtCheckSubclass للتأكد من أن popup_shell هو فئة فرعية من Shell.
  • تولد خطأ إذا كان حقل popped_up الخاص بالـ shell هو True بالفعل.
  • تستدعي إجراءات الاستدعاء في قائمة popup_callback الخاصة بالـ shell.
  • تضبط حقل popped_up الخاص بالـ shell إلى True وحقول grab_kind و spring_loaded الخاصة بالـ shell بشكل مناسب.
  • إذا كان حقل create_popup_child الخاص بالـ shell غير NULL، يتم استدعاؤه مع popup_shell كمعامل.
  • تستدعي:
XtAddGrab(popup_shell, (grab_kind == XtGrabExclusive), spring_loaded)
  • تستدعي XtRealizeWidget مع تحديد popup_shell.
  • تستدعي XMapWindow مع تحديد popup_shell.

(لاحظ أن هذه الإجراءات هي نفسها تلك الخاصة بـ XtPopup.) تحاول XtMenuPopup العثور على الـ shell عن طريق البحث في شجرة الـ widget بدءًا من الوالد للـ widget الذي تم استدعاؤها فيه. إذا وجدت shell بالاسم المحدد في الأطفال المنبثقين لذلك الوالد، فإنها تعرض الـ shell بالمعاملات المناسبة. بخلاف ذلك، تتحرك لأعلى سلسلة الوالدين حسب الحاجة. إذا وصلت XtMenuPopup إلى الـ widget التطبيق ولا يمكنها العثور على shell مطابق، فإنها تولد خطأ.
