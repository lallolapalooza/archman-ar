XtLastTimestampProcessed(3)

الحزمة: libxt

التراخيص: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtLastEventProcessed(3) XT FUNCTIONS XtLastEventProcessed(3)

اسم

XtLastEventProcessed, XtLastTimestampProcessed - آخر حدث، آخر طابع زمني تمت معالجته

الصيغة

#include <X11/Intrinsic.h>

XEvent* XtLastEventProcessed(Display* display);

Time XtLastTimestampProcessed(Display* display);

الوسائط

display
يحدد اتصال العرض المفتوح.

الوصف

XtLastEventProcessed تُرجع آخر حدث تم تمريره إلى XtDispatchEvent لاتصال العرض المحدد و NULL إذا لم يكن هناك أي حدث. يجب ألا يعدل العميل محتويات الحدث المُرجع.

XtLastTimestampProcessed تُرجع الطابع الزمني لآخر حدث KeyPress أو KeyRelease أو ButtonPress أو ButtonRelease أو MotionNotify أو EnterNotify أو LeaveNotify أو PropertyNotify أو SelectionClear تم تمريره إلى XtDispatchEvent لاتصال العرض المحدد وصفر إذا لم يكن هناك أي حدث من هذا القبيل.
