XtWindowOfObject(3)

الحزمة: libxt

التراخيص: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtDisplay(3) وظائف XT XtDisplay(3)

الاسم

XtDisplay, XtDisplayOfObject, XtScreen, XtScreenOfObject, XtWindow, XtWindowOfObject - الحصول على معلومات النافذة لعنصر واجهة المستخدم الرسومي

الصيغة

#include <X11/Intrinsic.h>

Display *XtDisplay(Widget w);

Display *XtDisplayOfObject(Widget object);

Screen *XtScreen(Widget w);

Screen *XtScreenOfObject(Widget object);

Window XtWindow(Widget w);

Window XtWindowOfObject(Widget object);

الوسائط

w
يحدد عنصر واجهة المستخدم الرسومي.
object
يحدد عنصر واجهة المستخدم الرسومي.

الوصف

XtDisplay تُرجع مؤشر العرض لعنصر واجهة المستخدم الرسومي المحدد.

XtDisplayOfObject تُرجع مؤشر العرض للكائن المحدد.

XtScreen تُرجع مؤشر الشاشة لعنصر واجهة المستخدم الرسومي المحدد.

XtScreenOfObject تُرجع مؤشر الشاشة للكائن المحدد.

XtWindow تُرجع النافذة لعنصر واجهة المستخدم الرسومي المحدد.

XtWindowOfObject تُرجع النافذة للكائن المحدد.
