XtUngrabKeyboard(3)

الحزمة: libxt

التراخيص: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtGrabKey(3) XT FUNCTIONS XtGrabKey(3)

الاسم

XtGrabKey, XtUngrabKey, XtGrabKeyboard, XtUngrabKeyboard, XtGrabButton, XtUngrabButton, XtGrabPointer, XtUngrabPointer - إدارة الالتقاطات (grabs)

الصيغة

#include <X11/Intrinsic.h>

void XtGrabKey(Widget widget, KeyCode keycode, Modifiers modifiers, Boolean owner_events, int pointer_mode, int keyboard_mode);

void XtUngrabKey(Widget widget, KeyCode keycode, Modifiers modifiers);

int XtGrabKeyboard(Widget widget, Boolean owner_events, int pointer_mode, int keyboard_mode, Time time);

void XtUngrabKeyboard(Widget widget, Time time);

void XtGrabButton(Widget widget, int button, Modifiers modifiers, Boolean owner_events, unsigned int event_mask, int pointer_mode, int keyboard_mode, Window confine_to, Cursor cursor);

void XtUngrabButton(Widget widget, unsigned button, Modifiers modifiers);

int XtGrabPointer(Widget widget, Boolean owner_events, unsigned int event_mask, int pointer_mode, int keyboard_mode, Window confine_to, Cursor cursor, Time time);

void XtUngrabPointer(Widget widget, Time time);

الوصف

XtGrabKey يستدعي XGrabKey محددًا النافذة الخاصة بالأداة كـ نافذة الالتقاط إذا تم تحقيق الأداة. المعطيات المتبقية هي نفسها كما في XGrabKey. إذا لم يتم تحقيق الأداة، أو تم إلغاء تحقيقها لاحقًا، فسيتم استدعاء XGrabKey (مرة أخرى) عند تحقيق الأداة وتعيين نافذتها. في المستقبل، إذا تم استدعاء XtDispatchEvent مع حدث KeyPress يتطابق مع رمز المفتاح والمعدلات المحددة (والتي قد تكون AnyKey أو AnyModifier، على التوالي) لنافذة الأداة، فستقوم Intrinsics باستدعاء XtUngrabKeyboard مع الطابع الزمني من حدث KeyPress إذا كان أي من الشروط التالية صحيحًا:

  • هناك تداعي نمطي (modal cascade) والأداة ليست ضمن المجموعة النشطة للتداعي ولم يتم التقاط لوحة المفاتيح مسبقًا، أو
  • XFilterEvent يعيد True.

XtUngrabKey يستدعي XUngrabKey محددًا النافذة الخاصة بالأداة كنافذة إلغاء الالتقاط إذا تم تحقيق الأداة. المعطيات المتبقية هي نفسها كما في XUngrabKey. إذا لم يتم تحقيق الأداة، فإن XtUngrabKey يزيل طلب XtGrabKey المؤجل، إن وجد، للأداة المحددة ورمز المفتاح والمعدلات.

إذا تم تحقيق الأداة المحددة، فإن XtGrabKeyboard يستدعي XGrabKeyboard محددًا النافذة الخاصة بالأداة كنافذة الالتقاط. المعطيات المتبقية والقيمة المرجعة هي نفسها كما في XGrabKeyboard. إذا لم يتم تحقيق الأداة، فإن XtGrabKeyboard يعيد فورًا GrabNotViewable. لا يوجد إلغاء التقاط مستقبلي ضمني بواسطة XtGrabKeyboard.

XtUngrabKeyboard يستدعي XUngrabKeyboard بالوقت المحدد.

XtGrabButton يستدعي XGrabButton محددًا النافذة الخاصة بالأداة كنافذة الالتقاط إذا تم تحقيق الأداة. المعطيات المتبقية هي نفسها كما في XGrabButton. إذا لم يتم تحقيق الأداة، أو تم إلغاء تحقيقها لاحقًا، فسيتم استدعاء XGrabButton (مرة أخرى) عند تحقيق الأداة وتعيين نافذتها. في المستقبل، إذا تم استدعاء XtDispatchEvent مع حدث ButtonPress يتطابق مع الزر والمعدلات المحددة (والتي قد تكون AnyButton أو AnyModifier، على التوالي) لنافذة الأداة، فستقوم Intrinsics باستدعاء XtUngrabPointer مع الطابع الزمني من حدث ButtonPress إذا كان أي من الشروط التالية صحيحًا:

  • هناك تداعي نمطي (modal cascade) والأداة ليست ضمن المجموعة النشطة للتداعي ولم يتم التقاط المؤشر مسبقًا، أو
  • XFilterEvent يعيد True.

XtUngrabButton يستدعي XUngrabButton محددًا النافذة الخاصة بالأداة كنافذة إلغاء الالتقاط إذا تم تحقيق الأداة. المعطيات المتبقية هي نفسها كما في XUngrabButton. إذا لم يتم تحقيق الأداة، فإن XtUngrabButton يزيل طلب XtGrabButton المؤجل، إن وجد، للأداة المحددة والزر والمعدلات.

XtGrabPointer يستدعي XGrabPointer محددًا النافذة الخاصة بالأداة كنافذة الالتقاط. المعطيات المتبقية والقيمة المرجعة هي نفسها كما في XGrabPointer. إذا لم يتم تحقيق الأداة، فإن XtGrabPointer يعيد فورًا GrabNotViewable. لا يوجد إلغاء التقاط مستقبلي ضمني بواسطة XtGrabPointer.

XtUngrabPointer يستدعي XUngrabPointer بالوقت المحدد.
