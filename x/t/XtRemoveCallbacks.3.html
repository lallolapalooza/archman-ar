XtRemoveCallbacks(3)

الحزمة: libxt

التراخيص: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtAddCallback(3) XT FUNCTIONS XtAddCallback(3)

الاسم

XtAddCallback, XtAddCallbacks, XtRemoveCallback, XtRemoveCallbacks, XtRemoveAllCallbacks - إضافة وإزالة إجراءات الاستدعاء

الصيغة

#include <X11/Intrinsic.h>

void XtAddCallback(Widget w, const char *callback_name, XtCallbackProc callback, XtPointer client_data);

void XtAddCallbacks(Widget w, const char *callback_name, XtCallbackList callbacks);

void XtRemoveCallback(Widget w, const char *callback_name, XtCallbackProc callback, XtPointer client_data);

void XtRemoveCallbacks(Widget w, const char *callback_name, XtCallbackList callbacks);

void XtRemoveAllCallbacks(Widget w, const char *callback_name);

المعاملات

callback
يحدد إجراء الاستدعاء.
callbacks
يحدد قائمة إجراءات الاستدعاء المختومة بصفر وبيانات العميل المقابلة.
callback_name
يحدد قائمة الاستدعاء التي سيتم إلحاق الإجراء بها أو حذفها منها.
client_data
يحدد الوسيط الذي سيتم تمريره إلى الإجراء المحدد عند استدعائه بواسطة XtCallbacks أو NULL، أو بيانات العميل للمطابقة على إجراءات الاستدعاء المسجلة.
w
يحدد الأداة.

الوصف

تقوم الدالة XtAddCallback بإضافة إجراء الاستدعاء المحدد إلى قائمة استدعاء الأداة المحددة.

تقوم الدالة XtAddCallbacks بإضافة قائمة الاستدعاءات المحددة إلى قائمة استدعاء الأداة المحددة.

تقوم الدالة XtRemoveCallback بإزالة استدعاء فقط إذا تطابق كل من الإجراء وبيانات العميل.

تقوم الدالة XtRemoveCallbacks بإزالة إجراءات الاستدعاء المحددة من قائمة استدعاء الأداة المحددة.

تقوم الدالة XtRemoveAllCallbacks بإزالة جميع إجراءات الاستدعاء من قائمة استدعاء الأداة المحددة.
