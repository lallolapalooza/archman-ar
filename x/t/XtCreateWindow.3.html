XtCreateWindow(3)

الحزمة: libxt

التراخيص: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtCreateWindow(3) XT FUNCTIONS XtCreateWindow(3)

الاسم

XtCreateWindow - دالة مساعدة لإنشاء النافذة

الصيغة

#include <X11/Intrinsic.h>

void XtCreateWindow(Widget w, unsigned int window_class, Visual *visual, XtValueMask value_mask, XSetWindowAttributes *attributes);

المعاملات

attributes
يحدد سمات النافذة المراد استخدامها في استدعاء XCreateWindow.
value_mask
يحدد حقول السمات التي سيتم استخدامها.
visual
يحدد نوع العرض (عادةً CopyFromParent).
w
يحدد الـ Widget المستخدم لتعيين إحداثيات x,y وما إلى ذلك.
window_class
يحدد فئة نافذة Xlib (على سبيل المثال، InputOutput، InputOnly، أو CopyFromParent).

الوصف

تستدعي الدالة XtCreateWindow الدالة XCreateWindow من Xlib مع قيم من بنية الـ Widget والمعاملات الممررة. ثم، تقوم بتعيين النافذة المنشأة إلى حقل نافذة الـ Widget.

تقوم XtCreateWindow بتقييم الحقول التالية من بنية Core للـ Widget:

  • depth
  • screen
  • parent -> core.window
  • x
  • y
  • width
  • height
  • border_width
