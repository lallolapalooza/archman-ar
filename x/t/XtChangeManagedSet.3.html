الاسم

XtChangeManagedSet - لتغيير المجموعات المُدارة

الصيغة

```c void XtChangeManagedSet( Widget widget, ... /* XtWidgetGeometry *request */ ); ```

المعاملات

widget

يحدد الـ widget الذي يتم التعامل معه.

...

قائمة ذات طول صفري تنتهي بنقطتين (NULL) تحدد مجموعة الـ widgets التي سيتم إدارتها أو إلغاء إدارتها.

الوصف

تقوم الدالة XtChangeManagedSet بتغيير مجموعة الـ widgets المُدارة بواسطة الـ widget المحدد. يتم تمرير قائمة ذات طول صفري تنتهي بنقطتين (NULL) تحتوي على هياكل XtWidgetGeometry إلى الدالة. كل هيكل XtWidgetGeometry يمثل طلبًا لتغيير حالة إدارة الـ widget المرتبط به.

يتم تعيين الحقل request_mode في هيكل XtWidgetGeometry لتحديد نوع التغيير المطلوب:

  • XtSetManaged: لإدارة الـ widget.
  • XtUnsetManaged: لإلغاء إدارة الـ widget.

إذا كان الحقل widget في هيكل XtWidgetGeometry يساوي NULL، فهذا يشير إلى نهاية القائمة.
