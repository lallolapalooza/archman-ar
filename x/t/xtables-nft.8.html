xtables-nft(8)

الحزمة: iptables

التراخيص: GPL-2.0-only

XTABLES-NFT(8) دليل مدير النظام XTABLES-NFT(8)

الاسم

xtables-nft — iptables باستخدام واجهة برمجة تطبيقات nftables الأساسية

الوصف

xtables-nft هي إصدارات من iptables تستخدم واجهة برمجة تطبيقات nftables. هذه مجموعة من الأدوات لمساعدة مسؤول النظام على ترحيل مجموعة القواعد من iptables(8)، ip6tables(8)، arptables(8)، و ebtables(8) إلى nftables(8).

مجموعة xtables-nft تتكون من عدة أوامر:

•
iptables-nft
•
iptables-nft-save
•
iptables-nft-restore
•
ip6tables-nft
•
ip6tables-nft-save
•
ip6tables-nft-restore
•
arptables-nft
•
ebtables-nft

تستخدم هذه الأدوات امتدادات إطار عمل libxtables وترتبط بنظام nft_compat الفرعي لنواة nf_tables.

الاستخدام

تسمح لك أدوات xtables-nft بإدارة الواجهة الخلفية لـ nf_tables باستخدام الصيغة الأصلية لأدوات iptables(8)، ip6tables(8)، arptables(8)، و ebtables(8).

يجب عليك استخدام أدوات xtables-nft بنفس الطريقة التي تستخدم بها الأدوات الأصلية المقابلة.

سيؤدي إضافة قاعدة إلى إضافتها إلى نظام nf_tables الفرعي للنواة بدلاً من ذلك. سرد مجموعة القواعد سيستخدم الواجهة الخلفية لـ nf_tables أيضًا.

عند تصميم هذه الأدوات، كانت الفكرة الرئيسية هي استبدال كل ملف ثنائي قديم برابط رمزي لبرنامج xtables-nft، على سبيل المثال:

/sbin/iptables -> /usr/sbin/iptables-nft-multi
/sbin/ip6tables -> /usr/sbin/ip6tables-nft-multi
/sbin/arptables -> /usr/sbin/arptables-nft-multi
/sbin/ebtables -> /usr/sbin/ebtables-nft-multi

سيوضح إصدار iptables ما إذا كانت واجهة برمجة التطبيقات القديمة (get/setsockopt) أو واجهة برمجة التطبيقات الجديدة nf_tables هي المستخدمة:

iptables -V
iptables v1.7 (nf_tables)

الاختلافات عن iptables القديمة

نظرًا لأن أدوات xtables-nft تستخدم واجهة برمجة تطبيقات nf_tables للنواة، فإن إضافة وحذف القواعد يكون دائمًا ذرية. على عكس iptables-legacy، فإن iptables-nft -A .. لن تحتاج إلى استرداد مجموعة القواعد الحالية من النواة، وتغييرها، وإعادة تحميل مجموعة القواعد المعدلة. بدلاً من ذلك، ستخبر iptables-nft النواة بإضافة قاعدة واحدة. لهذا السبب، فإن خيار --wait في iptables-legacy هو no-op في iptables-nft.

يتيح استخدام أدوات xtables-nft مراقبة تغييرات مجموعة القواعد باستخدام الأمر xtables-monitor(8).

عند استخدام -j TRACE لتصحيح عبور الحزم إلى مجموعة القواعد، لاحظ أنك ستحتاج إلى استخدام xtables-monitor(8) في وضع --trace للحصول على أحداث تتبع المراقبة.

أمثلة

أحد الأمثلة الأساسية هو إنشاء مجموعة القواعد الهيكلية في nf_tables من أدوات xtables-nft، على جهاز جديد:

root@machine:~# iptables-nft -L
[...]
root@machine:~# ip6tables-nft -L
[...]
root@machine:~# arptables-nft -L
[...]
root@machine:~# ebtables-nft -L
[...]
root@machine:~# nft list ruleset
table ip filter {
	chain INPUT {
		type filter hook input priority 0; policy accept;
	}
	chain FORWARD {
		type filter hook forward priority 0; policy accept;
	}
	chain OUTPUT {
		type filter hook output priority 0; policy accept;
	}
}
table ip6 filter {
	chain INPUT {
		type filter hook input priority 0; policy accept;
	}
	chain FORWARD {
		type filter hook forward priority 0; policy accept;
	}
	chain OUTPUT {
		type filter hook output priority 0; policy accept;
	}
}
table bridge filter {
	chain INPUT {
		type filter hook input priority -200; policy accept;
	}
	chain FORWARD {
		type filter hook forward priority -200; policy accept;
	}
	chain OUTPUT {
		type filter hook output priority -200; policy accept;
	}
}
table arp filter {
	chain INPUT {
		type filter hook input priority 0; policy accept;
	}
	chain FORWARD {
		type filter hook forward priority 0; policy accept;
	}
	chain OUTPUT {
		type filter hook output priority 0; policy accept;
	}
}

(يرجى ملاحظة أنه في الأجهزة الجديدة، يؤدي سرد مجموعة القواعد للمرة الأولى إلى إنشاء جميع الجداول والسلاسل).

لترحيل مجموعة قواعد التصفية الكاملة الخاصة بك، في حالة iptables(8)، ستستخدم:

root@machine:~# iptables-legacy-save > myruleset # يقرأ من x_tables
root@machine:~# iptables-nft-restore myruleset   # يكتب إلى nf_tables
أو 
root@machine:~# iptables-legacy-save | iptables-translate-restore | less

لرؤية كيف ستبدو القواعد في صيغة nft nft(8).

قيود

يجب عليك استخدام نواة لينكس >= 4.17.

الهدف CLUSTERIP غير مدعوم.

للحصول على معلومات محدثة حول هذا، يرجى التوجه إلى http://wiki.nftables.org/.

انظر أيضًا

nft(8), xtables-translate(8), xtables-monitor(8)
