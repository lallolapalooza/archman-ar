XtAppSetWarningHandler(3)

الحزمة: libxt

التراخيص: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtAppError(3) XT FUNCTIONS XtAppError(3)

الاسم

XtAppError, XtAppSetErrorHandler, XtAppSetWarningHandler, XtAppWarning - معالجات الأخطاء منخفضة المستوى

الصيغة

#include <X11/Intrinsic.h>

_X_NORETURN void XtAppError(XtAppContext app_context, const char *message);

XtErrorHandler XtAppSetErrorHandler(XtAppContext app_context, _X_NORETURN XtErrorHandler handler);

XtErrorHandler XtAppSetWarningHandler(XtAppContext app_context, XtErrorHandler handler);

void XtAppWarning(XtAppContext app_context, const char *message);

المعاملات

app_context
يحدد سياق التطبيق.
message
يحدد رسالة الخطأ غير الفادح التي سيتم الإبلاغ عنها.
handler
يحدد الإجراء الجديد لخطأ فادح، والذي لا يجب أن يعود، أو إجراء خطأ غير فادح، والذي يعود عادةً.
message
يحدد الرسالة التي سيتم الإبلاغ عنها.

الوصف

الدالة XtAppError تستدعي إجراء الخطأ المثبت وتمرر الرسالة المحددة.

الدالة XtAppSetErrorHandler تسجل الإجراء المحدد، والذي يتم استدعاؤه عند حدوث حالة خطأ فادحة.

الدالة XtAppSetWarningHandler تسجل الإجراء المحدد، والذي يتم استدعاؤه عند حدوث حالة خطأ غير فادحة.

الدالة XtAppWarning تستدعي إجراء الخطأ غير الفادح المثبت وتمرر الرسالة المحددة.
