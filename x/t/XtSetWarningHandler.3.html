XtSetWarningHandler(3)

الحزمة: libxt

التراخيص: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtError(3) وظائف التوافق XT XtError(3)

الاسم

XtError, XtSetErrorHandler, XtSetWarningHandler, XtWarning - معالجات الأخطاء منخفضة المستوى

الصيغة

#include <X11/Intrinsic.h>

_X_NORETURN void XtError(const char *message);

void XtSetErrorHandler(_X_NORETURN XtErrorHandler handler);

void XtSetWarningHandler(XtErrorHandler handler);

void XtWarning(const char *message);

الوسائط

message
يحدد رسالة الخطأ غير الفادح التي يجب الإبلاغ عنها.
handler
يحدد إجراء الخطأ الفادح الجديد، والذي لا يجب أن يعود، أو إجراء الخطأ غير الفادح، والذي يعود عادةً.
message
يحدد الرسالة التي يجب الإبلاغ عنها.

الوصف

تم استبدال الدالة XtError بـ XtAppError.

تم استبدال الدالة XtSetErrorHandler بـ XtAppSetErrorHandler.

تم استبدال الدالة XtSetWarningHandler بـ XtAppSetWarningHandler.

تم استبدال الدالة XtWarning بـ XtAppWarning.
