XTextWidth16(3)

الحزمة: libx11

التراخيص: MIT AND X11

XTextWidth(3) وظائف XLIB XTextWidth(3)

الاسم

XTextWidth, XTextWidth16 - حساب عرض النص

الصيغة

int XTextWidth(XFontStruct *font_struct, _Xconst char *string, int count);

int XTextWidth16(XFontStruct *font_struct, _Xconst XChar2b *string, int count);

المعاملات

count
يحدد عدد الأحرف في السلسلة المحددة.
font_struct
يحدد الخط المستخدم لحساب العرض.
string
يحدد سلسلة الأحرف.

الوصف

تعيد الدالتان XTextWidth و XTextWidth16 عرض سلاسل الأحرف المكونة من 8 بت أو 2 بايت المحددة.
