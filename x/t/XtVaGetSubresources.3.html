XtVaGetSubresources(3)

الحزمة: libxt

التراخيص: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtGetSubresources(3) XT FUNCTIONS XtGetSubresources(3)

الاسم

XtGetSubresources, XtVaGetSubresources - الحصول على الموارد الفرعية

الصيغة

#include <X11/Intrinsic.h>

void XtGetSubresources(Widget w, XtPointer base, const char *name, const char * class, XtResourceList resources, Cardinal num_resources, ArgList args, Cardinal num_args);

void XtVaGetSubresources(Widget w, XtPointer base, const char *name, const char *class, XtResourceList resources, Cardinal num_resources, ...);

المعاملات

args
تحدد قائمة الوسائط لتجاوز الموارد التي تم الحصول عليها من قاعدة بيانات الموارد.
base
تحدد عنوان الأساس لهيكل بيانات الجزء الفرعي حيث يجب كتابة الموارد.
class
تحدد فئة الجزء الفرعي.
name
تحدد اسم الجزء الفرعي.
num_args
تحدد عدد الوسائط في قائمة الوسائط.
num_resources
تحدد عدد الموارد في قائمة الموارد.
resources
تحدد قائمة الموارد للجزء الفرعي.
w
تحدد الأداة (widget) التي تريد موارد لجزء فرعي أو التي تحدد قاعدة بيانات الموارد للبحث فيها.
...
تحدد الوسائط المتغيرة لتجاوز الموارد التي تم الحصول عليها من قاعدة بيانات الموارد.

الوصف

تقوم الدالة XtGetSubresources ببناء قائمة اسم/فئة من اسم التطبيق/فئته، وأسماء/فئات جميع أسلافه، والأداة نفسها. ثم، تضيف إلى هذه القائمة زوج الاسم/الفئة الممرر. يتم جلب الموارد من قائمة الوسائط، أو قاعدة بيانات الموارد، أو القيم الافتراضية في قائمة الموارد. ثم يتم نسخها إلى سجل الجزء الفرعي. إذا كانت args هي NULL، فيجب أن يكون num_args صفرًا. ومع ذلك، إذا كان num_args صفرًا، فلن يتم الرجوع إلى قائمة الوسائط.
