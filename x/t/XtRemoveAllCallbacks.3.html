XtRemoveAllCallbacks(3)

الحزمة: libxt

التراخيص: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtAddCallback(3) وظائف XT XtAddCallback(3)

الاسم

XtAddCallback, XtAddCallbacks, XtRemoveCallback, XtRemoveCallbacks, XtRemoveAllCallbacks - إضافة وإزالة إجراءات رد الاتصال

الصيغة

#include <X11/Intrinsic.h>

void XtAddCallback(Widget w, const char *callback_name, XtCallbackProc callback, XtPointer client_data);

void XtAddCallbacks(Widget w, const char *callback_name, XtCallbackList callbacks);

void XtRemoveCallback(Widget w, const char *callback_name, XtCallbackProc callback, XtPointer client_data);

void XtRemoveCallbacks(Widget w, const char *callback_name, XtCallbackList callbacks);

void XtRemoveAllCallbacks(Widget w, const char *callback_name);

الوسائط

callback
يحدد إجراء رد الاتصال.
callbacks
يحدد قائمة إجراءات رد الاتصال المتصلة بـ NULL والبيانات العميل المقابلة.
callback_name
يحدد قائمة رد الاتصال التي سيتم إلحاق الإجراء بها أو حذفها منها.
client_data
يحدد الوسيط الذي سيتم تمريره إلى الإجراء المحدد عند استدعائه بواسطة XtCallbacks أو NULL، أو بيانات العميل للمطابقة على إجراءات رد الاتصال المسجلة.
w
يحدد الأداة.

الوصف

تقوم الدالة XtAddCallback بإضافة إجراء رد الاتصال المحدد إلى قائمة ردود الاتصال الخاصة بالأداة المحددة.

تقوم الدالة XtAddCallbacks بإضافة قائمة ردود الاتصال المحددة إلى قائمة ردود الاتصال الخاصة بالأداة المحددة.

تقوم الدالة XtRemoveCallback بإزالة رد اتصال فقط إذا تطابق الإجراء وبيانات العميل.

تقوم الدالة XtRemoveCallbacks بإزالة إجراءات رد الاتصال المحددة من قائمة ردود الاتصال الخاصة بالأداة المحددة.

تقوم الدالة XtRemoveAllCallbacks بإزالة جميع إجراءات رد الاتصال من قائمة ردود الاتصال الخاصة بالأداة المحددة.
