XtAppSetWarningMsgHandler(3)

الحزمة: libxt

التراخيص: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtAppErrorMsg(3) XT FUNCTIONS XtAppErrorMsg(3)

اسم

XtAppErrorMsg, XtAppSetErrorMsgHandler, XtAppSetWarningMsgHandler, XtAppWarningMsg - معالجات الأخطاء عالية المستوى

صيغة

#include <X11/Intrinsic.h>

_X_NORETURN void XtAppErrorMsg(XtAppContext app_context, const char *name, const char *type, const char *class, const char *defaultMsg, String *params, Cardinal *num_params);

XtErrorMsgHandler XtAppSetErrorMsgHandler(XtAppContext app_context, _X_NORETURN XtErrorMsgHandler msg_handler);

XtErrorMsgHandler XtAppSetWarningMsgHandler(XtAppContext app_context, XtErrorMsgHandler msg_handler);

void XtAppWarningMsg(XtAppContext app_context, const char *name, const char *type, const char *class, const char *defaultMsg, String *params, Cardinal *num_params);

وسيطات

app_context
يحدد سياق التطبيق.
class
يحدد فئة المورد لرسالة الخطأ.
defaultMsg
يحدد الرسالة الافتراضية المراد استخدامها.
name
يحدد النوع العام للخطأ.
type
يحدد الاسم التفصيلي للخطأ.
msg_handler
يحدد الإجراء المحدد للخطأ الفادح، والذي يجب ألا يعود، أو الإجراء المحدد للخطأ غير الفادح، والذي يعود عادةً.
num_params
يحدد عدد القيم في قائمة المعلمات.
params
يحدد مؤشرًا إلى قائمة القيم التي سيتم تخزينها في الرسالة.

وصف

تقوم الدالة XtAppErrorMsg باستدعاء معالج الأخطاء عالي المستوى وتمرير المعلومات المحددة.

تقوم الدالة XtAppSetErrorMsgHandler بتسجيل الإجراء المحدد، والذي يتم استدعاؤه عند حدوث خطأ فادح.

تقوم الدالة XtAppSetWarningMsgHandler بتسجيل الإجراء المحدد، والذي يتم استدعاؤه عند حدوث حالة خطأ غير فادحة.

تقوم الدالة XtAppWarningMsg باستدعاء معالج الأخطاء عالي المستوى وتمرير المعلومات المحددة.
