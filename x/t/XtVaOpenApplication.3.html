XtVaOpenApplication(3)

الحزمة: libxt

التراخيص: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtOpenApplication(3) XT FUNCTIONS XtOpenApplication(3)

الاسم

XtOpenApplication, XtVaOpenApplication - تهيئة، فتح، أو إغلاق شاشة عرض

الصيغة

#include <X11/Intrinsic.h>

Widget XtOpenApplication(XtAppContext *app_context_return, const char *application_class, XrmOptionDescRec *options, Cardinal num_options, int *argc_in_out, char **argv_in_out, String *fallback_resources, WidgetClass widget_class, ArgList args, Cardinal num_args);

Widget XtVaOpenApplication(XtAppContext *app_context_return, const char *application_class, XrmOptionDescRec *options, Cardinal num_options, int *argc_in_out, char **argv_in_out, String *fallback_resources, WidgetClass widget_class, ...);

المعاملات

app_context_return
يحدد سياق التطبيق.
application_class
يحدد اسم الفئة لهذا التطبيق، والذي عادة ما يكون الاسم العام لجميع مثيلات هذا التطبيق.
options
يحدد كيفية تحليل سطر الأوامر لأي موارد خاصة بالتطبيق. يتم تمرير المعامل options كمعامل لـ XrmParseCommand. لمزيد من المعلومات، راجع Xlib - C Language X Interface.
num_options
يحدد عدد الإدخالات في قائمة الخيارات.
argc_in_out
يحدد مؤشرًا لعدد معاملات سطر الأوامر.
argv_in_out
يحدد معاملات سطر الأوامر.
fallback_resources
يحدد قيم الموارد التي سيتم استخدامها إذا تعذر فتح ملف موارد فئة التطبيق أو قراءته، أو NULL.
widget_class
يحدد فئة الأداة (widget) التي سيتم إنشاؤها.
args
يحدد قائمة المعاملات لتجاوز أي مواصفات موارد أخرى لأداة الغلاف (shell widget) التي تم إنشاؤها.
num_args
يحدد عدد الإدخالات في قائمة المعاملات.
...
يحدد قائمة المعاملات المتغيرة لتجاوز أي مواصفات موارد أخرى لأداة الغلاف التي تم إنشاؤها.

الوصف

تقوم الدالة XtOpenApplication باستدعاء XtToolkitInitialize متبوعة بـ XtCreateApplicationContext، ثم تقوم باستدعاء XtOpenDisplay مع display_string NULL و application_name NULL، وأخيراً تقوم باستدعاء XtAppCreateShell مع application_name NULL، و widget_class المحدد، و args و num_args المحدد، وتعيد الغلاف الذي تم إنشاؤه. يتم إعادة argc و argv المعدلين اللذين تم إرجاعهما بواسطة XtDisplayInitialize في argc_in_out و argv_in_out. إذا لم يكن app_context_return NULL، فسيتم أيضًا إرجاع سياق التطبيق الذي تم إنشاؤه. إذا تعذر فتح الشاشة المحددة بواسطة سطر الأوامر، فسيتم إصدار رسالة خطأ وإنهاء XtOpenApplication للتطبيق. إذا كان fallback_resources غير NULL، فسيتم استدعاء XtAppSetFallbackResources بالقيمة قبل استدعاء XtOpenDisplay.

تم استبدال XtAppInitialize و XtVaAppInitialize بـ XtOpenApplication و XtVaOpenApplication على التوالي.
