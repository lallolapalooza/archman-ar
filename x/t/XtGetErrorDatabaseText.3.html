XtGetErrorDatabase(3) وظائف التوافق XT XtGetErrorDatabase(3)

الاسم

XtGetErrorDatabase, XtGetErrorDatabaseText - الحصول على قاعدة بيانات الأخطاء

الصيغة

#include <X11/Intrinsic.h>

XrmDatabase *XtGetErrorDatabase(void);

void XtGetErrorDatabaseText(const char *name, const char *type, const char *class, const char *defaultMsg, char *buffer_return, int nbytes);

المعاملات

buffer_return
يحدد المخزن المؤقت الذي سيتم إرجاع رسالة الخطأ إليه.
class
يحدد فئة المورد لرسالة الخطأ.
default
يحدد الرسالة الافتراضية للاستخدام.
name

type
يحدد الاسم والنوع اللذين يتم دمجهما لتشكيل اسم المورد لرسالة الخطأ.
nbytes
يحدد حجم المخزن المؤقت بالبايت.

الوصف

تم استبدال وظيفة XtGetErrorDatabase بوظيفة XtAppGetErrorDatabase.

تم استبدال وظيفة XtGetErrorDatabaseText بوظيفة XtAppGetErrorDatabaseText.
