Xau(3) دليل وظائف المكتبة Xau(3)

الاسم

مكتبة Xau: XauFileName, XauReadAuth, XauLockAuth, XauUnlockAuth, XauWriteAuth, XauDisposeAuth, XauGetAuthByAddr, XauGetBestAuthByAddr - إجراءات قاعدة بيانات مصادقة X

الملخص

#include <X11/Xauth.h>
typedef struct xauth {
        unsigned short  family;
        unsigned short  address_length;
        char    *address;
        unsigned short  number_length;
        char    *number;
        unsigned short  name_length;
        char    *name;
        unsigned short  data_length;
        char    *data;
} Xauth;
char *XauFileName (void);
Xauth *XauReadAuth (FILE *auth_file);
int XauWriteAuth (FILE *auth_file, Xauth *auth);
Xauth *XauGetAuthByAddr (unsigned short family, unsigned short
address_length, const char *address, unsigned short
number_length, const char *number, unsigned short
name_length, const char *name);
Xauth *XauGetBestAuthByAddr (unsigned short family, unsigned short
address_length, const char *address, unsigned short
number_length, const char *number, int types_length,
char **types, const int *type_lengths);
int XauLockAuth (const char *file_name, int retries, int
timeout, long dead);
int XauUnlockAuth (const char *file_name);
int XauDisposeAuth (Xauth *auth);

الوصف

XauFileName يقوم بإنشاء اسم ملف المصادقة الافتراضي عن طريق التحقق أولاً من متغير البيئة XAUTHORITY إذا تم تعيينه، وإلا فإنه يعيد $HOME/.Xauthority. هذا الاسم مخصص بشكل ثابت ولا ينبغي تحريره.

XauReadAuth يقرأ الإدخال التالي من auth_file. الإدخال **غير** مخصص بشكل ثابت ويجب تحريره عن طريق استدعاء XauDisposeAuth.

XauWriteAuth يكتب إدخال مصادقة إلى auth_file. يعيد 1 عند النجاح، و 0 عند الفشل.

XauGetAuthByAddr يبحث عن إدخال يتطابق مع زوج عنوان الشبكة/رقم العرض المحدد. الإدخال **غير** مخصص بشكل ثابت ويجب تحريره عن طريق استدعاء XauDisposeAuth.

XauGetBestAuthByAddr مشابه لـ XauGetAuthByAddr، باستثناء أنه يتم تحديد قائمة بطرق المصادقة المقبولة. ستقوم Xau باختيار إدخال الملف الذي يتطابق مع أقدم إدخال في هذه القائمة (على سبيل المثال، أكثر طرق المصادقة أمانًا). الوسيط types هو مصفوفة من السلاسل النصية، سلسلة نصية واحدة لكل طريقة مصادقة. types_length تحدد عدد العناصر في مصفوفة types. types_lengths هي مصفوفة من الأعداد الصحيحة تمثل طول كل سلسلة نصية.

XauLockAuth يقوم بالعمل اللازم لتحديث ملف مصادقة بشكل متزامن. أولاً، يقوم بإنشاء اسمين للملف، أحدهما ملحق بـ "-c" بـ file_name، والآخر ملحق بـ "-l". إذا كان الملف "-c" موجودًا بالفعل وأقدم من dead ثانية، يقوم XauLockAuth بإزالته هو والملف المرتبط به "-l". لمنع مشاكل التزامن المحتملة مع NFS، يجبر قيمة dead صفرية على إزالة الملفات. يقوم XauLockAuth بإجراء retries محاولات لإنشاء وربط أسماء الملفات، مع التوقف لمدة timeout ثانية بين كل محاولة. يعيد XauLockAuth مجموعة من القيم اعتمادًا على النتائج:

LOCK_ERROR
حدث خطأ في النظام، إما اسم ملف طويل جدًا، أو فشل غير متوقع من استدعاء نظام. قد يكون errno مفيدًا.
LOCK_TIMEOUT
فشلت محاولات retries.
LOCK_SUCCESS
نجح القفل.

XauUnlockAuth يعكس عمل XauLockAuth عن طريق إلغاء ربط كلا اسمي الملف "-c" و "-l".

XauDisposeAuth يحرر التخزين المخصص للاحتفاظ بإدخال مصادقة.
