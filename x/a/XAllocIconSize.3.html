XAllocIconSize(3)

الحزمة: libx11

التراخيص: MIT AND X11

XAllocIconSize(3) وظائف XLIB XAllocIconSize(3)

الاسم

XAllocIconSize, XSetIconSizes, XGetIconSizes, XIconSize - تخصيص بنية حجم الأيقونة وتعيين أو قراءة خاصية WM_ICON_SIZES لنافذة

الصيغة

XIconSize *XAllocIconSize(void);

int XSetIconSizes(Display *display, Window w, XIconSize *size_list, int count);

Status XGetIconSizes(Display *display, Window w, XIconSize **size_list_return, int *count_return);

الوسائط

display
يحدد الاتصال بخادم X.
count
يحدد عدد العناصر في قائمة الأحجام.
count_return
يعيد عدد العناصر في قائمة الأحجام.
size_list
يحدد قائمة الأحجام.
size_list_return
يعيد قائمة الأحجام.
w
يحدد النافذة.

الوصف

تقوم الدالة XAllocIconSize بتخصيص وإعادة مؤشر إلى بنية XIconSize. لاحظ أن جميع الحقول في بنية XIconSize يتم تعيينها مبدئيًا إلى صفر. إذا لم تتوفر ذاكرة كافية، تعيد XAllocIconSize القيمة NULL. لتحرير الذاكرة المخصصة لهذه البنية، استخدم XFree.

تستخدم الدالة XSetIconSizes فقط من قبل مديري النوافذ لتعيين أحجام الأيقونات المدعومة.

يمكن أن تولد XSetIconSizes أخطاء BadAlloc و BadWindow.

تعيد الدالة XGetIconSizes القيمة صفر إذا لم يقم مدير النوافذ بتعيين أحجام الأيقونات؛ وإلا، فإنها تعيد قيمة غير صفرية. يجب على التطبيق الذي يريد معرفة أحجام الأيقونات التي ستكون موضع تقدير أكبر من قبل مدير النوافذ الذي يعمل عليه التطبيق استدعاء XGetIconSizes. يجب على التطبيق بعد ذلك استخدام XSetWMHints لتزويد مدير النوافذ بخريطة بكسل أيقونة أو نافذة بأحد الأحجام المدعومة. لتحرير البيانات المخصصة في size_list_return، استخدم XFree.

يمكن أن تولد XGetIconSizes خطأ BadWindow.

الخصائص

WM_ICON_SIZES
قد يقوم مدير النوافذ بتعيين هذه الخاصية على النافذة الجذرية لتحديد أحجام الأيقونات التي يدعمها. النوع C لهذه الخاصية هو XIconSize.

البنى

تحتوي بنية XIconSize على:

typedef struct {
        int min_width, min_height;
        int max_width, max_height;
        int width_inc, height_inc;
} XIconSize;

تحدد الأعضاء width_inc و height_inc تسلسلًا حسابيًا للأحجام (من الحد الأدنى إلى الحد الأقصى) التي تمثل أحجام الأيقونات المدعومة.

التشخيصات

BadAlloc
فشل الخادم في تخصيص المورد المطلوب أو ذاكرة الخادم.
BadWindow
قيمة وسيطة للنافذة لا تسمي نافذة معرفة.
