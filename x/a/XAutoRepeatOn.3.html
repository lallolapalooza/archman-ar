XAutoRepeatOn(3)

الحزمة: libx11

التراخيص: MIT AND X11

NAME

XAutoRepeatOn, XAutoRepeatOff, XAutoRepeatSet - enable, disable, or set keyboard auto-repeat

SYNTAX

Boolean XAutoRepeatOn(Display *display);
Boolean XAutoRepeatOff(Display *display);
Boolean XAutoRepeatSet(Display *display, Boolean state);

ARGUMENTS

display Specifies the connection to the X server.

DESCRIPTION

Keyboard auto-repeat is a feature where a key, once pressed, is repeatedly reported by the server until it is released. By default, keyboard auto-repeat is enabled. For example, if the user holds down a key on the keyboard, the character associated with that key is typed repeatedly.

The function XAutoRepeatOn enables keyboard auto-repeat for the specified display.

The function XAutoRepeatOff disables keyboard auto-repeat for the specified display.

The function XAutoRepeatSet sets the auto-repeat state to either True (enabled) or False (disabled) for the specified display.

All functions return True if the auto-repeat state was changed, and False otherwise. If the server does not support this feature, the function returns False.

STRUCTURES

None.

DIAGNOSTICS

BadAlloc
The server failed to allocate memory.
Success
The function returned True or False indicating success or failure.

الاسم

XAutoRepeatOn, XAutoRepeatOff, XAutoRepeatSet - تمكين، تعطيل، أو ضبط التكرار التلقائي للوحة المفاتيح

الصيغة

Boolean XAutoRepeatOn(Display *display);
Boolean XAutoRepeatOff(Display *display);
Boolean XAutoRepeatSet(Display *display, Boolean state);

المعاملات

display يحدد الاتصال بخادم X.

الوصف

التكرار التلقائي للوحة المفاتيح هي ميزة حيث يتم الإبلاغ عن مفتاح، بمجرد الضغط عليه، بشكل متكرر بواسطة الخادم حتى يتم تحريره. افتراضيًا، يكون التكرار التلقائي للوحة المفاتيح ممكّنًا. على سبيل المثال، إذا ضغط المستخدم باستمرار على مفتاح في لوحة المفاتيح، فسيتم كتابة الحرف المرتبط بهذا المفتاح بشكل متكرر.

تقوم الدالة XAutoRepeatOn بتمكين التكرار التلقائي للوحة المفاتيح للعرض المحدد.

تقوم الدالة XAutoRepeatOff بتعطيل التكرار التلقائي للوحة المفاتيح للعرض المحدد.

تقوم الدالة XAutoRepeatSet بتعيين حالة التكرار التلقائي إلى True (ممكّن) أو False (معطّل) للعرض المحدد.

جميع الدوال تُرجع True إذا تم تغيير حالة التكرار التلقائي، وFalse بخلاف ذلك. إذا كان الخادم لا يدعم هذه الميزة، تُرجع الدالة False.

الهياكل

لا شيء.

التشخيصات

BadAlloc
فشل الخادم في تخصيص الذاكرة.
Success
أرجعت الدالة True أو False للإشارة إلى النجاح أو الفشل.
