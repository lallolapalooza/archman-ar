Xaw User Documentation – September 2023

NAME

Xaw – Athena Widget Set

SYNOPSIS

<Xaw>

DESCRIPTION

The Xaw library provides a collection of widgets that can be used to build graphical user interfaces for X applications.

WIDGETS

  • XawBox: A container widget that arranges its children in a row or column.
  • XawCommand: A simple button widget that triggers an action when clicked.
  • XawDialog: A dialog box widget that can contain other widgets.
  • XawForm: A form widget that allows children to be positioned and constrained relative to each other.
  • XawLabel: A widget that displays a string of text.
  • XawMenu: A menu widget that displays a list of options.
  • XawScrollbar: A scrollbar widget for scrolling content.
  • XawToggle: A toggle button widget that can be in an on or off state.
  • XawStripChart: A widget for displaying strip chart data.
  • XawList: A widget for displaying and selecting items from a list.
  • XawPixmap: A widget for displaying pixmaps.
  • XawText: A widget for editing and displaying text.
  • XawSimpleMenu: A simpler menu widget.
