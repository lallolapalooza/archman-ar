XAllocSizeHints(3) وظائف XLIB XAllocSizeHints(3)

الاسم

XAllocSizeHints، XSetWMNormalHints، XGetWMNormalHints، XSetWMSizeHints، XGetWMSizeHints، XSizeHints - تخصيص هيكل تلميحات الحجم وتعيين أو قراءة خاصية WM_NORMAL_HINTS لنافذة

الصيغة

XSizeHints *XAllocSizeHints(void);

void XSetWMNormalHints(Display *display، Window w، XSizeHints *hints);

Status XGetWMNormalHints(Display *display، Window w، XSizeHints *hints_return، long *supplied_return);

void XSetWMSizeHints(Display *display، Window w، XSizeHints *hints، Atom property);

Status XGetWMSizeHints(Display *display، Window w، XSizeHints *hints_return، long *supplied_return، Atom property);

الوسائط

display
يحدد الاتصال بخادم X.
hints
يحدد تلميحات حجم النافذة في حالتها العادية.
hints
يحدد هيكل XSizeHints المراد استخدامه.
hints_return
يعيد تلميحات حجم النافذة في حالتها العادية.
property
يحدد اسم الخاصية.
supplied_return
يعيد التلميحات التي تم تقديمها من قبل المستخدم.
w
يحدد النافذة.

الوصف

تقوم الدالة XAllocSizeHints بتخصيص وإعادة مؤشر إلى هيكل XSizeHints. لاحظ أن جميع الحقول في هيكل XSizeHints يتم تعيينها مبدئيًا إلى صفر. إذا لم تتوفر ذاكرة كافية، تعيد XAllocSizeHints قيمة NULL. لتحرير الذاكرة المخصصة لهذا الهيكل، استخدم XFree.

تقوم الدالة XSetWMNormalHints باستبدال تلميحات الحجم لخاصية WM_NORMAL_HINTS على النافذة المحددة. إذا لم تكن الخاصية موجودة بالفعل، تقوم XSetWMNormalHints بتعيين تلميحات الحجم لخاصية WM_NORMAL_HINTS على النافذة المحددة. يتم تخزين الخاصية بنوع WM_SIZE_HINTS وبصيغة 32.

يمكن أن تنتج XSetWMNormalHints أخطاء BadAlloc و BadWindow.

تقوم الدالة XGetWMNormalHints بإعادة تلميحات الحجم المخزنة في خاصية WM_NORMAL_HINTS على النافذة المحددة. إذا كانت الخاصية من نوع WM_SIZE_HINTS، وبصيغة 32، وطويلة بما يكفي لاحتواء هيكل تلميحات حجم قديم (ما قبل ICCCM) أو جديد، تقوم XGetWMNormalHints بتعيين الحقول المختلفة لهيكل XSizeHints، وتعّين الوسيط supplied_return لقائمة الحقول التي قدمها المستخدم (سواء كانت تحتوي على قيم محددة أم لا)، وتعيد حالة غير صفرية. بخلاف ذلك، تعيد حالة صفرية.

إذا أعادت XGetWMNormalHints بنجاح وتم قراءة خاصية تلميحات حجم ما قبل ICCCM، فسيتضمن الوسيط supplied_return الأجزاء التالية:

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

إذا كانت الخاصية طويلة بما يكفي لاحتواء حجم الأساس وحقول ميلاد النافذة أيضًا، فسيتضمن الوسيط supplied_return الأجزاء التالية أيضًا:

PBaseSize|PWinGravity

يمكن أن تنتج XGetWMNormalHints خطأ PN BadWindow.

تقوم الدالة XSetWMSizeHints باستبدال تلميحات الحجم للخاصية المحددة على النافذة المسماة. إذا لم تكن الخاصية المحددة موجودة بالفعل، تقوم XSetWMSizeHints بتعيين تلميحات الحجم للخاصية المحددة على النافذة المسماة. يتم تخزين الخاصية بنوع WM_SIZE_HINTS وبصيغة 32. لتعيين تلميحات الحجم العادية لنافذة، يمكنك استخدام الدالة XSetWMNormalHints.

يمكن أن تنتج XSetWMSizeHints أخطاء BadAlloc و BadAtom و BadWindow.

تقوم الدالة XGetWMSizeHints بإعادة تلميحات الحجم المخزنة في الخاصية المحددة على النافذة المسماة. إذا كانت الخاصية من نوع WM_SIZE_HINTS، وبصيغة 32، وطويلة بما يكفي لاحتواء هيكل تلميحات حجم قديم (ما قبل ICCCM) أو جديد، تقوم XGetWMSizeHints بتعيين الحقول المختلفة لهيكل XSizeHints، وتعّين الوسيط supplied_return لقائمة الحقول التي قدمها المستخدم (سواء كانت تحتوي على قيم محددة أم لا)، وتعيد حالة غير صفرية. بخلاف ذلك، تعيد حالة صفرية. للحصول على تلميحات الحجم العادية لنافذة، يمكنك استخدام الدالة XGetWMNormalHints.

إذا أعادت XGetWMSizeHints بنجاح وتم قراءة خاصية تلميحات حجم ما قبل ICCCM، فسيتضمن الوسيط supplied_return الأجزاء التالية:

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

إذا كانت الخاصية طويلة بما يكفي لاحتواء حجم الأساس وحقول ميلاد النافذة أيضًا، فسيتضمن الوسيط supplied_return الأجزاء التالية أيضًا:

PBaseSize|PWinGravity

يمكن أن تنتج XGetWMSizeHints أخطاء BadAtom و BadWindow.

الخصائص

WM_NORMAL_HINTS
تلميحات الحجم لنافذة في حالتها العادية. النوع C لهذه الخاصية هو XSizeHints.

الهياكل

يحتوي هيكل XSizeHints على:

/* أقنعة بتات تلميحات الحجم */

#define USPosition (1L << 0) /* المستخدم حدد x، y */
#define USSize (1L << 1) /* المستخدم حدد العرض، الارتفاع */
#define PPosition (1L << 2) /* البرنامج حدد الموضع */
#define PSize (1L << 3) /* البرنامج حدد الحجم */
#define PMinSize (1L << 4) /* البرنامج حدد الحد الأدنى للحجم */
#define PMaxSize (1L << 5) /* البرنامج حدد الحد الأقصى للحجم */
#define PResizeInc (1L << 6) /* البرنامج حدد زيادات تغيير الحجم */
#define PAspect (1L << 7) /* البرنامج حدد نسب العرض إلى الارتفاع الدنيا والقصوى */
#define PBaseSize (1L << 8)
#define PWinGravity (1L << 9)
#define PAllHints (PPosition| PSize| PMinSize| PMaxSize| PResizeInc| PAspect) 
/* القيم */
typedef struct {
        long flags;     /* يحدد أي حقول في هذا الهيكل معرفة */
        int x, y;       /* مهمل */
        int width, height;      /* مهمل */
        int min_width, min_height;
        int max_width, max_height;
        int width_inc, height_inc;
        struct {
               int x;   /* البسط */
               int y;   /* المقام */
        } min_aspect, max_aspect;
        int base_width, base_height;
        int win_gravity;
        /* قد يتم توسيع هذا الهيكل في المستقبل */
} XSizeHints;

أعضاء x و y و width و height مهملون الآن ويتركون فقط لأسباب التوافق. تحدد الأعضاء min_width و min_height الحد الأدنى لحجم النافذة الذي لا يزال يسمح للتطبيق بأن يكون مفيدًا. تحدد الأعضاء max_width و max_height الحد الأقصى لحجم النافذة. تحدد الأعضاء width_inc و height_inc متوالية حسابية للأحجام (من الحد الأدنى إلى الأقصى) التي تفضل النافذة تغيير حجمها إليها. يتم التعبير عن الأعضاء min_aspect و max_aspect كنسب x و y، وتسمح للتطبيق بتحديد نطاق نسب العرض إلى الارتفاع التي يفضلها. تحدد الأعضاء base_width و base_height الحجم المطلوب للنافذة. سيفسر مدير النوافذ موضع النافذة وعرض حدودها لوضع نقطة المستطيل الخارجي للنافذة العامة المحددة من قبل عضو win_gravity. يشمل المستطيل الخارجي للنافذة أي حدود أو زخارف يوفرها مدير النوافذ. بمعنى آخر، إذا قرر مدير النوافذ وضع النافذة حيث العميل

XAllocSizeHints(3) — libX11 — X Version 11

NAME

XAllocSizeHints, XSetSizeHints, XGetSizeHints, XFreeSizeHints ― allocate, set, get, and free size hints

SYNTAX

#include <X11/Xutil.h>

Bool XAllocSizeHints(XSizeHints *hints);
void XSetSizeHints(Display *display, Window w, XSizeHints *hints,
    Atom property);
void XGetSizeHints(Display *display, Window w, XSizeHints *hints,
    Atom *property_return);
void XFreeSizeHints(XSizeHints *hints);

ARGUMENTS

i h i n t s
Specifies the size hints structure.
d i s p l a y
Specifies the connection to the X server.
w
Specifies the window.
p r o p e r t y
Specifies the WM_NORMAL_HINTS atom or the WM_HINTS atom.
p r o p e r t y _ r e t u r n
Returns the atom that was used for the hints.

DESCRIPTION

The XAllocSizeHints function allocates storage for the `XSizeHints' structure.

The XSetSizeHints function sets the size hints for the specified window. The property argument must be the WM_NORMAL_HINTS atom or the WM_HINTS atom. If the property is not None, it is set to the specified atom.

The XGetSizeHints function gets the size hints for the specified window. The property_return argument returns the atom that was used for the hints. If the property is None, no size hints are set for the window.

The XFreeSizeHints function frees the storage for the `XSizeHints' structure.

PROPERTIES

The size hints are stored in the WM_NORMAL_HINTS property of the window. The WM_NORMAL_HINTS property is a list of values that specify the preferred size, minimum size, maximum size, and other geometry information for the window. The format of the WM_NORMAL_HINTS property is defined in the X Protocol specification.

The WM_HINTS property is a subset of the WM_NORMAL_HINTS property that contains only the hints that are relevant to the window manager. The format of the WM_HINTS property is defined in the X Protocol specification.

STRUCTURES

The `XSizeHints' structure contains the following members:

long flags
int x, y
int width, height
int min_width, min_height
int max_width, max_height
int width_inc, height_inc
structcional { int width; int height; } min_aspect, max_aspect;

The flags member is a bitmask that indicates which of the other members in the structure are set. The following bits are defined:

PPosition
The x and y members are set.
PSize
The width and height members are set.
PMinSize
The min_width and min_height members are set.
PMaxSize
The max_width and max_height members are set.
PResizeInc
The width_inc and height_inc members are set.
PAspect
The min_aspect and max_aspect members are set.

The x and y members specify the preferred position of the window. The width and height members specify the preferred size of the window. The min_width and min_height members specify the minimum size of the window. The max_width and max_height members specify the maximum size of the window. The width_inc and height_inc members specify the increment for the width and height of the window. The min_aspect and max_aspect members specify the minimum and maximum aspect ratio of the window.

If the PAspect flag is set, then the aspect ratio of the window must be between the values specified by min_aspect and max_aspect. The aspect ratio is defined as width / height. The min_aspect and max_aspect members are specified as integers in the form of x * 65536 + y, where x is the numerator and y is the denominator.

If the PWinGravity flag is set, the win_gravity member specifies the gravity of the window. The gravity determines where the window is placed on the parent window's border when the window is mapped. The gravity is one of the following values:

The PAllHints macro is used to set all of the hints in the `XSizeHints' structure. Use of this macro is highly discouraged.

The placement of the client window is relative to the parent window's border. If win_gravity is set to ForgetGravity, the window manager chooses the gravity. If win_gravity is set to the value returned by the XSetWMHints function, the position on the parent window's border named by the win_gravity will be placed where the client window would have been placed in the absence of a window manager.

Note that use of the PAllHints macro is highly discouraged.

DIAGNOSTICS

BadAlloc
The server failed to allocate the requested resource or server memory.
BadAtom
A value for an Atom argument does not name a defined Atom.
BadWindow
A value for a Window argument does not name a defined Window.

XAllocSizeHints, XSetSizeHints, XGetSizeHints, XFreeSizeHints - تخصيص، تعيين، الحصول على، وحذف تلميحات الحجم

الصيغة

#include <X11/Xutil.h>

void XSetSizeHints(Display *display, Window w, XSizeHints *hints,

المعاملات

يحدد بنية تلميحات الحجم.
d i s p l a y
يحدد الاتصال بخادم X.

الوصف

الدالة XAllocSizeHints تخصص مساحة لبنية `XSizeHints'.

الدالة XSetSizeHints تعين تلميحات الحجم للنافذة المحددة. يجب أن يكون المعامل property هو ذرة WM_NORMAL_HINTS أو ذرة WM_HINTS. إذا كان property هو None، يتم تعيينه إلى الذرة المحددة.

الدالة XGetSizeHints تحصل على تلميحات الحجم للنافذة المحددة. تعيد المعامل property_return الذرة التي تم استخدامها للتلميحات. إذا كان property هو None، لا يتم تعيين أي تلميحات حجم للنافذة.

الدالة XFreeSizeHints تحرر المساحة لبنية `XSizeHints'.

الخصائص

يتم تخزين تلميحات الحجم في الخاصية WM_NORMAL_HINTS للنافذة. الخاصية WM_NORMAL_HINTS هي قائمة بقيم تحدد الحجم المفضل، الحد الأدنى للحجم، الحد الأقصى للحجم، ومعلومات الهندسة الأخرى للنافذة. يتم تعريف تنسيق الخاصية WM_NORMAL_HINTS في مواصفات بروتوكول X.

الخاصية WM_HINTS هي مجموعة فرعية من الخاصية WM_NORMAL_HINTS تحتوي فقط على التلميحات ذات الصلة بمدير النوافذ. يتم تعريف تنسيق الخاصية WM_HINTS في مواصفات بروتوكول X.

البنى

تحتوي بنية `XSizeHints' على الأعضاء التالية:

long flags
int x, y
int width, height
int min_width, min_height
int max_width, max_height
int width_inc, height_inc
structcional { int width; int height; } min_aspect, max_aspect;

عضو flags هو قناع بت يشير إلى أي من الأعضاء الأخرى في البنية تم تعيينها. البتات التالية معرفة:

PPosition
تم تعيين أعضاء x و y.
PSize
تم تعيين أعضاء width و height.
PMinSize
تم تعيين أعضاء min_width و min_height.
PMaxSize
تم تعيين أعضاء max_width و max_height.
PResizeInc
تم تعيين أعضاء width_inc و height_inc.
PAspect
تم تعيين أعضاء min_aspect و max_aspect.

يحدد عضوي x و y الموضع المفضل للنافذة. يحدد عضوي width و height الحجم المفضل للنافذة. يحدد عضوي min_width و min_height الحد الأدنى لحجم النافذة. يحدد عضوي max_width و max_height الحد الأقصى لحجم النافذة. يحدد عضوي width_inc و height_inc الزيادة في عرض وارتفاع النافذة. يحدد عضوي min_aspect و max_aspect نسبة العرض إلى الارتفاع الدنيا والقصوى للنافذة.

إذا تم تعيين علامة PAspect، فيجب أن تكون نسبة العرض إلى الارتفاع للنافذة بين القيم المحددة بواسطة min_aspect و max_aspect. يتم تعريف نسبة العرض إلى الارتفاع على أنها width / height. يتم تحديد أعضاء min_aspect و max_aspect كأعداد صحيحة بالصيغة x * 65536 + y، حيث x هو البسط و y هو المقام.

إذا تم تعيين علامة PWinGravity، يحدد عضو win_gravity جاذبية النافذة. تحدد الجاذبية مكان وضع النافذة على حدود النافذة الأصلية عند تعيين النافذة. الجاذبية هي إحدى القيم التالية:

الماكرو PAllHints يستخدم لتعيين جميع التلميحات في بنية `XSizeHints'. استخدام هذا الماكرو غير مستحسن بشدة.

وضع نافذة العميل نسبي إلى حدود النافذة الأصلية. إذا تم تعيين win_gravity إلى ForgetGravity، يختار مدير النوافذ الجاذبية. إذا تم تعيين win_gravity إلى القيمة التي تم إرجاعها بواسطة الدالة XSetWMHints، فسيتم وضع الموضع على حدود النافذة الأصلية المسمى بواسطة win_gravity حيث كانت ستوضع نافذة العميل في غياب مدير النوافذ.

لاحظ أن استخدام الماكرو PAllHints غير مستحسن للغاية.
