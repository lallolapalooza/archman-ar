XAutoRepeatOff(3)

الحزمة: libx11

التراخيص: MIT AND X11

NAME

XAutoRepeatOff — تعطيل التكرار التلقائي للمفاتيح

SYNTAX

void XAutoRepeatOff(Display *display);

ARGUMENTS

display
يحدد الاتصال بخادم X.

DESCRIPTION

يعطل وظيفة التكرار التلقائي للمفاتيح لخادم X.

عند تعطيل التكرار التلقائي، لن يتم إرسال أحداث المفاتيح المتكررة إلى العميل. يمكن استعادة هذا السلوك باستخدام XAutoRepeatOn.

STRUCTURES

لا توجد هياكل مرتبطة مباشرة بهذه الوظيفة.

DIAGNOSTICS

يمكن أن تؤدي أخطاء الخادم إلى إرسال استثناء BadAlloc.

BadAlloc
لم يكن بالإمكان تخصيص ذاكرة كافية.
