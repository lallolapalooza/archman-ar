xadump(1)

الحزمة: recoll

التراخيص: GPL

XADUMP(1) دليل الأوامر العامة XADUMP(1)

الاسم

xadump - وصول منخفض المستوى إلى فهرس Recoll Xapian.

ملخص

xadump [ -d <dbdir> ] [ -e <outputencoding> ] -i <docid> -D
xadump [ -d <dbdir> ] [ -e <outputencoding> ] -i <docid> -X
xadump [ -d <dbdir> ] [ -e <outputencoding> ] -i <docid> [ -x ] -T
xadump [ -d <dbdir> ] [ -e <outputencoding> ] -i <docid> [ -x ] -r

xadump [ -d <dbdir> ] [ -e <outputencoding> ] -t <term> -E
xadump [ -d <dbdir> ] [ -e <outputencoding> ] -t <term> -F
xadump [ -d <dbdir> ] [ -e <outputencoding> ] -t <term> -P

xadump -T [ -f ] [ -n ] [ -l ]

xadump -q term [term ...]

الوصف

الأمر xadump هو أداة وصول وتشخيص منخفضة المستوى لفهرس Xapian كما ينظمه مفهرس Recoll. يتم تحديد دليل الفهرس المراد استخدامه باستخدام الخيار -d.

تأخذ الخيارات -D و -X و -T و -r وسيطة docid واحدة محددة باستخدام الخيار -i. يعرض -D سجل بيانات المستند. يحذف -X جميع بيانات الفهرس للمستند. يطبع -T قائمة المصطلحات للمستند. بدون وسيطة docid، سيقوم هذا الخيار بإدراج قائمة مصطلحات الفهرس بأكملها. يمكن تعيين -f لسبق كل مصطلح بعدد مرات ظهوره (فقط إذا لم يتم تحديد docid). يمكن تعيين -n لتجاهل الأقواس المحيطة. يمكن تعيين -l لتخطي المصطلحات ذات البادئات. يطبع -r نص المستند كما تم إعادة بنائه من بيانات الفهرس.

عند تعيين الخيار -x، تتم طباعة المصطلحات مع فصل كل حرف بمسافة، وهو ما قد يكون مفيدًا للتحقق من بعض مشكلات الترميز.

تتطلب الخيارات -E و -F و -P جميعها وسيطة مصطلح، يتم تحديدها باستخدام -t <term>. يجري -E اختبار وجود مصطلح. يسترجع -F تكرار المصطلح للمصطلح المحدد. يعرض -P قائمة بالمشاركات للمصطلح المحدد.

مع الخيار -q، يقوم xadump بإجراء استعلام AND بسيط على الفهرس، باستخدام وسائط المصطلحات المحددة.
