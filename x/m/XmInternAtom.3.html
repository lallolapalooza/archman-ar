XmInternAtom(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmInternAtom(استدعاء مكتبة) XmInternAtom(استدعاء مكتبة)

الاسم

XmInternAtom — ماكرو يعيد ذرة لاسم معين

الشكل العام

#include <Xm/AtomMgr.h>
Atom XmInternAtom(
Display * display,
String name,
Boolean only_if_exists);

الوصف

XmInternAtom يعيد ذرة لاسم معين. تظل الذرة المعادة معرفة حتى بعد إغلاق اتصال العميل. تصبح الذرة المعادة غير معرفة عند إغلاق آخر اتصال بخادم X.

display
يحدد الاتصال بخادم X
name
يحدد الاسم المرتبط بالذرة التي تريد إعادتها. قيمة name تعتمد على حالة الأحرف.
only_if_exists
يحدد قيمة منطقية. إذا كانت False، يتم إنشاء الذرة حتى لو لم تكن موجودة. (إذا لم تكن موجودة، فستكون الذرة المعادة None.) إذا كانت True، يتم إنشاء الذرة فقط إذا كانت موجودة.

القيمة المعادة

يعيد ذرة.
