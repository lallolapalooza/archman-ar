XmVaCreateManagedPanedWindow(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreatePanedWindow(استدعاء مكتبة) XmVaCreatePanedWindow(استدعاء مكتبة)

الاسم

XmVaCreatePanedWindow, XmVaCreateManagedPanedWindow — وظائف إنشاؤها ملائمة لأداة PanedWindow.

ملخص

#include <Xm/PanedW.h>
Widget XmVaCreatePanedWindow(
Widget parent,
String name,
...);
Widget XmVaCreateManagedPanedWindow(
Widget parent,
String name,
...);

الوصف

تقوم هذه الوظائف بإنشاء مثيل لأداة ToggleButtonGadget وترجع معرف الأداة المرتبط بها. تستخدم هذه الروتينات اتفاقية استدعاء قائمة الوسائط المتغيرة ANSI C (varargs).

وظيفة XmVaCreatePanedWindow هي روتين ملائم يقوم باستدعاء XtCreateWidget.

وظيفة XmVaCreatePanedWindow هي روتين ملائم يقوم باستدعاء XtCreateManagedWidget.

parent
يحدد معرف الأداة الأصل.
name
يحدد اسم الأداة التي تم إنشاؤها.
...
يحدد قائمة الوسائط المتغيرة لتجاوز إعدادات الموارد الافتراضية.

للحصول على تعريف كامل لـ PanedWindow والموارد المرتبطة بها، انظر XmPanedWindow(3).

الإرجاع

ترجع معرف أداة PanedWindow.

ذات الصلة

XmPanedWindow(3)، XmCreatePanedWindow(3)، XtCreateWidget(3)، و XtCreateManagedWidget(3).
