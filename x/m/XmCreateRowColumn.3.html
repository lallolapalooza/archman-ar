التراخيص: LGPL-2.1-or-later

الاسم

XmCreateRowColumn — وظيفة إنشاء ودجت RowColumn

الملخص

#include <Xm/RowColumn.h>
Widget XmCreateRowColumn(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

الوصف

XmCreateRowColumn ينشئ مثيلاً لوجدت RowColumn ويعيد معرف الوجدت المرتبط به. إذا لم يتم تحديد XmNrowColumnType، فسيتم إنشاؤه مع XmWORK_AREA، وهو الافتراضي.

إذا تم استخدام هذه الوظيفة لإنشاء قائمة منبثقة من نوع XmMENU_POPUP أو قائمة منسدلة من نوع XmMENU_PULLDOWN، فلن يتم إنشاء ودجت MenuShell تلقائيًا كوالد لقسم القائمة. يجب على التطبيق أولاً إنشاء MenuShell باستخدام إما XmCreateMenuShell أو وظيفة الإنشاء القياسية للمجموعة.

parent
يحدد معرف الوجدت الوالد
name
يحدد اسم الوجدت الذي تم إنشاؤه
arglist
يحدد قائمة الوسائط
argcount
يحدد عدد أزواج السمات/القيم في قائمة الوسائط (arglist)

للحصول على تعريف كامل لـ RowColumn والموارد المرتبطة به، راجع XmRowColumn(3).

الإرجاع

يعيد معرف ودجت RowColumn.
