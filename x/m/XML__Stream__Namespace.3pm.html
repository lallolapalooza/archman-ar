XML__Stream__Namespace(3pm)

الحزمة: perl-xml-stream

التراخيص: GPL, PerlArtistic

XML::Stream::Namespace(3) وثائق مقدمة من المستخدم لـ Perl XML::Stream::Namespace(3)

الاسم

XML::Stream::Namespace - كائن لتسهيل تعريف مساحات الأسماء في
XML::Stream.

الملخص

XML::Stream::Namespace هي حزمة مساعدة لـ XML::Stream. توفر طريقة نظيفة لتعريف مساحات الأسماء ليستخدمها XML::Stream عند الاتصال.

الوصف

تسمح لك هذه الوحدة بتعيين وقراءة العناصر من مساحة اسم XML::Stream.

الوظائف

SetNamespace("mynamespace");
SetXMLNS("http://www.mynamespace.com/xmlns");
SetAttributes(attrib1=>"value1",
              attrib2=>"value2");
GetNamespace() تُرجع "mynamespace"
GetXMLNS() تُرجع "http://www.mynamespace.com/xmlns"
GetAttributes() تُرجع جدول هاش ( attrib1=>"value1",attrib2=>"value2")
GetStream() تُرجع السلسلة التالية:
  "xmlns:mynamespace='http://www.nynamespace.com/xmlns'
   mynamespace:attrib1='value1'
   mynamespace:attrib2='value2'"

أمثلة

$myNamespace = XML::Stream::Namespace->new("mynamspace");
$myNamespace->SetXMLNS("http://www.mynamespace.org/xmlns");
$myNamespace->SetAttributes(foo=>"bar",
                            bob=>"vila");
$stream = XML::Stream->new;
$stream->Connect(name=>"foo.bar.org",
                 port=>1234,
                 namespace=>"foo:bar",
                 namespaces=>[ $myNamespace ]);
#
# الاتصال أعلاه سيرسل ما يلي كسلسلة الفتح
# للدفق إلى foo.bar.org:1234...
#
#   <stream:stream
#    xmlns:stream="http://etherx.jabber.org/streams"
#    to="foo.bar.org"
#    xmlns="foo:bar"
#    xmlns:mynamespace="http://www.mynamespace.org/xmlns"
#    mynamespace:foo="bar"
#    mynamespace:bob="vila">
#
