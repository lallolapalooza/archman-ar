XmVaCreateFileSelectionBox(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateFileSelectionBox(استدعاء مكتبة) XmVaCreateFileSelectionBox(استدعاء مكتبة)

الاسم

XmVaCreateFileSelectionBox, XmVaCreateManagedFileSelectionBox — وظائف مساعدة لإنشاء ودجة FileSelectionBox.

الملخص

#include <Xm/FileSB.h>
Widget XmVaCreateFileSelectionBox(
Widget parent,
String name,
...);
Widget XmVaCreateManagedFileSelectionBox(
Widget parent,
String name,
...);

الوصف

تقوم هذه الوظائف بإنشاء نسخة من ودجة FileSelectionBox وإرجاع معرف الودجة المرتبط بها. تستخدم هذه الروتينات اتفاقية استدعاء قائمة الوسائط المتغيرة ANSI C (varargs).

XmVaCreateFileSelectionBox هي روتين مساعدة يستدعي XtCreateWidget.

XmVaCreateManagedFileSelectionBox هي روتين مساعدة يستدعي XtCreateManagedWidget.

parent
يحدد معرف الودجة الأم.
name
يحدد اسم الودجة المنشأة.
...
يحدد قائمة الوسائط المتغيرة لتجاوز افتراضات الموارد.

للحصول على تعريف كامل لـ FileSelectionBox والموارد المرتبطة بها، راجع XmFileSelectionBox(3).

الإرجاع

ترجع معرف ودجة FileSelectionBox.

ذات صلة

XmCreateFileSelectionBox(3), XtCreateManagedWidget(3), XtCreateWidget(3), و XmFileSelectionBox(3).
