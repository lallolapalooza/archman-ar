XML__LibXML__Schema(3pm)

الحزمة: perl-xml-libxml

التراخيص: GPL

XML::LibXML::Schema(3) وثائق بيرل المساهمة من المستخدم XML::LibXML::Schema(3)

الاسم

XML::LibXML::Schema - التحقق من صحة مخطط XML

الملخص

use XML::LibXML;
$doc = XML::LibXML->new->parse_file($url);
$xmlschema = XML::LibXML::Schema->new( location => $filename_or_url, no_network => 1 );
$xmlschema = XML::LibXML::Schema->new( string => $xmlschemastring, no_network => 1 );
eval { $xmlschema->validate( $doc ); };

الوصف

فئة XML::LibXML::Schema هي واجهة أمامية صغيرة لتطبيق مخطط XML الخاص بـ libxml2. حاليًا، يدعم فقط تحليل المخططات والتحقق من صحة المستندات. اعتبارًا من الإصدار 2.6.32، يدعم libxml2 الأنواع العشرية حتى 24 رقمًا فقط (يتطلب المعيار 18 على الأقل).

الطرق

جديد
$xmlschema = XML::LibXML::Schema->new( location => $filename_or_url, no_network => 1 );
$xmlschema = XML::LibXML::Schema->new( string => $xmlschemastring, no_network => 1 );

يتطلب مُنشئ XML::LibXML::Schema استدعاءه بقائمة من المعلمات. يلزم معلمة location أو string على الأقل لتحديد مصدر المخطط. المعلمة الاختيارية no_network التي تم تعيينها إلى 1 تسبب عدم وصول المحلل إلى الشبكة، والمعلمة الاختيارية recover التي تم تعيينها إلى 1 تسبب عدم قيام المحلل باستدعاء die() عند حدوث أخطاء.

من المهم أن يكون لكل مخطط مصدر واحد فقط.

تسمح معلمة location بتحليل مخطط من نظام الملفات أو عنوان URL (غير HTTPS).

ستقوم معلمة string بتحليل المخطط من سلسلة XML المعطاة.

لاحظ أن المُنشئ سيستدعي die() إذا لم يفي المخطط بالقيود الخاصة بمواصفات مخطط XML.

التحقق من الصحة
eval { $xmlschema->validate( $doc ); };

تسمح هذه الوظيفة بالتحقق من صحة مستند (محلل) مقابل مخطط XML المعطى. يجب أن تكون الوسيطة لهذه الوظيفة كائن XML::LibXML::Document. إذا نجحت هذه الوظيفة، فسترجع 0، وإلا فستستدعي die() وتقوم بتوصيف الأخطاء التي تم العثور عليها. بسبب هذا، يجب دائمًا تقييم validate().
