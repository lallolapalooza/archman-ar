XmCreateToggleButton(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmCreateToggleButton(استدعاء مكتبة) XmCreateToggleButton(استدعاء مكتبة)

الاسم

XmCreateToggleButton — وظيفة إنشاء أداة تبديل الزر

ملخص

#include <Xm/ToggleB.h>
Widget XmCreateToggleButton(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

الوصف

XmCreateToggleButton تنشئ مثيلًا لأداة تبديل الزر وتعيد معرّف الأداة المرتبط بها.

parent
يحدد معرّف الأداة الأم
name
يحدد اسم الأداة المنشأة
arglist
يحدد قائمة الوسائط
argcount
يحدد عدد أزواج السمات/القيم في قائمة الوسائط (arglist)

لتعريف كامل لزر التبديل والموارد المرتبطة به، راجع XmToggleButton(3).

الإرجاع

يعيد معرّف أداة زر التبديل.

متعلق
