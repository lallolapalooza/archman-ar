XML__RegExp(3pm)

الحزمة: perl-xml-regexp

التراخيص: GPL, PerlArtistic

XML::RegExp(3) وثائق Perl المساهمة من قبل المستخدم XML::RegExp(3)

الاسم

XML::RegExp - تعابير نمطية لرموز XML

الملخص

use XML::RegExp;
if ($my_name =~ /^$XML::RegExp::Name$/)
{
  # $my_name هو 'Name' صالح لـ XML
}

الوصف

تحتوي هذه الحزمة على تعابير نمطية لرموز XML التالية: BaseChar، Ideographic، Letter، Digit، Extender، CombiningChar، NameChar، EntityRef، CharRef، Reference، Name، NmToken، و AttValue.

تم أخذ تعريفات هذه الرموز من مواصفات XML (Extensible Markup Language 1.0) على http://www.w3.org/TR/REC-xml.

كما تحتوي على التعابير النمطية للرموز التالية من مواصفات أسماء XML على http://www.w3.org/TR/REC-xml-names: NCNameChar، NCName، QName، Prefix، و LocalPart.
