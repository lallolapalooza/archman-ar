XmCreateText(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmCreateText(استدعاء مكتبة) XmCreateText(استدعاء مكتبة)

الاسم

XmCreateText — دالة إنشاء عنصر واجهة المستخدم النصي

ملخص

#include <Xm/Text.h>
Widget XmCreateText(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

الوصف

XmCreateText تنشئ مثيلًا لعنصر واجهة المستخدم النصي وتعيد معرف الواجهة.

parent
تحدد معرف الواجهة الأصل
name
تحدد اسم الواجهة التي تم إنشاؤها
arglist
تحدد قائمة المعاملات
argcount
تحدد عدد أزواج السمات/القيم في قائمة المعاملات (arglist)

لتعريف كامل للنص والموارد المرتبطة به، انظر XmText(3).

الإرجاع

يعيد معرف الواجهة النصية.

متعلق

XmText(3).
