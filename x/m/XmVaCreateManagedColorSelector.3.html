XmVaCreateManagedColorSelector(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateColorSelector(استدعاء مكتبة) XmVaCreateColorSelector(استدعاء مكتبة)

اسم

XmVaCreateColorSelector, XmVaCreateManagedColorSelector — وظائف مساعدة لإنشاء عنصر تحكم ColorSelector.

نظرة عامة

#include <Xm/ColorS.h>
Widget XmVaCreateColorSelector(
Widget parent,
String name,
...);
Widget XmVaCreateManagedColorSelector(
Widget parent,
String name,
...);

وصف

تقوم هذه الوظائف بإنشاء مثيل لعنصر تحكم ColorSelector وإرجاع معرف العنصر المرتبط به. تستخدم هذه الروتينات اتفاقية استدعاء قائمة الوسائط المتغيرة ANSI C (varargs).

الوظيفة XmVaCreateColorSelector هي روتين مساعد يستدعي XtCreateWidget.

الوظيفة XmVaCreateManagedColorSelector هي روتين مساعد يستدعي XtCreateManagedWidget.

parent
يحدد معرف العنصر الأب.
name
يحدد اسم العنصر الذي تم إنشاؤه.
...
يحدد قائمة الوسائط المتغيرة لتجاوز الإعدادات الافتراضية للموارد.

للحصول على تعريف كامل لـ ColorSelector والموارد المرتبطة به، انظر XmColorSelector(3).

القيمة المعادة

تُرجع معرف عنصر تحكم ColorSelector.

ذات صلة

XmColorSelector(3), XmCreateColorSelector(3), XtCreateWidget(3), و XtCreateManagedWidget(3).
