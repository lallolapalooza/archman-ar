XmTextSetString(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmTextSetString(استدعاء مكتبة) XmTextSetString(استدعاء مكتبة)

الاسم

XmTextSetString — دالة Text لتعيين قيمة النص.

الملخص

#include <Xm/Text.h>
void XmTextSetString(
Widget widget,
char * value);

الوصف

تقوم XmTextSetString بتعيين قيمة النص لعنصر واجهة Text. تستدعي هذه الدالة قوائم الاستدعاءات XmNvalueChangedCallback وإجراءات التحقق، سواء كانت XmNmodifyVerifyCallback أو XmNmodifyVerifyCallbackWcs، أو كليهما. إذا تم تسجيل كلتا قائمتي استدعاءات التحقق، يتم تنفيذ إجراءات قائمة XmNmodifyVerifyCallback أولاً ويتم تمرير البيانات الناتجة إلى استدعاءات XmNmodifyVerifyCallbackWcs. تقوم هذه الدالة أيضًا بتعيين موضع مؤشر الإدخال إلى بداية السلسلة النصية وتستدعي استدعاءات XmNmotionVerifyCallback للعنصر.

widget
تحدد معرف عنصر واجهة Text.
value
تحدد مؤشر الحرف لقيمة السلسلة النصية وتضع السلسلة النصية في نافذة تحرير النص.

للحصول على تعريف كامل لـ Text والموارد المرتبطة به، انظر XmText(3).

ذات الصلة

XmText(3) و XmTextSetStringWcs(3).
