XmActivateProtocol(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmActivateProtocol(استدعاء مكتبة) XmActivateProtocol(استدعاء مكتبة)

الاسم

XmActivateProtocol — دالة VendorShell لتنشيط بروتوكول

الملخص

#include <Xm/Protocols.h>
void XmActivateProtocol(
Widget shell,
Atom property,
Atom protocol);

الوصف

XmActivateProtocol تنشط بروتوكولاً. تقوم بتحديث المعالجات و property إذا تم تحقيق shell. يكون مفيدًا أحيانًا للسماح لمعلومات حالة البروتوكول (قوائم رد الاتصال، وما إلى ذلك) بالبقاء، حتى لو اختار العميل التخلي مؤقتًا عن التفاعل. هذا مدعوم بالسماح للبروتوكول protocol بأن يكون في إحدى حالتين: نشط أو غير نشط. إذا كان protocol نشطًا وتم تحقيق shell، فإن property تحتوي على Atom الخاص بالبروتوكول protocol. إذا كان protocol غير نشط، فإن Atom غير موجود في property.

XmActivateWMProtocol هي واجهة ملائمة. تستدعي XmActivateProtocol مع تعيين قيمة الخاصية إلى الذرة التي تم إرجاعها عن طريق استدعاء WM_PROTOCOLS.

shell
يحدد الواجهة (widget) المرتبط بخاصية البروتوكول
property
يحدد خاصية البروتوكول
protocol
يحدد Atom الخاص بالبروتوكول

لتعريف كامل لـ VendorShell والموارد المرتبطة بها، انظر VendorShell(3).

ذات صلة

VendorShell(3)، XmActivateWMProtocol(3)، XmRemoveProtocols(3) و XmInternAtom(3).
