XmMultiList(3)

identifier This value is of type XtPointer and is intended to be used for any purpose. It is intended to be used as an identifier for the object pointed to by this row

selected This value is True if this row is selected; may be set by the application.

Neither sort_id nor data are used by the MultiList widget; they exist solely for the convenience of the programmer.

الترجمات

فيما يلي ربطات الترجمة الافتراضية التي يستخدمها زر الأيقونة:

~Ctrl ~Shift <Btn1Down>: ButtonDown()
Ctrl ~Shift <Btn1Down>: ButtonDown(Toggle)
~Ctrl Shift <Btn1Down>: ButtonDown(Extend)
Button1 <Motion>: Motion()
<Btn1Up>: ButtonUpOrLeave()

الإجراءات التالية مدعومة بواسطة MultiList:

ButtonDown(type)
تعالج إجراء ضغط الزر الذي قد يبدأ إما بتحديد أو نقر مزدوج. يمكن أن تكون الوسيطة type إما Toggle أو Extend. تحدد هذه القيم وضع التحديد الموسع الذي سيتم تطبيقه.
