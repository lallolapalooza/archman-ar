XmbDrawImageString(3)

الحزمة: libx11

التراخيص: MIT AND X11

XmbDrawImageString(3) وظائف XLIB XmbDrawImageString(3)

الاسم

XmbDrawImageString, XwcDrawImageString, Xutf8DrawImageString - رسم نص صورة باستخدام مجموعة خطوط واحدة

الصيغة

void XmbDrawImageString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, _Xconst char *string, int num_bytes);

void XwcDrawImageString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, _Xconst wchar_t *string, int num_wchars);

void Xutf8DrawImageString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, _Xconst char *string, int num_bytes);

المعاملات

الوصف

تقوم وظائف XmbDrawImageString و XwcDrawImageString و Xutf8DrawImageString بملء مستطيل وجهة بالبكسل الخلفية المحدد في GC ثم ترسم النص ببكسل المقدمة. المستطيل المملوء هو المستطيل الذي تم إرجاعه بواسطة XmbTextExtents أو XwcTextExtents أو Xutf8TextExtents لنفس النص و XFontSet.

عندما تحتوي XFontSet على مجموعات أحرف مفقودة، يتم رسم كل حرف غير متاح بالسلسلة الافتراضية التي تم إرجاعها بواسطة XCreateFontSet. السلوك المتعلق بنقطة التعليمات البرمجية غير الصالحة غير محدد.

وظيفة Xutf8TextExtents هي امتداد تم تقديمه بواسطة The XFree86 Project, Inc.، في إصدارها 4.0.2. يتم الإشارة إلى وجودها بواسطة الماكرو X_HAVE_UTF8_STRING.
