XmVaCreatePanedWindow(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreatePanedWindow(استدعاء مكتبة) XmVaCreatePanedWindow(استدعاء مكتبة)

الاسم

XmVaCreatePanedWindow, XmVaCreateManagedPanedWindow — وظائف ملائمة لإنشاء نافذة مقسمة (PanedWindow).

الملخص

#include <Xm/PanedW.h>
Widget XmVaCreatePanedWindow(
Widget parent,
String name,
...);
Widget XmVaCreateManagedPanedWindow(
Widget parent,
String name,
...);

الوصف

تنشئ هذه الوظائف مثيلاً لعنصر واجهة ToggleButtonGadget وتعيد معرف الواجهة المرتبط بها. تستخدم هذه الروتينات اتفاقية استدعاء قائمة الوسائط متغيرة الطول (varargs) القياسية ANSI C.

تعد الوظيفة XmVaCreatePanedWindow روتيناً ملائماً يستدعي XtCreateWidget.

تعد الوظيفة XmVaCreatePanedWindow روتيناً ملائماً يستدعي XtCreateManagedWidget.

parent
يحدد معرف الواجهة الأب.
name
يحدد اسم الواجهة المنشأة.
...
يحدد قائمة الوسائط المتغيرة لتجاوز قيم الموارد الافتراضية.

للحصول على تعريف كامل للنافذة المقسمة (PanedWindow) ومواردها المرتبطة، انظر XmPanedWindow(3).

الإرجاع

يعيد معرف الواجهة PanedWindow.

ذات الصلة

XmPanedWindow(3), XmCreatePanedWindow(3), XtCreateWidget(3), و XtCreateManagedWidget(3).
