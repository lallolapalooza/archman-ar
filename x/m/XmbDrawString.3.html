XmbDrawString(3)

الحزمة: libx11

التراخيص: MIT AND X11

XmbDrawString(3) وظائف XLIB XmbDrawString(3)

الاسم

XmbDrawString, XwcDrawString, Xutf8DrawString - رسم نص باستخدام مجموعة خطوط واحدة

الصيغة

void XmbDrawString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, _Xconst char *string, int num_bytes);

void XwcDrawString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, _Xconst wchar_t *string, int num_wchars);

void Xutf8DrawString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, _Xconst char *string, int num_bytes);

المعاملات

d
يحدد الكائن القابل للرسم.
display
يحدد الاتصال بخادم X.
font_set
يحدد مجموعة الخطوط.
gc
يحدد GC.
num_bytes
يحدد عدد البايتات في معامل السلسلة النصية.
num_wchars
يحدد عدد الأحرف في معامل السلسلة النصية.
string
يحدد السلسلة النصية.
x

y
تحدد الإحداثيات x و y.

الوصف

تقوم الدوال XmbDrawString و XwcDrawString و Xutf8DrawString برسم النص المحدد باستخدام البكسل الأمامي. عندما تكون XFontSet تحتوي على مجموعات رموز مفقودة، يتم رسم كل حرف غير متاح باستخدام السلسلة النصية الافتراضية التي تم إرجاعها بواسطة XCreateFontSet. سلوك نقطة الترميز غير الصالحة غير محدد.

الدالة Xutf8DrawString هي امتداد تم تقديمه بواسطة The XFree86 Project, Inc.، في إصدارها 4.0.2. يشير وجودها بواسطة الماكرو X_HAVE_UTF8_STRING.
