Parser::Style::Stream(3) وثائق بيرل المساهمة من المستخدم Parser::Style::Stream(3)

الاسم

XML::Parser::Style::Stream - نمط التدفق لـ XML::Parser

الملخص

use XML::Parser;
my $p = XML::Parser->new(Style => 'Stream', Pkg => 'MySubs');
$p->parsefile('foo.xml');

{
  package MySubs;

  sub StartTag {
    my ($e, $name) = @_;
    # افعل شيئًا مع علامات البداية
  }

  sub EndTag {
    my ($e, $name) = @_;
    # افعل شيئًا مع علامات النهاية
  }

  sub Characters {
    my ($e, $data) = @_;
    # افعل شيئًا مع عقد النص
  }
}

الوصف

يستخدم هذا النمط الخيار Pkg للعثور على الإجراءات الفرعية في حزمة معينة لاستدعائها لكل حدث. إذا لم تكن أي من الإجراءات الفرعية التي يبحث عنها هذا النمط موجودة، فإن تأثير التحليل بهذا النمط هو طباعة نسخة قياسية من المستند بدون تعليقات أو إعلانات. تتلقى جميع الإجراءات الفرعية كمعلمة أولى لها مثيل Expat للمستند الذي تقوم بتحليله.

يبحث عن الروتينات التالية:

  • StartDocument

    يتم استدعاؤه في بداية التحليل.

  • StartTag

    يتم استدعاؤه لكل علامة بداية بمعلمة ثانية لنوع العنصر. سيحتوي المتغير $_ على نسخة من العلامة وسيحتوي المتغير %_ على قيم السمات المقدمة لهذا العنصر.

  • EndTag

    يتم استدعاؤه لكل علامة نهاية بمعلمة ثانية لنوع العنصر. سيحتوي المتغير $_ على نسخة من علامة النهاية.

  • Text

    يتم استدعاؤه قبل علامات البداية أو النهاية مباشرة مع نص غير علامات مجمعة في المتغير $_.

  • PI

    يتم استدعاؤه لتعليمات المعالجة. سيحتوي المتغير $_ على نسخة من PI ويتم إرسال الهدف والبيانات كمعلمات ثانية وثالثة على التوالي.

  • EndDocument

    يتم استدعاؤه عند الانتهاء من التحليل.
