XmVaCreateManagedArrowButtonGadget(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateArrowButtonGadget(استدعاء مكتبة) XmVaCreateArrowButtonGadget(استدعاء مكتبة)

الاسم

XmVaCreateArrowButtonGadget, XmVaCreateManagedArrowButtonGadget — وظائف إنشاء ملائمة لأداة ArrowButtonGadget.

الملخص

#include <Xm/ArrowBG.h>
Widget XmVaCreateArrowButtonGadget(
Widget parent,
String name,
...);
Widget XmVaCreateManagedArrowButtonGadget(
Widget parent,
String name,
...);

الوصف

تنشئ هذه الوظائف مثيلاً لأداة ArrowButtonGadget وتعيد معرف الأداة المرتبط. تستخدم هذه الروتينات اصطلاح استدعاء قائمة الوسائط المتغيرة ANSI C (varargs).

تعد الوظيفة XmVaCreateArrowButtonGadget روتينًا ملائمًا يستدعي XtCreateWidget.

تعد الوظيفة XmVaCreateManagedArrowButtonGadget روتينًا ملائمًا يستدعي XtCreateManagedWidget.

parent
يحدد معرف الأداة الأصل.
name
يحدد اسم الأداة التي تم إنشاؤها.
...
يحدد قائمة الوسائط المتغيرة لتجاوز افتراضيات الموارد.

للحصول على تعريف كامل لـ ArrowButtonGadget والموارد المرتبطة بها، انظر XmArrowButtonGadget(3).

الإرجاع

يعيد معرف أداة ArrowButtonGadget.

ذات الصلة

XmArrowButtonGadget(3), XmCreateArrowButtonGadget(3), XtCreateWidget(3), و XtCreateManagedWidget(3).
