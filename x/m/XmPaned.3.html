الاسم

XmPaned — فئة عنصر التحكم Paned

المُلَخَّص

#include <Xm/Paned.h>

الوصف

يدير عنصر التحكم Paned العناصر الفرعية بطريقة متجانبة عمودياً أو أفقياً مع وجود كل عنصر فرعي في لوحة منفصلة. يمكن إعادة تحجيم الألواح ديناميكيًا بواسطة المستخدم باستخدام "مقبض التحكم" الذي يظهر بين الألواح.

يتحكم مبرمجو التطبيقات في ما إذا كانت المقابض والفواصل معروضة أم لا، والحجم المفضل لكل لوحة، وأي لوحة سيتم إجبارها على استيعاب قيود الحجم المفروضة من قبل العنصر الأب لعنصر التحكم Paned.

إدارة الهندسة

عادةً ما يقوم عنصر التحكم Paned بإعادة تحجيم عناصره الفرعية إلى أحجامها المفضلة عند إدارة عنصر فرعي جديد. سيحاول أولاً تعديل حجم نفسه لاحتواء لوحاته بالكامل. إذا لم يكن هذا ممكنًا، فسيبحث عبر العناصر الفرعية، من الأسفل إلى الأعلى (أو من اليمين إلى اليسار)، عن لوحة لتعديل حجمها.

سيحاول عنصر التحكم Paned احترام طلب هندسة عناصره الفرعية. سيحاول أولاً تعديل حجم نفسه لتلبية الطلب ثم يمر عبر قواعد التخطيط أدناه لتلبية الطلب. فقط إذا كانت جميع الألواح عند الحد الأدنى/الأقصى لها، سيتم رفض طلب الهندسة. إذا كانت المورد XmNallowResize هو False للعنصر الفرعي، فسيتم رفض جميع طلبات الهندسة،
بالطبع.

اعتبارات خاصة

عندما يقوم المستخدم بتغيير حجم لوحة باستخدام المقابض، يفترض عنصر التحكم Paned أن هذا الحجم الجديد هو الحجم المفضل لكل من اللوحة العلوية واللوحة السفلية، ما لم يكن المورد XmNresizeToPreferred للعنصر المقيد صحيحًا لهذه اللوحة.

دلالات التخطيط

للاستفادة بفعالية من عنصر التحكم Paned، من المفيد معرفة القواعد التي يستخدمها لتحديد أي عنصر فرعي سيتم تغيير حجمه في أي موقف معين. هناك ثلاث قواعد مستخدمة لتحديد العنصر الفرعي الذي سيتم تغيير حجمه. بينما تظل هذه القواعد كما هي دائمًا، يمكن أن تتغير الألواح التي يتم البحث فيها اعتمادًا على ما تسبب في تغيير التخطيط.

قواعد التخطيط

1. لا تسمح للوحة بالنمو أكبر من حدها الأقصى أو أصغر من حدها الأدنى. بالإضافة إلى ذلك، لا تسمح للوحة بدون مقبض بالانكماش إلى ما دون حجمها المفضل بسبب حركة مقبض لوحة أخرى.

2. لا تعدل الألواح التي تم تعيين XmNskipAdjust لها.

3. لا تعدل الألواح بعيدًا عن حجمها المفضل، على الرغم من أن تحريك لوحة أقرب إلى حجمها المفضل لا بأس به.

عند البحث عن العناصر الفرعية، يبحث عنصر التحكم Paned عن الألواح التي تلبي جميع القواعد، وإذا لم ينجح، فإنه يلغي القاعدة 3 ثم القاعدة 2. القاعدة 1 مفروضة دائمًا.

إذا كان إعادة التخطيط بسبب تغيير حجم أو تغيير في الإدارة، يتم البحث عن الألواح من الأسفل إلى الأعلى. إذا كانت هناك حاجة لمساحة فوق المقبض الحالي، يتم البحث عن الألواح من الأسفل إلى الأعلى بدءًا من اللوحة الثانية فوق المقبض الذي تم تحريكه. إذا كانت هناك حاجة لمساحة أسفل المقبض الحالي، يتم البحث عن الألواح من الأعلى إلى الأسفل بدءًا من اللوحة الثانية أسفل المقبض الذي تم تحريكه. لا يقوم عنصر التحكم Paned بلف تغيير حجم لوحاته. لذلك، إذا كانت هناك حاجة لمساحة أسفل المقبض، فلن يتم تغيير حجم أي عنصر فرعي فوق المقبض.

ملاحظة: إذا كان الاتجاه أفقيًا، فاستبدل "اليمين" بـ "الأسفل" و "اليسار" بـ "الأعلى" في الفقرة المذكورة أعلاه.

تغيير حجم الألواح

عندما يتم تغيير حجم عنصر التحكم Paned، يجب عليه تحديد حجم جديد لكل لوحة. هناك طريقتان للقيام بذلك. يمكن لعنصر التحكم Paned إما منح كل لوحة حجمها المفضل ثم تغيير حجم الألواح لتناسبها، أو يمكنه استخدام الأحجام الحالية ثم تغيير حجم الألواح لتناسبها. يسمح المورد XmNresizeToPreferred المقيد للتطبيق بإخبار عنصر التحكم Paned ما إذا كان سيتم الاستعلام عن العنصر الفرعي حول حجمه المفضل (خاضع لـ XmNpreferredPaneSize) أو استخدام الحجم الحالي عند إعادة حساب مواقع الألواح بعد تغيير حجم عنصر التحكم Paned.

تفترض جميع الألواح أنها يجب أن تغير حجمها إلى حجمها المفضل حتى يصبح عنصر التحكم Paned مرئيًا للمستخدم.

الفئات

الموارد الجديدة

يحدد الجدول التالي مجموعة من موارد عنصر التحكم التي يستخدمها المبرمج لتحديد البيانات. يمكن للمبرمج أيضًا تعيين قيم الموارد للفئات الموروثة لتعيين سمات لهذا العنصر. للإشارة إلى مورد بالاسم أو الفئة في ملف .Xdefaults، قم بإزالة البادئة XmN أو XmC واستخدم الأحرف المتبقية. لتحديد إحدى القيم المعرفة لمورد في ملف .Xdefaults، قم بإزالة البادئة Xm واستخدم الأحرف المتبقية (بأحرف صغيرة أو كبيرة، ولكن قم بتضمين أي مسافات بادئة بين الكلمات). تشير الرموز في عمود الوصول إلى ما إذا كان يمكن تعيين المورد المحدد في وقت الإنشاء (C)، أو تعيينه باستخدام XtSetValues (S)، أو استرجاعه باستخدام XtGetValues (G)، أو غير قابل للتطبيق (N/A).

RESOURCES

The XmPaned widget has the following resources:

XmNallowResize
When set to True, this Boolean resource allows a pane to be resized. When set to False, the Paned widget always denies pane requests to resize.
XmNpaneMaximum
Allows an application to specify the maximum size to which a pane may be resized. This value must be greater than the specified minimum.
XmNpaneMinimum
Allows an application to specify the minimum size to which a pane may be resized. This value must be greater than 0 (zero).
XmNskipAdjust
When set to True, this Boolean resource allows an application to specify that the Paned widget should not automatically resize this pane.
XmNpreferredPaneSize
Preferred size of the pane. If this value is not set the paned widget will query the child for a preferred size. This resource allows the user or application to provide a new preferred size.
XmNresizeToPreferred
Specifies whether to resize each pane to its preferred size when the Paned window is resized. If this is False then only those panes the user has not resized with the sashes will be resized to their preferred size.
XmNshowSash
If True show the Sash below or to the right of this pane.
