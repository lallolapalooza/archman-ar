XmVaCreateScale(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateScale(استدعاء مكتبة) XmVaCreateScale(استدعاء مكتبة)

الاسم

XmVaCreateScale, XmVaCreateManagedScale — دوال مساعدة لإنشاء عنصر واجهة Scale.

ملخص

#include <Xm/Scale.h>
Widget XmVaCreateScale(
Widget parent,
String name,
...);
Widget XmVaCreateManagedScale(
Widget parent,
String name,
...);

الوصف

تقوم هذه الدوال بإنشاء نسخة من عنصر واجهة ToggleButtonGadget وتعيد معرف الواجهة المرتبط بها. تستخدم هذه الروتينات اتفاقية استدعاء قائمة الوسائط المتغيرة ANSI C (varargs).

الدالة XmVaCreateScale هي روتين مساعدة يستدعي XtCreateWidget.

الدالة XmVaCreateManagedScale هي روتين مساعدة يستدعي XtCreateManagedWidget.

parent
يحدد معرف الواجهة الأصل.
name
يحدد اسم الواجهة المنشأة.
...
يحدد قائمة الوسائط المتغيرة لتجاوز إعدادات الموارد الافتراضية.

للحصول على تعريف كامل لـ Scale والموارد المرتبطة بها، انظر XmScale(3).

القيمة المعادة

تعيد معرف الواجهة Scale.

ذات الصلة

XmScale(3), XmCreateScale(3), XtCreateWidget(3), و XtCreateManagedWidget(3).
