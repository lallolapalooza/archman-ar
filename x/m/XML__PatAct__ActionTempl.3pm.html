XML__PatAct__ActionTempl(3pm)

الحزمة: libxml-perl

التراخيص: GPL, PerlArtistic

XML::PatAct::ActionTempl(3) وثائق Perl المقدمة من المستخدم XML::PatAct::ActionTempl(3)

الاسم

XML::PatAct::ACTION - وحدة إجراء لـ

الملخص

use XML::PatAct::ACTION;
my $patterns = [ PATTERN => ACTION,
                 ... ];
my $matcher = XML::PatAct::ACTION->new(Patterns => $patterns,
                                       Matcher => $matcher );

الوصف

XML::PatAct::ACTION هي معالج PerlSAX لتطبيق قوائم الأنماط والإجراءات على محللات XML أو أشجارها. XML::PatAct::ACTION ...

يتم إنشاء مثيلات XML::PatAct::ACTION جديدة عن طريق استدعاء `new()'. يمكن تمرير المعلمات كقائمة من أزواج المفتاح والقيمة أو كهاش. خيارات Patterns و Matcher مطلوبة. Patterns هي قائمة الأنماط والإجراءات المراد تطبيقها. Matcher هو مثيل لوحدة مطابقة الأنماط أو الاستعلام.
