XmVaCreateManagedColumn(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateColumn(استدعاء مكتبة) XmVaCreateColumn(استدعاء مكتبة)

الاسم

XmVaCreateColumn, XmVaCreateManagedColumn — وظائف ملائمة لإنشاء عنصر واجهة المستخدم Column.

الملخص

#include <Xm/Column.h>
Widget XmVaCreateColumn(
Widget parent,
String name,
...);
Widget XmVaCreateManagedColumn(
Widget parent,
String name,
...);

الوصف

تقوم هذه الوظائف بإنشاء مثيل لعنصر واجهة المستخدم Column وتعيد معرّف العنصر المرتبط به. تستخدم هذه الروتينات اتفاقية استدعاء قائمة الوسائط المتغيرة ANSI C (varargs).

الوظيفة XmVaCreateColumn هي روتين ملائم يقوم باستدعاء XtCreateWidget.

الوظيفة XmVaCreateManagedColumn هي روتين ملائم يقوم باستدعاء XtCreateManagedWidget.

parent
يحدد معرّف العنصر الأب.
name
يحدد اسم العنصر الذي تم إنشاؤه.
...
يحدد قائمة الوسائط المتغيرة لتجاوز قيم الموارد الافتراضية.

للحصول على تعريف كامل لـ Column والموارد المرتبطة به، انظر XmColumn(3).

الإرجاع

يعيد معرّف عنصر واجهة المستخدم Column.

ذات الصلة

XmColumn(3), XmCreateColumn(3), XtCreateWidget(3), و XtCreateManagedWidget(3).
