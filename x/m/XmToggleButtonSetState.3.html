XmToggleButtonSetState(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmToggleButtonSetState(استدعاء مكتبة) XmToggleButtonSetState(استدعاء مكتبة)

الاسم

XmToggleButtonSetState — دالة ToggleButton تقوم بتعيين أو تغيير الحالة الحالية

ملخص

#include <Xm/ToggleB.h>
void XmToggleButtonSetState(
Widget widget,
Boolean state,
Boolean notify);

الوصف

XmToggleButtonSetState تقوم بتعيين أو تغيير الحالة الحالية لـ ToggleButton.

widget
يحدد معرف عنصر واجهة ToggleButton.
state
يحدد قيمة منطقية تشير إلى ما إذا كانت حالة ToggleButton محددة أو غير محددة. إذا كانت القيمة True، تكون حالة الزر محددة؛ إذا كانت False، تكون حالة الزر غير محددة.
notify
يشير إلى ما إذا كان سيتم استدعاء XmNvalueChangedCallback؛ يمكن أن يكون True أو False. يتم استدعاء XmNvalueChangedCallback فقط عندما تقوم هذه الدالة بتغيير حالة ToggleButton. عندما يكون هذا الوسيط True ويكون ToggleButton ابنًا لعنصر واجهة RowColumn لديه XmNradioBehavior بقيمة True، فإن تعيين ToggleButton يتسبب في إلغاء تحديد عناصر واجهة ToggleButton و ToggleButtonGadget الأخرى التابعة لـ RowColumn.

لتعريف كامل لـ ToggleButton والموارد المرتبطة به، راجع XmToggleButton(3).
