XmVaCreateMultiList(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateMultiList(استدعاء مكتبة) XmVaCreateMultiList(استدعاء مكتبة)

الاسم

XmVaCreateMultiList, XmVaCreateManagedMultiList — دوال مساعدة لإنشاء ودجات MultiList.

الملخص

#include <Xm/MultiList.h>
Widget XmVaCreateMultiList(
Widget parent,
String name,
...);
Widget XmVaCreateManagedMultiList(
Widget parent,
String name,
...);

الوصف

تقوم هذه الدوال بإنشاء مثيل لوجت ToggleButtonGadget وتعيد معرف الودجت المرتبط به. تستخدم هذه الروتينات اتفاقية استدعاء قائمة المتغيرات الطولية ANSI C (varargs).

الدالة XmVaCreateMultiList هي روتين مساعد يستدعي XtCreateWidget.

الدالة XmVaCreateMultiList هي روتين مساعد يستدعي XtCreateManagedWidget.

parent
يحدد معرف الودجت الأب.
name
يحدد اسم الودجت الذي تم إنشاؤه.
...
يحدد قائمة المتغيرات لتجاوز إعدادات الموارد الافتراضية.

للحصول على تعريف كامل لـ MultiList وموارده المرتبطة، انظر XmMultiList(3).

الإرجاع

يعيد معرف الودجت MultiList.

ذات صلة

XmMultiList(3), XmCreateMultiList(3), XtCreateWidget(3), و XtCreateManagedWidget(3).
