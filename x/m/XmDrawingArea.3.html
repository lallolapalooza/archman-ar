معلومات الاستدعاء

يتم تمرير مؤشر إلى البنية التالية إلى الإجراءات XmNexposeCallback و XmNinputCallback و XmNresizeCallback:

typedef struct
{
        int reason;
        XEvent * event;
        Window window;
} XmDrawingAreaCallbackStruct;
reason
يشير إلى سبب استدعاء الاستدعاء.
event
يشير إلى XEvent الذي أدى إلى تشغيل الاستدعاء. هذه القيمة NULL لـ XmNresizeCallback.
window
يتم تعيينها إلى نافذة الأداة.

يتم تمرير مؤشر إلى البنية التالية إلى الإجراءات XmNconvertCallback:

typedef struct
{
        int reason;
        XEvent *event;
        Atom selection;
        Atom target;
        XtPointer source_data;
        XtPointer location_data;
        int flags;
        XtPointer parm;
        int parm_format;
        unsigned long parm_length;
        int status;
        XtPointer value;
        Atom type;
        int format;
        unsigned long length;
} XmConvertCallbackStruct;
reason
يشير إلى سبب استدعاء الاستدعاء.
event
يشير إلى XEvent الذي أدى إلى تشغيل الاستدعاء. يمكن أن تكون هذه القيمة NULL.
selection
يشير إلى التحديد الذي يتم طلب التحويل له. القيم الممكنة هي CLIPBOARD و PRIMARY و SECONDARY و _MOTIF_DROP.
target
يشير إلى هدف التحويل.
source_data
يحتوي على معلومات حول مصدر التحديد. عندما يكون التحديد _MOTIF_DROP، فإن source_data هو سياق السحب. بخلاف ذلك، فإنه يكون NULL.
location_data
يحتوي على معلومات حول موقع البيانات المراد تحويلها. إذا كانت القيمة NULL، فإن البيانات المراد نقلها تتكون من التحديد الحالي للأداة.
flags
يشير إلى حالة التحويل. فيما يلي القيم الممكنة:
XmCONVERTING_NONE
هذا العلم غير مستخدم حاليًا.
XmCONVERTING_PARTIAL
تمكنت الأداة المستهدفة من التحويل، ولكن تم فقدان بعض البيانات.
XmCONVERTING_SAME
هدف التحويل هو مصدر البيانات المراد نقلها.
XmCONVERTING_TRANSACT
هذا العلم غير مستخدم حاليًا.
parm
يحتوي على بيانات المعلمات لهذا الهدف. إذا لم تكن هناك بيانات معلمات، فستكون القيمة NULL.
عندما يكون selection هو CLIPBOARD و target هو _MOTIF_CLIPBOARD_TARGETS أو _MOTIF_DEFERRED_CLIPBOARD_TARGETS، فإن القيمة هي العملية المطلوبة (XmCOPY أو XmMOVE أو XmLINK).
parm_format
يحدد ما إذا كان يجب النظر إلى البيانات الموجودة في parm كقائمة من الكميات char أو short أو long. القيم الممكنة هي 0 (عندما تكون parm NULL) أو 8 (عندما يجب النظر إلى البيانات الموجودة في parm كقائمة من chars) أو 16 (عندما يجب النظر إلى البيانات الموجودة في parm كقائمة من shorts) أو 32 (عندما يجب النظر إلى البيانات الموجودة في parm كقائمة من longs). لاحظ أن parm_format يرمز إلى نوع بيانات، وليس عدد البتات في كل عنصر قائمة. على سبيل المثال، في بعض الأجهزة، يعني parm_format بقيمة 32 أن البيانات الموجودة في parm يجب أن تُنظر إليها كقائمة من الكميات 64 بت، وليس 32 بت.
parm_length
يحدد عدد عناصر البيانات في parm، حيث يكون لكل عنصر الحجم المحدد بواسطة parm_format. عندما تكون parm NULL، تكون القيمة 0.
status
عضو IN/OUT يحدد حالة التحويل. القيمة الأولية هي XmCONVERT_DEFAULT. يمكن لإجراء الاستدعاء تعيين هذا العضو إلى إحدى القيم التالية:
XmCONVERT_DEFAULT
تعني هذه القيمة أنه يتم استدعاء إجراء تحويل فئة الأداة، إن وجد، بعد إرجاع إجراءات الاستدعاء. إذا أنتج إجراء تحويل فئة الأداة أي بيانات، فإنه يستبدل البيانات التي قدمتها إجراءات الاستدعاء في العضو value.
XmCONVERT_MERGE
تعني هذه القيمة أنه يتم استدعاء إجراء تحويل فئة الأداة، إن وجد، بعد إرجاع إجراءات الاستدعاء. إذا أنتج إجراء تحويل فئة الأداة أي بيانات، فإنه يضيف بياناته إلى البيانات التي قدمتها إجراءات الاستدعاء في العضو value. هذه القيمة مخصصة للاستخدام مع الأهداف التي ينتج عنها قوائم بيانات، مثل TARGETS.
XmCONVERT_DONE
تعني هذه القيمة أن إجراء الاستدعاء قد أكمل التحويل بنجاح. لا يتم استدعاء إجراء تحويل فئة الأداة، إن وجد، بعد إرجاع إجراءات الاستدعاء.
XmCONVERT_REFUSE
تعني هذه القيمة أن إجراء الاستدعاء قد أنهى عملية التحويل دون إكمال التحويل المطلوب. لا يتم استدعاء إجراء تحويل فئة الأداة، إن وجد، بعد إرجاع إجراءات الاستدعاء.
value
معامل IN/OUT يحتوي على أي بيانات تنتجها إجراءات الاستدعاء كنتيجة للتحويل. القيمة الأولية هي NULL. إذا قام إجراء الاستدعاء بتعيين هذا العضو، فيجب عليه التأكد من أن الأعضاء type و format و length تتوافق مع البيانات الموجودة في value. يتحمل إجراء الاستدعاء مسؤولية تخصيص الذاكرة، ولكن ليس تحريرها، عند تعيين هذا العضو.
type
معامل IN/OUT يشير إلى نوع البيانات الموجودة في العضو value. القيمة الأولية هي INTEGER.
format
معامل IN/OUT يحدد ما إذا كان يجب النظر إلى البيانات الموجودة في value كقائمة من الكميات char أو short أو long. القيمة الأولية هي 8. يمكن لإجراء الاستدعاء تعيين هذا العضو إلى 8 (لقائمة من char) أو 16 (لقائمة من short) أو 32 (لقائمة من long).
length
عضو IN/OUT يحدد عدد عناصر البيانات في value، حيث يكون لكل عنصر الحجم الذي يرمز إليه format. القيمة الأولية هي 0.

        int reason;
        XEvent *event;
        Atom selection;
        XtEnum operation;
        int flags;
        XtPointer transfer_id;
        XtPointer destination_data;
        XtPointer location_data;
        Time time;

reason
يشير إلى سبب استدعاء الاستدعاء.
event
يشير إلى XEvent الذي أدى إلى تشغيل الاستدعاء. يمكن أن تكون هذه القيمة NULL.
selection
يشير إلى التحديد الذي يتم طلب نقل البيانات له. القيم الممكنة هي CLIPBOARD و PRIMARY و SECONDARY و _MOTIF_DROP.
operation
يشير إلى نوع عملية النقل المطلوبة.
•
عندما يكون التحديد PRIMARY، فإن القيم الممكنة هي XmMOVE و XmCOPY و XmLINK.
•
عندما يكون التحديد SECONDARY أو CLIPBOARD، فإن القيم الممكنة هي XmCOPY و XmLINK.
•
عندما يكون التحديد _MOTIF_DROP، فإن القيم الممكنة هي XmMOVE و XmCOPY و XmLINK و XmOTHER. القيمة XmOTHER تعني أن إجراء الاستدعاء يجب أن يحصل على مزيد من المعلومات من XmDropProcCallbackStruct في العضو destination_data.
flags
يشير إلى ما إذا كانت أداة الوجهة هي أيضًا مصدر البيانات المراد نقلها أم لا. فيما يلي القيم الممكنة:
XmCONVERTING_NONE
أداة الوجهة ليست مصدر البيانات المراد نقلها.
XmCONVERTING_SAME
أداة الوجهة هي مصدر البيانات المراد نقلها.
transfer_id
يعمل كمعرف فريد

NAME

XmDrawingArea

a drawing area widget

SYNOPSIS

#include <Xm/DrawingA.h>

DESCRIPTION

The XmDrawingArea widget provides a generic area for drawing and event handling. It is a subclass of XmManager. The XmDrawingArea widget has no children and therefore does not perform any geometry management.

The XmDrawingArea widget supports the following resources:

XmNclipWindow
Specifies a clipping window. This resource is a Boolean and is TRUE by default. If TRUE, the widget creates a clip window. The clip window is used to ensure that drawing is clipped to the widget's boundaries. If FALSE, no clip window is created, and the widget does not clip drawing operations.
XmNdrawingPolicy
Specifies how the widget handles expose events. The default value is XmRETAINED. The valid values are:
XmRETAINED
The widget retains its contents when it is exposed. The widget's background is not cleared, and the XmNexposeCallback is called with the XmEXPOSE event.
XmNONRETAINED
The widget does not retain its contents when it is exposed. The widget's background is cleared, and the XmNexposeCallback is called with the XmEXPOSE event.
XmNexposeCallback
Specifies a list of callbacks that are invoked when the widget receives an XmEXPOSE event. The callback reason is XmCR_EXPOSE.
XmNinputCallback
Specifies a list of callbacks that are invoked when the widget receives a keyboard or mouse input event. The callback reason is XmCR_INPUT.
XmNresizeCallback
Specifies a list of callbacks that are invoked when the widget is resized. The callback reason is XmCR_RESIZE.

The XmDrawingArea widget also supports all the resources of XmManager.

Callback Structures

The callback structure for the XmDrawingArea widget is XmDrawingAreaCallbackStruct.

reason
Indicates the reason why the callback was invoked. For XmDrawingArea, the possible reasons are:
XmCR_EXPOSE
An expose event occurred.
XmCR_INPUT
An input event occurred.
XmCR_RESIZE
The widget was resized.
event
A pointer to the X event that triggered the callback. This is a valid pointer for XmCR_EXPOSE and XmCR_INPUT callbacks. For XmCR_RESIZE callbacks, this pointer is NULL.
window
The window ID of the widget that received the event. This is valid for XmCR_EXPOSE and XmCR_INPUT callbacks.
xdisplay
The display pointer for the widget. This is valid for XmCR_EXPOSE and XmCR_INPUT callbacks.
widget
The widget that received the event. This is valid for XmCR_EXPOSE and XmCR_INPUT callbacks.
width
The width of the widget after resizing. This is valid for XmCR_RESIZE callbacks.
height
The height of the widget after resizing. This is valid for XmCR_RESIZE callbacks.

The XmDrawingArea widget also supports the following transfer resources:

transfer_id
A unique identifier for the transfer transaction. This is a type XmTransferId.
destination_data
Contains information about the destination. When the selection is _MOTIF_DROP, the callback procedures are called by the drop site's XmNdropProc, and destination_data is a pointer to the XmDropProcCallbackStruct passed to the XmNdropProc procedure. When the selection is SECONDARY, destination_data is an Atom representing a target recommmended by the selection owner for use in converting the selection. Otherwise, destination_data is NULL.
location_data
Contains information about the location where data is to be transferred. The value is always NULL when the selection is SECONDARY or CLIPBOARD. If the value is NULL, the data is to be inserted at the widget's cursor position. location_data is only valid for the duration of a transfer. Once XmTransferDone procedures start to be called, location_data will no longer be stable.
time
Indicates the time when the transfer operation began.

Translations

XmDrawingArea inherits translations from XmManager. Before calling the XmManager actions, all events in the inherited translations except <BtnMotion>, <EnterWindow>, <LeaveWindow>, <FocusIn>, and <FocusOut> also call the DrawingAreaInput() action.

XmDrawingArea has the following additional translations. The following key names are listed in the X standard key event translation table syntax. This format is the one used by Motif to specify the widget actions corresponding to a given key. A brief overview of the format is provided under VirtualBindings(3). For a complete description of the format, please refer to the X Toolkit Instrinsics Documentation.

<BtnDown>:
DrawingAreaInput()
<BtnUp>:
DrawingAreaInput()
<KeyDown>:
DrawingAreaInput() ManagerGadgetKeyInput()
<KeyUp>:
DrawingAreaInput()

Action Routines

The XmDrawingArea action routines are

DrawingAreaInput():
Unless the event takes place in a gadget, calls the callbacks for XmNinputCallback
ManagerGadgetKeyInput():
Causes the current gadget to process a keyboard event

Additional Behavior

The XmDrawingArea widget has the following additional behavior:

<Expose>:
Calls the callbacks for XmNexposeCallback
<Widget Resize>:
Calls the callbacks for XmNresizeCallback
