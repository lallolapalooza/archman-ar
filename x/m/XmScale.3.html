الاسم

XmScale — فئة عنصر تحكم Scale

الملخص

#include <Xm/Scale.h>

الوصف

يستخدم Scale بواسطة التطبيق للإشارة إلى قيمة من ضمن نطاق من القيم، ويتيح للمستخدم إدخال أو تعديل قيمة من نفس النطاق.

يحتوي Scale على منطقة مستطيلة مطولة تشبه شريط التمرير (ScrollBar). يشير شريط التمرير داخل هذه المنطقة إلى القيمة الحالية على طول Scale. يمكن للمستخدم أيضًا تعديل قيمة Scale عن طريق تحريك شريط التمرير داخل المنطقة المستطيلة لـ Scale. يمكن لـ Scale أيضًا تضمين مجموعة تسميات تقع خارج منطقة Scale. يمكن لهذه أن تشير إلى القيمة النسبية في مواضع مختلفة على طول Scale. يعتمد وضع هذه التسمية على مورد XmNlayoutDirection لعنصر التحكم.

يمكن أن يكون Scale للإدخال/الإخراج أو للإخراج فقط. يمكن للتطبيق تعيين قيمة Scale للإدخال/الإخراج، ويمكن للمستخدم أيضًا تعديلها باستخدام شريط التمرير. يستخدم Scale الإخراج فقط كمؤشر للقيمة الحالية لشيء ما ولا يمكن تعديله بشكل تفاعلي بواسطة المستخدم. يحدد مورد XmScale XmNeditable ما إذا كان يمكن للمستخدم تعديل قيمة Scale بشكل تفاعلي.

يمكن للمستخدم تحديد الموارد في ملف موارد الأداة (gadget) التي تم إنشاؤها تلقائيًا والتي تحتوي على عنوان عنصر تحكم Scale. اسم الأداة هو Title. يعتمد وضع العنوان على مورد XmNlayoutDirection لعنصر التحكم. يعتمد اتجاه العنوان على اتجاه تخطيط عنصر التحكم.

يستخدم Scale سمة XmQTspecifyRenderTable، ويحتفظ بسمة XmQTtransfer.

سلوك نقل البيانات

يدعم Scale سحب تمثيل قيمة Scale من Scale عندما يتم عرض القيمة وعندما يتم تعيين قيمة مورد XmNenableUnselectableDrag الخاص بـ XmDisplay على True.

كمصدر للبيانات، يدعم Scale الأهداف التالية والتحويلات المرتبطة بها للبيانات إلى هذه الأهداف:

COMPOUND_TEXT
ينقل عنصر التحكم تمثيلاً نصيًا لـ XmNvalue كنوع COMPOUND_TEXT.
UTF8_STRING
ينقل عنصر التحكم تمثيلاً نصيًا لـ XmNvalue كنوع UTF8_STRING.
STRING
ينقل عنصر التحكم تمثيلاً نصيًا لـ XmNvalue كنوع STRING.
_MOTIF_CLIPBOARD_TARGETS
ينقل عنصر التحكم، كنوع ATOM، قائمة بالأهداف التي يدعمها لاختيار CLIPBOARD. وتشمل هذه STRING و COMPOUND_TEXT و UTF8_STRING.
_MOTIF_EXPORT_TARGETS
ينقل عنصر التحكم، كنوع ATOM، قائمة بالأهداف التي سيتم استخدامها كقيمة لـ XmNexportTargets في سياق السحب والإفلات (drag-and-drop). وتشمل هذه STRING و COMPOUND_TEXT و UTF8_STRING.

كمصدر للبيانات، يدعم Scale أيضًا الأهداف القياسية التالية لـ Motif:

BACKGROUND
ينقل عنصر التحكم XmNbackground كنوع PIXEL.
CLASS
يجد عنصر التحكم أول نافذة (shell) في التسلسل الهرمي لعناصر التحكم التي تحتوي على خاصية WM_CLASS وينقل محتوياتها كنص باللغة المحلية الحالية.
CLIENT_WINDOW
يجد عنصر التحكم أول نافذة (shell) في التسلسل الهرمي لعناصر التحكم وينقل نافذتها كنوع WINDOW.
COLORMAP
ينقل عنصر التحكم XmNcolormap كنوع COLORMAP.
FOREGROUND
ينقل عنصر التحكم XmNforeground كنوع PIXEL.
NAME
يجد عنصر التحكم أول نافذة (shell) في التسلسل الهرمي لعناصر التحكم التي تحتوي على خاصية WM_NAME وينقل محتوياتها كنص باللغة المحلية الحالية.
TARGETS
ينقل عنصر التحكم، كنوع ATOM، قائمة بالأهداف التي يدعمها. وتشمل هذه الأهداف القياسية في هذه القائمة. وتشمل أيضًا STRING و COMPOUND_TEXT و UTF8_STRING.
TIMESTAMP
ينقل عنصر التحكم الطابع الزمني المستخدم للحصول على الاختيار كنوع INTEGER.
_MOTIF_RENDER_TABLE
ينقل عنصر التحكم XmNrenderTable إذا كان موجودًا، أو جدول عرض النص الافتراضي، كنوع STRING.
_MOTIF_ENCODING_REGISTRY
ينقل عنصر التحكم سجل الترميز الخاص به كنوع STRING. القيمة هي قائمة بعناصر مفصولة بـ NULL في شكل أزواج علامة الترميز. يرمز هذا الهدف إلى هدف النقل لسجل ترميز مقاطع Motif. يمكن للتطبيقات وعناصر التحكم استخدام هذا السجل لتسجيل تنسيقات ترميز النص لعلامات جدول العرض المحددة. تصل التطبيقات إلى هذا السجل عن طريق استدعاء XmRegisterSegmentEncoding و XmMapSegmentEncoding.

XmScale - Scale widget, a positioner widget

#include <Xm/Scale.h>

Widget XmCreateScale(Widget parent, char *name, ArgList args, Cardinal arg_count);

The Scale widget is a positioner widget. It displays a slider in a scale, and the user can move the slider to set a value. The scale can be horizontal or vertical. The scale can be oriented as a slider or as a single-shot slider (where the user clicks a button to increment or decrement the value). The Scale widget also supports the Motif drag-and-drop protocol.

The Scale widget includes a label that can be displayed either above or to the side of the scale. This label is a child of the Scale widget.

The Scale widget also includes a text field where the user can enter the desired value directly. This text field is also a child of the Scale widget.

The Scale widget supports the following resource types:

XmNdecimalPoints

Specifies the number of digits to the right of the decimal point.

XmNdecrementCallback

Specifies a list of callbacks to be called when the user decrements the value by clicking the decrement button.

XmNdragCallback

Specifies a list of callbacks to be called when the value changes during a drag operation.

XmNeditMode

Specifies whether the Scale widget is in edit mode or slider mode. In edit mode, the user can enter the value directly into the text field. In slider mode, the user can only move the slider.

XmNincrement

Specifies the amount to increment or decrement the value when the user clicks the increment or decrement button.

XmNincrementCallback

Specifies a list of callbacks to be called when the user increments the value by clicking the increment button.

XmNinverted

Specifies whether the Scale widget is inverted. In an inverted scale, the value increases as the slider moves down or to the left.

XmNlabelString

Specifies the string to be displayed in the label.

XmNmaximum

Specifies the maximum value of the scale.

XmNminimum

Specifies the minimum value of the scale.

XmNscaleBottom

Specifies the value of the bottom of the scale.

XmNscaleGray

Specifies the gray value of the scale.

XmNscaleLeft

Specifies the value of the left of the scale.

XmNscaleRight

Specifies the value of the right of the scale.

XmNscaleTop

Specifies the value of the top of the scale.

XmNshowValue

Specifies whether the text field is displayed.

XmNtopShadowPixmap

Specifies the pixmap to be used for the top shadow.

XmNvalueChangedCallback

Specifies a list of callbacks to be called when the value changes.

XmNvalueW

Specifies the current value of the scale.

event
Points to the XEvent that triggered the callback
