XML__LibXML__Pattern(3pm)

الحزمة: perl-xml-libxml

التراخيص: GPL

XML::LibXML::Pattern(3) توثيق Perl مساهم به XML::LibXML::Pattern(3)

الاسم

XML::LibXML::Pattern - واجهة XML::LibXML::Pattern - لأنماط XPath لـ libxml2

ملخص

use XML::LibXML;
my $pattern = XML::LibXML::Pattern->new('/x:html/x:body//x:div', { 'x' => 'http://www.w3.org/1999/xhtml' });
# اختبار تطابق على عقدة XML::LibXML::Node $node
if ($pattern->matchesNode($node)) { ... }
# أو على قارئ XML::LibXML::Reader
if ($reader->matchesPattern($pattern)) { ... }
# أو تخطي قراءة جميع العقد التي لا تتطابق
print $reader->nodePath while $reader->nextPatternMatch($pattern);
$pattern = XML::LibXML::Pattern->new( pattern, { prefix => namespace_URI, ... } );
$bool = $pattern->matchesNode($node);

الوصف

هذه واجهة Perl لدعم مطابقة الأنماط في libxml2 http://xmlsoft.org/html/libxml-pattern.html. يتطلب هذا الميزة إصدارات حديثة من libxml2.

الأنماط هي مجموعة فرعية صغيرة من لغة XPath، والتي تقتصر على (مجموعات منفصلة من) مسارات الموقع التي تتضمن محوري الطفل والسليل في شكل مختصر كما هو موضح في BNF الممتد أدناه:

Selector ::=     Path ( '|' Path )*
Path     ::=     ('.//' | '//' | '/' )? Step ( '/' Step )*
Step     ::=     '.' | NameTest
NameTest ::=     QName | '*' | NCName ':' '*'

لتحسين قابلية القراءة، يمكن استخدام المسافات البيضاء في عبارات XPath النمطية على الرغم من أنها غير مسموح بها صراحةً بواسطة القواعد: يمكن إضافة المسافات البيضاء بحرية داخل الأنماط قبل أو بعد أي رمز، حيث

token     ::=     '.' | '/' | '//' | '|' | NameTest

لاحظ أنه لا يُسمح بأي شروط أو اختبارات للسمات.

تكون الأنماط مفيدة بشكل خاص لتحليل التدفق المقدم عبر الواجهة "XML::LibXML::Reader".

جديد()
$pattern = XML::LibXML::Pattern->new( pattern, { prefix => namespace_URI, ... } );

يأخذ مُنشئ النمط تعبير النمط (كما هو موضح في قواعد BNF أعلاه) ومرجع HASH اختياري يقوم بتعيين البادئات إلى معرفات موارد مساحة الاسم. تعيد الدالة كائن نمط مجمع.

لاحظ أنه إذا كان للمستند مساحة اسم افتراضية، فيجب تعيين بادئة لها لتتم مطابقتها (كما هو مطلوب بموجب مواصفات XPath 1.0). على سبيل المثال، لمطابقة عنصر "<a xmlns="http://foo.bar"</a>"، يجب استخدام نمط مثل هذا:

$pattern = XML::LibXML::Pattern->new( 'foo:a', { foo => 'http://foo.bar' });
matchesNode($node)
$bool = $pattern->matchesNode($node);

نظرًا لكائن XML::LibXML::Node، تعيد قيمة صحيحة إذا تمت مطابقة العقدة بتعبير النمط المجمع.

انظر أيضًا

XML::LibXML::Reader للحصول على طرق أخرى تتضمن أنماطًا مجمعة.
