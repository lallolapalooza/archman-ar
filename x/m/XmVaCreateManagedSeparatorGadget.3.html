XmVaCreateManagedSeparatorGadget(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateSeparatorGadget(استدعاء مكتبة) XmVaCreateSeparatorGadget(استدعاء مكتبة)

الاسم

XmVaCreateSeparatorGadget، XmVaCreateManagedSeparatorGadget — وظائف إنشاء ملائمة لعنصر واجهة المستخدم SeparatorGadget.

ملخص

#include <Xm/SeparatorG.h>
Widget XmVaCreateSeparatorGadget(
Widget parent,
String name,
...);
Widget XmVaCreateManagedSeparatorGadget(
Widget parent,
String name,
...);

الوصف

تقوم هذه الوظائف بإنشاء نسخة من عنصر واجهة المستخدم ToggleButtonGadget وإرجاع معرف الواجهة المرتبط به. تستخدم هذه الروتينات اتفاقية استدعاء قائمة الوسائط المتغيرة ANSI C (varargs).

الوظيفة XmVaCreateSeparatorGadget هي روتين ملائم يستدعي XtCreateWidget.

الوظيفة XmVaCreateSeparatorGadget هي روتين ملائم يستدعي XtCreateManagedWidget.

parent
يحدد معرف الواجهة الأب.
name
يحدد اسم الواجهة التي تم إنشاؤها.
...
يحدد قائمة الوسائط المتغيرة لتجاوز افتراضات الموارد.

للحصول على تعريف كامل لـ SeparatorGadget والموارد المرتبطة به، انظر XmSeparatorGadget(3).

الإرجاع

ترجع معرف الواجهة SeparatorGadget.

ذات الصلة

XmSeparatorGadget(3)، XmCreateSeparatorGadget(3)، XtCreateWidget(3)، و XtCreateManagedWidget(3).
