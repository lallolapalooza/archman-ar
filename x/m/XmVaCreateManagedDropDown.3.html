XmVaCreateManagedDropDown(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateDropDown(استدعاء مكتبة) XmVaCreateDropDown(استدعاء مكتبة)

الاسم

XmVaCreateDropDown, XmVaCreateManagedDropDown — وظائف مساعدة لإنشاء عناصر من نوع DropDown.

الموجز

#include <Xm/DropDown.h>
Widget XmVaCreateDropDown(
Widget parent,
String name,
...);
Widget XmVaCreateManagedDropDown(
Widget parent,
String name,
...);

الوصف

تقوم هذه الوظائف بإنشاء مثيل لعنصر DropDown وإرجاع معرف العنصر المرتبط. تستخدم هذه الروتينات اصطلاح استدعاء قائمة وسيطات متغيرات ANSI C (varargs).

XmVaCreateDropDown هي روتين مساعد يستدعي XtCreateWidget.

XmVaCreateManagedDropDown هي روتين مساعد يستدعي XtCreateManagedWidget.

parent
يحدد معرف العنصر الأب.
name
يحدد اسم العنصر الذي تم إنشاؤه.
...
يحدد قائمة الوسائط المتغيرة لتجاوز القيم الافتراضية للموارد.

للحصول على تعريف كامل لـ DropDown والموارد المرتبطة به، انظر XmDropDown(3).

الإرجاع

ترجع معرف عنصر DropDown.

ذات الصلة

XmDropDown(3), XmCreateDropDown(3), XtCreateWidget(3), و XtCreateManagedWidget(3).
