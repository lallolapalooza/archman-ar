XmCreateNotebook(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmCreateNotebook(استدعاء مكتبة) XmCreateNotebook(استدعاء مكتبة)

الاسم

XmCreateNotebook — دالة إنشاء أداة Notebook

الاختصار

#include <Xm/Notebook.h>
void XmCreateNotebook(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

الوصف

XmCreateNotebook تنشئ نسخة من أداة Notebook وتعيد معرف الأداة المرتبط بها.

parent
يحدد معرف الأداة الأصل.
name
يحدد اسم الأداة التي تم إنشاؤها.
arglist
يحدد قائمة الوسائط.
argcount
يحدد عدد أزواج السمات/القيم في قائمة الوسائط (arglist).

لتعريف كامل لـ Notebook وموارده المرتبطة، انظر XmNotebook(3).

الإرجاع

يعيد معرف أداة Notebook.

ذات صلة

XmNotebook(3).
