الاسم

XmArrowButton — فئة عنصر تحكم ArrowButton

الملخص

#include <Xm/ArrowB.h>

الوصف

يتكون ArrowButton من سهم اتجاهي محاط بظل حد. عند تحديده، يتغير الظل لإعطاء انطباع بأن ArrowButton قد تم الضغط عليه. عندما لا يكون ArrowButton محددًا، يعود الظل لإعطاء انطباع بأن ArrowButton قد تم تحريره، أو تم إخراجه.

يحمل ArrowButton السمة XmQTactivatable.

الفئات

يرث ArrowButton السلوك والموارد والسمات من فئات Core و XmPrimitive.

مؤشر الفئة هو xmArrowButtonWidgetClass.

اسم الفئة هو XmArrowButton.

موارد جديدة

يحدد الجدول التالي مجموعة من موارد عناصر التحكم التي يستخدمها المبرمج لتحديد البيانات. يمكن للمبرمج أيضًا تعيين قيم الموارد للفئات الموروثة لتعيين سمات لعنصر التحكم هذا. للإشارة إلى مورد بالاسم أو بالفئة في ملف .Xdefaults، قم بإزالة البادئة XmN أو XmC واستخدم الأحرف المتبقية. لتحديد أحد القيم المعرفة لمورد في ملف .Xdefaults، قم بإزالة البادئة Xm واستخدم الأحرف المتبقية (بأحرف صغيرة أو كبيرة، ولكن قم بتضمين أي شرطات سفلية بين الكلمات). تشير الرموز في عمود الوصول إلى ما إذا كان يمكن تعيين المورد المعطى في وقت الإنشاء (C)، أو تعيينه باستخدام XtSetValues (S)، أو استرجاعه باستخدام XtGetValues (G)، أو غير قابل للتطبيق (N/A).

XmNactivateCallback
يحدد قائمة بمسؤولات الاستدعاء التي يتم استدعاؤها عند تنشيط ArrowButton. لتنشيط الزر، اضغط مع تحرير BSelect أثناء وجود المؤشر داخل عنصر تحكم ArrowButton. يقوم تنشيط ArrowButton أيضًا بتعطيله. السبب المرسل بواسطة مسؤول الاستدعاء هذا هو XmCR_ACTIVATE. يستخدم مسؤول الاستدعاء هذا السمة XmQTactivatable.
XmNarmCallback
يحدد قائمة بمسؤولات الاستدعاء التي يتم استدعاؤها عند تسليح ArrowButton. لتسليح عنصر التحكم هذا، اضغط BSelect أثناء وجود المؤشر داخل ArrowButton. السبب المرسل بواسطة مسؤول الاستدعاء هذا هو XmCR_ARM.

•
XmARROW_DOWN
•
XmARROW_LEFT

XmARROW_RIGHT
XmNdetailShadowThickness
يحدد سمك ظلال السهم الداخلية. السمك الافتراضي هو 2 بكسل.
XmNdisarmCallback
يحدد قائمة بمسؤولات الاستدعاء التي يتم استدعاؤها عند تعطيل ArrowButton. لتعطيل عنصر التحكم هذا، اضغط مع تحرير BSelect أثناء وجود المؤشر داخل ArrowButton. سبب مسؤول الاستدعاء هذا هو XmCR_DISARM.
XmNmultiClick
إذا تم اتباع نقرة زر بنقرة زر أخرى خلال الفترة الزمنية المحددة بواسطة وقت النقرة المتعدد للشاشة، وكان هذا المورد معينًا إلى XmMULTICLICK_DISCARD، فلن تتم معالجة النقرة الثانية. إذا تم تعيين هذا المورد إلى XmMULTICLICK_KEEP، فسيتم معالجة الحدث وسيتم زيادة click_count في هيكل مسؤول الاستدعاء. عند عدم وجود الزر في قائمة، القيمة الافتراضية هي XmMULTICLICK_KEEP.

NAME

XmArrowButton, XmArrowButtonGadget — A callback for ArrowButton widgets

SYNOPSIS

#include <Xm/ArrowB.h>

DESCRIPTION

The ArrowButton widget provides a clicking area that activates a callback procedure when clicked. The widget displays an arrow that can point in any of the four cardinal directions.

The following actions are defined for this widget:

ButtonActivate():
Activates the widget and calls the callbacks for XmNactivateCallback.
ButtonDepress():
Draws the shadow in the selected state and calls the callbacks for XmNarmCallback.
ButtonRetract():
Draws the shadow in the unselected state and calls the callbacks for XmNdisarmCallback.
FocusIn():
Draws the shadow in the selected state.
FocusOut():
Draws the shadow in the unselected state.
Enter():
Draws the shadow in the selected state.
Leave():
Draws the shadow in the unselected state.
Help():
Calls the callbacks for XmNhelpCallback if any exist. If there are no help callbacks for this widget, this action calls the help callbacks for the nearest ancestor that has them.

ButtonTakeFocus():

Causes the ArrowButton to take keyboard focus when Ctrl<Btn1Down> is pressed, without activating the widget.

Disarm():

Draws the shadow in the unselected state and calls the callbacks for XmNdisarmCallback.

Help():

Calls the callbacks for XmNhelpCallback if any exist. If there are no help callbacks for this widget, this action calls the help callbacks for the nearest ancestor that has them.

MultiActivate():

If XmNmultiClick is XmMULTICLICK_DISCARD, this action does nothing.

If XmNmultiClick is XmMULTICLICK_KEEP, this action increments click_count in the callback structure and draws the shadow in the unselected state. If the pointer is within the ArrowButton, this action calls the callbacks for XmNactivateCallback and XmNdisarmCallback.

MultiArm():

If XmNmultiClick is XmMULTICLICK_DISCARD, this action does nothing. If XmNmultiClick is XmMULTICLICK_KEEP, this action draws the shadow in the selected state and calls the callbacks for XmNarmCallback.

Additional Behavior

This widget has the following additional behavior:

<EnterWindow>:
Draws the ArrowButton shadow in its selected state if the pointer leaves and re-enters the window while <Btn1> is pressed.
<LeaveWindow>:
Draws the ArrowButton shadow in its unselected state if the pointer leaves the window while <Btn1> is pressed.

Virtual Bindings

The bindings for virtual keys are vendor specific. For information about bindings for virtual buttons and keys, see VirtualBindings(3).
