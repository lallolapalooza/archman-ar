XmCreateHierarchy(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmCreateHierarchy(استدعاء مكتبة) XmCreateHierarchy(استدعاء مكتبة)

الاسم

XmCreateHierarchy — دالة إنشاء عنصر واجهة المستخدم Hierarchy

الملخص

#include <Xm/Hierarchy.h>
Widget XmCreateHierarchy(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

الوصف

تقوم XmCreateHierarchy بإنشاء مثيل لعنصر واجهة المستخدم Hierarchy وتعيد معرف الواجهة.

parent
يحدد معرف الواجهة الأصل
name
يحدد اسم الواجهة المنشأة
arglist
يحدد قائمة الوسائط
argcount
يحدد عدد أزواج السمة/القيمة في قائمة الوسائط (arglist)

للحصول على تعريف كامل لـ Hierarchy والموارد المرتبطة به، انظر XmHierarchy(3).

القيمة المرجعة

تعيد معرف الواجهة Hierarchy.
