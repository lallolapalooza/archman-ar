موارد جديدة

يحدد الجدول التالي مجموعة من موارد الـ Widget التي يستخدمها المبرمج لتحديد البيانات. يمكن للمبرمج أيضًا تعيين قيم الموارد للفئات الموروثة لتعيين سمات لهذا الـ Widget. للإشارة إلى مورد بالاسم أو بالفئة في ملف .Xdefaults، قم بإزالة البادئة XmN أو XmC واستخدم الأحرف المتبقية. لتحديد أحد القيم المعرفة لمورد في ملف .Xdefaults، قم بإزالة البادئة Xm واستخدم الأحرف المتبقية (بأحرف صغيرة أو كبيرة، ولكن قم بتضمين أي شرطات سفلية بين الكلمات). تشير الرموز في عمود الوصول إلى ما إذا كان يمكن تعيين المورد المعطى وقت الإنشاء (C)، أو تعيينه باستخدام XtSetValues (S)، أو استرجاعه باستخدام XtGetValues (G)، أو أنه غير قابل للتطبيق (N/A).

RESOURCES

XmNancestorSensitive
This resource is used to control the sensitivity of the widget and its children. When this resource is True, the widget and its children are allowed to be sensitive. When it is False, the widget and its children are forced to be insensitive. This resource is dynamically set by the toolkit based on the sensitivity of the parent widget. It is not intended to be set directly by the application.
XmNautoShowCursorPosition
Causes the cursor to be automatically displayed at the insertion point when the Boolean value is True. If the Boolean value is False, the cursor is only displayed when the user directly interacts with the widget. The default value is True.
XmNcursorPosition
Specifies the cursor position within the text. The position is zero-based. The default value is 0.
XmNcursorPositionVisible
Indicates whether the cursor is visible when the Boolean value is True. The default value is True.
XmNdisplayPos
Specifies the starting position of the text displayed in the window. This resource is ignored if the widget is not a scrolled text widget or if XmNscrollHorizontal or XmNscrollVertical is False. The default value is 0.
XmNeditMode
Specifies the edit mode for the Text widget. The possible values are XmSINGLE_LINE_EDIT and XmMULTIPLE_LINE_EDIT. The default value is XmMULTIPLE_LINE_EDIT.
XmNfontList
Specifies the font list to be used for rendering text. If the value is NULL at initialization, the parent hierarchy of the widget is searched for an ancestor that holds the XmQTspecifyFontList trait. If such an ancestor is found, the font list is initialized to the XmTEXT_FONT_LIST value of the ancestor widget. If no such ancestor is found, the default is implementation dependent.
Text searches the font list for the first occurrence of a font set that has XmFONTLIST_DEFAULT_TAG. If a default element is not found, the first font set in the font list is used. If the list contains no font sets, the first font in the font list will be used. Refer to XmFontList(3) for more information on a font list structure.
XmNmaxLength
Specifies the maximum number of characters that can be entered into the text widget. If the value is 0, there is no maximum length. The default value is 0.
XmNpostVerifyCallback
Specifies a list of callbacks to be called after the text has been modified. The callback reason is XmCR_POST_VERIFY. The default value is NULL.
XmNpreeditType
Specifies the preedit type for Input Method editors. This resource is used by Input Method clients and may not be supported by all Input Method servers. The default value is implementation dependent.
XmNrenderTable
Specifies the render table to be used in deriving a font set or font for rendering text. If both a render table and a font list are specified, the render table will take precedence. If the value of XmNrenderTable is NULL at initialization, the parent hierarchy of the widget is searched for an ancestor that holds the XmQTspecifyRenderTable trait. If such an ancestor is found, the font list is initialized to the XmTEXT_RENDER_TABLE value of the ancestor widget. If no such ancestor is found, the default is implementation dependent.
Text searches the render table for the first occurrence of a rendition that has the tag _MOTIF_DEFAULT_LOCALE. If a default element is not found, the first rendition in the table is used. Refer to XmRenderTable(3) for more information on the render table structure.
XmNresizeHeight
Indicates that Text will attempt to resize its height to accommodate all the text contained in the widget when the Boolean value is True. If the Boolean value is set to True, the text is always displayed, starting from the first position in the source, even if instructed otherwise. This attribute is ignored when the application uses a Text widget whose parent is a ScrolledWindow and when XmNscrollVertical is True.
When the XmNlayoutDirection resource is XmTOP_TO_BOTTOM, this resource indicates that the text attempts to resize its height to accommodate all the text contained in the widget when the Boolean value is True. This attribute is ignored if XmNwordWrap is True.
XmNresizeWidth
Indicates that Text attempts to resize its width to accommodate all the text contained in the widget when the Boolean value is True. This attribute is ignored if XmNwordWrap is True.
When the XmNlayoutDirection resource is XmTOP_TO_BOTTOM, this attribute is still effective even if XmNwordWrap is True. Also, this attribute is ignored when the application uses a text widget whose parent is a ScrolledWindow and XmNscrollHorizaontal is True.
XmNrows
Specifies the initial height of the text window measured in character heights. This attribute is ignored if the text widget resource XmNeditMode is XmSINGLE_LINE_EDIT. The value must be greater than 0 (zero). The default value depends on the value of the XmNheight resource. If no height is specified, the default is 1.
When the XmNlayoutDirection resource is XmTOP_TO_BOTTOM, this attribute is still effective, even if the XmText widget resource XmNeditMode is XmSINGLE_LINE_EDIT. If no height is specified, the default is 20.
XmNscrollHorizontal
Adds a ScrollBar that allows the user to scroll horizontally through text when the Boolean value is True. This resource is forced to False when the Text widget is placed in a ScrolledWindow with XmNscrollingPolicy set to XmAUTOMATIC.
When the XmNlayoutDirection resource is XmTOP_TO_BOTTOM, this attribute is ignored if the XmText widget resource XmNeditMode is XmSINGLE_LINE_EDIT.
XmNscrollLeftSide
Indicates that the vertical ScrollBar should be placed on the left side of the scrolled text window when the Boolean value is True. This attribute is ignored if XmNscrollVertical is False or the Text resource XmNeditMode is XmSINGLE_LINE_EDIT.
When the XmNlayoutDirection resource is XmTOP_TO_BOTTOM, this resource is still effective, even if the XmText widget resource XmNeditMode is XmSINGLE_LINE_EDIT.
XmNscrollTopSide
Indicates that the horizontal ScrollBar should be placed on the top side of the scrolled text window when the Boolean value is True.
When the XmNlayoutDirection resource is XmTOP_TO_BOTTOM, this attribute is ignored if XmNscrollHorizontal is False or the Xmtext resource XmNeditMode is XmSINGLE_LINE_EDIT.
XmNscrollVertical
Adds a ScrollBar that allows the user to scroll vertically through text when the Boolean value is True. This attribute is ignored if the Text resource XmNeditMode is XmSINGLE_LINE_EDIT. This resource is forced to False when the Text widget is placed in a ScrolledWindow with XmNscrollingPolicy set to XmAUTOMATIC.
When the XmNlayoutDirection resource is XmTOP_TO_BOTTOM, this resource is still effective, even if the XmText widget resource XmNeditMode is XmSINGLE_LINE_EDIT.
XmNtextWrap
Indicates that lines are to be broken at word breaks (that is, the text does not go off the right edge of the window) when the Boolean value is True. Words are defined as a sequence of characters separated by whitespace. Whitespace is defined as a space, tab, or newline. This attribute is ignored if the text widget resource XmNeditMode is XmSINGLE_LINE_EDIT. Note that this resource is only valid when the widget is not a scroll one, or, if the widget is a scroll widget, that the XmNscrollHorizontal resource is False.
Indicates that lines are to be broken at word breaks (that is, when the XmNlayoutDirection resource is XmTOP_TO_BOTTOM, the text does not go off the bottom edge of the window) when the Boolean value is True.
XmNtranslations
Defines the translations for the Text widget. The default translations are implementation dependent.
XmNverifyCallback
Specifies a list of callbacks to be called before the text has been modified. The callback reason is XmCR_VERIFY. The default value is NULL.
XmNwordWrap
Indicates that lines are to be broken at word breaks (that is, the text does not go off the right edge of the window) when the Boolean value is True. Words are defined as a sequence of characters separated by whitespace. Whitespace is defined as a space, tab, or newline. This attribute is ignored if the text widget resource XmNeditMode is XmSINGLE_LINE_EDIT. Note that this resource is only valid when the widget is not a scroll one, or, if the widget is a scroll widget, that the XmNscrollHorizontal resource is False.
Indicates that lines are to be broken at word breaks (that is, when the XmNlayoutDirection resource is XmTOP_TO_BOTTOM, the text does not go off the bottom edge of the window) when the Boolean value is True.

يتم تمرير مؤشر إلى البنية التالية إلى كل رد نداء:

typedef struct

        int reason;

يحدد ودجت النص بنية رد نداء جديدة لاستخدامها مع ردود نداء التحقق. لاحظ أنه لا تكون جميع الحقول ذات صلة بكل سبب لرد النداء. يجب على التطبيق أولاً النظر إلى حقل reason واستخدام أعضاء البنية فقط التي تكون صالحة لسبب معين. يمكن تعديل القيم startPos و endPos و text في بنية رد النداء XmTextVerifyCallbackStruct عند تلقي رد النداء، وسيتم عكس هذه التغييرات كتغييرات تم إجراؤها على مصدر ودجت النص. (على سبيل المثال، يمكن تحويل جميع ضغطات المفاتيح إلى مسافات أو أحرف NULL عند إدخال كلمة مرور في ودجت النص.) لا ينبغي لمبرمج التطبيق الكتابة فوق حقل text، بل يجب ربط البيانات بهذا المؤشر.

يشير إلى سبب استدعاء رد النداء.
event

يشير إلى ما إذا كان الإجراء الذي استدعى رد النداء قد تم تنفيذه. تعيين doit إلى False ينفي الإجراء. لاحظ أنه لا يمكن نفي جميع الإجراءات. على سبيل المثال، قد تكون ردود نداء XmCR_LOSING_FOCUS خارجة عن سيطرة الودجت إذا تم إنشاؤها بواسطة نقرات الماوس.

Table 11-1 lists the default key bindings for single-line text widgets.

backspace():
If there is a nonnull selection, deletes the selection. Otherwise, deletes the character immediately preceding the insertion cursor. This action may have different behavior in a right-to-left language environment.
The backspace() action produces calls to the XmNmodifyVerifyCallback procedures with reason value XmCR_MODIFYING_TEXT_VALUE, the XmNvalueChangedCallback procedures with reason value XmCR_VALUE_CHANGED, and the XmNmotionVerifyCallback procedures with reason value XmCR_MOVING_INSERT_CURSOR.
backward-character(extend):
Moves the insertion cursor one character to the left. This action may have different behavior in a right-to-left language environment.
If called with an argument of extend, moves the insertion cursor as in the case of no argument and extends the current selection.
The backward-character() action produces calls to the XmNmotionVerifyCallback procedures with reason value XmCR_MOVING_INSERT_CURSOR. If called with the extend argument, the backward-character() action may produce calls to the XmNgainPrimaryCallback procedures. See callback description for more information.
backward-paragraph(extend):
If this action is called with no argument, moves the insertion cursor to the first non-whitespace character preceding the current line. If the insertion cursor is already at the beginning of a paragraph, moves the insertion cursor to the beginning of the previous paragraph.
If called with an argument of extend, moves the insertion cursor as in the case of no argument and extends the current selection.
The backward-paragraph() action produces calls to the XmNmotionVerifyCallback procedures with reason value XmCR_MOVING_INSERT_CURSOR. If called with the extend argument, the backward-paragraph() action may produce calls to the XmNgainPrimaryCallback procedures. See callback description for more information.
backward-word(extend):
If this action is called with no argument, moves the insertion cursor to the first whitespace character or beginning-of-line following the next non-whitespace character. If the insertion cursor is already at the beginning of a word, moves the insertion cursor to the beginning of the previous word. This action may have different behavior in a locale other than the C locale.
If called with an argument of extend, moves the insertion cursor as in the case of no argument and extends the current selection.
The backward-word() action produces calls to the XmNmotionVerifyCallback procedures with reason value XmCR_MOVING_INSERT_CURSOR. If called with the extend argument, the backward-word() action may produce calls to the XmNgainPrimaryCallback procedures. See callback description for more information.
beginning-of-file():
Moves the insertion cursor to the beginning of the text. If called with the extend argument, it extends the current selection.
The beginning-of-file() action produces calls to the XmNmotionVerifyCallback procedures with reason value XmCR_MOVING_INSERT_CURSOR. If called with the extend argument, the beginning-of-file() action may produce calls to the XmNgainPrimaryCallback procedures. See callback description for more information.
beginning-of-line():
Moves the insertion cursor to the beginning of the current line. If called with the extend argument, it extends the current selection.
The beginning-of-line() action produces calls to the XmNmotionVerifyCallback procedures with reason value XmCR_MOVING_INSERT_CURSOR. If called with the extend argument, the beginning-of-line() action may produce calls to the XmNgainPrimaryCallback procedures. See callback description for more information.
cancel-selection():
Deselects any selected text. This action may produce no callbacks, however, the cancel-selection() action may produce calls to the XmNgainPrimaryCallback procedures. See callback description for more information.
copy-primary():
Copies the primary selection to the selection buffer. If the primary selection is empty, this action does nothing.
cut-primary():
Deletes the primary selection and copies it to the selection buffer. If the primary selection is empty, this action does nothing.
delete-line():
Deletes the current line. If the current line is empty, deletes the next line. The deleted text is stored in the selection buffer.
The delete-line() action produces calls to the XmNmodifyVerifyCallback procedures with reason value XmCR_MODIFYING_TEXT_VALUE, the XmNvalueChangedCallback procedures with reason value XmCR_VALUE_CHANGED, and the XmNmotionVerifyCallback procedures with reason value XmCR_MOVING_INSERT_CURSOR.
delete-next-character():
In normal mode, if there is a nonnull selection, kills the selection; otherwise, kills the character following the insertion cursor and stores the character in the cut buffer. In add mode, if there is a nonnull selection, the cursor is not disjoint from the selection, and XmNpendingDelete is set to True, deletes the selection; otherwise, kills the character following the insertion cursor and stores the character in the cut buffer. This may impact the selection.
The killed text is stored in CUT_BUFFER0.
The delete-next-character() action produces calls to the XmNmodifyVerifyCallback procedures with reason value XmCR_MODIFYING_TEXT_VALUE, the XmNvalueChangedCallback procedures with reason value XmCR_VALUE_CHANGED, and the XmNmotionVerifyCallback procedures with reason value XmCR_MOVING_INSERT_CURSOR.
delete-next-word():
In normal mode, if there is a nonnull selection, deletes the selection; otherwise, kills the characters following the insertion cursor to the next space, tab or end-of-line character, and stores the characters in the cut buffer. In add mode, if there is a nonnull selection, the cursor is not disjoint from the selection, and XmNpendingDelete is set to True, deletes the selection; otherwise, kills the characters following the insertion cursor to the next space, tab or end-of-line character, and stores the characters in the cut buffer. This may impact the selection. This action may have different behavior in a locale other than the C locale.

ينتج عن إجراء newline-and-indent() استدعاءات لإجراءات XmNmodifyVerifyCallback بقيمة سبب XmCR_MODIFYING_TEXT_VALUE، وإجراءات XmNvalueChangedCallback بقيمة سبب XmCR_VALUE_CHANGED، وإجراءات XmNmotionVerifyCallback بقيمة سبب XmCR_MOVING_INSERT_CURSOR.

next-page(extend):
إذا كان XmNeditMode هو XmMULTI_LINE_EDIT وتم استدعاء هذا الإجراء بدون وسيطة، فإنه ينقل مؤشر الإدراج للأمام صفحة واحدة.
إذا كان XmNeditMode هو XmMULTI_LINE_EDIT وتم استدعاء هذا الإجراء بوسيطة extend، فإنه ينقل مؤشر الإدراج كما في حالة عدم وجود وسيطة ويمدد التحديد الحالي.
ينتج عن إجراء next-page() استدعاءات لإجراءات XmNmotionVerifyCallback بقيمة سبب XmCR_MOVING_INSERT_CURSOR. إذا تم استدعاؤه بوسيطة extend، فقد ينتج عن إجراء next-page() استدعاءات لإجراءات XmNgainPrimaryCallback. انظر وصف الاستدعاء لمعرفة المزيد من المعلومات.

process-bdrag()
إذا كان المؤشر داخل التحديد، يبدأ هذا الإجراء عملية سحب للتحديد. يضبط هذا الإجراء XmNconvertProc لـ DragContext إلى دالة تستدعي إجراءات XmNconvertCallback، ربما عدة مرات، لتحديد _MOTIF_DROP.
إذا لم يكن هناك تحديد أو كان المؤشر خارج التحديد، يقوم هذا الإجراء بالتحضير لبدء تحديد ثانوي في موضع المؤشر.
ملاحظة:
لاحظ أنه عند سحب تحديد ثانوي إلى أداة مختلفة، سيتم نقل التركيز لمحة وجيزة إلى الأداة الثانية، ثم العودة إلى الأداة الأصلية. سيؤدي هذا إلى إنشاء استدعاءات لإجراءات XmNlosingFocusCallback مع فقدان التركيز (من كل أداة) وكذلك استدعاءات لإجراءات XmNfocusCallback مع استعادة التركيز.
process-cancel():
يلغي العملية الحالية extend-adjust() أو secondary-adjust() أو process-bdrag() ويترك حالة التحديد كما كانت قبل العملية؛ وإلا، وإذا كان الوالد مديرًا، يمرر الحدث إلى الوالد.
process-down(extend):
إذا كان XmNeditMode هو XmSINGLE_LINE_EDIT، وكان XmNnavigationType هو XmNONE، ينتقل إلى الأداة الموجودة أسفل الأداة الحالية في مجموعة علامات التبويب.
إذا كان XmNeditMode هو XmMULTI_LINE_EDIT وتم استدعاء هذا الإجراء مع وسيطة extend، فإنه يحرك مؤشر الإدراج كما في حالة عدم وجود وسيطة ويمد التحديد الحالي.
في هذه الحالة، سينتج الإجراء استدعاءات XmNlosingFocusCallback مع قيمة السبب XmCR_LOSING_FOCUS.
إذا كان XmNeditMode هو XmMULTI_LINE_EDIT، فإنه يحرك مؤشر الإدراج لأسفل سطر واحد.
ينتج الإجراء process-down() استدعاءات لإجراءات XmNmotionVerifyCallback مع قيمة السبب XmCR_MOVING_INSERT_CURSOR.
في الكتابة العمودية، يحرك مؤشر الإدراج حرفًا واحدًا لأسفل.

process-return():
إذا كان XmNeditMode هو XmSINGLE_LINE_EDIT، يستدعي الاستدعاءات لـ XmNactivateCallback، وإذا كان الوالد مديرًا، يمرر الحدث إلى الوالد. إذا كان XmNeditMode هو XmMULTI_LINE_EDIT، فإنه يدرج سطرًا جديدًا.
ينتج الإجراء process-return() أثناء التحرير أحادي السطر استدعاءات لإجراءات XmNactivateCallback مع قيمة السبب XmCR_ACTIVATE. أثناء التحرير متعدد الأسطر، ينتج الإجراء process-return() استدعاءات لإجراءات XmNmodifyVerifyCallback مع قيمة السبب XmCR_MODIFYING_TEXT_VALUE، وإجراءات XmNvalueChangedCallback مع قيمة السبب XmCR_VALUE_CHANGED، وإجراءات XmNmotionVerifyCallback مع قيمة السبب XmCR_MOVING_INSERT_CURSOR.
process-shift-down():
إذا كان XmNeditMode هو XmMULTI_LINE_EDIT، فإنه يحرك مؤشر الإدراج لأسفل سطر واحد ويحدد. إذا كان XmNeditMode هو XmSINGLE_LINE_EDIT، فإن هذا الإجراء يتصرف مثل process-up() في XmSINGLE_LINE_EDIT. راجع الإجراء process-up().
ينتج الإجراء process-shift-down() استدعاءات لإجراءات XmNmotionVerifyCallback مع قيمة السبب XmCR_MOVING_INSERT_CURSOR.
في الكتابة العمودية، إذا تم استدعاؤه مع الوسيطة up، فإنه يحرك مؤشر الإدراج حرفًا واحدًا لأعلى ويمد التحديد الحالي. إذا تم استدعاؤه مع الوسيطة down، فإنه يحرك مؤشر الإدراج حرفًا واحدًا لأسفل ويمد التحديد الحالي.

process-tab(Prev|Next):
إذا كان XmNeditMode هو XmSINGLE_LINE_EDIT، فإنه ينتقل إلى مجموعة علامات التبويب التالية إذا كانت وسيطة الاتجاه هي Next، أو إلى مجموعة علامات التبويب السابقة إذا كانت الوسيطة Prev. إذا كان XmNeditMode هو XmMULTI_LINE_EDIT، وكان الاتجاه هو Next، فإن الإجراء يدرج علامة جدولة. الوسيطة Prev ليس لها تأثير مع XmMULTI_LINE_EDIT. في أداة النص، هناك علامة جدولة معدة مسبقًا في كل ثماني أعمدة.
ينتج الإجراء process-tab() تحت التحرير متعدد الأسطر استدعاءات لإجراءات XmNmotionVerifyCallback مع قيمة السبب XmCR_MOVING_INSERT_CURSOR. تحت التحرير أحادي السطر، لا ينتج الإجراء أي استدعاءات، ما لم يؤد إلى فقدان التركيز عن الأداة، وفي هذه الحالة، يتم استدعاء إجراءات XmNlosingFocusCallback مع قيمة السبب XmCR_LOSING_FOCUS.

إذا كان XmNeditMode هو XmMULTI_LINE_EDIT، فإنه يحرك مؤشر الإدراج لأعلى سطر واحد.
إذا كان XmNeditMode هو XmMULTI_LINE_EDIT وتم استدعاء هذا الإجراء مع وسيطة extend، فإنه يحرك مؤشر الإدراج كما في حالة عدم وجود وسيطة ويمد التحديد الحالي.
ينتج الإجراء process-up() تحت التحرير متعدد الأسطر استدعاءات لإجراءات XmNmotionVerifyCallback مع قيمة السبب XmCR_MOVING_INSERT_CURSOR. تحت التحرير أحادي السطر، لا ينتج الإجراء أي استدعاءات ما لم يؤد إلى فقدان التركيز عن الأداة، وفي هذه الحالة، يتم استدعاء إجراءات XmNlosingFocusCallback مع قيمة السبب XmCR_LOSING_FOCUS.
في الكتابة العمودية، يحرك مؤشر الإدراج حرفًا واحدًا لأعلى.
