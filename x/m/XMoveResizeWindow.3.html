XMoveResizeWindow(3)

الحزمة: libx11

التراخيص: MIT AND X11

NAME

XMoveResizeWindow, XResizeWindow, XMoveWindow — move and resize windows

SYNTAX

int XMoveResizeWindow(Display *display, Window w, int x, int y,
    unsigned int width, unsigned int height);
int XResizeWindow(Display *display, Window w, unsigned int width,
    unsigned int height);
int XMoveWindow(Display *display, Window w, int x, int y);

ARGUMENTS

display
Specifies the connection to the X server.
w
Specifies the window.
x, y
Specify the coordinates for the upper-left corner of the window.
width, height
Specify the new width and height of the window.

DESCRIPTION

The XMoveResizeWindow function combines the functionality of XMoveWindow and XResizeWindow. It moves the specified window to the specified coordinates and also changes its width and height.

The coordinates are relative to the parent window's origin. Negative coordinates are allowed and indicate a position relative to the parent's origin, but the window's upper-left corner will not be placed outside the parent's clipping region.

The XResizeWindow function changes the width and height of the specified window. The new dimensions must be within the minimum and maximum geometry of the window.

The XMoveWindow function changes the position of the specified window. The new coordinates are relative to the parent window's origin.

These functions do not draw in the window or affect its visibility. They simply change the window's geometry. To make the changes visible, you may need to explicitly map or raise the window.

If the window is not explicitly mapped, these functions do not generate any events. If the window is already mapped, these functions can generate ConfigureNotify events.

STRUCTURES

None.

DIAGNOSTICS

BadWindow
A value for a Window argument does not name a defined Window.

الاسم

XMoveResizeWindow، XResizeWindow، XMoveWindow — تحريك وتغيير حجم النوافذ

الصيغة

int XMoveResizeWindow(Display *display, Window w, int x, int y,
    unsigned int width, unsigned int height);
int XResizeWindow(Display *display, Window w, unsigned int width,
    unsigned int height);
int XMoveWindow(Display *display, Window w, int x, int y);

المعاملات

display
يحدد الاتصال بخادم X.
w
يحدد النافذة.
x, y
يحدد إحداثيات الزاوية العلوية اليسرى للنافذة.
width, height
يحدد العرض والارتفاع الجديدين للنافذة.

الوصف

تجمع الدالة XMoveResizeWindow وظائف XMoveWindow و XResizeWindow. تقوم بنقل النافذة المحددة إلى الإحداثيات المحددة وتغيير عرضها وارتفاعها أيضًا.

الإحداثيات نسبية إلى أصل النافذة الأم. يُسمح بالإحداثيات السالبة وتشير إلى موقع نسبي لأصل النافذة الأم، لكن الزاوية العلوية اليسرى للنافذة لن توضع خارج منطقة الاقتصاص الخاصة بالنافذة الأم.

تغير الدالة XResizeWindow عرض وارتفاع النافذة المحددة. يجب أن تكون الأبعاد الجديدة ضمن الهندسة الدنيا والقصوى للنافذة.

تغير الدالة XMoveWindow موضع النافذة المحددة. الإحداثيات الجديدة نسبية إلى أصل النافذة الأم.

هذه الدوال لا ترسم في النافذة أو تؤثر على رؤيتها. إنها ببساطة تغير هندسة النافذة. لجعل التغييرات مرئية، قد تحتاج إلى تعيين النافذة أو رفعها صراحةً.

إذا لم يتم تعيين النافذة صراحةً، فلن تولد هذه الدوال أي أحداث. إذا تم تعيين النافذة بالفعل، فيمكن لهذه الدوال توليد أحداث ConfigureNotify.

الهياكل

لا شيء.

التشخيصات

BadWindow
قيمة لمعامل Window لا تسمي نافذة معرفة.
