XmVaCreateComboBox(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateComboBox(استدعاء مكتبة) XmVaCreateComboBox(استدعاء مكتبة)

الاسم

XmVaCreateComboBox, XmVaCreateManagedComboBox — وظائف إنشاء مريحة لأدوات ComboBox.

ملخص

#include <Xm/ComboBox.h>
Widget XmVaCreateComboBox(
Widget parent,
String name,
...);
Widget XmVaCreateManagedComboBox(
Widget parent,
String name,
...);

الوصف

تقوم هذه الوظائف بإنشاء مثيل لأداة ComboBox وإرجاع معرّف الأداة المرتبط بها. تستخدم هذه الروتينات اتفاقية استدعاء قائمة الوسائط المتغيرة القياسية ANSI C (varargs).

تعتبر الوظيفة XmVaCreateComboBox روتينًا مريحًا يستدعي XtCreateWidget.

تعتبر الوظيفة XmVaCreateManagedComboBox روتينًا مريحًا يستدعي XtCreateManagedWidget.

parent
يحدد معرّف الأداة الأصل.
name
يحدد اسم الأداة التي تم إنشاؤها.
...
يحدد قائمة الوسائط المتغيرة لتجاوز القيم الافتراضية للموارد.

للحصول على تعريف كامل لـ ComboBox والموارد المرتبطة به، انظر XmComboBox(3).

الإرجاع

تُرجع معرّف أداة ComboBox.

ذات الصلة

XmComboBox(3), XmCreateComboBox(3), XtCreateWidget(3), و XtCreateManagedWidget(3).
