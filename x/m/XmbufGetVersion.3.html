XmbufGetVersion(3)

الحزمة: libxext

التراخيص: LicenseRef-libxext

اسم

XmbufGetVersion, XmbufGetVersionByClient, XmbufGetVersionByRequest - الحصول على إصدار وملحقات X Multi-Buffering

الصيغة

int XmbufGetVersion(
    Display *dpy,
    int *major_version_return,
    int *minor_version_return,
    Bool *is_multi_buffer_available
);
int XmbufGetVersionByClient(
    Display *dpy,
    int *major_version_return,
    int *minor_version_return,
    Bool *is_multi_buffer_available,
    XID client_id
);
int XmbufGetVersionByRequest(
    Display *dpy,
    int *major_version_return,
    int *minor_version_return,
    Bool *is_multi_buffer_available,
    CARD32 request_id
);

هياكل

لا يوجد هياكل معرفة في هذا الملحق.

الوصف

تسمح هذه الوظائف للمطورين بالتحقق من توفر وامتداد X Multi-Buffering (تخزين مؤقت متعدد) على نظام X Window. يقوم الامتداد بتوفير دعم للتخزين المؤقت المزدوج، والتخزين المؤقت المتعدد، والتخزين المؤقت ثلاثي الأبعاد.

dpy
مؤشر إلى بنية العرض التي تمثل اتصال خادم X.
major_version_return
عدد صحيح حيث سيتم إرجاع الإصدار الرئيسي لملحق Multi-Buffering.
minor_version_return
عدد صحيح حيث سيتم إرجاع الإصدار الثانوي لملحق Multi-Buffering.
is_multi_buffer_available
قيمة منطقية حيث سيتم إرجاع ما إذا كان ملحق Multi-Buffering متاحًا أم لا. سيتم تعيينه إلى True إذا كان متاحًا، وإلى False إذا لم يكن متاحًا.
client_id
معرف العميل (XID) الخاص بالعميل الذي تريد التحقق من إصداره.
request_id
معرف الطلب (request ID) الخاص بالطلب الذي تريد التحقق من إصداره.

تُرجع هذه الوظائف رمز حالة يوضح نجاح أو فشل العملية. قيم الإرجاع المحتملة هي:

  • Success: تم استرداد الإصدار ومعلومات التوفر بنجاح.
  • BadAlloc: فشل تخصيص الذاكرة.
  • BadRequest: طلب غير صالح.
  • BadServer: خطأ في الخادم.
  • BadExtension: الامتداد غير موجود.
