XmVaCreatePushButtonGadget(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreatePushButtonGadget(استدعاء مكتبة) XmVaCreatePushButtonGadget(استدعاء مكتبة)

الاسم

XmVaCreatePushButtonGadget, XmVaCreateManagedPushButtonGadget — وظائف ملائمة لإنشاء عنصر واجهة مستخدم PushButtonGadget.

الملخص

#include <Xm/PushBG.h>
Widget XmVaCreatePushButtonGadget(
Widget parent,
String name,
...);
Widget XmVaCreateManagedPushButtonGadget(
Widget parent,
String name,
...);

الوصف

تقوم هذه الوظائف بإنشاء نسخة من عنصر واجهة مستخدم ToggleButtonGadget وتعيد معرف العنصر المنشأ. تستخدم هذه الروتينات اتفاقية استدعاء قائمة الوسائط متغيرة الطول القياسية ANSI C (varargs).

الوظيفة XmVaCreatePushButtonGadget هي روتين ملائم يقوم باستدعاء XtCreateWidget.

الوظيفة XmVaCreatePushButtonGadget هي روتين ملائم يقوم باستدعاء XtCreateManagedWidget.

parent
يحدد معرف العنصر الأب.
name
يحدد اسم العنصر المنشأ.
...
يحدد قائمة الوسائط المتغيرة لتجاوز القيم الافتراضية للموارد.

للحصول على تعريف كامل لعنصر PushButtonGadget وموارده المرتبطة، انظر XmPushButtonGadget(3).

الإرجاع

يعيد معرف عنصر PushButtonGadget.

ذات الصلة

XmPushButtonGadget(3), XmCreatePushButtonGadget(3), XtCreateWidget(3), و XtCreateManagedWidget(3).
