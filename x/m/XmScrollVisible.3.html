XmScrollVisible(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmScrollVisible(استدعاء مكتبة) XmScrollVisible(استدعاء مكتبة)

الاسم

XmScrollVisible — وظيفة ScrolledWindow تجعل عنصر تابع غير مرئي لنافذة العمل الخاصة بـ ScrolledWindow مرئيًا

الملخص

#include <Xm/ScrolledW.h>
void XmScrollVisible(
Widget scrollw_widget,
Widget widget,
Dimension left_right_margin,
Dimension top_bottom_margin);

الوصف

XmScrollVisible تجعل عنصر واجهة المستخدم أو الأداة الملحقة التابعة لنافذة العمل الخاصة بـ ScrolledWindow والتي تم حجبها أو حجبها جزئيًا مرئية. تقوم الدالة بإعادة تحديد موضع نافذة العمل وتعيين الهوامش المحددة بين عنصر واجهة المستخدم وحدود نافذة العرض الأقرب. يحدد موقع عنصر واجهة المستخدم بالنسبة لنافذة العرض ما إذا كان يجب تعديل أحد الهامشين أو كليهما. تتطلب هذه الدالة أن يتم تعيين XmNscrollingPolicy لعنصر واجهة المستخدم ScrolledWindow إلى XmAUTOMATIC.

scrollw_widget
يحدد معرف عنصر واجهة المستخدم ScrolledWindow الذي تحتوي نافذة العمل الخاصة به على عنصر تابع محجوب.
widget
يحدد معرف عنصر واجهة المستخدم الذي سيتم جعله مرئيًا.
left_right_margin
يحدد الهامش الذي سيتم إنشاؤه بين الحافة اليسرى أو اليمنى لعنصر واجهة المستخدم والحافة المرتبطة بنافذة العرض. يتم إنشاء هذا الهامش فقط إذا كان يجب تحريك عنصر واجهة المستخدم أفقيًا لجعله مرئيًا.
top_bottom_margin
يحدد الهامش الذي سيتم إنشاؤه بين الحافة العلوية أو السفلية لعنصر واجهة المستخدم والحافة المرتبطة بنافذة العرض. يتم إنشاء هذا الهامش فقط إذا كان يجب تحريك عنصر واجهة المستخدم عموديًا لجعله مرئيًا.

للحصول على تعريف كامل لـ ScrolledWindow والموارد المرتبطة به، انظر XmScrolledWindow(3)
