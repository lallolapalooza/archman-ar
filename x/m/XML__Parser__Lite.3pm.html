XML__Parser__Lite(3pm)

الحزمة: perl-xml-parser-lite

التراخيص: Artistic-1.0-Perl

XML::Parser::Lite(3) وثائق Perl مساهمة من المستخدم XML::Parser::Lite(3)

الاسم

XML::Parser::Lite - محلل XML خفيف الوزن مكتوب بالكامل بلغة Perl (يعتمد على التعبيرات العادية)

ملخص

use XML::Parser::Lite;
$p1 = new XML::Parser::Lite;
$p1->setHandlers(
  Start => sub { shift; print "start: @_\n" },
  Char => sub { shift; print "char: @_\n" },
  End => sub { shift; print "end: @_\n" },
);
$p1->parse('<foo id="me">Hello World!</foo>');
$p2 = new XML::Parser::Lite
  Handlers => {
    Start => sub { shift; print "start: @_\n" },
    Char => sub { shift; print "char: @_\n" },
    End => sub { shift; print "end: @_\n" },
  }
;
$p2->parse('<foo id="me">Hello <bar>cruel</bar> World!</foo>');

الوصف

تنفذ هذه الوحدة محلل XML بواجهة مشابهة لـ XML::Parser. على الرغم من أنه لا يتم دعم جميع الاستدعاءات، يجب أن تكون قادرًا على استخدامها بنفس الطريقة التي تستخدم بها XML::Parser. نظرًا لاستخدام ميزات التعبيرات العادية التجريبية، ستعمل فقط على Perl 5.6 وما فوق وقد تتصرف بشكل مختلف على منصات مختلفة.

لاحظ أنه لا يمكنك استخدام التعبيرات العادية أو الانقسام في الاستدعاءات. هذا يرجع إلى قيود تنفيذ التعبيرات العادية لـ perl (والتي ليست قابلة لإعادة الدخول).

الإجراءات الفرعية/الأساليب

جديد

المُنشئ.

الدالة new() تُرجع الكائن الذي تم استدعاؤه عليه عند استدعائها كأسلوب كائن. تم توريث هذا السلوك من SOAP::Lite، الذي تم فصل XML::Parser::Lite منه. هذا يعني أن ما يلي هو في الواقع إجراء بدون تأثير إذا كان $obj كائنًا:

$obj = $obj->new();

تقبل new معلمة مسماة واحدة، "Handlers" مع مرجع تجزئة كقيمة:

my $parser = XML::Parser::Lite->new(
   Handlers => {
       Start => sub { shift; print "start: @_\n" },
       Char => sub { shift; print "char: @_\n" },
       End => sub { shift; print "end: @_\n" },
   }
);

سيتم تمرير المعالجات المقدمة إلى setHandlers.

setHandlers

تعين (أو تعيد تعيين) معالجات التحليل. تقبل تجزئة بأسماء المعالجات ومراجع كود المعالجات كمعلمات. تمرير "undef" بدلاً من مرجع كود يستبدل المعالج بإجراء بدون تأثير.

يمكن تعيين المعالجات التالية:

Init
Start
Char
End
Final

يتم تجاهل جميع المعالجات الأخرى.

استدعاء setHandlers بدون معلمات يعيد تعيين جميع المعالجات إلى إجراءات بدون تأثير.

parse

يحلل XML المقدم. على عكس أسلوب parse الخاص بـ XML::Parser، تقوم parse() بتحليل السلاسل النصية فقط.

أساليب المعالج

Init

يتم استدعاؤها قبل بدء التحليل. يجب عليك إجراء أي تهيئات ضرورية في Init.

Start

يتم استدعاؤها في بداية كل عقدة XML. انظر XML::Parser للتفاصيل.

Char

يتم استدعاؤها لكل تسلسل أحرف. قد يتم استدعاؤها عدة مرات للأحرف الموجودة في عقدة XML (حتى لكل حرف فردي). يجب أن يضمن تنفيذك أنه يلتقط جميع الأحرف.

End

يتم استدعاؤها في نهاية كل عقدة XML. انظر XML::Parser للتفاصيل.

Comment

انظر XML::Parser للتفاصيل.

XMLDecl

انظر XML::Parser للتفاصيل.

Doctype

انظر XML::Parser للتفاصيل.

Final

يتم استدعاؤها في نهاية عملية التحليل. يجب عليك إجراء أي تنظيفات ضرورية هنا.

انظر أيضًا

XML::Parser - محلل XML كامل، والذي يعتمد عليه XML::Parser::Lite. يتطلب مترجم C ومحلل XML expat.

XML::Parser::LiteCopy - تفرع في XML::Parser::Lite::Tree.

YAX - وحدة أخرى مكتوبة بالكامل بلغة Perl لتحليل XML.

XML::Parser::REX - وحدة أخرى تحلل XML باستخدام التعبيرات العادية.
