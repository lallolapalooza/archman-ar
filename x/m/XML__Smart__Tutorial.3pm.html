الاسم

XML::Smart::Tutorial - دليل وأمثلة لـ XML::Smart.

ملخص

هذه الوثيقة هي دليل لـ XML::Smart وتوضح بعض الأمثلة للأشياء الشائعة.

العمل مع المحتويات:

في XML::Smart، الكلمة المفتاحية CONTENT محفوظة ويجب عدم استخدامها مباشرة، حيث أن XML::Smart ستتعامل مع تحويل الوسائط إلى محتويات عقدة، بما في ذلك محتويات العقد المتعددة تلقائيًا.

ماذا يحدث عند تعيين قيمة:

$xml->{root}{foo} = 'simple value' ;

هنا ستكون foo وسيطًا/خاصية عادية، وستنشئ بيانات XML التالية:

<root foo="simple value"/>

ولكن إذا قمت بإدراج بعض العلامات أو الأسطر في القيم، فبشكل افتراضي، سيقوم XML::Smart بتحويلها إلى محتوى عقدة:

$xml->{root}{foo} = "line0\nlien1\nline2\n" ;

وستقوم بإنشاء بيانات XML التالية:

<root>
<foo>line0
lien1
line2
</foo>
</root>

ولكن ماذا يمكنك أن تفعل إذا كنت تريد فرض نوع معين، على سبيل المثال، أن يكون لديك محتوى عقدة بقيمة بسيطة:

$xml->{root}{foo} = 'simple value' ;
$xml->{root}{foo}->set_node(1) ;

وستقوم بإنشاء بيانات XML التالية:

<root>
  <foo>simple value</foo>
</root>

محتويات متعددة:

عندما يكون لديك محتوى/بيانات مستوردة، تحتاج إلى العمل بطريقة مختلفة. لنفترض أنك قمت بتحميل بيانات XML التالية:

<root>
content0
<tag1 arg="1"/>
content1
</root>

إذا قمت بالوصول مباشرة إلى مفتاح الجذر كسلسلة نصية، فستحصل على جميع أجزاء المحتوى مجمعة. لذلك، هذا الكود:

my $xml = new XML::Smart(q`
<root>
content0
<tag1 arg="1"/>
content1
</root>
`,'smart') ;

print "#$xml->{root}#" ;

سيقوم بطباعة ما يلي:

#
content0

content1
#

للوصول إلى كل جزء من المحتوى بشكل مستقل، يجب عليك استخدام مصفوفة تستقبل الدالة content():

my @content = $xml->{root}->content ;

print "#$content[0]#\n" ;

وهذا سيقوم بطباعة ما يلي:

#
content0
#

الآن لتعيين قيم المحتوى المتعددة، يجب عليك استخدام الدالة content() مع وسيطين:

$xml->{root}->content(0,'new content') ;

والآن ستكون بيانات XML الناتجة:

<root>new content<tag1 arg="1"/>
content1
</root>

إذا استخدمت الدالة content() مع وسيط واحد فقط، فستقوم بإزالة جميع المحتويات المتعددة وتعيين القيمة الجديدة بدلاً من المحتوى الأول.

تعيين محلل XML.

افتراضيًا، سيستخدم XML::Smart XML::Parser أو XML::Smart::Parser (بهذا الترتيب من الأفضلية) لتحميل بيانات XML.

لفرض أو تعريف المحلل بنفسك، يمكنك استخدام الخيار الوسيط الثاني عند إنشاء كائن XML::Smart:

my $xml = new XML::Smart( 'some.xml' , 'XML::Parser' ) ;

## و

my $xml = new XML::Smart( 'some.xml' , 'XML::Smart::Parser' ) ;

XML::Smart لديها أيضًا محلل إضافي، وهو XML::Smart::HTMLParser، والذي يمكن استخدامه لتحميل HTML كـ XML، أو لتحميل بيانات XML غير منتظمة:

my $xml = new XML::Smart( 'some.xml' , 'XML::Smart::HTMLParser' ) ;

أسماء مستعارة لخيارات المحلل:

SMART|REGEXP   => XML::Smart::Parser
HTML           => XML::Smart::HTMLParser

لذلك، يمكنك استخدام:

my $xml = new XML::Smart( 'some.xml' , 'smart' ) ;
my $xml = new XML::Smart( 'some.xml' , 'html' ) ;

تخصيص المحلل.

يمكنك تخصيص الطريقة التي سيعامل بها المحلل بيانات XML:

فرض العقد/العلامات والوسائط/الخصائص إلى أحرف صغيرة أو كبيرة:

## للأحرف الصغيرة:
my $xml = new XML::Smart( 'some.xml' ,
lowtag => 1 ,
lowarg => 1 ,
) ;

## للأحرف الكبيرة:

my $xml = new XML::Smart( 'some.xml' ,
upertag => 1 ,
uperarg => 1 ,
) ;

تحميل الوسائط بدون قيم (علامات) كقيمة منطقية TRUE:

** ملاحظة، هذا الخيار سيعمل فقط عندما يتم تحليل XML بواسطة XML::Smart::HTMLParser، حيث أنه وحده يقبل الوسائط بدون قيم!

my $xml = new XML::Smart(
'<root><foo arg1="" flag></root>' ,
'XML::Smart::HTMLParser' ,
arg_single => 1 ,
) ;

هذه هي بنية المثال أعلاه:

'root' => {
            'foo' => {
                       'flag' => 1,
                       'arg1' => ''
                     },
          },

تخصيص أحداث التحليل:

XML::Smart يمكنها إعادة توجيه عملية التحليل إلى دوال مخصصة:

my $xml = XML::Smart->new( 'some.xml' ,
on_start => \&on_start ,
on_char  => \&on_char ,
on_end   => \&on_end ,
) ;

sub on_start {
  my ( $tag , $pointer , $pointer_back ) = @_ ;
  $pointer->{$tag}{type_user} = 1 if $tag =~ /(?:name|age)/ ;
}
sub on_char {
  my ( $tag , $pointer , $pointer_back , $content) = @_ ;
  $$content =~ s/\s+/ /gs ;
}

sub on_end {
  my ( $tag , $pointer , $pointer_back ) = @_ ;
  $pointer->{$tag}{type_extra} = 1 if $tag =~ /(?:more|tel|address)/ ;
}
