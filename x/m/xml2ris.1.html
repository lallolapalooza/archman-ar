الاسم

xml2ris - تحويل XML إلى تنسيق RIS.

الملخص

xml2ris [خيار]... [ملف_الإدخال]...

الوصف

xml2ris هي أداة سطر أوامر تقوم بتحويل الملفات بتنسيق XML إلى تنسيق RIS. تنسيق RIS هو تنسيق شائع يستخدم لتخزين المراجع الببليوغرافية.

التحويل إلى MODS

لاستخدام xml2ris لتحويل ملف XML إلى RIS، يجب أن يكون ملف XML الخاص بك متوافقًا مع مواصفات MODS (Metadata Object Description Schema). يقوم xml2ris بقراءة عناصر XML المحددة وتعيينها إلى حقول RIS المقابلة.

التحويل من MODS

إذا كان لديك ملف بتنسيق RIS وترغب في تحويله إلى XML بتنسيق MODS، فإن xml2ris يمكنه مساعدتك في ذلك. سيتم إنشاء ملف XML الذي يتبع مخطط MODS استنادًا إلى البيانات الموجودة في ملف RIS.

أمثلة

لتحويل ملف XML يسمى references.xml إلى تنسيق RIS وحفظه في references.ris:

xml2ris references.xml > references.ris

لتحويل ملف RIS يسمى articles.ris إلى XML بتنسيق MODS وحفظه في articles.mods.xml:

xml2ris --from-ris articles.ris > articles.mods.xml
