XmCreateBulletinBoardDialog(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmCreateBulletinBoardDialog(استدعاء مكتبة) XmCreateBulletinBoardDialog(استدعاء مكتبة)

الاسم

XmCreateBulletinBoardDialog — وظيفة إنشاء مريحة لصندوق حوار BulletinBoard

الملخص

#include <Xm/BulletinB.h>
Widget XmCreateBulletinBoardDialog(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

الوصف

XmCreateBulletinBoardDialog هي وظيفة إنشاء مريحة تنشئ DialogShell و BulletinBoard غير مُدار كابن لـ DialogShell. يستخدم BulletinBoardDialog للتفاعلات التي لا تدعمها مجموعة الحوار القياسية. هذه الوظيفة لا تنشئ تلقائياً أي تسميات أو أزرار أو مكونات حوار أخرى. يجب إضافة مثل هذه المكونات بواسطة التطبيق بعد إنشاء BulletinBoardDialog.

استخدم XtManageChild لرفع BulletinBoardDialog (مع تمرير BulletinBoard كمعامل الأداة)؛ واستخدم XtUnmanageChild لإنزاله.

XmCreateBulletinBoardDialog تفرض قيمة مورد Shell XmNallowShellResize على True.

parent
يحدد معرف الأداة الأصل
name
يحدد اسم الأداة التي تم إنشاؤها
arglist
يحدد قائمة الوسائط
argcount
يحدد عدد أزواج السمات/القيم في قائمة الوسائط (arglist)

للحصول على تعريف كامل لـ BulletinBoard والموارد المرتبطة به، انظر XmBulletinBoard(3).

القيمة المرتجعة

ترجع معرف الأداة BulletinBoard.
