XmDropTransfer(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

NAME

DropTransfer - transfer resources

SYNOPSIS

```c
#include <Xm/DropTransfer.h>
```

DESCRIPTION

The DropTransfer function is used to initiate a drag and drop operation. The drag and drop operation can be initiated either by the application or by the Motif toolkit. If the application initiates the drag and drop operation, it calls this function.

The function takes the following arguments:

Widget widget
The widget that will be the drag source.
XEvent *event
A pointer to the X event that will trigger the drag and drop operation. This is usually a ButtonPress or MotionNotify event.
XmImportUnsupported *import_unsupported
A pointer to an XmImportUnsupported structure that specifies the data to be transferred. This structure contains the following fields:
    Atom        target;
    Atom        transfer_type;
    XtPointer   data;
    unsigned long length;
    XtPointer   client_data;
    Boolean     send_select;

The following functions are associated with the DropTransfer function:

XmDropTransferAdd
Adds a drop site to the drop site list. A drop site is a widget that can receive dropped data.
XmDropTransferStart
Starts the drag and drop operation.
XmDropTransferDestroy
Destroys a drop site.

The DropTransfer function returns True if the drag and drop operation was successfully initiated, and False otherwise. If the drag and drop operation failed, the reason for the failure can be determined by examining the reason field of the XmDragDropEnd event.

Inherited Resources

DropTransfer inherits behavior and a resource from Object. For a complete description of this resource, refer to the Object reference page.

XmNdestroyCallback XmCCallback XtCallbackList NULL C
