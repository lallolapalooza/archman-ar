XmVaCreatePushButton(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreatePushButton(استدعاء مكتبة) XmVaCreatePushButton(استدعاء مكتبة)

الاسم

XmVaCreatePushButton, XmVaCreateManagedPushButton — وظائف إنشاء مريحة لأداة الزر.

الملخص

#include <Xm/PushB.h>
Widget XmVaCreatePushButton(
Widget parent,
String name,
...);
Widget XmVaCreateManagedPushButton(
Widget parent,
String name,
...);

الوصف

تقوم هذه الوظائف بإنشاء مثيل لأداة ToggleButtonGadget وترجع معرف الأداة المرتبط بها. تستخدم هذه الروتينات اصطلاح استدعاء قائمة المتغيرات الطويلة (varargs) القياسي ANSI C.

XmVaCreatePushButton هي روتين ملائم يقوم باستدعاء XtCreateWidget.

XmVaCreatePushButton هي روتين ملائم يقوم باستدعاء XtCreateManagedWidget.

parent
يحدد معرف الأداة الأصل.
name
يحدد اسم الأداة التي تم إنشاؤها.
...
يحدد قائمة المتغيرات لتجاوز قيم الموارد الافتراضية.

للحصول على تعريف كامل لـ PushButton والموارد المرتبطة بها، انظر XmPushButton(3).

العودة

يرجع معرف أداة PushButton.

ذات الصلة

XmPushButton(3)، XmCreatePushButton(3)، XtCreateWidget(3)، و XtCreateManagedWidget(3).
