NAME

XmForm - A composite widget that allows the geometry of its children to be specified by constraints. The XmForm widget is a subclass of XmManager.

SYNOPSIS

#include <Xm/Form.h>

The structure of the XmForm widget is the same as that of the XmManager widget.

CALLBACKS

The XmForm widget supports the following callbacks:

XmNdestroyCallback
Invoked when the widget is destroyed.

See XmManager(3) for a complete list of widget resources.

DESCRIPTION

The XmForm widget is a composite widget that allows the geometry of its children to be specified by constraints. The XmForm widget is a subclass of XmManager. It provides a flexible geometry management system that allows relationships to be defined between the widget's children and between the children and the form widget itself.

When a child is added to the form, the parent widget allocates a set of constraints for the child. These constraints define the child's position and size in terms of its relationship to the form and to other widgets. If the constraints are not explicitly set, the form widget assigns default values. The form widget automatically manages the geometry of its children based on these constraints.

The XmForm widget allows widgets to be attached to the form's top, bottom, left, and right edges, and to other widgets' edges.

The XmForm widget does not provide any special callback routines.
