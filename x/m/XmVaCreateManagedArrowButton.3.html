XmVaCreateManagedArrowButton(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateArrowButton(استدعاء مكتبة) XmVaCreateArrowButton(استدعاء مكتبة)

الاسم

XmVaCreateArrowButton, XmVaCreateManagedArrowButton — وظائف إنشاء مريحة لأداة ArrowButton.

الملخص

#include <Xm/ArrowB.h>
Widget XmVaCreateArrowButton(
Widget parent,
String name,
...);
Widget XmVaCreateManagedArrowButton(
Widget parent,
String name,
...);

الوصف

تقوم هذه الوظائف بإنشاء مثيل لأداة ArrowButton وتعيد معرف الأداة المرتبط بها. تستخدم هذه الروتينات اصطلاح استدعاء قائمة الوسائط المتغيرة ANSI C (varargs).

XmVaCreateArrowButton هي روتين مريح يستدعي XtCreateWidget.

XmVaCreateManagedArrowButton هي روتين مريح يستدعي XtCreateManagedWidget.

parent
يحدد معرف الأداة الأصل.
name
يحدد اسم الأداة المنشأة.
...
يحدد قائمة الوسائط المتغيرة لتجاوز افتراضات الموارد.

للحصول على تعريف كامل لـ ArrowButton والموارد المرتبطة بها، انظر XmArrowButton(3).

الإرجاع

تعيد معرف أداة ArrowButton.

ذات الصلة

XmArrowButton(3), XmCreateArrowButton(3), XtCreateWidget(3), و XtCreateManagedWidget(3).
