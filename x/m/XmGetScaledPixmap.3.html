XmGetScaledPixmap(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmGetScaledPixmap(استدعاء مكتبة) XmGetScaledPixmap(استدعاء مكتبة)

الاسم

XmGetScaledPixmap — قراءة ملف pixmap وتوسيع نطاقه وفقًا لـ pixmap ودقة الطباعة

الملخص

#include <Xm/Xm.h>
XtEnum XmGetScaledPixmap(
Widget widget,
String image_name,
Pixel foreground,
Pixel background,
int depth,
Double scaling_ratio);

الوصف

يستخدم XmGetScaledPixmap وسيطته Widget للبحث عن سلف Print Shell للحصول على معلومات دقة pixmap ودقة الطابعة الافتراضية التي سيتم استخدامها إذا كان scaling_ratio ==0.

إذا كان التوسيع 0، وكان PrintShell صالح موجودًا، فإن XmGetScaledPixmap يطبق نسبة تساوي (دقة الطابعة / دقة pixmap الافتراضية) قبل إنشاء Pixmap على شاشة الأداة. بخلاف ذلك، يتم استخدام scaling_ratio في توسيع كل من أبعاد الصورة التي يتم تحويلها كـ Pixmap.

يكمل XmGetScaledPixmap واجهة برمجة التطبيقات الحالية XmGetPixmapByDepth من خلال الاستفادة من XmNdefaultPixmapResolution الخاص بـ XmPrintShell المتجذر. ارجع إلى وثائق XmGetPixmapByDepth للحصول على التفاصيل.

widget
الأداة المستخدمة لتحديد دقة pixmap الافتراضية (من سلف print shell).
image_name
انظر XmGetPixmapByDepth للوصف.
foreground
انظر XmGetPixmapByDepth للوصف.
background
انظر XmGetPixmapByDepth للوصف.
depth
انظر XmGetPixmapByDepth للوصف.
scaling_ratio
يشير إلى نسبة التوسيع المراد تطبيقها، أو 0.

قيمة الإرجاع

تُرجع Pixmap أو NULL إذا فشلت.

الأخطاء/التحذيرات

نفس أخطاء XmGetPixmapByDepth.

انظر أيضًا
