التراخيص: LGPL-2.1-or-later

NAME

XmIconGadget — The icon gadget widget

SYNOPSIS

#include <Xm/IconGadget.h>

A mask of widget resource record components.

typedef struct _XmIconGadgetRec { ... } XmIconGadgetRec;

Structure for the icon gadget widget record.

typedef struct _XmIconGadgetExtObjectRec { ... } XmIconGadgetExtObjectRec;

Structure for the icon gadget extension record.

DESCRIPTION

The XmIconGadget widget is a simple gadget that displays an icon. It supports the resources defined by XmGadget and XmManager. It does not support any additional resources.

When XmIconGadget is a child of a XmContainer widget, it is used to represent an item within the container. The icon itself can be either a pixmap or a string. If a pixmap is specified, it will be displayed. If a string is specified, it will be drawn using the font and foreground color resources.
