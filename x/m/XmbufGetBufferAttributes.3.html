XmbufGetBufferAttributes(3)

الحزمة: libxext

التراخيص: LicenseRef-libxext

NAME

XmbufGetBufferAttributes, XmbufGetBufferAttributesAsync - request attributes of a buffer

SYNTAX

    int XmbufGetBufferAttributes(Display *display, XID buffer_id,
                                 int *width_ret, int *height_ret,
                                 int *cpp_ret, int *nap_ret);
    int XmbufGetBufferAttributesAsync(Display *display, XID buffer_id,
                                      int *width_ret, int *height_ret,
                                      int *cpp_ret, int *nap_ret);

STRUCTURES

None.

DESCRIPTION

XmbufGetBufferAttributes and XmbufGetBufferAttributesAsync request the attributes of the buffer specified by buffer_id.

The attributes returned are:

  • width_ret - the width of the buffer in pixels.

  • height_ret - the height of the buffer in pixels.

  • cpp_ret - the number of bytes per pixel.

  • nap_ret - the number of available pixel planes.

XmbufGetBufferAttributes waits for the server to reply, while XmbufGetBufferAttributesAsync allows the application to continue processing while the request is in flight.

Both functions return the same error codes as XmbufCreateBuffer.

PREDEFINED VALUES
