XmNdragMotionCallback
يحدد قائمة الاستدعاءات التي يتم استدعاؤها عند تحرك المؤشر. نوع البنية التي يتم تمرير عنوانها إلى هذا الاستدعاء هو XmDragMotionCallbackStruct. السبب الذي يتم إرساله بواسطة الاستدعاء هو XmCR_DRAG_MOTION.
XmNdragOperations
يحدد مجموعة العمليات الصالحة المرتبطة بعميل مبادر لمعاملة سحب. هذا المورد هو قناع بت يتم تشكيله بواسطة الجمع بين قيمة واحدة أو أكثر من القيم التالية باستخدام عملية بت مثل OR الشامل (|): XmDROP_COPY، XmDROP_LINK، XmDROP_MOVE. القيمة XmDROP_NOOP لهذا المورد تشير إلى أنه لا توجد عمليات صالحة. بالنسبة لأدوات النص وأدوات حقل النص، يتم تعيين هذا المورد إلى XmDROP_COPY | XmDROP_MOVE؛ بالنسبة لقائمة الأدوات، يتم تعيينها إلى XmDROP_COPY.
XmNdropFinishCallback
يحدد قائمة الاستدعاءات التي يتم استدعاؤها عند اكتمال الإسقاط. نوع البنية التي يتم تمرير عنوانها إلى هذا الاستدعاء هو XmDropFinishCallbackStruct. السبب الذي يتم إرساله بواسطة الاستدعاء هو XmCR_DROP_FINISH.
XmNdropSiteEnterCallback
يحدد قائمة الاستدعاءات التي يتم استدعاؤها عند دخول المؤشر إلى موقع إسقاط. نوع البنية التي يتم تمرير عنوانها إلى هذا الاستدعاء هو XmDropSiteEnterCallbackStruct. السبب الذي يتم إرساله بواسطة الاستدعاء هو XmCR_DROP_SITE_ENTER.
XmNdropSiteLeaveCallback
يحدد قائمة الاستدعاءات التي يتم استدعاؤها عند مغادرة المؤشر لـ موقع إسقاط. نوع البنية التي يتم تمرير عنوانها إلى هذا الاستدعاء هو XmDropSiteLeaveCallbackStruct. السبب الذي يتم إرساله بواسطة الاستدعاء هو XmCR_DROP_SITE_LEAVE.
XmNdropStartCallback
يحدد قائمة الاستدعاءات التي يتم استدعاؤها عند بدء إسقاط. نوع البنية التي يتم تمرير عنوانها إلى هذا الاستدعاء هو XmDropStartCallbackStruct. السبب الذي يتم إرساله بواسطة الاستدعاء هو XmCR_DROP_START.
XmNexportTargets
يحدد قائمة ذرات الهدف المرتبطة بهذا المصدر. هذا المورد يحدد أهداف التحديد التي يمكن تحويل هذا المصدر إليها.
XmNincremental
يحدد قيمة منطقية تشير إلى ما إذا كان النقل على جانب المبادر يستخدم آلية نقل التحديد المتزايد لـ Xt الموضحة في X Toolkit Intrinsics—C Language Interface. إذا كانت القيمة صحيحة، فإن المبادر يستخدم النقل المتزايد؛ إذا كانت القيمة خاطئة، فإن المبادر يستخدم النقل الذري.
XmNinvalidCursorForeground
يحدد قيمة البكسل الأمامية للمؤشر عندما تكون الحالة غير صالحة. هذا المورد افتراضياً يأخذ قيمة المورد XmNcursorForeground.
XmNnoneCursorForeground
يحدد قيمة البكسل الأمامية للمؤشر عندما تكون الحالة لا شيء. هذا المورد افتراضياً يأخذ قيمة المورد XmNcursorForeground.
XmNnumExportTargets
يحدد عدد الإدخالات في قائمة ذرات التصدير.
XmNoperationChangedCallback
يحدد قائمة الاستدعاءات التي يتم استدعاؤها عند بدء السحب وعندما يطلب المستخدم تطبيق عملية مختلفة على الإسقاط. نوع البنية التي يتم تمرير عنوانها إلى هذا الاستدعاء هو XmOperationChangedCallbackStruct. السبب الذي يتم إرساله بواسطة الاستدعاء هو XmCR_OPERATION_CHANGED.
XmNoperationCursorIcon
يحدد أيقونة المؤشر المستخدمة للإشارة إلى نوع العملية التي تقوم بها معاملة السحب. إذا كانت NULL، فإن موارد XmScreen توفر أيقونات افتراضية لعمليات النسخ والربط والنقل.
XmNsourceCursorIcon
يحدد أيقونة المؤشر المستخدمة لتمثيل المصدر عند استخدام نمط مرئي ديناميكي. إذا كانت NULL، فإن المورد XmNdefaultSourceCursorIcon لـ XmScreen يوفر أيقونة مؤشر افتراضية.
XmNsourcePixmapIcon
يحدد أيقونة البكسل المستخدمة لتمثيل المصدر عند استخدام نمط مرئي مسجل مسبقًا. يتم استخدام الأيقونة بالاقتران مع خريطة الألوان لـ الأداة التي تم تمريرها إلى XmDragStart. إذا كانت NULL، يتم استخدام XmNsourceCursorIcon.
XmNstateCursorIcon
يحدد أيقونة المؤشر المستخدمة للإشارة إلى حالة موقع الإسقاط. إذا كانت NULL، فإن موارد XmScreen توفر أيقونات افتراضية لـ حالة موقع إسقاط صالح، غير صالح، أو لا شيء.
XmNtopLevelEnterCallback
يحدد قائمة الاستدعاءات التي يتم استدعاؤها عند دخول المؤشر إلى نافذة من المستوى الأعلى أو النافذة الجذر (بسبب تغيير الشاشات). نوع البنية التي يتم تمرير عنوانها إلى هذا الاستدعاء هو XmTopLevelEnterCallbackStruct. السبب الذي يتم إرساله بواسطة الاستدعاء هو XmCR_TOP_LEVEL_ENTER.
XmNtopLevelLeaveCallback
يحدد قائمة الاستدعاءات التي يتم استدعاؤها عند مغادرة المؤشر لـ نافذة من المستوى الأعلى أو النافذة الجذر (بسبب تغيير الشاشات). نوع البنية التي يتم تمرير عنوانها إلى هذا الاستدعاء هو XmTopLevelLeaveCallbackStruct. السبب الذي يتم إرساله بواسطة الاستدعاء هو XmCR_TOP_LEVEL_LEAVE.
XmNvalidCursorForeground
يحدد قيمة البكسل الأمامية للمؤشر المعين كـ أيقونة مؤشر صالحة.

NAME

XmDragContext - A widget that manages drag and drop operations

SYNOPSIS

    The XmDragContext widget is a subclass of the XmManager widget.

DESCRIPTION

The XmDragContext widget provides a way to manage drag and drop operations in an X Window System environment. It allows users to drag data from one widget to another, with the ability to perform various actions during the drag operation.

The following key names are listed in the X standard key event translation table syntax. This format is the one used by Motif to specify the widget actions corresponding to a given key. A brief overview of the format is provided under VirtualBindings(3). For a complete description of the format, please refer to the X Toolkit Instrinsics Documentation.

Button1<Enter>:
DragMotion()
Button1<Leave>:
DragMotion()
Button1<Motion>:
DragMotion()
Button2<Enter>:
DragMotion()
Button2<Leave>:
DragMotion()
Button2<Motion>:
DragMotion()
<Btn2Up>:
FinishDrag()
<Btn1Up>:
FinishDrag()
<Key>Return:
FinishDrag()
<Key><osfActivate>:
FinishDrag()
<BtnDown>:
IgnoreButtons()
<BtnUp>:
IgnoreButtons()
:<Key><osfCancel>:
CancelDrag()
:<Key><osfHelp>:

:<Key><osfRight>:

:<KeyUp>:
DragKey(Update)
:<KeyDown>:
DragKey(Update)

Action Routines

The XmDragContext action routines are

CancelDrag():
Cancels the drag operation and frees the associated DragContext.
DragKey(String)
If the value of String is Left, Right, Up, or Down, this action moves the dragged object in the corresponding location. Any other values of String are ignored.
DragMotion():
Drags the selected data as the pointer is moved.
FinishDrag():
Finishes the drag operation and starts the drop operation.
HelpDrag():
Initiates a conditional drop that enables the receiver to provide help information to the user. The user can cancel or continue the drop operation in response to this information.

Virtual Bindings

The bindings for virtual keys are vendor specific. For information about bindings for virtual buttons and keys, see VirtualBindings(3).
