XmNdecrementCallback
يحدد قائمة الاستدعاءات التي يتم استدعاؤها عندما يقوم المستخدم بإجراء يحرك شريط التمرير بمقدار زيادة واحدة وتنخفض القيمة. السبب الممرر إلى الاستدعاء هو XmCR_DECREMENT.
XmNdragCallback
يحدد قائمة الاستدعاءات التي يتم استدعاؤها عند كل تغيير تدريجي في الموضع عند سحب شريط التمرير. السبب المرسل من الاستدعاء هو XmCR_DRAG.
XmNeditable
يحدد كيف سيتفاعل شريط التمرير مع إدخال المستخدم. يمكن أن يكون لهذا المورد قيم `True` أو `False`، على النحو التالي:
True
يسمح لشريط التمرير بالاستجابة لإدخال المستخدم. هذه هي القيمة الافتراضية.
False
يجعل شريط التمرير الخاص بالمقياس غير حساس لإدخال المستخدم. المظهر المرئي ليس رمادياً. ستستخدم هذه القيمة في الغالب في وضع XmTHERMOMETER.
عند استخدام XmNeditable على عنصر واجهة مستخدم، فإنه يضبط موقع الإسقاط إلى XmDROP_SITE_ACTIVE.
XmNincrement
يحدد المقدار الذي تزداد به القيمة أو تنقص به عندما يقوم المستخدم بإجراء يحرك شريط التمرير بمقدار زيادة واحدة. التغيير الفعلي في القيمة هو الأصغر بين XmNincrement و (XmNvalue السابقة - XmNminimum) عندما يتحرك شريط التمرير إلى نهاية شريط التمرير بالقيمة الدنيا، والأصغر بين XmNincrement و (XmNmaximum - XmNsliderSize - XmNvalue السابقة) عندما يتحرك شريط التمرير إلى نهاية شريط التمرير بالقيمة القصوى. يجب أن تكون قيمة هذا المورد أكبر من 0 (صفر).
XmNincrementCallback
يحدد قائمة الاستدعاءات التي يتم استدعاؤها عندما يقوم المستخدم بإجراء يحرك شريط التمرير بمقدار زيادة واحدة وتزداد القيمة. السبب الممرر إلى الاستدعاء هو XmCR_INCREMENT.
XmNinitialDelay
يحدد مقدار الوقت بالمللي ثانية للانتظار قبل بدء حركة شريط التمرير المستمرة أثناء الضغط على زر في سهم أو منطقة التمرير. يجب أن تكون قيمة هذا المورد أكبر من 0 (صفر).
XmNmaximum
يحدد القيمة القصوى لشريط التمرير. يجب أن تكون XmNmaximum أكبر من XmNminimum.
XmNminimum
يحدد القيمة الدنيا لشريط التمرير. يجب أن تكون XmNmaximum أكبر من XmNminimum.
XmNorientation
يحدد ما إذا كان شريط التمرير معروضًا عموديًا أو أفقيًا. يمكن أن يكون لهذا المورد قيم XmVERTICAL و XmHORIZONTAL.
XmNpageDecrementCallback
يحدد قائمة الاستدعاءات التي يتم استدعاؤها عندما يقوم المستخدم بإجراء يحرك شريط التمرير بمقدار زيادة صفحة واحدة وتنخفض القيمة. السبب الممرر إلى الاستدعاء هو XmCR_PAGE_DECREMENT.
XmNpageIncrement
يحدد المقدار الذي تزداد به القيمة أو تنقص به عندما يقوم المستخدم بإجراء يحرك شريط التمرير بمقدار زيادة صفحة واحدة. التغيير الفعلي في القيمة هو الأصغر بين XmNpageIncrement و (XmNvalue السابقة - XmNminimum) عندما يتحرك شريط التمرير إلى نهاية شريط التمرير بالقيمة الدنيا، والأصغر بين XmNpageIncrement و (XmNmaximum - XmNsliderSize - XmNvalue السابقة) عندما يتحرك شريط التمرير إلى نهاية شريط التمرير بالقيمة القصوى. يجب أن تكون قيمة هذا المورد أكبر من 0 (صفر).

RESOURCES

XmNdecrementCallback
Specifies the list of callbacks that is called when the user takes an action that moves the ScrollBar by one page increment and the value decreases. The reason passed to the callback is XmCR_DECREMENT.
XmNincrementCallback
Specifies the list of callbacks that is called when the user takes an action that moves the ScrollBar by one unit increment and the value increases. The reason passed to the callback is XmCR_INCREMENT.
XmNinitialDelay
Specifies the amount of time in milliseconds to wait before subsequent slider movements are generated when the user presses and holds a scroll arrow. The value of this resource must be greater than 0 (zero).
XmNmaximum
Specifies the maximum value of the ScrollBar. The default value is 100.
XmNminimum
Specifies the minimum value of the ScrollBar. The default value is 0.
XmNpageDecrementCallback
Specifies the list of callbacks that is called when the user takes an action that moves the ScrollBar by one page increment and the value decreases. The reason passed to the callback is XmCR_PAGE_DECREMENT.
XmNpageIncrementCallback
Specifies the list of callbacks that is called when the user takes an action that moves the ScrollBar by one page increment and the value increases. The reason passed to the callback is XmCR_PAGE_INCREMENT.
XmNprocessingDirection
Specifies whether the value for XmNmaximum should be on the right or left side of XmNminimum for horizontal ScrollBars or above or below XmNminimum for vertical ScrollBars. This resource can have values of XmMAX_ON_TOP, XmMAX_ON_BOTTOM, XmMAX_ON_LEFT, and XmMAX_ON_RIGHT. If the ScrollBar is oriented vertically, the default value is XmMAX_ON_BOTTOM. If the ScrollBar is oriented horizontally, the default value depends on the XmNlayoutDirection resource of the widget.
XmNrepeatDelay
Specifies the amount of time in milliseconds to wait between subsequent slider movements after the XmNinitialDelay has been processed. The value of this resource must be greater than 0 (zero).
XmNshowArrows
Specifies whether the arrows are displayed and how they are to be displayed. This resource can take the following values:
XmEACH_SIDE
Indicates that one arrow is displayed on each end of the ScrollBar slider. This corresponds to a value of True in previous releases.
XmMAX_SIDE
Indicates that both arrows are displayed on the XmNmaximum side of the ScrollBar slider.
XmMIN_SIDE
Indicates that both arrows are displayed on the XmNminimum side of the ScrollBar slider.
XmNONE
Indicates that no arrows are displayed. This corresponds to a value of False in previous releases.
XmEACH_SIDE is the default value.
XmNsliderMark
Specifies the shape the slider is to be displayed in. This resource can take the following values:
XmETCHED_LINE
Specifies the slider as an etched line.
XmNONE
Specifies the slider as a foregrounded rectangle. This is the default for a regular slider.
XmROUND_MARK
Specifies the slider as a shadowed circle. This is the default when the slider is a thermometer.
XmTHUMB_MARK
Specifies the slider as a series of three etched lines centered in the middle of the slider.
XmNslidingMode
Specifies the mode the slider works in. There are two possible modes:
XmSLIDER
Allows the slider to move freely between the minimum and maximum ends of the scale. This is the default value.
XmTHERMOMETER
Forces the slider to be anchored to one side of the trough area.
XmNsliderSize
Specifies the length of the slider between the values of 1 and (XmNmaximum - XmNminimum). The value is constrained to be within these inclusive bounds. The default value is (XmNmaximum - XmNminimum) divided by 10, with a minimum of 1.
XmNsliderVisual
Specifies the color of the slider visual. This resource can take the following values:
XmBACKGROUND_COLOR
Specifies that the slider visual is in the background color.
XmFOREGROUND_COLOR
Specifies that the slider visual is in the foreground color.
XmSHADOWED_BACKGROUND
Specifies that the slider visual is in the background color, with a shadow. This is the default for a regular slider.
XmTROUGH_COLOR
Specifies that the slider visual is in the trough color. This is the default when the slider is a thermometer.
XmNsnapBackMultiple
Specifies the distance over which the scrollbar slider snaps back to its original position when the user drags the mouse outside the ScrollBar edge. This distance is defined in terms of multiples of the width of the slider. For example, a multiple of 0 (zero) causes the slider to snap back as soon as the pointer moves out of the ScrollBar frame, a multiple of 1 causes the slider to snap back as soon as the pointer moves beyond 1 ScrollBar width of the ScrollBar edge. Whenever the slider snaps back, the ScrollBar dragCallback is called if there is one.
The default value is large enough to prevent unwanted snapBack activity if the mouse is moved within the boundaries of any reasonable screen. To reset the default, set this resource to a large value, such as 10000.
XmNtoBottomCallback
Specifies the list of callbacks that is called when the user takes an action that moves the slider to the end of the ScrollBar with the maximum value. The reason passed to the callback is XmCR_TO_BOTTOM.
XmNtoTopCallback
Specifies the list of callbacks that is called when the user takes an action that moves the slider to the end of the ScrollBar with the minimum value. The reason passed to the callback is XmCR_TO_TOP.
XmNtroughColor
Specifies the color of the slider trough. This color defaults to the color used for selections.
XmNvalue
Specifies the slider's position, between XmNminimum and (XmNmaximum - XmNsliderSize). The value is constrained to be within these inclusive bounds. The initial value of this resource is the larger of 0 (zero) and XmNminimum.
XmNvalueChangedCallback
Specifies the list of callbacks that is called when the slider is released after being dragged. These callbacks are also called in place of XmNincrementCallback, XmNdecrementCallback, XmNpageIncrementCallback, XmNpageDecrementCallback, XmNtoTopCallback, or XmNtoBottomCallback when one of these callback lists would normally be called but the value of the corresponding resource is NULL. The reason passed to the callback is XmCR_VALUE_CHANGED.

NAME

XmScrollBar - A window widget that allows the user to select a value from a range of values

SYNOPSIS

#include <Xm/Xm.h>
#include <Xm/ScrollBar.h>

The class record constant associated with the XmScrollBar widget is named xmScrollBarWidgetClass.

DESCRIPTION

The XmScrollBar widget provides a graphical mechanism for selecting a value from a contiguous range of values. The scroll bar consists of a slider, two arrow buttons, and a background. The slider's position represents the current value. The arrow buttons allow the user to adjust the value by increments or decrements.

The scroll bar can be oriented vertically or horizontally. In vertical orientation, the slider moves up and down. In horizontal orientation, the slider moves left and right.

The scroll bar is typically used in conjunction with another widget to control the viewable area of a larger window or data structure. For example, a vertical scroll bar could be used to control the visible portion of a text widget.

Callback Information

A pointer to the following structure is passed to each callback:

typedef struct
{
        int reason;
        XEvent * event;
        int value;
        int pixel;
} XmScrollBarCallbackStruct;
reason
Indicates why the callback was invoked.
event
Points to the XEvent that triggered the callback.
value
Contains the new slider location value.
pixel
Is used only for XmNtoTopCallback and XmNtoBottomCallback. For horizontal ScrollBars, it contains the x coordinate of where the mouse button selection occurred. For vertical ScrollBars, it contains the y coordinate.

Action Routines

The ScrollBar action routines are

CancelDrag():
If the key press occurs during scrolling, cancels the scroll and returns the slider to its previous location in the scrollbar, otherwise, and if the parent is a manager, it passes the event to the parent.
IncrementDownOrRight(Down|Right):
With an argument of Down, or 0 (zero) for compatibility, moves the slider down by one increment. With an argument of Right, or 1 for compatibility, it moves the slider right by one increment. If XmNprocessingDirection is XmMAX_ON_RIGHT or XmMAX_ON_BOTTOM, movement toward the right or bottom calls the callbacks for XmNincrementCallback. If XmNprocessingDirection is XmMAX_ON_LEFT or XmMAX_ON_TOP, movement toward the right or bottom calls the callbacks for XmNdecrementCallback.
IncrementUpOrLeft(Up|Left):
With an argument of Up, or 0 (zero) for compatibility, moves the slider up by one increment. With an argument of Left, or 1 for compatibility, it moves the slider left by one increment. If XmNprocessingDirection is XmMAX_ON_RIGHT or XmMAX_ON_BOTTOM, movement toward the left or up calls the callbacks for XmNdecrementCallback. If XmNprocessingDirection is XmMAX_ON_LEFT or XmMAX_ON_TOP, movement toward the left or up calls the callbacks for XmNincrementCallback.
Moved():
Moves the slider to the current pointer location.
PageDownOrRight(Down|Right):
With an argument of Down, or 0 (zero) for compatibility, moves the slider down by one page increment. With an argument of Right, or 1 for compatibility, it moves the slider right by one page increment. If XmNprocessingDirection is XmMAX_ON_RIGHT or XmMAX_ON_BOTTOM, movement toward the right or bottom calls the callbacks for XmNpageIncrementCallback. If XmNprocessingDirection is XmMAX_ON_LEFT or XmMAX_ON_TOP, movement toward the right or bottom calls the callbacks for XmNpageDecrementCallback.
PageUpOrLeft(Up|Left):
With an argument of Up, or 0 (zero) for compatibility, moves the slider up by one page increment. With an argument of Left, or 1 for compatibility, it moves the slider left by one page increment. If XmNprocessingDirection is XmMAX_ON_RIGHT or XmMAX_ON_BOTTOM, movement toward the left or up calls the callbacks for XmNpageDecrementCallback. If XmNprocessingDirection is XmMAX_ON_LEFT or XmMAX_ON_TOP, movement toward the left or up calls the callbacks for XmNpageIncrementCallback.
PrimitiveHelp():
Invokes the help action for the widget.
PrimitiveNextTabGroup():
Moves the keyboard focus to the next widget in the tab group.
PrimitiveParentActivate():
Activates the default button in the parent widget.
PrimitivePrevTabGroup():
Moves the keyboard focus to the previous widget in the tab group.
Release():
Releases the grab on the pointer and ends the scrolling action.
Select():
Begins a scrolling operation by grabbing the pointer and initiating the scroll.
TopOrBottom():
Moves the slider to the top or bottom of the scroll bar, depending on the direction of the event.
