XmScrollBarGetValues(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmScrollBarGetValues(استدعاء مكتبة) XmScrollBarGetValues(استدعاء مكتبة)

الاسم

XmScrollBarGetValues — وظيفة شريط التمرير تعيد قيم الزيادة لشريط التمرير

الملخص

#include <Xm/ScrollBar.h>
void XmScrollBarGetValues (widget, value_return, slider_size_return,
increment_return, page_increment_return)
        Widget  widget;
        int     * value_return;
        int     * slider_size_return;
        int     * increment_return;
        int     * page_increment_return;
(void)

الوصف

XmScrollBarGetValues تعيد قيم الزيادة لشريط التمرير. يتم تراكب منطقة التمرير مع شريط تمرير يتم ضبط حجمه وموضعه باستخدام سمات شريط التمرير الرئيسي أو سمات وظيفة شريط التمرير.

widget
يحدد معرف عنصر واجهة شريط التمرير.
value_return
يعيد موضع شريط التمرير بين الموارد XmNminimum و XmNmaximum. حدد NULL لمنع إعادة قيمة معينة.
slider_size_return
يعيد حجم شريط التمرير كقيمة بين 0 (صفر) والقيمة المطلقة لـ XmNmaximum ناقص XmNminimum. يختلف حجم شريط التمرير، اعتمادًا على مقدار مساحة التمرير التي يمثلها.
increment_return
يعيد مقدار الزيادة والنقصان.
page_increment_return
يعيد مقدار الزيادة والنقصان للصفحة.

للحصول على تعريف كامل لشريط التمرير والموارد المرتبطة به، انظر XmScrollBar(3).

الإرجاع

يعيد قيم الزيادة لشريط التمرير.
