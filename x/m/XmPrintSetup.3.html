XmPrintSetup(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmPrintSetup(استدعاء مكتبة) XmPrintSetup(استدعاء مكتبة)

الاسم

XmPrintSetup — إعداد وإنشاء ويدجت Print Shell

الملخص

#include <Xm/Print.h>
Widget XmPrintSetup(
Widget video_widget,
Screen *print_screen,
String print_shell_name,
ArgList args,
Cardinal num_args);

الوصف

وظيفة تقوم بالإعداد المناسب وإنشاء XmPrintShell مُفعّل تعيده إلى المتصل. هذه الوظيفة تخفي تفاصيل Xt لإعداد تسلسل هرمي لـ print shell صالح للتطبيق. وهي تهدف أيضًا إلى تشجيع الاتساق في الطريقة التي ترتب بها التطبيقات التسلسل الهرمي لويدجت الطباعة الخاص بها.

يجب أن ينتمي print_screen إلى اتصال Display الذي تم تهيئته بالفعل باستخدام Xt.

يتم استخدام video_widget للوصول إلى سياق التطبيق، اسم التطبيق وفئته، و argc/argv المخزنة في applicationShell التي ترأس هذا الويدجت. إذا لم يتم العثور على applicationShell، يتم استخدام NULL argv/argc.

يقوم XmPrintSetup بعد ذلك بإنشاء ApplicationShell غير مُفعّل بنفس الاسم والفئة الخاصة بتلك التي يوفرها عرض الفيديو، على عرض الطباعة والشاشة المحددة للطباعة.

ثم يتم إنشاء XmPrintShell كطفل لهذا الـ shell العلوي، باستخدام XtCreatePopupShell، بالاسم print_shell_name، وباستخدام args المقدمة. ثم يقوم بتفعيل ورسم الـ print shell، باستخدام XtPopup مع XtGrabNone.

بهذه الطريقة، يمكن لملفات موارد التطبيق والمستخدمين تحديد سمات خاصة بالطباعة باستخدام الصيغة التالية (إذا كان print_shell_name هو "Print"):

Dtpad.Print*textFontList: somefont
*Print*background:white
*Print*highlightThickness:0
video_widget
ويدجت فيديو لجلب بيانات الفيديو من التطبيق.
print_screen
شاشة طباعة على عرض الطباعة - تحدد الشاشة التي يتم إنشاء الـ shell الجديد عليها.
print_shell_name
يحدد اسم XmPrintShell الذي تم إنشاؤه على خادم طباعة X.
args
يحدد قائمة الوسائط التي يتم منها الحصول على الموارد لـ XmPrintShell.
num_args
يحدد عدد الوسائط في قائمة الوسائط.

قيمة الإرجاع

معرف ويدجت XmPrintShell الذي تم إنشاؤه على اتصال خادم طباعة X، أو NULL في حالة حدوث خطأ.

الأخطاء/التحذيرات

لا يوجد.

أمثلة

من رد استدعاء OK و رد استدعاء SetUp لويدجت مربع حوار الطباعة الأساسي:

static void
printOKCB(Widget, XtPointer call_data, XtPointer client_data)
{
  AppPrint *p = (AppPrint *) client_data;
  DtPrintSetupCallbackStruct *pbs =
                         (XmPrintCallbackStruct *) call_data;
  /* اتصال إذا لم يتم بالفعل.
     رد استدعاء مربع حوار الطباعة يوفر دائمًا
             اسم الطابعة، عرض الطباعة والشاشة
             مهيأة بالفعل: تم استدعاء XpInitContext */
 */
  p->print_shell = XmPrintSetup (widget, pbs->print_screen,
                                              "Print", NULL, 0);
  ...
}
