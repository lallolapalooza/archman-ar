XmGetPixmapByDepth(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

الاسم

XmGetPixmapByDepth - دالة XmGetPixmapByDepth

نبذة

#include <Xm/Xm.h>

Pixmap XmGetPixmapByDepth (
    Widget widget,
    _Xconst char *image_name,
    Pixel foreground,
    Pixel background
);

الوصف

تستدعي دالة XmGetPixmapByDepth دالة XmGetPixmap مع زيادة العمق.

تُرجع الدالة XmGetPixmapByDepth خريطة بكسل (pixmap) تمثل الصورة المسماة image_name. إذا تم العثور على الصورة، يتم إرجاع خريطة بكسل. إذا لم يتم العثور على الصورة، يتم إرجاع XmUNSPECIFIED_PIXMAP.

تُستخدم الدالة XmGetPixmapByDepth للحصول على خريطة بكسل لصورة تم تسجيلها مسبقًا باستخدام XmInstallImage.

تعمل الدالة XmGetPixmapByDepth بشكل مشابه للدالة XmGetPixmap، ولكنها تأخذ عمق الشاشة المستهدفة في الاعتبار عند البحث عن خريطة البكسل.

يتم تخزين خريطة البكسل المستعادة في ذاكرة التخزين المؤقت، بحيث إذا تم استدعاء الدالة مرة أخرى بنفس المعلمات، فسيتم إرجاع خريطة البكسل المخزنة مؤقتًا بدلاً من إعادة إنشائها.

تُستخدم المعلمات foreground و background لتحديد ألوان المقدمة والخلفية لخريطة البكسل. إذا تم تعيين أي من هذه المعلمات إلى XmUNSPECIFIED_PIXMAP، فسيتم استخدام الألوان الافتراضية.

مثال

فيما يلي مثال على كيفية استخدام الدالة XmGetPixmapByDepth:

    Widget my_widget;
    char *image_name = "my_image";
    Pixel fg, bg;
    Pixmap pixmap;

    /* الحصول على ألوان المقدمة والخلفية */
    XtVaGetValues(my_widget, XmNforeground, &fg, XmNbackground, &bg, NULL);

    /* الحصول على خريطة البكسل */
    pixmap = XmGetPixmapByDepth(my_widget, image_name, fg, bg);

    /* التحقق مما إذا تم العثور على خريطة البكسل */
    if (pixmap == XmUNSPECIFIED_PIXMAP) {
        /* التعامل مع الخطأ */
        fprintf(stderr, "Could not find pixmap for image: %s\n", image_name);
    } else {
        /* استخدام خريطة البكسل */
        XtVaSetValues(my_widget, XmNpixmap, pixmap, NULL);
    }

الاستخدام

تُستخدم الدالة XmGetPixmapByDepth لإنشاء خريطة بكسل لصورة موجودة. تُستخدم خريطة البكسل لإنشاء صور معقدة، مثل الصور ذات التدرجات أو الأنماط.

يجب تسجيل الصورة مسبقًا باستخدام الدالة XmInstallImage قبل استدعاء XmGetPixmapByDepth.

الإرجاع

تُرجع خريطة بكسل عند النجاح؛ تُرجع XmUNSPECIFIED_PIXMAP إذا تعذر العثور على الصورة المقابلة لـ image_name.

ذات الصلة

XmDestroyPixmap(3)، XmInstallImage(3)، و XmUninstallImage(3).
