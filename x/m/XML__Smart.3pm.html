XML__Smart(3pm)

الحزمة: perl-xml-smart

التراخيص: GPL, PerlArtistic

XML::Smart(3) وثائق Perl المساهم بها من المستخدم XML::Smart(3)

الاسم

XML::Smart - طريقة ذكية وسهلة وقوية للوصول أو إنشاء XML من الملفات والبيانات وعناوين URL.

الإصدار

الإصدار 1.79

الملخص

توفر هذه الوحدة طريقة سهلة للوصول/إنشاء بيانات XML. تعتمد على شجرة HASH تم إنشاؤها من بيانات XML، وتمكن الوصول الديناميكي إليها من خلال بناء الجملة القياسي في Perl للتجزئة (Hash) والمصفوفة (Array)، دون الحاجة بالضرورة إلى الاهتمام بأي منهما تعمل معه. بمعنى آخر، كل نقطة في الشجرة تعمل كتجزئة (Hash) وكمصفوفة (Array) في نفس الوقت!

توفر هذه الوحدة بالإضافة إلى ذلك موارد خاصة مثل: البحث عن العقد بواسطة السمات (attributes)، اختيار قيمة سمة في كل عقدة متعددة، تغيير تنسيق الإخراج، وما إلى ذلك.

تقوم الوحدة أيضًا بالتعامل التلقائي مع البيانات الثنائية (التشفير/فك التشفير من/إلى base64)، CDATA (مثل المحتويات مع <tags>) واليونيكود. يمكن استخدامها لإنشاء ملفات XML، تحميل XML من الويب (فقط باستخدام عنوان URL كمسار ملف) ولديها طريقة سهلة لإرسال بيانات XML عبر المقابس (sockets) - فقط بإضافة طول البيانات في رأس <?xml؟>.

يمكنك استخدام XML::Smart مع XML::Parser، أو مع المحللين القياسيين الاثنين لـ XML::Smart:

XML::Smart::Parser
XML::Smart::HTMLParser.

XML::Smart::HTMLParser يمكن استخدامها لتحميل/تحليل بيانات XML غير منتظمة/سيئة، أو علامات HTML.

## إنشاء الكائن وتحميل الملف:
my $XML = XML::Smart->new('file.xml') ;

## فرض استخدام المحلل 'XML::Smart::Parser'.
my $XML = XML::Smart->new('file.xml' , 'XML::Smart::Parser') ;

## الحصول من الويب:
my $XML = XML::Smart->new('http://www.perlmonks.org/index.pl?node_id=16046') ;
## قص الجذر:
$XML = $XML->cut_root ;
## أو تغيير الجذر:
$XML = $XML->{hosts} ;
## الحصول على العنوان [0] للخادم [0]:
my $srv0_addr0 = $XML->{server}[0]{address}[0] ;
## ...أو...
my $srv0_addr0 = $XML->{server}{address} ;

## الحصول على الخادم حيث السمة 'type' تساوي 'suse':
my $server = $XML->{server}('type','eq','suse') ;

## الحصول على العنوان مرة أخرى:
my $addr1 = $server->{address}[1] ;
## ...أو...
my $addr1 = $XML->{server}('type','eq','suse'){address}[1] ;

## الحصول على جميع عناوين الخادم:
my @addrs = @{$XML->{server}{address}} ;
## ...أو...
my @addrs = $XML->{server}{address}('@') ;

## الحصول على قائمة أنواع جميع الخوادم:
my @types = $XML->{server}('[@]','type') ;

## إضافة عقدة خادم جديدة:

version => 8.9 ,

                                        ## المقبس من معرفة كمية البيانات المراد قراءتها.

الأساليب (Methods)

new (FILE|DATA|URL , PARSER , OPTIONS)

إنشاء كائن XML.

الوسائط (Arguments):

FILE|DATA|URL
يمكن أن تكون الوسيطة الأولى: 
- بيانات XML كسلسلة نصية.
- مسار ملف.
- مقبض ملف (GLOB).
- عنوان URL (يتطلب LWP::UserAgent).

إذا لم يتم تمرير أي شيء، يتم بدء شجرة XML فارغة، حيث يجب عليك إنشاء بيانات XML الخاصة بك، ثم بناء/حفظ/إرسالها.

PARSER (اختياري)
تعيين محلل XML المراد استخدامه. الخيارات: 
XML::Parser
XML::Smart::Parser
XML::Smart::HTMLParser

XML::Smart::Parser يمكنه فقط التعامل مع بيانات XML الأساسية (لا يدعم PCDATA، وأي رأس مثل: ENTITY, NOTATION, إلخ...)، ولكنه خيار جيد عندما لا ترغب في تثبيت وحدات كبيرة لتحليل XML، حيث يأتي مع الوحدة الرئيسية. ولكنه لا يزال بإمكانه التعامل مع CDATA والبيانات الثنائية.

** انظر "تحليل HTML كـ XML" لـ XML::Smart::HTMLParser.

أسماء مستعارة للخيارات:

SMART|REGEXP   => XML::Smart::Parser
HTML           => XML::Smart::HTMLParser

الافتراضي:

إذا لم يتم التعيين، سيبحث عن XML::Parser ويقوم بتحميله. إذا لم يتم تحميل XML::Parser، فسيستخدم XML::Smart::Parser، وهو في الواقع نسخة من XML::Parser::Lite مع بعض الإصلاحات.

OPTIONS
يمكنك فرض الحالة العلوية والسفلية للعلامات (العقد) والوسائط (السمات)، وأشياء إضافية أخرى.
lowtag
جعل العلامات بحالة سفلية.
lowarg
جعل الوسائط بحالة سفلية.
upertag
جعل العلامات بحالة علوية.
uperarg
جعل الوسائط بحالة علوية.
arg_single
تعيين قيمة الوسائط إلى 1 عندما تكون قيمتها undef.

** سيعمل هذا الخيار فقط عند تحليل XML بواسطة XML::Smart::HTMLParser، لأنه يقبل الوسائط بدون قيم:

my $xml = new XML::Smart(
'<root><foo arg1="" flag></root>' ,
'XML::Smart::HTMLParser' ,
arg_single => 1 ,
) ;

في هذا المثال، تم استخدام الخيار "arg_single"، والذي سيعين flag إلى 1، ولكن arg1 سيظل له قيمة سلسلة فارغة ("").

هذه هي شجرة المثال أعلاه:

'root' => {
            'foo' => {
                       'flag' => 1,
                       'arg1' => ''
                     },
          },
use_spaces
قبول المحتويات التي تحتوي فقط على مسافات.
on_start (CODE) *اختياري
تعليمات برمجية/دالة فرعية لاستدعائها عند بدء علامة.

** سيتم استدعاء هذا بعد تحليل XML::Smart للعلامة، يجب استخدامه فقط إذا كنت ترغب في تغيير الشجرة.

on_char (CODE) *اختياري
تعليمات برمجية/دالة فرعية لاستدعائها عند المحتوى.

** سيتم استدعاء هذا بعد تحليل XML::Smart للعلامة، يجب استخدامه فقط إذا كنت ترغب في تغيير الشجرة.

on_end (CODE) *اختياري
تعليمات برمجية/دالة فرعية لاستدعائها عند انتهاء علامة.

** سيتم استدعاء هذا بعد تحليل XML::Smart للعلامة، يجب استخدامه فقط إذا كنت ترغب في تغيير الشجرة.
