الوصف

تحتوي مكتبة لغة التطبيق لـ امتداد X11 للتخزين المؤقت المزدوج، والتخزين المؤقت المتعدد، والمجسم على الواجهات الموضحة أدناه. باستثناء XmbufQueryExtension، إذا تم استدعاء أي من هذه الروتينات بعرض لا يدعم الامتداد، فسيتم استدعاء ExtensionErrorHandler (الذي يمكن تعيينه باستخدام XSetExtensionErrorHandler ويعمل بنفس طريقة XSetErrorHandler) وسيتم إرجاع الوظيفة بعد ذلك.

XmbufQueryExtension ترجع True إذا كان امتداد التخزين المؤقت المتعدد / المجسم متاحًا على العرض المحدد. إذا كان الامتداد موجودًا، فسيتم تخزين قيمة رمز الحدث الأول (الذي يجب إضافته إلى ثوابت نوع الحدث MultibufferClobberNotify و MultibufferUpdateNotify للحصول على القيم الفعلية) في event_base_return وقيمة رمز الخطأ الأول (الذي يجب إضافته إلى ثابت نوع الخطأ MultibufferBadBuffer للحصول على القيمة الفعلية) في error_base_return.

XmbufGetVersion يحصل على أرقام الإصدار الرئيسي والثانوي للامتداد. قيمة الإرجاع هي صفر إذا حدث خطأ أو غير صفر إذا لم يحدث خطأ.

XmbufCreateBuffers يطلب إنشاء "count" من المخازن المؤقتة بالـ update_action و update_hint المحددة وربطها بالنافذة المشار إليها. يتم إرجاع عدد المخازن المؤقتة التي تم إنشاؤها (صفر إذا حدث خطأ) ويتم ملء buffers_update بمعرفات Multibuffer بهذا العدد.

XmbufDestroyBuffers يدمر المخازن المؤقتة المرتبطة بالنافذة المحددة.

XmbufDisplayBuffers يعرض المخازن المؤقتة المشار إليها في نوافذها المناسبة في غضون max_delay مللي ثانية بعد مرور min_delay مللي ثانية. لا يمكن ربط مخزنين مؤقتين بنفس النافذة أو سيتم إنشاء خطأ Match.

XmbufGetWindowAttributes يحصل على سمات التخزين المؤقت المتعدد التي تنطبق على جميع المخازن المؤقتة المرتبطة بالنافذة المحددة. يمكن تحرير قائمة المخازن المؤقتة المرتجعة باستخدام XFree. ترجع قيمة غير صفرية عند النجاح وصفر إذا حدث خطأ.

XmbufChangeWindowAttributes يضبط سمات التخزين المؤقت المتعدد التي تنطبق على جميع المخازن المؤقتة المرتبطة بالنافذة المحددة. يقتصر هذا حاليًا على update_hint.

XmbufGetBufferAttributes يحصل على سمات المخزن المؤقت المشار إليه. ترجع قيمة غير صفرية عند النجاح وصفر إذا حدث خطأ.

XmbufChangeBufferAttributes يضبط سمات المخزن المؤقت المشار إليه. يقتصر هذا حاليًا على event_mask.

XmbufGetScreenInfo يحصل على المعلمات التي تتحكم في كيفية إنشاء النوافذ الأحادية والمجسمة على شاشة العنصر القابل للرسم المحدد. يتم إرجاع أعداد مجموعات العرض المرئي والأعماق في nmono_return و nstereo_return. إذا كان nmono_return أكبر من صفر، فسيتم تعيين mono_info_return إلى عنوان مصفوفة من هياكل XmbufBufferInfo التي تصف العروض المرئية والأعماق المختلفة التي يمكن استخدامها. بخلاف ذلك، يتم تعيين mono_info_return إلى NULL. وبالمثل، يتم تعيين stereo_info_return وفقًا لـ nstereo_return. يمكن تحرير التخزين الذي تم إرجاعه في mono_info_return و stereo_info_return بواسطة XFree. إذا لم تحدث أخطاء، فسيتم إرجاع قيمة غير صفرية.

XmbufCreateStereoWindow ينشئ نافذة مجسمة بنفس طريقة إنشاء XCreateWindow نافذة أحادية. يتم إرجاع معرفات المخازن المؤقتة للمخزن الأيسر والأيمن في left_return و right_return، على التوالي. إذا تم تثبيت معالج أخطاء امتداد يعود، فسيتم إرجاع None إذا كان الامتداد غير متاح على هذا العرض.

XmbufQueryExtension(3)

NAME

XmbufQueryExtension - Query the multi-buffering extension

SYNTAX

#include <X11/extensions/mbuf.h>
Bool XmbufQueryExtension (Display *display, int *event_base, int *error_base);

STRUCTURES

This extension defines no structures.

DESCRIPTION

XmbufQueryExtension checks if the multi-buffering extension is available on the specified display. If the extension is available, it returns True and fills in the values pointed to by event_base and error_base with the base event code and error code for the extension, respectively. If the extension is not available, it returns False.

PREDEFINED VALUES

The multi-buffering extension defines the following event and error codes:

XmbufUpdateNotify
XmbufClobberNotify
XmbufUpdateNotifyMask
XmbufClobberNotifyMask
XmbufNumberEvents
XmbufNumberErrors
XmbufBadBuffer

The event codes are used to notify the client of events such as buffer updates or overwrites. The error codes are used to indicate errors such as an invalid buffer being accessed.

ferUpdateNotifyMask
MultibufferClobberNotify
MultibufferUpdateNotify
MultibufferNumberEvents
MultibufferBadBuffer
MultibufferNumberErrors
