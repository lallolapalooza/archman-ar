XmVaCreateRowColumn(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateRowColumn(استدعاء مكتبة) XmVaCreateRowColumn(استدعاء مكتبة)

الاسم

XmVaCreateRowColumn, XmVaCreateManagedRowColumn — وظائف مساعدة لإنشاء أداة RowColumn.

الملخص

#include <Xm/RowColumn.h>
Widget XmVaCreateRowColumn(
Widget parent,
String name,
...);
Widget XmVaCreateManagedRowColumn(
Widget parent,
String name,
...);

الوصف

تقوم هذه الوظائف بإنشاء مثيل لأداة ToggleButtonGadget وتعيد معرف الأداة المرتبط بها. تستخدم هذه الروتينات اتفاقية استدعاء قائمة الوسائط المتغيرة ANSI C (varargs).

تعتبر الوظيفة XmVaCreateRowColumn روتينًا مساعدًا يستدعي XtCreateWidget.

تعتبر الوظيفة XmVaCreateRowColumn روتينًا مساعدًا يستدعي XtCreateManagedWidget.

parent
تحدد معرف الأداة الأصل.
name
تحدد اسم الأداة المنشأة.
...
تحدد قائمة الوسائط المتغيرة لتجاوز قيم الموارد الافتراضية.

للحصول على تعريف كامل لـ RowColumn والموارد المرتبطة به، انظر XmRowColumn(3).

الإرجاع

تعيد معرف أداة RowColumn.

ذات صلة

XmRowColumn(3), XmCreateRowColumn(3), XtCreateWidget(3), و XtCreateManagedWidget(3).
