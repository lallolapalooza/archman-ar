XmVaCreateManagedExt18List(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateExt18List(استدعاء مكتبة) XmVaCreateExt18List(استدعاء مكتبة)

الاسم

XmVaCreateExt18List, XmVaCreateManagedExt18List — وظائف إنشاء مساعدة لعنصر واجهة المستخدم Ext18List.

الملخص

#include <Xm/Ext18List.h>
Widget XmVaCreateExt18List(
Widget parent,
String name,
...);
Widget XmVaCreateManagedExt18List(
Widget parent,
String name,
...);

الوصف

تقوم هذه الوظائف بإنشاء نسخة من عنصر واجهة المستخدم Ext18List وتعيد معرّف العنصر المرتبط بها. تستخدم هذه الروتينات اتفاقية استدعاء قائمة الوسائط المتغيرة (varargs) لمعيار ANSI C.

وظيفة XmVaCreateExt18List هي روتين مساعد يستدعي XtCreateWidget.

وظيفة XmVaCreateManagedExt18List هي روتين مساعد يستدعي XtCreateManagedWidget.

parent
يحدد معرّف العنصر الأب.
name
يحدد اسم العنصر الذي تم إنشاؤه.
...
يحدد قائمة الوسائط المتغيرة لتجاوز إعدادات الموارد الافتراضية.

للحصول على تعريف كامل لعنصر Form وموارده المرتبطة، انظر XmExt18List(3).

الإرجاع

يعيد معرّف عنصر واجهة المستخدم Ext18List.

ذات الصلة

XmCreateExt18List(3), XtCreateManagedWidget(3), XtCreateWidget(3), و XmExt18List(3).
