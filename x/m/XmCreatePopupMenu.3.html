XmCreatePopupMenu(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmCreatePopupMenu(استدعاء مكتبة) XmCreatePopupMenu(استدعاء مكتبة)

الاسم

XmCreatePopupMenu — دالة إنشاء مريحة لأداة RowColumn

الشكل العام

#include <Xm/RowColumn.h>
Widget XmCreatePopupMenu(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

الوصف

تقوم XmCreatePopupMenu بإنشاء مثيل لأداة RowColumn من النوع XmMENU_POPUP وتعيد معرّف الأداة المرتبط. عند استخدام هذه الدالة لإنشاء لوحة قائمة منبثقة (Popup menu pane)، يتم تلقائيًا إنشاء أداة MenuShell كوالد للوحة القائمة. والد أداة MenuShell هو الأداة المشار إليها بواسطة المعلمة parent.

تم توفير XmCreatePopupMenu كدالة مريحة لإنشاء أدوات RowColumn تم تكوينها للعمل كلوحات قوائم منبثقة وهي ليست منفذة كفئة أداة منفصلة.

تُستخدم قائمة Popup Menu كأول لوحة قائمة ضمن نظام قائمة Popup Menu؛ وجميع لوحات القائمة الأخرى من نوع Pulldown. تعرض لوحة قائمة Popup Menu ظلًا ثلاثي الأبعاد، ما لم يتم تعطيل الميزة بواسطة التطبيق. يظهر الظل حول حافة لوحة القائمة.

يجب إنشاء لوحة قائمة Popup Menu كابنة لأداة MenuShell لكي تعمل بشكل صحيح عند دمجها في قائمة. إذا استخدم التطبيق هذه الدالة المريحة لإنشاء لوحة قائمة Popup، يتم تلقائيًا إنشاء MenuShell كالوالد الحقيقي للوحة القائمة. إذا لم يستخدم التطبيق هذه الدالة المريحة لإنشاء RowColumn ليعمل كلوحة قائمة Popup، فإن مسؤولية إنشاء أداة MenuShell تقع على عاتق التطبيق.

للوصول إلى PopupMenu، يجب على التطبيق أولاً تحديد موقع الأداة باستخدام الدالة XmMenuPosition ثم إدارتها باستخدام XtManageChild.

parent
يحدد معرّف الأداة الوالدة.
name
يحدد اسم الأداة التي تم إنشاؤها.
arglist
يحدد قائمة الوسائط.
argcount
يحدد عدد أزواج السمات/القيم في قائمة الوسائط (arglist).

تدعم لوحات قائمة Popup قابلیت السحب (tear-off capabilities) للقوائم القابلة للسحب من خلال موارد XmRowColumn. لتعريف كامل لـ RowColumn وموارده المرتبطة، انظر XmRowColumn(3).

الإرجاع

يعيد معرّف أداة RowColumn.

ذات صلة

XmCreateSimplePopupMenu(3)، XmMenuPosition(3)، XmMenuShell(3)، XmRowColumn(3)، و XmVaCreateSimplePopupMenu(3).
