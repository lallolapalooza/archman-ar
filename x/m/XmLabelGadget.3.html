التراخيص: LGPL-2.1-or-later

الاسم

XmLabelGadget — فئة عنصر واجهة المستخدم LabelGadget

الملخص

#include <Xm/LabelG.h>

الوصف

LabelGadget هو عنصر واجهة مستخدم قابل للإنشاء ويستخدم أيضًا كفئة أساسية لعناصر واجهة المستخدم للأزرار الأخرى، مثل PushButtonGadget و ToggleButtonGadget.

يمكن لـ LabelGadget أن يحتوي إما على نص أو بيكسماپ (صورة نقطية). نص LabelGadget هو سلسلة نصية مركبة. ارجع إلى دليل مبرمج Motif (Motif Programmer's Guide) لمزيد من المعلومات حول السلاسل النصية المركبة. يمكن أن يكون النص متعدد اللغات، متعدد الأسطر، و/أو متعدد الخطوط. عندما يكون LabelGadget غير نشط، يتم تنقيط نصه، أو يتم عرض البيكسماپ غير النشط المقدم من المستخدم.

يدعم LabelGadget كل من الاختصارات (accelerators) والاختصارات التذكيرية (mnemonics) بشكل أساسي للاستخدام في عناصر واجهة المستخدم الفرعية من LabelGadget الموجودة في القوائم. الاختصارات التذكيرية متاحة في نظام القوائم عندما يكون الزر مرئيًا. يمكن الوصول إلى الاختصارات في نظام القوائم حتى عندما لا يكون الزر مرئيًا. يعرض LabelGadget الاختصار التذكيري عن طريق تسطير أول حرف مطابق في سلسلة النص. يتم عرض الاختصار كسلسلة نصية مجاورة لنص التسمية أو البيكسماپ، اعتمادًا على اتجاه التخطيط.

يتكون LabelGadget من العديد من حقول الهامش المحيطة بالنص أو البيكسماپ. هذه الحقول الهامشية هي موارد يمكن للمستخدم تعيينها، ولكن عناصر واجهة المستخدم الفرعية لـ LabelGadget والوالدين المديرين (Manager parents) يقومون أيضًا بتعديل بعض هذه الحقول. يميلون إلى تعديل الموارد XmNmarginLeft و XmNmarginRight و XmNmarginTop و XmNmarginBottom ويتركون الموارد XmNmarginWidth و XmNmarginHeight كما تم تعيينها بواسطة التطبيق.

يأخذ LabelGadget في الاعتبار XmNshadowThickness عند تحديد تخطيطه ولكنه لا يرسم الظل. أي، إذا كان XmNshadowThickness أكبر من 0 (صفر)، يترك LabelGadget مساحة للظل، ولكن الظل لا يظهر.

في LabelGadget، يتم فرض XmNtraversalOn و XmNhighlightOnEnter على False داخل نوافذ القوائم المنبثقة (Popup menu panes) ونوافذ القوائم السفلية (Pulldown menu panes) وقوائم الخيارات (OptionMenus). بخلاف ذلك، تكون قيمة هذه الموارد الافتراضية False.

يستخدم LabelGadget سمات XmQTmenuSystem و XmQTspecifyRenderTable، ويحتفظ بسمات XmQTaccessTextual و XmQTcareParentVisual و XmQTmenuSavvy و XmQTtransfer.

سلوك نقل البيانات

يدعم LabelGadget وعناصر واجهة المستخدم الفرعية الخاصة به، باستثناء عند استخدامه في نظام القائمة، سحب محتويات التسمية من LabelGadget. ومع ذلك، تكون محتويات التسمية قابلة للسحب فقط إذا تم تعيين المورد XmNenableUnselectableDrag لـ XmDisplay على True.

كمصدر للبيانات، يدعم LabelGadget وعناصر واجهة المستخدم الفرعية الخاصة به الأهداف التالية وتحويلات البيانات المقابلة لهذه الأهداف:

locale
إذا كان الهدف locale يتطابق مع اللغة المحلية للعنصر، يقوم العنصر بنقل XmNlabelString بالترميز الخاص باللغة المحلية. هذا الهدف مدعوم فقط عندما تكون XmNlabelType هي XmSTRING أو XmPIXMAP_AND_STRING.
COMPOUND_TEXT
يقوم العنصر بنقل XmNlabelString بنوع COMPOUND_TEXT. هذا الهدف مدعوم فقط عندما تكون XmNlabelType هي XmSTRING أو XmPIXMAP_AND_STRING.
UTF8_STRING
يقوم العنصر بنقل XmNlabelString بنوع UTF8_STRING. هذا الهدف مدعوم فقط عندما تكون XmNlabelType هي XmSTRING أو XmPIXMAP_AND_STRING.
PIXMAP
يقوم العنصر بنقل XmNlabelPixmap بنوع DRAWABLE. هذا الهدف مدعوم عندما تكون XmNlabelType هي XmPIXMAP أو XmPIXMAP_AND_STRING.
STRING
يقوم العنصر بنقل XmNlabelString بنوع STRING. هذا الهدف مدعوم عندما تكون XmNlabelType هي XmSTRING أو XmPIXMAP_AND_STRING.
TEXT
إذا كان XmNlabelString قابلاً للتحويل بالكامل إلى ترميز اللغة المحلية، يقوم العنصر بنقل XmNlabelString بترميز اللغة المحلية. بخلاف ذلك، يقوم العنصر بنقل XmNlabelString بنوع COMPOUND_TEXT. هذا الهدف مدعوم عندما تكون XmNlabelType هي XmSTRING أو XmPIXMAP_AND_STRING.
_MOTIF_CLIPBOARD_TARGETS
ينقل العنصر، بنوع ATOM، قائمة بالأهداف التي يدعمها لاختيار CLIPBOARD. عندما تكون XmNlabelType هي XmSTRING أو XmPIXMAP_AND_STRING، تشمل هذه الأهداف التالية:
•
_MOTIF_COMPOUND_STRING
•
COMPOUND_TEXT
•
UTF8_STRING
•
ترميز اللغة المحلية، إذا كان XmNlabelString قابلاً للتحويل بالكامل إلى ترميز اللغة المحلية
•
STRING، إذا كان XmNlabelString قابلاً للتحويل بالكامل إلى STRING
عندما تكون XmNlabelType هي XmPIXMAP أو XmPIXMAP_AND_STRING، تشمل الأهداف PIXMAP.
_MOTIF_COMPOUND_STRING
يقوم العنصر بنقل XmNlabelString كسلسلة نصية مركبة بتنسيق Byte Stream. هذا الهدف مدعوم عندما تكون XmNlabelType هي XmSTRING أو XmPIXMAP_AND_STRING.
_MOTIF_EXPORT_TARGETS
ينقل العنصر، بنوع ATOM، قائمة بالأهداف التي سيتم استخدامها كقيمة لـ XmNexportTargets في سياق DragContext في نقل السحب والإفلات. عندما تكون XmNlabelType هي XmSTRING أو XmPIXMAP_AND_STRING، تشمل هذه _MOTIF_COMPOUND_STRING و COMPOUND_TEXT و UTF8_STRING و ترميز اللغة المحلية و STRING و TEXT و BACKGROUND و FOREGROUND. عندما تكون XmNlabelType هي XmPIXMAP أو XmPIXMAP_AND_STRING، تشمل هذه PIXMAP و BACKGROUND و FOREGROUND.

كمصدر للبيانات، يدعم LabelGadget أيضًا أهداف Motif القياسية التالية:

BACKGROUND
يقوم العنصر بنقل XmNbackground للعنصر الأب بنوع PIXEL.
CLASS
يجد العنصر أول نافذة عائمة (shell) في التسلسل الهرمي للعناصر التي تحتوي على خاصية WM_CLASS وينقل محتوياتها كنص باللغة المحلية الحالية.
CLIENT_WINDOW
يجد العنصر أول نافذة عائمة في التسلسل الهرمي للعناصر وينقل نافذتها بنوع WINDOW.
COLORMAP
يقوم العنصر بنقل XmNcolormap للعنصر الأب بنوع COLORMAP.
FOREGROUND
يقوم العنصر بنقل XmNforeground للعنصر الأب بنوع PIXEL.
NAME
يجد العنصر أول نافذة عائمة في التسلسل الهرمي للعناصر التي تحتوي على خاصية WM_NAME وينقل محتوياتها كنص باللغة المحلية الحالية.
TARGETS
ينقل العنصر، بنوع ATOM، قائمة بالأهداف التي يدعمها. تشمل هذه الأهداف القياسية في هذه القائمة. عندما تكون XmNlabelType هي XmSTRING أو XmPIXMAP_AND_STRING، تشمل هذه أيضًا _MOTIF_COMPOUND_STRING و COMPOUND_TEXT و UTF8_STRING و ترميز اللغة المحلية و STRING و TEXT. عندما تكون XmNlabelType هي XmPIXMAP أو XmPIXMAP_AND_STRING، تشمل هذه أيضًا PIXMAP.
TIMESTAMP
يقوم العنصر بنقل الطابع الزمني المستخدم للحصول على التحديد بنوع INTEGER.
_MOTIF_RENDER_TABLE
يقوم العنصر بنقل XmNrenderTable إذا كان موجودًا، وإلا فإنه ينقل جدول العرض النصي الافتراضي، بنوع STRING.
_MOTIF_ENCODING_REGISTRY
يقوم العنصر بنقل سجل الترميز الخاص به بنوع STRING. القيمة هي قائمة بعناصر مفصولة بـ NULL في شكل أزواج وسم ترميز. يرمز هذا الهدف إلى هدف النقل لسجل ترميز مقاطع Motif. يمكن للعناصر و التطبيقات استخدام هذا السجل لتسجيل تنسيقات ترميز النص لعلامات جدول العرض المحددة. التطبي

RESOURCES

XmNalignment
Specifies the alignment of the label string or pixmap within the gadget. Valid values are:
XmALIGNMENT_BEGINNING
XmALIGNMENT_CENTER
XmALIGNMENT_END
The default value is implementation dependent.
XmNfontList
Specifies the font list associated with the labelString. If this value is NULL at initialization, Label searches its parent hierarchy for an ancestor that holds the XmQTspecifyFontList trait. If such an ancestor is found, Label initializes XmNfontList to the XmLABEL_FONT_LIST value of the ancestor widget. Similarly, button subclasses of Label initialize XmNfontList to the XmBUTTON_FONT_LIST value of the ancestor widget. (Note that all current subclasses of Label are button subclasses.) If no such ancestor is found, the default is implementation dependent. If a font list and a render table are both specified, the render table will take precedence.
XmNlabelInsensitivePixmap
Specifies a pixmap to be displayed when the gadget is insensitive. If this pixmap is not specified, the gadget uses the XmNlabelPixmap pixmap and ditheres it to achieve an insensitive appearance.
XmNlabelPixmap
Specifies a pixmap to be displayed as the label. If this pixmap is specified, it overrides the XmNlabelString and XmNlabelType resources. The default value is XmUNSPECIFIED_PIXMAP.
XmNlabelString
Specifies the text or pixmap label for the gadget. The type of the label is determined by XmNlabelType. If XmNlabelType is XmSTRING, the label is a text string. If XmNlabelType is XmPIXMAP, the label is a pixmap. If XmNlabelType is XmIMAGELIST, the label is a list of pixmaps. The default value is NULL.
XmNlabelType
Specifies the type of the label. Valid values are:
XmSTRING
XmPIXMAP
XmIMAGELIST
The default value is XmSTRING.
XmNலாமல்
Specifies the spacing between the label and the gadget border. The default value is 0.
XmNmarginLeft
Specifies the margin on the left side of the label.
XmNmarginRight
Specifies the margin on the right side of the label.
XmNmarginTop
Specifies the margin on the top of the label.
XmNpixmapAlignment
Specifies the alignment of the pixmap within the gadget when the XmNlabelType is XmPIXMAP. Valid values are XmALIGNMENT_BEGINNING, XmALIGNMENT_CENTER, and XmALIGNMENT_END. The default value is XmALIGNMENT_CENTER.
XmNpixmapInsensitivePixmap
Specifies a pixmap to be displayed when the gadget is insensitive. If this pixmap is not specified, the gadget uses the XmNlabelPixmap pixmap and ditheres it to achieve an insensitive appearance. The default value is XmUNSPECIFIED_PIXMAP.
XmNpixmapPosition
Specifies the position of the pixmap relative to the text string when both are present. Valid values are:
XmSTRING
XmPIXMAP
XmLEFT_TOP
XmLEFT_BOTTOM
XmRIGHT_TOP
XmRIGHT_BOTTOM
XmTOP_LEFT
XmTOP_RIGHT
XmBOTTOM_LEFT
XmBOTTOM_RIGHT
The default value is XmRIGHT.
XmNpixmapTextPadding
The amount of space to be left between the pixmap and the label string.
XmNrecomputeSize
Specifies a Boolean value that indicates whether the gadget shrinks or expands to accommodate its contents (label string or pixmap) as a result of an XtSetValues resource value that would change the size of the gadget. If True, the gadget shrinks or expands to exactly fit the label string or pixmap. If False, the gadget never attempts to change size on its own.
XmNrenderTable
Specifies the render table associated with the labelString. If this value is NULL at initialization, Label searches its parent hierarchy for an ancestor that holds the XmQTspecifyRenderTable trait. If such an ancestor is found, Label initializes XmNrenderTable to the XmLABEL_RENDER_TABLE value of the ancestor widget. Similarly, button subclasses of Label initialize XmNrenderTable to the XmBUTTON_RENDER_TABLE value of the ancestor widget. (Note that all current subclasses of Label are button subclasses.) If no such ancestor is found, the default is implementation dependent. If a font list and a render table are both specified, the render table will take precedence. Refer to XmRenderTable(3) for more information on the creation and structure of a render table.
XmNstringDirection
Is a synthetic resource for setting XmNlayoutDirection. The values for this resource are XmSTRING_DIRECTION_L_TO_R and XmSTRING_DIRECTION_R_TO_L. Refer to the XmNlayoutDirection resource description. The XmNstringDirection resource is obsoleted by XmNlayoutDirection, but is kept here for backward compatibility.
