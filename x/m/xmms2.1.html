XMMS2(1) دليل الأوامر العامة XMMS2(1)

الاسم

xmms2 - واجهة سطر الأوامر الرسمية لـ XMMS2

الملخص

xmms2 [أمر] [وسائط]
xmms2 help [أمر]

الوصف

XMMS2 هو إعادة تصميم لمشغل الموسيقى XMMS (https://en.wikipedia.org/wiki/XMMS). يتميز بنموذج العميل والخادم، مما يسمح بواجهات مستخدم متعددة (حتى متزامنة!)، نصية ورسومية. تدعم جميع تنسيقات الصوت الشائعة باستخدام المكونات الإضافية. علاوة على ذلك، توجد مكتبة وسائط مرنة لتنظيم الموسيقى الخاصة بك.

xmms2 هو عميل واجهة سطر الأوامر الرسمي لـ XMMS2.

الاستدعاء

وضع السطر

إذا تم تمرير أمر كوسيط إلى xmms2، فسيتم تفسير هذا الأمر وسيخرج xmms2 بعد الانتهاء منه.

الوضع التفاعلي

يتميز xmms2 ببيئة قوية شبيهة بالصدفة عبر readline تسمح للمستخدم بإدخال الأوامر عند موجه الأوامر ولديها الميزات الرائعة المعتادة مثل توسيع مسار الملفات وتحرير الأسطر.

الأوامر

تقبل جميع الأوامر الخيار -h/--help الذي يعرض مساعدة الأمر.

يشير pattern إلى تعريف مجموعة. (انظر PATTERN أدناه.)

يشير position إلى نمط لمطابقة مواضع قائمة التشغيل. عند غيابه في أمر، يكون الافتراضي هو نهاية قائمة التشغيل. (انظر POSITION PATTERN أدناه.)

الأوامر العامة

add [ -f [-N] [-P] [-A key=value]... ] [-p playlist] [-n | -a position] [-o prop[,...]] [-j] arguments...
add [-p playlist] [-n | -a position] [-o prop[,...]] [-j] pattern...

إضافة الوسائط إلى قائمة تشغيل. سيحاول تخمين ما إذا كانت arguments تشكل pattern أو تمثل مسارات ملفات. يمكن تجاوز هذا السلوك عن طريق فرض النوع باستخدام -f و -t. إذا كانت مسارات الملفات تحتوي على أحرف * أو ؟، فسوف يحاول توسيعها. في حالة فشل العثور على تطابق، سيتم محاولة إضافة أحرف * و ؟ كجزء من عنوان URL.
-f, --file
فرض معاملة arguments كمسارات ملفات.
-P, --pls
فرض معاملة arguments كملفات قوائم تشغيل. هذا الخيار يعني -f.
-t, --pattern
فرض معاملة arguments كنقش.
-N, --non-recursive
لا تقم بإضافة الدلائل بشكل متكرر.
-p, --playlist playlist
أضف الوسائط إلى playlist بدلاً من قائمة التشغيل النشطة.
-n, --next
أضف الوسائط بعد المقطع الحالي.
-a, --at position
أضف الوسائط في الموضع المحدد.
-A, --attribute key=value
أضف الوسائط مع سمة key=value محددة. قد تحدث عدة مرات. صالحة فقط عند إضافة ملفات جديدة إلى مكتبة الوسائط.
-o, --order prop[,...]
أضف الوسائط مرتبة حسب قائمة الخصائص المفصولة بفواصل. إذا كان للخاصية بادئة -، يتم ترتيب الوسائط بترتيب عكسي حسب تلك الخاصية.
-j, --jump
الانتقال إلى الوسائط المضافة حديثًا والبدء في تشغيلها.
exit
الخروج من الواجهة الشبيهة بالصدفة.
help [-a] command
عرض المساعدة حول command. هذا يعادل command -h. إذا كان command اسمًا مستعارًا، فاعرض تعريف الاسم المستعار. إذا لم يتم توفير أمر، فاعرض قائمة بجميع الأوامر المتاحة.
-a, --alias
عرض الأسماء المستعارة المتاحة إذا لم يتم توفير command. بخلاف ذلك، ليس له تأثير.
info [pattern | positions...]
عرض خصائص جميع الوسائط التي تطابق pattern أو في المواضع المعطاة. بدون وسيط، يعرض خصائص المقطع الحالي.
jump [-b] pattern|position
الانتقال إلى أول وسائط تطابق pattern أو إلى الموضع المحدد.
-b, --backward
الانتقال للخلف إلى أول وسائط تطابق النمط.
list [-p name] [pattern | positions...]
عرض محتويات قائمة تشغيل (النشطة افتراضيًا). إذا تم توفير pattern، فسيتم تصفية المحتويات بشكل إضافي ولن يتم عرض سوى الوسائط المطابقة.
-p, --playlist
عرض playlist، بدلاً من قائمة التشغيل النشطة.
move [-p playlist] [-n | -a position] pattern | positions...
نقل الإدخالات داخل قائمة تشغيل (النشطة افتراضيًا).
-p, --playlist playlist
قائمة التشغيل التي سيتم العمل عليها.
-n, --next
نقل المقاطع المطابقة بعد المقطع الحالي.
-a, --at position
نقل المقاطع المطابقة بإزاحة أو إلى position.
next [offset]
الانتقال إلى المقطع التالي. إذا تم توفير offset، فسيعمل مثل jump +offset.
pause
إيقاف التشغيل مؤقتًا.
play
بدء التشغيل.
prev [offset]
الانتقال إلى المقطع السابق. إذا تم توفير offset، فسيعمل مثل jump -offset.
remove [-p playlist] pattern | positions...
إزالة الوسائط المطابقة من قائمة تشغيل (النشطة افتراضيًا).
-p, --playlist playlist
إزالة من playlist، بدلاً من قائمة التشغيل النشطة.
current [-r seconds] [-f format]
عرض حالة التشغيل، إما بشكل مستمر أو مرة واحدة.
-r, --refresh seconds
تعيين التأخير، بالثواني، بين كل تحديث لبيانات تشغيل المقطع الحالي. إذا كان 0، فسيتم طباعة البيانات الوصفية مرة واحدة فقط (افتراضيًا) وسيخرج الأمر فورًا. عند العمل في وضع التحديث، يتم توفير تحكم أساسي على قائمة التشغيل النشطة.
-f, --format format
تعيين سلسلة التنسيق المستخدمة لعرض معلومات الحالة، بدلاً من تلك الموجودة في ملف التكوين (انظر FORMAT STRING أدناه).
search [-o prop1[,prop2...]] [-l prop1[,prop2...] ] pattern

إعادة تسمية قائمة التشغيل المحددة.

-p, --playlist
إعادة تسمية قائمة التشغيل المحددة.

نسخ مجموعة موجودة إلى المجموعة الجديدة.
-e, --empty
تهيئة مجموعة فارغة.
collection list

أوامر الخادم

server browse URL
تصفح عنوان URL عبر المكونات الإضافية xform المتاحة في الخادم.
server config [name [value]]
الحصول على قيم التكوين أو تعيينها. إذا لم يتم توفير اسم أو قيمة، فسيتم سرد جميع قيم التكوين. إذا تم توفير اسم فقط، فسيتم عرض محتوى قيمة التكوين المقابلة. إذا تم توفير كل من الاسم والقيمة، فسيتم تعيين المحتوى الجديد لقيمة التكوين.

اسم قيمة التكوين يخضع لتوسيع حرف البدل في shell بحيث يمكن الاستعلام عن قيم متعددة (ولكن ليس تعيينها) مرة واحدة.

server import [-N] path
استيراد ملفات جديدة إلى مكتبة الوسائط. افتراضيًا، يتم استيراد الدلائل بشكل متكرر.
-N, --non-recursive
عدم استيراد الدلائل بشكل متكرر.
server plugins
سرد المكونات الإضافية المحملة في الخادم.
server property [-i | -s | -D] [-S] mid [name [value]]
الحصول على خصائص لوسيط معين أو تعيينها. إذا لم يتم توفير اسم أو قيمة، فسيتم سرد جميع الخصائص. إذا تم توفير اسم فقط، فسيتم عرض قيمة الخاصية. إذا تم توفير كل من الاسم والقيمة، فسيتم تعيين القيمة الجديدة للخاصية.

افتراضيًا، تستخدم عمليات التعيين المصدر "client/xmms2-cli"، بينما تستخدم عمليات القائمة والعرض تفضيل المصدر. استخدم خيار --source لتجاوز هذا السلوك.

افتراضيًا، سيتم استخدام القيمة لتحديد ما إذا كان يجب حفظها كسلسلة أو عدد صحيح. استخدم العلامة --int أو --string لتجاوز هذا السلوك.

-i, --int
فرض معاملة القيمة كعدد صحيح.
-s, --string
فرض معاملة القيمة كسلسلة.
-D, --delete
حذف الخاصية المحددة.
-S, --source
مصدر الخاصية.
server rehash [pattern]
إعادة تجزئة الوسائط التي تطابق النمط، أو مكتبة الوسائط بأكملها إذا لم يتم توفير نمط
server remove [pattern]
إزالة الوسائط المطابقة من مكتبة الوسائط.
server shutdown
إيقاف تشغيل الخادم.
server stats
عرض إحصائيات حول الخادم: وقت التشغيل، الإصدار، حجم مكتبة الوسائط، إلخ.
server sync
حفظ المجموعات فورًا على القرص. (بخلاف ذلك يتم إجراؤها فقط عند الإيقاف أو بعد 10 ثوانٍ من آخر تغيير للمجموعات.)

server

r~11">server volume [-c name] [value]
الحصول على مستوى الصوت أو تعيينه (في نطاق 0-100). إذا تم توفير قيمة، فقم بتعيين مستوى الصوت إلى القيمة. بخلاف ذلك، اعرض مستوى الصوت الحالي. افتراضيًا، ينطبق الأمر على جميع قنوات الصوت. استخدم العلامة --channel لتجاوز هذا السلوك. التغييرات النسبية في مستوى الصوت ممكنة عن طريق وضع بادئة للقيمة بـ + أو -.
-c, --channel
الحصول على مستوى الصوت أو تعيينه للقناة المسماة فقط.

PATTERN

تُستخدم الأنماط للبحث عن الأغاني في مكتبة الوسائط، وقد تتطلب بعض هذه الأنماط الهروب (باستخدام '\') اعتمادًا على الغلاف المستخدم. يمكن العثور على الخصائص في مخرجات xmms2 info.

<property>:<string>
مطابقة الأغاني التي تتطابق خاصيتها مع السلسلة. يشير ؟ في السلسلة إلى حرف بدل واحد، و * يشير إلى أحرف بدل متعددة.
<property>~<string>
مطابقة الأغاني التي تتطابق خاصيتها بشكل تقريبي مع السلسلة. يعادل المطابقة عن طريق <property>:*<string>*.
<property><operation><number>
يمكن أن تكون العملية <، <=، > أو >=، سيطابق النمط الأغاني التي خاصيتها قيمة رقمية أصغر من، أصغر من أو تساوي، أكبر من، أكبر من أو تساوي مقارنة بالرقم.
+<property>
مطابقة الأغاني التي لديها الخاصية.
in:<namespace>/<collection>
مطابقة الأغاني في المجموعة المحددة. قد يكون فضاء الأسماء Playlists أو Collections.
NOT <pattern>
مطابقة مكمل النمط.

<pattern> <pattern>
<pattern> AND <pattern>

مطابقة الأغاني التي تطابقها كلا النمطين.
<pattern> OR <pattern>
مطابقة الأغاني التي تطابقها واحدة على الأقل من النمطين.
( <pattern> )
مطابقة الأغاني التي يطابقها النمط، وتستخدم لتجميع مطابقات AND و OR.
<string>
مطابقة الأغاني التي يتطابق فيها الفنان أو العنوان أو الألبوم مع السلسلة.
~<string>
مطابقة الأغاني التي يتطابق فيها الفنان أو العنوان أو الألبوم بشكل تقريبي مع السلسلة.
#<number>
مطابقة معرف مكتبة الوسائط المحدد.

POSITION PATTERN

تُستخدم أنماط الموضع مع الأوامر التي تعمل على محتوى قائمة التشغيل.

M_N
تحديد إدخالات قائمة التشغيل التي تتراوح من M موضعًا قبل الأغنية الحالية، إلى N موضعًا بعدها. يمكن حذف كل من M و N وسيكون افتراضهما 0.
-N
تحديد الأغنية N موضعًا قبل الأغنية الحالية.
+N
تحديد الأغنية N موضعًا بعد الأغنية الحالية.
pos0,pos1,...,posN
تحديد موضع واحد أو أكثر في قائمة التشغيل.

FORMAT STRING

يمكن تخصيص الأوامر التي تنتج بيانات وصفية منسقة بمساعدة سلاسل تنسيق معرفة من قبل المستخدم مثل ما يلي:

´${artist} - ${title}´

عند تمرير البيانات الوصفية، سيتم إدراج اسم الفنان والعنوان في السلسلة الناتجة. بالإضافة إلى البيانات الوصفية المقدمة من مكتبة الوسائط، تتوفر قائمة الخصائص التالية أيضًا:

position
موضع قائمة التشغيل الحالي.
playback_status
حالة التشغيل كسلسلة (متوقف، قيد التشغيل، متوقف مؤقتًا، غير معروف).
playtime
وقت تشغيل الأغنية الحالية.
duration
مدة الأغنية الحالية، بتنسيق دقائق:ثواني مع صفر مسبوق.
minutes
جزء الدقائق، مع صفر مسبوق، من مدة الأغنية الحالية.
seconds
جزء الثواني، مع صفر مسبوق، من مدة الأغنية الحالية.

ALIASES

تتم قراءة قائمة بأسماء الأوامر المستعارة من ملف التكوين في القسم [alias] وقت التشغيل. بناء جملة الأسماء المستعارة لـ xmms2 يشبه إلى حد ما bash والأغلفة الأخرى. يتم تعريف الاسم المستعار بواسطة قائمة من الأوامر والوسائط مفصولة بفاصلة منقوطة. يتم دعم توسيع المعلمات (انظر Expansion أدناه).

يتضمن التكوين الافتراضي الأسماء المستعارة التالية:
addpls
add -f -P $@
clear
playlist clear
status
current -f $1
ls
list
mute
server volume 0
quit
server shutdown
repeat
seek 0
scap
stop ; playlist clear ; add $@ ; play

Expansion

Positional Parameters

يمكن للاسم المستعار استخدام المعلمات الموضعية، على سبيل المثال:

foo = add -f $1 $3

foo ctkoz.ogg and slre.ogg

سيؤدي ذلك إلى:

add -f ctkoz.ogg slre.ogg

Special Parameters

$@
يقوم هذا بتوسيع جميع المعلمات التي تم تمريرها إلى الاسم المستعار.

CONFIGURATION

يتم تفسير جميع أحرف التحكم كما هو متوقع، بما في ذلك تسلسلات هروب ANSI.

AUTO_UNIQUE_COMPLETE

قيمة منطقية، تكمل اختصارًا لأمر ولوسائطه. على سبيل المثال: `serv vol 42' سيتم إكماله إلى `server volume 42'. (ملاحظة: يجب أن تكون الاختصارات غير غامضة)

CLASSIC_LIST

قيمة منطقية، تنسيق مخرجات list مشابه لواجهة سطر الأوامر الكلاسيكية.

CLASSIC_LIST_FORMAT

سلسلة لتنسيق مخرجات list الكلاسيكية.

GUESS_PLS

قيمة منطقية، حاول تخمين ما إذا كان عنوان URL قائمة تشغيل وأضفه وفقًا لذلك. (غير موثوق به)

HISTORY_FILE

الملف لحفظ سجل الأوامر.

PLAYLIST_MARKER

السلسلة المستخدمة لوضع علامة على الإدخال النشط الحالي في قائمة التشغيل.

PROMPT

السلسلة المستخدمة كطلب في وضع تفاعلي.

SERVER_AUTOSTART

قيمة منطقية، إذا كانت صحيحة، سيحاول xmms2 بدء تشغيل xmms2d(1) إذا لم يكن قيد التشغيل بالفعل.

SHELL_START_MESSAGE

قيمة منطقية، إذا كانت صحيحة، سيعرض xmms2 رسالة ترحيب ومساعدة أساسية عند بدء التشغيل في وضع تفاعلي.

STATUS_FORMAT

سلسلة لتنسيق مخرجات status.

FILES

$XDG_CACHE_HOME/xmms2/nyxmms2_history

ملف سجل الأوامر الافتراضي إذا كان HISTORY_FILE غير مضبوط.

$XDG_CONFIG_HOME/xmms2/clients/nycli.conf

ملف التكوين لـ xmms2.

ENVIRONMENT

XMMS_PATH

تجاوز مسار الاتصال الافتراضي.
للاتصال عبر IPv4
tcp://IPv4-Address:port
للاتصال عبر IPv6
tcp://[IPv6-Address]:port
للاتصال عبر مقبس unix
unix:///path/to/socket
