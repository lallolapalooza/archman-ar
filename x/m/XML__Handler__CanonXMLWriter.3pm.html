XML__Handler__CanonXMLWriter(3pm)

الحزمة: libxml-perl

التراخيص: GPL, PerlArtistic

XML::Handler::CanonXMLWriter(3) وثائق بيرل المساهمة XML::Handler::CanonXMLWriter(3)

الاسم

XML::Handler::CanonXMLWriter - إخراج XML بصيغة XML المعيارية

الملخص

use XML::Handler::CanonXMLWriter;
$writer = XML::Handler::CanonXMLWriter OPTIONS;
$parser->parse(Handler => $writer);

الوصف

"XML::Handler::CanonXMLWriter" هو معالج PerlSAX سيعيد سلسلة نصية أو يكتب تيارًا من XML المعياري لمثيل XML ومحتواه.

"XML::Handler::CanonXMLWriter" كائنات تحتوي على الخيارات المستخدمة لكتابة كائنات XML. يمكن توفير الخيارات عند إنشاء الكائن،

$writer = new XML::Handler::CanonXMLWriter PrintComments => 1;

أو تعديلها في أي وقت قبل استدعاء الدالة `parse()' الخاصة بالمحلل:

$writer->{PrintComments} = 0;

الخيارات

IOHandle
يحتوي IOHandle على مقبض لكتابة XML المعياري إليه. إذا لم يتم توفير IOHandle، فسيتم إرجاع سلسلة XML المعيارية من `parse()'.
PrintComments
بشكل افتراضي، لا يتم كتابة التعليقات إلى الإخراج. سيؤدي تعيين التعليق إلى قيمة صحيحة إلى تضمين التعليقات في الإخراج.
