XmTabStack(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

NAME

XmTabStack - A collection of tabbed dialogs; specifies the tab stack widget

SYNOPSIS

#include <Xm/TabStack.h>

DESCRIPTION

The XmTabStack widget is a container that manages a set of child widgets that are displayed as a group of tabbed dialogs. Only one child widget is visible at a time, and the user can switch between them by clicking on the corresponding tab. The XmTabStack widget is a subclass of XmBulletinBoard and inherits all of its resources.

Default access is indicated as follows:

G

C

S

R
Read access to the resource

The `Type` column indicates the data type of the resource.

Calback Information

A pointer to the following structure is passed to each callback:

typedef struct _XmTabStackCallbackStruct {
	int	reason;
	XEvent	*event;
	Widget	selected_child;
} XmTabStackCallbackStruct;
reason
Indicates why the callback was invoked. Valid callbacks reasons include:
XmCR_TAB_SELECTED
Indicates that a child has been made the selected widget.
event
Points to the XEvent that triggered the callback.
selected_child
Contains the widget ID of the selected child.

Translations

XmTabStack includes the translations from the XmManager.

Additional Behavior

The XmTabStack has no additional behavior.

Virtual Bindings

The bindings for virtual keys are vendor specific. For information about bindings for virtual buttons and keys, see VirtualBindings(3X).
