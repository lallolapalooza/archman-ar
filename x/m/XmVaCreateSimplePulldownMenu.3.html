XmVaCreateSimplePulldownMenu(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

NAME

XmVaCreateSimplePulldownMenu - A RowColumn widget that is a pulldown menu, creating child widgets based on resource lists.

SYNOPSIS

#include <Xm/RowColumn.h>
Widget XmVaCreateSimplePulldownMenu(
    Widget parent,
    String name,
    ArgList args,
    Cardinal arg_count )
Widget XmVaCreateSimplePulldownMenuWidget(
    Widget parent,
    String name,
    ArgList args,
    Cardinal arg_count )

DESCRIPTION

XmVaCreateSimplePulldownMenu creates a RowColumn widget that is a pulldown menu. The RowColumn widget's XmNrowColumnType resource is set to XmMENU_PULLDOWN. The widget's children are created based on the resource lists provided in the variable-length argument list. These children are typically menu items.

The variable-length argument list is a list of XmVaCreateRowColumn(3) argument lists. Each list is created using XtVaCreateArgsList and contains the resources for one child menu item. The last argument in the variable-length argument list must be NULL.

XmVaCreateSimplePulldownMenuWidget is equivalent to XmVaCreateSimplePulldownMenu.

XtVaNestedList
This is followed by one additional argument of type XtVarArgsList. This argument is a nested list of varargs returned by XtVaCreateArgsList.

For more information on variable-length argument lists, see the X Toolkit Intrinsics documentation.

A number of resources exist specifically for use with this and other simple menu creation routines. For a complete definition of RowColumn and its associated resources, see XmRowColumn(3).

RETURN

Returns the RowColumn widget ID.

RELATED

XmCreatePulldownMenu(3), XmCreateRowColumn(3), XmCreateSimplePulldownMenu, and XmRowColumn(3).

الاسم

XmVaCreateSimplePulldownMenu - ويدجت RowColumn وهو قائمة منسدلة، ينشئ ويدجتات فرعية بناءً على قوائم الموارد.

الملخص

#include <Xm/RowColumn.h>
Widget XmVaCreateSimplePulldownMenu(
    Widget parent,
    String name,
    ArgList args,
    Cardinal arg_count )
Widget XmVaCreateSimplePulldownMenuWidget(
    Widget parent,
    String name,
    ArgList args,
    Cardinal arg_count )

الوصف

XmVaCreateSimplePulldownMenu ينشئ ويدجت RowColumn وهو قائمة منسدلة. يتم تعيين خاصية XmNrowColumnType الخاصة بويدجت RowColumn إلى XmMENU_PULLDOWN. يتم إنشاء الويدجتات الفرعية بناءً على قوائم الموارد المقدمة في قائمة الوسائط ذات الطول المتغير. عادةً ما تكون هذه الويدجتات الفرعية عناصر قائمة.

قائمة الوسائط ذات الطول المتغير هي قائمة بقوائم وسائط XmVaCreateRowColumn(3). يتم إنشاء كل قائمة باستخدام XtVaCreateArgsList وتحتوي على موارد لعنصر قائمة فرعي واحد. يجب أن يكون الوسيط الأخير في قائمة الوسائط ذات الطول المتغير هو NULL.

XmVaCreateSimplePulldownMenuWidget يعادل XmVaCreateSimplePulldownMenu.

XtVaNestedList
يتبع ذلك وسيط إضافي واحد من نوع XtVarArgsList. هذا الوسيط هو قائمة متداخلة من varargs يتم إرجاعها بواسطة XtVaCreateArgsList.

لمزيد من المعلومات حول قوائم الوسائط ذات الطول المتغير، راجع توثيق X Toolkit Intrinsics.

توجد عدد من الموارد خصيصًا للاستخدام مع هذه الروتينات البسيطة لإنشاء القوائم وغيرها. للحصول على تعريف كامل لـ RowColumn والموارد المرتبطة به، راجع XmRowColumn(3).

الإرجاع

يعيد معرف ويدجت RowColumn.

ذات صلة

XmCreatePulldownMenu(3), XmCreateRowColumn(3), XmCreateSimplePulldownMenu, و XmRowColumn(3).
