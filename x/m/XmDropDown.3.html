NAME

XmDropDown - a dropdown widget

INTEGRATION

XmDropDown integrates with XmManager.

DESCRIPTION

The DropDown widget is a convenient way to combine a label, text widget, and a popup list of choices. The widget is typically used in combination with other widgets to create common dialog box items like menus or editable lists.

When the user clicks on the DropDown widget, a popup shell appears, containing a scrolled list widget. The items displayed in the list are the choices available to the user. When the user selects an item from the list, the popup shell disappears, and the text widget in the DropDown is updated with the selected item.

The DropDown widget manages its child widgets (label, text, and arrow) internally. You can also create and manage your own label, text, and arrow widgets and add them to the DropDown widget.

معلومات الاستدعاء

لا تحتوي أي من إجراءات الاستدعاء الخاصة بـ DropDown حاليًا على أي بيانات استدعاء معرّفة لها. الأداة التي يتم تمريرها إلى كل من هذه الدوال هي أداة DropDown.

void (Callback)(Widget cbw, XtPointer client_data, XtPointer unused)

cbw هذا هو معرف الأداة لـ DropDown.

client_data بيانات العميل التي مررها مبرمج التطبيق إلى هذه الأداة.

unused هذه القيمة غير محددة.

إدارة الأشكال الهندسية

تقوم أداة DropDown بترتيب عناصرها الفرعية (التسمية، النص، والسهم) في صف. يتم تحديد مقدار المساحة المخصصة لكل منها عندما لا يُسمح لـ DropDown بأن يكون بالحجم الدقيق الذي يريده، وذلك باستخدام القواعد التالية:

1. يُعطى السهم دائمًا حجمه المطلوب.

2. إذا كان مربع التحرير والسرد أكبر مما يريده، تُعطى كل المساحة الإضافية لأداة النص.

3. إذا كان مربع التحرير والسرد أصغر مما يريده، يتم تقليص حجم أداتي النص والتسمية إلى ما دون الحجم المطلوب بنفس النسبة تمامًا.

على سبيل المثال:

إذا كانت المساحة المتاحة للتسمية والنص هي 100 بكسل، وكانت التسمية تريد أن تكون بعرض 50 بكسل، وكان مربع التحرير والسرد يفضل أن يكون عرضه 100 بكسل، فستحصل التسمية على 34 بكسل، والنص على 66 بكسل.

يتم تحديد حجم أداة shell المنبثقة بحيث يساوي عرض أداة قائمة التمرير عرض أداة النص مطروحًا منه قيمة المورد "popupOffset". ومع ذلك، إذا كانت shell المنبثقة موجودة في مربع تحرير وسرد مخصص، فسيُسمح لها بأن تكون بأي حجم يفضله العنصر الفرعي لـ shell المنبثقة.
