XML__LibXML__RelaxNG(3pm)

الحزمة: perl-xml-libxml

التراخيص: GPL

XML::LibXML::RelaxNG(3) وثائق Perl المساهمة من المستخدم XML::LibXML::RelaxNG(3)

الاسم

XML::LibXML::RelaxNG - التحقق من مخططات RelaxNG

الملخص

use XML::LibXML;
$doc = XML::LibXML->new->parse_file($url);
$rngschema = XML::LibXML::RelaxNG->new( location => $filename_or_url, no_network => 1 );
$rngschema = XML::LibXML::RelaxNG->new( string => $xmlschemastring, no_network => 1 );
$rngschema = XML::LibXML::RelaxNG->new( DOM => $doc, no_network => 1 );
eval { $rngschema->validate( $doc ); };

الوصف

فئة XML::LibXML::RelaxNG هي واجهة أمامية صغيرة لتطبيق RelaxNG في libxml2. حاليًا، تدعم فقط تحليل المخططات والتحقق من صحة المستندات.

الطرق

new
$rngschema = XML::LibXML::RelaxNG->new( location => $filename_or_url, no_network => 1 );
$rngschema = XML::LibXML::RelaxNG->new( string => $xmlschemastring, no_network => 1 );
$rngschema = XML::LibXML::RelaxNG->new( DOM => $doc, no_network => 1 );

يحتاج مُنشئ XML::LibXML::RelaxNG إلى استدعائه بقائمة من المعلمات. يتطلب وجود معلمة location أو string أو DOM على الأقل لتحديد مصدر المخطط. المعلمة الاختيارية no_network التي تم تعيينها إلى 1 تجعل المحلل لا يصل إلى الشبكة، والمعلمة الاختيارية recover التي تم تعيينها إلى 1 تجعل المحلل لا يستدعي die() عند حدوث أخطاء.

من المهم أن يكون لكل مخطط مصدر واحد فقط.

تسمح معلمة location بتحليل مخطط من نظام الملفات أو عنوان URL (غير HTTPS).

ستقوم معلمة string بتحليل المخطط من سلسلة XML المعطاة.

تسمح معلمة DOM بتحليل المخطط من مستند XML::LibXML::Document تم تحليله مسبقًا.

لاحظ أن المُنشئ سيستدعي die() إذا لم يفي المخطط بقيود مواصفات RelaxNG.

validate
eval { $rngschema->validate( $doc ); };

تسمح هذه الوظيفة بالتحقق من صحة مستند (تم تحليله) مقابل مخطط RelaxNG المعطى. يجب أن يكون وسيط هذه الوظيفة كائن XML::LibXML::Document. إذا نجحت هذه الوظيفة، فستعيد 0، وإلا فستستدعي die() وتقوم بالإبلاغ عن الأخطاء التي تم العثور عليها. نظرًا لهذا، يجب دائمًا تقييم validate().
