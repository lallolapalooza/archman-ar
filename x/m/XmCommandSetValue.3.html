XmCommandSetValue(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmCommandSetValue(استدعاء مكتبة) XmCommandSetValue(استدعاء مكتبة)

الاسم

XmCommandSetValue — دالة Command تستبدل سلسلة نصية معروضة

ملخص

#include <Xm/Command.h>
void XmCommandSetValue(
Widget widget,
XmString command);

الوصف

XmCommandSetValue تستبدل السلسلة النصية المعروضة في منطقة Command في ودجة Command مع XmString المقدمة.

widget
يحدد معرف ودجة Command
command
يحدد XmString المقدمة

لتعريف كامل لـ Command والموارد المرتبطة بها، انظر XmCommand(3).

XmCommand(3).
