الاسم

XmDrawnButton - زر يتم إنشاؤه بواسطة البرنامج، يعرض صورة أو نصًا أو كليهما. يوفر XmDrawnButton الوظائف الأساسية لإنشاء زر مع ميزات إضافية. يمكن رسم المحتويات بواسطة التطبيق.

الملخص

#include <Xm/DrawnB.h>

لإنشاء زر مرسوم:

    Widget              new_button;
    Arg                 al[6];
    int                 ac;

    ac = 0;
    XtSetArg(al[ac], XmNwidth, 100); ac++;
    XtSetArg(al[ac], XmNheight, 50); ac++;
    XtSetArg(al[ac], XmNuserData, NULL); ac++;
    XtSetArg(al[ac], XmNdrawProc, MyDrawProc); ac++;
    XtSetArg(al[ac], XmNhighlightProc, MyHighlightProc); ac++;
    XtSetArg(al[ac], XmNarmPixmap, NULL); ac++;

    new_button = XmCreateDrawnButton(parent, "drawn_button", al, ac);

الوصف

تعتبر XmDrawnButton أداة عنصر واجهة مستخدم لإنشاء زر يمكن للتطبيق رسم محتوياته. توفر XmDrawnButton آلية لإدارة الموارد الأساسية لـ XmPrimitive و XmManager، بالإضافة إلى توفير إمكانيات لرسم محتوى الزر. تشمل الموارد الإضافية المحددة بواسطة XmDrawnButton ما يلي:

XmNuserData

يحتوي على مؤشر إلى البيانات الخاصة بالمستخدم. يمكن أن تكون هذه البيانات أي شيء يعرّفه المبرمج. يمكن للمبرمج تعيين قيمة لهذه الخاصية عند إنشاء الأداة أو لاحقًا باستخدام XtSetValues. يمكن استرداد هذه القيمة باستخدام XtGetValues.

XmNdrawProc

يشير إلى إجراء الرسم الذي سيتم استدعاؤه لرسم محتويات الزر. إذا تم تعيينه إلى NULL، فلن يتم استدعاء أي إجراء رسم.

XmNhighlightProc

يشير إلى إجراء التمييز الذي سيتم استدعاؤه لتمييز الزر (على سبيل المثال، عند تلقي أحداث التركيز). إذا تم تعيينه إلى NULL، فلن يتم استدعاء أي إجراء تمييز.

XmNarmPixmap

يشير إلى صورة نقطية (Pixmap) سيتم عرضها عند تنشيط الزر. إذا تم تعيينه إلى NULL، فلن يتم عرض أي صورة نقطية.

XmNactivateCallback

تتم استدعاء هذه القائمة المرجعية عندما يتم تنشيط الزر (على سبيل المثال، عند النقر فوقه بالزر الأيسر للفأرة). يتم تمرير مؤشر إلى هيكل XmDrawnButtonCallbackStruct إلى كل إجراء مرجعي.

XmNdisarmCallback

تتم استدعاء هذه القائمة المرجعية عندما يتم تعطيل الزر (على سبيل المثال، عند تحرير الزر الأيسر للفأرة بعد تنشيطه). يتم تمرير مؤشر إلى هيكل XmDrawnButtonCallbackStruct إلى كل إجراء مرجعي.

XmNresizeCallback

تتم استدعاء هذه القائمة المرجعية عندما يتغير حجم الزر. يتم تمرير مؤشر إلى هيكل XmDrawnButtonCallbackStruct إلى كل إجراء مرجعي.

XmNhelpCallback

تتم استدعاء هذه القائمة المرجعية عندما يتم طلب المساعدة للزر. يتم تمرير مؤشر إلى هيكل XmDrawnButtonCallbackStruct إلى كل إجراء مرجعي.

XmNarmCallback

تتم استدعاء هذه القائمة المرجعية عند قيام الزر بـ "التجهيز" (على سبيل المثال، عند الضغط على زر الفأرة عليه). يتم تمرير مؤشر إلى هيكل XmDrawnButtonCallbackStruct إلى كل إجراء مرجعي.

XmNinputCallback

تتم استدعاء هذه القائمة المرجعية عند حدوث إدخال غير معالج بواسطة إجراءات XmDrawnButton الافتراضية. يتم تمرير مؤشر إلى هيكل XmDrawnButtonCallbackStruct إلى كل إجراء مرجعي.

XmNfocusCallback

تتم استدعاء هذه القائمة المرجعية عندما يحصل الزر على التركيز. يتم تمرير مؤشر إلى هيكل XmDrawnButtonCallbackStruct إلى كل إجراء مرجعي.

XmNmenubarBeginningCallback

تتم استدعاء هذه القائمة المرجعية عند بداية شريط القوائم.

XmNmenubarEndCallback

تتم استدعاء هذه القائمة المرجعية في نهاية شريط القوائم.

XmNmenuDeactivatedCallback

تتم استدعاء هذه القائمة المرجعية عند إلغاء تنشيط القائمة.

XmNmultiClick

يتحكم في كيفية معالجة النقرات المتعددة. إذا تم تعيينه إلى XmMULTICLICK_KEEP، فسيتم استدعاء إجراء XmNactivateCallback لكل نقرة، وسيحتوي حقل click_count في هيكل XmDrawnButtonCallbackStruct على عدد النقرات في التسلسل الأخير.

NAME

XmDrawnButton — A drawn button widget

SYNOPSIS

#include <Xm/DrawnB.h>

DESCRIPTION

The XmDrawnButton widget is a button that allows the user to draw their own label within the widget. It is derived from XmPrimitive and inherits its resources. It also includes resources from Core, Composite, and XmManager.

The XmDrawnButton widget has the following specific resources:

XmNactivateCallback
Specifies the list of functions to be called when the button is activated. The corresponding callback reason is XmCR_ACTIVATE.
XmNarmCallback
Specifies the list of functions to be called when the button is armed. The corresponding callback reason is XmCR_ARM.
XmNdisarmCallback
Specifies the list of functions to be called when the button is disarmed. The corresponding callback reason is XmCR_DISARM.
XmNenableWidget
Specifies whether the button widget should be enabled or disabled. If this resource is False, the button is disabled and cannot be activated. This resource is equivalent to XmNpushButtonEnabled for XmPushButton widgets.
XmNhelpCallback
Specifies the list of functions to be called when the button is activated with the Help key. The corresponding callback reason is XmCR_HELP.
XmNmultiClick
Specifies the multi-click behavior for the button. This resource can be set to XmMULTICLICK_DISCARD or XmMULTICLICK_KEEP. The default value is XmMULTICLICK_DISCARD.
XmNrecomputeSize
Specifies whether the widget should automatically recompute its size when its label string or label pixmap changes. The default is True.
XmNshadowType
Specifies the shadow type for the button. This resource can be set to XmSHADOW_IN, XmSHADOW_OUT, XmSHADOW_ETCHED_IN, XmSHADOW_ETCHED_OUT, or XmSHADOW_NONE.

The XmDrawnButton widget also supports the following resources from XmPrimitive:

Action Routines

The XmDrawnButton action routines are

Activate():
If XmNpushButtonEnabled is True, redraws the shadow in the unselected state; otherwise, redraws the shadow according to XmNshadowType. If the pointer is within the DrawnButton, calls the XmNactivateCallback callbacks.
Arm():
If XmNpushButtonEnabled is True, redraws the shadow in the selected state; otherwise, redraws the shadow according to XmNshadowType. Calls the callbacks for XmNarmCallback.
ArmAndActivate():
If XmNpushButtonEnabled is True, redraws the shadow in the selected state; otherwise, redraws the shadow according to XmNshadowType. Calls the callbacks for XmNarmCallback.
If XmNpushButtonEnabled is True, the shadow is redrawn in the unselected state; otherwise, the shadow is redrawn according to XmNshadowType. The callbacks for XmNactivateCallback and XmNdisarmCallback are called. These actions happen either immediately or at a later time.
ButtonTakeFocus():
Causes the PushButton to take keyboard focus when Ctrl<Btn1Down> is pressed, without activating the widget.
Disarm():
Marks the DrawnButton as unselected and calls the callbacks for XmNdisarmCallback.
Help():
Calls the callbacks for XmNhelpCallback if any exist. If there are no help callbacks for this widget, this action calls the help callbacks for the nearest ancestor that has them.
MultiActivate():
If XmNmultiClick is XmMULTICLICK_DISCARD, this action does nothing.
If XmNmultiClick is XmMULTICLICK_KEEP, this action increments click_count in the callback structure. If XmNpushButtonEnabled is True, this action redraws the shadow in the unselected state; otherwise, it redraws the shadow according to XmNshadowType. If the pointer is within the DrawnButton, this action calls the XmNactivateCallback callbacks and calls the callbacks for XmNdisarmCallback.
MultiArm():
If XmNmultiClick is XmMULTICLICK_DISCARD, this action does nothing.
If XmNmultiClick is XmMULTICLICK_KEEP and if XmNpushButtonEnabled is True, this action redraws the shadow in the selected state; otherwise, it redraws the shadow according to XmNshadowType and calls the callbacks for XmNarmCallback.

Additional Behavior

This widget has the following additional behavior:

<EnterWindow>:
Draws the shadow in its selected state if XmNpushButtonEnabled is True and if the cursor leaves and re-enters the window while BSelect is pressed.
<LeaveWindow>:
Draws the shadow in its unselected state if XmNpushButtonEnabled is True and if the cursor leaves the window while BSelect is pressed.

Virtual Bindings

The bindings for virtual keys are vendor specific. For information about bindings for virtual buttons and keys, see VirtualBindings(3).
