XML__SAX__DocumentLocator(3pm)

الحزمة: perl-xml-sax

التراخيص: Artistic-1.0-Perl, GPL-1.0-or-later

XML::SAX::DocumentLocator(3) وثائق بيرل المساهمة من قبل المستخدم XML::SAX::DocumentLocator(3)

الاسم

XML::SAX::DocumentLocator - فئة مساعدة لمحددات المستندات

الملخص

my $locator = XML::SAX::DocumentLocator->new(
    sub { $object->get_public_id },
    sub { $object->get_system_id },
    sub { $reader->current_line },
    sub { $reader->current_column },
    sub { $reader->get_encoding },
    sub { $reader->get_xml_version },
);

الوصف

تمنحك هذه الوحدة مرجع علامة تبويب (tied hash reference) يستدعي الإغلاقات (closures) المحددة عند الطلب للمعرف العام (PublicId) والمعرف النظامي (SystemId) ورقم السطر (LineNumber) ورقم العمود (ColumnNumber).

إنها مفيدة لكتابة محللات SAX حتى لا تضطر إلى تحديث أرقام الأسطر باستمرار في مرجع علامة تبويب على الكائن الذي تمرره إلى set_document_locator(). راجع الكود المصدري لـ XML::SAX::PurePerl للحصول على مثال استخدام.

واجهة برمجة التطبيقات (API)

هناك طريقة واحدة فقط: "new". ببساطة مرر لها قائمة من الإغلاقات التي عند استدعائها ستعيد المعرف العام (PublicId) والمعرف النظامي (SystemId) ورقم السطر (LineNumber) ورقم العمود (ColumnNumber) والترميز (Encoding) وإصدار XML (XMLVersion) على التوالي.

يتم تمرير معلمة واحدة للإغلاقات، وهو المفتاح الذي يتم طلبه. ولكن يمكنك تجاهل ذلك بحرية.
