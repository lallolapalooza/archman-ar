NAME

XmSeparatorGadget - Separator gadget primitive

SYNOPSIS

#include <Xm/SeparatorG.h>

DESCRIPTION

The XmSeparatorGadget is a primitive widget that provides visual separation between gadgets or widgets in a manager gadget or window. It can be configured to draw a line, an etched line, or a shadow line.

The separator gadget draws its visual representation based on the XmNseparatorType resource.

  • XmSINGLE_LINE: Draws a single line.
  • XmSINGLE_LINE_ETCHED: Draws a single line etched to appear as if it is recessed.
  • XmDOUBLE_LINE: Draws two single lines, one recessed and one raised.
  • XmSINGLE_LINE_RAISED: Draws a single line etched to appear as if it is raised.

The XmNx and XmNy resources define the position of the separator gadget. The XmNwidth resource defines the width of the separator gadget.

The XmNbackground, XmNtopShadowColor, and XmNbottomShadowColor resources control the colors used to draw the separator. The default values for the shadow colors are obtained from the default screen and widget resources.

XmSeparatorGadget supports the XmNdestroyCallback resource. This callback is invoked when the separator gadget is destroyed.

Behavior

XmSeparatorGadget has no behavior.
