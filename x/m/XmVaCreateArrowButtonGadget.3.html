XmVaCreateArrowButtonGadget(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateArrowButtonGadget(استدعاء مكتبة) XmVaCreateArrowButtonGadget(استدعاء مكتبة)

الاسم

XmVaCreateArrowButtonGadget, XmVaCreateManagedArrowButtonGadget — وظائف إنشاء ملائمة لأداة ArrowButtonGadget.

الملخص

#include <Xm/ArrowBG.h>
Widget XmVaCreateArrowButtonGadget(
Widget parent,
String name,
...);
Widget XmVaCreateManagedArrowButtonGadget(
Widget parent,
String name,
...);

الوصف

تقوم هذه الوظائف بإنشاء نسخة من أداة ArrowButtonGadget وتعيد معرف الأداة المرتبط بها. تستخدم هذه الروتينات اصطلاح استدعاء قائمة المتغيرات الطويلة ANSI C (varargs).

الوظيفة XmVaCreateArrowButtonGadget هي روتين ملائم يستدعي XtCreateWidget.

الوظيفة XmVaCreateManagedArrowButtonGadget هي روتين ملائم يستدعي XtCreateManagedWidget.

parent
تحدد معرف الأداة الأم.
name
تحدد اسم الأداة التي تم إنشاؤها.
...
تحدد قائمة المتغيرات لتجاوز افتراضيات الموارد.

لتعريف كامل لـ ArrowButtonGadget والموارد المرتبطة به، انظر XmArrowButtonGadget(3).

الإرجاع

تعيد معرف أداة ArrowButtonGadget.

ذات الصلة

XmArrowButtonGadget(3), XmCreateArrowButtonGadget(3), XtCreateWidget(3), و XtCreateManagedWidget(3).
