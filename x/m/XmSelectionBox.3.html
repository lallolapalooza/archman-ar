NAME

XmSelectionBox
a work area widget that allows the user to select a single item from a list, enter a specific value, or both.

SYNOPSIS

#include <Xm/SelectioB.h>

The structure of the XmSelectionBox widget class is:

 widgetClass = xmSelectionBoxWidgetClass

Creating a SelectionBox

 widget = XmCreateSelectionBox(parent, name, arglist, argCount);

DESCRIPTION

The XmSelectionBox widget is a composite widget that combines a list, a text field, and several command buttons into a single work area. It is used to prompt the user to select a single item from a list or to enter a specific value. The XmSelectionBox widget is derived from the XmBulletinBoard widget.

The XmSelectionBox widget has the following child widgets:

  • List

  • Text

  • Selection Dialog (OK, Cancel, Help buttons)

The XmSelectionBox widget creates and manages its children. The widget's appearance and behavior are controlled by its corresponding resources.

If the XmNselectionLabelString resource is set, a label is created above the text field. If the XmNlistLabelString resource is set, a label is created above the list. The default label strings are in English.

The XmNtextAccelerators resource can be used to modify the default accelerators for the Text descendant. The default accelerators are described in the Accelerators section.

The XmSelectionBox widget supports the dialog shell.

When the user selects an item from the list, the item is copied to the text field. If the user modifies the text in the text field, the selection in the list is deselected. When the user clicks the OK button, the value in the text field is passed to the callback function. When the user clicks the Cancel button, the widget is popped down, and the callback function is called with the XmCR_CANCEL reason.

The XmSelectionBox widget includes the standard dialog shell.

CALLBACK RESOURCES

The following callback resources are supported by the XmSelectionBox widget:

XmNokCallback
Specifies the callback function to be called when the user selects OK. The reason code is XmCR_OK.
XmNcancelCallback
Specifies the callback function to be called when the user selects Cancel. The reason code is XmCR_CANCEL.
XmNhelpCallback
Specifies the callback function to be called when the user selects Help. The reason code is XmCR_HELP.
XmNapplyCallback
Specifies the callback function to be called when the user selects Apply. The reason code is XmCR_APPLY.
XmNvalueChangedCallback
Specifies the callback function to be called when the value in the text field changes. The reason code is XmCR_VALUE_CHANGED.
XmNdisκτη_Callback
Specifies the callback function to be called when the user selects an item from the list. The reason code is XmCR_VALUE_CHANGED.

CALLBACK INFORMATION

A pointer to the following structure is passed to each callback:

typedef struct
{
        int reason;
        XEvent * event;
        XmString value;
        int length;
} XmSelectionBoxCallbackStruct;
reason
Indicates why the callback was invoked. This can be XmCR_OK, XmCR_CANCEL, XmCR_HELP, XmCR_APPLY, or XmCR_VALUE_CHANGED.
event
Points to the XEvent that triggered the callback. This is NULL if the event is not event-driven.
value
Indicates the XmString value selected by the user from the SelectionBox list or entered into the SelectionBox text field. This field is valid for XmCR_OK and XmCR_VALUE_CHANGED callbacks.
length
Indicates the size in bytes of the XmString value. This member is obsolete and exists for compatibility with earlier releases.

ACTION ROUTINES

The XmSelectionBox action routines are

SelectionBoxUpOrDown(Previous|Next|First|Last):
When called with an argument of Previous, or 0 (zero) for the argument, this routine moves the selection up one item in the list. When called with an argument of Next, it moves the selection down one item. When called with an argument of First, it moves the selection to the first item in the list. When called with an argument of Last, it moves the selection to the last item in the list.
SelectionBoxRestore():
This routine restores the original value of the text field from the SelectionBox list.
Activate():
Invokes the XmNokCallback.
Cancel():
Invokes the XmNcancelCallback.
Help():
Invokes the XmNhelpCallback.
Apply():
Invokes the XmNapplyCallback.

EXAMPLE

Creating a selection box:

    Widget selection_box;
    Arg args[10];
    int i = 0;

    XtSetArg(args[i], XmNpromptString,
        XmStringCreateLtoR("Select a file:", XmSTRING_DEFAULT_CHARSET)); i++;
    XtSetArg(args[i], XmNlistItems, file_list); i++;
    XtSetArg(args[i], XmNlistVisibleItemCount, 10); i++;
    selection_box = XmCreateSelectionBox(parent, "selection_box",
        args, i);

STRUCTURE

The XmSelectionBox widget creates the following child widgets:

  • List widget

  • Text widget

  • OK Pushbutton widget

  • Cancel Pushbutton widget

  • Help Pushbutton widget

  • Apply Pushbutton widget (if XmNapplyCallback is set)

  • Selection Label widget (if XmNselectionLabelString is set)

  • List Label widget (if XmNlistLabelString is set)

  • Prompt Label widget (if XmNpromptString is set)
