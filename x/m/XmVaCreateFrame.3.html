XmVaCreateFrame(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateFrame(استدعاء مكتبة) XmVaCreateFrame(استدعاء مكتبة)

الاسم

XmVaCreateFrame, XmVaCreateManagedFrame — وظائف مساعدة لإنشاء أداة Frame.

الملخص

#include <Xm/Frame.h>
Widget XmVaCreateFrame(
Widget parent,
String name,
...);
Widget XmVaCreateManagedFrame(
Widget parent,
String name,
...);

الوصف

تقوم هذه الوظائف بإنشاء نسخة من أداة Frame وإرجاع معرف الأداة المرتبط. تستخدم هذه الروتينات اتفاقية استدعاء قائمة الوسائط المتغيرة ANSI C (varargs).

الوظيفة XmVaCreateFrame هي روتين مساعد يستدعي XtCreateWidget.

الوظيفة XmVaCreateManagedFrame هي روتين مساعد يستدعي XtCreateManagedWidget.

parent
يحدد معرف الأداة الأب.
name
يحدد اسم الأداة التي تم إنشاؤها.
...
يحدد قائمة الوسائط المتغيرة لتجاوز القيم الافتراضية للموارد.

لتعريف كامل لـ Frame والموارد المرتبطة به، انظر XmFrame(3).

القيمة المرجعة

تُرجع معرف أداة Frame.

ذات الصلة

XmFrame(3), XmCreateFrame(3), XtCreateWidget(3), و XtCreateManagedWidget(3).
