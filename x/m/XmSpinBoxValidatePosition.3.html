XmSpinBoxValidatePosition(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmSpinBoxValidatePosition(استدعاء مكتبة) XmSpinBoxValidatePosition(استدعاء مكتبة)

الاسم

XmSpinBoxValidatePosition — ترجمة القيمة الحالية لطفل XmSpinBox المحدد إلى موضع صالح

الملخص

#include <Xm/SpinBox.h>
int XmSpinBoxValidatePosition(
Widget textfield,
int *position);

الوصف

وظيفة XmSpinBoxValidatePosition هي أداة يمكن للتطبيقات استخدامها لتنفيذ سياسة لتتبع تعديلات المستخدم على أطفال XmSpinBox قابلة للتحرير من نوع XmNUMERIC. تُركت تفاصيل متى وكيف تدخل تعديلات المستخدم حيز التنفيذ للتطبيق.

textfield
يحدد وسيط textfield معرف الأداة للطفل الذي يتم تعديله في XmSpinBox. المتطلب لـ textfield هو أن يحمل خاصية accessTextual (وهو بالفعل متطلب لأطفال XmSpinBox). بهذه الطريقة، يمكن لـ XmSpinBox استخراج السلسلة النصية من أداة textfield (حتى لو لم تكن XmTextField).
position
يتم تعيين الموقع الذي يشير إليه الوسيط position لنتيجة الترجمة التي تم إجراؤها بواسطة XmSpinBoxValidatePosition. تتحقق XmSpinBoxValidatePosition أولاً للتأكد من أن هذا طفل XmSpinBox من نوع XmNUMERIC. إذا لم يكن كذلك، فإن XSmpinBoxValidatePosition يضبط position على الموضع الحالي ويعيد XmCURRENT_VALUE.

تحاول XmSpinBoxValidatePosition ترجمة سلسلة الإدخال إلى رقم عشري. إذا فشلت هذه الترجمة، فإن XmSpinBoxValidatePosition يضبط position على الموضع الحالي ويعيد XmCURRENT_VALUE.

تحول XmSpinBoxValidatePosition الرقم العشري إلى عدد صحيح باستخدام خاصية XmNdecimalPoints. يتم اقتطاع الأرقام العشرية الزائدة. يتم التحقق من صحة العدد الصحيح الناتج للتأكد من أنه يقع ضمن النطاق الصالح المحدد بواسطة XmNminimumValue و XmNmaximumValue شاملة. إذا كان الإدخال خارج هذا النطاق، فإن XmSpinBoxValidatePosition يضبط position على أقرب حد ويعيد إما XmMINIMUM_VALUE أو XmMAXIMUM_VALUE.

أخيرًا، تتحقق XmSpinBoxValidatePosition من العدد الصحيح للتأكد من أنه ينتمي إلى السلسلة المحددة بواسطة XmNminimumValue ... XmNminimumValue + ((n - 1) * XmNincrementValue). إذا لم ينتم العدد الصحيح إلى هذه السلسلة، فإن XmSpinBoxValidatePosition يضبط position على أقرب عنصر أقل من أو يساوي العدد الصحيح ويعيد XmINCREMENT_VALUE.

بخلاف ذلك، تقوم XmSpinBoxValidatePosition بتعيين العدد الصحيح إلى position وتعيد XmVALID_VALUE.

قيمة الإرجاع

تعيد وظيفة XmSpinBoxValidatePosition حالة التحقق. مجموعة القيم الممكنة التي تم إرجاعها هي كما يلي:

XmCURRENT_VALUE
لا يمكن التحويل، إعادة قيمة الموضع الحالية.
XmMINIMUM_VALUE
أقل من الحد الأدنى.
XmMAXIMUM_VALUE
أكثر من الحد الأقصى.
XmINCREMENT_VALUE
ليس على الزيادة.
XmVALID_VALUE
حسناً.

أمثلة

يوضح المثال الأول كيف يمكن استخدام وظيفة XmSpinBoxValidatePosition من داخل استدعاء XmNmodifyVerifyCallback مثبت على XmSpinBox أو XmSimpleSpinBox:

/*
 * تثبيت استدعاء على ضغط زر التدوير في SpinBox.
 */
  XtAddCallback(sb, XmNmodifyVerifyCallback, ModifyVerifyCB, NULL);
  XtAddCallback(simple_sb, XmNmodifyVerifyCallback, ModifyVerifyCB, NULL);

مع قيام الاستدعاء بما يلي:

void ModifyVerifyCB(widget, call_data, client_data) {
    XmSpinBoxCallbackStruct *cbs = (XmSpinBoxCallbackStruct*) call_data;
    int position;
    Widget textual = NULL;
    if (XtIsSubclass(w, xmSimpleSpinBoxWidgetClass))
    {
        Arg args[1];
        XtSetArg(args[0], XmNtextField, &textual);
        XtGetValues(w, args, 1);
    }
    else if (XtIsSubclass(w, xmSpinBoxWidgetClass))
      textual = cbs->widget;
    else
      textual = (Widget) NULL;
    ...
    if (XmSpinBoxValidatePosition(textual, &position) == XmCURRENT_VALUE)
      XBell(XtDisplay(w), 0);
    else
      cbs->position = position;
}

يوضح هذا المثال الثاني كيف يمكن استخدام وظيفة XmSpinBoxValidatePosition من داخل استدعاء XmNactivateCallback مثبت على طفل TextField الخاص بـ XmSpinBox:

/*
 * تثبيت استدعاء على ضغط زر التدوير في SpinBox.
 */
XtAddCallback(tf, XmNactivateCallback, ModifyVerifyChildCB, NULL);

مع قيام الاستدعاء بما يلي:

void ModifyVerifyChildCB(widget, call_data, client_data) {
    int     position;
    Widget  textual = widget;
    Arg     args[1];
    if (XmSpinBoxValidatePosition (textual, &position) == XmCURRENT_VALUE)
      XBell(XtDisplay(widget), 0);
    /* تعيين خاصية قيد الموضع لأداة النص */
    XtSetArg(args[0], XmNposition, position);
    XtSetValues(textual, args, 1);
}
