NAME

XML::RSS - A Perl module for creating and manipulating RSS files

SYNOPSIS

 use XML::RSS;

 my $rss = XML::RSS->new(version=>'2.0');

 $rss->channel(
  title=>'My Cool Feed',
  link =>'http://example.com/',
  description =>'The latest updates from my site.',
  language =>'en-us',
  docs =>'http://blogs.law.harvard.edu/tech/rss',
  webMaster =>'webmaster@example.com (Webmaster)',
  managingEditor =>'editor@example.com (Editor)',
  image => {
   url =>'http://example.com/logo.png',
   title =>'My Cool Feed Logo',
   link =>'http://example.com/',
   width =>88,
   height =>31,
  },
 );

 $rss->add_item(
  title =>'First Post',
  link =>'http://example.com/post1',
  description =>'This is the content of my first post.',
  pubDate =>'Sun, 10 Jan 2001 10:20:00 GMT',
  guid =>'http://example.com/post1',
 );

 $rss->add_item(
  title =>'Second Post',
  link =>'http://example.com/post2',
  description =>'This is the content of my second post.',
  pubDate =>'Mon, 11 Jan 2001 11:30:00 GMT',
  guid =>'http://example.com/post2',
 );

 print $rss->as_string();

DESCRIPTION

XML::RSS is a Perl module that allows you to easily create and manipulate RSS (Rich Site Summary) files. RSS is a simple XML format for sharing news headlines, content summaries, and metadata. This module allows you to generate RSS feeds programmatically.

The module supports different versions of the RSS specification, including 0.9, 0.91, 1.0, and 2.0. You can specify the desired version when creating a new XML::RSS object.

It provides methods to set channel information (title, link, description, etc.) and add individual items (posts, articles, etc.) with their respective details.

Methods

The following methods are available:

new( [version => $version] [, encoding => $encoding] )
Creates a new XML::RSS object. The optional version parameter specifies the RSS version to use (e.g., '2.0', '1.0'). If not provided, it defaults to '2.0'. The optional encoding parameter specifies the character encoding for the output XML. Defaults to 'UTF-8'. 

 my $rss = XML::RSS->new(version =>'0.91', encoding =>'iso-8859-1');
channel( $key => $value, ... )
Sets or gets channel-level elements. You can pass key-value pairs to set multiple channel elements at once, or pass a single key to retrieve the value of that element. 

 # Set channel elements
 $rss->channel(
  title =>'My RSS Feed',
  link =>'http://example.com/',
  description =>'Latest news and updates.',
 );

 # Get a channel element
 my $title = $rss->channel('title');
add_item( $key => $value, ... )
Adds a new item to the RSS feed. Key-value pairs represent the elements of the item (e.g., title, link, description, pubDate, guid). 

 $rss->add_item(
  title =>'New Article',
  link =>'http://example.com/article1',
  description =>'Read my latest article here.',
  pubDate =>'Tue, 22 Feb 2005 10:00:00 GMT',
 );
items()
Returns an array reference of all items currently in the feed.
as_string()
Returns the complete RSS feed as an XML string.
parse( $xml_string )
Parses an RSS XML string and populates the XML::RSS object with its content.
parse_file( $filename )
Parses an RSS file and populates the XML::RSS object with its content.

Namespaces and Modules

XML::RSS supports non-standard elements through namespaces, allowing you to include custom data in your feeds. You can declare a namespace and then add elements belonging to that namespace to your items.

For example, to add elements of a made-up "My" module, first declare the namespace by associating a prefix with a URI:

$rss->add_module(prefix=>'my', uri=>'http://purl.org/my/rss/module/');

Then proceed as usual:

$rss->add_item (title=>$title, link=>$link, my=>{ rating =>$rating });

You can also set the value of the module's prefix to an array reference of "{ el => , val => }" hash-references, in which case duplicate elements are possible:

$rss->add_item(title=>$title, link=>$link, my=> [
  {el => "rating", value => $rating1, }
  {el => "rating", value => $rating2, },
]

Non-standard namespaces are not, however, currently accessible via a simple prefix; access them via their namespace URL like so:

print $rss->{items}->[0]->{'http://purl.org/my/rss/module/'}->{rating};

XML::RSS will continue to provide built-in support for standard RSS 1.0 modules as they appear.

Non-API Methods

$rss->as_rss_0_9()

WARNING: this function is not an API function and should not be called directly. It is kept as is for backwards compatibility with legacy code. Use the following code instead:

$rss->{output} = "0.9";
my $text = $rss->as_string();

This function renders the data in the object as an RSS version 0.9 feed, and returns the resultant XML as text.

Needed for XML::Parser. Don't use this directly.

Needed for XML::Parser. Don't use this directly.
