XmVaCreateManagedFrame(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateFrame(استدعاء مكتبة) XmVaCreateFrame(استدعاء مكتبة)

الاسم

XmVaCreateFrame, XmVaCreateManagedFrame — وظائف مساعدة لإنشاء ويدجت الإطار.

الملخص

#include <Xm/Frame.h>
Widget XmVaCreateFrame(
Widget parent,
String name,
...);
Widget XmVaCreateManagedFrame(
Widget parent,
String name,
...);

الوصف

تقوم هذه الوظائف بإنشاء نسخة من ويدجت الإطار وإرجاع معرف الويدجت المرتبط به. تستخدم هذه الروتينات اصطلاح استدعاء قائمة الوسائط ذات الطول المتغير ANSI C (varargs).

وظيفة XmVaCreateFrame هي روتين مساعدة يستدعي XtCreateWidget.

وظيفة XmVaCreateManagedFrame هي روتين مساعدة يستدعي XtCreateManagedWidget.

parent
يحدد معرف الويدجت الأصل.
name
يحدد اسم الويدجت المنشأ.
...
يحدد قائمة الوسائط المتغيرة لتجاوز الإعدادات الافتراضية للموارد.

لتعريف كامل للإطار والموارد المرتبطة به، انظر XmFrame(3).

العودة

ترجع معرف ويدجت الإطار.

ذات الصلة

XmFrame(3), XmCreateFrame(3), XtCreateWidget(3), و XtCreateManagedWidget(3).
