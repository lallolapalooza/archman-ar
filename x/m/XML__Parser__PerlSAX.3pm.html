XML__Parser__PerlSAX(3pm)

XML::Parser::PerlSAX(3) توثيق Perl مساهم به من قبل المستخدم XML::Parser::PerlSAX(3)

الاسم

XML::Parser::PerlSAX - محلل PerlSAX باستخدام XML::Parser

الملخص

use XML::Parser::PerlSAX;
$parser = XML::Parser::PerlSAX->new( [OPTIONS] );
$result = $parser->parse( [OPTIONS] );
$result = $parser->parse($string);

الوصف

"XML::Parser::PerlSAX" هو محلل PerlSAX يستخدم الوحدة XML::Parser. تلخص صفحة الدليل هذه الخيارات والمعالجات والخصائص المحددة التي تدعمها "XML::Parser::PerlSAX"؛ يرجى الرجوع إلى معيار PerlSAX في `"PerlSAX.pod"' للحصول على معلومات الاستخدام العامة.

الأساليب

new
ينشئ كائن محلل جديد. يتم تمرير خيارات التحليل الافتراضية، الموصوفة أدناه، كأزواج مفتاح-قيمة أو كجدول واحد. يمكن تغيير الخيارات مباشرة في كائن المحلل ما لم يُذكر خلاف ذلك. الخيارات الممررة إلى `parse()' تتجاوز الخيارات الافتراضية في كائن المحلل لمدة التحليل.
parse
يحلل مستندًا. يتم تمرير الخيارات، الموصوفة أدناه، كأزواج مفتاح-قيمة أو كجدول واحد. الخيارات الممررة إلى `parse()' تتجاوز الخيارات الافتراضية في كائن المحلل.
location
يعيد الموقع كجدول: 
ColumnNumber    رقم العمود للتحليل.
LineNumber      رقم السطر للتحليل.
BytePosition    موضع البايت الحالي للتحليل.
PublicId        سلسلة نصية تحتوي على المعرف العام، أو undef
                إذا لم يكن متاحًا.
SystemId        سلسلة نصية تحتوي على المعرف النظامي، أو undef
                إذا لم يكن متاحًا.
Base            القيمة الحالية للأساس لحل عناوين URI النسبية.

تحذير ألفا: خصائص `"SystemId"' و `"PublicId"' المعادلة هي المعرفات النظامية والعامة للمستند الممرر إلى `parse()'، وليس المعرفات للكيان الخارجي الذي يتم تحليله حاليًا. المواضع العمودية والسطر والبايت هي للكيان الحالي الذي يتم تحليله.

الخيارات

الخيارات التالية مدعومة بواسطة "XML::Parser::PerlSAX":

Handler          المعالج الافتراضي لتلقي الأحداث
DocumentHandler  المعالج لتلقي أحداث المستند
DTDHandler       المعالج لتلقي أحداث DTD
ErrorHandler     المعالج لتلقي أحداث الخطأ
EntityResolver   المعالج لحل الكيانات
Locale           المنطقة المحلية لتوفير التوطين للأخطاء
Source           جدول يحتوي على مصدر الإدخال للتحليل
UseAttributeOrder تم التعيين إلى true لتوفير خاصيات AttributeOrder و Defaulted
                  في `start_element()'

إذا لم يتم توفير أي معالجات، فسيتم تجاهل جميع الأحداث بصمت، باستثناء `fatal_error()' التي ستؤدي إلى استدعاء `die()' بعد استدعاء `end_document()'.

إذا تم تمرير وسيطة سلسلة نصية واحدة إلى الدالة `parse()'، فيتم التعامل معها كما لو تم تقديم خيار `"Source"' مع معلمة `"String"'.

قد يحتوي جدول `"Source"' على المعلمات التالية:

ByteStream       تيار البايتات الخام (مقبض الملف) الذي يحتوي على
                 المستند.
String           سلسلة نصية تحتوي على المستند.
SystemId         المعرف النظامي (URI) للمستند.
PublicId         المعرف العام.
Encoding         سلسلة نصية تصف ترميز الأحرف.

إذا كان هناك أكثر من واحد من `"ByteStream"'، `"String"'، أو `"SystemId"'، فيتم إعطاء الأفضلية أولاً لـ `"ByteStream"'، ثم `"String"'، ثم `"SystemId"'.

المعالجات

المعالجات والخصائص التالية مدعومة بواسطة "XML::Parser::PerlSAX":

أساليب DocumentHandler

start_document
تلقي إشعار ببداية المستند.

لم يتم تعريف خصائص.

end_document
تلقي إشعار بنهاية المستند.

لم يتم تعريف خصائص.

start_element
تلقي إشعار ببداية عنصر. 
Name             اسم نوع العنصر.
Attributes       جدول يحتوي على السمات المرفقة بالعنصر، إن وجدت.

يحتوي جدول `"Attributes"' على قيم سلاسل نصية فقط.

إذا كانت خاصية المحلل `"UseAttributeOrder"' صحيحة، فسيتم تمرير الخصائص التالية أيضًا إلى `"start_element"':

AttributeOrder   مصفوفة من أسماء السمات بالترتيب الذي تم
                 تحديدها به، تليها أسماء السمات الافتراضية.
Defaulted        رقم فهرس أول سمة افتراضية في
                 `AttributeOrder. إذا كان هذا الفهرس يساوي
                 طول `AttributeOrder'، فلم تكن هناك قيم افتراضية.

ملاحظة لمستخدمي "XML::Parser": `"Defaulted"' ستكون نصف قيمة وظيفة specified_attr() في "XML::Parser::Expat" لأن أسماء السمات فقط هي المقدمة، وليس قيمها.

end_element
تلقي إشعار بنهاية عنصر. 
Name             اسم نوع العنصر.
characters
تلقي إشعار ببيانات الأحرف. 
Data             الأحرف من مستند XML.
processing_instruction
تلقي إشعار بتعليمات المعالجة. 
Target           هدف تعليمات المعالجة.
Data             بيانات تعليمات المعالجة، إن وجدت.
comment
تلقي إشعار بتعليق. 
Data             بيانات التعليق، إن وجدت.
start_cdata
تلقي إشعار ببداية قسم CDATA.

لم يتم تعريف خصائص.

end_cdata
تلقي إشعار بنهاية قسم CDATA.

لم يتم تعريف خصائص.

entity_reference
تلقي إشعار بمرجع كيان داخلي. إذا تم تعريف هذا المعالج، فلن يتم توسيع الكيانات الداخلية ولن يتم تمريرها إلى معالج `characters()'. إذا لم يتم تعريف هذا المعالج، فستتم توسيع الكيانات الداخلية إذا أمكن وتمريرها إلى معالج `characters()'. 
Name             اسم مرجع الكيان.
Value            قيمة مرجع الكيان.

أساليب DTDHandler

notation_decl
تلقي إشعار بحدث إعلان الترميز. 
Name             اسم الترميز.
PublicId         المعرف العام للترميز، إن وجد.
SystemId         المعرف النظامي للترميز، إن وجد.
Base             الأساس لحل عنوان URI النسبي، إن وجد.
unparsed_entity_decl
تلقي إشعار بحدث إعلان كيان غير معالج. 
Name             اسم الكيان.
PublicId         المعرف العام للكيان، إن وجد.
SystemId         المعرف النظامي للكيان، إن وجد.
NotationName     اسم الترميز المحدد في إعلان الكيان.
Base             الأساس لحل عنوان URI النسبي، إن وجد.

أساليب ErrorHandler

error
تلقي إشعار بخطأ غير فادح. 
Message          رسالة الخطأ.
fatal_error
تلقي إشعار بخطأ فادح. 
Message          رسالة الخطأ.

سيؤدي استدعاء هذا المعالج إلى إنهاء التحليل.

warning
تلقي إشعار بتحذير. 
Message          رسالة التحذير.

أساليب EntityResolver

resolve_entity
يتم استدعاؤها لحل مرجع كيان عام أو نظامي. 
PublicId         المعرف العام للكيان.
SystemId         المعرف النظامي للكيان.

يجب أن تعيد هذه الدالة جدولاً يحتوي على المفاتيح التالية: `PublicId' (اختياري)، `SystemId' (اختياري)، `Encoding' (اختياري). إذا تم إرجاع `undef'، فلن يتم حل الكيان.
