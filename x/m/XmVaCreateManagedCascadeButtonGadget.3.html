XmVaCreateManagedCascadeButtonGadget(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmVaCreateManagedCascadeButtonGadget(استدعاء مكتبة) XmVaCreateManagedCascadeButtonGadget(استدعاء مكتبة)

الاسم

XmVaCreateCascadeButtonGadget, XmVaCreateManagedCascadeButtonGadget — وظائف مساعدة لإنشاء عنصر واجهة مستخدم CascadeButtonGadget.

بنية الاستدعاء

#include <Xm/CascadeBG.h>
Widget XmVaCreateCascadeButtonGadget(
Widget parent,
String name,
...);
Widget XmVaCreateManagedCascadeButtonGadget(
Widget parent,
String name,
...);

الوصف

تنشئ هذه الوظائف مثيلاً لعنصر واجهة مستخدم CascadeButtonGadget وتعيد معرف الواجهة المرتبط. تستخدم هذه الروتينات اصطلاح استدعاء قائمة الوسائط المتغيرة ANSI C (varargs).

الوظيفة XmVaCreateCascadeButtonGadget هي روتين مساعد يستدعي XtCreateWidget.

الوظيفة XmVaCreateManagedCascadeButtonGadget هي روتين مساعد يستدعي XtCreateManagedWidget.

parent
يحدد معرف الواجهة الأم.
name
يحدد اسم الواجهة التي تم إنشاؤها.
...
يحدد قائمة الوسائط المتغيرة لتجاوز الافتراضات للموارد.

للحصول على تعريف كامل لـ CascadeButtonGadget والموارد المرتبطة به، راجع XmCascadeButtonGadget(3).

الارجاع

تعيد معرف الواجهة CascadeButtonGadget.

ذات صلة

XmCascadeButtonGadget(3)، XmCreateCascadeButtonGadget(3)، XtCreateWidget(3)، و XtCreateManagedWidget(3).
