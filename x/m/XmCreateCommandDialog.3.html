XmCreateCommandDialog(3)

الحزمة: openmotif

التراخيص: LGPL-2.1-or-later

XmCreateCommandDialog(استدعاء مكتبة) XmCreateCommandDialog(استدعاء مكتبة)

الاسم

XmCreateCommandDialog — وظيفة الإنشاء المريحة لمربع حوار الأوامر

الملخص

#include <Xm/Command.h>
Widget XmCreateCommandDialog(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

الوصف

XmCreateCommandDialog هي وظيفة مريحة تنشئ DialogShell وطفل Command غير مُدار من DialogShell. يُستخدم CommandDialog لإدخال الأوامر للمعالجة.

استخدم XtManageChild لإظهار CommandDialog (مع تمرير الأمر كمعامل الأداة)؛ استخدم XtUnmanageChild لإخفائه.

XmCreateCommandDialog تفرض قيمة مورد Shell XmNallowShellResize إلى True.

parent
يحدد معرف الأداة الأصل
name
يحدد اسم الأداة التي تم إنشاؤها
arglist
يحدد قائمة المعاملات
argcount
يحدد عدد أزواج السمة/القيمة في قائمة المعاملات (arglist)

للحصول على تعريف كامل للأمر والموارد المرتبطة به، راجع XmCommand(3).

الناتج

يعيد معرف أداة الأمر.
