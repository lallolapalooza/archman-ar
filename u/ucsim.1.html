الاسم

uCsim - محاكي المتحكمات الدقيقة

-e command -E -g -G -h -H -I options -k portnum -l -o colors -p prompt -P -R seed -s file -S options -t cpu_type -U uartnr -u hw -v -V -w -X freq[k|M] -z portnum -Z portnum

الوصف

uCsim هو محاكي متحكمات دقيقة، معالجات دقيقة لعائلات معالجات متعددة. يمكن تشغيله كأمر ucsim_XXXX ، حيث يحدد XXXX نوع المعالج الذي تتم محاكاته. على سبيل المثال، ucsim_51 يبدأ محاكي المتحكم الدقيق Intel MCS51، ucsim_z80 يبدأ محاكي المعالج الدقيق Zilog Z80، وما إلى ذلك.

الخيارات

خيارات الأمر

-a nr
تحديد حجم مساحة المتغيرات (الافتراضي = 256).
-b
سمة بالأبيض والأسود (بدون ألوان).
-B
إصدار صوت عند نقاط التوقف.
-c file
فتح وحدة تحكم الأوامر على file (استخدم - للإدخال/الإخراج القياسي).
-C file
قراءة الأوامر الأولية من file وتنفيذها.
-e command
تنفيذ command عند بدء تشغيل البرنامج (قبل ملف الإعداد).
-E
ابدأ، ابدأ المحاكاة في وضع المحاكاة.
-g
ابدأ، ابدأ المحاكاة.
-G
ابدأ، ابدأ المحاكاة، ثم توقف عند التوقف.
-h
اطبع هذا المساعدة واخرج.
-H
اطبع أنواع وحدات المعالجة المركزية المعروفة واخرج.
-I options
options هي قائمة مفصولة بفواصل من الخيارات وفقًا لواجهة المحاكي. الخيارات المعروفة هي:
if=memory[address] تشغيل الواجهة في موقع الذاكرة المعطى.
in=file تحديد ملف الإدخال للإدخال/الإخراج.
out=file تحديد ملف الإخراج للإدخال/الإخراج.
-k portnum
استخدم localhost:portnum للإدخال/الإخراج التسلسلي. هذا الخيار مهمل، استخدم -S بدلاً منه.
-l
استخدم ألوان السمة الفاتحة (الافتراضي هو الداكن).
-o colors
قائمة مواصفات الألوان: what=colspec,... حيث colspec هي قائمة مفصولة بنقطتين: خيارات الألوان مثل: prompt=b:white:black (أبيض غامق على أسود).
-p prompt
تحديد سلسلة النص للموجه.
-P
الموجه هو حرف فارغ ('\0').
-q
وضع هادئ (يعني -b).
-R seed
تعيين بذرة مولد الأرقام العشوائية.
-s file
توصيل الواجهة التسلسلية uart0 بالملف file هذا الخيار مهمل، استخدم -S بدلاً منه.
-S options
options هي قائمة مفصولة بفواصل من الخيارات وفقًا للواجهة التسلسلية. الخيارات المعروفة هي:
uart=nr رقم UART (الافتراضي = 0)
in=file سيتم قراءة الإدخال التسلسلي من الملف المسمى `file'.
out=file سيتم كتابة الإخراج التسلسلي إلى `file'.
port=nr استخدم localhost:nr كخادم للخط التسلسلي.
iport=nr استخدم localhost:nr كخادم للإدخال التسلسلي.
oport=nr استخدم localhost:nr كخادم للإخراج التسلسلي.
raw قم بإجراء اتصال غير تفاعلي حتى على tty.
-t cpu_type
يحدد نوع وحدة التحكم. استخدم -H لسرد القيم الممكنة.
-U uartnr
استخدم وحدة التحكم القياسية كطرفية لـ UART ID = uartnr.
-u hw
استخدم وحدة التحكم القياسية كشاشة للعرض للأجهزة المحددة.
-v
اطبع رقم الإصدار واخرج.
-V
وضع مطول.
-w
ذاكرة فلاش قابلة للكتابة.
-X freq[k|M]
تردد XTAL بالهرتز، استخدم اللاحقة k أو M لتحديد التردد بالكيلوهيرتز أو الميجاهيرتز.
-z portnum
استمع على portnum لوحدة تحكم الأوامر.
-Z portnum
استمع على portnum لوحدة تحكم الأوامر (لا توجد وحدة تحكم على stdio).
