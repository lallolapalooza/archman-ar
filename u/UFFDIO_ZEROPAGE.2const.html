UFFDIO_ZEROPAGE(2const) UFFDIO_ZEROPAGE(2const)

الاسم

UFFDIO_ZEROPAGE - صفر نطاق ذاكرة مسجل مع userfaultfd

المكتبة

مكتبة C القياسية (libc،  -lc)

الملخص

#include <linux/userfaultfd.h>  /* تعريف ثوابت UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, UFFDIO_ZEROPAGE, struct uffdio_zeropage *argp);
#include <linux/userfaultfd.h>
struct uffdio_zeropage {
    struct uffdio_range  range;
    __u64                mode;      /* أعلام تتحكم في السلوك */
    __s64                zeropage;  /* عدد البايتات التي تم تفريغها */
};

الوصف

صفر نطاق ذاكرة مسجل مع userfaultfd.

يمكن أن يتم إجراء عملية OR منطقية على القيمة التالية في mode لتغيير سلوك عملية UFFDIO_ZEROPAGE:

UFFDIO_ZEROPAGE_MODE_DONTWAKE
لا توقظ الخيط الذي ينتظر حل خطأ الصفحة.

يتم استخدام الحقل zeropage بواسطة النواة لإرجاع عدد البايتات التي تم تفريغها بالفعل، أو خطأ بنفس طريقة UFFDIO_COPY. إذا كانت القيمة التي تم إرجاعها في الحقل zeropage لا تتطابق مع القيمة التي تم تحديدها في range.len، تفشل العملية مع الخطأ EAGAIN. الحقل zeropage هو للإخراج فقط؛ لا يتم قراءته بواسطة عملية UFFDIO_ZEROPAGE.

قيمة الإرجاع

تعمل عملية ioctl(2) هذه على إرجاع 0 عند النجاح. في هذه الحالة، تم تفريغ المساحة بأكملها. عند حدوث خطأ، يتم إرجاع -1 ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EAGAIN
عدد البايتات التي تم تفريغها (أي القيمة التي تم إرجاعها في الحقل zeropage) لا يساوي القيمة التي تم تحديدها في الحقل range.len.
EINVAL
إما range.start أو range.len لم يكن مضاعفًا لحجم صفحة النظام؛ أو range.len كان صفرًا؛ أو النطاق المحدد كان غير صالح.
EINVAL
تم تحديد بت غير صالح في الحقل mode.
ESRCH (منذ Linux 4.13)
لقد خرجت العملية المخطئة في وقت عملية UFFDIO_ZEROPAGE.
