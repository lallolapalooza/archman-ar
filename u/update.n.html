update(n)

الحزمة: tcl

التراخيص: TCL

update(n) أوامر Tcl المضمنة update(n)

الاسم

update - معالجة الأحداث المعلقة ومهام الخمول

الملخص

update ?idletasks?

الوصف

يُستخدم هذا الأمر لجعل التطبيق “محدّثًا” عن طريق الدخول إلى حلقة الأحداث بشكل متكرر حتى تتم معالجة جميع الأحداث المعلقة (بما في ذلك مهام الخمول).

إذا تم تحديد الكلمة المفتاحية idletasks كوسيط لهذا الأمر، فلن تتم معالجة أي أحداث جديدة أو أخطاء؛ سيتم استدعاء مهام الخمول فقط. هذا يتسبب في تنفيذ العمليات التي يتم تأجيلها عادةً، مثل تحديثات العرض وحسابات تخطيط النافذة، على الفور.

يعد الأمر update idletasks مفيدًا في البرامج النصية حيث تم إجراء تغييرات على حالة التطبيق وتريد ظهور هذه التغييرات على الشاشة فورًا، بدلاً من الانتظار حتى يكتمل البرنامج النصي. يتم إجراء معظم تحديثات العرض كمهام خمول، لذا فإن update idletasks سيؤدي إلى تشغيلها. ومع ذلك، هناك بعض أنواع التحديثات التي تحدث فقط استجابةً للأحداث، مثل تلك التي يتم تشغيلها بواسطة تغييرات حجم النافذة؛ لن تحدث هذه التحديثات في update idletasks.

يعد الأمر update بدون خيارات مفيدًا في البرامج النصية حيث تقوم بإجراء عملية حسابية طويلة الأمد ولكنك لا تزال تريد أن يستجيب التطبيق للأحداث مثل تفاعلات المستخدم؛ إذا قمت باستدعاء update بشكل متقطع، فسيتم معالجة إدخال المستخدم أثناء الاستدعاء التالي لـ update.

مثال

قم بإجراء حسابات لمدة ثانية تقريبًا ثم قم بالانتهاء:

set x 1000
set done 0
after 1000 set done 1
while {!$done} {
    # مثال سخيف جدا!
    set x [expr {log($x) ** 2.8}]
    # اختبر لمعرفة ما إذا كان وقتنا قد انتهى. سيؤدي هذا أيضًا
    # إلى إتاحة فرصة لخدمة مقابس الشبكة، وإذا تم تحميل حزمة Tk،
    # لتحديث واجهة المستخدم.
    update
}
