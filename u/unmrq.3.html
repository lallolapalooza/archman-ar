DORMRQ¶

DORMRQ

Purpose:

           >
           > DORMRQ overwrites the general real M-by-N matrix C with
           >
           >                          SIDE = 'L'     SIDE = 'R'
           >            TRANS = 'N':      Q * C          C * Q
           >            TRANS = 'T':      Q**T * C       C * Q**T
           >
           > where Q is a real orthogonal matrix defined as the product of k
           > elementary reflectors
           >
           >               Q = H(1) H(2) . . . H(k)
           >
           > as returned by DGERQF. Q is of order M if SIDE = 'L' and of order N
           > if SIDE = 'R'.
           >

Parameters

           >          SIDE is CHARACTER*1
           >          = 'L': apply Q or Q**T from the Left;
           >          = 'R': apply Q or Q**T from the Right.
           >
           >          TRANS is CHARACTER*1
           >          = 'N':  No transpose, apply Q;
           >          = 'T':  Transpose, apply Q**T.
           >
           >          M is INTEGER
           >          The number of rows of the matrix C. M >= 0.
           >
           >          N is INTEGER
           >          The number of columns of the matrix C. N >= 0.
           >
           >          K is INTEGER
           >          The number of elementary reflectors whose product defines
           >          the matrix Q.
           >          If SIDE = 'L', M >= K >= 0;
           >          if SIDE = 'R', N >= K >= 0.
           >
           >          A is REAL array, dimension
           >                               (LDA,M) if SIDE = 'L',
           >                               (LDA,N) if SIDE = 'R'
           >          The i-th row must contain the vector which defines the
           >          elementary reflector H(i), for i = 1,2,...,k, as returned by
           >          DGERQF in the last k rows of its array argument A.
           >
           >          LDA is INTEGER
           >          The leading dimension of the array A. LDA >= max(1,K).
           >
           >          TAU is REAL array, dimension (K)
           >          TAU(i) must contain the scalar factor of the elementary
           >          reflector H(i), as returned by DGERQF.
           >
           >          C is REAL array, dimension (LDC,N)
           >          On entry, the M-by-N matrix C.
           >          On exit, C is overwritten by Q*C or Q**T*C or C*Q**T or C*Q.
           >
           >          LDC is INTEGER
           >          The leading dimension of the array C. LDC >= max(1,M).
           >
           >          WORK is REAL array, dimension (MAX(1,LWORK))
           >          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
           >
           >          LWORK is INTEGER
           >          The dimension of the array WORK.
           >          If SIDE = 'L', LWORK >= max(1,N);
           >          if SIDE = 'R', LWORK >= max(1,M).
           >          For good performance, LWORK should generally be larger.
           >
           >          If LWORK = -1, then a workspace query is assumed; the routine
           >          only calculates the optimal size of the WORK array, returns
           >          this value as the first entry of the WORK array, and no error
           >          message related to LWORK is issued by XERBLA.
           >
           >          INFO is INTEGER
           >          = 0:  successful exit
           >          < 0:  if INFO = -i, the i-th argument had an illegal value
           >

Purpose:

           >

           >
           >                          SIDE = 'L'     SIDE = 'R'
           >            TRANS = 'N':      Q * C          C * Q
           >            TRANS = 'C':      Q**H * C       C * Q**H

           >
           >               Q = H(1)**H H(2)**H . . . H(k)**H

           >          = 'C':  Conjugate transpose, apply Q**H.
           >
           >          M is INTEGER
           >          The number of rows of the matrix C. M >= 0.
           >
           >          N is INTEGER
           >          The number of columns of the matrix C. N >= 0.
           >
           >          K is INTEGER
           >          The number of elementary reflectors whose product defines
           >          the matrix Q.
           >          If SIDE = 'L', M >= K >= 0;

           >                               (LDA,M) if SIDE = 'L',

           >          The i-th row must contain the vector which defines the
           >          elementary reflector H(i), for i = 1,2,...,k, as returned by
           >          ZGERQF in the last k rows of its array argument A.
           >

           >          reflector H(i), as returned by ZGERQF.
           >
           >          C is COMPLEX*16 array, dimension (LDC,N)
           >          On entry, the M-by-N matrix C.
           >          On exit, C is overwritten by Q*C or Q**H*C or C*Q**H or C*Q.
           >
           >          LDC is INTEGER

           >

DORMRQ

الغرض:

           >
           > يقوم DORMRQ بالكتابة فوق المصفوفة العامة الحقيقية M-by-N المسماة C بـ
           >
           >                          SIDE = 'L'     SIDE = 'R'
           >            TRANS = 'N':      Q * C          C * Q
           >            TRANS = 'T':      Q**T * C       C * Q**T
           >
           > حيث Q هي مصفوفة متعامدة حقيقية معرفة كناتج لـ k
           > انعكاسات أولية
           >
           >               Q = H(1) H(2) . . . H(k)
           >
           > كما تم إرجاعها بواسطة DGERQF. Q يكون من الرتبة M إذا كانت SIDE = 'L' ومن الرتبة N
           > إذا كانت SIDE = 'R'.
           >

           >          = 'R': تطبيق Q أو Q**T من اليمين.
           >
           >          TRANS هو CHARACTER*1
           >          = 'N':  بدون تبديل، تطبيق Q؛
           >          = 'T':  تبديل، تطبيق Q**T.
           >
           >          M هو INTEGER
           >          عدد صفوف المصفوفة C. M >= 0.
           >
           >          N هو INTEGER
           >          عدد أعمدة المصفوفة C. N >= 0.
           >
           >          K هو INTEGER
           >          عدد الانعكاسات الأولية التي يعرف ناتجها
           >          المصفوفة Q.
           >          إذا كانت SIDE = 'L', M >= K >= 0؛
           >          إذا كانت SIDE = 'R', N >= K >= 0.
           >
           >          A هو مصفوفة REAL، البعد
           >                               (LDA,M) إذا كانت SIDE = 'L'،
           >                               (LDA,N) إذا كانت SIDE = 'R'
           >          يجب أن يحتوي الصف i على المتجه الذي يعرف الانعكاس الأولي
           >          H(i)، لكل i = 1,2,...,k، كما تم إرجاعه بواسطة
           >          DGERQF في الصفوف k الأخيرة من وسيط المصفوفة A الخاص به.
           >
           >          LDA هو INTEGER
           >          البعد الرئيسي للمصفوفة A. LDA >= max(1,K).
           >
           >          TAU هو مصفوفة REAL، البعد (K)
           >          يجب أن يحتوي TAU(i) على العامل القياسي للانعكاس الأولي
           >          H(i)، كما تم إرجاعه بواسطة DGERQF.
           >
           >          C هو مصفوفة REAL، البعد (LDC,N)
           >          عند الإدخال، المصفوفة M-by-N المسماة C.

           >
           >          LDC هو INTEGER
           >          البعد الرئيسي للمصفوفة C. LDC >= max(1,M).
           >
           >          WORK هي مصفوفة REAL، البعد (MAX(1,LWORK))
           >          عند الخروج، إذا كان INFO = 0، فإن WORK(1) يعيد LWORK الأمثل.
           >
           >          LWORK هو INTEGER
           >          بعد المصفوفة WORK.
           >          إذا كانت SIDE = 'L'، LWORK >= max(1,N)؛
           >          إذا كانت SIDE = 'R'، LWORK >= max(1,M).
           >          لأداء جيد، يجب أن يكون LWORK أكبر بشكل عام.
           >
           >          إذا كانت LWORK = -1، فسيتم افتراض استعلام عن مساحة العمل؛ الروتين
           >          يحسب فقط الحجم الأمثل لمصفوفة WORK، ويعيد
           >          هذه القيمة كالإدخال الأول لمصفوفة WORK، ولا يتم إصدار رسالة خطأ
           >          متعلقة بـ LWORK بواسطة XERBLA.
           >
           >          INFO هو INTEGER
           >          = 0:  انتهاء ناجح
           >          < 0:  إذا كان INFO = -i، فإن الوسيط i كان له قيمة غير قانونية

           >          البعد الرئيسي للمصفوفة C. LDC >= max(1,M).
           >
           >          WORK هي مصفوفة COMPLEX*16، البعد (MAX(1,LWORK))
           >          عند الخروج، إذا كان INFO = 0، فإن WORK(1) يعيد LWORK الأمثل.
           >
           >          LWORK هو INTEGER
           >          البعد المصفوفة WORK.
           >          إذا كانت SIDE = 'L'، LWORK >= max(1,N)؛
           >          إذا كانت SIDE = 'R'، LWORK >= max(1,M).
           >          لأداء جيد، يجب أن يكون LWORK أكبر بشكل عام.
           >
           >          إذا كانت LWORK = -1، فسيتم افتراض استعلام عن مساحة العمل؛ الروتين
           >          يحسب فقط الحجم الأمثل لمصفوفة WORK، ويعيد
           >          هذه القيمة كالإدخال الأول لمصفوفة WORK، ولا يتم إصدار رسالة خطأ
           >          متعلقة بـ LWORK بواسطة XERBLA.
           >
           >          INFO هو INTEGER
           >          = 0:  انتهاء ناجح
           >          < 0:  إذا كان INFO = -i، فإن الوسيط i كان له قيمة غير قانونية
           >
