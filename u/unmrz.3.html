NAME

unmrz - unmr's matrix multiply with a general matrix

SYNOPSIS

    subroutine unmrz(side, trans, m, n, k, l, a, lda, tau, c, ldc, work, lwork, info)

        character(len=1) :: side, trans
        integer :: m, n, k, l, lda, ldc, lwork, info
        complex(kind=8), dimension(lda, *) :: a
        complex(kind=8), dimension(*) :: tau, work

Function Documentation

side

        side is CHARACTER*1
        = 'L': apply the triangular factor U from the left
        = 'R': apply the triangular factor U from the right

trans

        trans is CHARACTER*1
        = 'N': does nothing (trivial case)
        = 'C': apply U'
        = 'T': apply U (complex conjugation)

m

        m is INTEGER
        The number of rows of the matrix C, and the number of rows of U if
        SIDE = 'L'.

n

        n is INTEGER
        The number of columns of the matrix C, and the number of columns of
        U if SIDE = 'R'.

k

        k is INTEGER
        The number of columns of the matrix A, and the number of rows of
        the matrix U if SIDE = 'L'.

l

        l is INTEGER
        The number of rows of the matrix A, and the number of columns of
        the matrix U if SIDE = 'R'.

a

        a is COMPLEX*16 array, dimension (LDA, K) if SIDE = 'L', and (LDA, L)
        if SIDE = 'R'
        Contains the vectors of the elementary reflectors whose product
        is the triangular factor U. See Details of Overlap and Blocking below.

lda

        lda is INTEGER
        The first dimension of A.
        If SIDE = 'L', LDA >= max(1,M).

tau

        tau is COMPLEX*16 array, dimension (K) if SIDE = 'L', and (L)
        if SIDE = 'R'
        Scalar weight factors of the elementary reflectors.

c

        c is COMPLEX*16 array, dimension (LDC, N)
        On entry, the m-by-n matrix C.

ldc

        ldc is INTEGER
        The leading dimension of the array C. ldc >= max(1,m).

work

        work is COMPLEX*16 array, dimension (LWORK)
        Workspace array.
        If LWORK = -1, then only the optimal size of the WORK array is computed.

lwork

        lwork is INTEGER
        The dimension of the array WORK.
        If SIDE = 'L', LWORK >= max(1,N);
        if SIDE = 'R', LWORK >= max(1,M).
        For good performance, LWORK should generally be larger.
        
        If LWORK = -1, then a workspace query is assumed; the routine
        only calculates the optimal size of the WORK array, returns
        this value as the first entry of the WORK array, and no error
        message related to LWORK is issued by XERBLA.

info

        info is INTEGER
        = 0:  successful exit
        < 0:  if INFO = -i, the i-th argument had an illegal value
