umoci-raw-unpack(1)

الحزمة: umoci

التراخيص: Apache

Aleksa Sarai SEPTEMBER 2018

الاسم

umoci raw unpack - تفريغ صورة OCI إلى نظام ملفات جذر

الملخص

umoci raw unpack [خيارات umoci-unpack(1)] rootfs

الوصف

تستخرج جميع الطبقات (بشكل حتمي) إلى نظام ملفات جذر في المسار rootfs. يجب ألا يكون هذا المسار موجودًا بالفعل.

الخيارات

تم تعريف الخيارات العامة في umoci(1)، بينما الخيارات الخاصة بهذا الأمر الفرعي متطابقة مع umoci-unpack(1) باستثناء أن مسار rootfs يتم توفيره بدلاً من مسار bundle.

مثال

يقوم المثال التالي بتنزيل صورة من سجل docker(1) باستخدام skopeo(1)، وتفريغ هذه الصورة إلى نظام ملفات جذر، وإنشاء ملف تكوين OCI وقت التشغيل باستخدام umoci-raw-runtime-config(1) ثم إنشاء حاوية جديدة باستخدام runc(8).

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
# umoci raw unpack --image image rootfs
# umoci raw runtime-config --image image --rootfs rootfs config.json
# runc run ctr
[ container session ]

مع الخيار --rootless، من الممكن أيضًا تنفيذ المثال أعلاه بدون امتيازات الجذر. سيقوم umoci بإنشاء تكوين يعمل مع الحاويات غير الجذرية في runc(8).

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
% umoci raw unpack --image image --rootless rootfs
% umoci raw runtime-config --image image --rootfs rootfs --rootless config.json
% runc --root $HOME/runc run ctr
[ rootless container session ]
