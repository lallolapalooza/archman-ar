uplevel(n)

الحزمة: tcl

التراخيص: TCL

uplevel(n) أوامر Tcl المدمجة uplevel(n)

الاسم

uplevel - تنفيذ نص برمجي في إطار مكدس مختلف

الملخص

uplevel ?level? arg ?arg ...?

الوصف

يتم ربط جميع وسائط arg معًا كما لو تم تمريرها إلى concat؛ ثم يتم تقييم النتيجة في سياق المتغير المشار إليه بواسطة level. تعيد uplevel نتيجة هذا التقييم.

إذا كان level عددًا صحيحًا، فإنه يشير إلى مسافة (صعودًا في مكدس استدعاء الإجراءات) للانتقال إليها قبل تنفيذ الأمر. إذا كان level يتكون من # متبوعًا برقم، فإن الرقم يشير إلى رقم مستوى مطلق. إذا تم حذف level، فإنه يفتراضي إلى 1. لا يمكن افتراض level إذا كان أول وسيط command يبدأ برقم أو #.

على سبيل المثال، لنفترض أنه تم استدعاء الإجراء a من المستوى الأعلى، وأنه استدعى b، وأن b استدعى c. لنفترض أن c يستدعي الأمر uplevel. إذا كان level هو 1 أو #2 أو تم حذفه، فسيتم تنفيذ الأمر في سياق المتغير الخاص بـ b. إذا كان level هو 2 أو #1، فسيتم تنفيذ الأمر في سياق المتغير الخاص بـ a. إذا كان level هو 3 أو #0، فسيتم تنفيذ الأمر على المستوى الأعلى (لن تكون المتغيرات العامة مرئية فقط).

يتسبب الأمر uplevel في اختفاء الإجراء المستدعي من مكدس استدعاء الإجراءات أثناء تنفيذ الأمر. في المثال أعلاه، لنفترض أن c يستدعي الأمر

uplevel 1 {set x 43; d}

حيث d هو إجراء Tcl آخر. سيقوم الأمر set بتعديل المتغير x في سياق b، وسيتم تنفيذ d على المستوى 3، كما لو تم استدعاؤه من b. إذا قام بدوره بتنفيذ الأمر

uplevel {set x 42}

فإن الأمر set سيعدل نفس المتغير x في سياق b: لا يبدو أن الإجراء c موجود على مكدس الاستدعاءات عند تنفيذ d. يمكن استخدام الأمر info level للحصول على مستوى الإجراء الحالي.

يجعل uplevel من الممكن تنفيذ هياكل تحكم جديدة كإجراءات Tcl (على سبيل المثال، يمكن استخدام uplevel لتنفيذ هيكل while كإجراء Tcl).

يقدم الأمران namespace eval و apply طرقًا أخرى (بخلاف استدعاءات الإجراءات) يمكن أن يتغير بها سياق تسمية Tcl. إنهما يضيفان إطار استدعاء إلى المكدس لتمثيل سياق مساحة الاسم. هذا يعني أن كل أمر namespace eval يعتبر مستوى استدعاء آخر لأوامر uplevel و upvar. على سبيل المثال، سيعيد info level 1 قائمة تصف أمرًا هو إما استدعاء الإجراء الخارجي أو أمر namespace eval الخارجي. أيضًا، يقوم uplevel #0 بتقييم نص برمجي على المستوى الأعلى في مساحة الاسم الخارجية (مساحة الاسم العالمية).

مثال

كما ذكرنا أعلاه، الأمر uplevel مفيد لإنشاء هياكل تحكم جديدة. يوضح هذا المثال كيف (بدون معالجة الأخطاء) يمكن استخدامه لإنشاء أمر do وهو المقابل لـ while باستثناء إجراء اختبار الحلقة دائمًا بعد تشغيل جسم الحلقة:

proc do {body while condition} {
    if {$while ne "while"} {
        error "required word missing"
    }
    set conditionCmd [list expr $condition]
    while {1} {
        uplevel 1 $body
        if {![uplevel 1 $conditionCmd]} {
            break
        }
    }
}
