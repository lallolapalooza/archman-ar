upterm-config-view(1)

الحزمة: upterm

التراخيص: Apache-2.0

UPTERM(1) دليل Upterm UPTERM(1)

الاسم

upterm-config-view - عرض محتويات ملف الإعدادات

الملخص

upterm config view [flags]

الوصف

عرض محتويات ملف الإعدادات.

ملف الإعدادات: /build/.config/upterm/config.yaml

إذا كان ملف الإعدادات موجودًا، فسيعرض هذا الأمر محتوياته. إذا لم يكن موجودًا، فسيعرض هذا الأمر ملف إعدادات مثال يمكنك استخدامه كقالب.

الخيارات

-h, --help[=false] مساعدة للعرض

الخيارات الموروثة من الأوامر الأصل

--debug[=false] تمكين تسجيل مستوى التصحيح (ملف السجل: /build/.upterm/upterm.log).

مثال

  # عرض الإعدادات الحالية:
  upterm config view
  # عرض وحفظ كإعدادات جديدة:
  upterm config view > "$(upterm config path)"
