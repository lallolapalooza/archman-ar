User::Identity::Collection::Emails(3pm)

NAME

User::Identity::Collection::Emails - Perl extension for managing email addresses.

INHERITANCE

User::Identity::Collection::Emails inherits from User::Identity::Collection.

SYNOPSIS

use User::Identity::Collection::Emails;

my $emails = User::Identity::Collection::Emails->new;
$emails->add( 'user@example.com' );
$emails->add( 'another@domain.net' );

print $emails->first . "\n";
# user@example.com

print $emails->all->[0] . "\n";
# user@example.com

print $emails->all->[1] . "\n";
# another@domain.net

DESCRIPTION

User::Identity::Collection::Emails is a specialised collection for managing email addresses. It inherits all the methods from User::Identity::Collection and provides additional methods specific to email addresses.

OVERLOADED

This class overloads the fallback operator to allow direct access to email addresses.

METHODS

new
Constructor for User::Identity::Collection::Emails.
add( $email )
Adds an email address to the collection. The email address is validated.
first
Returns the first email address in the collection.
all
Returns a list of all email addresses in the collection.

DIAGNOSTICS

The following diagnostics may be issued:

  • Invalid email address: %s: The provided email address is not valid.
