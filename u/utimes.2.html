utime(2) دليل استدعاءات النظام utime(2)

الاسم

utime, utimes — تغيير أوقات الوصول والتعديل لملف

المكتبة

مكتبة C القياسية (libc، -lc)

ملخص

#include <utime.h>
int utime(const char *path,
          const struct utimbuf *_Nullable times);
#include <sys/time.h>
int utimes(const char *path,
          const struct timeval times[_Nullable 2]);

الوصف

ملاحظة: قد تفضل التطبيقات الحديثة استخدام الواجهات الموصوفة في utimensat(2).

يقوم استدعاء النظام utime() بتغيير أوقات الوصول والتعديل لـ inode المحدد بواسطة path إلى الحقول actime و modtime في times على التوالي. سيتم تعيين وقت تغيير الحالة (ctime) إلى الوقت الحالي، حتى لو لم تتغير الطوابع الزمنية الأخرى فعليًا.

إذا كان times فارغًا (NULL)، فسيتم تعيين أوقات الوصول والتعديل للملف إلى الوقت الحالي.

يُسمح بتغيير الطوابع الزمنية عندما: يكون لدى العملية امتيازات مناسبة، أو يتطابق معرف المستخدم الفعال مع معرف المستخدم للملف، أو يكون times فارغًا ولدى العملية إذن الكتابة للملف.

الهيكل utimbuf هو:


struct utimbuf {
    time_t actime;       /* وقت الوصول */
    time_t modtime;      /* وقت التعديل */
};

يسمح استدعاء النظام utime() بتحديد الطوابع الزمنية بدقة ثانية واحدة.

استدعاء النظام utimes() مشابه، ولكن الوسيط times يشير إلى مصفوفة بدلاً من هيكل. عناصر هذه المصفوفة هي هياكل timeval، والتي تسمح بدقة 1 ميكروثانية لتحديد الطوابع الزمنية. الهيكل timeval هو:


struct timeval {
    long tv_sec;        /* ثواني */
    long tv_usec;       /* ميكروثواني */
};

times[0] يحدد وقت الوصول الجديد، و times[1] يحدد وقت التعديل الجديد. إذا كان times فارغًا (NULL)، فعلى غرار utime()، يتم تعيين أوقات الوصول والتعديل للملف إلى الوقت الحالي.

قيمة الإرجاع

عند النجاح، يتم إرجاع صفر. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EACCES
يُمنع إذن البحث لأحد المجلدات في بادئة المسار لـ path (انظر أيضًا path_resolution(7)).
EACCES
times فارغ (NULL)، معرف المستخدم الفعال للمستدعي لا يتطابق مع مالك الملف، لا يملك المستدعي إذن الكتابة للملف، والمستدعي غير مميز (Linux: لا يملك إما القدرة CAP_DAC_OVERRIDE أو القدرة CAP_FOWNER).
EFAULT
يشير path إلى عنوان غير صالح.
ENOENT
path غير موجود.
EPERM
times ليس فارغًا (NULL)، معرف المستخدم الفعال للمستدعي لا يتطابق مع مالك الملف، والمستدعي غير مميز (Linux: لا يملك القدرة CAP_FOWNER).
EROFS
يقع path على نظام ملفات للقراءة فقط.

المعايير

لا شيء.

POSIX.1-2024.

التاريخ

utime()
SVr4، POSIX.1-2001. تم إلغاؤه في POSIX.1-2008. تمت إزالته في POSIX.1-2024.
utimes()
4.3BSD، POSIX.1-2001.

ملاحظات

لا يسمح Linux بتغيير الطوابع الزمنية على ملف غير قابل للتغيير، أو تعيين الطوابع الزمنية إلى شيء آخر غير الوقت الحالي على ملف قابل للإلحاق فقط.
