ungtsqr(3)

LAPACK

NAME

ungtsqr — generates a matrix A having the specified singular values and first factors of the right singular vectors

SYNOPSIS

    SUBROUTINE UNGTSQR(N, M, K, A, LDA, C, LDC, L, S, INFO)
        INTEGER          :: N, M, K, LDA, LDC, INFO
        REAL             :: S( * )
        COMPLEX*16       :: A( LDA, * ), C( LDC, * ), L( * )

Detailed Description

UNGTSQR is intended to generate a matrix A ( N-by-M ) with any diagonal N-by-N orthogonal matrix Q and any N-by-K matrix X of orthogonal columns, such that A = Q * S * XH, where S is a real diagonal N-by-N matrix. S must be such that S = diag(s1, s2, ..., sN).

The singular values of A are |s1|, |s2|, ..., |sN|. The matrix A is generated by the call to UNGQR.

Arguments

N

CHARACTER. Default: None.

The number of rows of the matrix A. N >= 0.

M

CHARACTER. Default: None.

The number of columns of the matrix A. M >= 0.

K

CHARACTER. Default: None.

The number of right singular vectors in the matrix C. K >= 0.

A

COMPLEX*16. Default: None.

The N-by-M matrix A, which will be generated by the subroutine.

LDA

INTEGER. Default: None.

The leading dimension of the array A. LDA >= max(1, N).

C

COMPLEX*16. Default: None.

The N-by-K matrix C, which contains the first factors of the right singular vectors.

LDC

INTEGER. Default: None.

The leading dimension of the array C. LDC >= max(1, N).

L

COMPLEX*16. Default: None.

The N-by-N matrix L, which contains the left singular vectors.

S

REAL. Default: None.

The singular values of A. The singular values are not necessarily ordered.

INFO

INTEGER. Default: None.

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value.
