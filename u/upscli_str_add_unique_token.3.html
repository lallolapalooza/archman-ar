upscli_str_add_unique_token(3)

الحزمة: nut

التراخيص: GPL-2.0-or-later AND GPL-3.0-or-later

UPSCLI_STR_ADD_UNIQU(3) دليل NUT UPSCLI_STR_ADD_UNIQU(3)

اسم

upscli_str_add_unique_token - إضافة رمز فريد إلى مخزن مؤقت للسلاسل، مع استدعاءات اختيارية حسب الحاجة للتنفيذ

الملخص

        #include <upsclient.h>
        int     upscli_str_add_unique_token(char *tgt, size_t tgtsize, const char *token,
                                int (*callback_always)(char *, size_t, const char *),
                                int (*callback_unique)(char *, size_t, const char *) );

الوصف

الدالة upscli_str_add_unique_token() تأخذ المؤشر tgt إلى مخزن مؤقت char * مقدم من المستدعي بحجم tgtsize، والمؤشر token إلى رمز متصل يجب إضافته إلى نهاية المخزن المؤقت tgt، إذا لم يكن موجودًا بالفعل.

يتم تجريد محتويات token من أحرف المسافة المحيطة، وتتكرر الطريقة لمعالجة كل رمز مفصول بمسافة بشكل مستقل (إذا كانت هناك مسافات متبقية).

سيجمع المخزن المؤقت tgt الناتج في النهاية سلسلة تتكون من قيم token فريدة بترتيب الظهور الأول، مفصولة بمسافات فردية (ASCII 0x20).

اختياريًا، تستدعي callback_always (إذا لم تكن NULL) بعد التحقق من الإدخال للمسافات (وربما التكرار) وقبل التحقق مما إذا كان الرمز موجودًا بالفعل، و/أو callback_unique (إذا لم تكن NULL) بعد التحقق من التفرد وقبل إضافة رمز تم اكتشافه حديثًا.

•إذا أعادت هذه الاستدعاءات القيمة 0، فقم بإلغاء إضافة token وأعد القيمة -3.

يقع على عاتق المستدعي تخصيص المخزن المؤقت tgt ديناميكيًا أو ثابتًا وfree() له إذا لزم الأمر. بقدر ما تتعلق هذه الطريقة، يمكن إعادة استخدام المخزن المؤقت (في حلقات معالجة البيانات) عن طريق تعيين الحرف الأولي إلى '\0'، مما يجعله سلسلة فارغة مرة أخرى.

قيمة الإرجاع

الدالة upscli_str_add_unique_token() تعيد رمزًا رقميًا:

•0 إذا كانت قيمة token موجودة بالفعل في المخزن المؤقت tgt؛
•1 إذا تمت إضافة token بنجاح؛
•-1 إذا احتجنا إلى إضافة token، لكنها لم تتناسب مع حد tgtsize؛
•-2 إذا كانت السلسلة token أو tgt فارغة، أو إذا كان token فارغًا؛
•-3 إذا تم رفض token بواسطة طريقة الاستدعاء الاختيارية التي تعيد 0.
