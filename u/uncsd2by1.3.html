CUNCSD2BY1

الغرض:

!>
!> CUNCSD2BY1 يحسب تحليل CS لمصفوفة X ذات أعمدة متعامدة بحجم M-by-Q التي تم تقسيمها إلى هيكل كتلة 2-by-1:
!>
!>                                [  I1 0  0 ]
!>                                [  0  C  0 ]
!>          [ X11 ]   [ U1 |    ] [  0  0  0 ]
!>      X = [-----] = [---------] [----------] V1**T .
!>          [ X21 ]   [    | U2 ] [  0  0  0 ]
!>                                [  0  0  0 ]
!>                                [  0  S  0 ]
!>                                [  0  0  I2]
!>
!> X11 هي بحجم P-by-Q. المصفوفات الوحدوية U1, U2, و V1 هي بحجم P-by-P,
!> (M-P)-by-(M-P), و Q-by-Q على التوالي. C و S هما مصفوفتان قطريتان غير سالبتين بحجم R-by-R
!> تحققان C^2 + S^2 = I، حيث
!> R = MIN(P,M-P,Q,M-Q). I1 هي مصفوفة هوية بحجم K1-by-K1 و I2 هي مصفوفة هوية بحجم K2-by-K2،
!> حيث K1 = MAX(Q+P-M,0), K2 = MAX(Q-P,0).
!>
!>

المعلمات

JOBU1 
!>          JOBU1 هو CHARACTER
!>          = 'Y':      يتم حساب U1؛
!>          غير ذلك:  لا يتم حساب U1.
!>

JOBU2

!>          JOBU2 هو CHARACTER
!>          = 'Y':      يتم حساب U2؛
!>          غير ذلك:  لا يتم حساب U2.
!>

JOBV1T

!>          JOBV1T هو CHARACTER
!>          = 'Y':      يتم حساب V1T؛
!>          غير ذلك:  لا يتم حساب V1T.
!>

M

!>          M هو INTEGER
!>          عدد الصفوف في X.
!>

P

!>          P هو INTEGER
!>          عدد الصفوف في X11. 0 <= P <= M.
!>

Q

!>          Q هو INTEGER
!>          عدد الأعمدة في X11 و X21. 0 <= Q <= M.
!>

X11

!>          X11 هو مصفوفة COMPLEX، dimension (LDX11,Q)
!>          عند الإدخال، جزء من المصفوفة الوحدوية التي يراد حساب تحليل CS لها.
!>

LDX11

!>          LDX11 هو INTEGER
!>          البعد الرائد لـ X11. LDX11 >= MAX(1,P).
!>

X21

!>          X21 هو مصفوفة COMPLEX، dimension (LDX21,Q)
!>          عند الإدخال، جزء من المصفوفة الوحدوية التي يراد حساب تحليل CS لها.
!>

LDX21

!>          LDX21 هو INTEGER
!>          البعد الرائد لـ X21. LDX21 >= MAX(1,M-P).
!>

THETA

!>          THETA هي مصفوفة REAL، dimension (R)، حيث R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) و
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 هي مصفوفة COMPLEX، dimension (P)
!>          إذا كان JOBU1 = 'Y'، فإن U1 تحتوي على المصفوفة الوحدوية U1 بحجم P-by-P.
!>

LDU1

!>          LDU1 هو INTEGER
!>          البعد الرائد لـ U1. إذا كان JOBU1 = 'Y'، فإن LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 هي مصفوفة COMPLEX، dimension (M-P)
!>          إذا كان JOBU2 = 'Y'، فإن U2 تحتوي على المصفوفة الوحدوية U2 بحجم (M-P)-by-(M-P).
!>

LDU2

!>          LDU2 هو INTEGER
!>          البعد الرائد لـ U2. إذا كان JOBU2 = 'Y'، فإن LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T هي مصفوفة COMPLEX، dimension (Q)
!>          إذا كان JOBV1T = 'Y'، فإن V1T تحتوي على المصفوفة الوحدوية V1**T بحجم Q-by-Q.
!>

LDV1T

!>          LDV1T هو INTEGER
!>          البعد الرائد لـ V1T. إذا كان JOBV1T = 'Y'، فإن LDV1T >=
!>          MAX(1,Q).
!>

WORK

!>          WORK هي مصفوفة COMPLEX، dimension (MAX(1,LWORK))
!>          عند الخروج، إذا كان INFO = 0، فإن WORK(1) يعيد حجم LWORK الأمثل.
!>

LWORK

!>          LWORK هو INTEGER
!>          بعد المصفوفة WORK.
!>
!>          إذا كان LWORK = -1، فيفترض استعلام مساحة العمل؛ الروتين
!>          يحسب فقط الحجم الأمثل للمصفوفات WORK و RWORK،
!>          يعيد هذا الحجم كمدخل أول للمصفوفة WORK
!>          و RWORK على التوالي، ولا يتم إصدار رسالة خطأ متعلقة
!>          بـ LWORK أو LRWORK بواسطة XERBLA.
!>

RWORK

!>          RWORK هي مصفوفة REAL، dimension (MAX(1,LRWORK))
!>          عند الخروج، إذا كان INFO = 0، فإن RWORK(1) يعيد حجم LRWORK الأمثل.
!>          إذا كان INFO > 0 عند الخروج، فإن RWORK(2:R) تحتوي على قيم PHI(1)،
!>          ...، PHI(R-1) التي، مع THETA(1)، ...، THETA(R)،
!>          تحدد المصفوفة في شكل ثنائي قطري وسيط
!>          متبقي بعد عدم التقارب. INFO يحدد عدد
!>          قيم PHI غير الصفرية.
!>

LRWORK

!>          LRWORK هو INTEGER
!>          بعد المصفوفة RWORK.
!>
!>          إذا كان LRWORK = -1، فيفترض استعلام مساحة العمل؛ الروتين
!>          يحسب فقط الحجم الأمثل للمصفوفات WORK و RWORK،
!>          يعيد هذا الحجم كمدخل أول للمصفوفة WORK
!>          و RWORK على التوالي، ولا يتم إصدار رسالة خطأ متعلقة
!>          بـ LWORK أو LRWORK بواسطة XERBLA.
!>

IWORK

!>          IWORK هي مصفوفة INTEGER، dimension (M-MIN(P,M-P,Q,M-Q))
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  الخروج بنجاح.
!>          < 0:  إذا كان INFO = -i، فإن الوسيط i كان له قيمة غير قانونية.
!>          > 0:  لم يتقارب CBBCSD. انظر وصف WORK
!>                أعلاه للتفاصيل.
!>
