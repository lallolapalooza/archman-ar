NAME

umount - unmount file systems

LIBRARY

Standard C library (libc, often linked as -lc)

SYNOPSIS

#include <sys/mount.h>

int umount(const char *target);
int umount2(const char *target, int flags);

DESCRIPTION

The umount() system call detaches the named filesystem from the file hierarchy.

The argument target is a path from which the filesystem was mounted. When the filesystem is successfully detached, all references to the filesystem will be removed, and the filesystem will not be accessible anymore.

The umount2() system call is similar to umount(), but it accepts additional flags, which modify its behavior. The following flags are defined:

MNT_FORCE
Forcibly unmount the filesystem. This is useful for unmounting busy filesystems. If a filesystem is mounted read-only, this flag does nothing. On Linux, this flag is only useful for unmounting network filesystems.
MNT_DETACH
Detaches the filesystem from the file hierarchy now. Any references to files on the filesystem will fail with EBUSY until the filesystem is no longer busy. This is useful for unmounting busy filesystems.
MNT_EXPIRE
Prepare the filesystem to be unmounted. This is useful for unmounting a filesystem which is busy but will eventually be unmounted.

RETURN VALUE

On success, zero is returned.

On error, -1 is returned, and errno is set appropriately.

ERRORS

EBUSY
The specified file system is busy.
EINVAL
target does not refer to a mount point, or an invalid flag was specified.
ENOTDIR
A component of the path prefix of target is not a directory.
ENOMEM
Could not allocate memory.
ENOTBLK
target is not a block device.
ENOENT
The file system does not exist.
EROFS
The filesystem is mounted read-only, and the MNT_FORCE flag was not specified.
EPERM
The caller does not have the necessary privileges to unmount the file system.

STANDARDS

The umount() system call is part of POSIX.1-2001 and later.

The umount2() system call is Linux-specific.

HISTORY

The umount() system call first appeared in Version 7 Unix.

The umount2() system call was introduced in Linux kernel 1.3.83.

NOTES

To unmount a filesystem, you must have the CAP_SYS_ADMIN capability.

The umount command is a user-space utility that uses the umount() system call to unmount filesystems.
