UPSLOG(8) دليل NUT UPSLOG(8)

الاسم

upslog - مسجل حالة UPS

الموجز

upslog -h

upslog [خيارات]

الوصف

upslog هو خادم يقوم بالاستقصاء الدوري لوحدة UPS، وجلب المتغيرات التي تهمك، وتنسيقها، وكتابتها إلى ملف.

سلسلة التنسيق الافتراضية تتضمن متغيرات مدعومة من قبل العديد من نماذج UPS الشائعة. راجع الوصف أدناه لإنشاء سلسلتك الخاصة.

الخيارات

-f format

مراقبة UPS باستخدام سلسلة التنسيق هذه. تأكد من إحاطة format بعلامات اقتباس حتى لا يقوم shell بتقسيمها. الهروب الصالح ضمن هذه السلسلة هو:

%%

إدراج علامة "%" واحدة

%t

إدراج حرف جدولة واحد (مثل printf("\t"))

%TIME format%

إدراج الوقت بتنسيق strftime

%ETIME%

إدراج عدد الثواني منذ بداية "Epoch"، على غرار time_t. هذا الآن رقم من 10 أرقام.

%HOST%

إدراج اسم المضيف المحلي

%UPSHOST%

إدراج المضيف الخاص بوحدة UPS التي تتم مراقبتها (الجزء <system> من مواصفات التسجيل الخاصة بك، على سبيل المثال، ups[@host[:port]])

%PID%

إدراج PID الخاص بـ upslog نفسه

%VAR varname%

إدراج قيمة المتغير varname (راجع فصل "المتغيرات" في توثيق مطوري NUT عبر الإنترنت أو في ملف docs/nut-names.txt في مصادر إصدار NUT الذي قمت بتثبيته لمزيد من التفاصيل)

سلسلة التنسيق الافتراضية هي:

%TIME @Y@m@d @H@M@S% %VAR battery.charge% %VAR input.voltage%
%VAR ups.load% [%VAR ups.status%] %VAR ups.temperature%
%VAR input.frequency%

-N

بادئة %UPSHOST%%t قبل سلسلة التنسيق (سواء كانت افتراضية أو مخصصة). مفيد عند تسجيل أنظمة متعددة في نفس الوجهة.

ملاحظة
هذا الخيار لا يتحقق حاليًا مما إذا كان لديك بالفعل %UPSHOST% في سلسلة التنسيق (على سبيل المثال، محدد صراحة).

-i interval

انتظر هذا العدد من الثواني بين الاستقصاءات. الافتراضي هو 30 ثانية.

إذا كنت بحاجة إلى توقيت أدق، ففكر في كتابة المسجل الخاص بك باستخدام مكتبة upsclient(3).

-d count

الخروج بعد عدد التحديثات المحدد. الافتراضي هو 0 لحلقة لا نهائية (حتى يتم مقاطعتها بطريقة أخرى).

-l logfile

تخزين النتائج في هذا الملف.

يمكنك استخدام - للإخراج القياسي، ولكن upslog سيبقى في المقدمة افتراضيًا.

يتطلب استخدام خيار -s <system> أيضًا لتسجيل نظام واحد.

يمكن استخدامه مع -m <tuple>، وسيتم إضافته إلى القائمة.

-D

زيادة مستوى تفصيل التصحيح بمقدار واحد؛ سيبقى upslog في المقدمة افتراضيًا.

-F

سيعمل upslog في المقدمة، بغض النظر عن وجهة التسجيل.

-B

سيعمل upslog في الخلفية، بغض النظر عن وجهة التسجيل أو التصحيح.

-s ups

مراقبة وحدة UPS هذه. تنسيق هذا الخيار هو upsname[@hostname[:port]]. اسم المضيف الافتراضي هو "localhost".

قد يكون upsname نجمة * للاستعلام عن وحدات UPS التي يخدمها hostname حاليًا، ومراقبة كل منها (في نفس وجهة التسجيل).

يتطلب استخدام خيار -l <logfile> أيضًا لتسجيل نظام واحد.

يمكن استخدامه مع -m <tuple>، وسيتم إضافته إلى القائمة.

-m tuple

مراقبة وحدات UPS متعددة (يتم توفير عدة مثيلات لهذا الخيار).

تنسيق هذا الخيار هو زوج من مواصفات نظام UPS وملف السجل، مفصولة بفواصل. مثال على ذلك سيكون:

upsname@hostname:9999,/var/log/nut/cps.log

قد يكون upsname نجمة * للاستعلام عن وحدات UPS التي يخدمها hostname حاليًا، ومراقبة كل منها (في نفس وجهة التسجيل).

يمكن للأزواج تحديد - كملف سجل، لإصدار الرسائل على الإخراج القياسي (على سبيل المثال، ليتم جمعها بواسطة نظام journal للخدمات).

استخدام الإخراج القياسي عبر مواصفات التسجيل المستندة إلى الأزواج يعني أيضًا أن upslog سيبقى في المقدمة افتراضيًا.

-u username

إذا تم تشغيله كـ root، سيقوم upslog بتنفيذ setuid(2) إلى معرف المستخدم المرتبط بـ username لأسباب أمنية.

إذا لم يتم تعريف username، فسيستخدم القيمة التي تم تجميعها في البرنامج. الافتراضي هو nobody (إذا لم يتم تكوينه بشكل آخر)، وهو بعيد عن المثالي.

خيارات مشتركة

-h

عرض رسالة المساعدة الخاصة بسطر الأوامر.

-V

عرض شعار إصدار NUT. قد تتوفر المزيد من التفاصيل إذا قمت أيضًا بتصدير NUT_DEBUG_LEVEL=1 أو مستوى تفصيل أعلى.

-W secs

تعيين مهلة اتصالات الشبكة الأولية (افتراضيًا تكون غير حاجزة إلى أجل غير مسمى، أو حتى يقوم النظام بمقاطعة المحاولة). تتجاوز متغير البيئة الاختياري NUT_DEFAULT_CONNECT_TIMEOUT.

تأخيرات الخدمة

قيمة الفاصل الزمني هي ببساطة الرقم المعطى لـ sleep(3) بعد المرور عبر سلسلة التنسيق. لذلك، سيستغرق الاستعلام فعليًا وقتًا أطول قليلاً من الفاصل الزمني، اعتمادًا على سرعة نظامك.

التسجيل عند الطلب

إرسال SIGUSR1 إلى عملية upslog قيد التشغيل يجعلها تستيقظ من السكون الحالي وتسجل على الفور. هذا مفيد عندما يتم تشغيله من مشغل حدث upssched (على سبيل المثال، AT ONBATT أو AT ONLINE) لضمان وجود إدخال دائمًا، حتى لو انقطع التيار لفترة زمنية أقصر من تلك المحددة بواسطة الوسيط -i.

توطين السجلات

من الممكن وآمن تحديد نفس ملف السجل (بما في ذلك - للإخراج القياسي) في عدة أزواج، وسيتم فتحه أو إغلاقه مرة واحدة فقط دون تعارض.

فكر في إضافة %UPSHOST% إلى سلسلة التنسيق المخصصة الخاصة بك (على سبيل المثال، باستخدام خيار سطر الأوامر -N)، لتمييز الأسطر المقابلة للأنظمة المختلفة بسهولة، عند تسجيلها في نفس الوجهة.

تدوير السجل

يكتب upslog ملف PID الخاص به إلى upslog.pid، وسيعيد فتح ملف السجل إذا أرسلت له SIGHUP. هذا يسمح له بالاستمرار في العمل عند تدوير السجل بواسطة برنامج خارجي.

محاذير

تاريخيًا، كان هذا الخادم يدعم تسجيل البيانات لنظام UPS واحد في كل مرة تشغيل (محدد بواسطة الخيار -s) في اسم ملف سجل واحد أو الإخراج القياسي (محدد بواسطة الخيار -l).

منذ NUT v2.8.1، سمح بتسجيل أجهزة متعددة (يتم تسجيل كل منها في ملف وجهته الفردي أو الإخراج القياسي المشترك) كما هو محدد بواسطة خيارات tuple -m متعددة. ولكن كان الوضعان متعارضين فعليًا (تم تجاهل خيارات UPS الفردية إذا تم توفير الأزواج أيضًا).

منذ NUT v2.8.3، تم إضافة خيارات UPS الفردية إلى قائمة الأزواج، لذلك يمكن استخدام كل من الخيارات القديمة والجديدة بشكل موثوق لمراقبة أجهزة متعددة في نفس التشغيل.

upslog - Network UPS Tools - Logging utility

NAME

upslog - Network UPS Tools - Logging utility

SYNOPSIS

upslog [-h] [-s host] [-q port] [-u ups] [-l log] [-d dir] [-t timer] [-r rate] [-m mode] [-M maxlength] [-L localepath] [-p pidfile]

DESCRIPTION

upslog is a utility that logs UPS status information to a file. It connects to the upsd(8) server and retrieves information about the UPS. It can log various events such as power on, power off, battery status, etc.

OPTIONS

-h
Display help message and exit.
-s host
Specify the hostname or IP address of the upsd server. Default is localhost.
-q port
Specify the port number of the upsd server. Default is 3052.
-u ups
Specify the UPS name to monitor. If not specified, it defaults to the first UPS found.
-l log
Specify the log file path. Default is /var/log/upslog.
-d dir
Specify the directory for rotating logs. Default is /var/log.
-t timer
Specify the time interval (in seconds) between status checks. Default is 30.
-r rate
Specify the rate (in seconds) at which UPS status changes are logged. Default is 300.
-m mode
Specify the logging mode. Can be `append`, `overwrite`, or `rotate`. Default is `append`.
-M maxlength
Specify the maximum size (in bytes) of the log file before rotation. Default is 1048576.
-L localepath
Specify the path to the locale files for internationalization.
-p pidfile
Specify the path to the PID file. Default is /var/run/upslog.pid.

COMMON OPTIONS

The following options are common to most NUT utilities:

-h
Display help message and exit.
-s host
Specify the hostname or IP address of the upsd server.
-q port
Specify the port number of the upsd server.
-u ups
Specify the UPS name to monitor.
-D
Run in the foreground (do not daemonize).

SERVICE DELAYS

The upslog utility logs status changes to the specified log file. The rate at which these changes are logged is controlled by the -r option. If the UPS status changes frequently, it may be desirable to log these changes less often to avoid filling up the log file too quickly. The default rate is 300 seconds (5 minutes).

ON-DEMAND LOGGING

upslog can be configured to log status changes on demand. This is achieved by setting the -r option to 0. In this mode, upslog will only log status changes when explicitly requested by another utility, such as upsmon(8).

LOG CO-LOCATION

By default, upslog logs to a file named upslog in the directory specified by the -d option. If you wish to log to a different file, you can specify the full path using the -l option.

LOG ROTATION

upslog supports log rotation based on file size. When the log file reaches the size specified by the -M option, it will be renamed with a timestamp and a new log file will be created. The default maximum log file size is 1MB.

CAVEATS

Ensure that the directory specified for log files exists and that the upslog process has write permissions to it.

If running upslog as a service, ensure that the log file permissions are set correctly.
