March 1994 uncompress(1p)

NAME

uncompress - decompress files

SYNOPSIS

uncompress [ -c ] [ -f ] [ -v ] [ -k ] [ -o outfile ] [ -n ] [ -q ] [ -b maxbits ] [ -d ] [ file... ]

DESCRIPTION

The uncompress utility is used to decompress files that have been compressed by compress. The compressed file is restored to its original form. If no file name is specified, uncompress reads from standard input and writes to standard output. The compressed file is assumed to have been created using the LZW compression algorithm.

Options:

  • -c Write output on standard output; keep original files unchanged.
  • -f Force decompression even if the compressed file is the same size as the original.
  • -v Write a long form message showing the compression ratio.
  • -k Kill (delete) the compressed input file after decompressing.
  • -o outfile Place the decompressed output into outfile instead of overwriting the original compressed file.
  • -n Do not write the one-line diagnostic header.
  • -q Quiet mode. Suppress all diagnostic messages.
  • -b maxbits Use maxbits as the maximum number of bits to use in the Huffman codes. This option is rarely needed.
  • -d Equivalent to uncompress. This option is included for compatibility with other compression utilities.

EXIT STATUS

Returns 0 if successful, and non-zero if any error occurs.

SEE ALSO

compress(1), gzip(1)

الاسم

uncompress - فك ضغط الملفات

المُلَخَّص

uncompress [ -c ] [ -f ] [ -v ] [ -k ] [ -o ملف_خارجي ] [ -n ] [ -q ] [ -b الحد_الأقصى_للبِتات ] [ -d ] [ ملف... ]

الوصف

تُستخدم الأداة uncompress لفك ضغط الملفات التي تم ضغطها بواسطة compress. يتم استعادة الملف المضغوط إلى شكله الأصلي. إذا لم يتم تحديد اسم ملف، فإن uncompress تقرأ من الإدخال القياسي وتكتب إلى الإخراج القياسي. يُفترض أن الملف المضغوط قد تم إنشاؤه باستخدام خوارزمية ضغط LZW.

الخيارات:

  • -c اكتب الإخراج على الإخراج القياسي؛ احتفظ بالملفات الأصلية دون تغيير.
  • -f فرض فك الضغط حتى لو كان الملف المضغوط بنفس حجم الملف الأصلي.
  • -v اكتب رسالة مطولة تُظهر نسبة الضغط.
  • -k احذف (حذف) ملف الإدخال المضغوط بعد فك ضغطه.
  • -o ملف_خارجي ضع مخرجات فك الضغط في ملف_خارجي بدلاً من الكتابة فوق الملف المضغوط الأصلي.
  • -n لا تكتب رأس التشخيص ذي السطر الواحد.
  • -q الوضع الهادئ. قم بقمع جميع رسائل التشخيص.
  • -b الحد_الأقصى_للبِتات استخدم الحد_الأقصى_للبِتات كأقصى عدد من البتات لاستخدامها في رموز هوفمان. هذا الخيار نادرًا ما يكون ضروريًا.
  • -d مكافئ لـ uncompress. تم تضمين هذا الخيار للتوافق مع أدوات الضغط الأخرى.
