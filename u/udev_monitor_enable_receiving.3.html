udev_monitor_enable_receiving(3)

الاسم

udev_monitor_receive_device, udev_monitor_enable_receiving, udev_monitor_set_receive_buffer_size, udev_monitor_get_fd, udev_monitor_get_udev - استعلام وتعديل مراقب الأجهزة

الملخص

#include <libudev.h>

struct udev_device *udev_monitor_receive_device(struct udev_monitor *udev_monitor);

int udev_monitor_enable_receiving(struct udev_monitor *udev_monitor);

int udev_monitor_set_receive_buffer_size(struct udev_monitor *udev_monitor, int size);

int udev_monitor_get_fd(struct udev_monitor *udev_monitor);

struct udev *udev_monitor_get_udev(struct udev_monitor *udev_monitor);

قيمة الإرجاع

عند النجاح، ترجع udev_monitor_receive_device() مؤشرًا إلى جهاز تم إنشاء مرجع جديد له تم استلامه عبر المراقب. يتحمل المتصل مسؤولية إسقاط هذا المرجع عند الانتهاء. عند الفشل، يتم إرجاع NULL.

عند النجاح، ترجع udev_monitor_enable_receiving() و udev_monitor_set_receive_buffer_size() قيمة عدد صحيح أكبر من أو تساوي 0. عند الفشل، يتم إرجاع رمز خطأ سالب.

عند النجاح، ترجع udev_monitor_get_fd() واصف الملف المستخدم بواسطة هذا المراقب. عند الفشل، يتم إرجاع رمز خطأ سالب.

ترجع udev_monitor_get_udev() دائمًا مؤشرًا إلى سياق udev المرتبط بهذا المراقب.
