upscli_sendline_timeout(3)

الحزمة: nut

التراخيص: GPL-2.0-or-later AND GPL-3.0-or-later

UPSCLI_SENDLINE(3) دليل NUT UPSCLI_SENDLINE(3)

الاسم

upscli_sendline, upscli_sendline_timeout - إرسال أمر واحد إلى UPS

الملخص

        #include <upsclient.h>
        #include <time.h> /* أو <sys/time.h> على بعض المنصات */
        int upscli_sendline(UPSCONN_t *ups, const char *buf, size_t buflen);
        int upscli_sendline_timeout(UPSCONN_t *ups, const char *buf, size_t buflen,
                const time_t timeout);

الوصف

تقوم الدوال upscli_sendline() و upscli_sendline_timeout() بأخذ المؤشر ups الذي يشير إلى بنية حالة UPSCONN_t ونقل المخزن المؤقت buf بحجم buflen إلى الخادم.

يجب أن تكون البيانات في buf أمر بروتوكول مُنسق بالكامل حيث لا يتم إجراء أي تحليل للمخزن المؤقت داخل هذه الدالة.

الفرق بين الدالتين هو أن upscli_sendline_timeout() تتيح للمستدعي تحديد مقدار الوقت (timeout ثانية) الذي يجب أن يستسلم فيه ويعود، بينما upscli_sendline() لا تقدم هذه الحرية، وتستخدم مهلة فورية (0 ثانية).

قيمة الإرجاع

تعيد الدالتان upscli_sendline() و upscli_sendline_timeout() القيمة 0 عند النجاح، أو -1 إذا حدث خطأ.
