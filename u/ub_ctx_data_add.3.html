NAME

unbound-anchor - fetch root trust anchors for DNSSEC

SYNOPSIS

unbound-anchor [options]

DESCRIPTION

The unbound-anchor program fetches the root Trust Anchors (TA) from the IANA root trust anchor naming system. These trust anchors are needed to validate DNSSEC signed zones. The trust anchors are saved to a file, which can then be used by Unbound via the unbound.conf(5) trust-anchor-file option.

The program queries for the root zone's DNSKEY records, and finds the DS records for the root key. It selects the correct root key based on the current date. It saves the key in zone file format with a leading domain name and type.

The trust anchor file can be updated by running this program periodically.

OPTIONS

-a anchorfile
Save the anchor to the specified file. Default is to print it to standard output.
-v
Enable verbose output, showing progress and what it is doing.
-C unbound.conf
Use the specified unbound configuration file to find settings for the resolver, like nameserver for the query, and interface.
-h
Show help message and exit.

EXAMPLE

Fetch the root anchor and save it to a file named root.anchor:

unbound-anchor -a root.anchor

Fetch the root anchor and save it to /etc/unbound/root.anchor:

sudo unbound-anchor -a /etc/unbound/root.anchor

Fetch the root anchor and save it to /etc/unbound/root.anchor using unbound's configuration file to determine which nameserver to use for the query:

sudo unbound-anchor -a /etc/unbound/root.anchor -C /etc/unbound/unbound.conf

The root.anchor file can then be used in unbound.conf:

server:
    trust-anchor-file: "/etc/unbound/root.anchor"

FILES

/etc/unbound/root.anchor
Default location for the root anchor file. It is created by unbound-anchor if it does not exist.
