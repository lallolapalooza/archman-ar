توثيق الوظائف

subroutine cunm22 (character side, character trans, integer m, integer n, integer n1, integer n2, complex, dimension( ldq, * ) q, integer ldq, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( * ) work, integer lwork, integer info)

CUNM22 يضرب مصفوفة عامة بمصفوفة وحدة مخططة.

الغرض

!>
!>  CUNM22 يستبدل المصفوفة العامة المعقدة M-by-N، C بـ
!>
!>                  SIDE = 'L'     SIDE = 'R'
!>  TRANS = 'N':      Q * C          C * Q
!>  TRANS = 'C':      Q**H * C       C * Q**H
!>
!>  حيث Q هي مصفوفة وحدة معقدة من الرتبة NQ، مع NQ = M إذا كان
!>  SIDE = 'L' و NQ = N إذا كان SIDE = 'R'.
!>  مصفوفة الوحدة Q تعالج هيكل كتلة 2x2
!>
!>         [  Q11  Q12  ]
!>     Q = [            ]
!>         [  Q21  Q22  ],
!>
!>  حيث Q12 هي مصفوفة مثلثة سفلى بحجم N1xN1 و Q21 هي مصفوفة مثلثة عليا
!>  بحجم N2xN2.
!>

المعلمات

SIDE 
!>          SIDE is CHARACTER*1
!>          = 'L': apply Q or Q**H from the Left; (تطبيق Q أو Q**H من اليسار)
!>          = 'R': apply Q or Q**H from the Right. (تطبيق Q أو Q**H من اليمين)
!>

TRANS

!>          TRANS is CHARACTER*1
!>          = 'N':  apply Q (No transpose); (تطبيق Q (بدون تبديل))
!>          = 'C':  apply Q**H (Conjugate transpose). (تطبيق Q**H (تبديل مرافق))
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix C. (عدد صفوف المصفوفة C) M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix C. (عدد أعمدة المصفوفة C) N >= 0.
!>

N1
N2

!>          N1 is INTEGER
!>          N2 is INTEGER
!>          The dimension of Q12 and Q21, respectively. (بعد Q12 و Q21 على التوالي) N1, N2 >= 0.
!>          The following requirement must be satisfied: (يجب تحقيق الشرط التالي:)
!>          N1 + N2 = M if SIDE = 'L' and N1 + N2 = N if SIDE = 'R'.
!>

Q

!>          Q is COMPLEX array, dimension
!>                              (LDQ,M) if SIDE = 'L'
!>                              (LDQ,N) if SIDE = 'R'
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of the array Q. (البعد الرائد للمصفوفة Q)
!>          LDQ >= max(1,M) if SIDE = 'L'; LDQ >= max(1,N) if SIDE = 'R'.
!>

C

!>          C is COMPLEX array, dimension (LDC,N)
!>          On entry, the M-by-N matrix C. (عند الدخول، المصفوفة C بحجم M*N)
!>          On exit, C is overwritten by Q*C or Q**H*C or C*Q**H or C*Q. (عند الخروج، يتم استبدال C بـ Q*C أو Q**H*C أو C*Q**H أو C*Q)
!>

LDC

!>          LDC is INTEGER
!>          The leading dimension of the array C. (البعد الرائد للمصفوفة C) LDC >= max(1,M).
!>

WORK

!>          WORK is COMPLEX array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK. (عند الخروج، إذا كانت INFO = 0، فإن WORK(1) يعيد LWORK الأمثل)
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. (بعد المصفوفة WORK)
!>          If SIDE = 'L', LWORK >= max(1,N);
!>          if SIDE = 'R', LWORK >= max(1,M).
!>          For optimum performance LWORK >= M*N. (لأداء أمثل LWORK >= M*N)
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA. (إذا كانت LWORK = -1، فإنه يُفترض وجود استعلام عن مساحة العمل؛ تقوم الروتين فقط
!>          بحساب الحجم الأمثل لمصفوفة WORK، وتعيد
!>          هذه القيمة كإدخال أول لمصفوفة WORK، ولا يصدر XERBLA أي رسالة خطأ
!>          متعلقة بـ LWORK.)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit (نجاح)
!>          < 0:  if INFO = -i, the i-th argument had an illegal value (إذا كانت INFO = -i، فإن الوسيط i كان له قيمة غير قانونية)
!>
