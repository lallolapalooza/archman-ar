UNIVERSAL(3perl) دليل مبرمجي Perl UNIVERSAL(3perl)

الاسم

UNIVERSAL - الفئة الأساسية لجميع الفئات (مراجع مباركة)

الملخص

my $obj_is_io    = $fd->isa("IO::Handle");
my $cls_is_io    = Class->isa("IO::Handle");
my $obj_does_log = $obj->DOES("Logger");
my $cls_does_log = Class->DOES("Logger");
my $obj_sub      = $obj->can("print");
my $cls_sub      = Class->can("print");
my $eval_sub     = eval { $ref->can("fandango") };
my $ver          = $obj->VERSION;
# but never do this!
my $is_io        = UNIVERSAL::isa($fd, "IO::Handle");
my $sub          = UNIVERSAL::can($obj, "print");

الوصف

"UNIVERSAL" هي الفئة الأساسية التي ترث منها جميع المراجع المباركة. راجع perlobj.

"UNIVERSAL" توفر الأساليب التالية:

"$obj->isa( TYPE )"
"CLASS->isa( TYPE )"
"eval { VAL->isa( TYPE ) }"
حيث
"TYPE"
هو اسم حزمة
$obj
هو مرجع مبارك أو اسم حزمة
"CLASS"
هو اسم حزمة
"VAL"
هو أي مما سبق أو مرجع غير مبارك

عند استخدامه كطريقة للكائن أو الفئة ("$obj->isa( TYPE )")، "isa" تُرجع *صحيح* إذا كان $obj مباركًا في الحزمة "TYPE" أو يرث من الحزمة "TYPE".

عند استخدامه كطريقة للفئة ("CLASS->isa( TYPE )"، المشار إليه أحيانًا باسم طريقة ثابتة)، "isa" تُرجع *صحيح* إذا كانت "CLASS" ترث من (أو هي نفسها) اسم الحزمة "TYPE" أو ترث من الحزمة "TYPE".

إذا لم تكن متأكدًا مما لديك (حالة "VAL")، قم بتغليف استدعاء الطريقة في كتلة "eval" لالتقاط الاستثناء إذا كان "VAL" غير معرف أو مرجعًا غير مبارك. عامل التشغيل "isa" هو بديل يُرجع ببساطة خطأ في هذه الحالة، لذلك لا حاجة لـ "eval".

إذا كنت تريد التأكد من أنك تستدعي "isa" على كائن، وليس فئة، تحقق من المستدعي باستخدام "blessed" من Scalar::Util أولاً:

use Scalar::Util 'blessed';
if ( blessed( $obj ) && $obj->isa("Some::Class") ) {
    ...
}
"$obj->DOES( ROLE )"
"CLASS->DOES( ROLE )"
"DOES" يتحقق مما إذا كان الكائن أو الفئة يقوم بالدور "ROLE". الدور هو مجموعة مسماة من السلوكيات المحددة (غالبًا ما تكون أساليب بأسماء وتواقيع معينة)، مشابهة للفئة، ولكنها ليست بالضرورة فئة كاملة بحد ذاتها. على سبيل المثال، يمكن أن يكون التسجيل أو التسلسل أدوارًا.

"DOES" و "isa" متشابهان، ففي حالة كون أي منهما صحيحًا، فإنك تعلم أن الكائن أو الفئة التي تستدعي عليها الطريقة يمكنها أداء سلوكيات معينة. ومع ذلك، "DOES" يختلف عن "isa" لأنه لا يهتم *كيف* يؤدي المستدعي العمليات، بل فقط أنه يؤديها. ( بالطبع، "isa" تفرض علاقة وراثة. العلاقات الأخرى تشمل التجميع، التفويض، والمحاكاة).

افتراضيًا، تقتصر الفئات في Perl على أداء دور "UNIVERSAL"، بالإضافة إلى دور جميع الفئات في وراثتها. بعبارة أخرى، افتراضيًا "DOES" يستجيب بشكل متطابق لـ "isa".

هناك علاقة بين الأدوار والفئات، حيث أن كل فئة تشير ضمنيًا إلى وجود دور بنفس الاسم. هناك أيضًا علاقة بين الوراثة والأدوار، حيث أن فئة فرعية ترث من فئة أصلية تؤدي ضمنيًا أي أدوار يؤديها أصلها. وبالتالي يمكنك استخدام "DOES" بدلاً من "isa" بأمان، حيث ستُرجع *صحيح* في جميع الأماكن التي ستُرجع فيها "isa" *صحيح* (بشرط أن تتصرف أساليب "DOES" *و* "isa" التي تم تجاوزها بشكل مناسب).

"$obj->can( METHOD )"
"CLASS->can( METHOD )"
"eval { VAL->can( METHOD ) }"
"can" يتحقق مما إذا كان الكائن أو الفئة لديها طريقة تسمى "METHOD". إذا كانت موجودة، فإنها تُرجع مرجعًا للدالة الفرعية. إذا لم تكن موجودة، فإنها تُرجع undef. يشمل ذلك الطرق الموروثة أو المستوردة بواسطة $obj، "CLASS"، أو "VAL".

"can" لا يمكنه معرفة ما إذا كان الكائن سيكون قادرًا على توفير طريقة عبر AUTOLOAD (ما لم تتجاوز فئة الكائن "can" بشكل مناسب)، لذلك لا يعني بالضرورة أن الكائن لن يكون قادرًا على التعامل مع استدعاء الطريقة. للتغلب على ذلك، يستخدم بعض مؤلفي الوحدات إعلانًا أماميًا (راجع perlsub) للطرق التي سيتعاملون معها عبر AUTOLOAD. بالنسبة لهذه الدوال الفرعية "الوهمية"، سيظل "can" يُرجع مرجعًا للكود، والذي عند استدعائه، سيمر إلى AUTOLOAD. إذا لم يتم توفير AUTOLOAD مناسب، فسيؤدي استدعاء الكود المرجعي إلى حدوث خطأ.

يمكنك استدعاء "can" كطريقة فئة (ثابتة) أو طريقة كائن.

مرة أخرى، تنطبق نفس القاعدة المتعلقة بوجود مستدعٍ صالح - استخدم كتلة "eval" أو "blessed" إذا كنت بحاجة إلى مزيد من الحذر.

"VERSION ( [ REQUIRE] )"
"VERSION" ستُرجع قيمة المتغير $VERSION في الحزمة التي تم فيها مباركة الكائن. إذا تم توفير "REQUIRE"، فستقوم بإجراء مقارنة وستفشل إذا لم يكن إصدار الحزمة أكبر من أو يساوي "REQUIRE"، أو إذا كان أي من $VERSION أو "REQUIRE" ليس رقم إصدار "متساهل" (كما هو محدد بواسطة وحدة الإصدار).

القيمة المرجعة من "VERSION" ستكون في الواقع كائن الإصدار المحول إلى سلسلة نصية باستخدام المتغير $VERSION الخاص بالحزمة، والذي يُضمن أنه مكافئ ولكن قد لا يكون مطابقًا تمامًا لمحتويات المتغير $VERSION. إذا كنت تريد المحتويات الفعلية لـ $VERSION، استخدم $CLASS::VERSION بدلاً من ذلك.

"VERSION" يمكن استدعاؤه كطريقة فئة (ثابتة) أو طريقة كائن.

تحذيرات

ملاحظة: يستخدم "can" مباشرةً رمز Perl الداخلي للبحث عن الطرق، ويستخدم "isa" طريقة مشابهة جدًا واستراتيجية تخزين مؤقت. قد يتسبب هذا في تأثيرات غريبة إذا قام رمز Perl بتغيير @ISA ديناميكيًا في أي حزمة.

يمكنك إضافة طرق أخرى إلى فئة UNIVERSAL عبر رمز Perl أو XS. لا تحتاج إلى "use UNIVERSAL" لجعل هذه الطرق متاحة لبرنامجك (ولا يجب عليك القيام بذلك).

UNIVERSAL(3perl)

NAME

UNIVERSAL - Base class for all classes

SYNOPSIS

    # Check if an object is of a specific class:
    if ( $obj->isa( 'ClassName' ) ) { ... }

    # Check if an object is blessed into a specific class:
    if ( UNIVERSAL::isa( $obj, 'ClassName' ) ) { ... }

    # Get the class name of an object:
    my $class = $obj->{__CLASS__}; # DEPRECATED, DON'T USE
    my $class = ref( $obj );

    # Get the superclass name(s) of a class:
    my @superclasses = 'ClassName'->SUPER::();

    # Call a method from the superclass:
    my $result = $obj->SUPER::method( @args );

    # Check if an object is a reference:
    if ( ref( $obj ) ) { ... }

    # Get the type of reference:
    my $reftype = reftype( $ref );
    if ( $reftype eq 'HASH' ) { ... }

    # Override methods for all classes:
    package MyClass;
    sub isa { ... }

    # To call the original isa method:
    my $yes = $obj->SUPER::isa( 'Bar' );

DESCRIPTION

UNIVERSAL is a special class that all classes implicitly inherit from. It provides the basic methods that are available to all objects, such as isa(), can(), and VERSION().

The methods provided by UNIVERSAL are available to any object (or even non-objects, with some caveats). The primary purpose of UNIVERSAL is to provide a common base class so that you can write code that works with any object.

In older versions of Perl, methods like isa() were implemented as built-in functions. They are now methods provided by UNIVERSAL.

isa

The isa() method is used to check if an object is an instance of a particular class or one of its superclasses. It can be called as a method on an object or as a function with the object as the first argument.

    $obj->isa( 'ClassName' )
    UNIVERSAL::isa( $obj, 'ClassName' )

Both forms return true if the object is an instance of ClassName (or a subclass thereof), and false otherwise.

can

The can() method checks if an object's class (or one of its superclasses) has a method with the given name. It returns the subroutine reference if the method exists, and undef otherwise.

    if ( $obj->can( 'method_name' ) ) { ... }

VERSION

The VERSION() method is used to check the version of a class. It is typically used in conjunction with the use Module qw($VERSION); syntax.

    if ( $obj->VERSION( '1.23' ) ) { ... }

This checks if the object's class has a $VERSION variable defined and if that version is greater than or equal to the version specified.

AUTOLOAD

If a class does not define a method, Perl will look for an AUTOLOAD subroutine in the class or its superclasses. If found, AUTOLOAD will be called with the original method name and arguments.

DESTROY

If a class defines a DESTROY subroutine, it will be called automatically when an object of that class is about to be destroyed (i.e., when its reference count drops to zero).

WARNINGS

The isa() method is a method, which means it is subject to Perl's method resolution order. This can lead to unexpected behavior if you override isa() in a subclass. For example, the following code:

    package Foo;
    sub isa {
        my( $class, $class_to_check ) = @_;
        # ... some logic ...
        return $class->SUPER::isa( $class_to_check );
    }

    package Bar;
    sub isa {
        my( $class, $class_to_check ) = @_;
        return 1 if $class_to_check eq 'Bar';
        return $class->SUPER::isa( $class_to_check );
    }

    my $obj = new Bar;
    print $obj->isa( 'Bar' ); # This will likely NOT print 1

The problem is that this code would never call an overridden "isa" method in any class. Instead, use "reftype" from Scalar::Util for the first case:

    use Scalar::Util 'reftype';
                    $yes = reftype( $h ) eq "HASH";

and the method form of "isa" for the second:

$yes = Foo->isa("Bar");

EXPORTS

None of the UNIVERSAL methods are exported by default.
