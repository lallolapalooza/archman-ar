getutent(3) دليل وظائف المكتبة getutent(3)

الاسم

getutent, getutid, getutline, pututline, setutent, endutent, utmpname - الوصول إلى إدخالات ملف utmp

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <utmp.h>
struct utmp *getutent(void);
struct utmp *getutid(const struct utmp *ut);
struct utmp *getutline(const struct utmp *ut);
struct utmp *pututline(const struct utmp *ut);
void setutent(void);
void endutent(void);
int utmpname(const char *path);

الوصف

يجب أن تستخدم التطبيقات الجديدة إصدارات "utmpx" من هذه الوظائف المحددة بواسطة POSIX.1؛ انظر المعايير.

تقوم utmpname() بتعيين مسار ملف بتنسيق utmp لتصل إليه وظائف utmp الأخرى. إذا لم يتم استخدام utmpname() لتعيين المسار قبل استخدام الوظائف الأخرى، فإنها تفترض _PATH_UTMP، كما هو محدد في <paths.h>.

تقوم setutent() بإعادة مؤشر الملف إلى بداية ملف utmp. بشكل عام، من الجيد استدعاءها قبل أي من الوظائف الأخرى.

تقوم endutent() بإغلاق ملف utmp. يجب استدعائها عندما ينتهي كود المستخدم من الوصول إلى الملف باستخدام الوظائف الأخرى.

تقوم getutent() بقراءة سطر من الموضع الحالي للملف في ملف utmp. تُرجع مؤشرًا إلى بنية تحتوي على حقول السطر. يتم عرض تعريف هذه البنية في utmp(5).

تقوم getutid() بالبحث للأمام من موضع الملف الحالي في ملف utmp بناءً على ut. إذا كان ut->ut_type أحد RUN_LVL, BOOT_TIME, NEW_TIME, أو OLD_TIME، فستجد getutid() أول إدخال يتطابق حقله ut_type مع ut->ut_type. إذا كان ut->ut_type أحد INIT_PROCESS, LOGIN_PROCESS, USER_PROCESS, أو DEAD_PROCESS، فستجد getutid() أول إدخال يتطابق حقله ut_id مع ut->ut_id.

تقوم getutline() بالبحث للأمام من موضع الملف الحالي في ملف utmp. تقوم بمسح الإدخالات التي يكون ut_type الخاص بها USER_PROCESS أو LOGIN_PROCESS وتعيد الأول الذي يتطابق حقله ut_line مع ut->ut_line.

تقوم pututline() بكتابة بنية utmp ut في ملف utmp. تستخدم getutid() للبحث عن المكان المناسب في الملف لإدراج الإدخال الجديد. إذا لم تتمكن من العثور على مكان مناسب لـ ut، فستقوم pututline() بإلحاق الإدخال الجديد بنهاية الملف.

قيمة الإرجاع

تُرجع getutent() و getutid() و getutline() مؤشرًا إلى struct utmp عند النجاح، و NULL عند الفشل (والذي يتضمن حالة "السجل غير موجود"). يتم تخصيص struct utmp هذا في مساحة تخزين ثابتة، وقد يتم الكتابة فوقه بواسطة استدعاءات لاحقة.

عند النجاح، تُرجع pututline() ut؛ عند الفشل، تُرجع NULL.

تُرجع utmpname() 0 إذا تم تخزين الاسم الجديد بنجاح، أو -1 عند الفشل.

عند الفشل، تقوم هذه الوظائف بتعيين errno للإشارة إلى الخطأ.

الأخطاء

ENOMEM
نفاد الذاكرة.
ESRCH
السجل غير موجود.

يمكن أن تفشل setutent() و pututline() ووظائف getut*() أيضًا للأسباب الموضحة في open(2).

الملفات

/var/run/utmp
قاعدة بيانات المستخدمين المسجلين حاليًا
/var/log/wtmp
قاعدة بيانات تسجيل دخول المستخدمين السابقين

المعايير

التاريخ

XPG2, SVr4.

في XPG2 و SVID 2، تم توثيق وظيفة pututline() على أنها ترجع void، وهذا ما تفعله على العديد من الأنظمة (AIX, HP-UX). تقدم HP-UX وظيفة جديدة _pututline() مع النموذج الأولي المقدم أعلاه لـ pututline().

كل هذه الوظائف الآن مهملة على الأنظمة غير لينكس. POSIX.1-2001 و POSIX.1-2008، باتباع SUSv1، لا تحتوي على أي من هذه الوظائف، ولكن بدلاً من ذلك تستخدم

#include <utmpx.h>
struct utmpx *getutxent(void);
struct utmpx *getutxid(const struct utmpx *);
struct utmpx *getutxline(const struct utmpx *);
struct utmpx *pututxline(const struct utmpx *);
void setutxent(void);
void endutxent(void);

يتم توفير هذه الوظائف بواسطة glibc، وتؤدي نفس مهام نظيراتها بدون "x"، ولكنها تستخدم struct utmpx، والتي تم تعريفها في لينكس بأنها مطابقة لـ struct utmp. للاكتمال، توفر glibc أيضًا utmpxname()، على الرغم من أن هذه الوظيفة غير محددة بواسطة POSIX.1.

على بعض الأنظمة الأخرى، struct utmpx هي مجموعة شاملة لـ struct utmp، مع حقول إضافية، وإصدارات أكبر للحقول الحالية، ويتم الاحتفاظ بملفات متوازية، غالبًا /var/*/utmpx و /var/*/wtmpx.

من ناحية أخرى، لا يستخدم Linux glibc ملف utmpx متوازي لأن بنية utmp الخاصة به كبيرة بما يكفي بالفعل. وظائف "x" المذكورة أعلاه هي مجرد أسماء مستعارة لنظيراتها بدون "x" (على سبيل المثال، getutxent() هو اسم مستعار لـ getutent()).

ملاحظات

ملاحظات glibc

الوظائف المذكورة أعلاه ليست آمنة للخيوط. تضيف glibc إصدارات قابلة لإعادة الدخول

#include <utmp.h>
int getutent_r(struct utmp *ubuf, struct utmp **ubufp);
int getutid_r(struct utmp *ut,
              struct utmp *ubuf, struct utmp **ubufp);
int getutline_r(struct utmp *ut,
                struct utmp *ubuf, struct utmp **ubufp);

متطلبات ماكرو اختبار الميزات لـ glibc (انظر feature_test_macros(7)):

getutent_r(), getutid_r(), getutline_r():

    _GNU_SOURCE
        || /* منذ glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */    _SVID_SOURCE || _BSD_SOURCE

هذه الوظائف هي امتدادات GNU، ونظائر لوظائف بنفس الأسماء بدون اللاحقة _r. يمنح الوسيط ubuf هذه الوظائف مكانًا لتخزين نتيجتها. عند النجاح، تُرجع 0، ويتم كتابة مؤشر إلى النتيجة في *ubufp. عند حدوث خطأ، تُرجع هذه الوظائف -1. لا توجد مكافئات utmpx للوظائف المذكورة أعلاه. (لا يحدد POSIX.1 مثل هذه الوظائف.)

utmpxname(3) — Arch Linux man pages

NAME

utmpxname, getutxent, getutxid, getutxline, pututxline, setutxent, endutxent - manage utmp and wtmp files

LIBRARY

libc

SYNOPSIS

#include <utmpx.h>

char *
utmpxname(const char *file);

struct utmpx *
getutxent(void);

struct utmpx *
getutxid(const struct utmpx *id);

struct utmpx *
getutxline(const struct utmpx *line);

struct utmpx *
pututxline(const struct utmpx *utmpx);

void
setutxent(void);

void
endutxent(void);

DESCRIPTION

The utmp and wtmp files record user logins and logouts. The functions described here provide an interface to read and write these files. The interface is intended to be compatible with POSIX.1-2001.

The default utmp file is /var/run/utmp and the default wtmp file is /var/log/wtmp. These files can be changed using the utmpxname() function.

The utmpxname() function specifies the pathname of the file to be used for subsequent calls to getutxent(), getutxid(), getutxline(), pututxline(), setutxent(), and endutxent(). If file is NULL, the name of the current file is returned. If file is not NULL, the function returns the previous filename. The maximum length of the filename is subject to UTX_FILENAME_SIZE.

The setutxent() function opens the current utmp file (if it is not already open) and resets the file position indicator to the beginning of the file.

The getutxent() function reads the next entry from the current utmp file. If the file is not open, it opens it first. It returns a pointer to a structure containing the utmp entry. Successive calls to getutxent() return successive entries in the file.

The getutxid() function searches the utmp file for an entry whose type and ID match those in the structure pointed to by id. The fields used for matching are ut_type, ut_pid, and ut_id.

The getutxline() function searches the utmp file for an entry whose terminal line matches that in the structure pointed to by line. The field used for matching is ut_line.

The pututxline() function writes the utmp entry specified by utmpx to the utmp file. If the entry is new, it is appended to the file. If the entry already exists, it is overwritten. The search for an existing entry is done using the entry's type, terminal line, and ID.

The endutxent() function closes the current utmp file.

The structure utmpx is defined in <utmpx.h> and includes the following fields:

struct utmpx {
    char    ut_user[UT_NAMESIZE];    /* Login name */
    char    ut_id[UT_IDSIZE];        /* Terminal line identifier */
    char    ut_line[UT_LINESIZE];    /* Terminal line name */
    pid_t   ut_pid;                  /* Process ID */
    uint16_t ut_type;                /* Type of entry */
    struct timeval ut_tv;            /* Time entry was made */
    char    ut_host[UT_HOSTSIZE];    /* Hostname for remote login */
    char    __unused1[20];           /* Unused */
    char    __unused2[8];            /* Unused */
    int32_t ut_addr_v6[4];           /* IPv6 address of remote host */
};

The following are the possible values for ut_type:

  • EMPTY
  • RUN_LVL
  • BOOT_TIME
  • OLD_TIME
  • NEW_TIME
  • INIT_PROCESS
  • LOGIN_PROCESS
  • USER_PROCESS
  • DEAD_PROCESS
  • ACCOUNTING

RETURN VALUE

The utmpxname() function returns the previous pathname. On error, it returns NULL.

The getutxent(), getutxid(), and getutxline() functions return a pointer to a statically allocated utmpx structure, or NULL if end-of-file is reached or an error occurs.

The pututxline() function returns a pointer to the written utmpx structure on success, and NULL on error.

ERRORS

The behavior of these functions in the presence of errors is not well-defined. However, they may set $ERRNO.

FILES

/var/run/utmp
/var/log/wtmp

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

Interface Attribute
utmpxname, getutxent, getutxid, getutxline, pututxline, setutxent, endutxent Thread safety

STANDARDS

These functions are expected to be compatible with POSIX.1-2001.

HISTORY

The getutmp() and getutline() functions first appeared in 4.3BSD.

The getutxent(), getutxid(), getutxline(), pututxline(), setutxent(), and endutxent() functions first appeared in FreeBSD 2.2.

The utmpxname() function first appeared in FreeBSD 3.4.

NOTES

These functions use static buffers, so the information returned by successive calls may overwrite previous results. If you need to preserve the information, you should copy it immediately after the call.

The pututxline() function is not atomic. Multiple processes calling this function concurrently may lead to corrupted utmp or wtmp files.

The ut_addr_v6 field is intended for IPv6 addresses. It is a 32-bit array, allowing for 4 IPv6 addresses. However, only the first entry ut_addr_v6[0] is typically used on most systems.

EXAMPLES

The following example adds and removes a utmp record, assuming it is run from within a pseudo terminal. For usage in a real application, you should check the return values of getpwuid(3) and ttyname(3).

#include <err.h>
#include <pwd.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#include <unistd.h>
#include <utmp.h>
int
main(void)
{
    struct utmp entry;
    if (system("echo before adding entry:;who") == -1)
        err(EXIT_FAILURE, "system");
    entry.ut_type = USER_PROCESS;
    entry.ut_pid = getpid();
    strcpy(entry.ut_line, ttyname(STDIN_FILENO) + strlen("/dev/"));
    /* only correct for ptys named /dev/tty[pqr][0-9a-z] */
    strcpy(entry.ut_id, ttyname(STDIN_FILENO) + strlen("/dev/tty"));
    entry.ut_time = time(NULL);
    strcpy(entry.ut_user, getpwuid(getuid())->pw_name);
    memset(entry.ut_host, 0, UT_HOSTSIZE);
    entry.ut_addr = 0;
    setutent();
    if (pututline(&entry) == NULL)
        err(EXIT_FAILURE, "pututline");
    if (system("echo after adding entry:;who") == -1)
        err(EXIT_FAILURE, "system");
    entry.ut_type = DEAD_PROCESS;
    memset(entry.ut_line, 0, UT_LINESIZE);
    entry.ut_time = 0;
    memset(entry.ut_user, 0, UT_NAMESIZE);
    setutent();
    if (pututline(&entry) == NULL)
        err(EXIT_FAILURE, "pututline");
    if (system("echo after removing entry:;who") == -1)
        err(EXIT_FAILURE, "system");
    endutent();
    exit(EXIT_SUCCESS);
}
