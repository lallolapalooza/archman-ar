--post-size { width, height | size-name }
تغيير حجم الورقة مع الحفاظ على نسبة المحتوى بعد تطبيق خطوات المعالجة الأخرى.
--stretch { width, height | size-name }
تغيير حجم الورقة قبل تطبيق المعالجة الأخرى. يتم تمديد المحتوى الموجود على الورقة إلى الحجم المحدد، مما قد يغير نسبة العرض إلى الارتفاع.
--post-stretch { width, height | size-name }
تغيير حجم الورقة بعد تطبيق المعالجة الأخرى. يتم تمديد المحتوى الموجود على الورقة إلى الحجم المحدد، مما قد يغير نسبة العرض إلى الارتفاع.
-z factor ; --zoom factor
تغيير حجم الورقة وفقًا للعامل المحدد قبل إجراء المعالجة الأخرى.
--post-zoom factor
تغيير حجم الورقة وفقًا للعامل المحدد بعد الانتهاء من المعالجة.
-bn { v | h | v, h } ; --blackfilter-scan-direction { v | h | v, h }
الاتجاهات التي سيتم البحث فيها عن مناطق سوداء صلبة. يمكن تحديد v (للبحث العمودي)، h (للبحث الأفقي)، أو v,h (لكليهما). يعمل مرشح اللون الأسود عن طريق تحريك شريط افتراضي عبر كل صفحة. يتم تحديد مدى سواد المنطقة داخل الشريط الافتراضي، وإذا تجاوزت blackfilter-scan-threshold، فسيتم ملء وحدات البكسل السوداء في المنطقة. أثناء الملء، يتم تحديد مدى سواد كل بكسل بواسطة black-threshold. ثم يتم تحريك الشريط بمقدار blackfilter-scan-step في اتجاه المسح. بمجرد الوصول إلى حدود الصفحة، يتم تحريك الشريط لأسفل (مسح أفقي) أو لليمين (مسح عمودي) بمقدار blackfilter-scan-size.
-bs { size | h-size, v-size } ; --blackfilter-scan-size { size | h-size, v-size }
حجم الشريط الافتراضي في اتجاه المسح (يعني العرض للمرور الأفقي، الارتفاع للمرور العمودي) المستخدم للكشف عن المناطق السوداء. يمكن تحديد قيمتين لضبط الحجم بشكل فردي لكل من المرور الأفقي والعمودي. (الافتراضي: 20,20)
-bd { depth | h-depth, v-depth } ; --blackfilter-scan-depth { depth | h-depth, v-depth }
عمق الشريط الافتراضي في الاتجاه غير الماسح (يعني الارتفاع للمرور الأفقي، العرض للمرور العمودي) المستخدم للكشف عن المناطق السوداء. يمكن تحديد قيمتين لضبط العمق بشكل فردي لكل من المرور الأفقي والعمودي. (الافتراضي: 500,500)
-bp { step | h-step, v-step } ; --blackfilter-scan-step { step | h-step, v-step }
خطوات تحريك الشريط الافتراضي للكشف عن المناطق السوداء. يمكن تحديد قيمتين لضبط الخطوة بشكل فردي لكل من المرور الأفقي والعمودي. (الافتراضي: 5,5)
-bt threshold ; --blackfilter-scan-threshold threshold
نسبة البكسلات الداكنة التي فوقها يتم اكتشاف منطقة سوداء. (الافتراضي: 0.95).
-bx left, top, right, bottom ; --blackfilter-scan-exclude left, top, right, bottom
المنطقة التي لا ينبغي أن يعمل عليها مرشح اللون الأسود. يمكن أن يكون هذا مفيدًا لمنع مرشح اللون الأسود من العمل على محتوى الصفحة الداخلي. يمكن تحديده عدة مرات لتعيين أكثر من منطقة.
-bi intensity ; --blackfilter-intensity intensity
الكثافة التي يتم بها حذف المناطق السوداء. يقوم هذا بحذف وحدات البكسل حول شريط المسح الافتراضي. القيم الأكبر ستترك وحدات بكسل ضوضاء أقل حول المناطق السوداء السابقة، ولكن قد تحذف محتوى الصفحة. (الافتراضي: 20)
-ni intensity ; -noisefilter-intensity intensity
الكثافة التي يتم بها حذف وحدات البكسل الفردية أو مجموعات صغيرة من وحدات البكسل. سيتم حذف أي مجموعة تحتوي فقط على وحدات بكسل داكنة معًا. (الافتراضي: 4)
-ls { size | h-size, v-size } ; --blurfilter-size { size | h-size, v-size }
حجم منطقة التمويه للبحث عن مجموعات بكسلات "وحيدة". (الافتراضي: 100,100)
-lp { step | h-step, v-step } ; --blurfilter-step { step | h-step, v-step }
حجم خطوات "التمويه" في كل اتجاه. (الافتراضي: 50,50)
-li ratio ; --blurfilter-intensity ratio
الكثافة النسبية التي يتم بها حذف مجموعات صغيرة من وحدات البكسل. سيتم مسح أي منطقة مموهة تحتوي على نسبة بكسلات داكنة تصل إلى الحد المسموح به. (الافتراضي: 0.01)
-gs { size | h-size, v-size } ; --grayfilter-size { size | h-size, v-size }
حجم قناع مرشح الرمادي للبحث عن مناطق بكسلات "رمادية فقط". (الافتراضي: 50,50)
-gp { step | h-step, v-step } ; --grayfilter-step { step | h-step, v-step }
حجم الخطوات التي تحرك قناع مرشح الرمادي في كل اتجاه. (الافتراضي: 20,20)
-gt ratio ; --grayfilter-threshold ratio
الكثافة النسبية للرمادية التي يتم قبولها قبل مسح قناع مرشح الرمادي في الحالات التي لا يتم فيها العثور على بكسل أسود في القناع. (الافتراضي: 0.5)
-p x, y; --mask-scan-point x, y
تحديد نقطة البداية يدويًا للكشف عن القناع. يمكن تحديد خيارات --mask-scan-point متعددة للكشف عن أقنعة متعددة.
-m x1, y1, x2, y2; --mask x1, y1, x2, y2
إضافة قناع يدويًا، بالإضافة إلى الأقنعة التي تم اكتشافها تلقائيًا حول إحداثيات --mask-scan-point (ما لم يتم تحديد --no-mask-scan).

سيتم تعيين أي بكسل خارج القناع إلى اللون الأبيض، ما لم يغطِ قناع آخر هذا البكسل.

-mn { v \| h \| v,h }; --mask-scan-direction { v \| h \| v,h }
الاتجاهات التي سيتم البحث فيها عن حدود القناع، بدءًا من إحداثيات --mask-scan-point. يمكن تحديد v (للمرآة العمودية)، h (للمرآة الأفقية)، أو v,h (لكليهما). (الافتراضي: h، حيث أن v قد تقطع فقرات النص في الأوراق ذات الصفحة الواحدة)
-ms { size \| h-size, v-size }; --mask-scan-size { size \| h-size, v-size }
عرض الشريط الافتراضي المستخدم للكشف عن القناع. يمكن تحديد قيمتين لضبط الحجم الأفقي والعمودي بشكل فردي. (الافتراضي: 50,50)
-md { depth \| h-depth, v-depth }; --mask-scan-depth { depth \| h-depth, v-depth }
ارتفاع الشريط الافتراضي المستخدم للكشف عن القناع. (الافتراضي: -1,-1، باستخدام العرض الإجمالي أو ارتفاع الورقة)
-mp { step \| h-step, v-step }; --mask-scan-step { step \| h-step, v-step }
خطوات تحريك الشريط الافتراضي للكشف عن القناع. (الافتراضي: 5,5)
-mt { threshold \| h-threshold, v-threshold }; --mask-scan-threshold { threshold \| h-threshold, v-threshold }
نسبة البكسلات الداكنة التي يتم عندها اكتشاف حافة، بالنسبة إلى أقصى سواد عند العد من نقطة البداية باتجاه حافة واحدة. (الافتراضي: 0.1)
-mm w, h; --mask-scan-minimum w, h
الحد الأدنى للحجم المسموح به للقناع المكتشف تلقائيًا. سيتم تجاهل الأقنعة المكتشفة بهذا الحجم الأقل وسيتم تعيينها إلى الحجم المحدد بواسطة mask-scan-maximum. (الافتراضي: 100,100)
-mM w, h; --mask-scan-maximum w, h
الحد الأقصى للحجم المسموح به للقناع المكتشف تلقائيًا. سيتم تقليص الأقنعة المكتشفة بهذا الحجم الأكبر إلى القيمة القصوى، كل اتجاه بشكل فردي. (الافتراضي: حجم الورقة، أو حجم الصفحة المشتق من خيار --layout)
-mc color; --mask-color color
قيمة اللون التي سيتم بها مسح البكسلات التي لا تغطيها أي قناع. قد يكون هذا مفيدًا للاختبار لتصور تأثير التغطية. (لاحظ أنه يتوقع قيمة RGB: R*65536 + G*256 + B.)
-dn { left \| top \| right \| bottom },...; --deskew-scan-direction { left \| top \| right \| bottom },...
الحواف التي سيتم المسح منها للدوران. يمكن استخدام كل حافة من حواف القناع لاكتشاف دوران القناع. إذا تم تحديد حواف متعددة، فسيتم استخدام القيمة المتوسطة، ما لم يتجاوز الانحراف الإحصائي --deskew-scan-deviation. استخدم left للمسح من الحافة اليسرى، top للمسح من الحافة العلوية، right للمسح من الحافة اليمنى، bottom للمسح من الحافة السفلية. يمكن فصل الاتجاهات المتعددة بفواصل. (الافتراضي: left,right)
-ds pixels; -- deskew-scan-size pixels
حجم الخط الافتراضي لاكتشاف الدوران. (الافتراضي: 1500)
-dd نسبة؛ --deskew-scan-depth نسبة
كمية البكسلات الداكنة التي سيتم تجميعها حتى يتوقف المسح، نسبة إلى حجم شريط المسح. (الافتراضي: 0.5)
-dr درجات؛ --deskew-scan-range درجات
النطاق الذي سيتم البحث فيه عن الدوران، من -درجات إلى +درجات دوران. (الافتراضي: 5.0)
-dp درجات؛ --deskew-scan-step درجات
الخطوات بين اكتشافات زاوية الدوران الفردية. الأرقام الأقل تؤدي إلى نتائج أفضل ولكنها تبطئ المعالجة. (الافتراضي: 0.1)
-dv انحراف؛ --deskew-scan-deviation انحراف
الحد الأقصى للانحراف الإحصائي المسموح به بين النتائج من الحواف المكتشفة. لا يتم إجراء دوران إذا تجاوز هذا الحد. (الافتراضي: 1.0)
-W يسار، أعلى، يمين، أسفل؛ --wipe يسار، أعلى، يمين، أسفل
مسح منطقة يدويًا. سيتم تعيين أي بكسل في منطقة ممحوكة إلى اللون الأبيض. يمكن تحديد مناطق --wipe متعددة. يتم تطبيق هذا بعد تسوية الانحراف وقبل المسح التلقائي للحدود.
-mw { حجم \| يسار، يمين }؛ --middle-wipe { حجم \| يسار، يمين }
إذا تم تعيين --layout إلى double، يمكن تحديد حجم منطقة وسطى لمسحها بين الصفحتين على الورقة. قد يكون هذا مفيدًا إذا فشل المرشح الأسود في إزالة بعض المناطق السوداء (على سبيل المثال، الناتجة عن التصوير الفوتوغرافي في المنتصف بين صفحتين).
-B يسار، أعلى، يمين، أسفل؛ --border يسار، أعلى، يمين، أسفل
إضافة حدود يدويًا. سيتم تعيين أي بكسل في منطقة الحدود إلى اللون الأبيض. يتم تطبيق هذا بعد تسوية الانحراف وقبل المسح التلقائي للحدود.
-Bn { v \| h \| v,h }؛ --border-scan-direction { v \| h \| v,h }
الاتجاهات التي سيتم البحث فيها عن الحد الخارجي. يمكن تحديد إما v (للمرآة الرأسية)، h (للمرآة الأفقية) أو v,h (لكليهما). (الافتراضي: v)
-Bs { حجم \| حجم-أفقي، حجم-رأسي }؛ --border-scan-size { حجم \| حجم-أفقي، حجم-رأسي }
عرض الشريط الافتراضي المستخدم لاكتشاف الحدود. يمكن تحديد قيمتين لتعيين الحجم الأفقي والرأسي بشكل فردي. (الافتراضي: 5,5)
-Bp { خطوة \| خطوة-أفقية، خطوة-رأسية }؛ --border-scan-step { خطوة \| خطوة-أفقية، خطوة-رأسية }
الخطوات لتحريك الشريط الافتراضي لاكتشاف الحدود. (الافتراضي: 5,5)
-Bt عتبة؛ --border-scan-threshold عتبة
العدد المطلق للبكسلات الداكنة التي يغطيها قناع مسح الحدود والتي فوقها يتم اكتشاف حد. (الافتراضي: 5)
-Ba { يسار \| أعلى \| يمين \| أسفل }؛ --border-align { يسار \| أعلى \| يمين \| أسفل }
الاتجاه الذي سيتم فيه تحريك منطقة الحدود المكتشفة. استخدم --border-margin لتحديد المسافات الأفقية والرأسية التي يجب الحفاظ عليها من حافة الورقة. (الافتراضي: none)
-Bm رأسي، أفقي؛ --border-margin رأسي، أفقي
المسافة التي يجب الحفاظ عليها من حافة الورقة عند محاذاة منطقة حدود. يمكن استخدام لاحقات قياس مثل سم، بوصة.
-w عتبة؛ --white-threshold عتبة
نسبة السطوع التي يعتبر البكسل أبيض فوقها. (الافتراضي: 0.9)
-b عتبة؛ --black-threshold عتبة
نسبة السطوع التي يعتبر البكسل أسود (غير رمادي) تحتها. يستخدم هذا بواسطة المرشح الرمادي والمرشح الأسود. يستخدم هذا الرقم أيضًا عند تحويل صورة تدرج الرمادي إلى وضع أبيض وأسود (الافتراضي: 0.33)
-ip { 1 \| 2 }؛ --input-pages { 1 \| 2 }
إذا تم تحديد 2، يتم قراءة صورتين إدخال بدلاً من واحدة ويتم دمجهما داخليًا لتكوين ورقة بتخطيط مزدوج قبل المزيد من المعالجة. قبل الدمج الداخلي، يتم تطبيق --pre-rotation اختياريًا على كلتا صورتي الإدخال كأولى خطوات المعالجة.
-op { 1 \| 2 }؛ --output-pages { 1 \| 2 }
إذا تم تحديد 2، يتم كتابة صورتين إخراج بدلاً من واحدة، نتيجة لتقسيم ورقة ذات تخطيط مزدوج بعد المعالجة. بعد تقسيم الورقة، يتم تطبيق --post-rotation اختياريًا على كل صورة إخراج على حدة كآخر خطوة معالجة.
-S { عرض، ارتفاع \| اسم-حجم }؛ --sheet-size { عرض، ارتفاع \| اسم-حجم }
فرض حجم ورقة ثابت. عادةً، يتم تحديد حجم الورقة بواسطة حجم صورة الإدخال (إذا كان input-pages=1)، أو بواسطة الحجم المزدوج للصفحة الأولى في مجموعة إدخال من صفحتين (إذا كان input-pages=2). إذا كانت صورة الإدخال أصغر من الحجم المحدد هنا، فستظهر في المنتصف ومحاطة بحد أبيض على الورقة. إذا كانت صورة الإدخال أكبر، فستظهر في المنتصف وسيتم اقتصاص الحواف. قد يكون هذا الخيار مفيدًا أيضًا للحصول على صور إخراج ذات حجم منتظم إذا اختلفت أحجام صور الإدخال. يمكن استخدام أسماء أحجام قياسية مثل a4-landscape، letter، إلخ (انظر --size). (الافتراضي: كما في ملف الإدخال)
--sheet-background { أسود \| أبيض }
يعين لونًا يتم ملء الورقة به قبل تحميل أي صورة ووضعها عليها. قد يكون هذا مفيدًا عندما يختلف حجم الورقة عن حجم الصورة.
--no-blackfilter نطاق-الورقة
تعطيل مسح المنطقة السوداء. يمكن تحديد مؤشرات أوراق فردية.
--no-noisefilter نطاق-الورقة
تعطيل مرشح الضوضاء. يمكن تحديد مؤشرات أوراق فردية.
--no-blurfilter نطاق-الورقة
تعطيل مرشح التمويه. يمكن تحديد مؤشرات أوراق فردية.
--no-grayfilter نطاق-الورقة
تعطيل المرشح الرمادي. يمكن تحديد مؤشرات أوراق فردية.
--no-mask-scan نطاق-الورقة
تعطيل اكتشاف القناع. تظل الأقنعة المحددة صراحة بواسطة --mask سارية المفعول. يمكن تحديد مؤشرات أوراق فردية.
--no-mask-center نطاق-الورقة
تعطيل التوسيط التلقائي لكل قناع. يتم إجراء التوسيط التلقائي افتراضيًا إذا تم تعيين الخيار --layout. يمكن تحديد مؤشرات أوراق فردية.
--no-deskew نطاق-الورقة
تعطيل تسوية الانحراف. يمكن تحديد مؤشرات أوراق فردية.
--no-wipe نطاق-الورقة
تعطيل مناطق المسح الصريحة. هذا يعني أنه يمكن تعطيل تأثير المعلمة --wipe بشكل فردي لكل ورقة.
--no-border نطاق-الورقة
تعطيل الحدود المحددة صراحة. هذا يعني أنه يمكن تعطيل تأثير المعلمة --border بشكل فردي لكل ورقة.
--no-border-scan نطاق-الورقة
تعطيل مسح الحدود من حواف الورقة. يمكن تحديد مؤشرات أوراق فردية.
--no-border-align نطاق-الورقة
تعطيل محاذاة المنطقة المكتشفة بواسطة مسح الحدود (انظر --border-align). يمكن تحديد مؤشرات أوراق فردية.
-n نطاق-الورقة؛ --no-processing نطاق-الورقة
عدم إجراء أي معالجة على ورقة باستثناء التدوير والمرآة المسبق/اللاحق، وتحويلات عمق الملف عند الحفظ. هذا الخيار له نفس تأثير تعيين جميع خيارات --no-xxx معًا. يمكن تحديد مؤشرات أوراق فردية.
--interpolate { أقرب \| خطي \| تكعيبي }
تعيين وظيفة الاستيفاء المستخدمة لتسوية الانحراف والتمدد. يوفر الخيار cubic أفضل جودة للصورة، بينما nearest هو الأسرع. (الافتراضي: cubic)
--no-multi-pages
تعطيل معالجة الصفحات المتعددة حتى لو كان اسم ملف الإدخال يحتوي على % (يشير عادةً إلى بداية عنصر نائب لعداد الصفحة).
--dpi dpi
نقطة في البوصة المستخدمة لتحويل قيم الحجم المقاسة، مثل على سبيل المثال 21cm,27.9cm. لاحظ أن هذه المعلمة يجب أن تظهر قبل تحديد أي قيمة حجم لاحقة بالقياس. (الافتراضي: 300)
-t { pbm \| pgm \| ppm }; --type { pbm \| pgm> \| ppm }
نوع ملف الإخراج (وعمق البت). إذا لم يتم تحديده، فسيتم استخدام النوع الذي له نفس تنسيق البكسل، أو الأقرب، لملفات الإدخال الأصلية.
pbm
Portable Bit Map، صورة خام أحادية اللون.
pgm
Portable Grayscale Map، صورة خام تدرج رمادي 8 بت لكل بكسل.
ppm
Portable Pixel Map، صورة خام RGB 24 بت لكل بكسل.
-T ; --test-only
لا تكتب أي مخرجات. قد يكون مفيدًا بالاقتران مع --verbose للحصول على معلومات حول الإدخال.
-si nr; --start-input nr
تعيين رقم الصفحة الأولى للاستبدال بـ '%d' في أسماء ملفات الإدخال. في كل مرة يتم فيها تكرار تسلسل ملفات الإدخال، يتم زيادة هذا الرقم بمقدار 1. (الافتراضي: (startsheet-1)*inputpages+1)
-so nr; --start-output nr
تعيين رقم الصفحة الأولى للاستبدال بـ '%d' في أسماء ملفات الإخراج. في كل مرة يتم فيها تكرار تسلسل ملفات الإخراج، يتم زيادة هذا الرقم بمقدار 1. (الافتراضي: (startsheet-1)*outputpages+1)
--insert-blank nr [,nr...]
استخدام إدخال فارغ بدلاً من ملف إدخال من تسلسل ملفات الإدخال في مواضع الفهرس المحددة. سيتم مقاطعة تسلسل ملفات الإدخال مؤقتًا وسيستمر مع ملف الإدخال التالي بعد ذلك. يمكن أن يكون هذا مفيدًا لإدراج محتوى فارغ في تسلسل صور الإدخال.
--replace-blank nr [,nr...]
مثل --insert-blank، ولكن يتم استبدال صور الإدخال في مواضع الفهرس المحددة بمحتوى فارغ وبالتالي سيتم تجاهلها.
--overwrite
السماح بالكتابة فوق الملفات الموجودة. وإلا، سينتهي البرنامج بخطأ إذا كان ملف إخراج سيتم كتابته موجودًا بالفعل.
-q ; --quiet
وضع هادئ، لا يوجد إخراج على الإطلاق.
-v ; --verbose
إخراج مطول، المزيد من رسائل المعلومات.
-vv
إخراج أكثر تفصيلاً، عرض إعدادات المعلمات قبل المعالجة.
-V ; --version
معلومات إصدار الإنتاج والبناء.
