uncrustify(1)

الحزمة: uncrustify

التراخيص: GPL-2.0-only

UNCRUSTIFY(1) أوامر المستخدم UNCRUSTIFY(1)

الاسم

uncrustify - مُنسّق الشيفرة المصدرية بلغات C، C++، C#، D، Java و Pawn

الخلاصة

uncrustify [خيارات] [ملفات]

الوصف

إذا لم يتم تحديد أي ملفات إدخال، يتم قراءة الإدخال من stdin.
إذا كنت تقرأ من stdin، يجب عليك تحديد اللغة باستخدام -l.

إذا تم استخدام -F أو تم تحديد الملفات في سطر الأوامر، فإن اسم ملف الإخراج هو PFX + "/" + اسم الملف + SFX.
ما لم، بالطبع، يتم استخدام الخيارات --replace أو --no-backup.

عند القراءة من stdin أو معالجة ملف واحد عبر الخيار '-f'، يتم إخراج المخرجات إلى stdout، ما لم يتم إعادة توجيهها باستخدام -o FILE.

يتم دائمًا إخراج الأخطاء إلى stderr

الخيارات

خيارات أساسية:

-c CFG
استخدم ملف الإعدادات CFG، أو الافتراضيات إذا تم تعيين CFG إلى '-'.
إذا لم يتم تحديده، سيستخدم uncrustify $UNCRUSTIFY_CONFIG أو $HOME/.uncrustify.cfg.
-f FILE
معالجة الملف الفردي FILE، وإرسال المخرجات إلى stdout أو الملف المحدد باستخدام -o.
-o FILE
إعادة توجيه المخرجات إلى FILE.
استخدم مع -f، --update-config، --update-config-with-doc، --universalindent.
--check
لا تقم بإخراج النص الجديد، بدلاً من ذلك تحقق من عدم حدوث أي تغييرات عند معالجة الملفات. يتم طباعة حالة كل ملف إلى stderr. رمز الخروج هو EXIT_SUCCESS إذا لم تكن هناك تغييرات، و EXIT_FAILURE بخلاف ذلك.
-F FILE
قراءة الملفات المراد معالجتها من FILE، اسم ملف واحد لكل سطر. إذا كان FILE هو ´-´ فقم بقراءة أسماء الملفات من الإدخال القياسي بدلاً من ملف.
يمكنك إنشاء هذا الملف باستخدام شيء مثل ´find . -name "*.c" > list.txt´.
لا يمكن دمج هذا مع -f.
--prefix PFX
إضافة PFX إلى مسار اسم ملف الإخراج.
لا يمكن دمج هذا مع -f، --replace، أو --no-backup.
--suffix SFX
إلحاق SFX باسم ملف الإخراج.
الافتراضي هو '.uncrustify' إذا لم يتم تحديد SFX أو PFX.
لا يمكن دمج هذا مع -f، --replace، أو --no-backup.
--frag
افترض أن الإدخال عبارة عن جزء شيفرة وأن السطر الأول مُزاح بشكل صحيح.
--replace
استبدال ملفات المصدر (ينشئ نسخة احتياطية).
لا يمكن دمج هذا مع -f، --prefix، أو --suffix.
--no-backup
استبدال الملفات، بدون نسخة احتياطية. مفيد إذا كانت الملفات تحت سيطرة المصدر.
لا يمكن دمج هذا مع -f، --prefix، أو --suffix.
--if-changed
الكتابة إلى stdout (أو إنشاء ملف الإخراج FILE) فقط إذا تم اكتشاف تغيير.
--mtime
الحفاظ على وقت التعديل (mtime) على الملفات المستبدلة.
-l
تجاوز اللغة: C، CPP، D، CS، JAVA، PAWN، VALA، OC، OC+
-t
تحميل ملف بالأنواع (عادة غير مطلوب)
-q
وضع هادئ - لا مخرجات على stderr (-L سيحل محل هذا)

خيارات الإعداد/المساعدة:

-h -? --help --usage
طباعة هذه الرسالة والخروج
--version
طباعة الإصدار والخروج
--count-options
طباعة عدد الخيارات المتاحة والخروج
--show-config
طباعة توثيق الخيارات والخروج
--update-config
إخراج ملف إعدادات جديد.
--update-config-with-doc
إخراج ملف إعدادات جديد مع تعليقات توضيحية مضمنة.
--universalindent
إخراج ملف إعدادات لواجهة Universal Indent الرسومية.
--detect
يكتشف الإعدادات من ملف مصدر. استخدم مع '-f FILE'. الاكتشاف محدود حاليًا إلى حد ما.
--tracking space:FILE
إعداد معلومات تتبع المساحة لأغراض التصحيح.
--tracking nl:FILE
إعداد معلومات تتبع سطر جديد لأغراض التصحيح.
--tracking start:FILE
إعداد معلومات تتبع بداية الجملة لأغراض التصحيح. لا يمكن استخدامه مع الخيار -o.

خيارات التصحيح:

-p FILE
إخراج معلومات التصحيح إلى FILE، أو إلى stdout إذا تم تعيين FILE إلى '-'.
يجب استخدامه بالاشتراك مع '-f FILE'.
-ds FILE --dump-steps FILE
إخراج معلومات التحليل في لحظات مختلفة من عملية التنسيق.
ينشئ هذا سلسلة من الملفات المسماة 'FILE_nnn.log'، كل منها
يقابل خطوة تنسيق في uncrustify.
الملف 'FILE_000.log' يسرد خيارات التنسيق قيد الاستخدام.
يجب استخدامه بالاشتراك مع '-f FILE'.
-L SEV
تعيين مستوى الخطورة للسجل (انظر log_levels.h)
-s
إظهار مستوى الخطورة للسجل في السجلات
--decode FLAG
طباعة FLAG كنص والخروج

أمثلة

قراءة ملف D من stdin، الإخراج إلى stdout.
cat foo.d | uncrustify -q -c my.cfg -l d
معالجة ملف، الإخراج إلى stdout.
uncrustify -c my.cfg -d foo.d
معالجة شجرة مصادر، الإخراج إلى شجرة أخرى.
find src -name "*.[ch]" > files.txt
uncrustify -c my.cfg -F files.txt --prefix out
معالجة شجرة مصادر في المكان.
uncrustify -c my.cfg --no-backup $(find src -name "*.[ch]")

ملاحظات

استخدم التعليقات التي تحتوي على ' *INDENT-OFF*' و ' *INDENT-ON*' لتعطيل معالجة أجزاء من ملف المصدر.
