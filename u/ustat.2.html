ustat(2) دليل استدعاءات النظام ustat(2)

الاسم

ustat - الحصول على إحصائيات نظام الملفات

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <sys/types.h>
#include <unistd.h>    /* libc[45] */
#include <ustat.h>     /* glibc2 */
[[deprecated]] int ustat(dev_t dev, struct ustat *ubuf);

الوصف

يقوم ustat() بإرجاع معلومات حول نظام ملفات مثبت. dev هو رقم جهاز يحدد جهازًا يحتوي على نظام ملفات مثبت. ubuf هو مؤشر إلى بنية ustat تحتوي على الأعضاء التالية:


daddr_t f_tfree;      /* إجمالي الكتل الحرة */
ino_t   f_tinode;     /* عدد الـ inodes الحرة */
char    f_fname[6];   /* اسم نظام الملفات */
char    f_fpack[6];   /* اسم حزمة نظام الملفات */

الحقلان الأخيران، f_fname و f_fpack، غير مطبقين وسيتم ملؤهما دائمًا بالبايتات الفارغة ('\0').

قيمة الإرجاع

عند النجاح، يتم إرجاع الصفر وسيتم ملء بنية ustat التي يشير إليها ubuf. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno لتوضيح الخطأ.

الأخطاء

EFAULT
يشير ubuf خارج مساحة العنوان القابلة للوصول الخاصة بك.
EINVAL
dev لا يشير إلى جهاز يحتوي على نظام ملفات مثبت.
ENOSYS
نظام الملفات المثبت المشار إليه بواسطة dev لا يدعم هذه العملية، أو أي إصدار من Linux قبل Linux 1.3.16.

المعايير

لا شيء.

التاريخ

SVr4. تمت إزالته في glibc 2.28.

ustat() يعتبر مهملًا وقد تم توفيره فقط للتوافق. يجب على جميع البرامج الجديدة استخدام statfs(2) بدلاً من ذلك.

ملاحظات HP-UX

إصدار HP-UX من بنية ustat لديه حقل إضافي، f_blksize، وهو غير معروف في أماكن أخرى. تحذر HP-UX: بالنسبة لبعض أنظمة الملفات، لا يتغير عدد الـ inodes الحرة. سترجع هذه الأنظمة -1 في الحقل f_tinode. بالنسبة لبعض أنظمة الملفات، يتم تخصيص الـ inodes ديناميكيًا. سترجع هذه الأنظمة العدد الحالي للـ inodes الحرة.
