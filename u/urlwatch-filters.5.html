urlwatch-filters(5)

الحزمة: urlwatch

التراخيص: BSD-3-Clause

URLWATCH-FILTERS(5) توثيق urlwatch URLWATCH-FILTERS(5)

اسم

urlwatch-filters - تصفية مخرجات وبيانات الفروقات لمهام urlwatch

ملخص

urlwatch --edit

الوصف

يمكن لكل مهمة أن تحتوي على مرحلتي تصفية معدتين، مع معالجة مرشح واحد أو أكثر بعد بعضها البعض:

  • يطبق على الصفحة التي تم تنزيلها قبل مقارنة التغييرات (filter)
  • يطبق على نتيجة المقارنة قبل الإبلاغ عن التغييرات (diff_filter)

أثناء إنشاء خط أنابيب التصفية الخاص بك، قد ترغب في معاينة شكل المخرجات المصفاة. يمكنك القيام بذلك عن طريق تكوين مهمتك أولاً ثم تشغيل urlwatch باستخدام الأمر --test-filter، مع تمرير الفهرس (من --list) أو عنوان URL/موقع المهمة المراد اختبارها:

urlwatch --test-filter 1   # اختبار المهمة الأولى في القائمة
urlwatch --test-filter https://example.net/  # اختبار المهمة بعنوان URL المحدد

سيكون ناتج هذا الأمر هو النص العادي المصفى للمهمة، وهذا هو الناتج الذي سيكون (في تشغيل urlwatch حقيقي) مدخلًا لخوارزمية المقارنة.

يتم تطبيق filter فقط على المحتوى الجديد، وتم تصفية المحتوى القديم بالفعل عند استرجاعه. هذا يعني أن التغييرات في filter غير مرئية عند الإبلاغ عن المحتويات غير المتغيرة (انظر Display لمزيد من التفاصيل)، وسيكون ناتج المقارنة بين (المحتوى القديم مع المرشح وقت استرجاع المحتوى القديم) و (المحتوى الجديد مع المرشح الحالي).

بمجرد جمع urlwatch لقطتيين تاريخيتين على الأقل لمهمة (حالتين مختلفتين لصفحة ويب) يمكنك استخدام الخيار في سطر الأوامر --test-diff-filter لاختبار إعدادات diff_filter الخاصة بك؛ سيستخدم هذا بيانات تاريخية مخزنة محليًا.

مرشحات مدمجة

يمكن استرداد قائمة المرشحات المدمجة باستخدام:

urlwatch --features

في الوقت الحالي، المرشحات التالية مدمجة:

  • beautify: تجميل HTML
  • css: تصفية XML/HTML باستخدام محددات CSS
  • csv2text: تحويل CSV إلى نص عادي
  • element-by-class: الحصول على جميع عناصر HTML حسب الفئة
  • element-by-id: الحصول على عنصر HTML حسب المعرف الخاص به
  • element-by-style: الحصول على جميع عناصر HTML حسب النمط
  • element-by-tag: الحصول على عنصر HTML حسب العلامة الخاصة به
  • format-json: تحويل إلى JSON منسق
  • grep: تصفية الأسطر التي تطابق تعبيرًا عاديًا فقط
  • grepi: إزالة الأسطر التي تطابق تعبيرًا عاديًا
  • hexdump: تحويل البيانات الثنائية إلى تنسيق التفريغ السداسي عشري
  • html2text: تحويل HTML إلى نص عادي
  • pdf2text: تحويل PDF إلى نص عادي
  • pretty-xml: طباعة XML بشكل جميل
  • ical2text: تحويل iCalendar https://en.wikipedia.org/wiki/ICalendar إلى نص عادي
  • ocr: تحويل النص في الصور إلى نص عادي باستخدام Tesseract OCR
  • re.sub: استبدال النص بتعبيرات عادية باستخدام re.sub الخاص بـ Python
  • re.findall: البحث عن جميع المطابقات غير المتداخلة باستخدام re.findall الخاص بـ Python
  • reverse: عكس عناصر الإدخال
  • sha1sum: حساب تلخيص SHA-1 للمحتوى
  • shellpipe: تصفية باستخدام أمر shell
  • sort: فرز عناصر الإدخال
  • remove-duplicate-lines: إزالة الأسطر المكررة (حساسة لحالة الأحرف)
  • strip: إزالة المسافات البيضاء البادئة واللاحقة
  • striplines: إزالة المسافات البيضاء البادئة واللاحقة في كل سطر
  • xpath: تصفية XML/HTML باستخدام تعبيرات XPath
  • jq: تصفية وتحويل واستخراج القيم من JSON

اختيار العناصر من صفحة ويب

يمكنك اختيار عنصر HTML معين فقط باستخدام المرشح المدمج، على سبيل المثال لاستخراج <div id="something">.../<div> من صفحة، يمكنك استخدام ما يلي في urls.yaml الخاص بك:

url: http://example.org/idtest.html
filter:
  - element-by-id: something

أيضًا، يمكنك ربط المرشحات، لذلك يمكنك تشغيل html2text على النتيجة:

url: http://example.net/id2text.html
filter:
  - element-by-id: something
  - html2text

ربط مرشحات متعددة

يعرض مثال ملف urls.yaml أيضًا استخدام المرشحات المدمجة، هنا يتم استخدام 3 مرشحات: html2text، line-grep، وإزالة المسافات البيضاء للحصول على حقل معلومات معين فقط من صفحة ويب:

url: https://example.net/version.html
filter:
  - html2text
  - grep: "Current.*version"
  - strip

استخراج علامة <BODY> فقط من صفحة

إذا كنت ترغب في استخراج علامة الجسم فقط، يمكنك استخدام هذا المرشح:

url: https://example.org/bodytag.html
filter:
  - element-by-tag: body

التصفية بناءً على تعبير XPath

للتصفية بناءً على تعبير XPath https://www.w3.org/TR/1999/REC-xpath-19991116/، يمكنك استخدام مرشح xpath كما يلي:

url: https://example.net/xpath.html
filter:
  - xpath: /html/body/marquee

هذا يقوم بتصفية عناصر <marquee> فقط الموجودة مباشرة أسفل العنصر <body>، والذي بدوره يجب أن يكون أسفل العنصر <html> من المستند، مع إزالة كل شيء آخر.

راجع صفحة أمثلة XPath الخاصة بشركة Microsoft https://msdn.microsoft.com/en-us/library/ms256086(v=vs.110).aspx للحصول على بعض الأمثلة الأخرى. يمكنك أيضًا العثور على XPath لعقدة <html> في أدوات مطوري Chromium/Google Chrome بالنقر بزر الماوس الأيمن على العقدة واختيار نسخ XPath.

التصفية بناءً على محددات CSS

للتصفية بناءً على محدد CSS https://www.w3.org/TR/2011/REC-css3-selectors-20110929/، يمكنك استخدام مرشح css كما يلي:

url: https://example.net/css.html
filter:
  - css: ul#groceries > li.unchecked

هذا سيقوم بتصفية علامات <li class="unchecked"> فقط الموجودة مباشرة أسفل عناصر <ul id="groceries">.

توجد بعض القيود والإضافات كما هو موضح في توثيق cssselect https://cssselect.readthedocs.io/en/latest/#supported-selectors.

استخدام مرشحات XPath و CSS مع XML والاستثناءات

بشكل افتراضي، تم إعداد مرشحات XPath و CSS للمستندات HTML. ومع ذلك، من الممكن استخدامها لمستندات XML أيضًا (تقوم هذه الأمثلة بتحليل موجز RSS وتصفية العناوين وتواريخ النشر فقط):

url: https://example.com/blog/xpath-index.rss
filter:
  - xpath:
      path: '//item/title/text()|//item/pubDate/text()'
      method: xml
url: http://example.com/blog/css-index.rss
filter:
  - css:
      selector: 'item > title, item > pubDate'
      method: xml
  - html2text: re

لمطابقة عنصر في نطاق XML https://www.w3.org/TR/xml-names/، استخدم بادئة نطاق قبل اسم العلامة. استخدم : لفصل

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.
