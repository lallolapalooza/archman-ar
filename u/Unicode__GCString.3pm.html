Unicode__GCString(3pm)

الحزمة: perl-unicode-linebreak

التراخيص: PerlArtistic, GPL

Unicode::GCString(3) وثائق بيرل المساهمة من قبل المستخدم Unicode::GCString(3)

الاسم

Unicode::GCString - سلسلة نصية كسلسلة من كتل الأحرف الرسومية (Grapheme Clusters) UAX #29

الملخص

use Unicode::GCString;
$gcstring = Unicode::GCString->new($string);

الوصف

يعامل Unicode::GCString السلسلة النصية يونيكود كسلسلة من كتل الأحرف الرسومية الممتدة (extended grapheme clusters) كما هو معرف في الملحق القياسي ليونيكود #29 [UAX #29].

كتلة الأحرف الرسومية (Grapheme cluster) هي سلسلة من حرف (أو أكثر) من يونيكود تتكون من قاعدة أحرف رسومية (grapheme base) واحدة و ملحق أحرف رسومية (grapheme extender) اختياري و/أو حرف “بادئة” (“prepend” character). وهي قريبة مما يعتبره الناس حرفًا.

الواجهة العامة

المنشئات

new (STRING, [KEY => VALUE, ...])
new (STRING, [LINEBREAK])
المنشئ. إنشاء سلسلة كتل أحرف رسومية جديدة (كائن Unicode::GCString) من سلسلة يونيكود STRING.

بخصوص أزواج KEY => VALUE الاختيارية، انظر "Options" في Unicode::LineBreak. في الصيغة الثانية، يتحكم كائن Unicode::LineBreak LINEBREAK في ميزات التقسيم.

ملاحظة: تم تقديم الصيغة الأولى في الإصدار 2012.10.

copy
منشئ النسخ. إنشاء نسخة من سلسلة كتل الأحرف الرسومية. يتم تعيين الموضع التالي للسلسلة الجديدة في البداية.

الأحجام

chars
طريقة مثيل. تُرجع عدد أحرف يونيكود التي تشملها سلسلة كتل الأحرف الرسومية، أي الطول كسلسلة يونيكود.
columns
طريقة مثيل. تُرجع العدد الإجمالي لأعمدة كتل الأحرف الرسومية المعرفة بواسطة قاعدة بيانات الأحرف المدمجة. لمزيد من التفاصيل، انظر "DESCRIPTION" في Unicode::LineBreak.
length
طريقة مثيل. تُرجع عدد كتل الأحرف الرسومية الموجودة في سلسلة كتل الأحرف الرسومية.

العمليات كسلسلة نصية

as_string
"""OBJECT"""
طريقة مثيل. تحويل سلسلة كتل الأحرف الرسومية إلى سلسلة يونيكود بشكل صريح.
cmp (STRING)
STRING "cmp" STRING
طريقة مثيل. مقارنة السلاسل النصية. لا توجد غرائب. قد يكون أحد كل STRING سلسلة يونيكود.
concat (STRING)
STRING "." STRING
طريقة مثيل. ربط السلاسل النصية. قد يكون أحد كل STRING سلسلة يونيكود. لاحظ أن عدد الأعمدة (انظر columns()) أو كتل الأحرف الرسومية (انظر length()) للسلسلة الناتجة ليس دائمًا يساوي مجموع السلسلتين. الموضع التالي للسلسلة الجديدة هو ذلك الذي تم تعيينه في القيمة اليسرى.
join ([STRING, ...])
طريقة مثيل. ربط السلاسل النصية مع إدخال سلسلة كتل الأحرف الرسومية. يمكن أن يكون أي من STRING سلسلة يونيكود.
substr (OFFSET, [LENGTH, [REPLACEMENT]])
طريقة مثيل. تُرجع جزءًا من سلسلة كتل الأحرف الرسومية. يعتمد OFFSET و LENGTH على كتل الأحرف الرسومية. إذا تم تحديد REPLACEMENT، يتم استبدال الجزء الفرعي بها. قد يكون REPLACEMENT سلسلة يونيكود.

ملاحظة: لا يمكن لهذه الطريقة إرجاع lvalue، على عكس substr() المدمجة.

العمليات كسلسلة من كتل الأحرف الرسومية

as_array
"@{"OBJECT"}"
as_arrayref
طريقة مثيل. تحويل سلسلة كتل الأحرف الرسومية إلى مصفوفة من كتل الأحرف الرسومية.
eos
طريقة مثيل. اختبار ما إذا كان الموضع الحالي في نهاية سلسلة كتل الأحرف الرسومية.
item ([OFFSET])
طريقة مثيل. تُرجع كتلة الأحرف الرسومية ذات الفهرس OFFSET. إذا لم يتم تحديد OFFSET، فإنها تُرجع كتلة الأحرف الرسومية التالية.
next
"<"OBJECT">"
طريقة مثيل، تكرارية. تُرجع كتلة الأحرف الرسومية التالية وتزيد الموضع التالي.
pos ([OFFSET])
طريقة مثيل. إذا تم تحديد OFFSET الاختياري، يتم تعيين الموضع التالي بواسطته. تُرجع الموضع التالي لسلسلة كتل الأحرف الرسومية.

متفرقات

lbc
طريقة مثيل. تُرجع فئة تقسيم الأسطر (انظر Unicode::LineBreak) للحرف الأول من كتلة الأحرف الرسومية الأولى.
lbcext
طريقة مثيل. تُرجع فئة تقسيم الأسطر (انظر Unicode::LineBreak) لآخر ملحق أحرف رسومية لآخر كتلة أحرف رسومية. إذا لم تكن هناك ملحقات أحرف رسومية أو كانت فئتها CM، فسيتم إرجاع قيمة قاعدة الأحرف الرسومية الأخيرة.

تحذيرات

  • لا ينبغي الإشارة إلى كتلة الأحرف الرسومية باسم "grapheme" حتى لو فعل لاري ذلك.
  • على بيرل حول الإصدار 5.10.1، التحويل الضمني من كائن Unicode::GCString إلى سلسلة يونيكود في بعض الأحيان يمكن أن يسبب ارتباكًا في ذاكرة التخزين المؤقت "utf8_mg_pos_cache_update".

    على سبيل المثال، بدلاً من القيام بما يلي:

    $sub = substr($gcstring, $i, $j);

    قم بما يلي:

    $sub = substr("$gcstring", $i, $j);
$sub = substr($gcstring->as_string, $i, $j);
  • تقوم هذه الوحدة بتطبيق خوارزمية افتراضية لتحديد حدود كتل الأحرف الرسومية. آلية التخصيص لم يتم دعمها بعد.

Unicode::GCString(3pm)

NAME

Unicode::GCString - Determine character cell width for Unicode strings

SYNOPSIS 

use Unicode::GCString;

my $gcs = Unicode::GCString->new("abc\x{1100}def\x{304}ghi");
print $gcs->width, "\n"; # Prints 9
print $gcs->chars, "\n"; # Prints 9
print $gcs->strwidth, "\n"; # Prints 9
print $gcs->strchars, "\n"; # Prints 9

my $gcs2 = Unicode::GCString->new("abc\x{1100}def\x{304}ghi");
$gcs2->width_override(1, 2); # override the width of the 4th char (Han character) to be 2
print $gcs2->width, "\n"; # Prints 10
print $gcs2->chars, "\n"; # Prints 9
print $gcs2->strwidth, "\n"; # Prints 10
print $gcs2->strchars, "\n"; # Prints 9

my $gcs3 = Unicode::GCString->new("abc\x{1100}def\x{304}ghi");
$gcs3->width_override(1, 0); # override the width of the 4th char (Han character) to be 0
print $gcs3->width, "\n"; # Prints 8
print $gcs3->chars, "\n"; # Prints 9
print $gcs3->strwidth, "\n"; # Prints 8
print $gcs3->strchars, "\n"; # Prints 9

my $gcs4 = Unicode::GCString->new("abc\x{1100}def\x{304}ghi");
$gcs4->width_override(3, 2); # override the width of the 7th char (Combining mark) to be 2
print $gcs4->width, "\n"; # Prints 10
print $gcs4->chars, "\n"; # Prints 9
print $gcs4->strwidth, "\n"; # Prints 10
print $gcs4->strchars, "\n"; # Prints 9

my $gcs5 = Unicode::GCString->new("abc\x{1100}def\x{304}ghi");
$gcs5->width_override(3, 0); # override the width of the 7th char (Combining mark) to be 0
print $gcs5->width, "\n"; # Prints 7
print $gcs5->chars, "\n"; # Prints 9
print $gcs5->strwidth, "\n"; # Prints 7
print $gcs5->strchars, "\n"; # Prints 9

DESCRIPTION

This module determines the character cell width for Unicode strings. It uses the Unicode Character Database (UCD) to determine the width of each character.

The width of a character is defined as the number of screen columns it occupies. Most characters occupy one column. However, some characters, like CJK ideographs, occupy two columns. Combining characters may occupy zero columns, but they are still counted as characters.

The module provides the following methods:

  • new(STRING): Creates a new Unicode::GCString object from the given string.
  • width(): Returns the total character cell width of the string.
  • chars(): Returns the number of characters in the string.
  • strwidth(): Returns the total character cell width of the string, respecting any overridden widths.
  • strchars(): Returns the number of characters in the string, respecting any overridden widths.
  • width_override(INDEX, WIDTH): Overrides the width of the character at the given index to the given width. The index is 0-based. If WIDTH is 0, the character is treated as a combining character.

CAVEATS

This module relies on the Unicode Character Database (UCD) to determine character widths. The UCD is updated periodically, so the widths of some characters may change over time.

The module does not handle bidirectional text (e.g., Arabic, Hebrew) or grapheme clusters. For more advanced text handling, consider using modules like Unicode::EastAsianWidth or Text::Grapheme.

This document describes version 0.01 of Unicode::GCString.
