unvis(3bsd)

الحزمة: libbsd

التراخيص: custom

unvis(3bsd) 3bsd unvis(3bsd)

الاسم

unvis، strunvis، strnunvis، strunvisx، strnunvisx — فك ترميز التمثيل البصري للأحرف

المكتبة

المكتبة «libbsd»

الملخص

#include <vis.h> (راجع libbsd(7) لمعرفة استخدام التضمين.)
int
unvis(char *cp, int c, int *astate, int flag);

int
strunvis(char *dst, const char *src);

int
strnunvis(char *dst, size_t dlen, const char *src);

int
strunvisx(char *dst, const char *src, int flag);

int
strnunvisx(char *dst, size_t dlen, const char *src, int flag);

الوصف

تُستخدم الدوال unvis()، strunvis() و strunvisx() لفك ترميز التمثيل البصري للأحرف، كما ينتج عن دالة vis(3bsd)، مرة أخرى إلى الشكل الأصلي.

يتم استدعاء الدالة unvis() بأحرف متتالية في c حتى يتم التعرف على تسلسل صالح، وعند هذه النقطة يكون الحرف الذي تم فك ترميزه متاحًا في الحرف الذي يشير إليه cp.

تقوم الدالة strunvis() بفك ترميز الأحرف التي يشير إليها src إلى المخزن المؤقت الذي يشير إليه dst. تقوم الدالة strunvis() ببساطة بنسخ src إلى dst، وفك ترميز أي تسلسلات هروب على طول الطريق، وتعيد عدد الأحرف التي تم وضعها في dst، أو -1 إذا تم اكتشاف تسلسل هروب غير صالح. يجب أن يكون حجم dst مساويًا لحجم src (أي، لا يحدث توسيع أثناء فك الترميز).

تقوم الدالة strunvisx() بنفس عمل الدالة strunvis()، ولكنها تسمح لك بإضافة علامة تحدد نمط التشفير الذي تم تشفير السلسلة src به. حاليًا، العلامات المدعومة هي: VIS_HTTPSTYLE و VIS_MIMESTYLE.

تنفذ الدالة unvis() آلة حالة يمكن استخدامها لفك ترميز تيار عشوائي من البايتات. يتم تخزين جميع الحالات المرتبطة بالبايتات التي يتم فك ترميزها خارج الدالة unvis() (أي، يتم تمرير مؤشر إلى الحالة)، لذا يمكن خلط استدعاءات فك ترميز التيارات المختلفة بحرية. لبدء فك ترميز تيار من البايتات، قم أولاً بتهيئة عدد صحيح إلى الصفر. قم باستدعاء unvis() مع كل بايت متتابع، بالإضافة إلى مؤشر إلى هذا العدد الصحيح، ومؤشر إلى حرف وجهة. تحتوي الدالة unvis() على العديد من رموز الإرجاع التي يجب التعامل معها بشكل صحيح. وهي:

0 (صفر)
يلزم وجود حرف آخر؛ لم يتم التعرف على شيء حتى الآن.
UNVIS_VALID
تم التعرف على حرف صالح وهو متاح في الموقع الذي يشير إليه cp.
UNVIS_VALIDPUSH
تم التعرف على حرف صالح وهو متاح في الموقع الذي يشير إليه cp؛ ومع ذلك، يجب تمرير الحرف الحالي مرة أخرى.
UNVIS_NOCHAR
تم اكتشاف تسلسل صالح، ولكن لم يتم إنتاج أي حرف. رمز الإرجاع هذا ضروري للإشارة إلى فاصل منطقي بين الأحرف.
UNVIS_SYNBAD
تم اكتشاف تسلسل هروب غير صالح، أو أن أداة فك الترميز في حالة غير معروفة. يتم وضع أداة فك الترميز في الحالة الأولية.

عند معالجة جميع البايتات في التيار، قم باستدعاء unvis() مرة أخرى مع تعيين العلامة إلى UNVIS_END لاستخراج أي حرف متبقي (يتم تجاهل الحرف الذي تم تمريره).

يُستخدم وسيطة flag أيضًا لتحديد نمط تشفير المصدر. إذا تم تعيينها إلى VIS_HTTPSTYLE أو VIS_HTTP1808، ستقوم unvis() بفك ترميز سلاسل URI كما هو محدد في RFC 1808. إذا تم تعيينها إلى VIS_HTTP1866، ستقوم unvis() بفك ترميز مراجع الكيانات ومراجع الأحرف الرقمية كما هو محدد في RFC 1866. إذا تم تعيينها إلى VIS_MIMESTYLE، ستقوم unvis() بفك ترميز سلاسل MIME Quoted-Printable كما هو محدد في RFC 2045. إذا تم تعيينها إلى VIS_NOESCAPE، فلن تقوم unvis() بفك ترميز الأحرف المقتبسة بـ «\».

يوضح جزء الكود التالي الاستخدام الصحيح لـ unvis().

int state = 0;
char out;

while ((ch = getchar()) != EOF) {
again:
	switch(unvis(&out, ch, &state, 0)) {
	case 0:
	case UNVIS_NOCHAR:
		break;
	case UNVIS_VALID:
		(void)putchar(out);
		break;
	case UNVIS_VALIDPUSH:
		(void)putchar(out);
		goto again;
	case UNVIS_SYNBAD:
		errx(EXIT_FAILURE, "Bad character sequence!");
	}
}
if (unvis(&out, '\0', &state, UNVIS_END) == UNVIS_VALID)
	(void)putchar(out);

الأخطاء

ستعيد الدوال strunvis()، strnunvis()، strunvisx()، و strnunvisx() القيمة -1 عند حدوث خطأ وتعيين errno إلى:

[EINVAL]
تم اكتشاف تسلسل هروب غير صالح، أو أن أداة فك الترميز في حالة غير معروفة.

بالإضافة إلى ذلك، يمكن للدالتين strnunvis() و strnunvisx() أيضًا تعيين errno عند حدوث خطأ إلى:

[ENOSPC]
لا توجد مساحة كافية لإجراء التحويل.
