منذ 4.03

type t

النوع الخاص بأحرف يونيكود.

يمثل قيمة من هذا النوع قيمة مفردة من يونيكود وهي رقم صحيح في النطاقات 0x0000 ... 0xD7FF أو 0xE000 ... 0x10FFFF.

val min : t

min هو U+0000.

val max : t

max هو U+10FFFF.

val bom : t

bom هو U+FEFF، حرف علامة ترتيب البايت (BOM).

منذ 4.06

val rep : t

rep هو U+FFFD، حرف الاستبدال.

منذ 4.06

val succ : t -> t

succ u هي القيمة المفردة التي تلي u في مجموعة قيم يونيكود المفردة.

يثير Invalid_argument إذا كان u هو Uchar.max.

val pred : t -> t

pred u هي القيمة المفردة التي تسبق u في مجموعة قيم يونيكود المفردة.

يثير Invalid_argument إذا كان u هو Uchar.min.

val is_valid : int -> bool

is_valid n تكون true إذا وفقط إذا كان n قيمة يونيكود مفردة (أي في النطاقات 0x0000 ... 0xD7FF أو 0xE000 ... 0x10FFFF).

val of_int : int -> t

of_int i هو i كحرف يونيكود.

يثير Invalid_argument إذا لم يكن i يفي بـ Uchar.is_valid.

val to_int : t -> int

to_int u هو u كرقم صحيح.

val is_char : t -> bool

is_char u تكون true إذا وفقط إذا كان u حرف OCaml latin1.

val of_char : char -> t

of_char c هو c كحرف يونيكود.

val to_char : t -> char

to_char u هو u كحرف OCaml latin1.

يثير Invalid_argument إذا لم يكن u يفي بـ Uchar.is_char.

val equal : t -> t -> bool

equal u u' هو u = u'.

val compare : t -> t -> int

compare u u' هو Stdlib.compare u u'.

val seeded_hash : int -> t -> int

seeded_hash seed u وظيفة تجزئة مُهيأة بنفس القيمة المخرجة من Hashtbl.seeded_hash. تسمح هذه الوظيفة بتمرير هذه الوحدة كوسيط للمُنشئ Hashtbl.MakeSeeded.

منذ 5.3

val hash : t -> int

وظيفة تجزئة غير مُهيأة بنفس القيمة المخرجة من Hashtbl.hash. تسمح هذه الوظيفة بتمرير هذه الوحدة كوسيط للمُنشئ Hashtbl.Make.

قبل 5.3 كان خوارزمية التجزئة مختلفة. استخدم Hashtbl.rebuild للجداول المخزنة التي استخدمت وظيفة التجزئة هذه.

أدوات ترميز UTF

type utf_decode

النوع الخاص بنتائج فك ترميز UTF. تمثل القيم من هذا النوع نتيجة محاولة فك ترميز يونيكود.

val utf_decode_is_valid : utf_decode -> bool

utf_decode_is_valid d تكون true إذا وفقط إذا كانت d تحمل فك ترميز صالح.

val utf_decode_uchar : utf_decode -> t

utf_decode_uchar d هو حرف يونيكود الذي تم فك ترميزه بواسطة d إذا كانت utf_decode_is_valid d هي true و Uchar.rep بخلاف ذلك.

val utf_decode_length : utf_decode -> int

utf_decode_length d هو عدد العناصر من المصدر التي تم استهلاكها بواسطة فك الترميز d. يكون هذا دائمًا موجبًا بشكل صارم وأصغر من أو يساوي 4. يعتمد نوع عناصر المصدر على المُفكك الفعلي؛ بالنسبة للمُفككات في المكتبة القياسية، تُعيد هذه الوظيفة دائمًا طولًا بالبايت.

val utf_decode : int -> t -> utf_decode

utf_decode n u هو فك ترميز UTF صالح لـ u الذي استهلك n عناصر من المصدر لفك الترميز. يجب أن يكون n موجبًا وأصغر من أو يساوي 4 (لا يتم التحقق من هذا بواسطة الوحدة).

val utf_decode_invalid : int -> utf_decode

utf_decode_invalid n هو فك ترميز UTF غير صالح استهلك n عناصر من المصدر لإحداث خطأ. يجب أن يكون n موجبًا وأصغر من أو يساوي 4 (لا يتم التحقق من هذا بواسطة الوحدة). يحمل فك الترميز الناتج Uchar.rep كحرف يونيكود الذي تم فك ترميزه.

val utf_8_decode_length_of_byte : char -> int

utf_8_decode_length_of_byte byte هو عدد البايتات، من 1 إلى Uchar.max_utf_8_decode_length، التي سيستهلكها فك ترميز UTF-8 صالح يبدأ بالبايت byte أو 0 إذا كان byte لا يمكن أن يبدأ فك ترميز صالح.

منذ 5.4

val max_utf_8_decode_length : int

max_utf_8_decode_length هو 4، وهو الحد الأقصى لعدد البايتات التي يمكن لفك ترميز UTF-8 صالح أو غير صالح استهلاكها.

منذ 5.4

val utf_8_byte_length : t -> int

utf_8_byte_length u هو عدد البايتات المطلوبة لترميز u في UTF-8.

val utf_16_byte_length : t -> int

utf_16_byte_length u هو عدد البايتات المطلوبة لترميز u في UTF-16.
