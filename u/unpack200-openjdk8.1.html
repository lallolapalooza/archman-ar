unpack200-openjdk8(1)

الحزمة: jre8-openjdk-headless

التراخيص: LicenseRef-Java

unpack200(1) أدوات نشر Java unpack200(1)

الاسم

unpack200 - يحول ملفًا مضغوطًا بواسطة pack200(1) إلى ملف JAR للنشر على الويب.

الملخص

unpack200 [ خيارات ] input-file JAR-file
خيارات
خيارات سطر الأوامر. انظر الخيارات.
input-file
اسم الملف المدخل، والذي يمكن أن يكون ملف gzip مضغوط بواسطة pack200 أو ملف pack200. يمكن أن يكون المدخل أيضًا ملف JAR تم إنتاجه بواسطة pack200(1) بمستوى جهد 0، وفي هذه الحالة يتم نسخ محتويات الملف المدخل إلى ملف JAR الناتج مع علامة Pack200.
JAR-file
اسم ملف JAR الناتج.

الوصف

الأمر unpack200 هو تطبيق أصلي يقوم بتحويل ملف مضغوط بواسطة pack200(1) إلى ملف JAR. مثال شائع للاستخدام يتبع. في المثال التالي، تم إنشاء الملف myarchive.jar من myarchive.pack.gz بالإعدادات الافتراضية للأمر unpack200.

unpack200 myarchive.pack.gz myarchive.jar

الخيارات

-Hvalue --deflate-hint=قيمة

يضبط الضغط ليكون true (صحيح)، false (خطأ)، أو keep (احتفاظ) على جميع الإدخالات داخل ملف JAR. الوضع الافتراضي هو keep. إذا كانت القيمة true أو false، فإن الخيار --deflate=hint يتجاوز السلوك الافتراضي ويضبط وضع الضغط على جميع الإدخالات داخل ملف JAR الناتج.
-r --remove-pack-file

يزيل ملف الحزمة المدخل.
-v --verbose

يعرض رسائل دنيا. مواصفات متعددة لهذا الخيار تعرض رسائل أكثر تفصيلاً.
-q --quiet

يحدد عملية هادئة بدون رسائل.
-lfilename --log-file=اسم الملف

يحدد ملف سجل يتم فيه تسجيل رسائل الإخراج.
-? -h --help

يطبع معلومات المساعدة حول أمر unpack200.
-V --version

يطبع معلومات الإصدار حول أمر unpack200.
-Jخيار

يمرر الخيار إلى آلة جافا الافتراضية (JVM)، حيث خيار هو أحد الخيارات الموصوفة في صفحة المرجع لمشغل تطبيقات جافا. على سبيل المثال، -J-Xms48m يضبط ذاكرة بدء التشغيل على 48 ميجابايت. انظر java(1).

ملاحظات

لا ينبغي الخلط بين هذا الأمر وأمر unpack. فهما منتجان منفصلان تمامًا.

مواصفات واجهة برمجة تطبيقات Java SE المتوفرة مع JDK هي السلطة العليا في حالة وجود تناقضات.

حالة الخروج

يتم إرجاع قيم الخروج التالية: 0 للإكمال الناجح، وقيمة أكبر من 0 عند حدوث خطأ.
