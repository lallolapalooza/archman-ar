upscli_set_default_connect_timeout(3)

الحزمة: nut

التراخيص: GPL-2.0-or-later AND GPL-3.0-or-later

UPSCLI_SET_DEFAULT_C(3) دليل NUT UPSCLI_SET_DEFAULT_C(3)

الاسم

upscli_set_default_connect_timeout - تكوين جانب وحدة upsclient للمدة الافتراضية لاتصالات البدء.

الملخص

        #include <upsclient.h>
        int upscli_set_default_connect_timeout(const char *secs);

الوصف

تقوم الدالة upscli_set_default_connect_timeout() بتعيين المدة الافتراضية الداخلية لوحدة upsclient لاتصال upscli_connect(3) من سلسلة نصية تمثل عددًا غير سالب من الأرقام العشرية (يتم تجاهل التحليل غير الصحيح ولا يعدل القيمة المخزنة سابقًا)، تعيين قيمة NULL للوسيطة يجعل المدة الافتراضية الداخلية 0 مما يعني الحظر إلى أجل غير مسمى (الافتراضي لـ NUT لهذه الطريقة لأكثر من 20 عامًا).

بينما يمكن استدعاء هذه الطريقة بشكل صريح، يوصى باستدعاء upscli_init_default_connect_timeout(3) للتعيين المتسق من عدد من المصادر ذات الأولويات المختلفة.

قيمة الإرجاع

تعيد الدالة upscli_set_default_connect_timeout() 0 عند النجاح (إما إذا كانت السلسلة النصية NULL وبالتالي تم تطبيق الافتراضي المدمج 0، أو إذا كان محتواها صحيحًا وتم تطبيق قيمته)، أو -1 في حالة حدوث خطأ (لم تكن السلسلة النصية NULL، ولم يكن محتواها صحيحًا - ليس رقمًا، سالبًا، إلخ).
