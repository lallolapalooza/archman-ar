UFFDIO_COPY(2const) UFFDIO_COPY(2const)

الاسم

UFFDIO_COPY - نسخ قطعة ذاكرة متصلة بشكل ذري في النطاق المسجل لـ userfault

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <linux/userfaultfd.h>  /* تعريف ثوابت UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, UFFDIO_COPY, struct uffdio_copy *argp);
#include <linux/userfaultfd.h>
struct uffdio_copy {
    __u64  dst;   /* وجه النسخ */
    __u64  src;   /* مصدر النسخ */
    __u64  len;   /* عدد البايتات المراد نسخها */
    __u64  mode;  /* أعلام تتحكم في سلوك النسخ */
    __s64  copy;  /* عدد البايتات التي تم نسخها، أو خطأ معكوس */
};

الوصف

نسخ قطعة ذاكرة متصلة بشكل ذري في النطاق المسجل لـ userfault وإيقاظ السلسلة المحظورة اختياريًا.

يمكن دمج القيمة التالية مع mode بت (bitwise) لتغيير سلوك عملية UFFDIO_COPY:

UFFDIO_COPY_MODE_DONTWAKE
لا توقظ السلسلة التي تنتظر حل خطأ الصفحة
UFFDIO_COPY_MODE_WP
نسخ الصفحة بإذن للقراءة فقط. هذا يسمح للمستخدم باعتراض الكتابة التالية إلى الصفحة، مما سيؤدي إلى حظر وإنشاء رسالة خطأ حماية كتابة أخرى. يستخدم هذا فقط عندما تكون كلا الوضعين UFFDIO_REGISTER_MODE_MISSING و UFFDIO_REGISTER_MODE_WP ممكّنين للنطاق المسجل.

يستخدم الحقل copy بواسطة النواة لإرجاع عدد البايتات التي تم نسخها بالفعل، أو خطأ (قيمة سلبية بنمط errno). الحقل copy هو للمخرجات فقط؛ لا تقرأه عملية UFFDIO_COPY.

قيمة الإرجاع

عند النجاح، يتم إرجاع 0. في هذه الحالة، تم نسخ المنطقة بأكملها.

عند حدوث خطأ، يتم إرجاع -1 ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EAGAIN
عدد البايتات التي تم نسخها (أي القيمة التي تم إرجاعها في الحقل copy) لا تساوي القيمة المحددة في الحقل len.
EINVAL
لم يكن dst أو len مضاعفًا لحجم صفحة النظام، أو أن النطاق المحدد بواسطة src و len أو dst و len كان غير صالح.
EINVAL
تم تحديد بت غير صالح في الحقل mode.
ENOENT (منذ Linux 4.11)
غيرت عملية الخطأ تخطيط الذاكرة الافتراضية الخاصة بها بشكل متزامن مع عملية UFFDIO_COPY معلقة.
ENOSPC (من Linux 4.11 حتى Linux 4.13)
خرجت عملية الخطأ في وقت عملية UFFDIO_COPY.
ESRCH (منذ Linux 4.13)
خرجت عملية الخطأ في وقت عملية UFFDIO_COPY.
