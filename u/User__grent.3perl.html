User::grent(3perl) دليل مبرمجي بيرل User::grent(3perl)

الاسم

User::grent - واجهة بالاسم لوظائف getgr*() المدمجة في بيرل

الملخص

use User::grent;
my $gr = getgrgid(0) or die "No group zero";
if ( $gr->name eq 'wheel' && @{$gr->members} > 1 ) {
    print "gid zero name wheel, with other members";
} 
use User::grent qw(:FIELDS);
getgrgid(0) or die "No group zero";
if ( $gr_name eq 'wheel' && @gr_members > 1 ) {
    print "gid zero name wheel, with other members";
} 
my $gr = getgr($whoever);

الوصف

تقوم الصادرات الافتراضية لهذه الوحدة بتجاوز وظائف getgrent() و getgrgid() و getgrnam() الأساسية، واستبدالها بنسخ ترجع كائنات "User::grent". هذا الكائن لديه طرق ترجع اسم حقل الهيكل المسمى بشكل مشابه من C's passwd structure من grp.h؛ وهي name, passwd, gid, و members (وليس mem). الثلاثة الأولى ترجع قيمًا ثابتة، والأخيرة مرجع مصفوفة.

يمكنك أيضًا استيراد جميع حقول الهيكل مباشرة إلى مساحة الأسماء الخاصة بك كمتغيرات عادية باستخدام علامة الاستيراد :FIELDS. (لاحظ أن هذا لا يزال يتجاوز وظائفك الأساسية.) قم بالوصول إلى هذه الحقول كمتغيرات تسمى ببادئة "gr_". وبالتالي، يتوافق "$group_obj->gid()" مع $gr_gid إذا قمت باستيراد الحقول. مراجع المصفوفات متاحة كمتغيرات مصفوفات عادية، لذا فإن "@{ $group_obj->members() }" سيكون ببساطة @gr_members.

وظيفة getgr() هي واجهة أمامية بسيطة تقوم بتمرير وسيط رقمي إلى getgrgid() والباقي إلى getgrnam().

للوصول إلى هذه الوظيفة دون تجاوزات أساسية، قم بتمرير "use" قائمة استيراد فارغة، ثم قم بالوصول إلى الوظائف الأساسية باستخدام أسمائها المؤهلة بالكامل. من ناحية أخرى، لا تزال الوظائف المدمجة متاحة عبر الحزمة الزائفة "CORE::".
