CUPGTR

الغرض:

!>
!> CUPGTR يولد مصفوفة وحدوية معقدة Q والتي تُعرّف كناتج لـ n-1 عاكسات أولية H(i) من الرتبة n، كما تم إرجاعه بواسطة
!> CHPTRD باستخدام تخزين مكدس:
!>
!> إذا كان UPLO = 'U'، فإن Q = H(n-1) . . . H(2) H(1)،
!>
!> إذا كان UPLO = 'L'، فإن Q = H(1) H(2) . . . H(n-1).
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          = 'U': تم استخدام تخزين المثلث العلوي المكدس في استدعاء
!>                 سابق لـ CHPTRD؛
!>          = 'L': تم استخدام تخزين المثلث السفلي المكدس في استدعاء
!>                 سابق لـ CHPTRD.
!>

N

!>          N هو صحيح
!>          رتبة المصفوفة Q. N >= 0.
!>

AP

!>          AP هي مصفوفة COMPLEX، dimension (N*(N+1)/2)
!>          المتجهات التي تحدد العاكسات الأولية، كما تم إرجاعه بواسطة
!>          CHPTRD.
!>

TAU

!>          TAU هي مصفوفة COMPLEX، dimension (N-1)
!>          يجب أن تحتوي TAU(i) على العامل القياسي للعاكس
!>          الأولي H(i)، كما تم إرجاعه بواسطة CHPTRD.
!>

Q

!>          Q هي مصفوفة COMPLEX، dimension (LDQ,N)
!>          المصفوفة الوحدوية Q بحجم N×N.
!>

LDQ

!>          LDQ هو صحيح
!>          البعد الرئيسي للمصفوفة Q. LDQ >= max(1,N).
!>

WORK

!>          WORK هي مصفوفة COMPLEX، dimension (N-1)
!>

INFO

!>          INFO هو صحيح
!>          = 0:  انتهاء ناجح
!>          < 0:  إذا كان INFO = -i، فإن الوسيط i كان له قيمة غير قانونية
!>

ZUPGTR(3)

NAME

ZUPGTR

generates a complex unitary matrix Q which is defined as the product of elementary reflectors

SYNOPSIS

 subroutine zupgtr (uplo, n, ap, tau, q, ldq, work, info)

 CHARACTER(1) uplo
 INTEGER n
 complex*16, dimension(:) ap
 complex*16, dimension(:) tau
 complex*16, dimension(:,:) q
 INTEGER ldq
 complex*16, dimension(:) work
 INTEGER info

Detailed Description

Purpose:

!>
!> ZUPGTR generates a complex unitary matrix Q which is defined as the
!> product of n-1 elementary reflectors H(i) of order n, as returned by
!> ZHPTRD using packed storage:
!>
!> if UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> if UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Parameters

UPLO

!>          UPLO is CHARACTER*1
!>          = 'U': Upper triangular packed storage used in previous
!>                 call to ZHPTRD;
!>          = 'L': Lower triangular packed storage used in previous
!>                 call to ZHPTRD.
!>

N

!>          N is INTEGER
!>          The order of the matrix Q. N >= 0.
!>

AP

!>          AP is COMPLEX*16 array, dimension (N*(N+1)/2)
!>          The vectors which define the elementary reflectors, as
!>          returned by ZHPTRD.
!>

TAU

!>          TAU is COMPLEX*16 array, dimension (N-1)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by ZHPTRD.
!>

Q

!>          Q is COMPLEX*16 array, dimension (LDQ,N)
!>          The N-by-N unitary matrix Q.
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of the array Q. LDQ >= max(1,N).
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (N-1)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
