77_GLOBAL

This macro is used to define Fortran-callable BLAS routines. The first argument is the C name of the routine, and the second argument is the Fortran name of the routine. The Fortran name is typically the C name with a 'F77_' prefix, but this may vary depending on the Fortran compiler and system. The `F77_GLOBAL` macro handles these variations.
