uname(1p)

NAME

uname — return system name

SYNOPSIS

uname [-aA] [-*-M] [-X]

DESCRIPTION

The uname utility writes information to standard output concerning the current system. Without options, the default is to print the operating system name. The behavior of uname is enhanced by the presence of the following options:

-s
Write the operating system name.
-n
Write the network node hostname.
-r
Write the operating system release.
-v
Write the operating system version.
-m
Write the machine hardware name.
-p
Write the processor type (if available). If not available, behavior is undefined.
-i
Write the hardware platform (if available). If not available, behavior is undefined.
-o
Write the operating system name.
-A
Write all of the above information.
-X
Write all of the above information, in the following order, separated by spaces:

operand system name, network node hostname, operating system release, operating system version, machine hardware name, processor type, hardware platform, operating system.

The IEEE POSIX Shell Command Language specification is the reference document for the uname utility. The standard is available online at http://www.opengroup.org/onlinepubs/9699919799/utilities/uname.html .
