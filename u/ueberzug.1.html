UEBERZUGPP(1) دليل الأوامر العامة UEBERZUGPP(1)

الاسم

ueberzugpp - عرض الصور في طرفية

الملخص

ueberzugpp [خيارات]

الوصف

ueberzugpp هو برنامج مخصص لعرض الصور في طرفية مع بروتوكول اتصال بين العمليات (IPC).

الخيارات

-h, --help
عرض نص المساعدة.
--version
عرض الإصدار
--use-escape-codes
استخدام رموز الهروب للحصول على قدرات الطرفية
--no-stdin
لا تستمع عبر الإدخال القياسي للأوامر
--no-cache
تعطيل التخزين المؤقت للصور المعاد تحجيمها
--no-opencv
لا تستخدم OpenCV، استخدم Libvips بدلاً منها
-o, --output
طريقة إخراج الصورة، القيم الصالحة لهذا تشمل:
x11 (قد لا يكون متاحًا إذا تم تعطيله عند الترجمة)
sixel
kitty
iterm2
wayland (قد لا يكون متاحًا إذا تم تعطيله عند الترجمة)
chafa
-p, --parser
غير مستخدم، موجود فقط للتوافق مع الإصدارات السابقة
-l, --loader
غير مستخدم، موجود فقط للتوافق مع الإصدارات السابقة

الإدخال القياسي

يقرأ Ueberzugpp الأوامر عبر الإدخال القياسي. أو عبر مقبس يونكس الموجود في /tmp/ueberzug_.sock

يجب أن تكون الأوامر بصيغة JSON، كما هو موضح في قسم JSON IPC

اتصال JSON IPC

هناك إجراءان: add (إضافة) و remove (إزالة)

إضافة

مخطط JSON للإجراء

المفاتيح المطلوبة


action (سلسلة نصية)
يجب أن تكون add
path (سلسلة نصية)
المسار إلى الصورة المراد استخدامها
identifier (سلسلة نصية)
معرف للصورة، بحيث يمكن إزالتها باستخدام إجراء الإزالة
واحد من، width/height، أو max_width/max_height
width (عدد صحيح)
عرض الصورة
max_width (عدد صحيح)
أقصى عرض للصورة
height (عدد صحيح)
ارتفاع الصورة
max_height (عدد صحيح)
أقصى ارتفاع للصورة
x (عدد صحيح)
موضع العمود في الطرفية
y (عدد صحيح)
موضع الصف في الطرفية

المفاتيح الاختيارية

scaler (سلسلة نصية)
يمكن أن يكون fit_contain أو forced_cover.
كلاهما يعتمد على القياس على أي منهما أكبر، عرض الصورة أو ارتفاعها

إزالة

مخطط JSON للإجراء

المفاتيح المطلوبة

action (سلسلة نصية)
يجب أن تكون remove
identifier (سلسلة نصية)
معرف الصورة المراد إزالتها

مثال

قم بإنشاء ملف fifo باسم fifo، واحتفظ بصورة في المجلد الحالي باسم image.png لكي يعمل هذا المثال

ueberzugpp layer -o sixel < fifo &

echo '{"path": "./image.png", "action": "add", "identifier": "image", "x": 0, "y": 0, "width": 20, "height": 20}' > fifo
