UUCP(1P) دليل مبرمجي POSIX UUCP(1P)

مقدمة

هذه الصفحة الدليلية هي جزء من دليل مبرمجي POSIX. قد يختلف تطبيق Linux لهذا الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة في Linux.

الاسم

uucp — نسخ النظام إلى النظام

الملخص

uucp [-cCdfjmr] [-n مستخدم] ملف-مصدر... ملف-وجهة

الوصف

تقوم الأداة المساعدة uucp بنسخ الملفات المسماة بواسطة الوسيط ملف-مصدر إلى الوسيط ملف-وجهة. يمكن أن تكون الملفات المسماة على أنظمة محلية أو بعيدة.

لا يمكن للأداة المساعدة uucp ضمان دعم جميع ترميزات الأحرف في جميع الظروف. على سبيل المثال، قد تكون بيانات الإرسال مقيدة بـ 7 بتات بواسطة الشبكة الأساسية، ولا يلزم أن تكون الملفات ذات 8 بتات وأسماء الملفات قابلة للنقل إلى الأنظمة غير المعولمة، وما إلى ذلك. في ظل هذه الظروف، يوصى باستخدام الأحرف المعرفة فقط في الإصدار المرجعي الدولي لمعيار ISO/IEC 646:1991 (المعادل لـ ASCII) في نطاق 7 بتات، واستخدام الأحرف المعرفة فقط في مجموعة أحرف أسماء الملفات القابلة للنقل. بروتوكول نقل الملفات غير محدد بواسطة POSIX.1-2008.

تتطلب التطبيقات النموذجية لهذه الأداة المساعدة خط اتصالات مهيأ لاستخدام مجلد التعريفات الأساسية لـ POSIX.1-2017، الفصل 11، واجهة الطرفيات العامة، ولكن قد يتم استخدام وسائل اتصالات أخرى. في الأنظمة التي لا توجد بها وسائل اتصالات متاحة (مؤقتًا أو دائمًا)، يجب على هذه الأداة كتابة رسالة خطأ تصف المشكلة والخروج بحالة خروج غير صفرية.

خيارات

يجب أن تتوافق الأداة المساعدة uucp مع مجلد التعريفات الأساسية لـ POSIX.1-2017، القسم 12.2، إرشادات بناء جملة الأداة.

يجب دعم الخيارات التالية:

-c
لا تقم بنسخ الملف المحلي إلى دليل التخزين المؤقت للنقل إلى الجهاز البعيد (الافتراضي).
-C
فرض نسخ الملفات المحلية إلى دليل التخزين المؤقت للنقل.
-d
قم بإنشاء جميع الدلائل اللازمة لنسخ الملف (الافتراضي).
-f
لا تقم بإنشاء الدلائل الوسيطة لنسخ الملف.
-j
اكتب سلسلة تعريف المهمة إلى الإخراج القياسي. يمكن استخدام هذا التعريف للمهمة بواسطة uustat للحصول على حالة المهمة أو إنهائها.
-m
أرسل بريدًا إلكترونيًا إلى الطالب عند اكتمال النسخ.
-n مستخدم
أبلغ مستخدم على النظام البعيد أنه تم إرسال ملف.
-r
لا تبدأ نقل الملف؛ فقط قم بوضع المهمة في قائمة الانتظار.

العوامل التشغيلية

يجب دعم العوامل التشغيلية التالية:

ملف-وجهة، ملف-مصدر

مسار لملف سيتم نسخه إليه، أو منه، على التوالي. يمكن أن يكون أي اسم مسارًا على الجهاز المحلي، أو يمكن أن يأخذ الشكل:
اسم-النظام!مسار-الملف

حيث اسم-النظام مأخوذ من قائمة بأسماء الأنظمة التي تعرفها uucp. يمكن أن يكون اسم-النظام للوجهة أيضًا قائمة بأسماء مثل:

اسم-النظام!اسم-النظام!...!اسم-النظام!مسار-الملف

في هذه الحالة، يتم محاولة إرسال الملف عبر المسار المحدد إلى الوجهة. يجب توخي الحذر للتأكد من أن العقد الوسيطة في المسار على استعداد لإعادة توجيه المعلومات.

سيتم توسيع أحرف نمط قشرة المطابقة '؟'، '*'، و "[]" في مسار-الملف على النظام المناسب.

يمكن أن تكون مسارات الملفات:

1.
مسار مطلق.
2.
مسار مسبوق بـ ~مستخدم حيث مستخدم هو اسم تسجيل دخول على النظام المحدد ويتم استبداله بدليل تسجيل دخول هذا المستخدم. لاحظ أنه إذا تم تحديد اسم تسجيل دخول غير صالح، فإن الافتراضي هو الدليل العام (يسمى PUBDIR؛ الموقع الفعلي لـ PUBDIR غير محدد في التطبيق).
3.
مسار مسبوق بـ ~/وجهة حيث يتم إلحاق وجهة بـ PUBDIR.
ملاحظة:
يتم التعامل مع هذه الوجهة كاسم ملف ما لم يتم نقل أكثر من ملف واحد بهذا الطلب أو إذا كانت الوجهة موجودة بالفعل كدليل. لضمان أنها دليل، اتبع الوجهة بـ '/'. على سبيل المثال، ~/dan/ كوجهة تنشئ الدليل PUBDIR/dan إذا لم يكن موجودًا وتضع الملفات المطلوبة في هذا الدليل.
4.
سيتم إضافة الدليل الحالي إلى أي شيء آخر.

إذا كانت النتيجة مسار ملف خاطئ للنظام البعيد، فسيفشل النسخ. إذا كانت ملف-وجهة دليلًا، فسيتم استخدام الجزء الأخير من اسم ملف-مصدر.

أذونات القراءة والكتابة والتنفيذ التي تمنحها uucp غير محددة في التطبيق.

متغيرات البيئة

يجب أن تؤثر متغيرات البيئة التالية على تنفيذ uucp:

LANG
قدم قيمة افتراضية لمتغيرات العولمة التي لم يتم تعيينها أو قيمتها فارغة. (راجع مجلد التعريفات الأساسية لـ POSIX.1-2017، القسم 8.2، متغيرات العولمة لمعرفة الأسبقية لمتغيرات العولمة المستخدمة لتحديد قيم فئات اللغة المحلية.)
LC_ALL
إذا تم تعيينها إلى قيمة سلسلة غير فارغة، فتجاوز قيم جميع متغيرات العولمة الأخرى.
LC_COLLATE

تحديد اللغة المحلية لسلوك النطاقات، وفئات التكافؤ، وعناصر التجميع متعددة الأحرف داخل أنماط أسماء الملفات المحاطة بأقواس.
LC_CTYPE
تحديد اللغة المحلية لتفسير تسلسلات البايتات من بيانات النص كأحرف (على سبيل المثال، أحرف أحادية البايت مقابل متعددة البايتات في الوسائط وملفات الإدخال) وسلوك فئات الأحرف داخل أنماط أسماء الملفات المحاطة بأقواس (على سبيل المثال، "['[:lower:]']* ").
LC_MESSAGES

تحديد اللغة المحلية التي يجب استخدامها للتأثير على تنسيق ومحتويات رسائل التشخيص المكتوبة إلى الخطأ القياسي، ورسائل المعلومات المكتوبة إلى الإخراج القياسي.
NLSPATH
تحديد موقع كتالوجات الرسائل لمعالجة LC_MESSAGES.

This manual page is a translation of the POSIX standard document for the uucp utility.

NAME

uucp - UUCP copy utility

SYNOPSIS

uucp [ -c ] [ -C ] [ -d ] [ -f ] [ -g grade ] [ -j ] [ -m ] [ -n user ] [ -r ] [ -s file ] [ -x debug_level ] from-file ... to-file

uucp [ -c ] [ -C ] [ -d ] [ -f ] [ -g grade ] [ -j ] [ -m ] [ -n user ] [ -r ] [ -s file ] [ -x debug_level ] file ... user@node

uucp [ -c ] [ -C ] [ -d ] [ -f ] [ -g grade ] [ -j ] [ -m ] [ -n user ] [ -r ] [ -s file ] [ -x debug_level ] node1!file1 ... node2!file2

DESCRIPTION

The uucp utility is used to copy files between directories on different machines using the UUCP (Unix-to-Unix Copy Program) system. UUCP provides a mechanism for transferring files and executing commands on remote systems.

The syntax for specifying files allows for local files, remote files, and files on intermediate nodes. A local filename is a standard pathname. A remote filename consists of a system name (node name), followed by an exclamation mark (!), followed by a pathname on that system. For example:

[system!]path
Specifies a file on the remote system named system.

When copying files, the source and destination arguments can be local or remote. The interpretation of a filename as local or remote depends on whether it contains an explicit node name. A filename is considered remote if it contains at least one '!' character separating system names from pathnames.

The source and destination can be a single file or multiple files. If the destination is a directory, all source files are copied into that directory, preserving their original filenames. If the destination is a filename, only a single source file can be specified.

Shell metacharacters in pathnames are expanded on the appropriate system. For example, if the source is remote, wildcard expansion (like `*') will occur on the remote system.

The UUCP system maintains a queue of work to be done. When uucp is invoked, it adds the copy request to this queue. A separate UUCP daemon process typically polls this queue periodically and performs the requested transfers and command executions.

OPTIONS

The uucp utility supports the following options:

-c
Do not invoke the uucp command on the remote system. This means that file access control is not performed on the remote system.
-C
Do not copy the file locally. If the file is not accessible on the remote system, the copy fails.
-d
Create destination directories as needed. If the destination directory does not exist, uucp will attempt to create it.
-f
Do not create destination directories. If the destination directory does not exist, the copy fails.
-g grade
Set the priority grade for the transfer. The grade is a single character, typically a digit from 0 to 9, where lower numbers indicate higher priority. The interpretation of grades is implementation-defined.
-j
Log the job ID of the transfer request to standard output. This ID can be used with the uustat command to check the status of the job.
-m
Send mail to the originator of the file when the copy is completed.
-n user
Notify the specified user on the destination system that a file has been received. This is typically done by sending a mail message.
-r
Do not transfer the file immediately. Instead, place the request in the UUCP queue to be processed later by the UUCP daemon.
-s file
Place a status report in the specified file on the local system. This report will contain information about the transfer, such as success or failure.
-x debug_level
Enable debugging output. The debug_level is a decimal integer. Higher values produce more detailed debugging information, which is typically written to standard error or a log file.

OPERANDS

The following operands are supported:

from-file
One or more source filenames. These can be local or remote. Wildcards are expanded on the system where the file resides.
to-file
The destination filename or directory. This can be local or remote. If it is a directory, the source files are copied into it.
file
A filename. Used with the -s option to specify a file for status reports.
user
A username. Used with the -n option to specify a user to be notified upon completion.
node
A system name. Used to specify remote systems in filenames.

STDIN

Not used.

INPUT FILES

The source files specified by the from-file operands.

ENVIRONMENT VARIABLES

The following environment variables affect the execution of uucp:

LC_COLLATE
Determine the collation sequence for filename expansion. See Collation in the Base Definitions volume of POSIX.1‐2017.
LC_CTYPE
Determine the locale for interpretation of sequences of bytes of that are treated as characters. See Internationalization in the Base Definitions volume of POSIX.1‐2017.
LC_MESSAGES
Determine the locale that should be used to write messages to standard error and standard output. See Internationalization in the Base Definitions volume of POSIX.1‐2017.
PATH
Determine the search path for commands invoked by uucp (e.g., for remote command execution). See Utility Search Path in the Base Definitions volume of POSIX.1‐2017.
SHELL
Determine the command interpreter used for remote command execution. If this variable is not set, /bin/sh is used.
UUCP_MAILER
Determine the mailer program to use for sending notification messages. If not set, a default mailer is used.

ASYNCHRONOUS EVENTS

Default.

STDOUT

If the -j option is specified, the job ID of the transfer request is written to standard output.

STDERR

The standard error is used for diagnostic messages and debugging output if the -x option is specified.

OUTPUT FILES

The destination files specified by the to-file operand. If the -s option is used, the specified file will contain status information about the transfer. The files specified by to-file (which may be on other systems) are copies of the input files.

If -m is used, mail files are modified.

EXTENDED DESCRIPTION

None.

EXIT STATUS

The following exit values shall be returned:

0
Successful completion.
>0
An error occurred.

CONSEQUENCES OF ERRORS

Default.

The following sections are informative.

APPLICATION USAGE

This utility is part of the UUCP Utilities option and need not be supported by all implementations.

The domain of remotely accessible files can (and for obvious security reasons usually should) be severely restricted.

Note that the '!' character in addresses has to be escaped when using csh as a command interpreter because of its history substitution syntax. For ksh and sh the escape is not necessary, but may be used.

As noted above, shell metacharacters appearing in pathnames are expanded on the appropriate system. On an internationalized system, this is done under the control of local settings of LC_COLLATE and LC_CTYPE. Thus, care should be taken when using bracketed filename patterns, as collation and typing rules may vary from one system to another. Also be aware that certain types of expression (that is, equivalence classes, character classes, and collating symbols) need not be supported on non-internationalized systems.
