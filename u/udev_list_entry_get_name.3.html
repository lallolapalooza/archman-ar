udev_list_entry_get_name(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

UDEV_LIST_ENTRY(3) udev_list_entry UDEV_LIST_ENTRY(3)

الاسم

udev_list_entry, udev_list_entry_get_next, udev_list_entry_get_by_name, udev_list_entry_get_name, udev_list_entry_get_value - التنقل والوصول إلى قوائم udev

المُلخص

#include <libudev.h>

struct udev_list_entry *udev_list_entry_get_next(struct udev_list_entry *list_entry);

struct udev_list_entry *udev_list_entry_get_by_name(struct udev_list_entry *list_entry, const char *name);

const char *udev_list_entry_get_name(struct udev_list_entry *list_entry);

const char *udev_list_entry_get_value(struct udev_list_entry *list_entry);

قيمة الإرجاع

عند النجاح، تُرجع udev_list_entry_get_next() و udev_list_entry_get_by_name() مؤشرًا إلى عنصر القائمة المطلوب. إذا لم يتم العثور على مثل هذا العنصر، أو عند الفشل، يتم إرجاع NULL.

عند النجاح، تُرجع udev_list_entry_get_name() و udev_list_entry_get_value() مؤشرًا إلى سلسلة نصية ثابتة تمثل القيمة المطلوبة. السلسلة النصية مرتبطة بعمر عنصر القائمة نفسه. عند الفشل، يتم إرجاع NULL.
