UPDMAP(1) أوامر المستخدم UPDMAP(1)

الاسم

updmap - إدارة خرائط خطوط TeX
updmap-sys - إدارة خرائط خطوط TeX، على مستوى النظام
updmap-user - إدارة خرائط خطوط TeX، لكل مستخدم

الملخص

updmap [-user|-sys] [خيار] ... [أمر]
updmap-user [خيار] ... [أمر]
updmap-sys [خيار] ... [أمر]

الوصف

updmap الإصدار r65932 (2023-02-19 21:49:48 +0100)

تحديث ملفات خرائط الخطوط الافتراضية المستخدمة بواسطة pdftex و dvipdfm(x) (pdftex.map)، dvips (psfonts.map)، واختياريًا pxdvi، كما يتم تحديده بواسطة جميع ملفات التكوين updmap.cfg (عادةً تلك التي تنتج عن تشغيل "kpsewhich --all updmap.cfg"، ولكن انظر أدناه).

من بين أمور أخرى، تُستخدم ملفات الخرائط هذه لتحديد الخطوط التي يجب استخدامها كخرائط نقطية (bitmaps) وأيها يجب استخدامها كخطوط خارجية (outlines)، ولتحديد ملفات الخطوط التي يتم تضمينها، وعادةً ما تكون مقسمة (subsetted)، في الإخراج بتنسيق PDF أو PostScript.

updmap-sys (أو updmap -sys) مخصص للتأثير على التكوين على مستوى النظام، بينما يؤثر updmap-user (أو updmap -user) على ملفات التكوين الشخصية فقط، متجاوزًا ملفات النظام.

ونتيجة لذلك، بمجرد تشغيل updmap-user، حتى لو لمرة واحدة، فإن تشغيل updmap-sys لم يعد له أي تأثير. يصدر updmap-sys تحذيرًا بشأن هذا، نظرًا لأنه نادرًا ما يكون مرغوبًا فيه. انظر https://tug.org/texlive/scripts-sys-user.html للحصول على التفاصيل.

بشكل افتراضي، يتم أيضًا تحديث قاعدة بيانات أسماء ملفات TeX (ls-R).

نظام updmap معقد للأسف، لأسباب جوهرية وتاريخية. نظرة عامة:

- ملفات updmap.cfg تتعلق بشكل أساسي بإدراج ملفات أخرى، وهي ملفات .maps الخاصة بالخطوط، حيث يعطي كل سطر معلومات حول خط TeX (.tfm) مختلف.

محتويات تلك الملفات .map في الملفات الرئيسية الناتجة: psfonts.map لـ dvips و pdftex.map لـ pdftex و dvipdfmx.

- يقوم updmap بقراءة ملفات updmap.cfg ثم يقوم بدمج

محتويات تلك الملفات .map في الملفات الرئيسية الناتجة: psfonts.map لـ dvips و pdftex.map لـ pdftex و dvipdfmx.

- يتم إنشاء ملفات updmap.cfg وتحديثها عند تثبيت الحزم،

في وقت تثبيت النظام أو بواسطة مدير الحزم أو يدويًا، وليس (افتراضيًا) بواسطة updmap.

--cnffile ملف
لقراءة الملف FILE لتكوين updmap (يمكن تقديمه عدة مرات، وفي هذه الحالة يتم استخدام جميع الملفات)
--dvipdfmxoutputdir مجلد
تحديد مجلد الإخراج (صيغة dvipdfm(x))
--dvipsoutputdir مجلد
تحديد مجلد الإخراج (صيغة dvips)
--pdftexoutputdir مجلد
تحديد مجلد الإخراج (صيغة pdftex)
--pxdvioutputdir مجلد
تحديد مجلد الإخراج (صيغة pxdvi)
--outputdir مجلد
تحديد مجلد الإخراج (لجميع الملفات)
--copy
نسخ الملفات العامة بدلاً من استخدام الروابط الرمزية (symlinks)
--force
إعادة إنشاء الملفات حتى لو لم يتغير التكوين
--nomkmap
عدم إعادة إنشاء ملفات الخرائط
--nohash

--user

-n, --dry-run

--quiet, --silent

الإخراج الرئيسي:

الإخراج الرئيسي لـ updmap هو الملفات التي تحتوي على أسطر خريطة الخطوط الفردية التي تقرأها برامج التشغيل (dvips، pdftex، إلخ) للتعامل مع الخطوط.
تتم كتابة ملفات الخرائط لـ dvips (psfonts.map) و pdftex و dvipdfmx (pdftex.map) إلى TEXMFVAR/fonts/map/updmap/{dvips,pdftex}/.
بالإضافة إلى ذلك، يتم كتابة معلومات حول خطوط Kanji إلى TEXMFVAR/fonts/map/updmap/dvipdfmx/kanjix.map، واختياريًا إلى TEXMFVAR/fonts/map/updmap/pxdvi/xdvi-ptex.map. هذه مخصصة لـ Kanji فقط وليست مثل ملفات الخرائط الأخرى. يقرأ dvipdfmx pdftex.map لإدخالات الخريطة للخطوط غير Kanji.
إذا لم يتم تحديد أي خيار، بحيث يكون الاستدعاء هو "updmap-user" أو "updmap-sys"، فسيتم دائمًا إعادة إنشاء ملفات الإخراج هذه.
بخلاف ذلك، إذا تم تحديد خيار مثل --enable أو --disable، فسيتم إعادة إنشاء ملفات الإخراج إذا تغيرت قائمة الخرائط الممكّنة (من updmap.cfg). يتجاوز الخيار --force هذا، ويعيد دائمًا إنشاء ملفات الإخراج.

شرح أنواع الخرائط:

النوع العادي هو Map.
الاختلاف الوحيد بين Map و MixedMap هو أن إدخالات MixedMap لا تتم إضافتها إلى psfonts_pk.map. الغرض هو مساعدة المستخدمين الذين لديهم أجهزة تعرض خطوط Type 1 الخارجية بشكل أسوأ من خطوط Type 3 النقطية المعدلة حسب الوضع. لذلك، يستخدم MixedMap للخطوط المتاحة كـ Type 1 و Metafont.
تتم إضافة إدخالات KanjiMap إلى psfonts_t1.map و kanjix.map.

شرح أسماء الخيارات لـ --showoptions، --showoption، --setoption:

dvipsPreferOutline
true،false (الافتراضي true)
ما إذا كان dvips يستخدم الخرائط النقطية أم الخطوط الخارجية، عندما يكون كلاهما متاحًا.
dvipsDownloadBase35
true،false (الافتراضي true)
ما إذا كان dvips يتضمن الخطوط الـ 35 القياسية لـ PostScript في إخراجه.
pdftexDownloadBase14
true،false (الافتراضي true)
ما إذا كان pdftex يتضمن الخطوط الـ 14 القياسية لـ PDF في إخراجه.
texTextDir
مسار (مجلد)
موقع ملفات خطوط textext.
updmap-user(1) - TeX Live documentation

NAME

updmap-user - Configure user-specific updmap(1) settings

SYNOPSIS

updmap-user --help
updmap-user --version
updmap-user --sync <mapfile>
updmap-user --remove <mapfile>
updmap-user --list-mapfiles
updmap-user --force <mapfile>
updmap-user --output <output_map> <mapfile> [ ... ]
updmap-user --test
updmap-user --enable <feature> [--disable <feature>]
updmap-user --disable <feature> [--enable <feature>]
updmap-user --list-features

DESCRIPTION

This script is for configuring user-specific updmap(1) settings. It allows you to manage map files and features locally, without needing root privileges.

updmap(1) is used to manage PostScript font map files for TeX programs like dvips(1), pdftex(1), and xetex(1). It can update the map files used by these programs to locate fonts and their encodings.

This user-specific version creates configuration files in the user's home directory, typically in ~/.texlive2024/texmf-config/updmap.d/ or similar, instead of system-wide directories.

OPTIONS

--help
Display help message and exit.
--version
Display version information and exit.
--sync mapfile
Add the specified mapfile to the user's configuration. This makes the map file available for use. The file is copied to the user's configuration directory.
--remove mapfile
Remove the specified mapfile from the user's configuration. This will disable the map file.
--list-mapfiles
List all map files currently configured by the user.
--force mapfile
Force the regeneration of the map file specified. This is useful if the map file has been manually edited or if its contents are suspected to be outdated.
--output output_map mapfile [ ... ]
Create a new map file named output_map by merging the contents of the specified mapfiles. This is useful for creating custom map files that combine settings from multiple sources.
--test
Perform a test of the current configuration without making any changes. This can help identify potential issues or conflicts in the user's settings.
--enable feature
Enable a specific feature. Features can control various aspects of font handling, such as enabling specific font packages or types.
--disable feature
Disable a specific feature.
--list-features
List all available features that can be enabled or disabled.

ENVIRONMENT

The behaviour of updmap-user may be influenced by environment variables like TEXMFCONFIG, which specifies the user's TeX configuration directory.

EXAMPLES

To add a custom map file named myfonts.map:

updmap-user --sync myfonts.map

To remove the pdftex_dl14.map file:

updmap-user --remove pdftex_dl14.map

To list all configured map files:

updmap-user --list-mapfiles

To enable the t1fonts feature:

updmap-user --enable t1fonts

To create a combined map file named combined.map from psfonts.map and myfonts.map:

updmap-user --output combined.map psfonts.map myfonts.map

FILES

User-specific configuration files are typically stored in:

~/.texlive2024/texmf-config/updmap.d/
Directory for user-specific map file configurations.
~/.texlive2024/texmf-config/web2c/
Directory for user-specific configuration files like updmap.cfg.

The following are examples of map files that can be managed:

psfonts.map
The default map file for PostScript fonts. Usually contains settings for the 35 standard PostScript fonts.
psfonts_t1.map
A map file specifically for Type 1 fonts.
psfonts_pk.map
A map file for PK (Packed Font) files.
pdftex_dl14.map
For pdftex(1). Always downloads the standard 14 fonts.
pdftex_ndl14.map
For pdftex(1). Never downloads the standard 14 fonts.
ps2pk.map
Similar to psfonts.map file, but forces all fonts to be downloaded, so this map file can be used with xdvi(1) and ps2pk(1).

Configuration files for dvips(1):

config.builtin35
Loads builtin35.map instead of psfonts.map.
config.download35
Loads download35.map instead of psfonts.map.
config.outline
Loads psfonts_t1.map instead of psfonts.map.
config.pdf
Loads psfonts_t1.map instead of psfonts.map and has additional settings for PDF generation.
config.pk
Loads psfonts_pk.map instead of psfonts.map.
config.www
Loads psfonts_t1.map instead of psfonts.map. (For compatibility with old versions.)
config.gstopk
Loads psfonts_t1.map instead of psfonts.map.
