NAME

unibilium.h - interface to the unibilium library

SYNOPSIS

#include <unibilium.h>

DESCRIPTION

The unibilium library provides a small, fast, and efficient API for managing terminal capabilities. It is designed to be a drop-in replacement for the terminfo library, offering a cleaner API and better performance.

The library provides functions for:

  • Initializing and shutting down the library.
  • Loading terminal capability databases.
  • Retrieving and setting capabilities.
  • Extending the capability database with custom entries.
  • Formatting capability strings with parameters.

The library uses a compact binary format for its databases, which allows for faster loading and parsing compared to traditional terminfo files.

The API is designed to be simple and easy to use, with functions for both boolean, numeric, and string capabilities. It also provides functions for handling extended capabilities, which are capabilities that are not part of the standard terminfo database.

The library also offers functions for converting between variable and fixed-size data types, as well as for formatting capability strings with parameters. This allows for more flexibility and control when working with terminal capabilities.

The library is thread-safe and can be used in multi-threaded applications without the need for external synchronization.
