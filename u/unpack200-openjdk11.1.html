unpack200-openjdk11(1)

الحزمة: jdk11-openjdk

التراخيص: LicenseRef-Java

unpack200(1) أدوات نشر Java unpack200(1)

الاسم

unpack200 - يحوّل ملفًا مضغوطًا تم إنتاجه بواسطة pack200(1) إلى ملف JAR للنشر على الويب.

الملخص

unpack200 [ خيارات ] ملف-الإدخال ملف JAR
خيارات
خيارات سطر الأوامر. انظر الخيارات.
ملف-الإدخال
اسم ملف الإدخال، والذي يمكن أن يكون ملف gzip مضغوط بواسطة pack200 أو ملف pack200. يمكن أن يكون الإدخال أيضًا ملف JAR تم إنتاجه بواسطة pack200(1) بجهد 0، في هذه الحالة يتم نسخ محتويات ملف الإدخال إلى ملف JAR الناتج مع علامة Pack200.
ملف JAR
اسم ملف JAR الناتج.

الوصف

أمر unpack200 هو تطبيق أصلي يحوّل ملفًا مضغوطًا تم إنتاجه بواسطة pack200(1) إلى ملف JAR. يتبع الاستخدام النموذجي. في المثال التالي، تم إنتاج ملف myarchive.jar من myarchive.pack.gz باستخدام إعدادات الأمر الافتراضية لـ unpack200.

unpack200 myarchive.pack.gz myarchive.jar

الخيارات

-Hvalue --deflate-hint=value

يحدد الضغط إلى true، false، أو keep على جميع الإدخالات داخل ملف JAR. الوضع الافتراضي هو keep. إذا كانت القيمة true أو false، فإن خيار --deflate=hint يتجاوز السلوك الافتراضي ويحدد وضع الضغط على جميع الإدخالات داخل ملف JAR الناتج.
-r --remove-pack-file

يزيل ملف الحزمة المدخلة.
-v --verbose

يعرض رسائل الحد الأدنى. المواصفات المتعددة لهذا الخيار تعرض رسائل أكثر تفصيلاً.
-q --quiet

يحدد التشغيل الهادئ بدون رسائل.
-lfilename --log-file=filename

يحدد ملف سجل يتم فيه تسجيل رسائل الإخراج.
-? -h --help

يطبع معلومات المساعدة حول أمر unpack200.
-V --version

يطبع معلومات الإصدار حول أمر unpack200.
-Joption

يمرر الخيار إلى آلة Java الافتراضية (JVM)، حيث يكون option هو أحد الخيارات الموضحة في صفحة المرجع لمشغل تطبيق Java. على سبيل المثال، يحدد -J-Xms48m الذاكرة عند بدء التشغيل بـ 48 ميجابايت. انظر java(1).

ملاحظات

لا ينبغي الخلط بين هذا الأمر وأمر unpack. إنهما منتجان منفصلان تمامًا.

مواصفات واجهة برمجة تطبيقات Java SE المتوفرة مع JDK هي السلطة العليا في حالة وجود تناقضات.

حالة الخروج

يتم إرجاع قيم الخروج التالية: 0 للإكمال الناجح، وقيمة أكبر من 0 عند حدوث خطأ.
