uudoc(1) دليل الأوامر العامة uudoc(1)

الاسم

uudoc - التحقق من أنواع الملفات ومقارنة القيم.

الملخص

uudoc [-h|--help] [-V|--version]

الوصف

التحقق من أنواع الملفات ومقارنة القيم.

الخيارات

-h, --help
طباعة المساعدة
-V, --version
طباعة الإصدار

إضافي

الخروج بحالة يتم تحديدها بواسطة EXPRESSION.

EXPRESSION المحذوف افتراضيًا هو false. بخلاف ذلك، فإن EXPRESSION إما true أو false وتحدد حالة الخروج.

إنه أحد ما يلي:

- ( EXPRESSION ) EXPRESSION صحيحة - ! EXPRESSION EXPRESSION خاطئة - EXPRESSION1 -a EXPRESSION2 كل من EXPRESSION1 و EXPRESSION2 صحيحة - EXPRESSION1 -o EXPRESSION2 إما EXPRESSION1 أو EXPRESSION2 صحيحة

عمليات السلسلة: - -n STRING طول STRING غير صفري - STRING مكافئ لـ -n STRING - -z STRING طول STRING صفر - STRING1 = STRING2 السلاسل متساوية - STRING1 != STRING2 السلاسل غير متساوية

مقارنات الأعداد الصحيحة: - INTEGER1 -eq INTEGER2 INTEGER1 يساوي INTEGER2 - INTEGER1 -ge INTEGER2 INTEGER1 أكبر من أو يساوي INTEGER2 - INTEGER1 -gt INTEGER2 INTEGER1 أكبر من INTEGER2 - INTEGER1 -le INTEGER2 INTEGER1 أقل من أو يساوي INTEGER2 - INTEGER1 -lt INTEGER2 INTEGER1 أقل من INTEGER2 - INTEGER1 -ne INTEGER2 INTEGER1 لا يساوي INTEGER2

عمليات الملفات: - FILE1 -ef FILE2 FILE1 و FILE2 لهما نفس أرقام الجهاز و inode - FILE1 -nt FILE2 FILE1 أحدث (تاريخ التعديل) من FILE2 - FILE1 -ot FILE2 FILE1 أقدم من FILE2

- -b FILE الملف موجود وهو خاص بالكتلة - -c FILE الملف موجود وهو خاص بالحرف - -d FILE الملف موجود وهو دليل - -e FILE الملف موجود - -f FILE الملف موجود وهو ملف عادي - -g FILE الملف موجود وهو في وضع تعيين مجموعة الهوية - -G FILE الملف موجود وهو مملوك لـ ID المجموعة الفعالة - -h FILE الملف موجود وهو رابط رمزي (نفس -L) - -k FILE الملف موجود وله بت الالتصاق مضبوطًا - -L FILE الملف موجود وهو رابط رمزي (نفس -h) - -N FILE الملف موجود وتم تعديله منذ آخر قراءة له - -O FILE الملف موجود وهو مملوك لـ ID المستخدم الفعال - -p FILE الملف موجود وهو أنبوب مسمى - -r FILE الملف موجود وتم منح إذن القراءة - -s FILE الملف موجود وحجمه أكبر من الصفر - -S FILE الملف موجود وهو مقبس - -t FD واصف الملف FD مفتوح على طرفية - -u FILE الملف موجود وبتر المستخدم الخاص به مضبوط - -w FILE الملف موجود وتم منح إذن الكتابة - -x FILE الملف موجود وتم منح إذن التنفيذ (أو البحث)

باستثناء -h و -L، فإن جميع اختبارات الملفات تتبع (تتبع) الروابط الرمزية. كن حذرًا من أن الأقواس تحتاج إلى الهروب (على سبيل المثال، باستخدام الشرطة المائلة العكسية) للقشور. قد يكون INTEGER أيضًا -l STRING، والذي يُقيّم لطول STRING.

ملاحظة: -a و -o الثنائية غامضة بطبيعتها. استخدم test EXPR1 && test EXPR2 أو test EXPR1 || test EXPR2 بدلاً من ذلك. ملاحظة: [ يحترم خيارات --help و --version، لكن test لا يفعل ذلك. يعامل test كلًا من هذه الخيارات كما يعامل أي STRING آخر غير فارغ. ملاحظة: قد يكون لشلك إصدار خاص به من test و/أو [، والذي عادة ما يحل محل الإصدار الموضح هنا. يرجى الرجوع إلى وثائق شلك للحصول على تفاصيل حول الخيارات التي يدعمها.
