NAME

uncompress - decompress files

SYNOPSIS

uncompress [ -f ] [ -v ] [ -k ] [ -o output ] [ -L ] [ -n ] [ -q ] [ -b bits ] [ -d ] [ -Z ] [ -c ] [ file ... ]

DESCRIPTION

The uncompress utility is used to decompress files that have been compressed with compress. If the file operand is not specified, or if the file operand is ‘-’, uncompress reads from standard input and writes the decompressed data to standard output, leaving the original input unchanged.

When decompressing files, uncompress will replace each input file with a decompressed version. The original file is removed unless the archive was compressed with the -n option (see compress(1)).

The uncompress utility uses the Lempel-Ziv compression algorithm. Compression can be specified on the command line using the -Z option, but this is generally discouraged in favor of using the compress utility.

OPTIONS

-c, --stdout

Write output on standard output; keep original files unchanged.

-d, --decompress

Decompress.

-f, --force

Overwrite the output even if it is already exists.

-k, --keep

Do not delete the original compressed input files.

-L, --license

Display a license and exit.

-n, --no-name

Do not save or restore the original file name and permissions.

-o output, --output output

Write output to the specified file.

-q, --quiet

Suppress all messages.

-v, --verbose

Control the verbosity of uncompress.

-b bits, --bits bits

Maximum number of bits per code. This must be between 9 and 16.

-Z, --compress

Compress.

OPERANDS

The following operand is supported:

file ...

A path to a file to be decompressed. If no files are specified, standard input is used.

STDIN

If the file operand is ‘-’ or if no file operand is specified, standard input is read. The standard input is assumed to be compressed data. The decompressed data is written to standard output.

INPUT FILES

The input files are expected to be compressed data. The compression format is determined by the data itself.

ENVIRONMENT VARIABLES

The behavior of uncompress may be affected by the following environment variables:

COMPRESS_PROGRAM

The path to the compress program if it is not in the user’s PATH.

ASYNCHRONOUS EVENTS

No specific asynchronous events are handled.

STDOUT

Unless the -c option is used, standard output is not used. If the -c option is used, standard output receives the decompressed data.

STDERR

Standard error is used only for error messages and the verbose output requested by the -v option.

OUTPUT FILES

By default, uncompress replaces the input file with the decompressed file. If the -c option is used, the decompressed data is written to standard output. If the -o option is used, the decompressed data is written to the specified output file.

EXTENDED DESCRIPTION

None.

EXIT STATUS

The uncompress utility exits with a zero exit status if the decompression is successful, or a non-zero exit status otherwise.

CONSEQUENCES OF ERRORS

On error, the input file is not modified. The exit status will indicate the error.

APPLICATION USAGE

To decompress a file named file.Z, use:

uncompress file.Z

To decompress a file and redirect the output to standard output, use:

uncompress -c file.Z

EXAMPLES

Decompress example.Z and write the output to standard output:

uncompress -c example.Z

Decompress file1.Z and file2.Z, overwriting the original files:

uncompress file1.Z file2.Z

Decompress file.Z and save the decompressed output to output_file:

uncompress -o output_file file.Z

RATIONALE

The uncompress utility provides a way to decompress files that were compressed using the compress utility. It is part of the GNU Core Utilities, which aims to provide a consistent set of basic command-line utilities.

FUTURE DIRECTIONS

The uncompress utility is part of the traditional Unix compress suite. While it is still widely used, newer compression algorithms and tools such as gzip, bzip2, and xz offer better compression ratios and/or speed. Its use is generally discouraged in favor of these newer tools.
