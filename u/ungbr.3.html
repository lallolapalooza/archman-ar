CUNGBR

الغرض:

!>
!> CUNGBR تنشئ إحدى المصفوفات الوحدوية المعقدة Q أو P**H
!> التي تحددها CGEBRD عند اختزال مصفوفة معقدة A إلى شكل ثنائي القطر: A = Q * B * P**H.  تُعرّف Q و P**H كناتج
!> للمنعكسات الأولية H(i) أو G(i) على التوالي.
!>
!> إذا كان VECT = 'Q'، يُفترض أن A كانت مصفوفة M-by-K، وأن Q
!> من الدرجة M:
!> إذا كان m >= k، فإن Q = H(1) H(2) . . . H(k) وتعيد CUNGBR الأعمدة n الأولى
!> من Q، حيث m >= n >= k؛
!> إذا كان m < k، فإن Q = H(1) H(2) . . . H(m-1) وتعيد CUNGBR Q ك
!> مصفوفة M-by-M.
!>
!> إذا كان VECT = 'P'، يُفترض أن A كانت مصفوفة K-by-N، وأن P**H
!> من الدرجة N:
!> إذا كان k < n، فإن P**H = G(k) . . . G(2) G(1) وتعيد CUNGBR الصفوف m الأولى
!> من P**H، حيث n >= m >= k؛
!> إذا كان k >= n، فإن P**H = G(n-1) . . . G(2) G(1) وتعيد CUNGBR P**H ك
!> مصفوفة N-by-N.
!>

!>          = 'Q':  إنشاء Q؛
!>          = 'P':  إنشاء P**H.
!>

M

!>          M هو INTEGER
!>          عدد الصفوف للمصفوفة Q أو P**H التي سيتم إرجاعها.

!>          N >= 0.
!>          إذا كان VECT = 'Q'، فإن M >= N >= min(M,K)؛
!>          إذا كان VECT = 'P'، فإن N >= M >= min(N,K).
!>

K

!>          التي تم اختزالها بواسطة CGEBRD.
!>          K >= 0.
!>

A

!>          A هي مصفوفة COMPLEX، البعد (LDA,N)

!>          كما تم إرجاعها بواسطة CGEBRD.
!>          عند الخروج، المصفوفة M-by-N Q أو P**H.
!>

LDA

!>          البعد الرئيسي للمصفوفة A. LDA >= M.
!>

TAU

!>          TAU هي مصفوفة COMPLEX، البعد
!>                                (min(M,K)) إذا كان VECT = 'Q'
!>                                (min(N,K)) إذا كان VECT = 'P'

!>          H(i) أو G(i)، الذي يحدد Q أو P**H، كما
!>          تم إرجاعها بواسطة CGEBRD في وسيطة مصفوفة TAUQ أو TAUP الخاصة به.
!>

WORK

!>          WORK هي مصفوفة COMPLEX، البعد (MAX(1,LWORK))

!>

LWORK

!>          LWORK هو INTEGER
!>          بعد المصفوفة WORK. LWORK >= max(1,min(M,N)).

!>          هذه القيمة كالإدخال الأول لمصفوفة WORK، ولا يصدر رسالة خطأ
!>          مرتبطة بـ LWORK بواسطة XERBLA.
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  الخروج بنجاح
!>          < 0:  إذا كان INFO = -i، فإن الوسيط i كان له قيمة غير قانونية

DORGQR

DORGQR

Purpose:

!>
!> DORGQR generates an M-by-N matrix Q with orthonormal columns,
!> which form an orthonormal basis for the range of a bidiagonal
!> matrix A specified by the arguments K, L, D, E, TauQ, and TauP.
!> Q is defined as the first N columns of a matrix generated by a
!> sequence of M-by-M elementary reflectors H(i) or G(i).
!>
!> If VECT = 'Q', Q is the orthogonal matrix H(1)H(2)...H(K) and the
!> matrix D of dimension M-by-K is specified.
!>
!> If VECT = 'P', Q is the orthogonal matrix G(1)G(2)...G(K) and the
!> matrix D of dimension K-by-N is specified.
!>

Parameters

VECT 
!>          VECT is CHARACTER*1
!>          Specifies the form of the matrix Q:
!>          = 'Q': Q is a matrix of order M, formed by the first K
!>                 columns of a product of M-by-M reflectors, H(1)...H(K).
!>                 The Bidiagonal matrix A is M-by-K.
!>          = 'P': Q is a matrix of order N, formed by the first K
!>                 columns of a product of N-by-N reflectors, G(1)...G(K).
!>                 The Bidiagonal matrix A is K-by-N.
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix Q to be returned.
!>          If VECT = 'Q', M is the number of rows of the matrix A.
!>          If VECT = 'P', M is the number of rows of the matrix Q.
!>          M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix Q to be returned.
!>          If VECT = 'Q', N is the number of columns of the matrix Q.
!>          If VECT = 'P', N is the number of columns of the matrix A.
!>          N >= 0.
!>

K

!>          K is INTEGER
!>          The number of elementary reflectors whose product forms the
!>          matrix Q.
!>          If VECT = 'Q', K is the number of columns of A.
!>          If VECT = 'P', K is the number of rows of A.
!>          K >= 0.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,K) if VECT = 'Q'
!>                                      (LDA,N) if VECT = 'P'
!>          On entry, the vectors which define the elementary reflectors,
!>          as returned by DBDSQR.
!>          On exit, the M-by-N matrix Q.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.
!>          If VECT = 'Q', LDA >= max(1,M).
!>          If VECT = 'P', LDA >= max(1,K).
!>

TAU

!>          TAU is DOUBLE PRECISION array, dimension
!>                                (K) if VECT = 'Q'
!>                                (K) if VECT = 'P'
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i) or G(i), which determines Q, as returned by
!>          DBDSQR in its array argument TAUQ or TAUP.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,min(M,K)).
!>          For optimum performance LWORK >= min(M,K)*NB, where NB
!>          is the optimal blocksize.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
