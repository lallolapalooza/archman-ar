upscli_connect(3)

الحزمة: nut

التراخيص: GPL-2.0-or-later AND GPL-3.0-or-later

UPSCLI_CONNECT(3) دليل NUT UPSCLI_CONNECT(3)

الاسم

upscli_connect, upscli_tryconnect - فتح اتصال بخادم بيانات upsd الخاص بـ NUT

الملخص

        #include <upsclient.h>
        /* فتح اتصال بخادم بيانات upsd الخاص بـ NUT (مانع بشكل افتراضي) */
        int upscli_connect(UPSCONN_t *ups, const char *host, uint16_t port, int flags);
        /* فتح اتصال بخادم بيانات upsd الخاص بـ NUT مع مهلة محددة */
        int upscli_tryconnect(UPSCONN_t *ups, const char *host, uint16_t port, int flags,
                struct timeval * timeout);

الوصف

تقوم الدالة upscli_connect() بأخذ المؤشر ups إلى بنية حالة UPSCONN_t وفتح اتصال TCP بالمضيف host على المنفذ port المحدد.

بشكل افتراضي، يتم إجراء محاولة اتصال مانعة (حتى تنتهي طبقة النقل الخاصة بالنظام من المهلة في استدعاء select(2) الأساسي). يمكن تكوين مهلة افتراضية على مستوى البرنامج لهذه الطريقة باستخدام طرائق upscli_set_default_connect_timeout(3) أو upscli_init_default_connect_timeout(3). للعمليات ذات المهلة المحددة لكل عملية، يرجى استخدام طريقة upscli_tryconnect() بدلاً من ذلك.


ملاحظة

كجزء من التهيئة العامة، يمكن لكل من الدالة upscli_init(3) أو الاستدعاء الأول للدالة upscli_connect()، استدعاء طريقة upscli_init_default_connect_timeout(3) (إذا لم يتم استخدامها من قبل): هذا يسمح للعملاء القدامى (غير المعدلين) من NUT بالاستفادة بشكل متسق من وجود متغير البيئة NUT_DEFAULT_CONNECT_TIMEOUT لمحاولات upscli_connect(3) لعدم الحظر (كما هو افتراضي).

قد تكون flags إما UPSCLI_CONN_TRYSSL لمحاولة اتصال SSL، أو UPSCLI_CONN_REQSSL لطلب اتصال SSL.

تم تقديم علم إضافي UPSCLI_CONN_CERTVERIF في الإصدار 2.7 للتحقق من التوقيع المقدم أثناء المصافحة SSL. يجب استخدام هذا العلم بالاقتران مع استدعاءات upscli_init(3) و/أو upscli_add_host_cert(3) قبل الاتصال لتحديد شهادة CA للتحقق منها.

إذا كان وضع SSL مطلوبًا، فلن تعود هذه الدالة بنجاح إلا إذا تمكنت من إنشاء اتصال SSL مع الخادم. تشمل الأسباب المحتملة للفشل عدم وجود دعم SSL على الخادم، وإذا لم يتم تجميع upsclient نفسه بدعم SSL.

يجب عليك استدعاء upscli_disconnect(3) عند الانتهاء من الاتصال، وإلا فإن برنامجك سيتسرب ببطء الذاكرة وموصّلات الملفات.

قيمة الإرجاع

تقوم الدالة upscli_connect() بتعديل بنية UPSCONN_t وتعيد 0 عند النجاح، أو -1 في حالة حدوث خطأ.
