NAME

org.freedesktop.machine1 - Machine introspection interface

INTRODUCTION

This service exposes information about the running virtual machines and containers managed by systemd-machined(8). It is accessible through the org.freedesktop.machine1.Manager D-Bus interface.

THE MANAGER OBJECT

The org.freedesktop.machine1.Manager interface is available on the bus well-known name org.freedesktop.machine1 at object path /org/freedesktop/machine1.

It provides the following methods:

• GetMachine(string machine-name)
Retrieves a machine object for the given machine name.
• ListMachines()
Returns an array of object paths for all currently known machines.
• ListMachineEntries()
Returns an array of dictionaries, each describing a machine.
• CreateMachine(string type, string name, ...)`
Creates a new machine. See systemd-nspawn(1) for details.
• CopyMachine(string name, string new_name, ...)`
Copies an existing machine to a new one.
• RemoveMachine(string name)`
Removes a machine.
• StartMachine(string name, ...)`
Starts a machine.
• StopMachine(string name, ...)`
Stops a machine.
• TerminateMachine(string name, ...)`
Terminates a machine.
• Login(string name, uint32 flags, ...)`
Logs into a machine.
• GetMachineSSHInfo(string name)`
Retrieves SSH information for a machine.
• CopyFromMachineWithFlags(string name, uint32 flags, string path, uint32 mode)`
Copies a file or directory from a machine.
• CopyToMachineWithFlags(string name, uint32 flags, string path, uint32 mode)`
Copies a file or directory into a machine.

MACHINE OBJECTS

Machine objects are available under the object path /org/freedesktop/machine1/machine/<machine-name>. The object path is derived from the machine name.

Each machine object implements the org.freedesktop.machine1.Machine interface, which has the following properties:

Name
The name of the machine.
MachineClass
The class of the machine. This is either the string "vm" (for real VMs based on virtualized hardware) or "container" (for lightweight userspace virtualization sharing the same kernel as the host).
Leader
The PID of the leader process of the machine. (The leader process is the top-level process of the payload of the machine, i.e. for containers PID 1 inside the container, and for VMs the process encapsulating the VM. Its lifetime defines the lifetime of the machine.)
LeaderPIDFDId
Encodes the Linux pidfd inode ID of the leader process of the machine.
Supervisor
The PID of the supervisor process of the machine. (The supervisor process is the process that manages the machine, if there's a separate one for it. A supervisor process is not always defined, and does not define the machine's lifetime.)
SupervisorPIDFDId
Encodes the Linux pidfd inode ID of the supervisor process of the machine.
Class
The class of the machine and is either the string "vm" (for real VMs based on virtualized hardware) or "container" (for lightweight userspace virtualization sharing the same kernel as the host).
RootDirectory
The root directory of the container if it is known and applicable or the empty string.
NetworkInterfaces
Contains an array of network interface indices that point towards the container, the VM or the host. For details about this information see the description of CreateMachineWithNetwork() above.
VSockCID
The VSOCK CID of the VM if it is known, or VMADDR_CID_ANY otherwise.
SSHAddress
The address of the VM in a format ssh can understand if it is known or the empty string.
SSHPrivateKeyPath
The path to the SSH private key of the VM if it is known or the empty string.
State
The state of the machine and is one of "opening", "running", or "closing". Note that the state machine is not considered part of the API and states might be removed or added without this being considered API breakage.
Subgroup
Contains the sub-control-group path this machine's processes reside in, relative to the specified unit's control group.
UID
Contains the numeric UNIX UID of the user who registered the machine.

EXAMPLES

Example 1. Introspect org.freedesktop.machine1.Manager on the bus

$ gdbus introspect --system \
  --dest org.freedesktop.machine1 \
  --object-path /org/freedesktop/machine1

Example 2. Introspect org.freedesktop.machine1.Machine on the bus

$ gdbus introspect --system \
  --dest org.freedesktop.machine1 \
  --object-path /org/freedesktop/machine1/machine/rawhide

VERSIONING

These D-Bus interfaces follow the usual interface versioning guidelines[2].

HISTORY

The Manager Object

CopyFromMachineWithFlags() and CopyToMachineWithFlags() were added in version 252.

GetMachineSSHInfo() was added in version 256.

Machine Objects

CopyFromWithFlags() and CopyToWithFlags() were added in version 252.

GetSSHInfo(), VSockCID, SSHAddress, and SSHPrivateKeyPath were added in version 256.

LeaderPIDFDId, Supervisor, SupervisorPIDFDId, Subgroup, and UID were added in version 258.
