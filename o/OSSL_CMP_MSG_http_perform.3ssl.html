OSSL_CMP_MSG_http_perform(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

OSSL_CMP_MSG_HTTP_PERFORM(3ssl) OpenSSL OSSL_CMP_MSG_HTTP_PERFORM(3ssl)

الاسم

OSSL_CMP_MSG_http_perform - نقل طلب/استجابة CMP عبر HTTP(S) من جانب العميل

الملخص

#include <openssl/cmp.h>
OSSL_CMP_MSG *OSSL_CMP_MSG_http_perform(OSSL_CMP_CTX *ctx,
                                        const OSSL_CMP_MSG *req);

الوصف

تقوم OSSL_CMP_MSG_http_perform() بإرسال رسالة PKIMessage req المعطاة إلى خادم CMP المحدد في ctx وتعيد النتيجة التي تم الحصول عليها منه.

إذا تم استخدام OSSL_CMP_CTX_set_transfer_cb_arg(3) لتعيين وسيط دالة رد الاتصال للنقل، فسيتم أخذ المؤشر bios المقدم على أنه مصفوفة BIO ذات عنصرين لاستخدامها في التبادل مع الخادم كما هو موضح لمعلمتي bio و rbio في OSSL_HTTP_open(3). على سبيل المثال، قد يكون مؤشرا BIO متساويين ويشيران إلى اتصال TLS، كما في BRSKI-AE حيث يتم إعادة استخدام قناة TLS المنشأة مسبقًا لـ CMP.

بخلاف ذلك، يتم الاتصال بالخادم المحدد عبر OSSL_CMP_CTX_set1_server(3) واختياريًا OSSL_CMP_CTX_set_serverPort(3)، حيث يكون المنفذ الافتراضي هو 80 لـ HTTP و 443 لـ HTTPS. المسار HTTP (المعروف أيضًا باسم "CMP alias" في هذا السياق) المراد استخدامه هو افتراضيًا "/"، وإلا فسلسلة الأحرف المحددة عبر OSSL_CMP_CTX_set1_serverPath(3). عند النجاح، تعيد الدالة رسالة PKIMessage استجابة الخادم.

تستفيد الدالة من أي دالة رد اتصال HTTP تم تعيينها عبر OSSL_CMP_CTX_set_http_cb(3). إنها تحترم أي قيمة مهلة تم تعيينها عبر OSSL_CMP_CTX_set_option(3) مع وسيط OSSL_CMP_OPT_MSG_TIMEOUT. كما أنها تحترم أي خيارات وكيل HTTP(S) تم تعيينها عبر OSSL_CMP_CTX_set1_proxy(3) و OSSL_CMP_CTX_set1_no_proxy(3) ومتغيرات البيئة ذات الصلة. يدعم الوكلاء HTTP العادي مباشرة، بينما يتطلب استخدام وكيل لاتصالات HTTPS دالة رد اتصال مناسبة مثل OSSL_HTTP_proxy_connect(3).

ملاحظات

CMP معرف في RFC 4210. نقل HTTP لـ CMP معرف في RFC 6712.

قيم الإرجاع

تعيد OSSL_CMP_MSG_http_perform() رسالة استجابة CMP المستلمة عند النجاح، وإلا NULL.

انظر أيضاً

OSSL_CMP_CTX_new(3)، OSSL_HTTP_open(3)، و OSSL_HTTP_proxy_connect(3).

تاريخ

تمت إضافة دعم OpenSSL CMP في OpenSSL 3.0.

تمت إضافة استخدام OSSL_CMP_MSG_http_perform() لـ transfer_cb_arg في OpenSSL 3.5.
