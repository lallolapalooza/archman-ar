or1k-elf-c++filt(1)

الحزمة: or1k-elf-binutils

التراخيص: GPL

NAME

c++filt - demangle C++ symbol names

SYNOPSIS

c++filt [OPTION]...

DESCRIPTION

Read C++ mangled symbol names from standard input and write the demangled names to standard output. This is useful for viewing symbol names produced by the compiler in a human-readable form.

This program is part of the GNU Binutils.

OPTIONS

--help
Display a help message and exit.
--version
Display the version information and exit.

FOOTNOTES
