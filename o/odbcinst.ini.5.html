odbcinst.ini(5) صفحات دليل unixODBC odbcinst.ini(5)

الاسم

/etc/odbcinst.ini - ملف تكوين برامج تشغيل unixODBC

الوصف

/etc/odbcinst.ini هو ملف تكوين لبرامج تشغيل unixODBC.

يمكن تحديث الملف باستخدام الأداة المساعدة odbcinst (موصى بها) أو تحريره يدويًا.

صيغة الملف

الصيغة العامة لملف .ini هي:

[اسم القسم1]
مفتاح1 = قيمة1
مفتاح2 = قيمة2
...
[اسم القسم2]
مفتاح1 = قيمة1
مفتاح2 = قيمة2
...

كل برنامج تشغيل ODBC له قسمه الخاص ويمكن الإشارة إليه باسم ذلك القسم في ملفات مثل odbc.ini. ضمن كل قسم، تتعرف unixODBC أيضًا على مفاتيح التكوين التالية:

الوصف
سلسلة نصية تصف برنامج التشغيل باختصار.
برنامج التشغيل
مسار نظام ملفات لمكتبة برنامج التشغيل الفعلية.
الإعداد
مسار نظام ملفات لمكتبة إعداد برنامج التشغيل.
استخدام الملف
القسم المسمى [ODBC] يقوم بتكوين الخيارات العامة. المفاتيح المعترف بها في قسم [ODBC] تشمل:
التتبع
تمكين إخراج تتبع برنامج تشغيل ODBC، والذي يتم كتابته إلى مسار الملف المحدد بواسطة TraceFile.

بعض برامج تشغيل ODBC لديها خيارات التحكم في تتبع خاصة بها. على عكس خيار Trace، عادةً ما يتم تحديد هذه الخيارات المنفصلة على مستوى اسم مصدر البيانات (DSN).

سيتم تمكين Trace إذا كانت القيمة المقابلة تحتوي على أي متغير حالة للحرف "1"، "y"، "yes"، أو "on".

ملف التتبع
يحدد مسار النظام أو نمط المسار الذي سيتم كتابة إخراج تتبع برنامج تشغيل ODBC إليه. ليس لهذا الخيار أي تأثير ما لم يتم تمكين Trace. الموقع الافتراضي للملف لإخراج التتبع هو /tmp/sql.log.

تحذير: قد لا يعمل تعيين TraceFile إلى مسار يمكن لعدة مستخدمين الكتابة فيه بشكل صحيح، حيث سيكون المستخدم الأول فقط قادرًا على إنشاء وفتح الملف.

ملفات القوالب

تأتي العديد من برامج تشغيل ODBC مع قوالب ملفات .ini، والتي يمكن تثبيتها باستخدام الأداة المساعدة odbcinst.

تستخدم ملفات القوالب نفس صيغة odbcinst.ini.

أمثلة

لتثبيت برنامج تشغيل PostgreSQL الخاص بـ unixODBC، يمكن إدخال التكوين التالي في odbcinst.ini:

[PostgreSQL]
Description = برنامج تشغيل PostgreSQL لنظام GNU/Linux
Driver      = /usr/lib/psqlodbcw.so
Setup       = /usr/lib/libodbcpsqlS.so
FileUsage   = 1

يمكن أن تختلف مسارات برنامج التشغيل، اعتمادًا على نظام التشغيل الخاص بك وما إذا كان توزيعك يدعم متعدد الأغراض (multi-arch). تتطلب بعض برامج التشغيل أيضًا إدخالات Driver64 و Setup64.

يمكن الإشارة إلى القسم أعلاه في odbc.ini على النحو التالي:

Driver = PostgreSQL

الطريقة الموصى بها لإضافة برنامج تشغيل PostgreSQL إلى نظامك هي عن طريق إنشاء ملف قالب يحتوي على:

[PostgreSQL]
Description = برنامج تشغيل PostgreSQL لنظام GNU/Linux
Driver      = /usr/lib/psqlodbcw.so
Setup       = /usr/lib/libodbcpsqlS.so

واستدعاء odbcinst على النحو التالي:

# odbcinst -i -d -f template.ini
