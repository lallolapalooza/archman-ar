NAME

operon — command-line interface for Quod Libet

SYNOPSIS

operon COMMAND [ OPTIONS ] [ ARGUMENTS ]...

OPTIONS

All commands accept the following options:

-h, --help
Display help and exit

COMMAND OVERVIEW

list

Lists files in the library, with optional filtering and sorting.

operon list [-h] [-a] [-t] [-c <columns>] [<pattern>] [<file>...]

-h, --help
Display help and exit
-a, --all
Also list programmatic tags
-t, --terse
Output is terse and suitable for script processing
-c, --columns <name>,...
Defines which columns should be printed and in which order
Example:
operon list -a song.flac

operon list -t -c tag,value song.ogg

info

Lists non-tag metadata like length, size and format.

operon info [-h] [-t] [-c <c1>,<c2>...] <file>

-h, --help
Display help and exit
-t, --terse
Output is terse and suitable for script processing
-c, --columns <name>,...
Defines which columns should be printed and in which order
Example:
operon info a.ogg

print

Prints information per file built from tag values. The pattern can be customized by passing a pattern string (See quodlibet(1) for the pattern format)

operon print [-h] [-p <pattern>] <file>...

-h, --help
Display help and exit
-p, --pattern <pattern>
Use a custom pattern
Example:
operon print -p " - " a.ogg

EDIT TAGS

tag-set

Sets the specified tag value on all specified files.

operon tag-set [-h] [-p <pattern>] <tag> <value> <file>...

-h, --help
Display help and exit
-p, --pattern <pattern>
Use a custom pattern
Example:
operon tag-set album "The Dark Side of the Moon" *.flac

tag-remove

Removes the specified tag from all specified files.

operon tag-remove [-h] <tag> <file>...

-h, --help
Display help and exit
Example:
operon tag-remove album *.flac

tag-rename

Renames a tag.

operon tag-rename [-h] <old-name> <new-name> <file>...

-h, --help
Display help and exit
Example:
operon tag-rename title tracknumber *.mp3

tag-copy

Copies a tag's value from one tag to another.

operon tag-copy [-h] <from-tag> <to-tag> <file>...

-h, --help
Display help and exit
Example:
operon tag-copy album title *.flac

album-rename

Renames an album.

operon album-rename [-h] <old-album> <new-album> [-c <columns>] [<pattern>] [<file>...]

-h, --help
Display help and exit
-a, --all
Also list programmatic tags
-t, --terse
Output is terse and suitable for script processing
-c, --columns <name>,...
Defines which columns should be printed and in which order
Example:
operon list -a song.flac

operon list -t -c tag,value song.ogg

EDIT EMBEDDED IMAGES

image-extract

Extract all embedded images to the current working directory or the specified destination directory.

operon image-extract [-h] [--dry-run] [--primary] [-d <destination>] <file>...

-h, --help
Display help and exit
--dry-run
Print the found images and resulting file paths but don't save them
--primary
Only extract the primary images for each file
-d, --destination <destination>
Save all images to the specified destination
Example:
operon image-extract asong.mp3 anotherone.ogg

image-set

Set the provided image as primary embedded image and remove all other embedded images.

operon image-set <image-file> <file>...

-h, --help
Display help and exit
Example:
operon image-set cover.jpg song.mp3

image-clear

Remove all embedded images from all specified files.

operon image-clear <file>...

-h, --help
Display help and exit
Example:
operon image-clear song.mp3
