الاسم

org.freedesktop.oom1 - واجهة D-Bus لـ systemd-oomd

مقدمة

systemd-oomd.service(8) هي خدمة نظام تنفذ قاتل نفاد الذاكرة (OOM) في مساحة المستخدم. يصف هذا المستند واجهة D-Bus.

كائن المدير

تكشف الخدمة عن الواجهات التالية على كائن المدير في الحافلة:

node /org/freedesktop/oom1 {
  interface org.freedesktop.oom1.Manager {
    methods:
      DumpByFileDescriptor(out h fd);
    signals:
      Killed(s cgroup,
             s reason);
  };
  interface org.freedesktop.DBus.Peer { ... };
  interface org.freedesktop.DBus.Introspectable { ... };
  interface org.freedesktop.DBus.Properties { ... };
};

الأساليب

يتم إرسال إشارة Killed() عند قتل أي مجموعة cgroup بواسطة oomd.

لاحظ أنه سيتم إضافة المزيد من الأسباب في المستقبل، وسيتم توسيع الجدول أدناه وفقًا لذلك.

الجدول 1. أسباب القتل

السبب الوصف
memory-used استهلك التطبيق الكثير من الذاكرة والتبديل.
memory-pressure استهلك التطبيق ما يكفي من الذاكرة والتبديل للتسبب في تباطؤ كافٍ للتطبيقات الأخرى.
