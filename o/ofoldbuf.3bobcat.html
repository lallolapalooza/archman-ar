FBB::OFoldBuf(3bobcat) طي الأسطر الطويلة FBB::OFoldBuf(3bobcat)

الاسم

FBB::OFoldBuf - يطوي الأسطر الطويلة المكتوبة إلى ostream

الملخص

#include <bobcat/ofoldbuf>
خيار الربط: -lbobcat

الوصف

FBB::OFoldBuf هو تخصص لـ FBB::OFilterBuf يقوم بطي الأسطر الطويلة المكتوبة إلى كائن std::ostream. يكتب OFoldBuf الأسطر (المطوية) إلى ostream ثانية (تدفق الوجهة الذي يتم استخدامه بواسطة أو فتحه بواسطة الكائن OFoldBuf).

داخليًا، يحدد OFoldBuf إجراءاته باستخدام أتمتة محدودة الحالات تميز ثلاث حالات (INDENT، WS، و NON_WS) وثلاث فئات أحرف (\n، أحرف مسافة بيضاء أخرى (مسافة)، وأحرف غير مسافة). تتم مناقشة التركيبات التسعة الناتجة عن هاتين المجموعتين أدناه.

لن يقوم كائن OFoldBuf أبدًا بطي الأسطر في منتصف سلسلة من الأحرف غير الفارغة (تسمى "كلمة" أدناه) ولكنه سيقطع دائمًا سطرًا عند حرف مسافة بيضاء. ستظهر الأسطر الناتجة دائمًا إلى يمين هامش أيسر قابل للتكوين وإلى يسار هامش أيمن قابل للتكوين. يوجد استثناء مرضٍ لهذا: إذا كانت الكلمة طويلة جدًا بحيث لا تتناسب بين الهوامش، فستتجاوز الكلمة الهامش الأيمن.

قابلية المسافة البادئة المستخدمة للهوامش اليسرى قابلة للتكوين إما عن طريق المسافات (الافتراضي) أو علامات الجدولة. عند استخدام علامات الجدولة، فإن عرض حرف علامة الجدولة قابل للتكوين، مع استخدام افتراضي قدره 8 مواضع في تدفق الوجهة.

ما يلي هو وصف لـ الأتمتة المحدودة الحالة (FSA) التي تحدد ما يحدث عند ظهور أنواع أحرف مختلفة في حالاتها الثلاث. عبارة "... مكتوبة" تعني أن المعلومات الموصوفة مكتوبة إلى ostream المستخدم أو الذي فتحه كائن OFoldBuf. الحالة الأولية لـ OFoldBuf هي INDENT:

التعداد

يستخدم التعداد TabsOrBlanks لتحديد علامات الجدولة أو المسافات عند كتابة المسافة البادئة. الافتراضي هو المسافات. عند تحديد علامات الجدولة، يمكن أيضًا تكوين عرض أحرف علامة الجدولة (باستخدام الافتراضي 8 مواضع لكل حرف علامة جدولة). يحتوي التعداد على قيمتين:

o
BLANKS:
الافتراضي، يشير إلى أن الهامش الأيسر محدد ومكتوب كرقم من المسافات؛
o
TABS:
يشير إلى أن الهامش الأيسر محدد ومكتوب كرقم من أحرف علامة الجدولة.

يستخدم التعداد TrailingBlanks لتكوين الكائن OFoldBuf فيما يتعلق بأي مسافات بيضاء لاحقة قد تظهر في السطر النهائي. يمكن أن تظهر هذه المسافات البيضاء في السطر النهائي إذا لم يتم إنهاؤها بشكل صحيح بحرف سطر جديد ولكنها تنتهي بمسافة بيضاء. افتراضيًا، يتم تجاهل هذه المسافات البيضاء، ولكن يمكن الاحتفاظ بها أيضًا. يحتوي التعداد على قيمتين:

o
IGNORE_TRAILING_BLANKS:
يشير هذا إلى أن المسافات البيضاء اللاحقة التي تظهر في السطر النهائي إذا لم يتم إنهاؤها بحرف سطر جديد يجب عدم كتابتها إلى std::ostream الوجهة. هذا هو الافتراضي المستخدم بواسطة كائنات OFoldBuf.
o
KEEP_TRAILING_BLANKS:
يشير هذا إلى أن المسافات البيضاء اللاحقة في السطر النهائي إذا لم يتم إنهاؤها بحرف سطر جديد يجب كتابتها إلى std::ostream الوجهة.

NAME

ofoldbuf - output folding buffer

SYNOPSIS

    #include <bobcat/ofoldbuf>
    namespace FBB {
        class OFoldBuf : public std::streambuf
        {
            public:
                OFoldBuf(std::ostream &stream,
                         size_t lineLen,
                         size_t charWidth);
                ~OFoldBuf();
                void tabs(size_t, size_t tabWidth = 8);
                size_t leftMargin(std::ostreambuf const *buffer);
                size_t rightMargin(std::ostreambuf const *buffer);
            private:
                // ...
        };
    }

DESCRIPTION

The OFoldBuf class may be used to fold long lines of text to a specified line length. The text is directed to an output stream, specified by the stream parameter in the constructor. The lineLen parameter specifies the maximum line length. The charWidth parameter specifies the display width of a tab-character. If charWidth is 0, then tab-characters are ignored.

NAMESPACE

namespace FBB { ... }

INHERITS FROM

std::streambuf

ENUMERATION

o
OFoldBuf::foldPolicy: Defines the folding policy.
NO_FOLD
no folding is performed.
TAB_FOLD
folding is performed on tab-characters.
SPACE_FOLD
folding is performed on space characters.

CONSTRUCTORS

o
OFoldBuf(std::ostream &stream, size_t lineLen, size_t charWidth): The constructor initializes the object with the stream to be written to, the maximum line length, and the display width of a tab-character.

If charWidth is 0, then tab-characters are ignored.

o
OFoldBuf(std::ostream &stream, size_t lineLen, size_t charWidth, OFoldBuf::foldPolicy policy):

This constructor initializes the object with the stream to be written to, the maximum line length, the display width of a tab-character, and the folding policy.

MEMBER FUNCTIONS

o
~OFoldBuf():

The destructor ensures that any remaining buffered text is written to the output stream.

o
void tabs(size_t nl, size_t tabWidth = 8):

This member sets the tab-character width. The first parameter is used to specify the number of spaces that precede the tab-character (left margin). The second parameter specifies the display width of a tab-character.

If tabWidth is 0, tab-characters are ignored.

o
void lm(size_t nl):

This member is used to set the left margin of the output. The parameter nl specifies the number of spaces that precede the output.

o
size_t lm() const:

Returns the current left margin.

o
void mlm(size_t nl):

This member is used to set the left margin of the output. The parameter nl specifies the number of spaces that precede the tab-character.

o
size_t mlm() const:

Returns the current left margin for tab-characters.

o
void rm(size_t nl):

This member is used to set the right margin of the output. The parameter nl specifies the number of spaces that precede the end-of-line.

o
size_t rm() const:

Returns the current right margin.

o
void tabWidth(size_t tabWidth):

This member can be used to select tab-characters to be used when inserting left margins. The second parameter is used to specify the display width of a tab-character.

STATIC MEMBER FUNCTIONS

o
size_t leftMargin(std::ostreambuf const *buffer):

This member returns the current left margin setting of the OFoldBuf object passed to it as its argument. The member defines a std::streambuf parameter which is down cast to an OFoldBuf and an FBB::Exception exception is thrown if that cast fails.

o
size_t rightMargin(std::ostreambuf const *buffer):

This member returns the current right margin setting of the OFoldBuf object passed to it as its argument. The member’s parameter is down cast in the same way as leftMargin()'s argument: an FBB::Exception exception is thrown if that cast fails.

EXAMPLE

    #include <iostream>
    #include <ostream>
    #include <string>
    #include <bobcat/ofoldbuf>
    using namespace std;
    using namespace FBB;
    int main()
    {
        OFoldBuf fb(cout, 4, 40);
        ostream out(&fb);
        out << lm(4);
        string line;
        while (getline(cin, line))
            out << line << ’\n’;
    }
