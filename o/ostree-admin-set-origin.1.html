ostree-admin-set-origin(1)

الحزمة: ostree

التراخيص: LGPL-2.0-or-later

OSTREE ADMIN SET-OR(1) ostree admin set-origin OSTREE ADMIN SET-OR(1)

الاسم

ostree-admin-set-origin - تغيير "المصدر" (موقع الترقيات)

الملخص

ostree admin set-origin {اسم_الريموت} {عنوان_URL} [فرع]

الوصف

إضافة ريموت جديد باسم اسم_الريموت (إذا لم يكن موجودًا بالفعل). ثم تغيير ملف المصدر للنشر الحالي. هذا هو المرجع الذي سيتم "تتبعه" وترقيته باستخدام ostree admin upgrade.

الخيارات

--set=مفتاح=قيمة

تعيين خيار للريموت.

--index=فهرس

تغيير مصدر النشر المرقم فهرس (بدءًا من 0).

مثال

$ ostree admin set-origin exampleos http://os.example.com/repo exampleos/10.0/main/router
