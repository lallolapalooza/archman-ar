DESCRIPTION

OSSL_STORE is a generic interface for storing and retrieving cryptographic objects. These objects are commonly used in TLS and other cryptographic protocols. The OSSL_STORE_INFO structure is a container for retrieved objects.

An OSSL_STORE_INFO structure holds a single retrieved object. This object can be of different types, as indicated by the OSSL_STORE_INFO_get_type() function. The other OSSL_STORE_INFO_get0_*() and OSSL_STORE_INFO_get1_*() functions are accessors to retrieve the actual object. The *_get0_* variants return a pointer to the object owned by the OSSL_STORE_INFO structure, while the *_get1_* variants return a duplicate of the object that must be freed by the caller.

The OSSL_STORE_INFO_new_*() functions are constructors for creating new OSSL_STORE_INFO structures. These are typically used when implementing custom loaders.

OSSL_STORE_INFO_set0_NAME_description() sets the description associated with a NAME object. The description is owned by the OSSL_STORE_INFO structure.

OSSL_STORE_INFO_type_string() returns a human-readable string representation of the type of the object contained in the OSSL_STORE_INFO structure.

SUPPORTED OBJECTS

OSSL_STORE_INFO_NAME
A symbolic name. This is often used to identify an object or a group of objects.
OSSL_STORE_INFO_NAME_DESCRIPTION
A textual description associated with a name.
OSSL_STORE_INFO_PARAMS
Parameters, for example, Diffie-Hellman parameters.
OSSL_STORE_INFO_PKEY
A private key (possibly with key parameters).
OSSL_STORE_INFO_CERT
An X.509 certificate.
OSSL_STORE_INFO_CRL
A X.509 certificate revocation list.

RETURN VALUES

OSSL_STORE_INFO_get_type() returns the STORE type number of the given OSSL_STORE_INFO. There is no error value.

OSSL_STORE_INFO_get0_NAME(), OSSL_STORE_INFO_get0_NAME_description(), OSSL_STORE_INFO_get0_PARAMS(), OSSL_STORE_INFO_get0_PKEY(), OSSL_STORE_INFO_get0_CERT() and OSSL_STORE_INFO_get0_CRL() all return a pointer to the OpenSSL object on success, NULL otherwise.

OSSL_STORE_INFO_get1_NAME(), OSSL_STORE_INFO_get1_NAME_description(), OSSL_STORE_INFO_get1_PARAMS(), OSSL_STORE_INFO_get1_PKEY(), OSSL_STORE_INFO_get1_CERT() and OSSL_STORE_INFO_get1_CRL() all return a pointer to a duplicate of the OpenSSL object on success, NULL otherwise.

OSSL_STORE_INFO_type_string() returns a string on success, or NULL on failure.

OSSL_STORE_INFO_new_NAME(), OSSL_STORE_INFO_new_PARAMS(), OSSL_STORE_INFO_new_PKEY(), OSSL_STORE_INFO_new_CERT() and OSSL_STORE_INFO_new_CRL() return a OSSL_STORE_INFO pointer on success, or NULL on failure.

OSSL_STORE_INFO_set0_NAME_description() returns 1 on success, or 0 on failure.

SEE ALSO

HISTORY

The OSSL_STORE API was added in OpenSSL 1.1.1.

The OSSL_STORE_INFO_PUBKEY object type was added in OpenSSL 3.0.

الوصف

OSSL_STORE هي واجهة عامة لتخزين واسترجاع الكائنات التشفيرية. تُستخدم هذه الكائنات عادةً في بروتوكولات TLS وبروتوكولات التشفير الأخرى. يمثل هيكل OSSL_STORE_INFO حاوية للكائنات التي تم استرجاعها.

يمثل هيكل OSSL_STORE_INFO كائنًا واحدًا تم استرجاعه. يمكن أن يكون هذا الكائن من أنواع مختلفة، كما تشير إليه الدالة OSSL_STORE_INFO_get_type(). تقوم دوال OSSL_STORE_INFO_get0_*() و OSSL_STORE_INFO_get1_*() الأخرى باسترداد الكائن الفعلي. ترجع المتغيرات *_get0_* مؤشرًا إلى الكائن المملوك لهيكل OSSL_STORE_INFO، بينما ترجع المتغيرات *_get1_* نسخة مكررة من الكائن الذي يجب تحريره بواسطة المتصل.

تُعد الدوال OSSL_STORE_INFO_new_*() مُنشئات لإنشاء هياكل OSSL_STORE_INFO جديدة. تُستخدم هذه عادةً عند تنفيذ مُحمّلات مخصصة.

تقوم الدالة OSSL_STORE_INFO_set0_NAME_description() بتعيين الوصف المرتبط بكائن NAME. يمتلك هيكل OSSL_STORE_INFO هذا الوصف.

تقوم الدالة OSSL_STORE_INFO_type_string() بإرجاع تمثيل نصي قابل للقراءة من قبل الإنسان لنوع الكائن الموجود في هيكل OSSL_STORE_INFO.

الكائنات المدعومة

OSSL_STORE_INFO_NAME
اسم رمزي. يُستخدم هذا غالبًا لتحديد كائن أو مجموعة من الكائنات.
OSSL_STORE_INFO_NAME_DESCRIPTION
وصف نصي مرتبط باسم.
OSSL_STORE_INFO_PARAMS
معلمات، على سبيل المثال، معلمات Diffie-Hellman.
OSSL_STORE_INFO_PKEY
مفتاح خاص (ربما مع معلمات المفتاح).
OSSL_STORE_INFO_CERT
شهادة X.509.
OSSL_STORE_INFO_CRL
قائمة إلغاء شهادات X.509.

قيم الإرجاع

تُرجع الدالة OSSL_STORE_INFO_get_type() رقم نوع المتجر لـ OSSL_STORE_INFO المعطى. لا توجد قيمة خطأ.

تقوم كل من الدوال OSSL_STORE_INFO_get0_NAME()، OSSL_STORE_INFO_get0_NAME_description()، OSSL_STORE_INFO_get0_PARAMS()، OSSL_STORE_INFO_get0_PKEY()، OSSL_STORE_INFO_get0_CERT() و OSSL_STORE_INFO_get0_CRL() بإرجاع مؤشر إلى كائن OpenSSL عند النجاح، و NULL بخلاف ذلك.

تقوم كل من الدوال OSSL_STORE_INFO_get1_NAME()، OSSL_STORE_INFO_get1_NAME_description()، OSSL_STORE_INFO_get1_PARAMS()، OSSL_STORE_INFO_get1_PKEY()، OSSL_STORE_INFO_get1_CERT() و OSSL_STORE_INFO_get1_CRL() بإرجاع مؤشر إلى نسخة مكررة من كائن OpenSSL عند النجاح، و NULL بخلاف ذلك.

تُرجع الدالة OSSL_STORE_INFO_type_string() سلسلة نصية عند النجاح، أو NULL عند الفشل.

تُرجع الدوال OSSL_STORE_INFO_new_NAME()، OSSL_STORE_INFO_new_PARAMS()، OSSL_STORE_INFO_new_PKEY()، OSSL_STORE_INFO_new_CERT() و OSSL_STORE_INFO_new_CRL() مؤشر OSSL_STORE_INFO عند النجاح، أو NULL عند الفشل.

تُرجع الدالة OSSL_STORE_INFO_set0_NAME_description() القيمة 1 عند النجاح، أو 0 عند الفشل.
