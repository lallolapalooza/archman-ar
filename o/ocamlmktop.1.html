ocamlmktop(1)

الحزمة: ocaml

التراخيص: LGPL2.1, custom: QPL-1.0

OCAMLMKTOP(1) دليل الأوامر العامة OCAMLMKTOP(1)

الاسم

ocamlmktop - بناء أنظمة توابل مخصصة

الملخص

ocamlmktop [ -v|-version|-vnum ] [ -cclib اسم_المكتبة ] [ -ccopt خيار ] [ -custom ] [ -o ملف_تنفيذي ] [ -I دليل_المكتبة ] اسم_الملف ...

الوصف

يقوم الأمر ocamlmktop(1) ببناء أنظمة OCaml توابل تحتوي على كود مستخدم محمل مسبقًا عند بدء التشغيل. يأخذ الأمر ocamlmktop(1) كمُعاملات مجموعة من ملفات x.cmo و x.cma، ويربطها بملفات الكائنات التي تنفذ نظام OCaml توابل. إذا تم تقديم العلامة -custom، فيمكن أيضًا تقديم ملفات الكائنات C والمكتبات (.o و .a) على سطر الأوامر ويتم ربطها في نظام التوابل الناتج.

الخيارات

يتم التعرف على خيارات سطر الأوامر التالية بواسطة ocamlmktop(1).

-v
طباعة سلسلة إصدار المترجم والخروج.
-vnum أو -version
طباعة رقم إصدار المترجم بشكل مختصر والخروج.
-cclib -lاسم_المكتبة
تمرير خيار -lاسم_المكتبة إلى رابط C عند الربط في وضع "وقت التشغيل المخصص" (انظر الخيار المقابل لـ ocamlc(1).
-ccopt
تمرير الخيار المحدد إلى مترجم C ورابطه، عند الربط في وضع "وقت التشغيل المخصص". انظر الخيار المقابل لـ ocamlc(1).
-custom
الربط في وضع "وقت التشغيل المخصص". انظر الخيار المقابل لـ ocamlc(1).
-I دليل
إضافة الدليل المحدد إلى قائمة الأدلة التي يتم البحث فيها عن ملفات الواجهة المترجمة (.cmo و .cma).
-o ملف_تنفيذي
تحديد اسم ملف التوابل الذي ينتجه الرابط. الافتراضي هو a.out.

انظر أيضًا

ocamlc(1).
