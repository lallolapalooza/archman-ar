يمكن تعريفه بحرية

الطرق

void Release() [noreply]

يتم استدعاء هذه الطريقة عندما يقوم bluetoothd(8) بإلغاء تسجيل الملف التعريفي.

يمكن للملف التعريفي استخدامه للقيام بمهام التنظيف. لا توجد حاجة لإلغاء تسجيل الملف التعريفي، لأنه عندما يتم استدعاء هذه الطريقة، يكون قد تم إلغاء تسجيله بالفعل.

void NewConnection(object device, fd, dict fd_properties)

يتم استدعاء هذه الطريقة عندما يتم إنشاء اتصال جديد على مستوى الخدمة وتفويضه.

القيم المحتملة لـ fd_properties:

uint16 Version [اختياري]
إصدار الملف التعريفي.
uint16 Features [اختياري]
ميزات الملف التعريفي.

الأخطاء المحتملة:

org.bluez.Error.Rejected
