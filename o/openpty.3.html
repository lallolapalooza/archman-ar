openpty(3) دليل وظائف المكتبة openpty(3)

الاسم

openpty, login_tty, forkpty - وظائف أدوات طرفية

المكتبة

مكتبة أدوات النظام (libutil، -lutil)

الملخص

#include <pty.h>
int openpty(int *amaster, int *aslave, char *name,
              const struct termios *termp,
              const struct winsize *winp);
pid_t forkpty(int *amaster, char *name,
              const struct termios *termp,
              const struct winsize *winp);
#include <utmp.h>
int login_tty(int fd);

الوصف

تقوم الدالة openpty() بالبحث عن طرفية افتراضية متاحة وإرجاع واصفات الملفات للجانب الرئيسي (master) والجانب العبد (slave) في amaster و aslave. إذا كان name ليس NULL، فسيتم إرجاع اسم ملف الجانب العبد في name. إذا كان termp ليس NULL، فسيتم تعيين معلمات الطرفية للجانب العبد إلى القيم الموجودة في termp. إذا كان winp ليس NULL، فسيتم تعيين حجم النافذة للجانب العبد إلى القيم الموجودة في winp.

تقوم الدالة login_tty() بالتحضير لتسجيل الدخول على الطرفية المشار إليها بواسطة واصف الملف fd (والذي قد يكون جهاز طرفية حقيقي، أو جانب عبد لطرفية افتراضية كما تم إرجاعه بواسطة openpty()) عن طريق إنشاء جلسة جديدة، وجعل fd الطرفية المتحكمة للعملية المستدعية، وجعل fd تدفقات الإدخال والإخراج والخطأ القياسية للعملية الحالية، وإغلاق fd.

تجمع الدالة forkpty() بين openpty() و fork(2) و login_tty() لإنشاء عملية جديدة تعمل في طرفية افتراضية. يتم إرجاع واصف ملف يشير إلى الجانب الرئيسي للطرفية الافتراضية في amaster. إذا كان name ليس NULL، فإن المخزن المؤقت الذي يشير إليه يتم استخدامه لإرجاع اسم ملف الجانب العبد. الوسيطات termp و winp، إذا لم تكن NULL، ستحدد سمات الطرفية وحجم النافذة للجانب العبد للطرفية الافتراضية.

قيمة الإرجاع

إذا لم تكن استدعاءات openpty() أو login_tty() أو forkpty() ناجحة، فسيتم إرجاع -1 وسيتم تعيين errno للإشارة إلى الخطأ. بخلاف ذلك، ترجع openpty() و login_tty() والعملية الفرعية لـ forkpty() القيمة 0، وترجع العملية الأصلية لـ forkpty() معرف العملية للعملية الفرعية.

الأخطاء

تفشل openpty() إذا:

ENOENT
لا توجد أطرافية متاحة.

تفشل login_tty() إذا فشلت ioctl(2) في تعيين fd إلى الطرفية المتحكمة للعملية المستدعية.

تفشل forkpty() إذا فشلت إما openpty() أو fork(2).

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، راجع attributes(7).

الواجهة السمة القيمة
forkpty (), openpty () سلامة الخيوط MT-Safe locale
login_tty () سلامة الخيوط MT-Unsafe race:ttyname

المعايير

BSD.

التاريخ

تمت إضافة معدلات const إلى وسائط مؤشرات الهياكل في openpty() و forkpty() في glibc 2.8.

قبل glibc 2.0.92، ترجع openpty() واصفات ملفات لزوج طرفية افتراضية BSD؛ منذ glibc 2.0.92، تحاول أولاً فتح زوج طرفية افتراضية UNIX 98، ثم تعود إلى فتح زوج طرفية افتراضية BSD إذا فشل ذلك.

الأخطاء

لا أحد يعرف كم يجب تخصيص مساحة لـ name. لذا، قد يكون استدعاء openpty() أو forkpty() مع name غير NULL غير آمن.
