الاسم

org.freedesktop.import1 - واجهة D-Bus لـ systemd-importd

مقدمة

systemd-importd.service(8) هي خدمة نظام يمكن استخدامها لاستيراد وتصدير وتنزيل صور الأقراص. يمكن استخدام هذه الصور بواسطة أدوات مثل systemd-nspawn(1) لتشغيل الحاويات المحلية. تُستخدم الخدمة كخلفية لأوامر importctl pull-raw و importctl pull-tar والأوامر ذات الصلة. تصف هذه الصفحة واجهة D-Bus.

لاحظ أن systemd-importd.service(8) هي في الغالب خدمة مصاحبة صغيرة لـ systemd-machined.service(8). لذلك، تتوفر العديد من العمليات للتلاعب بصور الحاويات والأجهزة الافتراضية المحلية عبر واجهة برمجة تطبيقات D-Bus الخاصة بـ systemd-machined، راجع org.freedesktop.machine1(5).

الأساليب

ImportTar()/ImportTarEx() و ImportRaw()/ImportRawEx() تستورد صورة قرص وتضعها في دليل الصور. يجب أن يكون الوسيط الأول واصف ملف (تم فتحه للقراءة) يشير إلى ملف tar أو ملف خام المراد استيراده. يجب أن يشير إلى ملف على القرص، أو أنبوب، أو مقبس. عند استخدام ImportTar()/ImportTarEx()، يجب أن يشير واصف الملف إلى ملف tar، مضغوط اختياريًا بواسطة gzip(1) أو zstd(1) أو bzip2(1) أو xz(1). سيكتشف systemd-importd مخطط الضغط المستخدم (إن وجد) تلقائيًا. عند استخدام ImportRaw()/ImportRawEx()، يجب أن يشير واصف الملف إلى صورة قرص خام أو qcow2 تحتوي على تسمية قرص MBR أو GPT، مضغوطة اختياريًا أيضًا بواسطة gzip أو zstd أو bzip2 أو xz. في كلتا الحالتين، إذا تم تحديد الملف كواصف ملف على القرص، يتم إنشاء معلومات التقدم لعملية الاستيراد (حيث إننا نعرف الحجم الكلي على القرص). إذا تم تحديد مقبس أو أنبوب، فلن تكون معلومات التقدم متاحة. يتبع وسيط واصف الملف اسم محلي للصورة. يجب أن يكون هذا اسمًا مناسبًا كاسم مضيف وسيتم استخدامه لتسمية الصورة المستوردة أسفل /var/lib/machines/. يتم وضع استيراد tar كشجرة دليل أو كـ btrfs(8) subvolume أسفل دليل الصور تحت الاسم المحدد بدون لاحقة. يتم وضع استيراد خام كملف في دليل الصور مع إضافة اللاحقة .raw. في حالة ImportTar()/ImportRaw()، إذا كان الوسيط force صحيحًا، فسيتم إزالة أي صورة موجودة بنفس الاسم قبل بدء العملية. وإلا، تفشل العملية إذا كانت هناك صورة بنفس الاسم موجودة بالفعل. يتحكم الوسيط read_only في ما إذا كان سيتم إنشاء صورة قابلة للكتابة أو للقراءة فقط. في حالة ImportTarEx()/ImportRawEx()، يتم توفير هذه الأعلام المنطقية عبر معلمة أعلام (flags) بحجم 64 بت بدلاً من ذلك، حيث يرتبط البت 0 بالمعلمة force، والبت 1 بالمعلمة read_only. تحدد المعلمة class فئة الصورة، وتأخذ إحدى القيم: "machine" أو "portable" أو "sysext" أو "confext". تعود جميع الأساليب الأربعة فورًا بعد بدء الاستيراد، مع استمرار عملية الاستيراد. تعود بزوج من معرف النقل ومسار الكائن، والذي يمكن استخدامه لاسترداد معلومات التقدم حول النقل أو إلغائه. معرف النقل هو معرف رقمي بسيط، ومسار الكائن يشير إلى كائن org.freedesktop.import1.Transfer، راجع أدناه. استمع إلى إشارة TransferRemoved() لمعرف النقل للكشف عن اكتمال النقل. كائن النقل المُرجع مفيد لتحديد التقدم الحالي أو سجلات الإخراج لعملية الاستيراد الجارية.

ExportTar()/ExportTarEx() و ExportRaw()/ExportRaw() تنفذ العملية العكسية، ويمكن استخدامها لتصدير صورة نظام لوضعها في ملف tar أو صورة خام. تأخذ اسم الجهاز المراد تصديره كوسيطها الأول، متبوعًا بواصف ملف (مفتوح للكتابة) حيث سيتم كتابة ملف tar أو الملف الخام. يمكن أن يشير إما إلى ملف على القرص أو أنبوب/مقبس. يحدد الوسيط الثالث تنسيق الضغط الذي سيتم كتابة الصورة به. يأخذ إحدى القيم: "uncompressed" أو "xz" أو "bzip2" أو "gzip" أو "zstd"، اعتمادًا على مخطط الضغط المطلوب. ستكون الصورة المكتوبة إلى واصف الملف المحدد ملف tar في حالة ExportTar()/ExportTarEx() أو صورة قرص خام في حالة ExportRaw()/ExportRawEx(). لاحظ أنه في الوقت الحالي، لا يمكن تصدير صور الأقراص الخام كملفات tar، والعكس صحيح. قد يتم رفع هذا القيد في النهاية. تعيد الطريقة معرف نقل ومسار كائن لإلغاء أو تتبع عملية التصدير، بشكل مشابه لـ ImportTar()/ImportTarEx() أو ImportRaw()/ImportRawEx() كما هو موضح أعلاه. تتوقع ExportTarEx()/ExportRawEx() فئة الصورة كوسيط إضافي، وهو

import1.5.html

NAME

org.freedesktop.import1 - Programma di utilità per l'importazione di dati

SYNOPSIS

org.freedesktop.import1 [OPTIONS...] {IMPORT_SPEC}...

DESCRIPTION

org.freedesktop.import1 è un programma di utilità per l'importazione di dati da varie fonti in un'applicazione o in un database. Supporta diversi formati di input e destinazioni di output.

COMMANDS

Il comando principale è importare dati. I comandi specifici dipendono dalla configurazione e dai plugin disponibili.

OPTIONS

  • --verbose: Abilita l'output dettagliato.
  • --force: Sovrascrive i dati esistenti.
  • --config=FILE: Specifica un file di configurazione alternativo.

EXIT STATUS

Lo stato di uscita indica se l'operazione di importazione è andata a buon fine o meno.

EXAMPLES

Esempio di utilizzo:

org.freedesktop.import1 --verbose --config=myconfig.conf data.csv

FILES

  • /etc/org.freedesktop.import1.conf: File di configurazione predefinito.

ENVIRONMENT

Le variabili d'ambiente possono influenzare il comportamento di org.freedesktop.import1, ad esempio per le credenziali di accesso.

DEPENDENCIES

Potrebbero esserci dipendenze da librerie o altri programmi a seconda dei plugin utilizzati.
