od(1)

الحزمة: coreutils

التراخيص: GPL-3.0-or-later, GFDL-1.3-or-later

OD(1) أوامر المستخدم OD(1)

الاسم

od - تفريغ الملفات بصيغة ثمانية وصيغ أخرى

ملخص

od [خيار]... [ملف]...
od [-abcdfilosx]... [ملف] [[+]إزاحة[.][ثنائي]]
od --traditional [خيار]... [ملف] [[+]إزاحة[.][ثنائي] [+][تسمية][.][ثنائي]]

الوصف

اكتب تمثيلًا لا لبس فيه، بايتات ثمانية افتراضيًا، لـ ملف إلى المخرج القياسي. مع أكثر من وسيطة ملف واحدة، قم بدمجها بالترتيب المدرج لتشكيل المدخلات.

بدون ملف، أو عندما يكون ملف هو -، اقرأ المدخل القياسي.

إذا كان تنسيقا الاستدعاء الأول والثاني ينطبقان، يفترض التنسيق الثاني إذا بدأت الوسيطة الأخيرة بـ + أو (إذا كان هناك وسيطتان) رقم. تعني وسيطة الإزاحة -j OFFSET. LABEL هي العنوان الزائف عند طباعة البايت الأول، وتزداد عند تقدم التفريغ. بالنسبة لـ OFFSET و LABEL، يشير البادئة 0x أو 0X إلى الستة عشر، وقد تكون اللواحق . للثمانية و b للضرب في 512.

الوسائط الإلزامية للخيارات الطويلة إلزامية للخيارات القصيرة أيضًا.

-A, --address-radix=RADIX
تنسيق الإخراج لمواقع الملف؛ RADIX هو أحد [doxn]، للأرقام العشرية، الثمانية، الستة عشر، أو لا شيء
--endian={big|little}
تبديل بايتات الإدخال وفقًا للترتيب المحدد
-j, --skip-bytes=BYTES
تخطي BYTES بايت إدخال أولاً
-N, --read-bytes=BYTES
تحديد التفريغ إلى BYTES بايت إدخال
-S BYTES, --strings[=BYTES]
عرض السلاسل المنتهية بـ NUL فقط والتي لا تقل عن BYTES (3) حرف قابل للطباعة
-t, --format=TYPE
اختيار تنسيق الإخراج أو التنسيقات
-v, --output-duplicates
لا تستخدم * للإشارة إلى كبت الأسطر
-w[BYTES], --width[=BYTES]
إخراج BYTES بايت لكل سطر إخراج؛ يتم افتراض 32 عندما لا يتم تحديد BYTES
--traditional
قبول الوسائط بالشكل الثالث أعلاه
--help
عرض هذه المساعدة والخروج
--version
إخراج معلومات الإصدار والخروج

يمكن تداخل مواصفات التنسيق التقليدية؛ تتراكم:

-a
نفس -t a، اختر الأحرف المسماة، مع تجاهل البت عالي المستوى
-b
نفس -t o1، اختر بايتات ثمانية
-c
نفس -t c، اختر الأحرف القابلة للطباعة أو هروب الشرطة المائلة العكسية
-d
نفس -t u2، اختر وحدات ثنائية غير موقعة عشرية
-f
نفس -t fF، اختر أعداد عشرية عائمة
-i
نفس -t dI، اختر أعداد صحيحة عشرية
-l
نفس -t dL، اختر أعداد طويلة عشرية
-o
نفس -t o2، اختر وحدات ثمانية ثنائية
-s
نفس -t d2، اختر وحدات عشرية ثنائية
-x
نفس -t x2، اختر وحدات ستة عشرية ثنائية

يتكون TYPE من مواصفة واحدة أو أكثر من المواصفات التالية:

a
حرف مسمى، مع تجاهل البت عالي المستوى
c
حرف قابل للطباعة أو هروب بشرطة مائلة عكسية
d[SIZE]
عشري موقع، SIZE بايت لكل عدد صحيح
f[SIZE]
فاصلة عائمة، SIZE بايت لكل عدد عائم
o[SIZE]
ثماني، SIZE بايت لكل عدد صحيح
u[SIZE]
عشري غير موقع، SIZE بايت لكل عدد صحيح
x[SIZE]
ستة عشري، SIZE بايت لكل عدد صحيح

SIZE هو رقم. بالنسبة لـ TYPE في [doux]، يمكن أن يكون SIZE أيضًا C لحجم char، S لحجم short، I لحجم int، أو L لحجم long. إذا كان TYPE هو f، يمكن أن يكون SIZE أيضًا B لـ Brain 16 bit، H لـ Half precision float، F لـ sizeof(float)، D لـ sizeof(double)، أو L لـ sizeof(long double).

إضافة اللاحقة z إلى أي نوع يعرض الأحرف القابلة للطباعة في نهاية كل سطر إخراج.

BYTES هو ستة عشري مع بادئة 0x أو 0X، وقد يحتوي على لاحقة مضاعفة:

b
512
KB
1000
K
1024
MB
1000*1000
M
1024*1024

وهكذا للمضاعفات G، T، P، E، Z، Y، R، Q. يمكن أيضًا استخدام البادئات الثنائية: KiB=K، MiB=M، وهكذا.

أمثلة

od -A x -t x1z -v
عرض إخراج بتنسيق hexdump
od -A o -t oS -w16
تنسيق الإخراج الافتراضي الذي يستخدمه od
