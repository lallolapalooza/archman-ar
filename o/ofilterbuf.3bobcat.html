NAME

ofilterbuf — filter output stream buffer

SYNOPSIS

#include <bobcat/ofilterbuf>

Class hierarchy:
Object → streambuf → obuf → ofilterbuf

DESCRIPTION

This class is a buffer for filtering output. The derived classes will be able to transform or manipulate the output of the underlying buffer.

NAMESPACE

namespace bobcat

INHERITS FROM

obuf, streambuf, Object

CONSTRUCTORS

Constructors are protected as this is an abstract base class.

ofilterbuf(std::ostream &os) Constructs an ofilterbuf object. The output stream buffer is associated with the output stream os.

ofilterbuf(std::streambuf &buf) Constructs an ofilterbuf object. The output stream buffer is associated with the stream buffer buf.

PROTECTED MEMBER FUNCTIONS

int overflow(int c) This virtual function must be overridden by derived classes. It is called by the stream when the buffer is full. The character c is the character that has caused the buffer to overflow.

std::streambuf::int_type sync() Synchronize the buffer. This virtual function may be overridden by derived classes. It is called by the stream when the buffer needs to be flushed. The default implementation does nothing.

EXAMPLE

There is no example for this class, as it is an abstract base class. See the derived classes for examples.

الاسم

ofilterbuf — مخزن مؤقت لتدفق الإخراج المرشح

ملخص

#include <bobcat/ofilterbuf>

تسلسل الفئة:
Object → streambuf → obuf → ofilterbuf

الوصف

هذه الفئة عبارة عن مخزن مؤقت لتصفية الإخراج. ستكون الفئات المشتقة قادرة على تحويل أو معالجة إخراج المخزن المؤقت الأساسي.

المساحة الاسمية

namespace bobcat

يرث من

obuf, streambuf, Object

المنشئات

المنشئات محمية لأن هذه فئة أساسية مجردة.

ofilterbuf(std::ostream &os) ينشئ كائن ofilterbuf. يتم ربط مخزن الإخراج المؤقت بتدفق الإخراج os.

ofilterbuf(std::streambuf &buf) ينشئ كائن ofilterbuf. يتم ربط مخزن الإخراج المؤقت بالمخزن المؤقت للتدفق buf.

دوال الأعضاء المحمية

int overflow(int c) يجب أن تعيد هذه الدالة الافتراضية تعريفها في الفئات المشتقة. يتم استدعاؤها بواسطة التدفق عندما يكون المخزن المؤقت ممتلئًا. الحرف c هو الحرف الذي تسبب في تجاوز سعة المخزن المؤقت.

std::streambuf::int_type sync() مزامنة المخزن المؤقت. يمكن إعادة تعريف هذه الدالة الافتراضية في الفئات المشتقة. يتم استدعاؤها بواسطة التدفق عندما يحتاج المخزن المؤقت إلى تفريغه. التنفيذ الافتراضي لا يفعل شيئًا.

لا يوجد مثال لهذه الفئة، لأنها فئة أساسية مجردة. انظر الفئات المشتقة للأمثلة.
