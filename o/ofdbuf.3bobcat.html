FBB::OFdBuf(3bobcat) مخزن مؤقت لتيار إخراج واصف الملف FBB::OFdBuf(3bobcat)

الاسم

FBB::OFdBuf - مخزن مؤقت لتيار إخراج تم تهيئته بواسطة واصف ملف

الملخص

#include <bobcat/ofdbuf>
خيار الربط: -lbobcat

الوصف

يمكن استخدام كائنات FBB::OFdBuf كـ std::streambuf لكائنات std::ostream للسماح بالإدخال في واصف ملف.

لا يتم تعريف واصفات الملف ضمن سياق C++، ولكن يمكن استخدامها على أنظمة التشغيل التي تدعم هذا المفهوم. أدرك أن استخدام واصفات الملفات يدخل تبعيات نظام التشغيل.

اسم النطاق

FBB
جميع المنشئات والأعضاء والعوامل والمعدلات المذكورة في صفحة الدليل هذه معرفة في اسم النطاق FBB.

ترث من

std::streambuf

تعداد

التعداد العام Mode المعرف في الفئة FBB::OFdStreamBuf له القيم التالية:

o
CLOSE_FD، يشير إلى أنه يجب إغلاق واصف الملف المستخدم بواسطة الكائن؛
o
KEEP_FD (الافتراضي) يشير إلى أنه لا يجب إغلاق واصف الملف المستخدم بواسطة الكائن.

المنشئات

o
OFdBuf():
يقوم هذا المنشئ بتهيئة المخزن المؤقت للتيار، دون ربطه بواصف ملف، ودون استخدام التخزين المؤقت. يمكن استخدام العضو reset لربط الكائن لاحقًا بواصف ملف وحجم مخزن مؤقت اختياري. عند تدمير الكائن أو إذا تم استدعاء الإصدار غير المحدد الأنماط من العضو reset، يتم إغلاق واصف الملف.
o
OFdBuf(Mode mode):
يقوم هذا المنشئ بتهيئة المخزن المؤقت للتيار، دون ربطه بواصف ملف، ودون استخدام التخزين المؤقت. يمكن استخدام العضو reset لربط الكائن لاحقًا بواصف ملف وحجم مخزن مؤقت اختياري. عند تدمير الكائن أو إذا تم استدعاء الإصدار غير المحدد الأنماط من العضو reset، يحدد وسيط Mode ما إذا كان سيتم إغلاق واصف الملف أم سيبقى مفتوحًا.
o

يقوم هذا المنشئ بتهيئة المخزن المؤقت للتيار، وربطه بواصف الملف fd، وحجم مخزن مؤقت غير مرتجع اختياري (بحجم افتراضي 1). عند تدمير الكائن أو إذا تم استدعاء الإصدار المحدد الأنماط من العضو reset، يحدد وسيط Mode ما إذا كان سيتم إغلاق واصف الملف المستخدم حاليًا بواسطة الكائن أم سيبقى مفتوحًا.

منشئات النسخ والنقل (وعوامل التعيين) غير متوفرة.

وظائف الأعضاء

جميع أعضاء std::streambuf متوفرة، حيث أن FBB::OFdBuf ترث من هذه الفئة.

o
void eoi():
يتم إغلاق واصف الملف المستخدم بواسطة OFdBuf، بغض النظر عن Mode الذي تم تحديده عند إنشاء كائن OFdBuf. بعد eoi، لا يمكن استخدام كائن OFdBuf مرة أخرى حتى يتم استدعاء أحد أعضائه reset. بدلاً من استخدام هذا العضو، يمكن أيضًا استخدام المعدل eoi.
o
int fd() const:
يتم إرجاع واصف الملف المستخدم بواسطة كائن OFdBuf. إذا لم يكن OFdBuf مرتبطًا بواصف ملف، فسيتم إرجاع -1.
o
void reset(int xfd, size_t n = 1):
يتم (إعادة) تهيئة المخزن المؤقت للتيار، باستخدام واصف الملف fd، وحجم مخزن مؤقت غير مرتجع اختياري (بحجم افتراضي 1). عند الاستدعاء بشكل متكرر، يحدد مواصفات Mode المستخدمة عند إنشاء الكائن ما إذا كان سيتم إغلاق واصف الملف أم سيبقى مفتوحًا.
o
void reset(int xfd, Mode mode, size_t n = 1):
يتم (إعادة) تهيئة المخزن المؤقت للتيار، باستخدام واصف الملف fd، ومعامل إغلاق واصف الملف، وحجم مخزن مؤقت غير مرتجع اختياري (بحجم افتراضي 1). اعتمادًا على الوسيط Mode، سيتم إغلاق واصف الملف المستخدم حاليًا بواسطة الكائن أم سيبقى مفتوحًا عند تدمير كائن IFdBuf.
o
void warn(bool on):
عندما تكون on == true، يتم كتابة تحذير إلى تيار الخطأ القياسي عندما يعيد العضو sync القيمة -1. إذا لم يتم استدعاء warn بشكل صريح، فسيتم استخدام on == true.

المعدل

o
FBB::eoi:
يمكن إدراج المعدل eoi في ostream بدلاً من استدعاء العضو OFdBuf::end. يقوم بتنفيذ نفس الإجراءات التي يقوم بها العضو eoi. إذا تم إدراجه في std::ostream عادي، فلن يحدث شيء.

مثال

#include <unistd.h>
#include <ostream>
#include <string>
#include "../ofdbuf"
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
                           // define a streambuf of 20 or argv[1] characters
    OFdBuf buf{ STDOUT_FILENO, argc == 1 ? 20 : stoul(argv[1]) };
    ostream out{ &buf };
    out << "First line, just to start the insertions\n" <<
            argv[0] << endl <<          // using an explicit flush
            argc << "\n"
            "a long line to end this multiple-insertions statement\n";
}
