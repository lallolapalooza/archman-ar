openssl-sess_id(1ssl)

الحزمة: openssl

التراخيص: Apache-2.0

OPENSSL-SESS_ID(1ssl) OpenSSL OPENSSL-SESS_ID(1ssl)

الاسم

openssl-sess_id - أمر معالجة جلسة SSL/TLS

الملخص

openssl sess_id [-help] [-inform DER|PEM] [-outform DER|PEM|NSS] [-in filename] [-out filename] [-text] [-cert] [-noout] [-context ID]

الوصف

يعالج هذا الأمر النسخة المشفرة من بنية جلسة SSL ويطبع اختياريًا تفاصيل جلسة SSL (على سبيل المثال، المفتاح الرئيسي لجلسة SSL) بتنسيق قابل للقراءة. نظرًا لأن هذه أداة تشخيصية تتطلب بعض المعرفة ببروتوكول SSL لاستخدامها بشكل صحيح، فلن يحتاجها معظم المستخدمين.

قد يختلف التنسيق الدقيق للبيانات عبر إصدارات OpenSSL وهو غير موثق.

الخيارات

-help
طباعة رسالة استخدام.
-inform DER|PEM, -outform DER|PEM|NSS
تنسيقات الإدخال والإخراج؛ الافتراضي هو PEM. انظر openssl-format-options(1) للتفاصيل.

بالنسبة لإخراج NSS، يتم الإبلاغ عن معرف الجلسة والمفتاح الرئيسي بتنسيق "keylog" الخاص بـ NSS.

-in filename
يحدد هذا اسم ملف الإدخال لقراءة معلومات الجلسة منه أو الإدخال القياسي افتراضيًا.
-out filename
يحدد هذا اسم ملف الإخراج لكتابة معلومات الجلسة إليه أو الإخراج القياسي إذا لم يتم تحديد هذا الخيار.
-text
يطبع مكونات المفتاح العامة أو الخاصة المختلفة بتنسيق نص عادي بالإضافة إلى النسخة المشفرة.
-cert
إذا كان هناك شهادة موجودة في الجلسة، فسيتم إخراجها باستخدام هذا الخيار. إذا تم تحديد الخيار -text أيضًا، فسيتم طباعتها بتنسيق نصي.
-noout
يمنع هذا الخيار إخراج النسخة المشفرة من الجلسة.
-context ID
يمكن لهذا الخيار تعيين معرف الجلسة حتى تستخدم معلومات الجلسة الناتجة المعرف المقدم. يمكن أن يكون المعرف أي سلسلة من الأحرف. هذا الخيار لن يستخدم عادة.

الإخراج

إخراج نموذجي:

SSL-Session:
    Protocol  : TLSv1
    Cipher    : 0016
    Session-ID: 871E62626C554CE95488823752CBD5F3673A3EF3DCE9C67BD916C809914B40ED
    Session-ID-ctx: 01000000
    Master-Key: A7CEFC571974BE02CAC305269DC59F76EA9F0B180CB6642697A68251F2D2BB57E51DBBB4C7885573192AE9AEE220FACD
    Key-Arg   : None
    Start Time: 948459261
    Timeout   : 300 (sec)
    Verify return code 0 (ok)

يتم وصف هذه العناصر بتفصيل أكبر أدناه.

Protocol
هذا هو البروتوكول قيد الاستخدام TLSv1.3، TLSv1.2، TLSv1.1، TLSv1 أو SSLv3.
Cipher
الخوارزمية المستخدمة، وهذا هو رمز الخوارزمية SSL أو TLS الخام الفعلي. انظر مواصفات SSL أو TLS لمزيد من المعلومات.
Session-ID
معرف جلسة SSL بتنسيق سداسي عشري.
Session-ID-ctx
سياق معرف الجلسة بتنسيق سداسي عشري.
Master-Key
هذا هو المفتاح الرئيسي لجلسة SSL.
Start Time
هذا هو وقت بدء الجلسة ممثلاً كرقم صحيح بتنسيق Unix القياسي.
Timeout
المهلة بالثواني.
Verify return code
هذا هو رمز الإرجاع عند التحقق من شهادة عميل SSL.

ملاحظات

نظرًا لأن إخراج جلسة SSL يحتوي على المفتاح الرئيسي، فمن الممكن قراءة محتويات جلسة مشفرة باستخدام هذه المعلومات. لذلك، يجب اتخاذ احتياطات أمنية مناسبة إذا كانت المعلومات يتم إخراجها بواسطة تطبيق "حقيقي". ومع ذلك، يُنصح بشدة بعدم القيام بذلك ويجب استخدامه لأغراض التصحيح فقط.

أخطاء

يجب طباعة الخوارزمية ووقت البدء بتنسيق قابل للقراءة.
