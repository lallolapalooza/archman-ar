الحزمة: openmotif

OverrideShell OverrideShell

الاسم

OverrideShell - فئة ودجت OverrideShell

الملخص

#include <Xm/Xm.h>
#include <X11/Shell.h>

الوصف

يُستخدم OverrideShell لنافذة shell التي تتجاوز تمامًا مدير النوافذ، على سبيل المثال، نوافذ القوائم المنبثقة.

الفئات

OverrideShell يرث السلوك والموارد من Core و Composite و Shell.

مؤشر الفئة هو overrideShellWidgetClass.

اسم الفئة هو OverrideShell.

الموارد الجديدة

لا تحدد OverrideShell أي موارد جديدة، ولكنها تتجاوز الموردين XmNoverrideRedirect و XmNsaveUnder من فئة Shell.

الموارد الموروثة

OverrideShell يرث السلوك والموارد من الفئات الفائقة التالية. لوصف كامل لكل مورد، راجع صفحة المرجع لكل فئة.

يحدد الجدول التالي مجموعة من موارد ودجت التي يستخدمها المبرمج لتحديد البيانات. يمكن للمبرمج أيضًا تعيين قيم الموارد للفئات الموروثة لتكوين سمات هذا الودجت. للإشارة إلى مورد بالاسم أو بالفئة في ملف .Xdefaults، قم بإزالة البادئة XmN أو XmC واستخدم الأحرف المتبقية. لتحديد أحد القيم المعرفة لمورد في ملف .Xdefaults، قم بإزالة البادئة Xm واستخدم الأحرف المتبقية (بحروف صغيرة أو كبيرة، ولكن قم بتضمين الشرطات بين الكلمات). تشير الرموز في عمود الوصول إلى ما إذا كان يمكن تعيين المورد وقت الإنشاء (C)، أو بواسطة XtSetValues (S)، أو بواسطة XtGetValues (G)، أو غير قابل للتطبيق (N/A).

NAME

OverrideShell - OverrideShell widget

SYNOPSIS

#include <Xm/OverrideSB.h>

DESCRIPTION

OverrideShell is a subclass of Shell. It creates a popup window that overrides the existing window. This means that the popup window appears on top of all other windows on the screen and is the only window that can receive user input.

The OverrideShell widget is used for creating dialog boxes, menus, and other transient windows that need to take precedence over the main application window.
