oxipng(1) دليل الأوامر العامة oxipng(1)

الاسم

oxipng - تحسين ضغط ملفات PNG بدون فقدان

الاستخدام

oxipng [-o|--opt] [-r|--recursive] [--dir] [--out] [--stdout] [-p|--preserve] [-P|--pretend] [-s ] [--strip] [--keep] [-a|--alpha] [-i|--interlace] [--scale16] [-v|--verbose]... [-q|--quiet] [-f|--filters] [--fast] [--zc] [--nb] [--nc] [--np] [--ng] [--nx] [--nz] [--fix] [--force] [-Z|--zopfli] [--zi] [--timeout] [-t|--threads] [--sequential] [-h|--help] [-V|--version] <الملفات>

الوصف

تحسين ضغط ملفات PNG بدون فقدان

الخيارات

-o, --opt=المستوى [الافتراضي: 2]
تحديد مستوى الضبط المسبق. المستوى الافتراضي 2 سريع جدًا ويوفر ضغطًا جيدًا. المستويات المنخفضة أسرع، والمستويات الأعلى توفر ضغطًا أفضل، وإن كان ذلك مع عائدات متناقصة بشكل متزايد.


0 => --zc 5 --fast (1 تجربة، يتم تحديدها إرشادياً)
1 => --zc 10 --fast (1 تجربة، يتم تحديدها إرشادياً)
2 => --zc 11 -f 0,1,6,7 --fast (4 تجارب سريعة، 1 تجربة رئيسية)
3 => --zc 11 -f 0,7,8,9 (4 تجارب)
4 => --zc 12 -f 0,7,8,9 (4 تجارب)
5 => --zc 12 -f 0,1,2,5,6,7,8,9 (8 تجارب)
6 => --zc 12 -f 0-9 (10 تجارب)
max => (اسم مستعار ثابت للمستوى الأقصى)

سيؤدي تحديد خيار ضغط يدويًا (zc، f، إلخ) إلى تجاوز الإعداد المسبق للضبط، بغض النظر عن ترتيب كتابة الوسائط.

-r, --recursive
عندما يتم إعطاء الدلائل كمدخلات، قم بالمرور عبر أشجار الدلائل وتحسين جميع ملفات PNG الموجودة (الملفات ذات الامتداد ".png" أو ".apng").
--dir=الدليل
اكتب الملف (الملفات) الناتجة في <الدليل>. إذا لم يكن الدليل موجودًا، فسيتم إنشاؤه. لاحظ أن هذا لن يحافظ على بنية دليل ملفات الإدخال عند استخدامه مع '--recursive'.
--out=ملف
اكتب الملف الناتج إلى <ملف>
--stdout
اكتب المخرجات إلى stdout
-p, --preserve
الحفاظ على أذونات الملفات وطوابعها الزمنية إن أمكن
-P, --pretend
لا تكتب أي ملفات، فقط اعرض نتائج الضغط
-s
شطب الأجزاء القابلة للإزالة بأمان، مثل '--strip safe'
--strip=الوضع
شطب أجزاء البيانات الوصفية، حيث <الوضع> هو أحد هذه الخيارات:


safe => شطب جميع الأجزاء غير الهامة، باستثناء ما يلي:
cICP, iCCP, sRGB, pHYs, acTL, fcTL, fdAT
all => شطب جميع الأجزاء غير الهامة
<قائمة> => شطب الأجزاء في القائمة المفصولة بفواصل، على سبيل المثال 'bKGD,cHRM'

تحذير: 'all' سيحول APNGs إلى PNGs قياسية.

لاحظ أنه سيتم شطب 'bKGD'، 'sBIT' و 'hIST' قسرًا إذا تم تغيير نوع اللون أو عمق البت، بغض النظر عن أي خيارات تم تعيينها.

الافتراضي عند عدم تمرير --strip هو الاحتفاظ بجميع البيانات الوصفية.

--keep=قائمة
شطب جميع أجزاء البيانات الوصفية باستثناء تلك الموجودة في القائمة المفصولة بفواصل. القيمة الخاصة 'display' تشمل الأجزاء التي تؤثر على مظهر الصورة، وهي مكافئة لـ '--strip safe'.

على سبيل المثال، '--keep eXIf,display' سيشطب الأجزاء، مع الاحتفاظ فقط بـ eXIf وتلك التي تؤثر على مظهر الصورة.

-a, --alpha
إجراء تحسين إضافي على الصور ذات قناة ألفا، عن طريق تغيير قيم الألوان للبكسلات الشفافة بالكامل. يوصى بهذا بشكل عام لتحسين الضغط، ولكن كن حذرًا لأنه بينما هو "غير مرئي من حيث الخسارة"، إلا أنه تحويل فاقد للمعرفة وقد لا يكون مناسبًا لبعض التطبيقات.
-i, --interlace=النوع
تحديد نوع تسلسل PNG، حيث <النوع> هو أحد هذه الخيارات:


0 => إزالة التسلسل من جميع الصور التي تتم معالجتها
1 => تطبيق تسلسل Adam7 على جميع الصور التي تتم معالجتها
keep => الاحتفاظ بنوع التسلسل الحالي لكل صورة

لاحظ أن التسلسل يمكن أن يضيف 25-50٪ إلى حجم الصورة المحسنة. استخدمه فقط إذا كنت تعتقد أن الفوائد تفوق التكاليف لحالة استخدامك.

[الافتراضي: 0]

--scale16
تقليل الصور ذات 16 بت لكل قناة قسرًا إلى 8 بت لكل قناة. هذه عملية فاقدة للمعرفة ولكنها يمكن أن توفر توفيرًا كبيرًا عندما لا تحتاج إلى عمق أعلى. يتم إجراء التخفيض عن طريق تحجيم القيم بحيث، على سبيل المثال، يتم تقليل 0x00FF إلى 0x01 بدلاً من 0x00.

بدون هذا العلم، سيتم تقليل الصور ذات 16 بت فقط في عمقها إذا كان يمكن القيام بذلك بدون فقدان.

-v, --verbose
التشغيل في وضع الإسهاب (استخدمه مرتين لزيادة الإسهاب)
-q, --quiet
التشغيل في الوضع الهادئ
-f, --filters=قائمة
إجراء تجارب ضغط مع كل نوع من أنواع المرشحات المحددة. يمكنك تحديد قائمة مفصولة بفواصل، أو نطاق من القيم. على سبيل المثال، '-f 0-3' هو نفس '-f 0,1,2,3'.

مرشحات PNG التفاضلية (تطبيق نفس المرشح على كل سطر)
0 => لا شيء (يوصى دائمًا بتضمين هذا المرشح)
1 => الفرعية
2 => الأعلى
3 => المتوسط
4 => Paeth

استراتيجيات إرشادية (حاول العثور على أفضل مرشح تفاضلي لكل سطر)
5 => MinSum أدنى مجموع للاختلافات المطلقة
6 => Entropy أعلى إنتروبيا Shannon
7 => Bigrams أقل عدد من الأبيجرامات المميزة
8 => BigEnt أعلى إنتروبيا Shannon للأبيجرامات
9 => Brute أصغر حجم مضغوط (بطيء)

تعتمد القيمة الافتراضية على الإعداد المسبق لمستوى الضبط.

--fast
إجراء تقييم ضغط سريع لكل مرشح ممكّن، يليه تجربة ضغط رئيسية واحدة لأفضل نتيجة. يوصى به إذا كان لديك مرشحات أكثر تمكينًا من نوى وحدة المعالجة المركزية.
--zc=المستوى
مستوى ضغط Deflate (0-12) لتجارب الضغط الرئيسية. تم تعريف المستويات هنا بواسطة مكتبة ضغط libdeflate.

تعتمد القيمة الافتراضية على الإعداد المسبق لمستوى الضبط.

--nb
لا تغير عمق البت
--nc
لا تغير نوع اللون
--np
لا تغير لوحة الألوان
--ng
لا تغير إلى أو من التدرج الرمادي
--nx
لا تقم بإجراء أي تحويلات ولا تقم بإلغاء التداخل افتراضيًا.
--nz
لا تقم بإعادة ضغط IDAT ما لم يكن ذلك ضروريًا بسبب التحويلات. سيتم أيضًا تعطيل إعادة ضغط الأجزاء المضغوطة الأخرى (مثل iCCP). لاحظ أن الجمع بين '--nx' و '--nz' سيعطل بالكامل جميع التحسينات.
--fix
لا تقم بإجراء التحقق من المجموع الاختباري لأجزاء PNG. قد يسمح هذا بمعالجة بعض الملفات التي بها أخطاء بنجاح.
--force
اكتب المخرجات حتى لو كانت أكبر من المدخلات
-Z, --zopfli

NAME

oxipng — multi-pass PNG optimizer

SYNOPSIS

oxipng [options] [<files>...]

DESCRIPTION

Oxipng is a multi-pass PNG optimizer that reduces file size. It is written in Rust and is heavily inspired by optipng and pngcrush.

It supports a wide array of optimizations, including but not limited to:

  • IDAT compression strategy optimizations
  • Palette reductions (if possible)
  • Color type reductions (if possible)
  • Bit depth reductions (if possible)
  • `acTL` chunk removal (if not needed)
  • `tEXt`, `zTXt`, and `iTXt` chunk removal (if not needed)
  • `gAMA`, `cHRM`, `iCCP`, `sRGB` chunk removal (if not needed)
  • `bKGD` chunk removal (if not needed)
  • `hIST` chunk removal (if not needed)
  • `pHYs` chunk removal (if not needed)
  • `sPLT` chunk removal (if not needed)
  • `tIME` chunk removal (if not needed)

OPTIONS

-o level
Optimization level. Higher levels take longer but may reduce file size more. Levels are 1 through 6.
  • 1: 3 passes
  • 2: 5 passes
  • 3: 7 passes
  • 4: 8 passes
  • 5: 10 passes
  • 6: 12 passes

Note that levels 5 and 6 are similar to the default level in pngcrush. Level 6 is recommended for maximum compression, but it is significantly slower.

[default: 2]

-Z, --zopfli
Use the Zopfli algorithm for PNG IDAT compression. This will significantly increase compression time, but may yield smaller files. This option is implicitly set when using optimization levels 5 and 6.
--zi=iterations [default: 15]
Set the number of iterations to use for Zopfli compression. Using fewer iterations may speed up compression for large files. This option requires '--zopfli' to be set.
--timeout=secs
Maximum amount of time, in seconds, to spend on optimizations. Oxipng will check the timeout before each transformation or compression trial, and will stop trying to optimize the file if the timeout is exceeded. Note that this does not cut short any operations that are already in progress, so it is currently of limited effectiveness for large files with high compression levels.
-t, --threads=num
Set the maximum number of threads to use. Oxipng uses multithreading to evaluate multiple optimizations on the same file in parallel as well as process multiple files in parallel. You can set this to a lower value if you need to limit memory or CPU usage.

[default: num logical CPUs]

--sequential
Process multiple files sequentially rather than in parallel. Use this if you need determinism in the processing order. Note this is not necessary if using '--threads 1'.
-h, --help
Print help (see a summary with '-h')
-V, --version
Print version
<files>
File(s) to compress (use '-' for stdin)
