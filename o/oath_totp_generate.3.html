الاسم

oath_totp_generate - دالة API

ملخص

#include <oath.h>

int oath_totp_generate(const char * secret, size_t secret_length, time_t now, unsigned time_step_size, time_t start_offset, unsigned digits, char * output_otp);

الوسائط

const char * secret
سلسلة المفتاح المشترك
size_t secret_length
طول secret
time_t now
قيمة وقت يونكس لحساب TOTP
unsigned time_step_size
معلمة نظام خطوة الوقت (عادة 30)
time_t start_offset
وقت يونكس لبدء عد خطوات الوقت (عادة 0)
unsigned digits
عدد الأرقام المطلوبة في OTP، باستثناء المجموع الاختباري
char * output_otp
مخزن الإخراج المؤقت، يجب أن يحتوي على مساحة لـ OTP الناتج بالإضافة إلى صفر

الوصف

تنشئ كلمة مرور لمرة واحدة باستخدام خوارزمية TOTP المتغيرة زمنيًا الموصوفة في RFC 6238. يتم أخذ وسائط الإدخال كقيم وقت.

تصف معلمة النظام time_step_size طول نافذة الوقت لكل OTP. القيمة الموصى بها هي 30 ثانية، ويمكنك استخدام القيمة 0 أو الرمز OATH_TOTP_DEFAULT_TIME_STEP_SIZE للإشارة إلى ذلك.

تشير معلمة النظام start_offset إلى وقت يونكس الذي يتم فيه بدء عد خطوات الوقت. القيمة الموصى بها هي 0، للعودة إلى بداية عصر يونكس) ويمكنك استخدام الرمز OATH_TOTP_DEFAULT_START_TIME للإشارة إلى ذلك.

يجب أن يحتوي المخزن المؤقت output_otp على مساحة لـ digits حرف على الأقل، بالإضافة إلى واحد للحرف الفارغ الختامي.

حاليًا، القيم 6 و 7 و 8 فقط لـ digits مدعومة. قد يتم رفع هذا القيد في الإصدارات المستقبلية.

الإرجاع

عند النجاح، يتم إرجاع OATH_OK (صفر)، وإلا يتم إرجاع رمز خطأ.
