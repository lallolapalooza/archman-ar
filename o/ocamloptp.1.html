ocamloptp(1)

الحزمة: ocaml

التراخيص: LGPL2.1, custom: QPL-1.0

OCAMLCP(1) دليل الأوامر العامة OCAMLCP(1)

الاسم

ocamlcp, ocamloptp - مترجمات OCaml لإنشاء تقارير الأداء

ملخص

ocamlcp [ خيارات oamlc ] [ -P علامات ] ملف ...

ocamloptp [ خيارات oamlopt ] [ -P علامات ] ملف ...

الوصف

الأوامر ocamlcp و ocamloptp هي واجهات أمامية لـ ocamlc(1) و ocamlopt(1) التي تقوم بتجهيز الكود المصدري، وإضافة كود لتسجيل عدد المرات التي تم فيها استدعاء الدوال، وفروع الشروط التي تم اتخاذها، إلخ. يؤدي تنفيذ الكود المجهز إلى ملف تقرير أداء يسمى ocamlprof.dump، والذي يمكن قراءته باستخدام ocamlprof(1).

يقبل ocamlcp نفس الوسائط والخيارات مثل ocamlc(1) ويقبل ocamloptp نفس الوسائط والخيارات مثل ocamlopt(1). هناك استثناء واحد فقط: في كلتا الحالتين، الخيار -pp غير مدعوم. إذا كنت بحاجة إلى معالجة ملفاتك المصدر مسبقًا، فسيتعين عليك القيام بذلك بشكل منفصل قبل استدعاء ocamlcp أو ocamloptp.

الخيارات

بالإضافة إلى خيارات ocamlc(1) أو ocamlopt(1)، تقبل ocamlcp و ocamloptp خيارًا واحدًا للتحكم في نوع معلومات تقرير الأداء، وهو الخيار -P أحرف. تشير الأحرف إلى الأجزاء من البرنامج التي يجب إنشاء تقارير أداء لها:

a
جميع الخيارات
f
استدعاءات الدوال: يتم تعيين نقطة عد عند بداية جسم كل دالة
i
if ... then ... else: يتم تعيين نقاط عد في كل من فرعي then و else
l
حلقات while و for: يتم تعيين نقطة عد عند بداية جسم الحلقة
m
فروع match: يتم تعيين نقطة عد عند بداية جسم كل فرع من فروع مطابقة النمط
t
فروع try ... with: يتم تعيين نقطة عد عند بداية جسم كل فرع من فروع معالج الاستثناء

على سبيل المثال، الترجمة باستخدام ocamlcp -P film تنشئ تقارير أداء لاستدعاءات الدوال، و if ... then ... else ...، والحلقات، ومطابقة الأنماط.

استدعاء ocamlcp(1) أو ocamloptp(1) بدون الخيار -P يعتمد افتراضيًا على -P fm، مما يعني أنه يتم إنشاء تقارير أداء فقط لاستدعاءات الدوال ومطابقة الأنماط.

ملاحظة: للتوافق مع الإصدارات السابقة، تقبل ocamlcp(1) أيضًا الخيار -p بنفس الوسيط والمعنى مثل -P.

انظر أيضًا

ocamlc(1), ocamlopt(1), ocamlprof(1).
دليل مستخدم OCaml، الفصل "إنشاء تقارير الأداء".
