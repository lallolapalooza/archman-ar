oath_hex2bin(3)

الحزمة: oath-toolkit

التراخيص: GPL-3.0-or-later

oath_hex2bin(3) liboath oath_hex2bin(3)

الاسم

oath_hex2bin - دالة API

الملخص

#include <oath.h>

int oath_hex2bin(const char * hexstr, char * binstr, size_t * binlen);

المعاملات

const char * hexstr
سلسلة الإدخال بالبيانات السداسية عشرية
char * binstr
سلسلة الإخراج التي تحتوي على بيانات ثنائية، أو NULL
size_t * binlen
المتغير الإخراجي الذي يحمل الطول المطلوب لـ binstr

الوصف

تحويل سلسلة تحتوي على بيانات سداسية عشرية إلى بيانات ثنائية.

لا يتم تجاهل البيانات غير السداسية عشرية، بل تؤدي بدلاً من ذلك إلى خطأ OATH_INVALID_HEX.

إذا كان binstr هو NULL، فسيتم ملء binlen بالطول الضروري. إذا كان المخزن المؤقت binstr صغيرًا جدًا، فسيتم إرجاع OATH_TOO_SMALL_BUFFER وسيحتوي binlen على الطول الضروري.

القيم المعادة

عند النجاح، يتم إرجاع OATH_OK (صفر)، وإلا يتم إرجاع رمز خطأ.
