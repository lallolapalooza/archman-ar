NAME

org.freedesktop.login1 - D-Bus API of systemd-logind

INTRODUCTION

The org.freedesktop.login1 D-Bus interface allows querying information about users, sessions, seats, and devices, and controlling system state like shutdown, reboot, suspend, and hibernate.

The primary D-Bus object for interacting with the login manager is the Manager object, available at the object path /org/freedesktop/login1.

Further objects are available for individual seats, users, and sessions.

THE MANAGER OBJECT

The Manager object implements the org.freedesktop.login1.Manager interface.

The following methods are exported:

See systemd-logind.service(8) for details.

SEAT OBJECTS

Seat objects are available under the object path /org/freedesktop/login1/seat/SEAT, where SEAT is the name of the seat. For example, the default seat is usually seat0.

Seat objects implement the org.freedesktop.login1.Seat interface.

The following methods are exported:

SwitchTo(), Lock(), Unlock(), SetLockedHint(), SetIdleHint(), SetIdleSinceHint(), SetIdleSinceHintUSec(), StopIdleSessionUSec(), TakeDevice(), ReleaseDevice(), FlushLogindSELinuxContext(), SetSeatEnvironment(), GetSeatEnvironment(), RegisterSeatEnvironment(), UnregisterSeatEnvironment(), GetSessions(), GetUsers(), GetDevices(), GetManager().

USER OBJECTS

User objects are available under the object path /org/freedesktop/login1/user/UID, where UID is the numerical user ID. For example, the root user is /org/freedesktop/login1/user/0.

User objects implement the org.freedesktop.login1.User interface.

The following methods are exported:

GetSessions(), Terminate(), Kill(), SetUserInactivity(), SetUserClearedInactivity(), SetLoginUID(), SetPAMEnvironment(), GetPAMEnvironment(), SetUserEnvironment(), GetUserEnvironment(), RegisterUserEnvironment(), UnregisterUserEnvironment(), FlushLogindSELinuxContext(), GetManager().

SESSION OBJECTS

Session objects are available under the object path /org/freedesktop/login1/session/SESSION_ID, where SESSION_ID is the session ID. For example, /org/freedesktop/login1/session/42.

Session objects implement the org.freedesktop.login1.Session interface.

The following methods are exported:

Terminate(), Kill(), SetType(), SetClass(), SetTTY(), SetDisplay(), SetSeat(), SetUser(), SetLogo(), SetLanguage(), SetX11Domain(), SetRemote(), SetRemote(), SetIdleHint(), SetIdleSinceHint(), SetIdleSinceHintUSec(), StopIdleSessionUSec(), SetLoggingIn(), SetAlreadyInhibited(), SetWeakInhibited(), SetPrepareForShutdown(), SetWakeupFilter(), RegisterSessionEnvironment(), UnregisterSessionEnvironment(), SetSessionEnvironment(), GetSessionEnvironment(), FlushLogindSELinuxContext(), GetManager(), GetSeat(), GetUser(), GetLeader(), GetChildLogins(), GetUID(), GetGID(), GetTimestamp(), GetTimestampMonotonic(), GetRemoteHost(), GetRemotePort(), GetTTY(), GetDisplay(), GetType(), GetClass(), GetLogo(), GetLanguage(), GetX11Domain(), GetIdleHint(), GetIdleSinceHint(), GetIdleSinceHintUSec(), GetLoggingIn(), GetAlreadyInhibited(), GetWeakInhibited(), GetPrepareForShutdown(), GetWakeupDevices(), GetWakeupFilter(), GetSessionGroup(), GetSessionGroupMetadata(), GetLeaderPIDFDId().

EXAMPLES

Example 1. Introspect the login manager on the bus

$ gdbus introspect --system --dest org.freedesktop.login1 \
 --object-path /org/freedesktop/login1

or

$ busctl introspect org.freedesktop.login1 /org/freedesktop/login1

Example 2. Introspect the default seat on the bus

$ gdbus introspect --system --dest org.freedesktop.login1 \
 --object-path /org/freedesktop/login1/seat/seat0

or

$ busctl introspect org.freedesktop.login1 /org/freedesktop/login1/seat/seat0

Seat "seat0" is the default seat, so it'll be present unless local configuration is made to reassign all devices to a different seat. The list of seats and users can be acquired with loginctl list-sessions.

Example 3. Introspect a single user on the bus

$ gdbus introspect --system --dest org.freedesktop.login1 \
  --object-path /org/freedesktop/login1/user/_1000

or

$ busctl introspect org.freedesktop.login1 /org/freedesktop/login1/user/_1000

Example 4. Introspect org.freedesktop.login1.Session on the bus

$ gdbus introspect --system --dest org.freedesktop.login1 \
  --object-path /org/freedesktop/login1/session/45

or

$ busctl introspect org.freedesktop.login1 /org/freedesktop/login1/session/45

HISTORY

The Manager Object

HandlePowerKeyLongPress, HandleRebootKey, HandleRebootKeyLongPress, HandleSuspendKeyLongPress, and HandleHibernateKeyLongPress were added in version 251.

StopIdleSessionUSec was added in version 252.

PrepareForShutdownWithMetadata() and CreateSessionWithPIDFD() were added in version 255.

Sleep(), CanSleep(), SleepOperation, and ListSessionsEx() were added in version 256.

HandleSecureAttentionKey, SecureAttentionKey(), PreparingForShutdownWithMetadata, DesignatedMaintenanceTime, CanIdle, CanLock, and BlockWeakInhibited were added in version 257.

Session Objects

SetDisplay() was added in version 252.

SetTTY() was added in version 254.

SetClass() was added in version 256.

LeaderPIDFDId was added in version 258.
