openssl-engine(1ssl)

الحزمة: openssl

التراخيص: Apache-2.0

OPENSSL-ENGINE(1ssl) OpenSSL OPENSSL-ENGINE(1ssl)

الاسم

openssl-engine - تحميل والاستعلام عن المحركات

الملخص

openssl engine [-help] [-v] [-vv] [-vvv] [-vvvv] [-c] [-t] [-tt] [-pre command] ... [-post command] ... [engine ...]

الوصف

تم إهمال هذا الأمر. يجب استخدام المزودين بدلاً من المحركات.

يُستخدم هذا الأمر للاستعلام عن حالة وقدرات المحركات المحددة. يمكن تحديد المحركات قبل وبعد جميع العلامات الأخرى في سطر الأوامر. فقط تلك المحددة هي التي يتم الاستعلام عنها.

الخيارات

-help
عرض ملخص للخيارات.
-v -vv -vvv -vvvv
توفر معلومات حول كل محرك محدد. تسرد العلامة الأولى جميع أوامر التحكم الممكنة في وقت التشغيل؛ تضيف الثانية وصفًا لكل أمر؛ تضيف الثالثة علامات الإدخال، ويضيف الخيار النهائي علامات الإدخال الداخلية.
-c
يسرد قدرات كل محرك.
-t
يختبر ما إذا كان كل محرك محدد متاحًا، ويعرض الإجابة.
-tt
يعرض تتبع خطأ لأي محرك غير متاح.
-pre command
-post command
تكوين سطر الأوامر للمحركات. يتم إعطاء أمر -pre للمحرك قبل تحميله، ويتم إعطاء أمر -post بعد تحميل المحرك. الأمر هو بصيغة cmd:val حيث cmd هو الأمر، و val هي قيمة الأمر. انظر المثال أدناه.

هذان الخياران تراكميان، لذا يمكن إعطاؤهما أكثر من مرة في نفس الأمر.

أمثلة

لسرد جميع الأوامر المتاحة لمحرك ديناميكي:

$ openssl engine -t -tt -vvvv dynamic
(dynamic) Dynamic engine loading support
     [ unavailable ]
     SO_PATH: Specifies the path to the new ENGINE shared library
          (input flags): STRING
     NO_VCHECK: Specifies to continue even if version checking fails (boolean)
          (input flags): NUMERIC
     ID: Specifies an ENGINE id name for loading
          (input flags): STRING
     LIST_ADD: Whether to add a loaded ENGINE to the internal list (0=no,1=yes,2=mandatory)
          (input flags): NUMERIC
     DIR_LOAD: Specifies whether to load from 'DIR_ADD' directories (0=no,1=yes,2=mandatory)
          (input flags): NUMERIC
     DIR_ADD: Adds a directory from which ENGINEs can be loaded
          (input flags): STRING
     LOAD: Load up the ENGINE specified by other settings
          (input flags): NO_INPUT

لسرد قدرات محرك rsax:

$ openssl engine -c
(rsax) RSAX engine support
 [RSA]
(dynamic) Dynamic engine loading support
