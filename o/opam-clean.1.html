NAME

opam-clean - removes temporary files

SYNOPSIS

opam-clean [ OPTION ... ] [ FILE ... ]

DESCRIPTION

opam-clean is used to remove temporary files generated by opam during its execution. This can be useful to free up disk space or to reset the state of the opam environment.

If no file is specified, the command will remove all temporary files in the opam root directory.

OPTIONS

+
Remove temporary files.
-a, --all
Remove all temporary files, including those from previous versions of opam.
-h, --help
Show help message and exit.
-v, --version
Show version info and exit.

COMMON OPTIONS

These options are common to most opam commands:

-i, --install-conflicts
Allow installing packages that conflict with others.
-k, --keep-build-dirs
Keep the build directories after successful installation.
-j, --jobs
Number of parallel jobs to run.
--log-level
Set the log level.
-y, --yes
Automatically answer yes to confirmation prompts.

ENVIRONMENT

See opam(1) for environment variables that affect opam.

CLI VERSION

This option is available since opam 2.3.0.
