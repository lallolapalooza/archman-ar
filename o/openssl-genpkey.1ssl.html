الحزمة: openssl

NAME

openssl-genpkey

generating private keys

SYNOPSIS

openssl genpkey [-algorithm alg] [-pkeyopt opt:val] [-paramfile file] [-genparam] [-text] [-aes128] [-aes192] [-aes256] [-des] [-des3] [-idea] [-out file] [-passout arg] [-engine id]

DESCRIPTION

The openssl genpkey command is used for generating private keys or for generating parameters for certain types of keys, such as Diffie-Hellman (DH) or Elliptic Curve (EC) keys.

The command supports generating keys and parameters for a wide range of algorithms including RSA, DSA, DH, EC, X25519, X448, ED25519, ED448, ML-DSA, and ML-KEM.

It is a generic command that can invoke algorithm-specific generators. The use of this command is generally encouraged over the older algorithm-specific utilities (like genrsa, gendsa, etc.) as it provides a more consistent interface and allows for the use of more options.

OPTIONS

-algorithm alg
Specifies the algorithm to be used. Supported algorithms include RSA, DSA, DH, EC, X25519, X448, ED25519, ED448, ML-DSA, and ML-KEM. If this option is omitted, then the default algorithm is RSA.
-pkeyopt opt:val
Specifies algorithm-specific options. The available options depend on the algorithm specified with -algorithm. See the sections below for details.
-paramfile file
Specifies a file containing parameters. This is used when generating a key from existing parameters, such as DSA or DH parameters. If this option is used, then the -genparam option cannot be used.
-genparam
When this option is used, parameters are generated instead of a private key. This is typically used for algorithms like DH or DSA where parameters are generated separately from the private key. If this option is used, then the -paramfile option cannot be used.
-text
Prints the generated parameters or key in human-readable form to standard output.
-aes128, -aes192, -aes256, -des, -des3, -idea
These options encrypt the output private key. They are equivalent to specifying -passout with the appropriate encryption cipher. For example, -aes256 is equivalent to -passout aes256.
-out file
Specifies the output file for the generated key or parameters. If this option is omitted, the output will be written to standard output.
-passout arg
Specifies how the passphrase for encrypting the private key is provided. See openssl(1) for a full description of the format of arg.
-engine id
Specifies an engine to be used for the key generation. This option is deprecated and may be removed in future versions.

KEY GENERATION OPTIONS

The following options can be used with -pkeyopt when generating keys:

rsa_keygen_bits:numbits
The number of bits for the RSA key. Default is 2048.
rsa_keygen_pubexp:value
The public exponent for the RSA key. Default is 65537.
dsa_paramgen_bits:numbits
The number of bits for the DSA key parameters (prime modulus p). Minimum value is 512, maximum is 10000. Default is 2048.
dsa_paramgen_q:numbits
The number of bits for the DSA key parameter q. Default is 224.
dsa_paramgen_digest:digest
The digest algorithm to use for DSA parameter generation. Supported digests include SHA, SHA1, SHA224, SHA256, SHA384, SHA512. Default is SHA256.
dsa_paramgen_type:type
Specifies the type of DSA parameter generation.
0
Use FIPS 186-4 parameter generation.
1
Use FIPS 186-2 parameter generation.
2
Use FIPS 186-4 subgroup parameter generation.
Default is 0.
gindex:index
The index of the generator g to use for DSA parameter generation. This option is used in conjunction with dsa_paramgen_type:0 or dsa_paramgen_type:2. If not specified, a default value is used.
hexseed:seed
The seed data to use instead of generating a random seed internally. This should be used for testing purposes only. This will either produced fixed values for the generated parameters OR it will fail if the seed did not generate valid primes. This is only used by "fips186_4" and "fips186_2" key generation.
dh_paramgen_bits:numbits
The number of bits for the DH prime modulus p. Default is 2048.
dh_paramgen_p:value
The DH prime modulus p.
dh_paramgen_g:value
The DH generator g.
dh_paramgen_type:type
Specifies the type of DH parameter generation.
0
Use standard DH parameter generation.
1
Use FIPS 186-2 parameter generation.
2
Use FIPS 186-4 parameter generation.
Default is 0.
dh_rfc5114:group
Use a predefined RFC5114 DH group. Supported groups are 1, 2, 3, 4, 5, 6, 7.
group:groupname
Use a predefined named DH group. Supported groups include ffdhe2048, ffdhe3072, ffdhe4096, etc.
ec_paramgen_curve:curve
Specifies the curve to use for EC key generation. Supported curve names include nistp256, nistp384, nistp521, secp256k1, etc.
ec_param_enc:type
Specifies the encoding type for EC parameters.
named_curve
Encode parameters using a named curve.
explicit
Encode parameters explicitly.
Default is named_curve.

EC Parameter Generation Options

The EC parameter generation options are the same as for key generation. See "EC Key Generation Options" above.

NOTES

The use of the genpkey program is encouraged over the algorithm specific utilities because additional algorithm options and ENGINE provided algorithms can be used.

EXAMPLES

Generate an RSA private key using default parameters:

openssl genpkey -algorithm RSA -out key.pem

Encrypt output private key using 128 bit AES and the passphrase "hello":

openssl genpkey -algorithm RSA -out key.pem -aes-128-cbc -pass pass:hello

Generate a 2048 bit RSA key using 3 as the public exponent:

openssl genpkey -algorithm RSA -out key.pem \
    -pkeyopt rsa_keygen_bits:2048 -pkeyopt rsa_keygen_pubexp:3

Generate 2048 bit DSA parameters that can be validated: The output values for gindex and seed are required for key validation purposes and are not saved to the output pem file).

openssl genpkey -genparam -algorithm DSA -out dsap.pem -pkeyopt pbits:2048 \
    -pkeyopt qbits:224 -pkeyopt digest:SHA256 -pkeyopt gindex:1 -text

Generate DSA key from parameters:

openssl genpkey -paramfile dsap.pem -out dsakey.pem

Generate 4096 bit DH Key using safe prime group ffdhe4096:

openssl genpkey -algorithm DH -out dhkey.pem -pkeyopt group:ffdhe4096

Generate 2048 bit X9.42 DH key with 256 bit subgroup using RFC5114 group3:

openssl genpkey -algorithm DHX -out dhkey.pem -pkeyopt dh_rfc5114:3

Generate a DH key using a DH parameters file:

openssl genpkey -paramfile dhp.pem -out dhkey.pem

Output DH parameters for safe prime group ffdhe2048:

openssl genpkey -genparam -algorithm DH -out dhp.pem -pkeyopt group:ffdhe2048

Output 2048 bit X9.42 DH parameters with 224 bit subgroup using RFC5114 group2:

openssl genpkey -genparam -algorithm DHX -out dhp.pem -pkeyopt dh_rfc5114:2

Output 2048 bit X9.42 DH parameters with 224 bit subgroup using FIP186-4 keygen:

openssl genpkey -genparam -algorithm DHX -out dhp.pem -text \
    -pkeyopt pbits:2048 -pkeyopt qbits:224 -pkeyopt digest:SHA256 \
    -pkeyopt gindex:1 -pkeyopt dh_paramgen_type:2

Output 1024 bit X9.42 DH parameters with 160 bit subgroup using FIP186-2 keygen:

openssl genpkey -genparam -algorithm DHX -out dhp.pem -text \
    -pkeyopt pbits:1024 -pkeyopt qbits:160 -pkeyopt digest:SHA1 \
    -pkeyopt gindex:1 -pkeyopt dh_paramgen_type:1

Output 2048 bit DH parameters:

openssl genpkey -genparam -algorithm DH -out dhp.pem \
    -pkeyopt dh_paramgen_prime_len:2048

Output 2048 bit DH parameters using a generator:

openssl genpkey -genparam -algorithm DH -out dhpx.pem \
    -pkeyopt dh_paramgen_prime_len:2048 \
    -pkeyopt dh_paramgen_type:1

Generate EC parameters:

openssl genpkey -genparam -algorithm EC -out ecp.pem \
       -pkeyopt ec_paramgen_curve:secp384r1 \
       -pkeyopt ec_param_enc:named_curve

Generate EC key from parameters:

openssl genpkey -paramfile ecp.pem -out eckey.pem

Generate EC key directly:

openssl genpkey -algorithm EC -out eckey.pem \
       -pkeyopt ec_paramgen_curve:P-384 \
       -pkeyopt ec_param_enc:named_curve

Generate an X25519 private key:

openssl genpkey -algorithm X25519 -out xkey.pem

Generate an ED448 private key:

openssl genpkey -algorithm ED448 -out xkey.pem

Generate an ML-DSA-65 private key:

openssl genpkey -algorithm ML-DSA-65 -out ml-dsa-key.pem

Generate an ML-KEM-768 private key:

openssl genpkey -algorithm ML-KEM-768 -out ml-kem-key.pem

HISTORY

The ability to use NIST curve names, and to generate an EC key directly, were added in OpenSSL 1.0.2. The ability to generate X25519 keys was added in OpenSSL 1.1.0. The ability to generate X448, ED25519 and ED448 keys was added in OpenSSL 1.1.1.

The -engine option was deprecated in OpenSSL 3.0.

Support for ML-DSA and ML-KEM was added in OpenSSL 3.5.
