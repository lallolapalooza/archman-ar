خيارات الواجهة الوسطى لـ FLAMBDA

عند تمكين مولد شفرة Flambda وقت التكوين، يمكن تعديل سلوكه بالخيارات الإضافية التالية:

-02
قم بإجراء المزيد من التحسينات من المعتاد. قد تطول أوقات الترجمة.
-03
قم بإجراء المزيد من التحسينات من المعتاد، ربما بما في ذلك إلغاء تكرار الدوال التكرارية. قد تطول أوقات الترجمة بشكل كبير.
-Oclassic
اتخاذ قرارات الاستدعاء عند نقطة تعريف الدالة بدلاً من موقع (مواقع) الاستدعاء. هذا يعكس سلوك مترجمات OCaml التي لا تستخدم Flambda. مقارنة بالترجمة باستخدام استراتيجيات الاستدعاء الجديدة لـ Flambda (على سبيل المثال، عند -O2) ينتج عنه ملفات .cmx أصغر، وأوقات ترجمة أقصر، وشفرة ربما تعمل أبطأ.
-inlining-report
إنشاء ملفات .inlining (واحد لكل جولة تحسين) توضح جميع قرارات المستدعي.

NAME

ocamlopt.opt — The OCaml native compiler (native code generation)

SYNOPSIS

ocamlopt.opt [ options ] filenames

DESCRIPTION

ocamlopt.opt is the native-code compiler for Objective Caml. It translates Objective Caml source programs into efficient executable files. It can also generate object files that can be linked with C code or other native object files.

OPTIONS

The following options are available:

  • -help: Print a list of options and exit.
  • -version: Print the version of the compiler and exit.
  • -o executable: Specify the name of the output executable file.
  • -c: Compile only, do not link.
  • -I directory: Add directory to the list of directories searched for compiled interface files (.cm[i]) and implementations (.ml[i]).
  • -L directory: Add directory to the list of directories searched for linked libraries.
  • -linkall object: Link all objects from the archive object, not just the ones referenced.
  • -linkparam param: Pass param to the linker.
  • -native-src-dir directory: When compiling a library, keep the generated .cmx files in directory instead of the source directory.
  • -nodynlink: Disable dynamic loading of code.
  • -noautolink: Do not link in default libraries.
  • -open module: Automatically open the specified module.
  • -principal: Check that each type constructor and exception is used only when its defining module is open.
  • -rectypes: Allow recursive types.
  • -runtime-lib dir: Search for runtime libraries in dir.
  • -thread: Support for shared memory parallelism (threads).
  • -unsafe: Allow unsafe operations (e.g. array accesses).
  • -v: Print the compiler version and exit.
  • -verbose: Print the names of files as they are compiled.
  • -warn-error arg: Turn warnings into errors. arg is a comma-separated list of warning numbers.
  • -w arg: Enable or disable warnings. arg is a comma-separated list of warning numbers or prefixes.
  • -output-interface filename: Output the interface of the compiled module to filename.
  • -opaque: Disable opening of modules.
  • -opaque-debug: Enable opening of modules for debugging purposes.
  • -opaque-alias module: Alias module as opaque.
  • -opaque-all: Make all modules opaque.
  • -opaque-keep module: Keep module as non-opaque.
  • -inline n: Set the maximum inlining depth to n.
  • -unboxed-types: Allow unboxed types for performance.
  • -no-unbox-global-roots: Disable unboxing of global roots.
  • -inline-alloc-threshold n: Set the allocation threshold for inlining to n.

NAME

ocamlopt.opt — المترجم الأصلي لـ OCaml (توليد الكود الأصلي)

SYNOPSIS

ocamlopt.opt [ options ] filenames

DESCRIPTION

ocamlopt.opt هو المترجم للكود الأصلي لـ Objective Caml. يقوم بترجمة برامج Objective Caml المصدر إلى ملفات قابلة للتنفيذ بكفاءة. يمكنه أيضًا توليد ملفات كائن يمكن ربطها مع كود C أو ملفات كائن أصلية أخرى.

OPTIONS

الخيارات التالية متاحة:

  • -help: طباعة قائمة بالخيارات والخروج.
  • -version: طباعة إصدار المترجم والخروج.
  • -o executable: تحديد اسم ملف الإخراج القابل للتنفيذ.
  • -c: الترجمة فقط، لا ترابط.
  • -I directory: أضف directory إلى قائمة الأدلة التي يتم البحث فيها عن ملفات الواجهة المترجمة (.cm[i]) والتنفيذ (.ml[i]).
  • -L directory: أضف directory إلى قائمة الأدلة التي يتم البحث فيها عن المكتبات المرتبطة.
  • -linkall object: ربط جميع الكائنات من الأرشيف object، وليس فقط تلك المشار إليها.
  • -linkparam param: تمرير param إلى الرابط.
  • -native-src-dir directory: عند ترجمة مكتبة، احتفظ بملفات .cmx المولدة في directory بدلاً من دليل المصدر.
  • -nodynlink: تعطيل التحميل الديناميكي للكود.
  • -noautolink: لا تقم بربط المكتبات الافتراضية.
  • -open module: افتح الوحدة module المحددة تلقائيًا.
  • -principal: تحقق من أن كل مُنشئ نوع واستثناء يتم استخدامه فقط عندما تكون وحدته المحددة مفتوحة.
  • -rectypes: السماح بالأنواع المتكررة.
  • -runtime-lib dir: ابحث عن مكتبات وقت التشغيل في dir.
  • -thread: دعم التوازي في الذاكرة المشتركة (threads).
  • -unsafe: السماح بالعمليات غير الآمنة (مثل الوصول إلى المصفوفات).
  • -v: طباعة إصدار المترجم والخروج.
  • -verbose: طباعة أسماء الملفات أثناء ترجمتها.
  • -warn-error arg: تحويل التحذيرات إلى أخطاء. arg هي قائمة مفصولة بفواصل بأرقام التحذيرات.
