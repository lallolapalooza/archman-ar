NAME

openssl-crl - Certificate Revocation List (CRL) utility

SYNOPSIS

openssl crl [-in file] [-out file] [-text] [-fingerprint] [-hash] [-subject] [-issuer] [-dates] [-noout] [-modulus] [-pubkey] [-version] [-crlopt name:value]

DESCRIPTION

The openssl crl command is a utility for manipulating and viewing Certificate Revocation Lists (CRLs). CRLs are used to list certificates that have been revoked by a Certificate Authority (CA).

OPTIONS

  • -in file: Specifies the input CRL file.
  • -out file: Specifies the output file for the processed CRL.
  • -text: Prints the CRL contents in a human-readable text format.
  • -fingerprint: Prints the SHA1 fingerprint of the CRL.
  • -hash: Prints the hash of the CRL subject name.
  • -subject: Prints the subject name of the CRL issuer.
  • -issuer: Prints the issuer name of the CRL.
  • -dates: Prints the nextUpdate and lastUpdate dates of the CRL.
  • -noout: Do not output the encoded version of the CRL.
  • -modulus: Print the modulus of the CRL issuer's public key.
  • -pubkey: Print the public key of the CRL issuer.
  • -version: Print version information about the OpenSSL library.
  • -crlopt name:value: Set CRL option name to value. For example, -crlopt next_update:20240101000000Z.

EXAMPLES

  • View the contents of a CRL in human-readable format:

    openssl crl -in my_crl.pem -text -noout

  • Print the SHA1 fingerprint of a CRL:

    openssl crl -in my_crl.pem -fingerprint -noout

  • Print the issuer name and dates of a CRL:

    openssl crl -in my_crl.pem -issuer -dates -noout

FILES

  • my_crl.pem: Example CRL file.

HISTORY

The openssl crl command was first introduced in OpenSSL 0.9.4.

الاسم

openssl-crl - أداة قائمة مراجعة الشهادات (CRL)

الملخص

openssl crl [-in file] [-out file] [-text] [-fingerprint] [-hash] [-subject] [-issuer] [-dates] [-noout] [-modulus] [-pubkey] [-version] [-crlopt name:value]

الوصف

أمر openssl crl هو أداة لمعالجة وعرض قوائم مراجعة الشهادات (CRLs). تُستخدم قوائم مراجعة الشهادات لسرد الشهادات التي تم إلغاؤها من قبل سلطة الشهادات (CA).

الخيارات

  • -in file: يحدد ملف CRL المدخل.
  • -out file: يحدد ملف الإخراج لـ CRL المعالج.
  • -text: يطبع محتويات CRL بتنسيق نصي قابل للقراءة.
  • -fingerprint: يطبع بصمة SHA1 الخاصة بـ CRL.
  • -hash: يطبع تجزئة اسم موضوع CRL.
  • -subject: يطبع اسم موضوع جهة إصدار CRL.
  • -issuer: يطبع اسم جهة إصدار CRL.
  • -dates: يطبع تواريخ nextUpdate و lastUpdate الخاصة بـ CRL.
  • -noout: لا يخرج النسخة المشفرة من CRL.
  • -modulus: يطبع معامل المفتاح العام لمصدر CRL.
  • -pubkey: يطبع المفتاح العام لمصدر CRL.
  • -version: يطبع معلومات الإصدار حول مكتبة OpenSSL.
  • -crlopt name:value: تعيين خيار CRL name إلى value. على سبيل المثال، -crlopt next_update:20240101000000Z.

الأمثلة

  • عرض محتويات CRL بتنسيق نصي قابل للقراءة:

    openssl crl -in my_crl.pem -text -noout

  • طباعة بصمة SHA1 الخاصة بـ CRL:

    openssl crl -in my_crl.pem -fingerprint -noout

  • طباعة اسم المصدر وتواريخ CRL:

    openssl crl -in my_crl.pem -issuer -dates -noout

الملفات

  • my_crl.pem: مثال لملف CRL.
