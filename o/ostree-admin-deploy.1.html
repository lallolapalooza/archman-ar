ostree-admin-deploy(1)

الحزمة: ostree

التراخيص: LGPL-2.0-or-later

OSTREE ADMIN DEPLOY(1) ostree admin deploy OSTREE ADMIN DEPLOY(1)

الاسم

ostree-admin-deploy - سحب مراجعة كنشر افتراضي جديد

الملخص

ostree admin deploy [خيارات...] {REFSPEC}

الوصف

يأخذ التزامًا أو مراجعة REFSPEC، ويضع النشر الجديد في قائمة الانتظار ليكون الافتراضي عند إعادة التشغيل.

الخيارات

--stateroot="STATEROOT"

استخدم stateroot نظام تشغيل مختلف عن الحالي.

--os="STATEROOT"

اسم مستعار لـ --stateroot.

--origin-file="FILENAME"

استخدم FILENAME كمصدر، وهو المكان الذي سيبحث فيه OSTree عن إصدارات محدثة للشجرة.

--retain

لا تحذف النشر السابق.

--retain-pending

لا تحذف عمليات النشر المعلقة.

--retain-rollback

لا تحذف عمليات النشر التي يمكن التراجع عنها.

--not-as-default

إضافة نشر جديد بدلاً من تقديمه.

--lock-finalization

لن يتم "إنهاء" النشر افتراضيًا عند إيقاف التشغيل؛ لجدولته لاحقًا، استخدم ostree admin lock-finalization --unlock.

--karg-proc-cmdline

استيراد /proc/cmdline الحالي.

--karg="NAME=VALUE"

تعيين وسيط النواة، مثل root=/dev/sda1؛ هذا يلغي أي وسيط سابق بنفس الاسم.

--karg-append="NAME=VALUE"

إضافة وسيط النواة؛ مفيد مع console= الذي يمكن استخدامه عدة مرات.

--karg-delete="NAME=VALUE"

حذف وسيط النواة إذا كان موجودًا، يمكن استخدامه عدة مرات.
