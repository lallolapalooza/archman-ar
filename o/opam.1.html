OPAM(1) دليل Opam OPAM(1)

الاسم

opam - إدارة الحزم المصدرية

ملخص

opam [الأمر] …

الوصف

Opam هو مدير حزم. يستخدم أدوات mancoosi القوية للتعامل مع التبعيات، بما في ذلك دعم قيود الإصدار، والتبعيات الاختيارية، وإدارة التعارضات. التكوين الافتراضي يربطه بمستودع الحزم الرسمي لـ OCaml.

لديه دعم لمستودعات بعيدة مختلفة مثل HTTP، rsync، git، darcs و mercurial. يتم تثبيت كل شيء داخل دليل opam محلي، والذي يمكن أن يشمل بادئات تثبيت متعددة بمجموعات مختلفة من الحزم المثبتة.

استخدم إما opam <command> --help أو opam help <command> لمزيد من المعلومات حول أمر معين.

خيارات مشتركة

هذه الخيارات مشتركة لجميع الأوامر.

--best-effort
لا تفشل إذا لم يكن من الممكن تثبيت جميع الحزم المطلوبة: حاول تثبيت أكبر عدد ممكن. لاحظ أن ليس كل حلالات خارجية قد تدعم هذا الخيار (الإصدارات الحديثة من aspcud أو mccs يجب أن تفعل). هذا يعادل تعيين متغير البيئة $OPAMBESTEFFORT.
--cli=MAJOR.MINOR (افتراضي=2.4)
استخدم بناء جملة ودلالات واجهة سطر الأوامر للإصدار MAJOR.MINOR. مخصص لأي استخدام دائم لـ opam (البرامج النصية، مشاركات المدونات، إلخ)، أي إصدار من opam في نفس سلسلة MAJOR سيعمل كما هو الحال بالنسبة لإصدار MINOR المحدد. لم يكن الخيار متاحًا في opam 2.0، لذلك لاختيار واجهة سطر الأوامر 2.0، قم بتعيين متغير البيئة OPAMCLI إلى 2.0 بدلاً من استخدام هذا المعلمة.
--color=متى
لون المخرج. يجب أن تكون متى واحدة من always، never أو auto.
--confirm-level=مستوى
مستوى التأكيد، يجب أن يكون مستوى واحداً من ask، no، yes أو unsafe-yes. يمكن تحديده أكثر من مرة. إذا تم إعطاء --yes أو --no أيضًا، يتم أخذ قيمة آخر --confirm-level في الاعتبار. هذا يعادل تعيين $OPAMCONFIRMLEVEL`.
--criteria=المعايير
حدد تفضيلات المستخدم لحل التبعيات لهذا التشغيل. يتجاوز $OPAMCRITERIA، $OPAMFIXUPCRITERIA و $OPAMUPGRADECRITERIA. للحصول على تفاصيل حول اللغة المدعومة، والحلالات الخارجية المتاحة، انظر http://opam.ocaml.org/doc/External_solvers.html. دليل عام لاستخدام تفضيلات الحلالات يمكن العثور عليه في http://www.dicosmo.org/Articles/usercriteria.pdf.
--cudf=اسم الملف
خيار تصحيح الأخطاء: احفظ طلبات CUDF المرسلة إلى الحلال في اسم الملف-<n>.cudf حيث <n> هو الاستدعاء n-th للحلال أثناء تشغيل opam.
--debug
اطبع رسالة تصحيح الأخطاء إلى stderr. هذا يعادل تعيين $OPAMDEBUG إلى "true".
--debug-level=مستوى
مثل --debug، ولكنه يسمح بتحديد

ENVIRONMENT

The following environment variables may be set to alter the behavior of opam:

OPAM_ACTION_TOKEN This is set by opam during its execution and may be used by hooks or scripts to check if they are currently run by opam.

OPAM_BRANCH Used to specify the branch to clone when adding a repository.

OPAM_COLOR forces colour output, this variable can be set to `always', `never' or `auto' (default).

OPAM_CONFIG_DIR override the location of the opam configuration directory (default is $HOME/.opam).

OPAM_CRITERIA defines user preferences for dependency solving. See also option --criteria.

OPAM_DEBUG_REASONING debug solver reasoning. Mostly useful for solver developers.

OPAM_DEBUG_REPOS debug repository operations.

OPAM_DEV_MODE set to 1 to enable development mode.

OPAM_DEV_OPTS set to string of options to add to compiler configuration.

OPAM_DIFF_CMD the command to use for `opam diff'. Defaults to `git diff --no-index --

OPAM_DIFF_IGNORE a list of glob patterns separated by spaces, specifying files to ignore in `opam diff'.

OPAM_DIFF_RENAMES use `git diff --find-renames' when comparing files. Defaults to true.

OPAM_DIFF_WORD_DIFF use `git diff --word-diff' when comparing files. Defaults to false.

OPAM_EDIT_CMD the command to use for `opam edit'. Defaults to `vim'.

OPAM_EDIT_POST_CMD a command to run after `opam edit' completes. It is given the edited filename as an argument.

OPAM_EDIT_PRE_CMD a command to run before `opam edit' starts. It is given the filename to be edited as an argument.

OPAM_EDIT_RETRY if set to 1, opam will ask if you want to retry editing if the first attempt failed.

OPAM_ERROR_CONTEXT print context information for errors. (one of always, never or auto)

OPAM_FEATURES a space separated list of features to pass to configure scripts.

OPAM_KEEP_OLD_SWITCHES if set to 1, opam keeps old switches when creating a new one.

OPAM_KEEP_TESTS if set to 1, opam keeps test files after successful installation.

OPAM_KEEP_TIPS if set to 1, opam keeps tips files after successful installation.

OPAM_LOCKER path to locker program, defaults to `opam-locker'.

OPAM_LOG_DIR location where logs are stored. Defaults to `$OPAM_SWITCH_PREFIX/log'.

OPAM_LOGFILE path to the log file for the current opam invocation.

OPAM_MAKE_JOBS number of parallel jobs to use for the `make' command. Defaults to the number of cores.

OPAM_NO_PULL_ALWAYS if set to 1, `opam update' will not fetch Git history.

OPAM_ONLY_LOCAL_REPOS if set to 1, `opam update' will only update local repositories.

OPAM_ONLY_REMOTE_REPOS if set to 1, `opam update' will only update remote repositories.

OPAM_ORDER_WARNINGS if set to 1, opam will warn when it needs to install packages in a different order than requested.

OPAM_PATCH_CMD the command to use for `opam patch'. Defaults to `patch -p1'.

OPAM_PATCH_REJECT_EXT extension for rejected patches. Defaults to `.rej'.

OPAM_PATCH_REJECT_PREFIX prefix for rejected patches. Defaults to `.`.

OPAM_PATCH_STRIP number of leading components to strip from file names. Defaults to 1.

OPAM_PATCH_STRIP_REVERSED number of leading components to strip from file names when the patch is reversed. Defaults to 1.

OPAM_PRINTER_CMD the command to use for `opam printer'. Defaults to `ocamlfind printconf'.

OPAM_QUERY_DEPTH maximum depth for the dependency graph traversal. Defaults to 100.

OPAM_QUERY_OPTIONS options for the solver query.

OPAM_QUERY_PREFERENCE preference for the solver query. Possible values are `best-satisfying', `least-removed', `most-stable', `most-up-to-date', `package-priority', `version-lag', `version-lag-strict'. Defaults to `best-satisfying'.

OPAM_REAL_PREFIX override the location of the opam switch prefix.

OPAM_REPOSITORIES a list of repositories to use, separated by spaces. If set, overrides the list of repositories in `~/.opam/opam.conf'.

OPAM_REQUEST a list of packages to install or remove, separated by spaces. If set, overrides the packages specified on the command line.

OPAM_ROOT override the location of the opam root directory.

OPAM_SAFE_SWITCHES if set to 1, opam will not create switches with names containing special characters.

OPAM_SAVE_ACTIONS if set to 1, opam will save the actions it performed in a file named `opam-actions.log' in the current directory.

OPAM_SAVE_STATE if set to 1, opam will save the current state of the system in a file named `opam-state.tar.gz' in the current directory.

OPAM_SHOW_REMOTE_DIFFS if set to 1, opam will show remote diffs when updating repositories.

OPAM_SOLVER_ALLOW_UNSAFE_FEATURES if set to 1, opam will allow the solver to still return a solution when they reach timeout; while the solution remains assured to be consistent, there is no guarantee in this case that it fits the expected optimisation criteria. If `true', opam willcontinue with a warning, if `false' a timeout is an error. Currently only the builtin-z3 backend handles this degraded case.

OPAM_SOLVER_TIMEOUT change the time allowance of the solver. Default is 60.0, set to 0 for unlimited. Note that all solvers may not support this option.

OPAM_SOLVER_TOLERANCE changes the tolerance towards the solver choosing an unoptimized solution (i.e. might pull outdated packages). Typical values range from 0.0 (best solution known to the solver) to 1.0 (unoptimized solution). Default is 0.0. This option is useful in case the solver can't find a solution in a reasonable time (see $OPAM_SOLVER_TIMEOUT). Note that all solvers may not support this option.

OPAM_STATS Removed in 2.4.

OPAM_STATUS_LINE display a dynamic status line showing what's currently going on on the terminal. (one of one of always, never or auto)

OPAM_STRICT fail on inconsistencies (file reading, switch import, etc.).

OPAM_SWITCH see option `--switch'. Automatically set by `opam env --switch=SWITCH --set-switch'.

OPAM_UNLOCK_BASE see install option `--unlock-base'.

OPAM_UPGRADE_CRITERIA specifies user preferences for dependency solving when performing an upgrade. Overrides OPAM_CRITERIA in upgrades if both are set. See also option --criteria.

OPAM_USE_INTERNAL_SOLVER see option `--use-internal-solver'.

OPAM_USE_OPENSSL Removed in 2.2.

OPAM_UTF8 use UTF8 characters in output (one of one of always, never or auto). By default `auto', which is determined from the locale).

OPAM_UTF8_MSGS use extended UTF8 characters (camels) in opam messages. Implies OPAM_UTF8. This is set by default on macOS only.

OPAM_VALIDATION_HOOK if set, uses the `%{hook%}' command to validate an opam repository update.

OPAM_VERBOSE see option `--verbose'.

OPAM_VERBOSE_ON see option --verbose-on

OPAM_VERSION_LAG_POWER do not use.

OPAM_WITH_DEV_SETUP see install option `--with-dev-setup'.

OPAM_WITH_DOC see install option `--with-doc'.

OPAM_WITH_TEST see install option `--with-test.

OPAM_WORKING_DIR see option `--working-dir'.

OPAM_YES see options `--yes' and `--confirm-level`. OPAM_YES has priority over OPAM_NO and is ignored if OPAM_CONFIRM_LEVEL is set.

OPAMVAR_var overrides the contents of the variable var when substituting `%{var}%` strings in `opam` files.

OPAMVAR_package_var overrides the contents of the variable package:var when substituting `%{package:var}%` strings in `opam` files.

CLI VERSION

All scripts and programmatic invocations of opam should use `--cli' in order to ensure that they work seamlessly with future versions of the opam client. Additionally, blog posts or other documentation can benefit, as it prevents information from becoming stale.

Although opam only supports roots (~/.opam/) for the current version, it does provide backwards compatibility for its command-line interface.

Since CLI version support was only added in opam 2.1, use OPAM_CLI to select 2.0 support (as opam 2.0 will just ignore it), and `--cli=2.1' for 2.1 (or later) versions, since an environment variable controlling the parsing of syntax is brittle. To this end, opam displays a warning if OPAM_CLI specifies a valid version other than 2.0, and also if `--cli=2.0' is specified.

The command-line version is selected by using the `--cli' option or the OPAM_CLI environment variable. `--cli' may be specified morethan once, where the last instance takes precedence. OPAM_CLI is only inspected if `--cli' is not given.

EXIT STATUS

As an exception to the following, the `exec' command returns 127 if the command was not found or couldn't be executed, and the command's exit value otherwise.

0
Success, or true for boolean queries.
1
False. Returned when a boolean return value is expected, e.g. when running with --check, or for queries like opam lint.
2
Bad command-line arguments, or command-line arguments pointing to an invalid context (e.g. file not following the expected format).
5
Not found. You requested something (package, version, repository, etc.) that couldn't be found.
10
Aborted. The operation required confirmation, which wasn't given.
15
Could not acquire the locks required for the operation.
20
There is no solution to the user request. This can be caused by asking to install two incompatible packages, for example.
30
Error in package definition, or other metadata files. Using --strict raises this error more often.
31
Package script error. Some package operations were unsuccessful. This may be an error in the packages or an incompatibility with your system. This can be a partial error.
40
Sync error. Could not fetch some remotes from the network. This can be a partial error.
50
Configuration error. Opam or system configuration doesn't allow operation, and needs fixing.
60
Solver failure. The solver failed to return a sound answer. It can be due to a broken external solver, or an error in solver configuration.
99
Internal error. Something went wrong, likely due to a bug in opam itself.
130
User interrupt. SIGINT was received, generally due to the user pressing Ctrl-C.
0
on success.
123
on indiscriminate errors reported on standard error.
124
on command line parsing errors.
125
on unexpected internal errors (bugs).
