OPENSSL_gmtime(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

OPENSSL_gmtime(3ssl) OpenSSL OPENSSL_gmtime(3ssl)

الاسم

OPENSSL_gmtime, OPENSSL_gmtime_adj, OPENSSL_gmtime_diff - روتينات زمنية خاصة بـ OpenSSL مستقلة عن المنصة

الملخص

#include <openssl/crypto.h>
struct tm *OPENSSL_gmtime(const time_t *timer, struct tm *result);
int OPENSSL_gmtime_adj(struct tm *tm, int offset_day, long offset_sec);
int OPENSSL_gmtime_diff(int *pday, int *psec,
                       const struct tm *from, const struct tm *to);

الوصف

OPENSSL_gmtime() تُرجع الوقت العالمي المنسق (UTC) المحدد بواسطة timer إلى الوسيط result المقدم.

OPENSSL_gmtime_adj() تضيف الإزاحات في offset_day و offset_sec إلى tm.

OPENSSL_gmtime_diff() تحسب الفرق بين from و to.

ملاحظات

يُعتبر استدعاء OPENSSL_gmtime() مع result يساوي NULL خطأً. يتم تخزين محتويات time_t المعطاة بواسطة timer في result. الاستدعاء مع timer يساوي NULL يعني استخدام الوقت الحالي.

OPENSSL_gmtime_adj() تحول tm إلى قيمة الأيام والثواني، وتضيف الإزاحات، ثم تحول مرة أخرى إلى struct tm محددة بواسطة tm. لا يتم أخذ الثواني الكبيسة في الاعتبار.

OPENSSL_gmtime_diff() تحسب الفرق بين بنيتي struct tm from و to. يتم وضع الفرق بالأيام في *pday، ويتم وضع الثواني المتبقية في *psec. ستكون القيمة في *psec أقل من عدد الثواني في اليوم (3600). لا يتم أخذ الثواني الكبيسة في الاعتبار.

قيم الإرجاع

OPENSSL_gmtime() تُرجع NULL عند حدوث خطأ، أو result عند النجاح.

OPENSSL_gmtime_adj() و OPENSSL_gmtime_diff() ترجعان 0 عند حدوث خطأ، و 1 عند النجاح.

التاريخ

OPENSSL_gmtime() و OPENSSL_gmtime_adj() و OPENSSL_gmtime_diff() موجودة في OpenSSL منذ الإصدار 1.0.0.
