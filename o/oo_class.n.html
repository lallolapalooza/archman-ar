oo_class(n)

الحزمة: tcl

التراخيص: TCL

class(n) أوامر TclOO class(n)

الاسم

oo::class - فئة جميع الفئات

الموجز

package require TclOO
oo::class method ?arg ...?

هرمية الفئة

oo::object
   → oo::class

الوصف

الفئات هي كائنات يمكنها تصنيع كائنات أخرى وفقًا لنمط مخزن في كائن المصنع (الفئة). يتم إنشاء مثيل للفئة عن طريق استدعاء أحد أساليب المصنع الخاصة بالفئة، عادةً إما create إذا كان يتم إعطاء اسم صريح، أو new إذا كان سيتم تحديد اسم فريد بشكل عشوائي.

الفئة oo::class هي فئة جميع الفئات؛ كل فئة هي مثيل لهذه الفئة، وهي بدورها مثيل لنفسها. هذه الفئة هي فئة فرعية لـ oo::object، لذا فإن كل فئة هي أيضًا كائن. يمكن تعريف فئات وصفية إضافية (أي فئات الفئات) إذا لزم الأمر عن طريق إنشاء فئة فرعية لـ oo::class. لاحظ أن الكائن oo::class يخفي الأسلوب new بنفسه، لذلك يجب دائمًا إنشاء فئات جديدة باستخدام الأسلوب create.

الباني

يأخذ باني الفئة oo::class وسيطة اختيارية، والتي إذا كانت موجودة، يتم إرسالها إلى أمر oo::define (جنبًا إلى جنب مع اسم الفئة التي تم إنشاؤها حديثًا) للسماح بتكوين الفئة بشكل ملائم عند الإنشاء.

الهادم

لا تحدد الفئة oo::class هادمًا صريحًا. ومع ذلك، عند تدمير فئة، يتم أيضًا تدمير جميع فئاتها الفرعية ومثيلاتها، بالإضافة إلى جميع الكائنات التي تم دمجها فيها.

الأساليب المصدرة

cls create name ?arg ...?
ينشئ هذا مثيلاً جديدًا للفئة cls يسمى name (والذي يتم تفسيره ضمن نطاق السياق المتصل إذا لم يكن مؤهلاً بالكامل)، ويمرر الوسائط، arg ...، إلى الباني، وبعد ذلك (إذا أعاد نتيجة ناجحة) يعيد الاسم المؤهل بالكامل للكائن الذي تم إنشاؤه (يتم تجاهل نتيجة الباني). إذا فشل الباني (أي أعاد نتيجة غير OK) فيتم تدمير الكائن ويكون رسالة الخطأ هي نتيجة استدعاء هذا الأسلوب.
cls new ?arg ...?
ينشئ هذا مثيلاً جديدًا للفئة cls باسم فريد جديد، ويمرر الوسائط، arg ...، إلى الباني، وبعد ذلك (إذا أعاد نتيجة ناجحة) يعيد الاسم المؤهل بالكامل للكائن الذي تم إنشاؤه (يتم تجاهل نتيجة الباني). إذا فشل الباني (أي أعاد نتيجة غير OK) فيتم تدمير الكائن ويكون رسالة الخطأ هي نتيجة استدعاء هذا الأسلوب.

لاحظ أن هذا الأسلوب غير مصدّر بواسطة الكائن oo::class نفسه، لذلك لا يجب إنشاء فئات باستخدام هذا الأسلوب.

الأساليب غير المصدرة

تدعم الفئة oo::class الأساليب التالية غير المصدرة:

cls createWithNamespace name nsName ?arg ...?
ينشئ هذا مثيلاً جديدًا للفئة cls يسمى name (والذي يتم تفسيره ضمن نطاق السياق المتصل إذا لم يكن مؤهلاً بالكامل)، ويمرر الوسائط، arg ...، إلى الباني، وبعد ذلك (إذا أعاد نتيجة ناجحة) يعيد الاسم المؤهل بالكامل للكائن الذي تم إنشاؤه (يتم تجاهل نتيجة الباني). سيكون اسم النطاق الداخلي للمثيل هو nsName؛ يعتبر خطأ إذا لم يكن من الممكن إنشاء هذا النطاق. إذا فشل الباني (أي أعاد نتيجة غير OK) فيتم تدمير الكائن ويكون رسالة الخطأ هي نتيجة استدعاء هذا الأسلوب.

أمثلة

يقوم هذا المثال بتعريف هرمية فئات بسيطة وإنشاء مثيل جديد لها. ثم يستدعي أسلوبًا للكائن قبل تدمير الهرمية وإظهار أن التدمير انتقالي.

oo::class create fruit {
    method eat {} {
        puts "yummy!"
    }
}
oo::class create banana {
    superclass fruit
    constructor {} {
        my variable peeled
        set peeled 0
    }
    method peel {} {
        my variable peeled
        set peeled 1
        puts "skin now off"
    }
    method edible? {} {
        my variable peeled
        return $peeled
    }
    method eat {} {
        if {![my edible?]} {
            my peel
        }
        next
    }
}
set b [banana new]
$b eat               → prints "skin now off" and "yummy!"
fruit destroy
$b eat               → error "unknown command"
