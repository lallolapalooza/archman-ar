optionFindValue(3)

الحزمة: autogen

التراخيص: GPL3

optionFindValue(3) دليل المبرمج optionFindValue(3)

الاسم

optionFindValue - البحث عن مثيل خيار بقيمة هرمية

الملخص

#include <your-opts.h>
cc [...] -o outfile infile.c -lopts [...]

const tOptionValue * optionFindValue(const tOptDesc * odesc, char const * name, char const * val);

الوصف

هذا الروتين سيجد إدخالاً في خيار قيمة متداخلة أو قابل للتكوين. سيقوم بالبحث عبر القائمة وإرجاع إدخال مطابق.

odesc
خيار بنوع وسيط متداخل
name
اسم القيمة المراد البحث عنها
val
القيمة المطابقة

قيمة الإرجاع

هيكل قيمة مركبة

الأخطاء

النتيجة المرجعة هي NULL ويتم تعيين errno:

EINVAL - لا يشير pOptValue إلى قيمة خيار هرمية صالحة.

ENOENT - لم يطابق أي إدخال الاسم المعطى. @end itemize
