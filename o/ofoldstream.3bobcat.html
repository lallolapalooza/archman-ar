الحزمة: libbobcat

التراخيص: GPL

FBB::OFoldStream(3bobcat) طي الأسطر الطويلة FBB::OFoldStream(3bobcat)

الاسم

FBB::OFoldStream - يطوي الأسطر الطويلة

ملخص

#include <bobcat/ofoldstream>
خيار الربط: -lbobcat

الوصف

FBB::OFoldStream يطوي الأسطر الطويلة المكتوبة إليه. يقوم OFoldStream بكتابة الأسطر (المطوية) إلى ostream ثانٍ يتم استخدامه بواسطة كائن OFoldStream أو فتحه بواسطة هذا الكائن.

كائنات OFoldStream لا تطوي الأسطر أبدًا في منتصف سلسلة من الأحرف غير الفارغة ولكنها ستكسر دائمًا السطر عند أحرف المسافة البيضاء. ستظهر الأسطر الناتجة دائمًا إلى يمين هامش أيسر قابل للتكوين وإلى يسار هامش أيمن قابل للتكوين. هناك استثناء غريب إلى حد ما لهذا: إذا كانت كلمة طويلة جدًا بحيث لا تتسع بين الهوامش، فستتجاوز الكلمة الهامش الأيمن.

يتم تكوين المسافة البادئة المستخدمة للهوامش اليسرى لتكون إما مسافات (الافتراضي) أو علامات جدولة. عند استخدام علامات الجدولة، يكون عرض حرف الجدولة قابلاً للتكوين، باستخدام قيمة افتراضية تبلغ 8 مواضع في تدفق الوجهة.

تم تنفيذ OFoldStream كفئة غلاف حول std::ostream و FBB::OFoldBuf ويمكن العثور على وصف أكثر اكتمالًا لعملية الطي في صفحة الدليل ofoldbuf(3bobcat).

تعداد

يستخدم التعداد TabsOrBlanks لتحديد علامات الجدولة أو المسافات عند كتابة المسافة البادئة. الافتراضي هو المسافات. عند تحديد علامات الجدولة، يمكن أيضًا تكوين عرض عرض أحرف الجدولة (باستخدام الافتراضي 8 مواضع لكل حرف جدولة). يحتوي التعداد على قيمتين:

o
BLANKS:
الافتراضي، يشير إلى أن الهامش الأيسر محدد ومكتوب كعدد من المسافات؛
o
TABS:
يشير إلى أن الهامش الأيسر محدد ومكتوب كعدد من أحرف الجدولة.

يستخدم التعداد TrailingBlanks لتكوين كائن OFoldStream فيما يتعلق بأي مسافات لاحقة قد تظهر في السطر النهائي. إنه نفس نوع التعداد المستخدم مع OFoldBuf (راجع صفحة الدليل ofoldbuf(3bobcat)) ولديه قيمتان:

o
IGNORE_TRAILING_BLANKS:
يشير هذا إلى أنه لا يجب كتابة المسافات اللاحقة التي تظهر في السطر النهائي إذا لم يكن منتهيًا بسطر جديد إلى std::ostream الوجهة. هذا هو الافتراضي الذي تستخدمه كائنات OFoldStream.
o
KEEP_TRAILING_BLANKS:
يشير هذا إلى أنه يجب كتابة المسافات اللاحقة في السطر النهائي إذا لم يكن منتهيًا بسطر جديد إلى std::ostream الوجهة.

المنشئات

o
OFoldStream():
يقوم هذا المنشئ بتهيئة كائن OFoldStream ولكنه لا يربطه بتدفق وجهة. يستخدم القيم 0، 80، BLANKS، و IGNORE_TRAILING_BLANKS للهامش الأيسر، الهامش الأيمن، أحرف الهامش الأيسر، ووضع معالجة TrailingBlanks على التوالي.
o
OFoldStream(char const *fname, size_t leftIndent = 0, size_t rightMargin = 80, TabsOrBlanks tob = BLANKS, TrailingBlanks tb = IGNORE_TRAILING_BLANKS):
يقوم هذا المنشئ بتهيئة كائن OFoldStream ويفتح (باستخدام std::ios::out) تدفق الوجهة باستخدام الاسم المحدد كوسيط fname.
o
OFoldStream(std::ostream &stream, size_t leftIndent = 0, size_t rightMargin = 80, TabsOrBlanks tob = BLANKS, TrailingBlanks tb = IGNORE_TRAILING_BLANKS):
يقوم هذا المنشئ بتهيئة كائن OFoldStream ويستخدم تدفق الوجهة هو std::ostream stream المحدد.

يقوم المدمر بكتابة أي معلومات مخزنة مؤقتًا إلى تدفق الوجهة ثم سيقوم بتفريغ تدفق الوجهة.

منشئات النسخ والتحريك (وعوامل التعيين) غير متاحة.

دوال الأعضاء

جميع أعضاء std::ostream متاحة، حيث أن FBB::OFoldStream ترث من هذه الفئة.

o
void close():
يقوم هذا العضو بتفريغ أي معلومات معلقة إلى تدفق الوجهة ثم يغلق تدفق الوجهة.
o
void open(char const *fname, openmode mode = std::ios::out):
يقوم هذا العضو بربط كائن OFilterStream بكائن std::ofstream يتم توفير اسم الملف الخاص به ويجب أن يستقبل المعلومات المطوية.
o
void open(std::ostream &out):
يقوم هذا العضو بربط كائن OFilterStream بكائن ostream الموفر.
o
void setMargins(size_t leftMargin, size_t rightMargin):
يمكن استخدام هذا العضو لتعديل هوامش الطي اليسرى واليمنى. لاحظ أنه يمكن أيضًا تعديل الهامش الأيسر باستخدام معالجات FBB::lm و FBB::mlm.
o
void setTrailingBlanks(TrailingBlanks tb):
يمكن استخدام هذا العضو لتعديل معامل TrailingBlanks المستخدم حاليًا.
o
void useBlanks():
يمكن استخدام هذا العضو لتحديد المسافات لاستخدامها عند إدراج الهوامش اليسرى.
o
void useTabs(size_t tabWidth = 8):
يمكن استخدام هذا العضو لتحديد أحرف الجدولة لاستخدامها عند إدراج الهوامش اليسرى. يتم استخدام المعامل الثاني لتحديد عرض عرض حرف الجدولة.

دوال الأعضاء الثابتة

o
size_t leftMargin(std::ostream const &os):
يعيد هذا العضو إعداد الهامش الأيسر الحالي لكائن OFoldStream الذي تم تمريره إليه كوسيط له. يحدد العضو وسيط std::ostream لأنه في العديد من الحالات، سيتم استخدام كائن OFoldStream في دوال تعرف وسائط std::ostream بنفسها. داخليًا، يتم تحويل std::streambuf الخاص بـ std::ostream إلى OFoldBuf ويتم طرح استثناء FBB::Exception إذا فشل هذا التحويل.
o
size_t rightMargin(std::ostream const &os):
يعيد هذا العضو إعداد الهامش الأيمن الحالي لكائن OFoldStream الذي تم تمريره إليه كوسيط له. يتم تحويل وسيط العضو بنفس الطريقة التي يتم بها تحويل وسيط leftMargin(): يتم طرح استثناء FBB::Exception إذا فشل هذا التحويل.

مثال

#include <iostream>
#include <string>
#include <bobcat/ofoldstream>
using namespace std;
using namespace FBB;
void margins(ostream &out)
{
    cout << OFoldStream::leftMargin(out) << ", " <<
            OFoldStream::rightMargin(out) << endl;
}
int main()
{
    OFoldStream out(cout, 4, 40);
    out << lm(4);
    string line;
    while (getline(cin, line))
        out << line << ’\n’;
    margins(out);
}
