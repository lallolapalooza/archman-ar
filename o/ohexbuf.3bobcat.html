الحزمة: libbobcat

التراخيص: GPL

FBB::OHexBuf(3bobcat) كتابة القيم الست عشرية FBB::OHexBuf(3bobcat)

الاسم

FBB::OHexBuf - يكتب الأحرف المكتوبة إلى دفق إخراج كقيم ست عشرية

الملخص

#include <bobcat/ohexbuf>
خيار الربط: -lbobcat

الوصف

OHexBuf هو تخصص لـ FBB::OFilterBuf يدرج جميع الأحرف التي يستقبلها في ملف وجهة كقيم ست عشرية بعرض حرفين. اختياريًا، يمكن تحديد طول سطر أقصى.

لاحظ أن جميع المعلومات التي يتلقاها كائن OHexBuf يتم إدراجها كسلسلة (أو سلاسل) من القيم الست عشرية، وليس فقط الأحرف العادية. على سبيل المثال، عند إدراج القيمة 123، يتم إدراج الأحرف '1' و '2' و '3' بالتتابع، وبالتالي سينتج عن ذلك إدراج السلسلة 313233 في دفق الوجهة.

المساحة الاسمية

FBB
جميع المنشئات والأعضاء والعوامل والمعدلات المذكورة في صفحة الدليل هذه معرفة في المساحة الاسمية FBB.

يرث من

FBB::OFilterBuf

المنشئ

o
OHexBuf(std::ostream &stream, size_t width = 0, std::string const &separator = ""):
يتم إدراج الأحرف الست عشرية التي ينتجها كائن OFilterBuf في stream. اختياريًا، يمكن تحديد عرض السطر الأقصى (بالعدد الأحرف) باستخدام width. القيمة الافتراضية 0 تشير إلى عدم طلب فواصل أسطر. تحدد المعلمة separator الفاصل الذي يتم إدراجه بين قيم الأحرف الست عشرية. افتراضيًا، لا يتم استخدام فاصل.

منشئات النسخ والنقل (وعوامل التعيين) غير متاحة.

يكتب المدمر أي معلومات مخزنة مؤقتًا إلى دفق الوجهة ثم يقوم بتفريغ دفق الوجهة. أخيرًا، يقوم المدمر باستعادة علامات التنسيق الأصلية لدفق الإخراج المستلم ostream.

دوال العضو

جميع أعضاء FBB::OFilterBuf، وخاصة أعضائها out() و reset، متاحة، حيث أن FBB::OHexBuf يرث من هذه الفئة.

o
void eoi():
يكمل هذا العضو تحويل الحرف الست عشري الحالي، ويمسح الفاصل، ويتوقف عن استخدام عرض سطر الإخراج الأقصى. بدلاً من استدعاء هذا العضو، يمكن استخدام المعدل eoi (انظر أدناه).
o
void separator(bool reset = true):
يمسح هذا العضو الفاصل الذي يتم إدراجه بين قيم الأحرف الست عشرية. عندما يتم تعيين المعلمة reset إلى true (وهو الافتراضي)، يتم إعادة تعيين عرض الإخراج الحالي إلى 0.
o
void separator(std::string const &separator, bool reset = true):
يعيد هذا العضو تعيين الفاصل الذي يتم إدراجه بين قيم الأحرف الست عشرية إلى قيمة separator. عندما يتم تعيين المعلمة reset إلى true (وهو الافتراضي)، يتم إعادة تعيين عرض الإخراج الحالي إلى 0.
o
void setWidth(size_t width):
يحدد هذا العضو عرض أسطر الإخراج التي تم إنشاؤها إلى width حرفًا. لا يتم استخدام عرض سطر أقصى عند تحديد width = 0.
o
size_t size() const:
يعيد هذا العضو إزاحة العمود التالي حيث سيظهر الحرف الست عشري التالي. إذا تم طلب طول سطر أقصى و size() لا يعيد 0، فهذا يعني أن السطر الأخير الذي تم إدراجه لم ينتهِ بحرف '\n'. انظر أيضًا المثال أدناه.
قيمة هذا العضو غير محددة إذا لم يتم طلب طول سطر أقصى.

المعدل

o
FBB::eoi:
يمكن إدراج المعدل eoi في ostream لإكمال تحويل الأرقام الست عشرية. يتصرف بشكل متطابق مع استدعاء العضو end. إذا تم إدراجه في std::ostream عادي، فلن يحدث شيء.

العضو الثابت

o
std::string text2bin(std::string const &in):
يقوم هذا العضو الثابت بتحويل سلسلة من الأحرف الست عشرية التي تم إنشاؤها بواسطة كائن OHexBuf مرة أخرى إلى شكلها الثنائي. على سبيل المثال، عند استدعائه كـ OHexBuf::text2bin("736d616c6c206976")، فإن std::string المعاد سيكون يحتوي على 8 أحرف، لها على التوالي القيم الثنائية 0x73، 0x6d، 0x61، 0x6c، 0x6c، 0x20، 0x69، و 0x76.
هذه الدالة *لا* تتحقق مما إذا كان الوسيط الخاص بها مُشكّلًا بشكل صحيح. يتكون الوسيط المشكّل بشكل صحيح من عدد زوجي من أرقام الأرقام الست عشرية ( '0' حتى '9'، 'a' حتى 'f' (أو بأحرف كبيرة)). بالنسبة للوسائط المشكلة بشكل غير صحيح، تكون القيمة المعاد غير محددة.

مثال

    #include <iostream>
    #include <bobcat/ohexbuf>
    using namespace std;
    using namespace FBB;
    int main()
    {
        OHexBuf ohex(cout, 40);
        ostream out(&ohex);
        out << cin.rdbuf();
        if (ohex.size())
            cout << ’\n’;
    }
