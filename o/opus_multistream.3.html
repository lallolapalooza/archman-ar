الوصف التفصيلي

تتيح واجهة برمجة التطبيقات multistream دمج تدفقات Opus الفردية في حزمة واحدة، مما يتيح دعم ما يصل إلى 255 قناة.

على عكس تدفق Opus الأساسي، يجب على المرمّز ومفكك التشفير التفاوض على تكوين القناة قبل أن يتمكن مفكك التشفير من تفسير البيانات في الحزم الناتجة عن المرمّز بنجاح. يمكن حساب بعض المعلومات الأساسية، مثل مدة الحزمة، دون الحاجة إلى تفاوض خاص.

يتم تعريف تنسيق حزم Opus multistream في RFC 7845 وهو يعتمد على تأطير Opus الذاتي التحديد الموصوف في الملحق B من RFC 6716. تعتبر حزم Opus العادية مجرد حالة تنكسية لحزم Opus multistream، ويمكن ترميزها أو فك تشفيرها باستخدام واجهة برمجة التطبيقات multistream عن طريق تعيين streams إلى 1 عند تهيئة المرمّز أو مفكك التشفير.

يمكن أن تحتوي تدفقات Opus Multistream على ما يصل إلى 255 تدفق Opus أساسي. يمكن أن تكون هذه إما 'غير مقترنة' أو 'مقترنة'، مما يشير إلى أن مفكك التشفير مهيأ لفك تشفيرها إلى قناة واحدة أو قناتين، على التوالي. يتم ترتيب التدفقات بحيث تظهر جميع التدفقات المقترنة في البداية.

يحدد جدول mapping أي قناة مخرجة i يجب استخدامها لكل قناة إدخال/إخراج (I/O) j. يتم توفير هذا الجدول عادةً كمصفوفة char غير موقعة. دع i = mapping[j] يكون الفهرس لقناة الإدخال/الإخراج j. إذا كان i < 2*coupled_streams، فإن قناة الإدخال/الإخراج j يتم ترميزها كقناة يسرى للتدفق (i/2) إذا كان i زوجيًا، أو كقناة يمنى لللتدفق (i/2) إذا كان i فرديًا. بخلاف ذلك، يتم ترميز قناة الإدخال/الإخراج j كأحادية في التدفق (i - coupled_streams)، ما لم تكن لديها القيمة الخاصة 255، وفي هذه الحالة يتم حذفها من الترميز تمامًا (سيقوم مفكك التشفير بإعادة إنتاجها كصمت). يجب أن تكون كل قيمة i إما القيمة الخاصة 255 أو أقل من streams + coupled_streams.

يجب أن تستخدم قنوات الإخراج المحددة بواسطة المرمّز ترتيب قنوات Vorbis. قد يرغب مفكك التشفير في تطبيق تبديل إضافي للجدول الذي استخدمه المرمّز لتحقيق ترتيب قنوات إخراج مختلف (على سبيل المثال، للإخراج بترتيب WAV).

تحتوي كل حزمة multistream على حزمة Opus لكل تدفق، ويجب أن تكون جميع حزم Opus في حزمة multistream واحدة لها نفس المدة. لذلك يمكن استخراج مدة حزمة multistream من تسلسل TOC للتدفق الأول، والذي يقع في بداية الحزمة، تمامًا مثل تدفق Opus الأساسي:

int nb_samples;
int nb_frames;
nb_frames = opus_packet_get_nb_frames(data, len);
if (nb_frames < 1)
  return nb_frames;
nb_samples = opus_packet_get_samples_per_frame(data, 48000) * nb_frames;

تتم عملية الترميز وفك التشفير العامة بنفس الطريقة تمامًا كما هو الحال في واجهات برمجة التطبيقات العادية لمرمّز Opus و مفكك تشفير Opus. راجع وثائقهما للحصول على نظرة عامة حول كيفية استخدام الوظائف multistream المقابلة.

opus_encode_float

Encodes a Opus frame from floating point input.

Parameters

st OpusEncoder*: Encoder state.

pcm const float*: The input signal as interleaved samples in the range [-1.0, 1.0]. Samples with a range outside of this are supported but will be clipped by decoders using the integer API and should only be used if it is known that the far end supports extended dynamic range.

frame_size int: Number of samples per channel in the input signal. This must be an Opus frame size for the encoder's sampling rate. For example, at 48 kHz the permitted values are 120, 240, 480, 960, 1920, and 2880. Passing in a duration of less than 10 ms (480 samples at 48 kHz) will prevent the encoder from using the LPC or hybrid modes.

data unsigned char*: Output payload. This must contain storage for at least max_data_bytes.

max_data_bytes opus_int32: Size of the allocated memory for the output payload. This may be used to impose an upper limit on the instant bitrate, but should not be used as the only bitrate control. Use opus_encoder_ctl() with OPUS_SET_BITRATE to control the bitrate.

Returns

The length of the encoded packet (in bytes) on success or a negative error code (see Error codes) on failure.

OpusMSEncoder * opus_multistream_encoder_create (opus_int32 Fs, int channels, int streams, int coupled_streams, const unsigned char * mapping, int application, int * error)

Allocates and initializes a multistream encoder state. Call opus_multistream_encoder_destroy() to release this object when finished.

Parameters

Fs opus_int32: Sampling rate of the input signal (in Hz). This must be one of 8000, 12000, 16000, 24000, or 48000.

channels int: Number of channels in the input signal. This must be at most 255. It may be greater than the number of coded channels (streams + coupled_streams).

streams int: The total number of streams to encode from the input. This must be no more than the number of channels.

coupled_streams int: Number of coupled (2 channel) streams to encode. This must be no larger than the total number of streams. Additionally, The total number of encoded channels (streams + coupled_streams) must be no more than the number of input channels.

mapping const unsigned char[channels]: Mapping from encoded channels to input channels, as described in Opus Multistream API. As an extra constraint, the multistream encoder does not allow encoding coupled streams for which one channel is unused since this is never a good idea.

application int: The target encoder application. This must be one of the following:

OPUS_APPLICATION_VOIP
Process signal for improved speech intelligibility.
OPUS_APPLICATION_AUDIO
Favor faithfulness to the original input.
OPUS_APPLICATION_RESTRICTED_LOWDELAY
Configure the minimum possible coding delay by disabling certain modes of operation.

error int *: Returns OPUS_OK on success, or an error code (see Error codes) on failure.
