الوصف التفصيلي

Opus المخصص هو جزء اختياري من مواصفات Opus وتنفيذها المرجعي الذي يستخدم واجهة برمجة تطبيقات (API) مميزة عن الواجهة العادية ويدعم أحجام إطارات غير مدعومة عادةً. يُنصح بتجنب استخدام Opus المخصص إلا للتطبيقات الخاصة جدًا التي تحتاج إلى حجم إطار مختلف عن 2.5، 5، 10، أو 20 مللي ثانية (لأسباب تتعلق بالتعقيد أو زمن الاستجابة) وحيث يكون التوافق أقل أهمية.

بالإضافة إلى قيود التوافق، فإن استخدام Opus المخصص يعطل جزءًا كبيرًا من برنامج الترميز ويقلل بشكل عام من الجودة المتاحة عند معدل بت معين. عادةً، عندما يحتاج التطبيق إلى حجم إطار مختلف عن برنامج الترميز، يجب عليه التخزين المؤقت لمطابقة الأحجام، ولكن هذا يضيف تأخيرًا صغيرًا قد يكون مهمًا في بعض التطبيقات ذات زمن الاستجابة المنخفض جدًا. قد تعمل بعض وسائل النقل (خاصة وسائل النقل اللاسلكية ذات معدل ثابت) بشكل أفضل مع إطارات ذات مدد زمنية معينة.

يدعم Libopus الأوضاع المخصصة فقط إذا تم تمكينها وقت التجميع.

واجهة برمجة تطبيقات Opus المخصصة تشبه الواجهة العادية ولكن استدعاءات opus_encoder_create و opus_decoder_create تأخذ معلمة وضع إضافية وهي هيكل تم إنتاجه بواسطة استدعاء opus_custom_mode_create. يجب على كل من المشفر والمفكك إنشاء وضع باستخدام نفس معدل العينة (fs) وحجم الإطار (frame_size) بالضبط، لذا يجب إما إشارة هذه المعلمات خارج النطاق أو تثبيتها في تطبيق معين.

على غرار Opus العادي، تدعم الأوضاع المخصصة التبديل الديناميكي لحجم الإطار، ولكن الأحجام المتاحة تعتمد على حجم الإطار المحدد قيد الاستخدام. بالنسبة لبعض أحجام الإطارات الأولية، يتوفر حجم ديناميكي واحد فقط.

DESCRIPTION

This API provides a way to encode and decode Opus streams with a fixed mode, as opposed to the standard API which auto-detects the mode.

int opus_custom_encode (OpusCustomEncoder * st, const opus_int16 * pcm, int frame_size, unsigned char * compressed, int maxCompressedBytes)

Encodes a frame of audio.

Parameters

st OpusCustomEncoder*: Encoder state
pcm opus_int16*: PCM audio in signed 16-bit format (native endian). There must be exactly frame_size samples per channel.
frame_size int: Number of samples per frame of input signal
compressed char *: The compressed data is written here. This may not alias pcm and must be at least maxCompressedBytes long.
maxCompressedBytes int: Maximum number of bytes to use for compressing the frame (can change from one frame to another)

Returns

Number of bytes written to 'compressed'. If negative, an error has occurred (see error codes). It is IMPORTANT that the length returned be somehow transmitted to the decoder. Otherwise, no decoding is possible.

int opus_custom_encode_float (OpusCustomEncoder * st, const float * pcm, int frame_size, unsigned char * compressed, int maxCompressedBytes)

Encodes a frame of audio.

Parameters

st OpusCustomEncoder*: Encoder state
pcm float*: PCM audio in float format, with a normal range of +/-1.0. Samples with a range beyond +/-1.0 are supported but will be clipped by decoders using the integer API and should only be used if it is known that the far end supports extended dynamic range. There must be exactly frame_size samples per channel.
frame_size int: Number of samples per frame of input signal
compressed char *: The compressed data is written here. This may not alias pcm and must be at least maxCompressedBytes long.
maxCompressedBytes int: Maximum number of bytes to use for compressing the frame (can change from one frame to another)

Returns

Number of bytes written to 'compressed'. If negative, an error has occurred (see error codes). It is IMPORTANT that the length returned be somehow transmitted to the decoder. Otherwise, no decoding is possible.

OpusCustomMode * opus_custom_mode_create (opus_int32 Fs, int frame_size, int * error)

Creates a new mode struct. This will be passed to an encoder or decoder. The mode MUST NOT BE DESTROYED until the encoders and decoders that use it are destroyed as well.

Parameters

Fs int: Sampling rate (8000 to 96000 Hz)
frame_size int: Number of samples (per channel) to encode in each packet (64 - 1024, prime factorization must contain zero or more 2s, 3s, or 5s and no other primes)
error int*: Returned error code (if NULL, no error will be returned)

Returns

A newly created mode
