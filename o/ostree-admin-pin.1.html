ostree-admin-pin(1)

الحزمة: ostree

التراخيص: LGPL-2.0-or-later

OSTREE ADMIN PIN(1) ostree admin pin OSTREE ADMIN PIN(1)

الاسم

ostree-admin-pin - الاحتفاظ صراحة بتوزيع في فهرس معين

الخلاصة

ostree admin pin {INDEX}

الوصف

يضمن عدم تجميع التوزيع الموجود في INDEX افتراضيًا. يُطلق على هذا "التثبيت". إذا تم توفير الخيار -u، فإنه يلغي عملية التثبيت. يمكن أن يكون INDEX >= 0 أو إحدى الكلمات المفتاحية booted أو pending أو rollback.

الخيارات

--unpin،-u

يلغي عملية التثبيت.
