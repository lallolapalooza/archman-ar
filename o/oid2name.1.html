oid2name(1)

الحزمة: postgresql

التراخيص: PostgreSQL

OID2NAME(1) وثائق PostgreSQL 18.1 OID2NAME(1)

الاسم

oid2name - حل معرفات الكائنات (OIDs) وعقد الملفات في دليل بيانات PostgreSQL

الاستخدام

oid2name [خيار...]

الوصف

oid2name هو برنامج مساعد يساعد المسؤولين على فحص بنية الملفات التي يستخدمها PostgreSQL. للاستفادة منه، تحتاج إلى أن تكون على دراية ببنية ملفات قاعدة البيانات، والتي تم وصفها في الفصل 66.


ملاحظة

الاسم "oid2name" هو اسم تاريخي، وهو في الواقع مضلل إلى حد ما، نظرًا لأن معظم الوقت الذي تستخدمه فيه، ستكون مهتمًا فعليًا بأرقام عقد ملفات الجداول (وهي أسماء الملفات الظاهرة في أدلة قواعد البيانات). تأكد من فهمك للفرق بين معرفات الكائنات (OIDs) للجداول وعقد الملفات (filenodes) للجداول!

يتصل oid2name بقاعدة بيانات مستهدفة ويستخرج معلومات معرف الكائن (OID) وعقدة الملف (filenode) و/أو اسم الجدول. يمكنك أيضًا جعله يعرض معرفات كائنات قواعد البيانات أو معرفات كائنات مساحات الجداول (tablespaces).

الخيارات

يقبل oid2name وسائط سطر الأوامر التالية:

-f عقدة-الملف
--filenode=عقدة-الملف

يعرض معلومات للجدول الذي له عقدة الملف عقدة-الملف.

-i
--indexes

يتضمن الفهارس (indexes) والتسلسلات (sequences) في القائمة.

-o معرف-الكائن
--oid=معرف-الكائن

يعرض معلومات للجدول الذي له معرف الكائن معرف-الكائن.

-q
--quiet

يتجاهل العناوين (مفيد للبرمجة النصية).

-s
--tablespaces

يعرض معرفات كائنات مساحات الجداول.

-S
--system-objects

يتضمن الكائنات النظامية (تلك الموجودة في مخططات information_schema، pg_toast و pg_catalog).

-t نمط-اسم-الجدول
--table=نمط-اسم-الجدول

يعرض معلومات للجداول التي تطابق نمط-اسم-الجدول.

-V
--version

يطبع إصدار oid2name ويخرج.

-x
--extended

يعرض مزيدًا من المعلومات حول كل كائن معروض: اسم مساحة الجدول، اسم المخطط، ومعرف الكائن (OID).

-?
--help

يعرض المساعدة حول وسائط سطر الأوامر لـ oid2name، ويخرج.

يقبل oid2name أيضًا وسائط سطر الأوامر التالية لمعلمات الاتصال:

-d قاعدة-البيانات
--dbname=قاعدة-البيانات

قاعدة البيانات للاتصال بها.

-h المضيف
--host=المضيف

مضيف خادم قاعدة البيانات.

-H المضيف

مضيف خادم قاعدة البيانات. تم إيقاف استخدام هذا المعامل (deprecated) اعتبارًا من PostgreSQL 12.

-p المنفذ
--port=المنفذ

منفذ خادم قاعدة البيانات.

-U اسم-المستخدم
--username=اسم-المستخدم

اسم المستخدم للاتصال به.

لعرض جداول محددة، اختر الجداول التي سيتم عرضها باستخدام -o، -f و/أو -t. يأخذ -o معرف كائن (OID)، و -f يأخذ عقدة ملف (filenode)، و -t يأخذ اسم جدول (في الواقع، إنه نمط LIKE، لذا يمكنك استخدام أشياء مثل foo%). يمكنك استخدام أي عدد تريده من هذه الخيارات، وسيحتوي الإدراج على جميع الكائنات المطابقة لأي من الخيارات. ولكن لاحظ أن هذه الخيارات لا يمكنها عرض سوى الكائنات الموجودة في قاعدة البيانات التي تم تقديمها بواسطة -d.

إذا لم تقدم أيًا من -o، -f أو -t، ولكنك قدمت -d، فسوف يسرد جميع الجداول في قاعدة البيانات المسماة بواسطة -d. في هذا الوضع، تتحكم الخيارات -S و -i فيما يتم سرده.

إذا لم تقدم -d أيضًا، فسيعرض قائمة بمعرفات كائنات قواعد البيانات. بدلاً من ذلك، يمكنك تقديم -s للحصول على قائمة بمساحات الجداول.

البيئة

PGHOST
PGPORT
PGUSER

معلمات الاتصال الافتراضية.

تستخدم هذه الأداة، مثل معظم أدوات PostgreSQL الأخرى، متغيرات البيئة المدعومة بواسطة libpq (انظر القسم 32.15).

يحدد متغير البيئة PG_COLOR ما إذا كان سيتم استخدام الألوان في رسائل التشخيص. القيم الممكنة هي دائمًا (always)، تلقائي (auto) و أبدًا (never).

ملاحظات

يتطلب oid2name تشغيل خادم قاعدة بيانات بسجلات نظام غير تالفة. لذلك، فإن فائدته محدودة في حالات تلف قاعدة البيانات الكارثية.

أمثلة

$ # ما الموجود في خادم قاعدة البيانات هذا، على أي حال؟
$ oid2name
جميع قواعد البيانات:
    Oid  اسم قاعدة البيانات  مساحة الجدول
----------------------------------
  17228       alvherre  pg_default
  17255     regression  pg_default
  17227      template0  pg_default
      1      template1  pg_default
$ oid2name -s
جميع مساحات الجداول:
     Oid  اسم مساحة الجدول
-------------------------
    1663       pg_default
    1664        pg_global
  155151         fastdisk
  155152          bigdisk
$ # حسنًا، دعنا نلقي نظرة على قاعدة البيانات alvherre
$ cd $PGDATA/base/17228
$ # الحصول على أكبر 10 كائنات في قاعدة البيانات، مرتبة حسب الحجم
$ ls -lS * | head -10
-rw-------  1 alvherre alvherre 136536064 sep 14 09:51 155173
-rw-------  1 alvherre alvherre  17965056 sep 14 09:51 1155291
-rw-------  1 alvherre alvherre   1204224 sep 14 09:51 16717
-rw-------  1 alvherre alvherre    581632 sep  6 17:51 1255
-rw-------  1 alvherre alvherre    237568 sep 14 09:50 16674
-rw-------  1 alvherre alvherre    212992 sep 14 09:51 1249
-rw-------  1 alvherre alvherre    204800 sep 14 09:51 16684
-rw-------  1 alvherre alvherre    196608 sep 14 09:50 16700
-rw-------  1 alvherre alvherre    163840 sep 14 09:50 16699
-rw-------  1 alvherre alvherre    122880 sep  6 17:51 16751
$ # ما هو الملف 155173؟
$ oid2name -d alvherre -f 155173
من قاعدة البيانات "alvherre":
  عقدة الملف  اسم الجدول
----------------------
    155173    accounts
$ # يمكنك طلب أكثر من كائن واحد
$ oid2name -d alvherre -f 155173 -f 1155291
من قاعدة البيانات "alvherre":
  عقدة الملف     اسم الجدول
-------------------------
    155173       accounts
   1155291  accounts_pkey
$ # يمكنك مزج الخيارات، والحصول على مزيد من التفاصيل مع -x
$ oid2name -d alvherre -t accounts -f 1155291 -x
من قاعدة البيانات "alvherre":
  عقدة الملف     اسم الجدول      OID  المخطط  مساحة الجدول
------------------------------------------------------
    155173       accounts   155173  public  pg_default
   1155291  accounts_pkey  1155291  public  pg_default
$ # عرض مساحة القرص لكل كائن في قاعدة البيانات
$ du [0-9]* |
> while read SIZE FILENODE
> do
>   echo "$SIZE       `oid2name -q -d alvherre -i -f $FILENODE`"
> done
16            1155287  branches_pkey
16            1155289  tellers_pkey
17561            1155291  accounts_pkey
...
$ # نفسه، ولكن مرتب حسب الحجم
$ du [0-9]* | sort -rn | while read SIZE FN
> do
>   echo "$SIZE   `oid2name -q -d alvherre -f $FN`"
> done
133466             155173    accounts
17561            1155291  accounts_pkey
1177              16717  pg_proc_proname_args_nsp_index
...
$ # إذا كنت ترغب في رؤية ما هو موجود في مساحات الجداول، استخدم الدليل pg_tblspc
$ cd $PGDATA/pg_tblspc
$ oid2name -s
جميع مساحات الجداول:
     Oid  اسم مساحة الجدول
-------------------------
    1663       pg_default
    1664        pg_global
  155151         fastdisk
  155152          bigdisk
$ # ما هي قواعد البيانات التي لديها كائنات في مساحة الجدول "fastdisk"؟
$ ls -d 155151/*
155151/17228/  155151/PG_VERSION
$ # آه، ما هي قاعدة البيانات 17228 مرة أخرى؟
$ oid2name
جميع قواعد البيانات:
    Oid  اسم قاعدة البيانات  مساحة الجدول
----------------------------------
  17228       alvherre  pg_default
  17255     regression  pg_default
  17227      template0  pg_default
      1      template1  pg_default
$ # دعنا نرى ما هي الكائنات التي تمتلكها قاعدة البيانات هذه في مساحة الجدول.
$ cd 155151/17228
$ ls -l
total 0
-rw-------  1 postgres postgres 0 sep 13 23:20 155156
$ # حسنًا، هذا جدول صغير جدًا ... ولكن أي واحد هو؟
$ oid2name -d alvherre -f 155156
من قاعدة البيانات "alvherre":
  عقدة الملف  اسم الجدول
----------------------
    155156         foo

NAME

oid2name - convert PostgreSQL Object Identifiers (OIDs) to names

SYNOPSIS

oid2name [option...] [oid...]

DESCRIPTION

oid2name converts PostgreSQL Object Identifiers (OIDs) to their corresponding names. It can convert OIDs for databases, tables, columns, data types, functions, and operators. The tool connects to a PostgreSQL database to look up the names.

OPTIONS

-d dbname
Specifies the database to connect to. If not specified, the database name defaults to the user name.
-h hostname
Specifies the host name of the machine on which the server is running. Defaults to the value of the PGHOST environment variable or, if not set, to a local Unix-domain socket path.
-p port
Specifies the TCP port or local Unix domain socket file extension on which the server is listening for connections. Defaults to the value of the PGPORT environment variable or, if not set, to the default port (5432).
-U username
User name to connect as.
-w
Never prompt for a password.
-W
Force a password prompt to be issued.
--help
Show help about oid2name command line arguments.
--version
Show version information about oid2name command line arguments.

ENVIRONMENT

The following environment variables are supported by oid2name and also by the libpq connection library:

PGDATABASE
Default database name.
PGHOST
Default host name.
PGPORT
Default server port.
PGUSER
Default user name.
PGPASSWORD
Default password.

The PGHOST, PGPORT, PGDATABASE, and PGUSER environment variables are used to construct the default connection parameters.

NOTES

oid2name requires read access to the PostgreSQL system catalogs.

If no OIDs are provided on the command line, oid2name reads them from standard input.

EXAMPLES

To convert the OID 16384 (which typically represents the boolean data type) to its name in the default database: 

$ oid2name 16384
boolean

To convert multiple OIDs to their names, specifying the database and host: 

$ oid2name -d mydb -h localhost 1234 5678
mytable
mycolumn

To read OIDs from standard input and convert them: 

$ echo 1234 | oid2name
mytable
