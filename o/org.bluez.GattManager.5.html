org.bluez.GattManager(5) إدارة النظام لينكس org.bluez.GattManager(5)

الاسم

org.bluez.GattManager - توثيق واجهة برمجة تطبيقات GattManager الخاصة بـ BlueZ

الوصف

مدير GATT يسمح للتطبيقات الخارجية بتسجيل خدمات وملفات تعريف GATT.

تسجيل ملف تعريف يسمح للتطبيقات بالاشتراك في خدمات *بعيدة/عميل*.

تسجيل خدمة يسمح للتطبيقات بنشر خدمة GATT *محلية/خادم*، والتي تصبح متاحة بعد ذلك للأجهزة البعيدة. يتم تمثيل خدمة GATT بتسلسل هرمي لكائنات D-Bus حيث يتوافق العقدة الجذرية مع خدمة والعقد الفرعية تمثل خصائص واصفات تنتمي إلى تلك الخدمة. يجب على كل عقدة تنفيذ أحد الواجهات org.bluez.GattService(5) أو org.bluez.GattCharacteristic(5) أو org.bluez.GattDescriptor(5)، بناءً على السمة التي تمثلها. يجب على كل عقدة أيضًا تنفيذ واجهة خصائص D-Bus القياسية للكشف عن خصائصها. هذه الكائنات تمثل بشكل جماعي تعريف خدمة GATT.

لجعل تسجيل الخدمة بسيطًا، يتطلب bluetoothd(8) أن يتم تجميع جميع الكائنات التي تنتمي إلى خدمة GATT تحت مدير كائنات D-Bus الذي يدير فقط كائنات تلك الخدمة. لذلك، يجب أن تكون واجهة DBus.ObjectManager القياسية متاحة على مسار الخدمة الجذر. مثال لتسلسل هرمي للتطبيق يحتوي على خدمتي GATT منفصلتين قد يبدو كالتالي:

-> /com/example
  |   - org.freedesktop.DBus.ObjectManager
  |
  -> /com/example/service0
  | |   - org.freedesktop.DBus.Properties
  | |   - org.bluez.GattService1
  | |
  | -> /com/example/service0/char0
  | |     - org.freedesktop.DBus.Properties
  | |     - org.bluez.GattCharacteristic1
  | |
  | -> /com/example/service0/char1
  |   |   - org.freedesktop.DBus.Properties
  |   |   - org.bluez.GattCharacteristic1
  |   |
  |   -> /com/example/service0/char1/desc0
  |       - org.freedesktop.DBus.Properties
  |       - org.bluez.GattDescriptor1
  |
  -> /com/example/service1
    |   - org.freedesktop.DBus.Properties
    |   - org.bluez.GattService1
    |
   -> /com/example/service1/char0
        - org.freedesktop.DBus.Properties
        - org.bluez.GattCharacteristic1

عند تسجيل خدمة، سيقوم bluetoothd(8) تلقائيًا بالحصول على معلومات حول جميع الكائنات باستخدام مدير كائنات الخدمة. بمجرد تسجيل خدمة، لا ينبغي إزالة كائنات الخدمة. إذا تلقى bluetoothd(8) إشارة InterfacesRemoved من مدير كائنات الخدمة، فسوف يقوم بإلغاء تسجيل الخدمة على الفور. وبالمثل، إذا انفصل التطبيق عن الناقل، فسيتم إلغاء تسجيل جميع خدماته المسجلة تلقائيًا. سيتم تجاهل إشارات InterfacesAdded.

الأساليب

void RegisterApplication(object application, dict options)

يسجل تسلسل هرمي لخدمات GATT المحلية كما هو موضح أعلاه (خادم GATT) و/أو ملفات تعريف GATT (عميل GATT).

يحدد مسار كائن التطبيق مع معرف اتصال ناقل النظام D-Bus هوية التطبيق الذي يسجل خدمة GATT ( org.bluez.GattService(5) ) و/أو ملف تعريف ( org.bluez.GattProfile(5) ).

الأخطاء المحتملة:

org.bluez.Error.InvalidArguments
org.bluez.Error.AlreadyExists

void UnregisterApplication(object application)

يقوم هذا بإلغاء تسجيل الخدمات و/أو ملفات التعريف التي تم تسجيلها مسبقًا باستخدام RegisterApplication(). يجب أن يتطابق معلم مسار الكائن مع نفس القيمة التي تم استخدامها عند التسجيل.

الأخطاء المحتملة:

org.bluez.Error.InvalidArguments
org.bluez.Error.DoesNotExist
