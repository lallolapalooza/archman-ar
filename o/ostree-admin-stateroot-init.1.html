ostree-admin-stateroot-init(1)

الحزمة: ostree

التراخيص: LGPL-2.0-or-later

OSTREE ADMIN STATERO(1) ostree admin stateroot-init OSTREE ADMIN STATERO(1)

الاسم

ostree-admin-stateroot-init - تهيئة حالة فارغة لنظام تشغيل معين

الاستخدام

ostree admin stateroot-init {STATEROOT}

الوصف

يقوم بتهيئة stateroot جديد (يُعرف أيضًا باسم "osname") لنظام تشغيل. يضمن وجود الدلائل الفرعية الأساسية لـ /var (/tmp، /lib، /run، و /lock) وتهيئة STATEROOT المحدد كـ stateroot لـ OSTree. يتكون كل موقع نشر من var مشترك واحد ومجموعة من عمليات النشر (chroots).

مثال

$ ostree admin stateroot-init exampleos

        ostree/deploy/exampleos initialized as OSTree stateroot
OSTree
