opus_encoderctls - وحدات تحكم متعلقة بالمُشفّر


- هذه وحدات ماكرو ملائمة للاستخدام مع واجهة opus_encode_ctl.

الوصف التفصيلي

هذه وحدات ماكرو ملائمة للاستخدام مع واجهة opus_encode_ctl .

يتم استخدامها لإنشاء سلسلة الوسائط المناسبة لتلك المكالمة، مع تمرير النوع والحجم الصحيحين وما إلى ذلك كما هو متوقع لكل طلب معين.

بعض الأمثلة على الاستخدام:

int ret;
ret = opus_encoder_ctl(enc_ctx, OPUS_SET_BANDWIDTH(OPUS_AUTO));
if (ret != OPUS_OK) return ret;
opus_int32 rate;
opus_encoder_ctl(enc_ctx, OPUS_GET_BANDWIDTH(&rate));
opus_encoder_ctl(enc_ctx, OPUS_RESET_STATE);
