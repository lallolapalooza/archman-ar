NAME

opam-option - opam option processing

SYNOPSIS

opam-option [ OPTIONS ] [ SUBCOMMAND ]

DESCRIPTION

This man page describes the general options available for most opam commands.

Use opam(1) for the full documentation.

ARGUMENTS

The SUBCOMMAND is the command to run, followed by its own arguments.

OPTIONS

--help, -h
Display help message and exit
--version, -v
Display version information and exit
--color [auto|always|never]
Force colors in output.
--log-level [debug|info|warn|error|fatal]
Set the log level. Default: warn.
--debug
Shorthand for --log-level debug.
--no-auto-update
Do not update the opam repository automatically.
--sync-cache
Synchronise the local opam repository with the remote, but do not proceed with the rest of the operation.
--debug-level LEVEL
Sets the internal debugging level for the solver (integer, higher is more verbose).
--solver SOLVER
Use the specified solver.

COMMON OPTIONS

--root DIR
Use DIR as the repository root.
--all-switches
Operate on all installed switches.
--all-install-dirs
Operate on all installed switch prefixes.
--config-file FILE
Use FILE as configuration file.
--global-cache
Use the global cache directory.
--cache-policy [copy|symlink|hardlink]
Sets the cache policy. Default: symlink.
--no-cache
Disable the cache.

ENVIRONMENT

The following environment variables can be used to configure opam:

OPAMROOT
The opam root directory.
OPAMKEEPWORD
A list of words that should not be removed from packages names.
OPAMDEPEXT
If set, opam will check for dependencies that are only available as compiler plugins.
OPAM_REPLY_TO_USER
If set to a non-empty string, opam will ask the user for confirmation before making destructive changes.

CLI VERSION

This manual page applies to opam version 2.4.1.

EXIT STATUS

1
An internal error occurred (e.g. a bug).
2
An invalid command line option was specified.
3
A required command line argument was missing.
4
An invalid argument value was supplied.
5
A lock could not be acquired for the operation.
20
There is no solution to the user request. This can be caused by asking to install two incompatible packages, for example.
30
Error in package definition, or other metadata files. Using --strict raises this error more often.
31
Package script error. Some package operations were unsuccessful. This may be an error in the packages or an incompatibility with your system. This can be a partial error.
40
Sync error. Could not fetch some remotes from the network. This can be a partial error.
50
Configuration error. Opam or system configuration doesn't allow operation, and needs fixing.
60
Solver failure. The solver failed to return a sound answer. It can be due to a broken external solver, or an error in solver configuration.
99
Internal error. Something went wrong, likely due to a bug in opam itself.
130
User interrupt. SIGINT was received, generally due to the user pressing Ctrl-C.
0
on success.
123
on indiscriminate errors reported on standard error.
124
on command line parsing errors.
125
on unexpected internal errors (bugs).
