oath_strerror(3)

الحزمة: oath-toolkit

التراخيص: GPL-3.0-or-later

oath_strerror(3) liboath oath_strerror(3)

الاسم

oath_strerror - دالة API

الملخص

#include <oath.h>

const char * oath_strerror(int err);

المعاملات

int err
رمز خطأ liboath

الوصف

تحويل رمز الإرجاع إلى سلسلة نصية قابلة للقراءة البشرية تشرح سبب رمز الخطأ المحدد.

يمكن استخدام هذه السلسلة النصية لإخراج رسالة تشخيصية للمستخدم.

هذه الدالة هي واحدة من الدوال القليلة في المكتبة التي يمكن استخدامها دون استدعاء ناجح لـ oath_init().

قيمة الإرجاع

تُرجع مؤشرًا إلى سلسلة نصية مخصصة ثابتًا تحتوي على شرح لرمز الخطأ err.

منذ

1.8.0
