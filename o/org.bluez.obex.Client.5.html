الطرق

object CreateSession(string destination, dict args)

يقوم بالاتصال بعنوان الوجهة ثم يمضي في إنشاء كائن جلسة OBEX الذي ينفذ الواجهة org.bluez.obex.Session(5).

المعلمة الأخيرة هي قاموس للاحتفاظ بالمعلمات الاختيارية أو الخاصة بالنوع.

قيم args الممكنة:

string Target
نوع الجلسة التي سيتم إنشاؤها.

القيم الممكنة:

"ftp"
"map"
"opp"
"pbap"
"sync"
"bip-avrcp"
string Source
العنوان المحلي الذي سيتم استخدامه.
byte Channel
القناة التي سيتم استخدامها.
uint16 PSM
L2CAP PSM التي سيتم استخدامها.

الأخطاء الممكنة:

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed

void RemoveSession(object session)

يقوم بفصل وإزالة الجلسة التي تم إنشاؤها سابقًا بواسطة CreateSession() وإلغاء أي عمليات نقل معلقة.
