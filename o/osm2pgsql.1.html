الحزمة: osm2pgsql

MIDDLE OPTIONS

--drop
Remove all objects from the database before importing. This is the default. It does not work well with small imports. The default is disabled. The file will stay on disk after import, use --drop to remove it (but you can’t do updates then).
--middle-schema=SCHEMA
Use PostgreSQL schema SCHEMA for all tables, indexes, and functions in the middle. The schema must exist in the database and be writable by the database user. By default the schema set with --schema is used, or public if that is not set.
--middle-with-nodes
When a flat nodes file is used, nodes are not stored in the database. Use this option to force storing nodes with tags in the database, too.

خيارات الإخراج

-O, --output=OUTPUT
تحدد الإخراج المراد استخدامه. حاليًا يدعم osm2pgsql pgsql و flex و null. pgsql هو الإخراج الافتراضي لا يزال متاحًا للتوافق مع الإصدارات السابقة. يجب أن تستخدم الإعدادات الجديدة الإخراج flex الذي يسمح بتكوين أكثر مرونة. الإخراج null لا يكتب شيئًا وهو مفيد فقط للاختبار أو مع --slim لإنشاء جداول رفيعة.
-S, --style=FILE
ملف الأسلوب. يحدد هذا كيفية استيراد البيانات إلى قاعدة البيانات، ويعتمد تنسيقه على الإخراج. (بالنسبة للإخراج pgsql، الافتراضي هو /usr/share/osm2pgsql/default.style، للإخراجات الأخرى لا يوجد افتراضي.)

خيارات إخراج PGSQL

--tablespace-main-data=TABLESPC
تخزين جداول البيانات في مساحة جداول PostgreSQL TABLESPC.
--tablespace-main-index=TABLESPC
تخزين الفهارس في مساحة جداول PostgreSQL TABLESPC.
--latlong
تخزين الإحداثيات بدرجات خطوط العرض والطول.
-m, --merc
تخزين الإحداثيات في إسقاط مركاتور الكروي (Web Mercator، EPSG:3857) (الافتراضي).
-E, --proj=SRID
استخدام إسقاط EPSG:SRID.
-p, --prefix=PREFIX
بادئة لأسماء الجداول (الافتراضي: planet_osm). يؤثر هذا الخيار على أسماء جداول الإخراج الوسيطة وأسماء جداول إخراج pgsql.
--tag-transform-script=SCRIPT
تحديد برنامج نصي Lua لمعالجة تصفية العلامات وتسويتها. يحتوي البرنامج النصي على دوال رد اتصال للعقد والمسارات والعلاقات، والتي تأخذ كل منها مجموعة من العلامات وتعيد مجموعة علامات محسنة ومفلترة يتم كتابتها بعد ذلك إلى قاعدة البيانات.
-x, --extra-attributes
تضمين السمات (اسم المستخدم، معرف المستخدم، معرف التغيير، الطابع الزمني، والإصدار). يتطلب هذا أيضًا إدخالات إضافية في ملف الأسلوب الخاص بك.
-k, --hstore
إضافة علامات بدون عمود إلى عمود hstore إضافي (مفتاح/قيمة) في جداول قاعدة البيانات.
-j, --hstore-all
إضافة جميع العلامات إلى عمود hstore إضافي (مفتاح/قيمة) في جداول قاعدة البيانات.
-z, --hstore-column=PREFIX
إضافة عمود hstore إضافي (مفتاح/قيمة) يسمى PREFIX يحتوي على جميع العلامات التي لها مفتاح يبدأ بـ PREFIX، على سبيل المثال \--hstore-column "name:" سينتج عمود hstore إضافي يحتوي على جميع العلامات name:xx.
--hstore-match-only
احتفظ فقط بالكائنات التي لها قيمة في واحد على الأقل من الأعمدة غير hstore.
--hstore-add-index
إنشاء فهارس لجميع أعمدة hstore بعد الاستيراد.
-G, --multi-geometry
عادةً ما يقوم osm2pgsql بتقسيم الهندسات متعددة الأجزاء إلى صفوف قاعدة بيانات منفصلة لكل جزء. لذلك يمكن لكائن OSM واحد استخدام عدة صفوف في جداول الإخراج. باستخدام هذا الخيار، يقوم osm2pgsql بدلاً من ذلك بإنشاء ميزات هندسية متعددة في جداول PostgreSQL.
-K, --keep-coastlines
الاحتفاظ ببيانات الخط الساحلي بدلاً من تصفيتها. افتراضيًا، سيتم تجاهل الكائنات المسماة natural=coastline بناءً على افتراض أنه سيتم استخدام Shapefiles التي تم إنشاؤها بواسطة OSMCostline (https://osmdata.openstreetmap.de/) لبيانات الخط الساحلي.
--reproject-area
حساب عمود المساحة باستخدام إحداثيات إسقاط مركاتور الكروي حتى لو تم استخدام إسقاط مختلف للهندسات.
--output-pgsql-schema=SCHEMA
استخدام مخطط PostgreSQL SCHEMA لجميع الجداول والفهارس والدوال في إخراج pgsql. يجب أن يوجد المخطط في قاعدة البيانات وأن يكون قابلاً للكتابة بواسطة مستخدم قاعدة البيانات. افتراضيًا، يتم استخدام المخطط المحدد مع --schema، أو public إذا لم يتم تعيينه.

خيارات انتهاء الصلاحية

-e, --expire-tiles=[MIN_ZOOM-]MAX-ZOOM
إنشاء قائمة انتهاء صلاحية للبلاطات.
-o, --expire-output=FILENAME
اسم ملف الإخراج لقائمة البلاطات المنتهية الصلاحية.
--expire-bbox-size=SIZE
الحد الأقصى لحجم المضلع لانتهاء صلاحية المضلع بأكمله، وليس فقط الحدود.

خيارات متقدمة

-I, --disable-parallel-indexing
تعطيل التجميع المتوازي وإنشاء الفهارس على جميع الجداول، وبناء فهرس تلو الآخر.
--number-processes=THREADS
يحدد عدد الخيوط المتوازية المستخدمة لعمليات معينة.
