OSSL_SELF_TEST_set_callback(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

OSSL_SELF_TEST_SET_CALLBACK(3ssl) OpenSSL OSSL_SELF_TEST_SET_CALLBACK(3ssl)

الاسم

OSSL_SELF_TEST_set_callback, OSSL_SELF_TEST_get_callback - تحديد دالة استدعاء لمعالجة الاختبارات الذاتية

الموجز

#include <openssl/self_test.h>
void OSSL_SELF_TEST_set_callback(OSSL_LIB_CTX *ctx, OSSL_CALLBACK *cb, void *cbarg);
void OSSL_SELF_TEST_get_callback(OSSL_LIB_CTX *ctx, OSSL_CALLBACK **cb, void **cbarg);

الوصف

تعيين أو الحصول على دالة الاستدعاء الاختيارية للتطبيق (وحجة الاستدعاء) التي يتم استدعاؤها أثناء الاختبار الذاتي. دالة استدعاء التطبيق OSSL_CALLBACK(3) مرتبطة بـ OSSL_LIB_CTX. تتلقى دالة الاستدعاء الخاصة بالتطبيق معلومات حول اختبار ذاتي قيد التشغيل، ويمكنها إرجاع نتيجة إلى الاختبار الذاتي الذي يستدعيها. راجع openssl-core.h(7) لمزيد من المعلومات حول دالة الاستدعاء.

قيم الإرجاع

OSSL_SELF_TEST_get_callback() ترجع دالة الاستدعاء وحجة الاستدعاء التي تم تعيينها عبر OSSL_SELF_TEST_set_callback() للسياق المعطى للمكتبة ctx. ستكون المعلمات المرجعة NULL إذا لم يتم استدعاء OSSL_SELF_TEST_set_callback().
