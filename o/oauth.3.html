طريقة التوقيع المستخدمة لتوقيع الطلب.

المُعدِّدات:

OA_HMAC
استخدام طريقة توقيع الطلب HMAC-SHA1
OA_RSA
استخدام توقيع RSA
OA_PLAINTEXT
استخدام توقيع نص عادي (للاختبار فقط)

char* oauth_body_hash_data (size_t length, const char * data)

حساب تجزئة الجسم (sha1sum) للبيانات المعطاة وإرجاع معلمة oauth_body_hash=xxxx لإضافتها إلى الطلب. يجب تحرير السلسلة المرجعة بواسطة الدالة المتصلة. السلسلة المرجعة ليست مهيأة لـ URL بعد وهي مناسبة لتمريرها كمعلمة إلى oauth_catenc.

انظر http://oauth.googlecode.com/svn/spec/ext/body_hash/1.0/oauth-bodyhash.html

المعلمات:

length طول معلمة البيانات بالبايت
data لحساب التجزئة لها

char* oauth_http_get (const char * u, const char * q)

إجراء طلب HTTP GET، الانتظار حتى الانتهاء، وإرجاع محتوى الرد. (يتطلب libcurl أو عميل HTTP سطر الأوامر).

إذا تم تجميع البرنامج بدون libcurl، تقوم هذه الدالة باستدعاء أمر تنفيذي لسطر الأوامر محدد في متغير البيئة OAUTH_HTTP_GET_CMD - القيمة الافتراضية هي curl -sA 'liboauth-agent/0.1' '%u' حيث يتم استبدال %u بعنوان URL ومعلمات الاستعلام.

مثال bash & wget: export OAUTH_HTTP_CMD='wget -q -U 'liboauth-agent/0.1' '%u' '

تحذير: هذه دالة مؤقتة. إنها مريحة ومفيدة للاختبار أو تطوير كود OAuth. لكن لا تعتمد على هذه الدالة لتصبح جزءًا ثابتًا من هذه الواجهة. فهي لا تقوم بالكثير من التحقق من الأخطاء أو معالجتها على سبيل المثال..

ملاحظة: يتم دمج u و q ببساطة مع '؟' في الوسط، ما لم يكن q هو NULL. في هذه الحالة، سيتم استخدام u فقط.

المعلمات:

u عنوان URL أساسي للحصول عليه
q سلسلة استعلام لإرسالها مع طلب HTTP أو NULL.

القيمة المرجعة:

في حالة حدوث خطأ، يتم إرجاع NULL؛ وإلا، مؤشر إلى المحتوى المستلم من خادم HTTP. يجب تحرير الأخير بواسطة المستدعي.

char* oauth_sign_url (const char * url, const char * c_key, const char * c_secret, const char * t_key, const char * t_secret, OAuthMethod method, const char * http_method, char **postargs)

Sign the given URL according to OAuth Core 1.0, section 5.4.1, signature method defined in method. http://oauth.net/core/1.0/#sig_method Parameters:

url the url to sign. The URL may contain parameters which are then extracted and used to form the signature base string.
c_key consumer key
c_secret consumer secret
t_key token key
t_secret token secret
method Specify the signature method to use. It is of type OAuthMethod and most likely OA_HMAC.
http_method The HTTP request method to use (ie 'GET', 'PUT',..) If NULL is given as 'http_method' this defaults to 'GET' when 'postargs' is also NULL and when postargs is not NULL 'POST' is used.
postargs if not NULL, this is assumed to be an OAuth 1.0a entity-body parameter list, and 'http_method' defaults to 'POST'. Example: "x=1&y=2". Can be generated with oauth_serialize_url_parameters

Returns:

the signed url or NULL if an error occurred.

Examples:
tests/oauthbodyhash.c, tests/oauthexample.c, and tests/oauthtest.c.

splits the given url into a parameter array. (see oauth_serialize_url and oauth_serialize_url_parameters for the reverse)

Parameters:

Returns:

number of parameter(s) in array.
