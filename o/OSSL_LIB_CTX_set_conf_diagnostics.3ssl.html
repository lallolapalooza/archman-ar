OSSL_LIB_CTX_set_conf_diagnostics(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

OSSL_LIB_CTX_SET_CONF_DIAGNOSTICS(3ssl) OpenSSL OSSL_LIB_CTX_SET_CONF_DIAGNOSTICS(3ssl)

الاسم

OSSL_LIB_CTX_set_conf_diagnostics, OSSL_LIB_CTX_get_conf_diagnostics - تعيين واسترجاع تشخيصات التكوين

الملخص

#include <openssl/crypto.h>
void OSSL_LIB_CTX_set_conf_diagnostics(OSSL_LIB_CTX *ctx, int value);
int OSSL_LIB_CTX_get_conf_diagnostics(OSSL_LIB_CTX *ctx);

الوصف

OSSL_LIB_CTX_set_conf_diagnostics() تقوم بتعيين قيمة علامة تشخيصات التكوين. إذا كانت value غير صفرية، يمكن لتحليل وتطبيق بيانات التكوين اللاحقة الإبلاغ عن أخطاء كان سيتم تجاهلها. على وجه الخصوص، أي أخطاء في وحدة تكوين ssl ستؤدي إلى فشل استدعاءات SSL_CTX_new(3) و SSL_CTX_new_ex(3). يمكن أيضًا تعيين علامة تشخيصات التكوين عند تحميل ملف تكوين إلى OSSL_LIB_CTX باستخدام OSSL_LIB_CTX_load_config(3). إذا قام التكوين بتعيين قيمة config_diagnostics كما هو موصوف في config(5)، فستتجاوز القيمة التي تم تعيينها بواسطة OSSL_LIB_CTX_set_conf_diagnostics() قبل تحميل ملف التكوين.

OSSL_LIB_CTX_get_conf_diagnostics() تعيد القيمة الحالية لعلامة تشخيصات التكوين.

قيم الإرجاع

OSSL_LIB_CTX_get_conf_diagnostics() تعيد 0 إذا كان لا ينبغي إجراء تشخيصات التكوين، وقيمة غير صفرية بخلاف ذلك.

انظر أيضًا

SSL_CTX_new(3)، OSSL_LIB_CTX_load_config(3)، config(5)
