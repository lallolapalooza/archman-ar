opam-admin-help(1)

الحزمة: opam

التراخيص: LGPL-2.1-only

OPAM ADMIN-HELP(1) دليل Opam admin OPAM ADMIN-HELP(1)

الاسم

opam admin-help - عرض المساعدة حول opam admin والأوامر الفرعية لـ opam admin.

الملخص

opam admin help [--man-format=FMT] [OPTION]… [TOPIC]

الوصف

يطبع المساعدة حول أوامر opam admin.

استخدم `opam admin help topics' للحصول على القائمة الكاملة لمواضيع المساعدة.

الحجج

TOPIC
الموضوع الذي تريد الحصول على مساعدة بشأنه.

الخيارات

--man-format=FMT (افتراضي=pager)
عرض المخرجات بالتنسيق FMT. يجب أن تكون القيمة FMT إحدى القيم: auto، pager، groff أو plain. مع auto، يكون التنسيق pager أو plain كلما كان المتغير TERM في البيئة هو dumb أو غير معرف.

الخيارات الشائعة

--help[=FMT] (افتراضي=auto)
عرض هذه المساعدة بالتنسيق FMT. يجب أن تكون القيمة FMT إحدى القيم: auto، pager، groff أو plain. مع auto، يكون التنسيق pager أو plain كلما كان المتغير TERM في البيئة هو dumb أو غير معرف.
--version
عرض معلومات الإصدار.

حالة الخروج

opam admin help يخرج بالقيم التالية:

0
عند النجاح.
123
عند حدوث أخطاء غير مميزة يتم الإبلاغ عنها في المخرجات القياسية.
124
عند حدوث أخطاء في تحليل سطر الأوامر.
125
عند حدوث أخطاء داخلية غير متوقعة (أخطاء برمجية).
