opendmarc-params(8) دليل مدير النظام opendmarc-params(8)

الاسم

opendmarc-params - أداة إعداد معلمات التقارير لـ OpenDMARC

الموجز

opendmarc-params [خيارات] نطاق

الوصف

يقوم opendmarc-params بتسجيل عنوان تقرير محدد للنطاق domain المحدد ووضع علامة عليه كـ "مقفل" في قاعدة بيانات طلبات التقارير. يتم ذلك للسماح للمسؤول بفرض إنشاء التقارير وإرسالها إلى عنوان محدد بغض النظر عن البيانات التي قد تكون موجودة (أو غير موجودة) في DNS للنطاق المحدد.

الخيارات

--dbhost=host
يحاول الاتصال بخادم قاعدة البيانات على host المحدد. الافتراضي هو "localhost".
--dbname=name
يطلب الاتصال بقاعدة البيانات المسماة name. الافتراضي هو "opendmarc".
--dbpasswd=password
يحاول المصادقة مع خادم قاعدة البيانات باستخدام password المحدد. الافتراضي هو "opendmarc".
--dbport=port
يحاول الاتصال بقاعدة البيانات على منفذ TCP المحدد port. الافتراضي هو 3306.
--dbuser=user
يحاول المصادقة مع خادم قاعدة البيانات كمستخدم user المحدد. الافتراضي هو "opendmarc".
--help
يطبع رسالة استخدام ويخرج.
--rua=string
يضبط عنوان URI للتقرير للنطاق domain المحدد إلى string المحدد.
--unlock
يفتح قفل السجل للنطاق domain المحدد.
--verbose
يطلب إخراجًا مفصلاً.
--version
يطبع رقم الإصدار ويخرج.

الإصدار

تغطي صفحة الدليل هذه إصدار opendmarc-params الذي تم شحنه مع الإصدار 1.4.2 من OpenDMARC.
