opensips(8)

الحزمة: opensips

التراخيص: GPL

OpenSIPS(8) خادم SIP للمكالمات الصوتية عبر بروتوكول الإنترنت OpenSIPS(8)

الاسم

opensips - خادم SIP (RFC3261, RFC3263) مرن وقوي للمكالمات الصوتية عبر بروتوكول الإنترنت (VoIP)

ملخص

opensips [ -hcCrRvdDEVT ] [ -f ملف-التكوين ] [ -l العنوان ] [ -n عدد-العمليات ] [ -N عدد-عمليات-tcp ] [ -b الحد-الأقصى-حجم-المخزن-المؤقت-للاستقبال ] [ -m حجم-الذاكرة-المشتركة ] [ -w دليل-العمل ] [ -W طريقة ] [ -t دليل-chroot ] [ -u uid ] [ -g gid ] [ -P ملف-pid ] [ -i مسار-fifo ] [ -x مسار-المقبس ]

الوصف

OpenSIPS هو خادم VoIP قائم على SIP يعمل على معظم أنظمة التشغيل الشبيهة بيونكس. يدعم طبقات نقل UDP و TCP و TLS. من بين ميزاته:

  • خادم وكيل SIP، خادم تسجيل SIP، خادم إعادة توجيه SIP، خادم موقع SIP، خادم تطبيقات SIP
  • لغة معالجة المكالمات (RFC3880)
  • دعم ENUM
  • اجتياز NAT من جانب الخادم
  • موازنة التحميل
  • مصادقة، تفويض، ومحاسبة (AAA) مع واجهة خلفية لقاعدة البيانات (MySQL، Postgres، Unixodbc) أو RADIUS
  • الصوت، الفيديو، الرسائل الفورية، والحضور

الخيارات

-h
يعرض وصفًا موجزًا للاستخدام، بما في ذلك جميع الخيارات المتاحة.
-c
يتحقق من ملف التكوين ويعرض قائمة الأسماء المستعارة وواجهات الاستماع.
-C
مشابه لـ -c ولكنه يتحقق أيضًا من علامات الوظائف المصدرة من كتل المسار المضمنة.
-r
يستخدم DNS للتحقق مما إذا كان من الضروري إضافة حقل "received=" إلى "via".
-R
نفس -r ولكنه يستخدم DNS العكسي.
-v
يقوم بتشغيل فحص مضيف "via" عند إعادة توجيه الردود.
-d
يقوم بتشغيل التصحيح، ويزيد تكرار -d مستوى التصحيح.
-D
يشغل opensips في المقدمة (لا ينفصل إلى وضع daeomon).
-E
يرسل جميع رسائل السجل إلى stderr.
-T
يعطل دعم TCP.
-V
يعرض رقم الإصدار.
-f ملف-التكوين
يقرأ التكوين من ملف-التكوين (الافتراضي /etc/opensips/opensips.cfg ).
-l العنوان
يستمع على العنوان/الواجهة المحددة. تعني -l المتعددة الاستماع على عناوين متعددة. تنسيق العنوان هو [proto:]address[:port]، حيث proto = udp|tcp و address = host|ip_address|interface_name. مثال: -l localhost، -l udp:127.0.0.1:5080، -l eth0:5062. السلوك الافتراضي هو الاستماع على جميع واجهات ipv4.
-n عدد-العمليات
يحدد عدد العمليات الفرعية المتفرعة لكل واجهة (الافتراضي 8).
-N عدد-عمليات-tcp
يحدد عدد العمليات الفرعية المتفرعة لمعالجة اتصالات TCP الواردة (الافتراضي يساوي -n ).
-b الحد-الأقصى-حجم-المخزن-المؤقت-للاستقبال
أقصى حجم للمخزن المؤقت للاستقبال لن تتجاوزه إجراءات الفحص التلقائي حتى لو سمحت به نظام التشغيل.
-m حجم-الذاكرة-المشتركة
حجم الذاكرة المشتركة التي سيتم تخصيصها (بالميجابايت).
-w دليل-العمل
يحدد دليل العمل. في حالة الاحتمال الضئيل جدًا أن يتعطل opensips، سيتم إنشاء ملف النواة هنا.
-W طريقة
تحديد طريقة poll.
-t دليل-chroot
يجبر opensips على chroot بعد قراءة ملف التكوين.
-u uid
يغير معرف المستخدم الذي يعمل تحته opensips.
-g gid
يغير معرف المجموعة الذي يعمل تحته opensips.
-P ملف-pid
ينشئ ملفًا يحتوي على معرف العملية (pid) لعملية opensips الرئيسية.
-i مسار-fifo
ينشئ fifo، مفيد لمراقبة حالة opensips.
-x مسار-المقبس
ينشئ مقبس يونكس، مفيد لمراقبة حالة opensips (نفس -i مسار-fifo ولكن باستخدام مقابس يونكس بدلاً من ذلك).
